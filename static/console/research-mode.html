Отдельная экспериментальная память

Минимальный профиль

VELANTRIM_PROFILE=research
VELANTRIM_DB_PATH=./data/velantrim_research.db
VELANTRIM_NGRAM_DB=./data/velantrim_research_ngram.db
ENABLE_FRACTAL_ROUTER=1
ENABLE_RETRIEVAL_PATH=1
ENABLE_RESEARCH_API=1

Порядок реализации

  1. Создать config/exocortex-research.env с отдельными путями БД.
  2. Добавить ResearchStore или безопасный wrapper вокруг SQLiteGraphStore.
  3. Добавить POST /research/query без изменения стабильного POST /query.
  4. Вернуть memory_route и RetrievalPath в JSON-ответе.
  5. Добавить отдельную страницу /console/research для тестов.
Сейчас это красивый overview и архитектурный контракт. Runtime /research/query ещё не включён, чтобы stable V8.6 не получила случайные экспериментальные записи.
