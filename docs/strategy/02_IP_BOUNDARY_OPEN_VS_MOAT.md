# 2. ⚖️ IP-граница: Open (Crystal) vs Moat (Titan)

**Дата:** 2026-06-06 · [← назад к индексу](README.md)

## 🚧 Правило, которое тебя защищает

NLnet/NGI Zero финансирует **только то, что публикуется под признанной open-source лицензией целиком** ([eligibility](https://nlnet.nl/commonsfund/eligibility/)). Значит:

- ❌ Нельзя взять грант и оставить результат закрытым.
- ✅ Но чистый сплит Crystal/Titan = твой **IP-firewall**: решаешь **по каждой возможности отдельно**, что уходит в commons (грант, AGPL-3.0), а что остаётся продуктовым моатом.

> 💡 Принцип: **открытое ядро (open core) + продуктовая оболочка (product shell)**. Открытое усиливает экосистему и репутацию; закрытое держит ценность, за которую платят.

Бейджи: 💎 **OPEN→Crystal** · 🔒 **MOAT→Titan** · ⚖️ **CONTESTED** (твоё решение).

---

## 💎 OPEN → Crystal (кандидаты в грант)

Это «инфраструктура доверия к памяти» — максимально ценно как commons, и почти не раскрывает продуктовую магию.

| Модуль / возможность | Почему открывать | Что это даёт |
|---|---|---|
| Memory core + ESM + bi-temporal | базовый протокол честной памяти | стандарт, переиспользуемость |
| TruthGate (type-aware) | «единственный вход в канон» — образец архитектуры | доверие, цитируемость |
| Provenance receipts (replayable) | verifiable infrastructure = ядро ценностей NGI | сильный грантовый пункт |
| **GDPR-набор** (erasure/restrict/RoPA/crypto/PII/audit) | European dimension + право субъекта данных | почти «бесплатный» вес заявки |
| Contradiction detection (детерминированная) | immune-signal, проверяемо | reusability |
| Retrieval-примитивы (vector + graph-walk + BM25/RRF база) | переиспользуемый поиск | interop |
| **Capability-based tool registry + MCP gateway** | открытый стандарт MCP = interop/commons | см. [RFC](05_RFC_MCP_GATEWAY.md) |
| Graph observability / `integrity` отчёт | auditability | доверие, «value for money» |
| Swappable backends (sqlite/kuzu/ladybug/neo4j) | no vendor lock-in | принцип NGI |
| Decay/forgetting примитивы (база) | переиспользуемая «физиология памяти» | research-вклад |

---

## 🔒 MOAT → Titan (продуктовая ценность, держим приватным)

Это то, за что платит конечный пользователь/B2B — оркестрация, готовый интеллект и курированное знание.

| Модуль / возможность | Почему моат |
|---|---|
| LLM-оркестрация (`llm_router`, multi-provider, multilingual, `tts_router`) | интеграционная ценность, операционные секреты провайдеров |
| Высшая когниция (`noetic_core`, `essence`, `velum`, `perspectives`, `concept_emergence`) | твой главный исследовательский дифференциатор |
| Goals / curiosity / volition / identity / welfare (L6) | «агентность» — продуктовая магия |
| **Курированная база знаний** (готовый контент invariant/variant/practical, `world_skills_core`) | данные = моат; **таксономию можно открыть, контент — нет** |
| File generators (DOCX/PDF/PPTX/XLSX…) | прикладная фича продукта |
| Интегрированный продукт/UX, профили деплоя, оркестрация pipeline | сборка = продукт |
| Готовые промпты, tone-of-voice, system-идентичность | бренд/差ференциация |

## ⚖️ CONTESTED — реши сам, где линия

| Возможность | Вариант OPEN | Вариант MOAT | Рекомендация |
|---|---|---|---|
| Hybrid retriever | базовый BM25+Dense+RRF | продвинутый тюнинг/веса под домен | 💎 база открыта, 🔒 тюнинг моат |
| Causal graph | 15 типов + chain/contradictions | продвинутые reasoning-стратегии поверх | 💎 граф открыт, 🔒 reasoning-движок моат |
| База знаний | **таксономия/схема** (invariant/variant/practical) | **наполнение** (тысячи фактов) | 💎 схема в грант, 🔒 контент — продукт |
| Умное забывание | примитивы decay/FSRS | политики/калибровка под продукт | 💎 примитивы, 🔒 политики |
| Bio-слои (fractal/epigenetic) | прототипы как research | продуктовая интеграция | 💎 прототипы (как у Crystal), 🔒 интеграция |

## 🧭 Практические правила

1. **Грантовый deliverable = то, что целиком ляжет в Crystal под AGPL-3.0.** Если фича тянет за собой моат — выдели открытую часть (примитив/протокол), а ценность оставь в Titan.
2. **Данные ≠ код.** Можно открыть формат/таксономию знания, не открывая накопленный корпус. Это законный и сильный сплит.
3. **Открывай протоколы, держи реализации-«мозги».** MCP-доступ, receipt-формат, ESM-контракт — открыть. Оркестрацию и высшую когницию — придержать.
4. **Лицензионная гигиена.** В Titan-файлах, которые когда-нибудь уйдут в Crystal, держи заголовки чистыми; не примешивай приватные зависимости к open-кандидатам.
5. **Двойная выгода.** Каждый шаг [плана закалки Titan](04_TITAN_HARDENING_PLAN.md), помеченный 💎, одновременно рождает открытый Crystal-deliverable → грант оплачивает закалку продукта.

> ✅ Итог: эта граница позволяет брать деньги NLnet за **усиление commons**, не отдавая при этом продуктовый моат. Решение по каждой ⚖️-строке — за тобой; по 💎/🔒 — уже понятно.
