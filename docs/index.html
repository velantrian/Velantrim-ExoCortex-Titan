📲 Установить на смартфон (PWA)

  1. Откройте Research PWA в Chrome (Android) или Safari (iPhone).
  2. Android: меню ⋮ → Установить приложение / Добавить на главный экран.
  3. iPhone: кнопка «Поделиться» → На экран «Домой».

После установки иконка откроет приложение в полноэкранном режиме.
