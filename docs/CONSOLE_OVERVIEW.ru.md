```

├── static\console\index.html    ← главная страница консоли
```

## 🚀 Быстрый старт (3 шага)

### 1. Ключ сервера

В файле `.env` в корне проекта:

```env
VELANTRIM_API_KEY=ваш_секретный_ключ
```

Если ключа нет — скрипт запуска подставит dev-ключ для localhost.

### 2. Запуск

```powershell
cd "C:\path\to\Velantrim-ExoCortex-Titan"
.\scripts\start_console.ps1
```

Окно PowerShell **не закрывайте** — пока оно открыто, сервер работает.

### 3. Браузер

Откройте (после Ctrl+F5):

**http://127.0.0.1:8755/console/?v=40**

## 🌍 Язык и тема по умолчанию

| Настройка | Поведение при первом открытии |
|-----------|-------------------------------|
| **Язык** | Русский — если в системе/браузере `ru`. English, Deutsch, Français и др. — **английский** (немецкий добавите позже в переключатель). |
| **Тема** | **Светлая** — если Windows/macOS в light mode. **Тёмная** — если dark mode. |
| **Переключатели** | В шапке консоли — RU/EN и палитра тем **остаются**, выбор сохраняется в браузере. |

Данные консоли (чаты, ключи в полях) хранятся в **localStorage** браузера с префиксом `velantrim_titan_console_*` — отдельно от V8.6.

---

## 🔑 Где хранятся ключи

| Ключ | На диске | В браузере |
|------|----------|------------|
| **Velantrim (сервер)** | `.env` → `VELANTRIM_API_KEY` | `velantrim_titan_console_apiKey` |
| **LLM** (DeepSeek, Gemini…) | опционально в `config\llm.example.env` | `velantrim_titan_console_llmKeys` |
| **Чаты, память** | — | `velantrim_titan_console_chatArchive` и др. |

## 📦 Перенос на другой компьютер или в другую папку

**Да, можно.** Скопируйте **всю папку** проекта (`Velantrim-ExoCortex-Titan`) целиком:

- ✅ `.env`, `data\`, `static\`, `scripts\` — всё переносится
- ✅ Запуск из **нового** пути: `.\scripts\start_console.ps1`
- ✅ URL тот же: `http://127.0.0.1:8755/console/`
- ⚠️ Нельзя просто скопировать один `index.html` — нужен Python-сервер
- ℹ️ localStorage браузера привязан к `127.0.0.1:8755`, не к папке на диске

После переноса проверьте: http://127.0.0.1:8755/debug/console — поле `index_path` должно указывать на **новую** папку.

## 🛠 Если не открывается

| Ошибка | Решение |
|--------|---------|
| `ERR_CONNECTION_REFUSED` | Сервер не запущен → `.\scripts\start_console.ps1` |
| Старая версия UI | Ctrl+F5 или `?v=40` в URL |
| 401 на API | Вставьте `VELANTRIM_API_KEY` из `.env` в верхнее поле консоли |
