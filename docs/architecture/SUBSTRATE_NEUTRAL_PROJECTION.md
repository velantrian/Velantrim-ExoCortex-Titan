# Titan — Substrate-Neutral Projection

**Status:** Documentation-only architectural projection. Not a new runtime, provider, tool, memory authority, or production authorization.

Titan's durable federated role is execution/orchestration, providers, tools, retrieval composition, product surfaces, and bounded research incubation — not any specific LLM, Python framework, graph, RAG technique, vector store, database, or provider.

For a declared scope, preserve these distinctions:

```text
artifact present != contract proven
contract proven != configured
enabled/configured != wired into the required path
wired != executed
executed != observed in this runtime
retrieved != epistemically valid
orchestration capability != truth authority
tool capability != cross-domain authority
```

A replacement substrate may realize orchestration and execution differently, but must not manufacture evidence, truth, identity, consent, or Canon authority merely because it can invoke a tool or produce an answer.

Standalone/local Titan mechanisms do not automatically become ecosystem-wide authority in federated Velantrim.

Cross-project orientation and conformance checklist live in `velantrian/velantrim`; owning Titan specifications remain authoritative for Titan-specific semantics.
