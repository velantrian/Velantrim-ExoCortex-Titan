# 🌿 Velantrim Knowledge Base — Машинная суть знаний (v3.0)

**Версия:** 3.0
**Дата:** 20 мая 2026
**Главное изменение:** убрана педагогика. Собираем только **суть знания** для машины.

---

## 🎯 Ключевой инсайт v3.0

```
📚 Обычный учебник:
   ~10% — само знание (закон, формула, факт)
   ~90% — педагогика (объяснения, аналогии, примеры, упражнения)

🤖 Velantrim:
   100% — только знание
   Педагогика генерируется LLM на лету когда нужно человеку
```

**Машине не нужны:** объяснения «почему», аналогии, примеры для понимания, исторические байки, упражнения, метафоры.
**Машине нужны:** сам факт, формальная запись, условия применимости, границы, связи.

**Результат:** объём базы сокращается в 3-5 раз, скорость сбора растёт в 3 раза.

## 📦 ФОРМАТ ЗАПИСИ v3.0 (только суть)

```json
{
  "id": "law.newton.2",
  "domain": "physics.mechanics",
  "type": "law",
  "statement": "Ускорение тела пропорционально приложенной силе и обратно пропорционально массе.",
  "formal_notation": "F = m·a",
  "conditions": "Инерциальная система отсчёта; v << c",
  "limits": [
    "Не работает при релятивистских скоростях (нужна СТО)",
    "Не работает для квантовых систем (нужна QM)"
  ],
  "prereq": ["concept.force", "concept.mass", "concept.acceleration"],
  "derives_from": [],
  "confidence": 1.0,
  "tags": ["mechanics", "newton", "force"]
}
```

**Это всё.** Никаких title, examples, why_it_matters, common_confusions, level. Только суть.

## 🔑 Поля и их смысл

### Обязательные

🔵 **`id`** — уникальный идентификатор. Формат: `category.subcategory.name`
   - `law.newton.2` (закон)
   - `theorem.pythagoras` (теорема)
   - `axiom.peano.5` (аксиома)
   - `concept.entropy` (понятие)

🔵 **`domain`** — точная область: `physics.mechanics`, `chemistry.organic`, `math.algebra`, `biology.genetics`, `logic.formal`.

🔵 **`type`**:
- `law` — фундаментальный закон природы
- `axiom` — аксиома (математика/логика, не доказывается)
- `theorem` — теорема (доказывается)
- `principle` — принцип
- `definition` — определение
- `concept` — понятие
- `fact` — установленный факт
- `formula` — формула
- `process` — процесс (для PRACTICAL)
- `relation` — отношение (для PERCEPTION)

🔵 **`statement`** — само утверждение. **Короткое, точное, без объяснений**.
   - ❌ «Согласно второму закону Ньютона, когда вы прикладываете силу к телу...»
   - ✅ «Ускорение пропорционально силе и обратно пропорционально массе.»

🔵 **`confidence`** — уверенность 0.0-1.0:
- `1.0` — математическая истина или аксиома
- `0.95-0.99` — общепринятый научный закон
- `0.7-0.95` — стабильно подтверждённое
- `0.5-0.7` — есть споры
- `<0.5` — гипотеза

🔵 **`tags`** — 3-5 поисковых тегов.

### Очень важные

🟡 **`formal_notation`** — формальная запись (математическая, химическая, логическая). Где возможно — ОБЯЗАТЕЛЬНО.

🟡 **`conditions`** — при каких условиях факт работает. Одна строка.

🟡 **`limits`** — массив границ применимости. **Очень важно для физических законов и для безопасности практических знаний.**

🟡 **`prereq`** — массив id фактов которые нужно знать заранее. Это **граф зависимостей** — переходит в `requires`-связи в CausalGraph Velantrim.

🟡 **`derives_from`** — массив id законов на которых основан данный факт. Создаёт **иерархию знания** от базовых законов до применений.

### Опциональные

⚪ **`source`** — конкретный источник если важно (для VARIANT — обязательно).

⚪ **`valid_from`** / **`valid_until`** — даты актуальности (для VARIANT).

⚪ **`alternative_views`** — для спорных вопросов (для VARIANT).

⚪ **`success_rate`** — для PRACTICAL.

⚪ **`safety_critical`** — для PRACTICAL с рисками.

⚪ **`perceiver`** — для PERCEPTION.

⚪ **`affordances`** — для PERCEPTION.

## ❌ Что НЕ собираем больше (v3.0)

```
🚫 title              — извлекается из statement
🚫 why_it_matters     — это педагогика
🚫 examples           — это педагогика
🚫 common_confusions  — это педагогика
🚫 level T1/T2/T3     — это для учебной траектории
🚫 historical_context — для базовых законов опционально
🚫 discovered_by      — не суть, опционально
🚫 long descriptions  — машине не нужно
```

**Эти поля могут быть в отдельном педагогическом слое (Слой 2), но не в основной базе.**

## 🧠 Зачем такая чистота

```
До (v2.0 с педагогикой):
─────────────────────────
1 факт = ~500 слов
       = ~30-60 минут на запись
       = огромная база
       = LLM теряет фокус в шуме

После (v3.0 только суть):
─────────────────────────
1 факт = ~50-100 слов
       = ~10-20 минут на запись
       = компактная база
       = LLM работает с плотным знанием
```

**Машинная база знаний должна быть как кристаллический сплав:** плотная, чистая, без примесей. Тогда rасуждение быстрое и точное.

```
        ↓

        ↓

        ↓

        ↓

        ↓

   • BASE_LAW → ImmutableCore

   • PRACTICAL → Validated/Supported

        ↓

   • prereq → requires-связи
   • derives_from → derived-связи
        ↓
💾 SQLite storage
        ↓

```

## 🎯 Принципы качества

🪨 **Качество > количество.** 1000 точных лучше 100000 размытых.

✂️ **Только суть.** Без педагогики, без воды, без украшений.

🔗 **Связи обязательны.** prereq и derives_from где возможно.

📝 **Формальная нотация обязательна** где она существует (математика, физика, химия, логика).

⚖️ **Границы обязательны** для законов природы — `limits` поле.

🚫 **Не выдумывать.** Если не уверен — `confidence < 0.7` или не пиши.
