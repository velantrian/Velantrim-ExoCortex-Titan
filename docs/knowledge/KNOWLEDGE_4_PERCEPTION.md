# 👁️ KNOWLEDGE_4_PERCEPTION — Восприятие мира организмами (v3.0)

**Цель:** 300-1000 записей.
**ESM:** → `Supported`.
**Confidence:** 0.6-0.9.
**Время сбора:** 80-150 часов.

---

## 🎯 Главная идея

Один объект — разные восприятия. Это даёт системе глубину понимания.

```
🌳 ДЕРЕВО:
   🔬 наука:    организм с фотосинтезом
   🐦 воробей:  ветка для охоты и пения
   🐱 кошка:    охотничий пост
   👤 человек:  тень, плоды, материал
```

**Без педагогики:** только что объект «предлагает» воспринимающему (affordances). Без описаний «как это удивительно» и «почему важно».

## 📚 Что собирать

### Природные объекты (30-50)
Дерево, камень, река, цветок, гора, океан, лес, поле, болото, пустыня, ледник, песок, глина, облако, дождь, снег, ветер, огонь, молния, гриб, мох, лишайник.

### Воспринимающие субъекты (50-100)
**Птицы:** воробей, ворона, орёл, сова, аист, утка, дятел, ласточка.
**Млекопитающие:** кошка, собака, волк, лиса, олень, медведь, заяц, белка, мышь.
**Рептилии:** змея, ящерица.
**Земноводные:** лягушка.
**Рыбы:** общая категория + хищники + травоядные.
**Насекомые:** пчела, муравей, бабочка, стрекоза, муха, комар.
**Микро:** микориза, бактерии.

### Человеческие роли (30-60)
Ребёнок, инженер, поэт, фермер, врач, художник, учитель, повар, плотник, кузнец, музыкант, учёный, моряк, охотник, рыбак, программист, садовник, пастух.

## 📦 Формат v3.0

```json
{
  "id": "perception.tree.sparrow",
  "domain": "perception",
  "type": "relation",
  "statement": "Воробей воспринимает дерево как пространство для отдыха, охоты на насекомых, укрытия и гнездования.",
  "conditions": "Зависит от вида дерева и сезона.",
  "limits": [
    "Воробьи предпочитают лиственные деревья летом, хвойные зимой"
  ],
  "prereq": ["concept.bird_behavior", "concept.tree"],
  "confidence": 0.85,
  "tags": ["sparrow", "tree", "ethology"],

  "object": "tree",
  "perceiver": "Passer domesticus",
  "perceiver_category": "small_bird",
  "affordances": ["perch", "shelter", "prey_search", "nest_site", "observation_point"],
  "related_perceptions": ["perception.tree.cat", "perception.tree.human"],
  "source": "Cramp & Perrins, Handbook of European Birds, 1994"
}
```

**Особые поля для PERCEPTION:**
- `object` — объект восприятия
- `perceiver` — воспринимающий (вид с латинским названием для животных)
- `perceiver_category` — категория (bird/mammal/insect/human_role/...)
- `affordances` — массив действий что объект «предлагает» (Гибсон 1979)
- `related_perceptions` — другие восприятия того же объекта

---

## 🤖 Инструкция для ИИ-сборщика

1. Возьми **объект** (например, дерево).
2. Собери **5-15 восприятий** этого объекта:
   - 1 научное (для контекста)
   - 4-5 живых существ
   - 3-5 человеческих ролей
3. Каждое восприятие — отдельная запись.
4. **ОБЯЗАТЕЛЬНО:**
   - `object`, `perceiver`, `perceiver_category`
   - `affordances` — массив действий
   - `related_perceptions` — связи
5. **Опирайся на этологию** для животных, **феноменологию** для людей.
6. **НЕ ВЫДУМЫВАЙ** если не знаешь.
7. **НЕ ДОБАВЛЯЙ:** examples, why_it_matters, common_confusions.

**Объём:** 25-30 записей на файл (по 1-2 объекта). Файлов ~15-30.
