## 📦 Формат v3.0 (только суть)

```json
{
  "id": "law.newton.2",
  "domain": "physics.mechanics",
  "type": "law",
  "statement": "Ускорение пропорционально приложенной силе и обратно пропорционально массе.",
  "formal_notation": "F = m·a",
  "conditions": "Инерциальная система отсчёта; v << c",
  "limits": [
    "Не работает при v близких к c (нужна СТО)",
    "Не работает для квантовых систем (нужна QM)",
    "Не работает в неинерциальных системах без поправок"
  ],
  "prereq": ["concept.force", "concept.mass", "concept.acceleration", "concept.inertial_frame"],
  "derives_from": [],
  "confidence": 1.0,
  "tags": ["mechanics", "newton", "dynamics"],

  "discovered_by": "Isaac Newton",
  "year": 1687,
  "esm_target": "ImmutableCore"
}
```

**Дополнительные поля только для законов:**
- `discovered_by` — кто открыл (опционально, для контекста)
- `year` — когда (опционально)
- `esm_target` — всегда `ImmutableCore` для базовых законов

## 🤖 Инструкция для ИИ-сборщика

1. Возьми область (например, физика-механика).
2. Перечисли ВСЕ фундаментальные законы области (5-15 на область).
3. Каждый закон — отдельная запись по формату v3.0.
4. **ОБЯЗАТЕЛЬНО:**
   - `formal_notation` где есть
   - `conditions` (где работает)
   - `limits` (где НЕ работает) — критично!
   - `confidence: 1.0` для аксиом, `0.95-0.99` для эмпирических законов
   - `esm_target: "ImmutableCore"`
5. **НЕ ДОБАВЛЯЙ:** examples, why_it_matters, common_confusions, level, длинные описания.
6. **`statement` — максимум 1-2 предложения.** Только суть.

**Объём на файл:** 10-20 законов. Файлов всего ~10-15 на весь документ.
