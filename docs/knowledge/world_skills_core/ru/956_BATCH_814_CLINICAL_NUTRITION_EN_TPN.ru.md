| clinnutrition.ops.nutritional_screening | Скрининг питания — инструменты | METHOD | Скрининг питания: NRS-2002 (Nutritional Risk Score): госпитализированные пациенты. MNA (Mini Nutritional Assessment): пожилые. MUST (Malnutrition Universal Screening Tool): для любых условий. BAPEN. Компоненты: ИМТ, потеря веса, снижение приёма пищи, тяжесть болезни. Score ≥3 NRS-2002: высокий риск. | «Если скрининг не проводится, мальнутриция пропускается у 30-50% госпитализированных». |
| clinnutrition.ops.energy_requirements | Энергетические потребности — Харрис Бенедикт | METHOD | Расчёт потребности в энергии: Харриса-Бенедикта: Мужчины: 88.36 + (13.4×W) + (4.8×H) - (5.68×A). Женщины: 447.6 + (9.25×W) + (3.1×H) - (4.33×A). W=кг, H=см, A=лет. Multiply by stress factor. Mifflin-St Jeor: более точная для современных. Indirect Calorimetry (IC): золотой стандарт. | IC: ResMed Vmax. Измеряет RQ (Дыхательный коэффициент): жиры 0.7, углеводы 1.0, белки 0.82. |
| clinnutrition.ops.enteral_formula_types | Энтеральные формулы — выбор | METHOD | Виды энтерального питания: Стандартные полимерные (Isosource, Обеспечение): для большинства. Концентрированные (1,5-2 ккал/мл): ограничение жидкости. Полуэлементные: мальабсорбция. Специфические заболевания: почечные (Непро), печеночные, диабетические. Иммуномодулирующие (Воздействие): аргинин, омега-3. Кормление через зонд-блендер: настоящая еда в гастростоме. | Концентрированная формула при отёках/ХСН: меньше объём на тот же калораж. |
| clinnutrition.ops.tube_feeding_initiation | Кормление через зонд — частота начала | METHOD | Начало энтерального питания: ICU: начать в течение 24-48 ч при гемодинамической стабильности. Скорость введения: начать с 10-20 мл/ч → увеличивать каждые 4-6 ч. Тонкая кишка: быстрее, нет нужды в верификации размещения каждый раз. Желудок: gastric residual volume (GRV) контроль. Непрерывно vs болюсно. | Semi-recumbent position 30-45°: обязательна при желудочном кормлении (аспирация). |
| clinnutrition.ops.parenteral_nutrition | ТПП — полное парентеральное питание | METHOD | Тотальное парентеральное питание: Центральный доступ: ≥10% декстрозы. Периферический: <10% (PPN). Компоненты: декстроза (40-60% ккал), аминокислоты (белок), липиды (20-30% ккал). «All-in-one» (3-в-1): смешать все вместе. Monitoring: ежедневно глюкоза, электролиты. Нет ЭП → ТПП предпочтительнее ТПП ≤7 дней. | ТПП дороже ЭП в 5-10 раз + выше риск инфекций + кишечная атрофия. |
| clinnutrition.ops.refeeding_syndrome | Синдром повторного питания — профилактика | METHOD | Синдром возобновления кормления: при голодании нет инсулина → нет сдвига K/P/Mg внутриклеточно. При возобновлении кормления: инсулин → сдвиг → гипофосфатемия + гипокалиемия + гипомагниемия. Признаки: аритмии, дыхательная недостаточность, судороги. Профилактика: медленное начало (30-60% потребности), заместительная терапия электролитами. | Высокий риск: анорексия, хронический алкоголизм, потеря >15% веса за 3-6 мес. |
| clinnutrition.ops.icu_protein_requirements | ОИТ — Дозирование белка | METHOD | Протеиновые потребности в ОРиТ: ASPEN/SCCM 2016: 1.2-2.0 г/кг/сут. Тяжелые ожоги: до 3 г/кг. Ожирение ICU: 2.0-2.5 г/кг IBW. Определение потребности в белке: азотный баланс (суточные потери N × 6.25 = белок). Нигатив. Белковый катаболизм. Аминокислотная смесь: glutamine добавка (спорно в ICU). | Protein = наиболее важный нутриент в ICU (не только калории). |
| clinnutrition.ops.obesity_surgery_nutrition | Бариатрическая хирургия — потребности в питании | METHOD | Нутритивные потребности после бариатрической хирургии: Дефициты: железо, B12, фолат, кальций, витамин D, цинк, тиамин (B1). Специфические: RYGB = B12 дефицит наиболее частый. Рекомендации: ежедневный мультивитамин, B12 (1000 мкг/сут), кальций (1500-2000 мг в день, карбонат vs цитрат). Белок: 60-80 г/сут. | Тиамин дефицит: острая полинейропатия после бариатрики (быстро развивается при рвоте). |
| clinnutrition.ops.pediatric_nutrition_failure | Педиатрия — отсутствие развития | METHOD | Задержка физического развития (FTT) у детей: вес <5-го перцентиля или снижение ≥2 перцентильных линий. Причины: органические (мальабсорбция, кардиальная, хроническая болезнь), неорганические (психосоциальные). Оценка: дневник питания, 3-дневная запись. Цель: дополнительные 100-150% RDA для catch-up. | «Growth tracing»: отслеживание на кривой роста важнее разовых измерений. |
| clinnutrition.ops.food_first_approach | Еда прежде всего — до добавок | METHOD | Принцип «еда прежде всего»: реальная еда лучше добавок (синергетические эффекты питательных веществ). Добавки: только при доказанном дефиците или невозможности получить из еды. Fortified foods: промежуточный вариант. Screening → assessment → plan. «Whole food diet»: цельные зерна, бобовые, овощи, фрукты, нежирные белки. | Витамин С из апельсина vs добавки: одинаковая биодоступность, НО антиоксидантные эффекты — лучше в whole food. |
| clinnutrition.ops.micronutrient_deficiencies | Дефицит микроэлементов – глобальный уровень | METHOD | Глобальные дефициты микронутриентов: «Скрытый голод». Дефицит Fe: 2 млрд человек (анемия). Йод: зоб + кретинизм при беременности. Vit А: слепота у детей (127 млн детей). Цинк: нарушение роста + иммунитет. Vit D: рахит. Двойное бремя: ожирение + мальнутриция в одних семьях. | Фортификация продуктов: соль с йодом (профилактика зоба) = одна из самых эффективных программ. |
| clinnutrition.ops.nutrition_liver_disease | Заболевания печени — управление питанием | METHOD | Нутритивная поддержка при болезнях печени: Цирроз: белок 1.2-1.5 г/кг/сут (не ограничивать при гепатической энцефалопатии — устаревшая рекомендация). Поздняя ночная закуска (late evening snack): сохранение мышечной массы. Zinc: часто дефицит. Branched-Chain Amino Acids (BCAA): при рефрактерной энцефалопатии. Малые частые приёмы пищи: лучше переносимость. | Сухостой 12 часов у цирротиков = эквивалент 3-дневного голодания у здоровых (катаболизм). |
| clinnutrition.ops.sports_nutrition_practitioner | Спортивное питание — Клиническая практика | METHOD | Спортивное питание: RED-S (Relative Energy Deficiency in Sport): дефицит энергии → нарушение функций. Athlete Triad (женщины): эменорея + низкая плотность костей + низкое потребление энергии. LEA (Low Energy Availability): <30 ккал/кг FFM/сут = проблема. Nutrient timing. Recovery: углеводы + белок в первые 30-60 мин. | Female Athlete Triad: сначала выявить LEA, затем трактовать. |
| clinnutrition.ops.inflammation_nutrition | Воспаление — противовоспалительная диета | METHOD | Противовоспалительное питание: Омега-3 (EPA/DHA): рыба жирная, льняное масло. Полифенолы: ягоды, тёмный шоколад, оливковое масло. Клетчатка (пребиотики): разнообразный микробиом. Ограничить: красное мясо, сахар, ультраобработанные. Mediterranean Diet: наивысший уровень доказательств. | SMILES trial: Mediterranean Diet → снижение симптомов депрессии. |
| clinnutrition.ops.dysphagia_diet | Диета при дисфагии — IDDSI Framework | METHOD | Диета при дисфагии (IDDSI 2019): Международная инициатива по стандартизации диеты при дисфагии. Жидкость 0–4: 0 (тонкая), 1 (слегка толстая), 2 (слегка толстая), 3 (умеренная), 4 (очень толстая). Еда 3–7: 3 (жидкое), 4 (пюре), 5 (фарш, влажный), 6 (мягкий и порционный), 7 (обычный). | Сгущенная жидкость: IDDSI 3-4 при орофарингеальной дисфагии (аспирация тонких жидкостей). |
| clinnutrition.ops.fasting_therapeutic | Лечебное голодание — доказательства | METHOD | Терапевтическое голодание: Intermittent fasting (IF): 16:8, 5:2. Метаболические эффекты: снижение ИМТ, HbA1c, инсулинорезистентности. Ограниченное по времени питание (TRE). Fasting-mimicking diet (FMD, ProLon). Extended fast (>72 ч): медицинский надзор. Не для беременных, анорексии. | ЕСЛИ не превосходит постоянное ограничение калорий для веса (CALERIE). |
