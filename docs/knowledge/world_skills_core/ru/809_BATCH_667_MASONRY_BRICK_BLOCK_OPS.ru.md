# BATCH 667: Masonry — Brick & Block Laying

**KnowledgeUnits:** 5
**Namespace:** `mason.ops.*`
**Scope:** brick, block, mortar, bond_patterns, reinforcement, grouting, cleaning, pointing

| ID | KnowledgeUnit | Тип | Суть | Практический смысл |
|---|---|---|---|---|
| mason.ops.mortar_mixing_proportions | Раствор — смешивание и типы | METHOD | Приготовление кладочного раствора. Proportions (by volume): Type M (1:0.25:3 cement:lime:sand) — высокая прочность (подземные, retaining walls). Type S (1:0.5:4.5) — средняя прочность (exterior, below grade). Type N (1:1:6) — general use (стены выше земли). Type O (1:2:9) — низкая прочность (interior, non-load bearing). Mix: сначала сухие, затем вода (до пластичности). Lime: пластичность, water retention, self-healing. Retempering: добавление воды в течение 1.5-2 часов (повторное перемешивание). Не добавлять воду после начального схватывания! | Слишком крепкий раствор для слабого кирпича: трещины. |
| mason.ops.brick_bond_patterns | Кирпичные облигации — типы узоров | METHOD | Классические перевязки кирпичной кладки. Running bond (половинная перевязка): самый частый, each course shifted на половину кирпича. Stack bond (без перевязки): requires reinforcement в каждом втором-третьем ряду. English bond: alternating header и stretcher courses (прочный, для несущих стен). Flemish bond: alternating header и stretcher в каждом course (декоративный). Common bond: running с header course каждые 5-7 рядов. Soldier course (кирпичи вертикально торцом) — декоративный над окнами или карниз. Rowlock (кирпичи на ребре узкой стороной). | Отсутствие bond в load-bearing стене = трещины и потеря прочности. |
| mason.ops.block_laying_technique | Укладка блоков — техника | METHOD | Укладка бетонных блоков. Углы первыми (lead). String line между углами для ровного ряда. Mortar: нанести на face shells (боковые стенки блока) + на web (перегородки) для первого курса. Full bed для первого ряда (ровная поверхность). Buttering (нанесение на вертикальный шов предыдущего блока). Толщина шва: 10 мм (стандарт). Выравнивание: level (горизонталь каждого блока + ряд), plumb (вертикаль стены). Наполнение ячеек: grout (жидкий цементный раствор) с арматурой через каждые 1.2-1.8 м по вертикали. Clean-out: отверстия в нижнем ряду для очистки перед grouting. | Полые блоки без заполнения — значительно слабее (только для не-несущих). |
| mason.ops.weephole_flashing | Глазок — Установка | METHOD | Дренажные отверстия в кирпичной стене. Цель: выход воды из cavity (воздушный зазор) наружу. Расположение: каждый 3-4 кирпич на нижнем ряду, над всеми проёмами, под parapet cap. Материалы: plastic weephole tubes (трубки), screen vent (сетчатый), rope (хлопковый шнур). Flashing: металлический/резиновый водоотвод внизу cavity, направляющий воду к weephole. End dam: загнутый край flashing. Drip edge: капельник на flashing. | Без weepholes: вода скапливается в cavity, проникает внутрь (плесень, гниль дерева). |
| mason.ops.tuckpointing_repointing | Переназначение — Tuckpointing | METHOD | Замена старого растворного шва. Вырубка старого раствора: angle grinder с алмазным диском (глубина 2× ширины шва), или hand chisel для исторических зданий. Очистка: compressed air + water (насытить старый раствор чтобы не отсасывал воду из нового). Новый раствор: match original по цвету, текстуре, прочности (взять образец для lab match). Нанесение: tuckpointing trowel (узкий), заполнение fully, tooling (расшивка) — concave, vee, flush. Curing: медленное (туманное увлажнение), 3 дня. | Портланд-цемент на историческом кирпиче (до 1920) — слишком твёрдый — разрушает кирпич. |
