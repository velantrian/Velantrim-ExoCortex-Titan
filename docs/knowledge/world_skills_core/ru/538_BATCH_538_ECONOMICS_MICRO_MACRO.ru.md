# BATCH 538: Economics — Microeconomics & Macroeconomics

**KnowledgeUnits:** 17
**Namespace:** `economics.*`
**Scope:** supply_demand, elasticity, perfect_competition, monopoly, externalities, gdp, inflation, unemployment, fiscal_policy, monetary_policy, balance_of_payments.

| ID | KnowledgeUnit | Тип | Суть | Практический смысл |
|---|---|---|---|---|
| economics.supply_demand_law | Закон спроса и предложения | INVARIANT | Равновесная цена P_eq = пересечение кривых. Избыток предложения → P↓; дефицит → P↑. Сдвиги кривых: спрос (доходы↑, вкусы, субституты↑), предложение (издержки↓, технологии). | Нефть: снижение добычи (ОПЕК+) → сдвиг S влево → P↑. COVID: сдвиг D влево (локдаун) → P↓ до отрицательных (фьючерсы WTI, апр 2020). |
| economics.elasticity | Ценовая эластичность спроса | VARIANT | E_d = %ΔQ/%ΔP. | Е_д | >1 — эластичный (предметы роскоши). | E_d | <1 — неэластичный (инсулин, бензин). Единичная эластичность. Перекрёстная (субституты/комплементы), по доходу. | Выручка TR=P×Q. Эластичный спрос: P↓→TR↑. Неэластичный: P↑→TR↑ (акцизы на сигареты/бензин). |
| economics.perfect_competition | Совершенная конкуренция | MODEL | Много малых фирм, однородный продукт, свободный вход/выход, полная информация. P=MC (предельные издержки), P=min ATC в долгосрочном периоде (нулевая экономическая прибыль). | Сельское хозяйство: пшеница, кукуруза (приближённо). Фирма — price-taker (принимает цену). |
| economics.monopoly | Монополия | MODEL | Единственный продавец, барьеры входа. MR=MC → цена выше MC (надбавка). Потери мёртвого груза (deadweight loss). Естественная монополия (эффект масштаба → 1 фирма эффективнее: водопровод, сети). | Патенты — временная законная монополия (стимул инноваций). Microsoft (90-е, ОС), Google (поиск). |
| economics.oligopoly | Олигополия и теория игр | MODEL | Несколько крупных фирм, стратегическое взаимодействие. Модели: Курно (количество), Бертран (цена). Nash equilibrium — никому не выгодно отклоняться в одностороннем порядке. Дилемма заключённого. | Авиакомпании, сотовая связь, автопроизводители. Картель (ОПЕК) — договор о Q/P, но неустойчив (каждый хочет увеличить добычу). |
| economics.externalities | Внешние эффекты | PROCESS | Отрицательная (загрязнение — социальные издержки > частных) → налог Пигу. Положительная (образование, вакцины — социальная выгода > частной) → субсидия. Теорема Коуза: частное решение при нулевых транзакционных издержках и чётких правах собственности. | Торговля квотами на выбросы CO₂ (ETS EU): cap-and-trade. Налог на углерод. |
| economics.public_goods | Общественные блага | VARIANT | Неконкурентные (моё потребление не уменьшает твоего) и неисключаемые (нельзя запретить). Проблема безбилетника (free-rider). Предоставляются государством. | Национальная оборона, маяк, фундаментальная наука, чистый воздух. Финансирование через налоги. |
| economics.gdp | Валовой внутренний продукт (ВВП) | INVARIANT | Рыночная стоимость всех конечных товаров/услуг, произведённых в стране за период. Методы: производственный, по расходам (C+I+G+NX), по доходам (зарплата+прибыль+рента+проценты). | Номинальный (текущие цены) vs реальный (постоянные цены, base year). Рост ВВП ≠ рост благосостояния (не учитывает неравенство, экологию, домашний труд). |
| economics.inflation_causes | Инфляция | PROCESS | Устойчивый рост уровня цен. Причины: спрос (demand-pull — избыточный спрос), издержки (cost-push — энергия, сырьё), монетарная («слишком много денег гоняется за слишком малым количеством товаров» — Фридман). Измерение: ИПЦ (CPI), дефлятор ВВП. | Гиперинфляция (>50% в месяц): Германия 1923, Зимбабве 2008, Венесуэла 2018. Таргетирование инфляции (Центробанк, обычно 2%). |
| economics.unemployment_types | Типы безработицы | VARIANT | Фрикционная (переход между работами — естественно), структурная (несоответствие навыков — новые технологии), циклическая (спад в экономике — недостаточный спрос). Естественный уровень безработицы NAIRU. | Закон Оукена: рост безработицы на 1% → падение ВВП на ~2% относительно потенциального (для США). |
| economics.phillips_curve | Кривая Филлипса | MODEL | В краткосрочном периоде: инфляция ↑ ⇔ безработица ↓ (trade-off). В долгосрочном: вертикальная кривая на естественном уровне (адаптивные/рациональные ожидания). Стагфляция (1970-е: высокая и то, и другое — нефтяной шок). | Центробанк: снижение ставки → ↑AD → ↓безработица но ↑инфляция (компромисс). |
| economics.fiscal_policy | Фискальная политика | METHOD | Налоги (T) и государственные расходы (G). Экспансия (G↑/T↓, дефицит) — рецессия. Консолидация (G↓/T↑, профицит) — перегрев. Мультипликатор: ΔGDP = k·ΔG, k = 1/(1−MPC). | Laffer curve: слишком высокие налоги → снижение собираемости. Автоматические стабилизаторы (пособие по безработице). |
| economics.monetary_policy | Денежно-кредитная политика | METHOD | Операции на открытом рынке (покупка/продажа гос. облигаций), ставка рефинансирования, резервные требования. Количественное смягчение (QE — центральный банк покупает активы, увеличивая денежную базу). | Передаточный механизм: ↓ставка → ↑кредитование → ↑инвестиции → ↑C → ↑GDP. Лаги: 6-18 месяцев. |
| economics.interest_rate_parity | Паритет процентных ставок | INVARIANT | Разница процентных ставок = ожидаемое изменение валютного курса. Покрытый (CIP — через форвардный рынок) и непокрытый (UIP). | Carry trade: заём в низкопроцентной валюте (JPY), вложение в высокодоходную (AUD/NZD). Риск: резкое укрепление JPY. |
| economics.balance_of_payments | Платежный баланс (ПБ) | MODEL | Счёт текущих операций (торговля товарами/услугами, первичные/вторичные доходы) + Счёт капитала + Финансовый счёт (ПИИ, портфельные инвестиции, резервы) = 0 (с точностью до ошибок/пропусков). | Дефицит счёта текущих операций финансируется притоком капитала. Внезапная остановка (sudden stop) → кризис. |
| economics.comparative_advantage | Сравнительное преимущество (Рикардо) | INVARIANT | Торговля выгодна обеим сторонам, даже если одна производит всё абсолютно эффективнее — важно относительное преимущество. Страна специализируется на том, что у неё получается относительно лучше. | Португалия (вино и сукно), Англия (сукно). Современность: Китай (трудоёмкое), Германия (точное машиностроение). |
| economics.consumer_theory | Теория потребительского выбора | INVARIANT | Бюджетное ограничение + кривые безразличия → оптимальный выбор (MRS = P_x/P_y). Предельная полезность денег λ. Эффект дохода и эффект замещения. | Товар Гиффена (картофель в голодной Ирландии): ↑цены → ↑спроса (отказ от мяса, больше картофеля). Редкость. |
