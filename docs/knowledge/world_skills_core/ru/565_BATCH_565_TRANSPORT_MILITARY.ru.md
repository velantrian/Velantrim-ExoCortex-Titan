| transport.traffic_flow_theory | Теория транспортных потоков | INVARIANT | q = k·v (поток = плотность × скорость). Фундаментальная диаграмма: свободный поток → максимальный поток (q_max ~2000-2400 авт/полосу/ч при v~50-80 км/ч) → затор (скорость и поток падают). Волны плотности (ударные волны при торможении → распространяются назад). | Снижение скорости → увеличение плотности → водители тормозят → волна усиливается → фантомные пробки (без видимой причины). Решение: рамп-метринг (дозированный въезд), VSL (variable speed limits). |
| transport.railway_engineering | Принципы железнодорожной техники | METHOD | Колесо-рельс: конический профиль колеса → самоцентрирование. Ширина колеи: стандарт 1435 мм (60% мировых ж/д), русская 1520 мм. Радиус кривых (>300 м для скоростных >250 км/ч). Возвышение наружного рельса: h = 11.8·V²/R (мм, V в км/ч). | Контактная сеть: зигзаг (для равномерного износа пантографа). Температурные напряжения: бесстыковой путь (длинные сварные плети), нейтральная температура закрепления. |
| transport.ship_stability | Остойчивость корабля | INVARIANT | Метацентр M: пересечение линии действия силы поддержания с диаметральной плоскостью. Метацентрическая высота GM = KM − KG. GM > 0 — остойчиво (восстанавливающий момент). GM мало — валкая (мягкая), GM велико — жёсткая (резкая качка). Кренящий момент от ветра/волн. | Остойчивость повреждённого судна: затопление отсеков → потеря GM. Пробоина — контрзатопление (спрямление). Международная конвенция SOLAS (Safety of Life at Sea, после Титаника, 1914). |
| transport.aircraft_performance | Производительность самолета | METHOD | Взлётная дистанция: разбег + воздушный участок до высоты 35 футов (10.7 м). Сбалансированная длина поля (balanced field length): accelerate-stop = accelerate-go. Дальность (формула Бреге): R = (V·L/D)/(SFC)·ln(W₀/W₁). | Потолок: максимальная высота (набор ≤ 100 футов/мин для турбореактивных). Крейсерский эшелон (RVSM — reduced vertical separation 1000 фт между FL290-FL410). |
| transport.supply_chain | Цепочка поставок и логистика | METHOD | Модель SCOR: План, Источник, Изготовление, Доставка, Возврат. Эффект кнута (усиление колебаний солнечных лучей вверх по цепи). Страховой запас = z·σ·√L. EOQ (экономичный объем заказа): Q* = √(2DS/H). Инкотермс (FOB, CIF). | Just-in-Time (Toyota): минимальные запасы, но уязвимость к сбоям (пандемия, блокировка Суэца 2021). Resilient vs efficient. |
| transport.maritime_logistics | Морская логистика | VARIANT | Контейнеризация (Маклин, 1956) — революция: стандарт ISO 20'/40' (TEU — twenty-foot equivalent unit). Крупнейшие суда >24,000 TEU (MSC Irina). Основные маршруты: Азия-Европа (Суэц), Транстихоокеанский. Хабы (Сингапур, Роттердам, Шанхай). | Балластные воды — экологическая проблема (инвазивные виды). Качка параметрическая, слеминг (удары носом). |
| military_science.strategy_levels | Уровни войны | INVARIANT | Стратегический (зачем и где — победа в войне), оперативный (кампании, сражения на ТВД), тактический (бой, применение подразделений). Клаузевиц: «Война есть продолжение политики иными средствами». Центр тяжести (Schwerpunkt). Трение войны (неопределённость, хаос). | Великая стратегия: цель государства, все инструменты (дипломатия, экономика, военная сила). | military_science.offsensive_defensive | Нападение против защиты — принципы | VARIANT | Наступление: концентрация сил (3:1 локально в точке прорыва), внезапность, темп. Оборона: использование местности, эшелонирование, резерв для контратак. Ланчестерский квадратичный закон: сила пропорциональна квадрату численности при дальней стрельбе (N₁²−N₂²=const). | Ланчестер линейный для рукопашной (N₁−N₂ = const). Концентрация решает. |
| military_science.armor_history | Эволюция бронетанковой войны | RECORD | Танк (1916, Somme — Mark I). Blitzkrieg (Гудериан, 1939-41: танки + авиация + мотопехота → прорыв + глубокий охват). Основной боевой танк (MBT: T-72/T-90, Abrams M1, Leopard 2 — композитная броня, гладкоствольная пушка 120/125 мм). | Реактивная броня (ERA — Kontakt-5, Relikt), активная защита (Trophy, Arena — перехват снаряда), динамическое бронирование. | military_science.ballistics_exterior | Внешняя баллистика | PROCESS | Траектория снаряда: сила тяжести + аэродинамическое сопротивление (лобовое, донное, волновое при M>1).
