# BATCH 644: Locksmith — Lock & Key Operations

**KnowledgeUnits:** 5
**Namespace:** `locksmith.ops.*`
**Scope:** pin_tumbler, rekey, master_key, picking, automotive, safe, electronic, installation

| ID | KnowledgeUnit | Тип | Суть | Практический смысл |
|---|---|---|---|---|
| locksmith.ops.pin_tumbler_rekey | Rekey — Штифтовой тумблерный цилиндр | METHOD | Перекодировка замка под новый ключ. Разборка: снять цилиндр (KIK cylinder — remove retainer), извлечь plug. Высыпать старые пины. Новый ключ вставить в plug. Подбор пинов: bottom pins (по высоте порезок ключа), driver pins (верхние, обычно стандартны). Заполнение камер: bottom → driver → spring. Сборка: вставить plug, follower tool медленно продвигать, поочерёдно заполняя камеры. Проверка: ключ вращается плавно, без заеданий. Pin kit: набор пинов (0.165-0.335" длины, шаг 0.015-0.030"). | Master key: дополнительный master pin между bottom и driver для двух ключей. |
| locksmith.ops.lock_picking_raking | Взлом замков — грабли и SPP | METHOD | Вскрытие замка (locksport/legal). Raking: rake быстро скользит по пинам (city rake, snake rake), случайный подбор. SPP (Single Pin Picking): крючок, поочерёдное нажатие каждого пина до binding. Tension wrench: лёгкое давление, поиск binding pin. Binding pin: при давлении tension'ом один из пинов застревает (самый tight). Click: пин поднимается до shear line (слышен/ощутим щелчок). Security pins: spool, serrated — создают ложный set (counter-rotation). Только legal unlocking собственных замков! | Никогда не вскрывать замок в использовании (можно повредить). |
| locksmith.ops.automotive_lishi_pick | Автомобильная промышленность — Расшифровка Lishi Pick | METHOD | Вскрытие/декодирование авто замка. Lishi tool (2-in-1 pick + decoder): на каждый профиль ключа свой Lishi. Техника: вставить, tension, поочерёдное нажатие wafer'ов (пинов). Декодирование: шкала на инструменте показывает высоту порезки. Записать код (bitting): 6-8 цифр высот. Key origination: ручная нарезка (depth keys) или code machine (HPC, Futura). Transponder: программирование чипа (OBDII через scan tool или ключом on-board procedure). VATS (Vehicle Anti-Theft System): resistor в ключе (GM 1986-2003), 15 значений сопротивления. | Lishi позволяет сделать ключ без разбора двери. |
| locksmith.ops.safe_combination_change | Безопасно — изменение комбинации | METHOD | Смена комбинации на механическом замке сейфа. Типы: Group 1 (банковский), Group 2 (коммерческий). Процесс (Sargent & Greenleaf style): 1) Открыть сейф на существующей комбинации. 2) Снять заднюю крышку замка. 3) Change key вставить в change hole, повернуть. 4) Набрать НОВУЮ комбинацию (три числа), каждое поворотом диска до отверстия смены. 5) Change key обратно. 6) Проверить НОВУЮ комбинацию с открытой дверью (3 раза!). | Замок сейфа: не смазывать маслом! (графитовый порошок только). |
| locksmith.ops.electronic_access_install | Электронный замок — Установка | METHOD | Установка электронного замка (Schlage Encode, Yale Assure). Подготовка: измерить backset (60 или 70 мм), cross bore 54 мм, edge bore 25 мм. Монтаж: установить deadbolt latch, mounting plate, наружную панель, кабель через дверь, внутреннюю панель, батарейки. Programming: master code, user codes (4-8 digits). Smart: Wi-Fi (удалённое управление через Schlage Home, через Z-Wave/Zigbee хаб). Проверка: механический ключ работает, батарейки заряжены (low battery warning). | Батарейки менять раз в 6-12 мес (не ждать пока сядут!). |
