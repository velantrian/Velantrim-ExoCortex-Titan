| party.ops.sound_system_setup_small | Система громкой связи — настройка и структура усиления | METHOD | Звуковая система для мероприятия (до 200 чел). Компоненты: Mixer (Yamaha MG/Mackie), Amplifier (Crown/QSC), Speakers (active PA: QSC K12, JBL PRX, или пассивные). Сигнальная цепь: Source (DJ controller, microphone) → Mixer (gain, EQ, fader) → Main Out → Crossover (если subwoofer) → Amp → Speakers. Gain staging: 1) Channel Gain: trim так чтобы пик-индикатор загорался на самых громких моментах (не постоянно), затем чуть убавить. 2) Channel Fader: Unity (0 dB). 3) Master Fader: Unity. Проверка: pink noise или музыка, уровень SPL meter (90-95 dB на танцполе, до 100-105 пик для peak time, не >85 dB для dinner). Обратная связь (feedback): микрофон ловит звук из колонок. Решение: уменьшить мониторы, направить колонки вперёд микрофонов (speakers впереди микрофона), ring out мониторы (graphic EQ — убавить частоту feedback). Subwoofer crossover: 80-120 Гц. Crossover: отправляет низкие на sub, остальное на tops. Питание: рассчитать потребление (сумма мощностей всех устройств), не перегружать одну розетку (15A circuit), использовать отдельные цепи для света и звука. | Микрофон ведущего (SM58): кардиоида, не направлять на speakers. Беспроводные микрофоны (Shure ULX, Sennheiser EW): нужно частотное координирование, не интерферировать друг с другом или с TV. |
| party.ops.dj_mixing_beatmatching | DJ — битматчинг и фразировка | METHOD | Сведение треков. Beatmatching: темп A (BPM детектирован) -> adjust tempo slider на B так чтобы BPM B = BPM A. Синхронизация: cue в наушниках (Pre-Cueing), слышать оба трека. Beat align: kick drum с kick drum (1-2-3-4). Pitch bend: временное ускорение/замедление для точной синхронизации (jog wheel). Phrase matching: музыка состоит из фраз (4, 8, 16, 32 тактов). Трек A играет phrase, на начало новой фразы запустить трек B (чтобы вокал не перебивался). Transition (переход): EQ mixing (срезать Bass на треке B, постепенно менять balance — Bass A уменьшать, Bass B увеличивать). Backspin, echo out, filter sweep — эффекты для transition. Гармоничное сведение (Harmonic mixing): тональность трека (Key — Camelot wheel 1A-12B). Смешивать треки в тональности друг друга (или ±1 по кругу Camelot). DJ software: Serato, Rekordbox, Traktor, Virtual DJ. Controller: Pioneer DDJ, Denon. Sync button: не substitute для понимания beatmatching (техника должна работать без sync). | Phrase mismatch: vocal поверх vocal = хаос. Harmonic clash: два трека в разных key звучат диссонансно. |
| party.ops.mc_wedding_timeline | MC — Ведущий свадебного приема | METHOD | Ведение свадебного банкета. Подготовка: встреча с парой за 1-2 нед (план вечера, список имён для introductions, произношение имён фонетически записать!, особые просьбы — кто не speaks, sensitivities). Timeline: 1) Cocktail hour (фоновый джаз/лаунж), 2) Grand Entrance (вход пары + wedding party — MC объявляет каждое имя громко и чётко), 3) Welcome toast (предоставить слово родителям, шаферу/подружке невесты — MC координирует микрофон), 4) Dinner service (background music), 5) First Dance (MC объявляет, приглашает пару на танцпол), 6) Father-Daughter / Mother-Son dance, 7) Cake cutting, 8) Bouquet / Garter toss, 9) Open dance floor (DJ set), 10) Last song. MC микрофон: говорить чётко, уверенно, не запинаясь (репетировать сложные имена!). Держать микрофон близко (5-10 см) к губам, но не закрывать рот. Никаких пошлых шуток без согласования с парой. | Худший кошмар: неправильно произнести имя невесты/жениха. Фонетическая запись: Siobhan = «Ши-вон», Nguyen = «Нгу-ен». Всех членов bridal party спросить pronunciation заранее. Не «making it about me» — MC не центр внимания. |
| party.ops.lighting_dancefloor_atmosphere | Подсветка и освещение танцпола — настройка | METHOD | Световое оформление мероприятия. Uplighting: LED PAR cans (батарейные/проводные) расставлены по периметру зала, светят вверх на стены — заливка комнаты цветом. Wireless DMX управление (с телефона/планшета). Цвета: под свадебную палитру или mood (amber для элегантности, blue/purple для вечеринки). Dancefloor effects: Moving heads (роботы-вращающиеся головы — sharp beams, gobos), Derby/Laser (рассеянное лазерное шоу — НЕ смотреть в лучи!), Strobes (slow для эффекта, fast опасно для эпилептиков). Haze (дымка): создаёт лучи из эффектов видимыми. DMX control: все устройства по кабелю DMX512 цепочкой, управление из DMX software (Chauvet ShowXpress, Obsidian Onyx). Fog machine: заполняет танцпол дымом (water/glycol fluid). Fire alarm: проверить что venue дымовая сигнализация не сработает (particle detectors!) — либо отключить зону с разрешения venue manager (пожарный bypass). | Laser safety: FAA — лазеры не должны попадать в небо (авиация). Class 3B/4 lasers — требуют variance (регулирование). Не направлять на глаза. |
| party.ops.event_contract_deposit | Контракт на проведение мероприятия — Условия и депозит | METHOD | Договор на услуги DJ/MC. Элементы договора: 1) Дата, время, место проведения, имена клиентов, 2) Услуги (ведущий + диджей, звуковая система, подсветка), 3) Часы (настройка, начало и конец мероприятия, ставка сверхурочной работы X долларов США за 30 минут), 4) Общая плата (депозит X долларов США, не подлежащий возврату при подписании, остаток должен быть оплачен в течение 2 недель до даты), 5) Политика отмены (скользящая шкала — 30 дней, возврат 25%, 14 дней) — невозврат средств), 6) Пункт о питании (при проведении мероприятия >4-5 часов необходимо обеспечить горячее питание на 1-2 человек), 7) Оборудование: ответственность за ущерб, причиненный гостями (пролитие вина на контроллер!), 8) Форс-мажорные обстоятельства (стихийные бедствия, болезнь — запасной исполнитель), 9) Музыкальные ограничения (список запрещенных произведений, отсутствие явных текстов?). 10) Подписи. Резервное оборудование: DJ должен иметь резервный ноутбук/планшет, кабели на всякий случай. Страховка: ответственность $1M+ (для проведения мероприятия требуется сертификат). В день: приехать за 2-3 часа до начала для настройки и саундчека. | Do-Not-Play список: пара даёт список запрещённых песен (Chicken Dance, Wobble, explicit). DJ software: можно пометить треки как DNP. Громкость: venue может иметь sound limiter (авто отключение питания при >95-100 dB). |
