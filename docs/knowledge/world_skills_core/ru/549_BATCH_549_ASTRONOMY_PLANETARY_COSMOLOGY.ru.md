| astronomy.venus | Венера — Беглая теплица | PROCESS | Схожий размер/масса с Землёй. Плотная CO₂ атмосфера (92 бар, 96.5% CO₂), облака H₂SO₄. | astronomy.big_bang_timeline | Хронология Большого Взрыва | PROCESS | Планковская эпоха (<10⁻⁴³ с, все силы едины, квантовая гравитация) → инфляция (10⁻³⁶-10⁻³² с, экспоненциальное расширение, квантовые флуктуации → зародыши структуры) → кварковая эпоха → адронная → лептонная → первичный нуклеосинтез (3-20 мин: 75% H, 25% He, следы D, He-3, Li-7) → рекомбинация (380,000 лет: e⁻ + p⁺ → H, Вселенная прозрачна → реликтовое излучение) → тёмные века → первые звёзды (~100-400 млн лет) → реионизация. | Точное согласие теории первичного нуклеосинтеза (BBN) с наблюдаемым обилием лёгких элементов — триумф космологии Большого взрыва. |
| astronomy.cosmic_inflation | Космическая инфляция | MODEL | Решение проблем горизонта (почему CMB одинаков со всех сторон — не могли обменяться светом), плоскостности (почему Ω≈1), монополей. Скалярное поле инфлатон с медленным скатыванием (slow-roll). | Инфляция предсказывает почти масштабно-инвариантный спектр первичных возмущений (n_s ≈ 0.965 ≠ 1 — подтверждено Planck). Реликтовые гравитационные волны (B-mode поляризация) — «дымящийся пистолет» инфляции, пока не обнаружены (r < 0.032). |
| astronomy.dark_energy | Темная энергия и ускорение расширения | PROCESS | Сверхновые Ia показали ускоренное расширение (1998, Нобелевская премия 2011: Перлмуттер, Шмидт, Рийсс). Альтернативы: квинтэссенция (скалярное поле, w > −1), модифицированная гравитация (f(R), DGP). | Уравнение состояния тёмной энергии w: текущие ограничения w = −1.03±0.03. Если w ≠ −1 → динамическая тёмная энергия, не Λ. |
