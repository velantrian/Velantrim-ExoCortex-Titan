# BATCH 1001: Ground Transportation — School Bus & Transit

**KnowledgeUnits:** 5
**Namespace:** `transit.ops.*`
**Scope:** school_bus, pre_trip, loading, emergency_drill, route_planning, charter, transit, safety

| ID | KnowledgeUnit | Тип | Суть | Практический смысл |
|---|---|---|---|---|
| transit.ops.school_bus_pre_trip | Школьный автобус — Предрейсовый осмотр | METHOD | Предрейсовый осмотр школьного автобуса. Внутри: зеркала (наружные, внутренние, конвекс для прохода), аварийное освещение, аварийные выходы (выход через заднюю дверь, люк в крыше, окна), аптечка, огнетушитель, система деактивации (для съемной траверсы). Снаружи: освещение (все — стоп-сигналы, мигалочки, фонари школьного автобуса), шины (глубина протектора >2/32 дюйма, давление, без порезов), тормозные колодки (через смотровые отверстия), ремень безопасности, фонари подушек безопасности (торпедо), регулировка зеркал. Внизу: жидкости (масло, охлаждающая жидкость, тормозная жидкость), ремни, протечки. Зона безопасности учащихся: 10 футов (3 м) вокруг автобуса. | Требуется подтверждение CDL (коммерческие водительские права) + P (пассажир) + S (школьный автобус). |
| transit.ops.student_loading_unloading | Загрузка — Протокол безопасности учащихся | METHOD | Загрузка/выгрузка школьников. Lights: amber flashing при приближении к остановке (200-400 м). Stop arm, red lights: при остановке. Sweep check: специальная метла на некоторых автобусах (проверка под автобусом). Student crossing: пересекать на 10 feet впереди автобуса (driver видит), дождаться сигнала driver. Не пересекать позади! Driver: держать eye contact со студентами при пересечении. Roll call: проверить перед отправлением. Sleeping student check: КАЖДЫЙ рейс, till/back sweep (ходить до последнего ряда до открытия дверей). | Sleeping student: ребёнок прячется, спит — оставлен в автобусе. |
| transit.ops.transit_bus_schedule_headway | Транзитный автобус — ход и надежность | METHOD | Интервалы движения (прогресса) и надежности. Интервал в час пик: 5-15 мин (линии с повышенным спросом). Вне пик: 20-30 мин (низкий спрос). Своевременное выполнение (OTP): при появлении в пределах 0-5 минут по расписанию (цель >90%). Группировка: два автобуса идут вместе (один опаздывает → накапливает пассажиров → медленнее → ещё опаздывает). Корректировка группировки автобусов: по сигналу пассажира (держать автобус до времени отправления), пропуск остановки, ускорение следующего. CAD/AVL: отслеживание в реальном времени (компьютерная диспетчеризация/автоматическое определение местоположения транспортных средств). | Headway-based scheduling: нет расписания, только «каждые N минут» (более гибко). |
| transit.ops.bus_rapid_transit_features | BRT — Элементы дизайна | METHOD | Автобус быстрого транспорта (BRT). Выделенная полоса: Полоса только для автобусов (или полоса БАТ с правыми поворотами). Посадка на уровне платформы: автобус = платформа (без ступеней). Внебортовая оплата проезда: оплата на станции, а не в автобусе. Приоритет сигнала: светофоры пропускают BRT. Высокочастотная служба: <10 мин интервала. Современные автомобили: сочлененные (180-200 кресел). Станции: закрытые, информация в реальном времени. GTFS-Realtime: данные о остановке в транспортных приложениях. Пассажиропоток: на 30-50% выше обычного автобуса (имидж, надежность). | TransMilenio (Bogota) — образцовый BRT (350 тыс пассажиров/день). |
| transit.ops.paratransit_eligibility | Паратранзит — Оценка соответствия требованиям ADA | METHOD | Оценка прав на паратранзит (США ADA). ADA требует: паратранзит для людей, которые не могут использовать маршрутные автобусы. Право на участие: 1) функциональная способность садиться/ехать/выходить из автобуса (без специализированной помощи), 2) когнитивная способность ориентироваться в системе, 3) условия окружающей среды (могут влиять экстремальные погодные условия). Категории, соответствующие критериям: безусловный (всегда), условный (только в определенных условиях — например, лёд/снег). Оценка: функциональная оценка (кондиционный осмотр), а не медицинский диагноз. Апелляционный процесс. | Стоимость паратранзита: 5-7 раз по фиксированному маршруту (по АПТА). |
