# BATCH 1048: Pond Liner — EPDM Welding

**KnowledgeUnits:** 5
**Namespace:** `pondliner.ops.*`
**Scope:** seam, primer, tape, caulk, overlap, repair, fish_safe

| ID | KnowledgeUnit | Тип | Суть | Практический смысл |
|---|---|---|---|---|
| pondliner.ops.seam_tape_primer_epdm | Шовная лента — метод грунтовки | METHOD | Склеивание EPDM швов. Очистка: gasoline/white spirit (убрать release agent с factory). Primer (Firestone QuickPrime): нанести на обе поверхности (5-8 см полоса), дать высохнуть 2-5 мин (пока станет tacky). Seam tape (специальная двусторонняя лента): наклеить на одну поверхность, снять backing. Вторую поверхность прижать, roller (силиконовый валик) с большим давлением. Время: 24 часа до full strength. | Влажность/грязь: seam не держится. |
| pondliner.ops.caulk_lap_sealant_epdm | Герметик внахлест — метод герметика | METHOD | Альтернативный метод герметизации. Lap sealant (FireQuick Lap Sealant): наносится caulk gun. Нанести на overlapped seam край, разровнять. Для вертикальных швов: более удобен чем tape. Cover tape (односторонняя) поверх для защиты. Применение: сложные геометрии, pipe boots. Вулканизация: химически сшивается с EPDM (monolithic bond). | Лента + герметик вместе: золотой стандарт. |
| pondliner.ops.pipe_boot_flashing_install | Загрузочная трубка — прошивка | METHOD | Герметизация прохода трубы через EPDM. Pipe boot: pre-formed EPDM конус (натягивается на трубу). Hole в liner меньше diameter pipe (плотное облегание). Seal: lap sealant между liner и boot, stainless clamp на конце boot к трубе. Для нескольких труб: individual boots. | Без pipe boot: вода уходит под liner. |
| pondliner.ops.patch_repair_underwater | Патч — Подводный ремонт | METHOD | Ремонт прокола EPDM под водой. Primer: специальный underwater primer. Patch: округлить углы (квадратные отклеиваются). Нанести primer на patch и liner, дать flash. Сложить patch как тако (центр visible), прижать к liner, unfold, roller. Underwater: сложнее (visibility, pressure). | Всегда округлять углы patch! |
| pondliner.ops.fish_safe_sealant_cure | Fish-Safe — протокол лечения | METHOD | Обеспечение безопасности для рыб. После склеивания: выдержка 24-48 часов до заполнения водой. Запах: solvent должен полностью испариться. Промывка: заполнить водой, слить (опционально). Тест: запустить несколько "жертвенных" рыб (feeder goldfish) перед ценными koi. Продукты: специально маркированы fish-safe (Firestone, Oase). Не использовать кровельные sealant'ы! (токсичны). | Roofing EPDM и sealant содержат альгициды. |
