| linguistics.phonetics_articulatory | Артикуляционная фонетика | INVARIANT | Классификация звуков: место образования (губные, зубные, альвеолярные, велярные, глоттальные), способ (смычные, щелевые, аффрикаты, носовые, аппроксиманты), голос (звонкие/глухие). | IPA (Международный фонетический алфавит) — [p] глухой билабиальный смычный, [ð] звонкий дентальный фрикативный (англ. | linguistics.phonetics_acoustic | Акустическая фонетика | VARIANT | Спектрограмма: форманты (F1-F4). F1 обратно пропорциональна высоте гласного (низкий [a] — высокое F1 ~800 Гц), F2 — ряду (передний [i] — F2 ~2300 Гц). VOT (время начала голоса) различает звонкие/глухие смычные. | Синтез и распознавание речи. Гласные — формантная структура, согласные — переходы формант. |
| linguistics.phoneme_allophone | Фонема против аллофона | INVARIANT | Фонема — минимальная звуковая единица, различающая смысл (/p/ vs /b/ в "пил"-"бил"). Аллофоны — варианты фонемы, не различающие смысл (придыхательный [pʰ] в начале слова vs непридыхательный [p] после s в английском "pill" vs "spill"). | Минимальные пары — тест на фонему. Дополнительная дистрибуция (аллофоны не встречаются в одном контексте). |
| linguistics.syllable_structure | Слоговая структура | VARIANT | Слог = onset (приступ) + rhyme (рифма), где rhyme = nucleus (ядро, обычно гласный) + coda (кода, согласные после ядра). Универсальное предпочтение CV (открытый слог). | Языки различаются: японский (CV, максимум CVC с назальной кодой), русский/английский допускают сложные кластеры согласных (взгляд — CCCVC, strengths — CCCVCCCC). |
| linguistics.morphology_inflectional | Флективная и деривационная морфология | VARIANT | Словоизменительная (флективная): не меняет часть речи, выражает грамматические категории (падеж, число, время — "стол-столы", "иду-шёл"). Словообразовательная (деривационная): создаёт новые слова, может менять часть речи ("стол-ик", "ход-ить" → "про-ход"). | Агглютинативные языки (турецкий) — цепочки суффиксов с одним значением. Флективные (русский) — один суффикс объединяет несколько значений. |
| linguistics.morpheme_types | Типы морфем | VARIANT | Корень (обязательный), аффиксы: префикс (перед), суффикс (после), инфикс (внутри), циркумфикс (вокруг). Флексия (окончание). Свободные (могут быть отдельным словом) и связанные (только с другими) морфемы. | Тагальский: инфикс -in- в sulat (писать) → s-in-ulat (написанный). Русский: при- (префикс), -ова- (суффикс), -ть (окончание). |
| linguistics.syntax_phrase_structure | Структура фразы Грамматика | INVARIANT | Дерево непосредственных составляющих: S → NP + VP. NP → Det + N, VP → V + NP. Хомский (1957). Рекурсия: NP → NP + PP (бесконечное вложение). | Неоднозначность прикрепления: «I saw the man with the telescope» (с телескопом — я или мужчина?). |
| linguistics.syntax_x_bar | Теория X-бара | MODEL | Универсальная схема фразы: X'' (XP) → Specifier + X'; X' → X (head) + Complement. Промежуточный уровень X'. | Все фразы (NP, VP, AP, PP) имеют одинаковую структуру. Параметр «head-first» (англ.) vs «head-last» (японский). |
| linguistics.word_order | Типология порядка слов | VARIANT | Гринберг: доминирующие порядки: SOV (турецкий, японский, корейский, латынь) ~45%, SVO (английский, китайский, русский) ~42%, VSO (арабский, ирландский) ~10%. VOS, OVS, OSV — редкие. | Корреляции: SOV → послелоги, SVO → предлоги. SOV → Родительный падеж-существительное, SVO → Имя-родительный падеж. |
| linguistics.semantics_lexical | Лексическая семантика | VARIANT | Синонимия (полная: редко), антонимия (градуальная: горячий-холодный, комплементарная: живой-мёртвый, реляционная: учитель-ученик), гипонимия (роза — цветок), полисемия (много значений — "ключ"), омонимия (разные слова совпали — "ключ" от двери и "ключ" источник). | Меронимия (часть-целое: палец-рука). Семантические поля (цвета, родства). |
| linguistics.componential_analysis | Компонентный анализ | METHOD | Разложение значения слова на семантические признаки (атомы смысла). Мужчина = [+человек, +взрослый, +мужской пол]. Женщина = [+человек, +взрослый, −мужской пол]. | Системы родства, классификация глаголов движения. Не всегда работает для абстрактных понятий. |
| linguistics.pragmatics_grice | Принципы разговора Грайса | INVARIANT | Принцип Кооперации. Максимы: Количества (достаточно, не больше), Качества (правда), Релевантности (по теме), Способа (ясно). Нарушение → импликатура (скрытый смысл). | "Как тебе моя стрижка?" — "Какая красивая блузка!" (нарушение релевантности → импликатура: стрижка ужасна). |
| linguistics.speech_acts | Речевые акты (Остин, Сирл) | MODEL | Локуция (произнесение), иллокуция (намерение: просьба, приказ, обещание), перлокуция (эффект). Констативы (описание мира) vs перформативы (сами совершают действие: «объявляю вас мужем и женой»). | «Здесь холодно» = констатив? Или иллокутивный акт просьбы закрыть окно? Косвенные речевые акты. |
| linguistics.politeness_theory | Теория вежливости | PROCESS | Goffman: «лицо» — социальный имидж. Позитивное лицо (желание быть принятым) и негативное (желание свободы). Угроза лицу. Стратегии: bald on-record, позитивная вежливость, негативная, off-record (намёк). | Просьба: «Дай соль» → «Не мог бы ты передать соль?» → «Что-то суп сегодня пресный...» (off-record). |
| linguistics.sociolinguistics_dialect | Диалект, социолект, идиолект | VARIANT | Диалект — региональный вариант. Социолект — социальный (профессия, класс). Идиолект — индивидуальный язык. | linguistics.first_language_acquisition | Овладение первым языком | PROCESS | Стадии: гуление (2-3 мес), лепет (6-12), однословная (12-18), двусловная (18-24), телеграфная речь (24-30), освоение грамматики (3+).
