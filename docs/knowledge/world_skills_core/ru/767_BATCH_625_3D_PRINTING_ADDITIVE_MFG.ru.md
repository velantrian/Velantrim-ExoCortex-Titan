# BATCH 625: 3D Printing — Additive Manufacturing Operations

**KnowledgeUnits:** 5
**Namespace:** `print3d.ops.*`
**Scope:** FDM, SLA, slicing, filament, resin, bed_leveling, post_processing

| ID | KnowledgeUnit | Тип | Суть | Практический смысл |
|---|---|---|---|---|
| print3d.ops.fdm_bed_leveling | FDM — выравнивание слоя и первый слой | METHOD | Ручной бумажный метод (зазор 0,1 мм). Выравнивание сетчатого слоя (BLTouch, зонд). Микрошаг со смещением по оси Z. Тест первого слоя: ровное прилегание без щелей и гребешков. Адгезия основания: чистый изопропил, лист PEI, клей-карандаш для PLA на стекле. | Первый слой — 90% отказов начинаются здесь. |
| print3d.ops.filament_drying | Нить — сушка и хранение | METHOD | PLA гигроскопичен. Признаки влажного: хлопок, натягивание, плохая адгезия. Сушка: сушка 45-50°С PLA, 65-75°С PETG, 70-80°С Нейлон 4-6 часов. Хранение: герметичный ящик + влагопоглотитель. Нейлон/ПВА — распечатать из сухого короба. | Мокрый PLA становится хрупким. |
| print3d.ops.sla_resin_safety | SLA — Обращение со смолой и безопасность | METHOD | Фотополимер токсичен. PPE: нитриловые перчатки всегда, очки, маска. Вентиляция enclosure + exhaust. Wash: isopropyl 99% 2-5 мин. Post-cure: UV chamber 2-5 мин. Support removal. Disposal: НЕ сливать uncured в раковину — отвердить на солнце, затем в мусор. | Resin spill: немедленно вытереть. |
| print3d.ops.slicing_support | Нарезка — поддержка и ориентация | METHOD | Ориентация: опоры минимизации (>45° = нужны). Расстояние по Z 0,1-0,2 мм FDM, 0,05-0,1 SLA. Заполнение: 15-20% декоративное, 50-100% функциональное. Гироид — равномерная прочность. Высота слоя: качество 0,12, стандарт 0,20, черновое 0,28. Брим/Плот. | Orientation: нагрузку направлять поперёк слоёв. |
| print3d.ops.abs_enclosure | ABS — корпус и предотвращение деформации | METHOD | Высокая усадка → коробление. Решения: корпус 40-50°С, кровать 100-110°С, сопло 240-260°С, лист PEI + суспензия ABS, поля 8-10 мм, без сквозняков. Вентилятор охлаждения ВЫКЛ. Разглаживание паров: ацетоновый пар для блеска. | Пары ABS (стирол) — угольный/HEPA-фильтр, вентиляционное отверстие проверено. |
