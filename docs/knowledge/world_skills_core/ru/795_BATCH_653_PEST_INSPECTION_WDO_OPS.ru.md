# BATCH 653: Pest Inspection — Termite & WDO Reports

**KnowledgeUnits:** 5
**Namespace:** `pestinspect.ops.*`
**Scope:** WDO_inspection, WDI_report, wood_destroying, beetle, drywood_termite, subterranean, fungus, report

| ID | KnowledgeUnit | Тип | Суть | Практический смысл |
|---|---|---|---|---|
| pestinspect.ops.wdi_report_requirements | Отчет WDI — форма и требования | METHOD | Отчёт о Насекомые-древоразрушители (форма НПМА-33). Раздел 1: Заражение — свидетельство живых особей. Раздел 2: повреждение + нет живых насекомых (Заражение — повреждение, но неактивно). Раздел 3: благоприятные условия (влажность, контакт дерева с землей, недостаточная вентиляция). Раздел 4: предыдущее лечение. Необходимы для ипотеки (ВА, FHA). Осмотр: все доступные зоны (подвал, чердак, подвал, наружная часть). Рекомендации: условия лечения или коррекции. | Отчет WDI не является отчетом о структурной целостности. |
| pestinspect.ops.subterranean_termite_signs | Подземный термит — Знаки | METHOD | Признаки подземных термитов. Mud tubes (земляные ходы по фундаменту, трубам). Размер: карандаш. Test: разломать — если через 1-2 дня восстановлены = active infestation. Swarmers (крылатые + сброшенные крылья на подоконниках весной). Frass (экскременты) — для drywood, НЕ subterranean (subterranean галереи чистые). Hollow wood: tapping — глухой звук, probe протыкает. Повреждения: вдоль волокон (слоистая структура). Влажность: ключевой фактор (leaky pipe, gutter). | Mud tubes могут идти внутрь стены (невидимо). |
| pestinspect.ops.moisture_meter_use | Измеритель влажности — использование при проверке | METHOD | Применение влагомера для поиска скрытых проблем. Pin-type (контактный, измеряет сопротивление между электродами). Pinless (электромагнитный, сканирует поверхность — хорошо для быстрого поиска). Калибровка: по породе дерева. Критические значения: >20% MC = риск fungal decay, >28% = active decay. Области: вокруг окон/дверей, сантехники, крыши, стены ванной, crawlspace. Термограмма (ИК-камера): холодные пятна = влажность. | Pinless не проникает глубоко (поверхностный замер). |
| pestinspect.ops.wood_decay_fungus_types | Распад древесины — виды грибков | METHOD | Типы грибкового разрушения. Brown rot (бурая гниль): древесина темнеет, трескается поперёк в кубики (cubical checking), рассыпается в порошок. White rot (белая гниль): обесцвечивание, волокнистая структура, мягкая. Soft rot: в очень влажной среде. Poria incrassata (водопроводящий гриб — rhizomorphs проводят воду на метры). Условия: влажность древесины >20% + тепло. Лечение: удалить влажность (устранить источник) + заменить поражённую древесину + фунгицидная обработка соседней. | Сухая гниль — миф. Нужна влага! |
| pestinspect.ops.powderpost_beetle_damage | Пороховой жук — идентификатор повреждения | METHOD | Идентификация жука-точильщика. Lyctus (пороховой жук): мелкие отверстия (1-2 мм), активная мука (fine flour-like frass). Разрушает твёрдую древесину (дуб, ясень, орех — крахмал в древесине). Anobiid (мебельный жук): отверстия 2-4 мм, гранулированный frass. Old house borer (усач): овальные отверстия 6-12 мм. Индикатор активности: свежий frass (определяется по цвету/форме), отсутствие пыли/паутины в отверстиях. Treatment: borate (Tim-Bor, BoraCare) для prevention/remediation. Fumigation: для severe active infestation. | Старые отверстия (неактивные) не требуют treatment. |
