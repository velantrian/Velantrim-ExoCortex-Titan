Скорость проектирования: определите все геометрические элементы. Зеленая книга AASHTO: источник. Конус AASHTO на рампе: стандарт. | Сотка сегмента: короткий → низкий LOS → требуют коллекторно-распределительных дорог. |

| transeng.ops.sight_line_horizontal | Горизонтальное выравнивание — линии обзора | METHOD | Горизонтальное выравнивание: Minimum radius: R = V² / (127 × (e + f)). e = superelevation (до 10%), f = side friction factor. Коэффициенты слоя (а): асфальт = 0,44, гранулярная опора = 0,14. Модификаторы дренажные (м). ESAL (эквивалентные нагрузки на одну ось): расчётная нагрузка. Модуль упругости земляного полотна (Mr). | transeng.ops.traffic_signal_timing | Сигнал светофора — длина цикла | METHOD | Оптимальная длина цикла (Уэбстер): C₀ = (1.5 L + 5) / (1 - Y). L = total lost time.
