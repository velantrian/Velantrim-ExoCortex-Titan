# BATCH 987: Sign Making — Vinyl & Commercial Signage

**KnowledgeUnits:** 5
**Namespace:** `signmaking.ops.*`
**Scope:** vinyl_cutting, weeding, application, sandblasting, dimensional, illuminated, installation, design

| ID | KnowledgeUnit | Тип | Суть | Практический смысл |
|---|---|---|---|---|
| signmaking.ops.vinyl_cutter_setup | Резак для винила — лезвие и сила | METHOD | Настройка режущего плоттера (Roland, Graphtec, US Cutter). Blade depth: только кончик лезвия режет vinyl (0.1-0.2 мм выход). Тест: провести по vinyl, должен порезать vinyl + не оставить следа на backing. Blade force: начать с 80-100 gf, увеличивать если не режет. Speed: 300-500 мм/с (normal), медленнее для деталей. Tracking: vinyl edge parallel to rollers. Pinch rollers: давят на vinyl (не на edge zone). Test cut: перед каждым job. | Слишком глубокий blade: режет backing (vinyl не отделяется). |
| signmaking.ops.weeding_application_transfer | Прополка и перенос — виниловая аппликация | METHOD | Вывивание лишнего. Weeding hook: удалить фон, оставить design. Мелкие детали: пинцет (tweezers). Weeding с теплом (heat gun 50°C): облегчает для холодного vinyl. Transfer tape (application tape): клеевая поверхность на vinyl design. Ламинатор: ровное приклеивание без пузырей. Application: снять backing с vinyl, перенести на поверхность. Hinge method: один край, потом постепенно. Squeegee: от центра к краям. Снятие transfer tape: 180° (назад, не вверх). | Пузырь после нанесения: проколоть булавкой + сжать. |
| signmaking.ops.substrate_surface_preparation | Подготовка поверхности — табличка | METHOD | Подготовка поверхности под винил. Очистка: протирка IPA (изопропанол). Жирная поверхность (отпечатки пальцев): выглядеть. Температура применения: 15-27°C (холодный = адгезия). Текстурированные поверхности: винил под давлением (агрессивный клей). Кривые: нагрейте винил (60-70°С) перед нанесением (драпировкой). Заклепки: нарежьте винил до заклепок (звездчатый узор). Окна: низкоклейкая оконная пленка. Гофрированные поверхности: только цифровая УФ-печать. | Vinyl на vinyl (layering): двойные контуры = отслаивание (не >3 слоя). |
| signmaking.ops.dimensional_letter_install | Размерная буква — шпильки и дорожка качения | METHOD | Установка объёмных букв. Studs: металлические штыри в тыльной стороне букв (2-4 шт на букву). Шаблон: drill template для сверления отверстий в стене. Drill: в стену, заполнить epoxy, установить буквы. Raceway (металлический короб): трасса для электрических букв, скрывает провода. Illuminated (backlit / front lit): LED modules внутри пластиковых или алюминиевых букв, трансформатор 12V/24V. | Уровень: laser level для ровной строки. |
| signmaking.ops.banner_grommets_finishing | Баннер — Отделка и люверсы | METHOD | Финишная отделка баннера. Hem (подрубка): сварка double-ply кромки (hot knife или ultrasonic welder). Грюммет (grommet): медные кольца для крепления (шаг 60 см). Grommet punch (для ручного) или machine (серийное). Размещение: углы + каждые 60 см. Pole pocket: складка и шов для флагштока. Скрутка (banner rope): кручёный шнур через grommets для натяжения. Банерная ткань: 440 gsm, 500D×500D (heavy duty), 350 gsm (event). | Ветровые прорезы (wind slits): для продуваемых мест. |
