# BATCH 661: Cabinet Making — Custom Woodworking

**KnowledgeUnits:** 5
**Namespace:** `cabinet.ops.*`
**Scope:** face_frame, frameless, box_construction, drawer, door, hinge, finishing, installation

| ID | KnowledgeUnit | Тип | Суть | Практический смысл |
|---|---|---|---|---|
| cabinet.ops.box_construction_plywood | Строительство коробок — Столярные изделия из фанеры | METHOD | Сборка ящика шкафа. Материал: Baltic birch plywood (void-free, BB/BB, 3/4" для корпуса), МДФ для крашеных. Dado joint (паз): для полок и дна (1/4" dado blade на циркулярной пиле, глубина 1/2 толщины). Rabbet (фальц): задняя стенка (1/4" plywood). Pocket screws (Kreg jig): быстрая сборка. Glue: Titebond II. Squaring: диагонали равны. Clamps: 4-6 струбцин при сборке. Back panel: 1/4" plywood, фиксирует квадратность. Нагрузка: полки без поддержки на 900+ мм провисают. | Edge banding (ПВХ или шпоновая лента) на видимых торцах. |
| cabinet.ops.frameless_european_hinge | Безрамное — установка европейской петли | METHOD | Установка петли для корпусной мебели. 35 мм Blum, Grass, Salice. Чашечное отверстие: 35 мм fоerstner bit, глубина 12-13 мм, расстояние от края 3-4 мм. Монтажная пластина: на корпусе (adjustable). Регулировка: horizontal (вверх-вниз), depth (вглубь-наружу), lateral (влево-вправо). Soft-close dampener. Opening angle: 110°, 170° (full overlay), 0° inset. Overlay: full (дверь полностью закрывает торец), half (если mid partition), inset (дверь в проёме). Количество петель: <600 мм = 2, 600-1200 мм = 3, >1200 мм = 4. | Точность Foerstner: кондуктор (hinge jig, Blum MINIPRESS) для серийного производства. |
| cabinet.ops.drawer_slide_undermount | Ящик — направляющие под столешницу (Blum Tandem) | METHOD | Монтаж подвесных направляющих выдвижного ящика. Blum Tandem Plus / Legrabox: soft-close, full extension. Установка: rear socket на задней стенке (выдвижная планка), front bracket на лицевой панели. Накладка (drawer front): регулировка положения по 3 осям. Высота ящика: internal height = slide height. Типичные высоты: 68 мм, 83 мм, 108 мм. Push-to-open (TIP-ON): без ручки. Blumotion: встроенный soft close. Нагрузка: до 65 кг (Legrabox). | Точность установки rear bracket: ±1 мм влияет на работу механизма. |
| cabinet.ops.panel_finishing_finishing | Отделка панелей — Дверные профили | METHOD | Изготовление рамочно-филёнчатых дверей (shaker/raised panel). Рамка: rail + stile (поперечина + вертикальный брусок). Соединение: cope and stick (router table — stile получает groove + profile, rail получает tenon + profile). Филёнка (panel): raised panel bit на router table, или MDF flat panel. Fit: panel свободно в рамке (expansion). Glue: ТОЛЬКО на cope-and-stick joint, не на panel! (дерево двигается). Flat panel (MDF): клеить не рекомендуется, только зажать рамкой. | МДФ panel можно клеить (не двигается), зато тяжелее. |
| cabinet.ops.installation_shimming_scribing | Установка — Shim & Scribe | METHOD | Установка шкафов. Шимсование: подкладки (shims) под основание (пол не ровный). Стяжка шкафов (стеновые): найти studs (stud finder), screws в каждый stud. Зазор между шкафами: nail 8d (2.5") или pocket screw. Верхняя линия: laser level (все верхние кромки на одной высоте). Зазор к стене: scribing (плотное прилегание, если угол не 90°). Scribing caulk: силикон на стыке с потолком/стеной. Trim molding (карниз): под 45° в углах. Toe kick: клипсы к ножкам. | Выгнутая стена (concave/convex): не пытаться изогнуть шкаф, только scribe edge. |
