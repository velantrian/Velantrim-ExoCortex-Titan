# BATCH 587: Physics — Photonics, Metamaterials & Spintronics

**KnowledgeUnits:** 10
**Namespace:** `physics.photonics.*` `physics.metamaterials.*` `physics.spintronics.*`
**Scope:** photonic_crystals, plasmonics, metamaterials_negative_index, transformation_optics, cloaking, spintronics_basics, giant_magnetoresistance, spin_transfer_torque, mrram, skyrmions.

| ID | KnowledgeUnit | Тип | Суть | Практический смысл |
|---|---|---|---|---|
| physics.photonics.photonic_crystal | Фотонный кристалл — запрещенная зона для света | INVARIANT | Периодическая модуляция диэлектрической проницаемости с периодом ~λ/2 создаёт фотонную запрещённую зону: свет с определёнными частотами НЕ может распространяться (аналог электронной band gap). Дефект → локализованная мода → микрорезонатор (сверхвысокая добротность Q > 10⁶). | Безпороговые лазеры, сверхъяркие LED, оптические волноводы с острыми поворотами (90° без потерь!), оптические транзисторы. |
| physics.photonics.surface_plasmon | Поверхностный плазмонный поляритон (SPP) | PROCESS | Связанные колебания электромагнитного поля и электронов проводимости на границе металл-диэлектрик. Длина волны SPP меньше свободной → преодоление дифракционного предела! Локализованные плазмоны (наночастицы Au/Ag — цвет зависит от размера/формы). | Сенсоры (изменение n среды → сдвиг резонанса — детектирование единичных молекул), субволновая оптика, фототермическая терапия рака, SERS (гигантское комбинационное рассеяние). |
| physics.metamaterials.negative_refractive_index | Метаматериал с отрицательным показателем преломления | INVARIANT | Структура с одновременно ε < 0 и μ < 0 → n = −√(εμ) (Веселаго, 1968 — теоретически; Пендри, Смит, 2000 — экспериментально: split-ring resonator + wire array). Закон Снелла меняет знак! Обратный эффект Доплера, обратное излучение Черенкова. | Суперлинза (идеальная линза Пендри — преодоление дифракционного предела, усиление evanescent waves). Оболочка-невидимка. |
| physics.metamaterials.transformation_optics | Оптика трансформации — маскировка | METHOD | Уравнения Максвелла инвариантны относительно координатных преобразований, если соответствующим образом изменить ε и μ (Пендри, Леонхардт, 2006). Теоретически можно направить свет в обход объекта — невидимость. Экспериментально: ковровая оболочка (carpet cloak) в микроволновом и ИК диапазонах. | Идеальное плащание широкополосно и для всех углов — пока недостижимо. Ковровая оболочка работает для ограниченных углов и узкой полосы. |
| physics.metamaterials.metasurface | Метаповерхности — 2D метаматериалы | METHOD | Субволновые структуры на поверхности (V-антенны, наностолбики TiO₂/a-Si), каждая с контролируемой фазой задержки. Обобщённые законы Снелла с градиентом фазы. Позволяет создать плоскую оптику: металлизы — замена громоздких линз (толщина ~λ вместо см). | Metalens (Capasso, 2016): фокусировка без сферической аберрации в видимом свете. Компактные камеры, AR/VR оптика (тонкие, лёгкие, дёшевы в массовом производстве). |
| physics.spintronics.gmr | Гигантское магнитосопротивление (ГМР) | INVARIANT | Сопротивление многослойной структуры (Fe/Cr/Fe) зависит от взаимной ориентации намагниченности слоёв: параллельная → низкое R, антипараллельная → высокое R (эффект ~50-100%). Спин-зависимое рассеяние (Mott). Нобелевская премия 2007 (Ферт, Грюнберг). | Революция в жёстких дисках: головки чтения на GMR позволили терабайтные ёмкости (чувствительность к полям рассеяния битов ~10⁻⁶ Тл). |
| physics.spintronics.tmr_mtj | Туннельное магнитосопротивление (TMR) и MTJ | PROCESS | Магнитный туннельный переход (MTJ): два ферромагнетика разделены тонким (~1 нм) изолятором (MgO). Туннельный ток спиново-поляризован. Параллельно → низкое R, АП → высокое. TMR >600% при комнатной T (MgO MTJ). | MRAM (магнитная память): MTJ как ячейка памяти — непереносимая, быстрая, бесконечные циклы записи. STT-MRAM (запись током) — индустриальный стандарт. |
| physics.spintronics.stt | Крутящий момент передачи вращения (STT) | PROCESS | Спин-поляризованный ток, проходя через тонкий ферромагнитный слой, передаёт угловой момент намагниченности → переключение без внешнего магнитного поля. Пороговый ток J_c ~ 10⁶-10⁷ А/см². | Запись в MRAM, наногенераторы СВЧ (spin-torque nano-oscillator), race-track память (Паркин — движущиеся доменные стенки). |
| physics.spintronics.spin_hall | Эффект спин-холла и она | PROCESS | Прохождение тока через материал с сильным спин-орбитальным взаимодействием (Pt, Ta, W) → отклонение электронов со спином ↑ и ↓ в противоположные стороны (поперечное спиновое разделение без внешнего магнита!). Обратный эффект: спиновый ток → зарядовый ток. | Чисто электрическая генерация спинового тока (без ферромагнетика). SOT-MRAM (спин-орбитальный торк — трёхтерминальное переключение, быстрее и надёжнее STT). |
| physics.spintronics.skyrmion | Магнитные скирмионы | INVARIANT | Вихревые спиновые текстуры (топологически защищённые — требуется энергия для их уничтожения). Крошечные (диаметр ~1-100 нм в зависимости от материала), стабильны, движутся под сверхнизкими токами (в 10⁵-10⁶ раз меньше, чем для доменных стенок). Квантованный топологический заряд Q = ±1. | Идеальный кандидат для race-track памяти и логических устройств. MnSi, FeGe (B20 структуры, хиральные), тонкие плёнки (Pt/Co/MgO — DMI). |
