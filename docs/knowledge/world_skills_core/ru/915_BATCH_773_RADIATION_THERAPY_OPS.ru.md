| radtherapy.ops.linac_components | LINAC — Ключевые компоненты | METHOD | Линейный ускоритель (LINAC): Электронная пушка → Банчер → Ускорительный волновод → Изгибающий магнит (для фотонов) → Мишень (рентгеновские фотоны). Головка (гентри): первичный коллиматор + сглаживающий фильтр (или FFF) + вторичные коллиматоры (бранши X-Y) + MLC (многолепестковый коллиматор). Кольцо Гантри: вращается на 360°. EPID (электронное портальное устройство визуализации): для проверки. | FFF (Flattening Filter Free): более высокая мощность дозы → SBRT. |
| radtherapy.ops.imrt_optimization | IMRT — обратное планирование | METHOD | IMRT (лучевая терапия с модулированной интенсивностью): обратное планирование. Клиницист задает цели (целевая доза + ограничения OAR) → оптимизатор ищет надежные источники финансирования. Целевая функция: минимизировать взвешенную сумму отклонений. DVH (гистограмма «доза-объем»): оценка качества плана. Метрики оценки: D95% (доза для 95% объема), Dmax (максимальная доза). Листовые последовательности MLC → модулированные поля. | VMAT (объемная модулированная дуговая терапия): IMRT при вращении желудка. |
| radtherapy.ops.sbrt_lung_procedure | SBRT — Лечение легких | METHOD | Стереотаксическая радиохирургия тела (SBRT) лёгкого: движение опухоли при дыхании → 4D CT. ITV (Internal Target Volume): включает дыхательное движение. IGRT (Image-Guided RT): проверка перед каждой фракцией. Dose: 54 Гр/3 фракции = ablative. CBCT + couch corrections. Ablative doses: биологически эффективная доза (BED) >100 Гр (при α/β=10). | SBRT лёгкое vs хирургия: аналогичные исходы у операбельных + лучше у неоперабельных. |
| radtherapy.ops.radiobiology_lq_model | Радиобиология — линейно-квадратичная | METHOD | Линейно-квадратичная модель (LQ): S(d) = exp(-αd - βd²). SF2 (Surviving Fraction at 2 Gy): клеточная чувствительность. BED = D × (1 + d/[α/β]). α/β: опухоль = 10, лёгкое = 3, спинной мозг = 2. Гиперфракционирование: меньший d → меньше β-поражение. Гипофракционирование: больший d → эффективно при высоком α/β. | Предстательная железа: α/β≈1.5 → гипофракционирование эффективно. |
| radtherapy.ops.4d_ct_respiratory | 4D КТ — Дыхательная вентиляция | METHOD | 4D КТ: синхронизация КТ с дыхательным циклом. 10 фаз дыхательного цикла (0-90%). Prospective vs Retrospective gating. Respiratory tracking: внешний маркер (Varian RPM) или вnтренний. DIBH (Deep Inspiration Breath Hold): снижение дозы на сердце при левосторонних опухолях молочной железы. ITV contour: объединение контуров по всем фазам. | DIBH снижает среднюю сердечную дозу на 40-50% при левой молочной железе. |
| radtherapy.ops.proton_bragg_peak | Протонная терапия — Пик Брэгга | METHOD | Протонная терапия: протоны останавливают свою дозу с высокой точностью — Bragg peak. Дистальный спад за Bragg peak: нет exit dose. Преимущество: снижение дозы на ОАР позади опухоли. Spread-Out Bragg Peak (SOBP): модуляция для покрытия всего объёма. Range uncertainty: ±3.5% + 1-2 мм. Scanning (PBS): spot scanning vs passive scattering. | Протоны: наибольшая польза для опухолей у детей + в голове/шее (позади = критические ОАР). |
| radtherapy.ops.brachytherapy_hdr | Брахитерапия — протокол HDR | METHOD | Высокодозная брахитерапия (HDR): Iridium-192 (¹⁹²Ir) источник. Remote afterloading unit (Nucletron, Varian). Аппликаторы: цервикальный (tandem + ring), вагинальный цилиндр, интерстициальные иглы. Dose rate: >12 cGy/hour = HDR. Шаги: введение аппликатора → КТ/МРТ → planning → лечение → удаление. Fraction: 3-5 фракций. | HDR vs LDR: HDR = пациент амбулаторно + более контролируемая доза. |
| radtherapy.ops.dose_calculation | Расчет дозы — единицы измерения | METHOD | Расчёт монитор-единиц (MU): MU = Доза / (Коэффициент выхода × PDD × OF × Sc × Sp). Выходной коэффициент: зависит от размера поля. PDD (процентная глубинная доза): % от максимальной дозы при разной проверке. Sc (коэффициент рассеяния коллиматора), Sp (фантомное рассеяние). TPS (Система планирования лечения): Eclipse, Pinnacle — суперпозиция или Монте-Карло. Проверка MU: независимый расчет (RadCalc). | Monitor Unit = количество бит, указывающее LINAC сколько ионизировать. |
| radtherapy.ops.qa_dailyweekly | Обеспечение качества — проверки LINAC | METHOD | Контроль качества LINAC (AAPM TG-142): Ежедневно: постоянство выходного сигнала (<3%), выравнивание лазера (<2 мм), EPID, совпадение. Ежемесячно: абсолютный выход (±2%), плоскостность/симметрия, механический/радиационный изоцентр. Ежегодно: калибровка выхода по ТГ-51, энергии луча, калибровка MLC. IGRT QA: изображение кВ/МВ. Гамма-анализ: критерий прохождения 2%/2мм или 3%/3мм. | Индивидуальный контроль качества для каждого пациента: план IMRT/VMAT → гамма-прохождение измерения EPID ≥95%. |
| radtherapy.ops.radiotherapy_side_effects | Побочные эффекты RT — ведение | METHOD | Побочные эффекты лучевой терапии: Голова/шея: мукозит (WHO grade 1-4), ксеростомия, дисфагия, дерматит. Pelvis: диарея, цистит, ректит. Лёгкое: пневмонит (проявляется 6-12 нед после RT). Спинной мозг: Lhermitte's sign → миелопатия (поздняя). RTOG toxicity scale. Supportive care: mucoadhesive mouth rinses, amifostine. | Лучевой пневмонит: кортикостероиды (преднизолон 40-60 мг) + постепенное снижение. |
| radtherapy.ops.photon_beam_characteristics | Фотонный луч — выбор энергии | METHOD | Характеристики фотонного пучка: PDD curve: max dose in buildup region (dmax). dmax: 6 МВ = 1.5 см, 10 МВ = 2.5 см, 15 МВ = 3 см. Глубокие опухоли: высокая энергия (15-18 МВ). Поверхностные: 6 МВ или электроны. Skin sparing effect: отсутствие дозы на коже. Buildup region: отражает область, где нет полного электронного равновесия. | Mixed modality: фотоны для большинства + электроны для поверхностных поражений. |
| radtherapy.ops.electron_beam_energy | Электронный луч — глубинная доза | METHOD | Электронный пучок: хорошо для поверхностных поражений (кожа, послеоп. рубцы). R50 (глубина 50% дозы, см) ≈ Energy/2.5 (правило). R80 ≈ Energy/3. Эффективная лечебная глубина ≈ Energy/4. Конусы (cones/cutouts): ограничивают поле на коже. Bolus: увеличение поверхностной дозы (при дефиците buildup). | Электронная пушка дозы = 100% у Dmax, затем крутое падение (спаринг глубоких тканей). |
| radtherapy.ops.imrt_head_neck | IMRT головы и шеи — сохранение слюнных желез | METHOD | IMRT голова/шея: тройная доза (высокий риск 66-70 Гр, промежуточный 60 Гр, низкий риск 54-56 Гр). Сохранение весла: околоушная железа Dmean <26 Гр (QUANTEC) → снижение ксеростомии. Спинной мозг Dmax <45 Гр. Ствол головного мозга Dmax <54 Гр. Сопутствующий цисплатин: химическая RT. SIB (одновременное интегрированное усиление): одновременно разные дозы. | QUANTEC: Количественный анализ воздействия на нормальные ткани в клинике — стандартные дозы для ОАР. |
| radtherapy.ops.radiotherapy_breast | ЛТ молочной железы — Гипофракционирование | METHOD | ЛТ молочной железы: Стандартная: 50 Гр/25 фракций + boost. Гипофракционирование: 40 Гр/15 фракций (FAST-Forward trial, UK) = non-inferior. Canadian: 42.56 Гр/16 фракций. APBI (Accelerated Partial Breast Irradiation): только облучение ложа опухоли. Post-mastectomy: PMRT на стенке + регионарные. Heart sparing: особо важно при левостороннем. | 40Гр/15фракций: снижение длительности лечения + эквивалентная эффективность. |
| radtherapy.ops.radiosurgery_brain | SRS — Стереотаксическая радиохирургия головного мозга | METHOD | Стереотаксическая радиохирургия мозга: Гамма-нож (Leksell): 192-201 источника Co-60, изоцентр.
