| beauty.ops.facial_protocol | Лицо — протокол глубокого очищения | PROCESS | Профессиональная чистка лица. Шаги: 1) Анализ кожи (skin type — сухая/жирная/комбинированная, concerns — акне, пигментация, купероз). 2) Демакияж + очищение (мицеллярная вода + пенка/гель, спонжи). 3) Тонизация (лосьон, pH-баланс). 4) Пилинг / эксфолиация (энзимный — папаин/бромелайн для чувствительной, кислотный AHA/BHA для жирной/проблемной, механический scrub — микрочастицы жожоба для нормальной). Время воздействия: 3-10 мин в зависимости от типа. 5) Распаривание (vaporiser — озон для дезинфекции, тёплый пар 40-50°C, 5-10 мин, открывает поры, НЕ для купероза!). 6) Экстракция комедонов (уно — ложка, пальцы обёрнутые салфеткой — только если поры открыты и комендон легко выходит, не травмировать!). 7) Массаж лица (10-15 мин, lymphatic drainage, классический или по Жаке для жирной). 8) Маска (наносится кистью/шпателем, не разговаривать с клиентом пока маска на лице! — 10-20 мин). 9) Завершение — тоник, сыворотка, крем для глаз + дневной/ночной крем + SPF. | Экстракция: НЕЛЬЗЯ давить если комедон не поддаётся — травма, постакне, инфекция. Лучше оставить для следующей процедуры или порекомендовать ретиноиды. Стерильность: все инструменты дезинфицируются (Barbicide, автоклав для многоразовых), одноразовые салфетки/спонжи. |
| beauty.ops.waxing_technique | Нанесение воска — техника твердого и мягкого воска | METHOD | Депиляция воском. Soft wax (тёплый, наносится шпателем, снимается полоской ткани): для больших зон (ноги, руки, спина). Hard wax (толстый слой, застывает, снимается без полоски): для чувствительных зон (бикини, лицо, подмышки) — менее болезненно, меньше раздражения. Температура воска: 50-65°C (проверить на запястье как бутылочку для младенца). Подготовка: talc powder для впитывания влаги, pre-wax oil для защиты кожи. Нанесение: ПО направлению роста волос. Снятие: ПРОТИВ роста (одним резким движением параллельно коже, не вверх!). Натяжение кожи свободной рукой обязательно. Post-wax: успокаивающий лосьон (алоэ, бисаболол), ингибитор роста волос (медленнее отрастают). Противопоказания: ретиноиды/аккутан (accutane — истончение кожи — риск содрать эпидермис!), диабет (плохое заживление), варикоз, свежий загар, солнечные ожоги. | Направление снятия: если тянуть вверх (а не параллельно) — гематомы (синяки), разрыв капилляров. Воск не должен быть слишком горячим (ожог 2-3 степени за несколько секунд при 70°C+). |
| beauty.ops.manicure_efile_technique | Маникюр — Электронная пилка и наращивание ногтей | METHOD | Аппаратный маникюр. Фрезы: barrel/drum (цилиндрическая — для основной обработки, зачистки), ball (шар — для ногтевого валика), cone (конус — для вросшего ногтя), flame (пламя — для боковых пазух), needle (игла — для поднятия кутикулы). Абразивность (grit): coarse (синий/зелёный ремень — снятие материала), medium (красный — обработка), fine (жёлтый — финиш), extra fine (белый — полировка). Скорость: 5000-20000 об/мин. Техника: двигаться ПО направлению роста ногтя, не задерживаться на месте (ожог от трения!). Наращивание (gel/acrylic): nail preparation (баф 180 grit, дегидратор, primer). Форма (удлинение ногтевого ложа — nail form под свободный край). Гель: наносится кистью, слой за слоем, каждый слой полимеризуется в LED/UV лампе 30-60 сек. Акрил: смесь пудры (полимер) + liquid (мономер — ethyl methacrylate) на кисти, формование, застывает на воздухе за 1-2 мин. Опиливание и финишная форма. Покрытие: base → colour (2 тонких слоя, не толстый!) → top (запечатать свободный край для долговечности). | Аллергия на акриловый мономер (ММА — methyl methacrylate): запрещён для ногтей (слишком твёрдый, необратимо повреждает ноготь), но дешёвые салоны используют (резкий запах кошачьей мочи). EMA (ethyl methacrylate) — безопасен, разрешён. LED лампа (405 нм, UV-A) или UV (350 нм) — защита кожи рук клиента от фотостарения (SPF или специальные перчатки). |
| beauty.ops.lash_extensions_classic | Наращивание ресниц — классический набор аппликаций | METHOD | Наращивание ресниц. Классика (1:1 — одна искусственная ресница к одной натуральной). Объём (2D-6D — веер из 2-6 тонких ресниц на одну натуральную). Подготовка: очищение ресниц от макияжа/жира, подложка (under-eye gel pad/PU tape — защита нижних ресниц и кожи). Изоляция: tweezer'ы для отделения (один пинцет поднимает верхнее веко и отделяет одну ресницу, другой — захватывает extension). Клей (cyanoacrylate based): капля на клеевом камушке, заменять каждые 15-20 мин (загустевает). Время схватывания: 0.5-2 сек (быстросохнущий клей — опытный мастер). Длина: 6-15 мм (короче к внутреннему уголку, длиннее к внешнему). Изгиб (curl): B (слабый), C (средний — самый популярный), CC/D (сильный). Толщина: 0.03-0.07 (объём), 0.10-0.15 (классика). Размещение: 0.5-1 мм от кожи века (не касаться кожи — аллергия и раздражение!). Направление: повторять направление натуральной ресницы. Полный сет: 70-120 ресниц на глаз (60-90 мин). Инфилл (коррекция): каждые 2-3 недели (ресницы выпадают с естественным циклом). После: 24-48 часов не мочить (клей полимеризуется полностью). | Аллергия на цианакрилат: зуд, отёк век, краснота. Патч-тест (несколько ресниц, подождать 48 ч) для клиентов с history аллергии. Фумигация (пары клея — раздражение глаз): eye drops anesthetic до процедуры. |
| beauty.ops.permanent_makeup_lips | Румяна для губ — техника полуперманентного макияжа | METHOD | Татуаж губ (Lip Blush). Цель: придать цвет, скорректировать форму, создать эффект «губы без помады». Машина: rotary или coil machine, игла: 1R, 3R, 5R или nano needle. Пигмент: органический lip-specific pigment (разрешён для губ — без тяжёлых металлов, Permanent Makeup pigments должны быть compliant). Анестезия: topical (lidocaine/prilocaine крем) 20 мин, во время процедуры — спрей. Техника: контур губ (outline — обрамление, чёткая линия), затем заполнение (blushing — pixelated, микропиксели, сливаются в равномерный тон). Глубина: 0.2-0.3 мм! (губы очень тонкая кожа + слизистая, слишком глубоко = blowout/migration pigment). Проходы: 2-3 прохода для насыщенности. Herpes simplex prophylaxis (ВСЕМ клиентам — ацикловир за 48 часов до и 48 после, даже без history герпеса — процедура травмирует ткани, вирус активируется). Заживление: 5-10 дней, сильное шелушение, цвет кажется очень ярким первые дни (отец + корочка + pigment), затем светлеет на 30-50%. Touch-up через 6-8 нед. | HSV (герпес) — частая проблема после lip tattoo (даже если никогда не было симптомов — вирус может быть в dormant). Prophylaxis = MUST. Сообщать клиенту заранее (врач выписывает рецепт на валацикловир/ацикловир). |
| beauty.ops.makeup_contour_highlight | Мастерство макияжа — контур и хайлайтер | METHOD | Контуринг лица. Принцип: светлое (highlight) — «выдвигает» вперёд (centre of forehead, under eyes, bridge of nose, cupid's bow, центр подбородка). Тёмное (contour) — «отодвигает» назад (под скулами, виски, sides of nose, jawline). Формулы: cream (для сухой/нормальной кожи — более естественно, blending beauty blender), powder (жирная кожа, buildable). Face shapes: Round — contour temples, cheeks, jawline (сузить). Square — soften angles, contour jaw corners. Heart — contour temples + narrow chin. Blush placement: apples of cheeks (улыбка) для круглого лица, higher on cheekbones для oval. Highlight: верх скул (над contour), brow bone, inner corner eyes, cupid's bow. Brows: mapped (начало — вертикаль от крыла носа, арка — линия от крыла носа через зрачок, конец — от крыла носа через внешний угол глаза). Продукты: foundation primer (увлажняющий vs матирующий), colour corrector (зелёный — краснота, персиковый — синяки/пигментация для medium skin), concealer (на 1-2 тона светлее основы), setting powder (translucent), setting spray (matte или dewy). Инструменты: brushes (synthetic для cream/liquid, natural hair для powder), Beauty Blender (влажный!). Кисти держатся за ferrule (металлический обжим), моются мягким мылом еженедельно. | Мейкап-артист должен работать с разными skin tones (от very fair до deep dark). Практика на diverse portfolio. Санитария: кисти дезинфицируются между клиентами (спрей 70% спирт), одноразовые аппликаторы для туши, pomades в отдельные контейнеры (не double-dip). |
| beauty.ops.pedicure_medical_grade | Педикюр — протокол медицинского уровня | METHOD | Медицинский педикюр (отличается от салонного — работа с проблемной стопой, без замачивания в общей ванне). Waterless (сухой — spray дезинфектант вместо ванны — гигиеничнее, нет cross-contamination). Обработка: 1) осмотр стоп (грибок, вросший ноготь, сухие мозоли, трещины на пятках), 2) обработка ногтей (пилка, не закруглять в мясо углов на больших пальцах — вросший ноготь!), 3) удаление кутикулы (размягчитель, push back, обрезание размягчённой кутикулы — только мёртвой), 4) обработка стопы (скальпель-лезвие №10 для снятия гиперкератоза — омозолелости, аккуратно, слоями, до розового), 5) шлифовка пилочкой/фрезой. Не срезать мозоли полностью (оставить тонкий слой — защитная функция). Трещины: склеивание медицинским клеем (cyanoacrylate) если глубокие. Массаж стоп (5-10 мин). Покрытие: медицинский лак (лечебный — с климбазолом, маслом чайного дерева). Стерилизация: ВСЕ инструменты должны проходить автоклавирование (не просто Barbicide! — ножная ванна с дезинфекцией после каждого клиента недостаточна для Pedicure). | Грибок: не лечится маникюрными инструментами. Referral к подологу/дерматологу. При диабетической стопе — очень осторожно с режущими инструментами (микротравма = язва = гангрена). Только шлифовка без лезвий. |
