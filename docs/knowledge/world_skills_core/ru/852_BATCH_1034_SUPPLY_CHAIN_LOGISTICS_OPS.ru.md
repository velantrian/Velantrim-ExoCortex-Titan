| supplychain.ops.demand_forecasting | Прогнозирование спроса — методы | METHOD | Методы прогнозирования спроса: Наивный (последний период). Moving Average (SMA): сглаживание краткосрочных колебаний. Exponential Smoothing (SES, DES): α-весовой. Holt-Winters: тренд + сезонность. ARIMA: временные ряды. Machine Learning (XGBoost, LSTM). MAPE (Mean Absolute Percentage Error): метрика точности. Bias: систематическая ошибка (forecast > actual = over-forecast). | Распространение ошибок прогноза: усиление в нисходящем направлении (эффект кнута). |
| supplychain.ops.eoq_reorder | EOQ — экономичный объем заказа | METHOD | Оптимальный размер заказа (EOQ): Q* = √(2DS/H). D = годовой спрос, S = стоимость заказа, H = стоимость хранения. Общая стоимость = DS/Q + QH/2. Точка повторного заказа (ROP) = d × LT + страховой запас. Страховой запас = z × σ(долгосрочный спрос). z: уровень обслуживания (95% = 1,645). | EOQ предполагает постоянный спрос и lead time — в реальности использовать как baseline. |
| supplychain.ops.supplier_selection | Выбор поставщика — критерии | METHOD | Критерии выбора поставщика: Качество (PPM — доля дефектов на миллион), Доставка (OTIF — On Time In Full%), Стоимость (общая стоимость владения, TCO), Финансовая стабильность (рейтинг D&B), Мощность (запас), Инновации, Устойчивое развитие (показатель ESG), Соответствие требованиям (REACH, конфликтные минералы). Система показателей: средневзвешенное значение. | Единый или двойной источник: один = экономия, двойной = снижение рисков. |
| supplychain.ops.incoterms_2020 | Инкотермс 2020 — Передача риска | METHOD | Инкотермс 2020: стандартные условия поставки. EXW (Ex Works): риск покупателя с ворот продавца. FCA (Free Carrier): риск передаётся при передаче перевозчику. FOB (Free On Board): риск при погрузке на судно. CIF (Cost, Insurance, Freight): продавец = фрахт + страхование до порта назначения. DDP (Delivered Duty Paid): продавец несёт все расходы до места назначения. | DDP самый «удобный» для покупателя, самый дорогой. EXW = наименьшая ответственность продавца. |
| supplychain.ops.wms_picking_strategies | WMS — стратегии выбора | METHOD | Стратегии комплектации в WMS (Warehouse Management System): Discrete picking (один заказ за раз). Batch picking: несколько заказов одновременно (снижает travel). Zone picking: operator в зоне. Wave picking: несколько заказов волнами по расписанию. Cluster picking: несколько sku в тележку. Put-to-light, pick-to-light: световые индикаторы (ошибок меньше). | Оптимизация слоттинга: быстрые ходы к выдаче (ABC-анализ). |
| supplychain.ops.abc_xyz_analysis | Инвентаризация — анализ ABC/XYZ | METHOD | ABC-анализ: A = 20% SKU = 80% стоимости. B = 30% SKU = 15%. C = 50% SKU = 5%. XYZ: X = стабильный спрос, Y = сезонный, Z = нерегулярный. Матрица AX, AY, AZ → различные стратегии управления запасами. AX: EOQ, min/max. CZ: on-demand ordering. | ABC inventory counting: A = ежеквартально, B = полугодие, C = ежегодно. |
| supplychain.ops.ltl_ftl_shipping | Грузовые перевозки — LTL против FTL | METHOD | LTL (Less-than-Truckload): консолидация грузов от нескольких отправителей. Freight class (NMFC): 50-500 (по density, stowability, handling, liability). FTL (Full Truckload): полная загрузка одного грузовика. Рейтинги: spot rate (рыночная) vs contract rate. Lane analysis: специфический маршрут. Load board (DAT, uShip): поиск перевозчика. | LTL: медленнее (hub-and-spoke), больше handling = больше повреждений vs FTL. |
| supplychain.ops.customs_clearance | Таможенное оформление — Коды HTS | METHOD | Таможенная очистка: HTS (Harmonized Tariff Schedule) код = 10-значный (USA). HS code (международный) = первые 6 знаков. Импортные пошлины зависят от HTS кода + COO (Country of Origin). Free Trade Agreements (USMCA, EU FTA): снижение/нулевые пошлины при COO compliance. Customs Broker: лицензированный посредник. | Неправильный HTS код: штраф + задержка + пересчёт пошлин. |
| supplychain.ops.risk_supply_chain | Риск цепочки поставок — картирование | METHOD | Картирование риска цепочки поставок: уровень 1 (прямые поставщики), уровень 2 (их поставщики). Рисков: геополитика (тарифы), стихийное бедствие, банкротство поставщика, единый источник, концентрация (80%+ от одного региона). План непрерывности бизнеса (BCP): двойной источник, буферы запасов. | COVID-19: выявил концентрированные риски (Китай = 30%+ глобального производства). |
| supplychain.ops.reverse_logistics | Обратная логистика — Управление возвратами | METHOD | Обратная логистика: политика возврата, RMA (разрешение на возврат товара). | supplychain.ops.lean_kaizen | Бережливое производство — Кайдзен События | METHOD | Кайдзен (непрерывное совершенствование): короткая интенсивная сессия (3-5 дней).
