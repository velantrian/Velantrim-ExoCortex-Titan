# BATCH 993: Painting — Interior Professional Techniques

**KnowledgeUnits:** 5
**Namespace:** `paintpro.ops.*`
**Scope:** roller, cut_in, brush, prep, primer, ceiling, trim, color_matching, airless_spray

| ID | KnowledgeUnit | Тип | Суть | Практический смысл |
|---|---|---|---|---|
| paintpro.ops.roller_cover_selection | Покрытие валика — ворс и текстура | METHOD | Выбор валика на поверхности. Ворс (ворс): 6 мм (гладкая поверхность — гипсокартон, двери), 10-12 мм (легкая текстура — гладкая штукатурка), 15-20 мм (средняя текстура — акустический потолок, грубая штукатурка), 25+ мм (кирпич, кладка). Материал чехла: полиэстер (латекс/акрил — любой), барашек (масло), микрофибра (все). Роликовая рама: 9" (универсальный), 4" (обшивка, молдинг). Загрузка: лоток для краски — валик в краску, раскатать излишки на ребристой части. Не перенасыщать (капает). | Дешёвый cover: shed fibers (lint в покраске). |
| paintpro.ops.cutting_in_brush_technique | Врезка — техника кисти | METHOD | Прирезка кистью вдоль потолка/плинтусов. Кисть: 2"-2.5" angular brush (sash brush). Загрузка: 2/3 длины щетины в краску, снять с одной стороны. Держать кисть: как карандаш (light grip). Техника: немного отступить от линии, затем аккуратный проход вдоль линии, полосы 15-20 см. Keep wet edge (не давать предыдущему штриху засохнуть перед продолжением). Затирка: финальный lightly loaded stroke «feather the edge». | Сухой раскат в разрез за 5-10 мин (мокрый край для бесшовного). |
| paintpro.ops.airless_spray_tips | Безвоздушное распыление — выбор насадки | METHOD | Выбор форсунки для airless спрея. Tip code (e.g., 515): первые цифры × 2 = fan width (10"), последние 2 = orifice in thousands of inch (0.015"). Fan width: 25 см (малые площади), 30 см (средние), 40+ (потолки, большие стены). Orifice: 0.011-0.013 (lacquers, enamels), 0.015-0.017 (latex walls), 0.019-0.021 (elastomeric, texture). Pressure: увеличивать пока atomization не ровный (min pressure for good spray). Скорость: 30-40 см/сек. Расстояние: 30-45 см. Перекрытие: 50%. | Насадки Graco: двусторонние (Reverse-A-Clean, SwitchTip) для очистки и прочистки. |
| paintpro.ops.surface_preparation_patching | Подготовка поверхности — шпаклевка и обезжиривание | METHOD | Подготовка стен. Spackle: нанести шпателем в ямки/гвозди/кольца (dry 30-60 мин). Sand 120 grit, prime (PVA primer для porous repairs). Skim coat: тонкий слой joint compound по всей стене (для скрытия текстуры imperfections). Allow dry, sand 180, prime. Gloss paint: требует идеальной поверхности (любой изъян виден). Flat/eggshell: прощает поверхность. De-gloss: старая глянцевая поверхность — TSP wash или liquid de-glosser (лучше адгезия). | без грунтовки после шпаклевки: разница блеска (вариация всасывания). |
| paintpro.ops.paint_failure_causes | Отказ краски — анализ причин | METHOD | Причины отслоения краски. Peeling (отслоение): влажность в стене (bathroom, gutter leak), поверх глянца без de-gloss, поверх грязи. Alligatoring (трещины «крокодил»): толстый слой oil over latex, несовместимые слои. Lap marks: краска начала сухнуть перед roll-over. Runs/drips: overloading brush/roller или слишком thick coat. Mildew (плесень): недостаточная вентиляция, нет mildew-resistant paint. Решение: remove cause, strip, prime, repaint. | Масло поверх масла = ок. Латекс поверх масла = хорошо, если отшлифовать. Масло поверх латекса = пилинг. |
