| molbio.ops.restriction_cloning | Ограничивающее клонирование — методы | METHOD | Рестрикционное клонирование: рестриктаза разрезает ДНК по специфической последовательности → Insert + Vector с совместимыми концами → лигирование (T4 ДНК-лигаза). | molbio.ops.crispr_cas9 | CRISPR-Cas9 — Механизм | METHOD | CRISPR-Cas9: sgRNA (направляющая) → нуклеаза Cas9 → NGG PAM по продолжительности. Стратегия шлюзования: разброс → синглеты (устранение дублетов) → исключение живых/мертвых → интересующая популяция. Компенсация: коррекция спектрального перекрытия. Nested PCR: два последовательных ПЦР (inner primers → повышение специфичности). Hot-Start PCR: антитела ингибируют полимеразу до нагрева (снижение неспецифических продуктов). Digital PCR (ddPCR): абсолютная количественная оценка (капли). | LAMP (Loop-Mediated Amplification): изотермальная → не нужен термоциклер. |

| molbio.ops.cell_culture_aseptic | Клеточная культура — асептическая техника | METHOD | Клеточная культура: асептика в BSC (Grade A). Медицинская среда с сывороткой (DMEM, RPMI + 10% FBS). Субкультивирование (passaging): трипсинизация при ~80% конфлюентности. Seeding density: зависит от типа клеток. Mycoplasma testing: PCR или ELISA ежемесячно. Длина прочтения: 800-1000 нт. Применение: точечные мутации, клонов проверка. NGS: параллельное секвенирование миллиардов фрагментов. | Конструкция праймера: Tm 55–65°C, без шпилек/димеров (Primer3, олигоанализатор IDT). |

SDS-PAGE анализ: проверка выражения. | Проверка растворимости: пробная индукция при различных температурах + концентрация IPTG. |
| molbio.ops.co_immunoprecipitation | Co-IP — белок-белковое взаимодействие | METHOD | Ко-иммунопреципитация (Co-IP): лизат клеток + первичное антитело к белку A → инкубация с Protein A/G beads → отмывка → SDS-PAGE + Western Blot для обнаружения белка B. Скрининг библиотеки кДНК: поиск партнёров. Ложноположительные результаты: липкие белки (высокий фон). Требуется проверка: Co-IP или BiFC.
