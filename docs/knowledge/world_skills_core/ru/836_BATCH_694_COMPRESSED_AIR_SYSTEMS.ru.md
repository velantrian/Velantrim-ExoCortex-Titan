# BATCH 694: Compressed Air — System Design & Piping

**KnowledgeUnits:** 5
**Namespace:** `compair.ops.*`
**Scope:** compressor, dryer, filter, piping, loop, receiver, condensate, air_leak

| ID | KnowledgeUnit | Тип | Суть | Практический смысл |
|---|---|---|---|---|
| compair.ops.pipe_loop_ring_main | Труба — Петля/Кольцо Магистральная | METHOD | Проектирование магистрали сжатого воздуха. Ring main (закольцованная): обеспечивает равномерное давление, redundancy. Уклон: труба идёт с уклоном по потоку (1-2 см/м) для condensate removal. Drop legs: отводы вниз (не вверх — конденсат попадает в инструмент!). Drain valve: в нижней точке каждого drop leg. Материал: aluminium (гладкая внутрь, нет ржавчины), copper, stainless. Black iron: традиционный но ржавеет (contamination). Диаметр: по расходу (скорость <5-10 м/с). | Ржавчина из iron pipe забивает пневмоинструмент. |
| compair.ops.leak_detection_ultrasonic | Обнаружение утечек — ультразвуковое | METHOD | Поиск утечек сжатого воздуха. Ultrasonic leak detector (UE Systems): чувствителен к звуку турбулентности в диапазоне 40 кГц. Наушники + directional microphone. Обход всех соединений/фиттингов/шлангов. Tag: маркировка утечек (красный tag). Расчёт потерь: 1 мм отверстие при 7 бар = ~2 кВт потерь (значительные деньги). Fix: затянуть fitting, заменить seal. Проводить leak survey раз в квартал. | 20-30% сжатого воздуха теряется через утечки (типичный завод). |
| compair.ops.air_receiver_tank_sizing | Воздушный ресивер — определение размеров и дренаж | METHOD | Расчёт ресивера. Receiver tank: сглаживает пульсации, хранит запас. Объём: 20-30 литров на каждый м³/мин производительности компрессора (для винтового). Pressure vessel: ASME certified, safety valve (set pressure, ежегодный тест). Drain: auto drain (таймерный или level-sensing). Condensate: масло-вода (oil-water separator требуется для экологии). Location: после dryer (сухой воздух). | Мокрый воздух в tank = ржавчина. |
| compair.ops.filter_coalescing_particulate | Фильтр — коалесцирующий и сажевый | METHOD | Очистка сжатым воздухом. Сажевый фильтр (5 мкм → 1 мкм): механическое разделение, общего назначения. Коалесцирующий фильтр (0,01 мкм): удаляющий масляный аэрозоль и воду (для инструментов, распылителей краски). Фильтр с активированным углем: удаляет пары масла (для воздуха для дыхания, пищевых продуктов). Манометр дифференциального давления: индикатор замены элемента (когда ΔP увеличивается ~0,4 бар — менять). Установка: сажевая → коалесцирующая → углеродная (порядку!). Автоматический слив каждого фильтра. | Без coalescing: масло в пневмоинструменте (выход масла из глушителя). |
| compair.ops.dryer_refrigerated_desiccant | Сушилка — охлаждаемая или осушающая | METHOD | Осушка сжатого воздуха. Refrigerated: охлаждает воздух до +3°C (PDP — Pressure Dew Point), конденсат отделяется. Достаточно для 90% применений. Desiccant: силикагель/активированный оксид алюминия, PDP −40°C (для outdoor, критичных процессов). Heatless regen (продувка сухим воздухом), heated regen. Расход на регенерацию: 5-15% от total flow. | Refrigerated дешевле, desiccant для специальных. |
