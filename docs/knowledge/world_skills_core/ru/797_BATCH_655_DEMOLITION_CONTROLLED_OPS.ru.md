# BATCH 655: Demolition — Controlled Building Takedown

**KnowledgeUnits:** 5
**Namespace:** `demolition.ops.*`
**Scope:** survey, asbestos_abatement, soft_strip, implosion, high_reach, crushing, recycling, dust_control, safety

| ID | KnowledgeUnit | Тип | Суть | Практический смысл |
|---|---|---|---|---|
| demolition.ops.pre_demo_survey_hazmat | Предварительный демонстрационный опрос — Оценка опасности | METHOD | Обследование здания перед сносом. Asbestos survey: bulk sampling (потолочная плитка, изоляция труб, напольная плитка, текстура), NVLAP accredited lab. Lead paint: XRF анализатор (для зданий до 1978). PCBs (полихлорбифенилы): ballasts fluorescent, caulking, трансформаторы. Mercury: термостаты, выключатели. Universal waste: батарейки, лампы. Underground tanks: если на участке — удалить. Sewer/water line capping: disconnect before demo. Отчёт: hazmat inventory с рекомендациями по abatement. | Без обследования: снос незаконен (Закон о чистом воздухе, RCRA). |
| demolition.ops.soft_strip_interior | Мягкая полоса — внутренняя потрошка | PROCESS | Ручная разборка интерьера до сноса. Цель: удалить всё что не конструкция (гипсокартон, полы, потолки, двери, окна, сантехника, проводка, HVAC). Сортировка материалов для recycling: металл (сталь, медь, алюминий), дерево, бетон, гипс. Deconstruction (разборка для reuse): двери, окна, сантехника, hardwood floors. Ручной инструмент: sawzall, pry bar, sledgehammer. Mechanical: skid steer с grapple. Безопасность: падающие предметы, битое стекло, гвозди, открытая проводка (electricity cut off!). | Асбестовый монтаж делается до мягкой полосы (в комплекте). |
| demolition.ops.high_reach_excavator | Большой вылет — метод экскаватора | METHOD | Снос высотным экскаватором (Ultra-High Reach). Для зданий 5-25 этажей. Машина: 50-100 тонн, boom 30-50 м. Attachments: shear (гидравлические ножницы), pulveriser (дробилка), hammer (гидромолот), grapple, bucket. Техника: top-down (сверху вниз), методичная разборка этаж за этажом. Смачивание: water spray (dust suppression) из шланга на attachment. Debris: падает внутрь footprint здания (защита соседних). Spotter: направляет оператора (радио). | Близость соседних зданий: высокая точность (опытный оператор). |
| demolition.ops.implosion_sequence | Имплозия — последовательность и заряды | METHOD | Взрывной снос (шахматный порядок). Подготовка: structural analysis (слабые места для controlled collapse), удаление не-несущих элементов, test blast. Взрывчатка: dynamite/RDX размещается в шпурах (бурение в колоннах/балках). Detonators: электронные с задержкой (миллисекунды). Последовательность: сначала центральная часть, затем периметр (collapse внутрь footprint). Зона безопасности: эвакуация (radius 150-300 м), vibration monitoring (сейсмические датчики на соседних зданиях). Dust cloud: water cannon (пожарные гидранты). Post-blast inspection. | Имплозия: сложный engineering, делается специализированными компаниями. |
| demolition.ops.concrete_crushing_recycle | Дробление бетона — переработка на месте | METHOD | Переработка бетона на месте. Crusher: jaw crusher (щековая дробилка) → бетонные обломки дробятся до щебня. Магнитная сепарация: извлечение арматуры (сталь на переплавку). Продукт: aggregate (щебень) разных фракций (0-40 мм для fill, 40-100 для drainage). Тест: анализ на contaminants (heavy metals, oil). Use: sub-base для новой дороги/парковки, fill. Стоимость: часто дешевле вывоза (tipping fee vs recycled aggregate продажа). | Асфальт: отдельно продается на асфальтовый завод (RAP — Reclaimed Asphalt Pavement). |
