| microbiolab.ops.gram_stain_procedure | Окраска по Граму — шаг за шагом | METHOD | Окраска Грама: 1) Crystal violet 30-60 сек. 2) Iodine (mordant) 1 мин. 3) Acetone-alcohol (decolorizer) 10-15 сек (critical!). 4) Safranin 30-60 сек. Gram+ (фиолетовые): PG (peptidoglycan) толстый слой удерживает кристаллвиолетовый. Gram- (красные): тонкий PG + наружная мембрана → теряет при обесцвечивании. | Пересветленный: все Gram- (слишком много decolorizer). Недосветленный: все Gram+ (мало). |
| microbiolab.ops.culture_media_selective | Культурные медиа — типы | METHOD | Типы питательных сред: Базальные (Nutrient Agar/Broth): для общего роста. Обогащённые (Blood Agar, Chocolate Agar): для прихотливых организмов (Strep, H. influenzae). Селективные: MAC (MacConkey): Gram- только; Phenylethyl Alcohol (PEA): Gram+ только. Дифференциальные: MAC — лактозоферментирующие (розовые) vs non-fermenting (бесцветные). TCBS: V. cholerae. | Скрининг MRSA: Chromagar MRSA (хромогенная среда). |
| microbiolab.ops.antibiogram_mic | Чувствительность к антибиотикам — MIC | METHOD | Минимальная ингибирующая концентрация (MIC): наименьшая концентрация антибиотика, подавляющая видимый рост. Методы: Broth Microdilution (стандарт), Disk Diffusion (Kirby-Bauer), Etest (gradient strip). CLSI/EUCAST breakpoints: S (чувствительный), I (intermediate), R (resistant). MBC (Minimum Bactericidal Concentration). | Ванкомицин: МПК ≥2 мкг/мл = устойчивый к ванкомицину S. aureus (не MRSA). |
| microbiolab.ops.pcr_amplification | ПЦР — этапы метода | METHOD | Полимеразная цепная реакция (PCR): 1) Денатурация: 94-98°C (30 сек). 2) Отжиг праймеров: 50-65°C (30-60 сек). 3) Элонгация: 72°C (1 мин/кб). Циклы: 25-35. Термоциклер. dNTPs, праймеры, Taq полимераза, template DNA. Real-time PCR (qPCR): SYBR Green или TaqMan probe — количественный. Melting curve: проверка специфичности. | Ложноположительный: контаминация amplicon. Clean room design: разделить pre/post PCR areas. |
| microbiolab.ops.bsl2_bsl3_safety | Биобезопасность — уровни BSL | METHOD | Уровни биологической безопасности (BSL): BSL-1: не патогенные для здоровых людей (E. coli K12). BSL-2: умеренно опасные (S. aureus, Salmonella, HIV — работа в вытяжном шкафу, перчатки). BSL-3: серьёзная угроза по воздуху (Mycobacterium tuberculosis, West Nile virus — отрицательное давление, PAPR). BSL-4: смертоносные без лечения (Ebola, Marburg). | HEPA filter: блокирует 99.97% частиц ≥0.3 мкм (BSL-2 кабинеты, BSL-3 rooms). |
| microbiolab.ops.autoclave_sterilization | Автоклав — Валидация | METHOD | Стерилизация паром под давлением: 121°C, 15 psi, 15-20 мин (стандартный цикл). Показатели валидности: Chemical indicator (Class 4-6) цвет. Биологические: Geobacillus stearothermophilus спориls — inactivated при правильном цикле (еженедельный). Physical parameters: датчики давления/температуры. Dry goods (100 г glass): 40-60 мин (heat penetration). | Мешки для отходов не закрывать герметично (пар не проникает). |
| microbiolab.ops.aseptic_technique | Асептическая техника — Стандарт | METHOD | Асептика: минимизировать контаминацию при работе с культурами. Flame (flaming): петля или стеклянная пипетка (spore-former → красный/белый). BSC (Biological Safety Cabinet): ламинарный поток защищает продукт и оператора. Открывать сосуды коротко и под углом (не к вентиляции). PPE: перчатки, халат. Работать лицом к кабинету (не спиной). | Near-flame technique (open flame на bench): допустима для Gram-отрицательных (не спорообразующих). |
| microbiolab.ops.food_micro_enumeration | Пищевая микробиология — подсчет колоний | METHOD | Подсчёт колоний: серийные разведения (1:10 каждое). Посев: spread plate (100 мкл) или pour plate (1 мл + расплавленный агар). Инкубация: 37°C 24-48 ч (мезофилы) или 20-22°C 72 ч (психрофилы). Подсчёт: 30-300 КОЕ (Colony Forming Units)/пластинка. Результат: CFU/г = colonies × dilution factor. AOAC методы. | <10 CFU/г vs >10⁶ CFU/г: граница безопасности/порчи. |
| microbiolab.ops.mrsa_identification | MRSA — Лабораторная идентификация | METHOD | Идентификация MRSA: культура → S. aureus (трубчатая коагулаза CAP, ДНКаза). Мектицинорезистентность: оксациллин (≥4 мкг/мл = резистентный) или цефокситиновый диск (≤19 мм = R). Цефеид GeneXpert: ПЦР на гены mecA + SCCmec. Хромагар MRSA. Ген mecA: золотой стандарт ПЦР. | Деколонизация MRSA: назальный мупироцин + хлоргексидин для мытья тела (протокол). |
| microbiolab.ops.molecular_typing | Молекулярное типирование — WGS против PFGE | METHOD | Типирование изолятов: PFGE (Гель-электрофорез в импульсном поле): «золотой стандарт» ранее. Дайджест ограничений → шаблон. MLST (мультилокусное типирование последовательностей): 7 генов домашнего хозяйства → Тип последовательности. WGS (полное секвенирование генома): становится точнее, быстрее. Расстояние SNP: SNP/Мбит/с для кластеров вспышки. cgMLST (основной геном). | PFGE: занимает 3-4 дня. WGS: 24-48 часов (на быстрых секвенаторах). |
| microbiolab.ops.beta_lactamase_test | Бета-лактамазы — экспресс-тест | METHOD | Быстрый тест на бета-лактамазу: Nitrocefin (цветная ценоксалин цефалоспорин): при гидролизе меняет цвет с жёлтого на красный (30 сек-5 мин). Microtitre plate или disk. Важно: Haemophilus influenzae, N. gonorrhoeae, S. aureus. ESBL (Extended-Spectrum Beta-Lactamase): комбинированный диск тест (ceftazidime ± clavulanate). | AmpC Beta-Lactamase: не выявляется обычным Nitrocefin, требует специального теста. |
| microbiolab.ops.catalase_oxidase_tests | Тесты на каталазу и оксидазу | METHOD | Быстрые биохимические тесты: Каталаза: каплю H2O2 на колонию → пузырьки = Catalase+. Staphylococcus (каталаза+) vs Streptococcus (каталаза-). Оксидаза (Kovacs): фильтровальная бумага + 1% DMPP → фиолетовый = оксидаза+. Pseudomonas/Neisseria (оксидаза+) vs Enterobacteriaceae (оксидаза-). Коагулаза: S. aureus (коагулаза+). | Staphylococcus aureus против epidermidis: коагулаза+ против коагулазы-. |
| microbiolab.ops.streak_plate_quadrant | Полосовая пластина — квадрантный метод | METHOD | Метод квадрантного посева для изолятов: квадрант 1 (первичный посев, много материала). Flaming. Квадрант 2 (2-3 черты от Q1). Flaming. Q3 (от Q2). Flaming. Q4 (от Q3 → отдельные колонии). Incubation. Цель: получить изолированные колонии из смешанной культуры. Альтернатива: тройной посев. | Isolation: для чистой культуры перед идентификацией. |
| microbiolab.ops.blood_culture_protocol | Культура крови — время и объем | METHOD | Гемокультура: объём крови критичен — 10 мл/флакон (взрослые), 1-3 мл (дети). Два комплекта (аэроб + анаэроб): перед антибиотиком. Забор: 2-3 венепункции из разных мест (не из катетера). Интервал: одновременно или в течение 1 часа (при сепсисе немедленно). BACTEC/Virtuо: автоматические инкубаторы. Time to positivity (TTP): ранний = S. aureus (2-4 ч). | 3 комплекта за 24 ч: обнаружение 95%+ бактериемии. |
| microbiolab.ops.sensitivity_specificity_test | Тестовая диагностика — расчет PPV | METHOD | Диагностическая эффективность микробиологического теста: при низкой prevalence: PPV снижается (много ложноположительных). Пример: чувствительность 99%, специфичность 99%, prevalence 1% → PPV = только 50%! Likelihood ratio positive (LR+): Se / (1 - Sp). Pre-test probability → post-test probability (Bayes). | Подтверждающий тест для скрининга с низкой prevalence: обязателен. |
| microbiolab.ops.mold_identification | Плесень — микроскопическая идентификация | METHOD | Идентификация плесени: Лактофеноловый хлопок синий (LPCB): окраска без нагрева. Микропрепараты: подготовка скотча. Морфология конидий: Aspergillus (конидиальные головки круглые, столбчатые), Penicillium (щетковидные), Fusarium (веретеновидные макроконидии), Mucor/Rhizopus (спорангии). Скорость роста. Цвет по CMA/SDA. | Fusarium: важная причина keratitis у пользователей контактных линз (Renu outbreak 2006). |
| microbiolab.ops.urinalysis_interpretation | Анализ мочи — микроскопия | METHOD | Мочевой осадок: центрифугирование 10 мин → осадок. Нейтрофилы (WBC): >5/HPF = пиурия (инфекция). Бактерии: >5 pallets в brightfield при несвежей моче = UTI. RBCs: >5/HPF = гематурия. Цилиндры: wax casts (хроническая болезнь), granular (АТN). Crystals: uric acid, oxalate. Triple phosphate (struvite): инфекция urea-splitting organisms (Proteus). | Чистый образец мочи: suprapubic или midstream clean-catch (не катетер при рутинных). |
| microbiolab.ops.biofilm_formation | Биопленка — методы обнаружения | METHOD | Биоплёнка (Биопленка): прикрепление к поверхности → матрица (экзополисахарид). Детекция: Конго Красный агар (черные колонии = продуцент биопленок, стафилококк). Анализ кристаллического фиолетового: кристалл-фиолетовый связывается с биопленкой → спектрофотометр. Чувство кворума: молекулы N-ацил-гомосерин-лактона (AHL). Биопленка на катетерах: MRSA, Staphylococcus epidermidis, Candida. | Biofilm + антибиотик: минимум в 100-1000× больше MIC для penetration. |
| microbiolab.ops.maldi_tof_id | MALDI-TOF — Rapid ID | METHOD | MALDI-TOF MS (Matrix-Assisted Laser Desorption/Ionization Time-of-Flight): масс-спектрометрия для идентификации микроорганизмов. Протокол: снять колонию → нанести на target plate → матрица (CHCA) → лазер → уникальный ribosomal protein profile. Результат: 1-2 мин. Accuracy: 95%+ для бактерий.
