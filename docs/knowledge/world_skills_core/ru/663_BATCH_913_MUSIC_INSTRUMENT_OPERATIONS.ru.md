| musicinst.ops.guitar_setup_full | Электрогитара — полная настройка и интонация | METHOD | Полная настройка электрогитары. 1) Truss rod (анкер): измерить relief (прогиб грифа) — каподастр на 1-м ладу, прижать струну на 14-17 ладу, измерить зазор на 7-8 ладу щупом (0.2-0.3 мм для электрогитары, 0.25-0.5 мм для баса). Поворот анкерного ключа: по часовой — уменьшить relief (гриф ровнее), против — увеличить (больше прогиба). Не более 1/4 оборота за раз, подождать 10-15 мин для settle. 2) Action (высота струн над 12-м ладом): регулировка bridge saddles (низкая сторона 1.5-1.8 мм, высокая 1.2-1.5 мм для E-standard). 3) Intonation (интонация — длина струны): harmonic на 12-м ладу должен точно совпадать с зажатым 12-м ладом. Если зажатый выше/ниже — сдвинуть saddle (выше = удлинить струну, saddle назад; ниже = укоротить, saddle вперёд). 4) Pickup height: слишком близко к струнам — магнитное поле тянет струну (wolf tones), слишком далеко — слабый сигнал. Стандарт: 2.4 мм для низкой E, 2.0 мм для высокой e (при зажатом последнем ладу). 5) Nut (верхний порожек): прорези должны быть правильно вырезаны — слишком высоко = трудные первые лады (sharp notes), слишком низко = дребезг открытых струн. Файлы для пазов (0.010-0.056"). | Струны после настройки грифу дают settle минимум 30 мин. Замена струн другого калибра = новая полная настройка (натяжение меняется, всё плывёт). Интонация критична для записи (даже слегка расстроенная гитара на 12-м ладу звучит фальшиво в аккордах). |
| musicinst.ops.acoustic_bridge_repair | Акустическая гитара — переклейка бриджа | METHOD | Ремонт отклеившегося бриджа (струнодержателя) на акустической гитаре. Признак проблемы: поднятие задней кромки бриджа, видимый зазор между бриджем и декой. Процесс: 1) полное снятие струн, 2) защита деки вокруг бриджа от нагрева (термоизоляция картоном), 3) нагрев бриджа (специальная грелка/лампа, 60-80°C для размягчения старого клея), 4) осторожное отделение бриджа (тонкий шпатель, НЕ поддевать — расколется дека!), 5) зачистка старого клея с бриджа и деки до голого дерева (sandpaper, осторожно — не изменить геометрию), 6) подгонка: бридж должен плотно прилегать по всей площади без качания. Выравнивание: положение критично для интонации! (измеряется расстояние от 12-го лада до центра отверстия под бриджем = ровно масштаб/2 + compensation). 7) Склеивание: hot hide glue (мездровый клей — традиционный, обратимый, прочный) или Titebond Original (алифатическая смола — необратимая). Струбцины через специальные cauls (колодки) внутри и снаружи корпуса. Давление: через специальный long-reach clamp с доступом внутрь через звуковое отверстие. Выдержка 24 часа. | Hide glue: приготавливается на водяной бане (140-145°F/60-63°C), консистенция thin honey. Преимущества: обратим (будущий ремонт возможен), стеклование (твёрдый, не dempa вибрации), заполняет зазоры. Но: короткое working time (30-60 сек), нужна температура 20°C+ в мастерской. |
| musicinst.ops.violin_soundpost_setting | Скрипка — регулировка звукового поста | METHOD | Установка и регулировка душки (soundpost) — цилиндрического стержня между верхней и нижней деками. Функция: акустическая — передача вибрации от верхней деки к нижней; структурная — противостоит давлению подставки. Положение: стандартно на 2-3 мм за правой ножкой подставки (bridge) и на 5-7 мм внутрь от неё. Перемещение: ближе к подставке = ярче/громче, но резче; дальше = мягче/теплее. Наружу от центра = больше баса, ближе к центру = больше высоких. Инструмент: soundpost setter (S-образный стальной инструмент с острыми концами — протыкает душку для манипуляции через f-отверстие). Установка: душка вставляется через f-отверстие, ставится вертикально. Проверка: душка должна стоять точно вертикально, плотно прилегать торцевыми срезами к декам (угол среза повторяет наклон свода деки — важно!). Без струн: душка не должна падать (небольшое натяжение трения). | Без душки или упавшая душка: НЕМЕДЛЕННО ослабить струны! Давление подставки без поддержки душки может продавить/треснуть верхнюю деку. Душка делается из ели (резонансной), grain вдоль оси (перпендикулярно grain деки для передачи вибрации). |
| musicinst.ops.piano_tuning_temperament | Настройка фортепиано — Равная темперация | METHOD | Настройка фортепиано по равномерно темперированному строю. Основная октава (A4 = 440 Гц, камертон). Октавы: без биений (beats — пульсации затихают до нуля в соотношении 2:1 для A3-A4). Квинты: narrow (чуть уже чем чистые — с биением примерно 0.5-1 Гц в среднем регистре). Кварты: wide (чуть шире чем чистые — аналогичное биение). Терции: всё быстрее биются по мере подъёма по клавиатуре (C4-E4 = 4-6 Гц, C6-E6 = 20+ Гц). Tuning hammer: square tip на tuning pin (kolok). Техника: impact technique (короткий рывок, крутильный момент передаётся на pin, струна натягивается, pin застревает в деревянной втулке pinblock благодаря трению). Pin должен быть установлен stable (без обратного скручивания). Two strings (unisons): правый хор (на 3-струнных унисонах — по одному, явственно слышно биения между струнами одного хора; настроить чисто = ноль биений). Темперация: можно использовать электронный тюнер (ETD — TuneLab, Verituner, Cybertuner), но мастер должен слышать биения и подтверждать ухом. | Pinblock (вирбельбанк): многослойный клён, удерживающий колки. При износе pinblock'a колок не держит строй — дорогой ремонт (замена колков на oversize или полная замена pinblock). Влажность критична: при сезонных колебаниях деревянная дека набухает/усыхает → строй плывёт. Идеально: 42-45% RH. |
| musicinst.ops.brass_saxophone_repair_dent | Ремонт латуни/ветровки — удаление вмятин | METHOD | Удаление вмятин на медных духовых. Оценка: расположение (доступно ли?), глубина, острота. Инструменты: dent balls (стальные шары на стержне — просовываются в трубу, магнитный молоток снаружи притягивает шар, выстукивая вмятину изнутри), dent machine/magnet (электрический магнит — шар протаскивается магнитом снаружи), levers, burnishers. Техника: 1) нагрев? (для лакированных инструментов — минимально чтобы не сжечь лак, только для сильных вмятин), 2) постепенно, не пытаться выправить за один проход (растягивает металл, утонение стенки, трещина), 3) working от краёв вмятины к центру, 4) anneal (отжиг — нагрев до тёмно-красного и охлаждение) для снятия напряжений в латуни, если много работали (наклёп — металл становится твёрдым и хрупким), 5) final burnishing (полировка для сглаживания поверхности). Для больших раструбов (bell): rolling machine (три ролика давят снаружи, распределяя металл). Химическая очистка (chem clean — кислотная ванна для удаления оксидов и накипи изнутри инструмента). | Латунь наклёпывается (work hardening) — становится твёрдой и трескается. Если много выправляли — обязательно отжиг (anneal: 400-500°C, держать до тёмно-красного, быстро охладить в воде — обратный процесс для латуни!). Паяные швы: нагрев рядом с пайкой может расплавить припой. Температура припоя ниже чем отжига → аккуратно! |
