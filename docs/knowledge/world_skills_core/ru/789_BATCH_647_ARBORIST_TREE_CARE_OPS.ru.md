# BATCH 647: Arborist — Tree Care Operations

**KnowledgeUnits:** 43
**Namespace:** `arborist.ops.*`
**Scope:** pruning, removal, cabling, planting, diagnosis, climbing, stump_grinding, safety

| ID | KnowledgeUnit | Тип | Суть | Практический смысл |
|---|---|---|---|---|
| arborist.ops.crown_reduction_cut | Уменьшение кроны — правильный разрез | METHOD | Снижение кроны (НЕ topping!). Cut to lateral: срезать ветвь на боковую (lateral branch) минимум 1/3 диаметра срезаемой. Угол: lateral идёт в нужном направлении. Цель: снизить высоту/ширину сохраняя natural form. Максимальное удаление: 25% живой кроны за сезон. ANSI A300 стандарт. Место среза: за branch collar (не заподлицо!). Техника трёх надпилов (для толстых ветвей): undercut → top cut → final cut. | Топпинг = варварство: массивные ростки, слабые крепления, загнивание. |
| arborist.ops.rigging_block_setup | Такелаж — Блок и Шкив | METHOD | Такелаж для контролируемого спуска ветвей. Block (шкив) крепится выше срезаемой ветви (strop/ремень вокруг ствола). Rope (bull rope, 1.5-2 см) проходит через block к ground crew. Portawrap (фрикционное устройство на стволе) для контроля натяжения. Техника: climber срезает ветвь, ground crew плавно спускает. Let it run (не жёсткая остановка — shock loading). Вес: рассчитывать SWL (Safe Working Load, обычно 10:1 safety factor). Коммуникация: радио. | Никогда не стой под suspended load! |
| arborist.ops.disease_diagnosis_field | Болезни деревьев — полевая диагностика | METHOD | Диагностика болезней на месте. Признаки: leaf spot, chlorosis, canker, fungal conk (на стволе — признак внутренней гнили), dieback, oozing. Armillaria (корневая гниль, honey fungus — опята у основания), Hypoxylon canker (на дубе при стрессе), Emerald Ash Borer (D-shaped exit holes на ясене). Почва: pH, compaction, drainage. Root zone: girdling roots (обвивающие корни). Resistance drilling (резистограф): измерение плотности древесины (скрытая гниль). | Лечение: не всегда возможно. Часто — management (удаление опасных частей). |
| arborist.ops.climbing_technique_spurs | Техника лазания — шпоры и верёвка | METHOD | Лазание по деревьям. Два основных метода: 1) Spur climbing (шпоры — острые шипы на ногах) — только для удаления (повреждает кору!), 2) Rope climbing (верёвка через branch union) — для обрезки. Система: climbing line (10-13 мм, static), friction hitch (Blake's hitch, Distel, Prusik), saddle (harness — широкий пояс + leg loops). Техника: footlock (ногами + hitch), mechanical ascender (ручной подъёмник, Petzl Ascension). Безопасность: lanyard (дополнительная страховка), на два карабина. | Spur climbing повреждает кору — нельзя на живых деревьях для обрезки. |
| arborist.ops.pruning_young_tree | Обрезка молодого дерева — формирование | METHOD | Формирование молодого дерева. Цель: один центральный лидер (central leader) — не допускать co-dominant stems (два равных ствола). Удалить: dead, diseased, rubbing, crossing branches (dead/diseased/rubbing). Не удалять >25% листвы за раз. Правильная ветвь: угол 45-90°, не прижатая к стволу. Training: first 3-5 лет только corrective pruning. staking: только если необходимо (ветер), снимать через 1-2 года. |
| arborist.ops.cabling_bracing_support | Крепление — кабели и тросы для поддержки | METHOD | Кабельная поддержка слабых ветвей (cabling). Материалы: galvanized steel cable (6-12 мм), extra high strength (EHS). Установка: сверлить отверстие (на 2/3 диаметра ветви, не насквозь), вставить lag hook, закрепить cable. Высота: на 2/3 длины слабой развилки. Минимум 2 точки крепления. Alternative: dynamic cobra system (нейлоновый трос — современный, без сверления). Bracing (жёсткая опора): threaded rod через ствол (для трещин/развилок). |
| arborist.ops.stump_grinding_technique | Выкорчевывание пня — техника шлифовки | METHOD | Удаление пня фрезой (stump grinder). Машина: диск с зубьями (Carbide teeth). Процесс: спереди на пень, опускается диск, двигается left-right. Глубина: 15-30 см ниже уровня земли (для газона 15 см, для дренажа 30 см). Скорость: пень 30 см — 10-15 мин. Безопасность: осколки (камни в зубе — слом!), одежда + каска + очки. Размер: для больших >60 см — предварительно chainsaw. |
| arborist.ops.tree_planting_technique | Посадка дерева — техника | METHOD | Посадка дерева (ball & burlap/container). Яма: 2-3× ширина корневого кома, той же глубины (не глубже!). Root flare: должна быть видна над землёй (заглубление — главная причина гибели). Засыпка: original soil (без компоста/удобрения в яму — корни не уходят в родную почву). Water: обильный полив первый год (20-40 литров/неделя). Mulch: 5-10 см слой (не касаться ствола — vole/грызуны). |
| arborist.ops.soil_compaction_management | Уплотнение почвы — аэрация | METHOD | Уплотнение почвы (compaction) — проблема городских деревьев. Причина: пешеходы, машины. Решение: air spade (сжатый воздух — рыхление без повреждения корней), radial trenching (канавы от ствола). Mulch: 10 см слой (подавляет compaction). |
| arborist.ops.tree_hazard_assessment | Оценка опасности дерева | METHOD | Оценка риска падения дерева. Визуальная: target (цель — здание/люди), defects (гниль, трещины, грибы). VTA (Visual Tree Assessment): 1) Biomechanics (наклон, нагрузка), 2) Failure mode (отказ — ствол, корень, развилка). Tree Risk Assessment Qualification (TRAQ) — сертификация ISA. |
| arborist.ops.root_pruning_construction | Обрезка корней при строительстве | METHOD | Корни при строительстве. Critical Root Zone (CRZ): радиус = диаметр ствола × 1.5 фута (в дюймах). Не резать >30% корней с одной стороны. Cut: чистый срез (не рвать), засыпать почвой. Root barrier: физическое ограждение. |
| arborist.ops.pesticide_application_methods | Применение пестицидов — методы | METHOD | Обработка от вредителей. Spray: листва (insecticide/fungicide — дождь смывает). Soil drench: корни (imidacloprid для Emerald Ash Borer). Trunk injection: ствол (для дерева рядом с водой). Timing: весна или осень. |
| arborist.ops.wood_chip_mulch_types | Типы мульчи — щепа | METHOD | Мульча: arborist wood chips (кора + листья + ветки — лучшая для деревьев). Bark nuggets (кора отдельно — медленно разлагается). Не: rock/резина. |
| arborist.ops.tree_lightning_protection | Молниезащита деревьев | METHOD | Громоотвод для дерева. Кабель: медный (10-12 ga), от вершины по стволу в землю + grounding rod. Terminal (приёмник) на вершине. |
| arborist.ops.climbing_knots_essential | Основные узлы для лазания | METHOD | Узлы для альпинизма. Blake's hitch (самоблокирующийся), Clove hitch (на карабин), Taut-line hitch (регулировка), Prusik (запасной). Figure-8 (концевой), Bowline (петля не затягивается). |
| arborist.ops.felling_face_notch | Валка дерева — направляющий запил | METHOD | Валка дерева (felling). Face notch (V-образный вырез): 1/4-1/3 диаметра, открытый угол 70-90°. Back cut: с противоположной стороны, горизонтальный, на 2-3 см выше notch. Hinge (оставшаяся древесина): 10% диаметра (управляет падением). |
| arborist.ops.pruning_tool_sharpening | Заточка инструмента — секаторы/пилы | METHOD | Заточка секатора/сучкореза/садовой пилы. Секатор: diamond file (single bevel — только внешняя сторона). Pruning saw: tri-edge (трёхгранный напильник). |
| arborist.ops.tree_removal_crane | Удаление дерева краном | METHOD | Кран для удаления (crane removal). Вес: оценить weight каждой секции. Sling: round sling (нейлон), shackle. План: cut sequence, pick points. |
| arborist.ops.ivy_vine_removal | Удаление плюща со ствола | METHOD | Плющ (ivy) удушает дерево. Cut: 50 см от земли, оторвать плющ от ствола. Не тянуть кору. |
| arborist.ops.pest_emerald_ash_borer | Ясеневая изумрудная узкотелая златка | METHOD | EAB (Agrilus planipennis). Признаки: D-shaped holes, epicormic shoots, dieback. Лечение: imidacloprid или trunk injection (TREE-äge). |
| arborist.ops.dutch_elm_disease | Голландская болезнь вяза | METHOD | Ophiostoma ulmi (грибок), передаётся elm bark beetle. Признаки: увядание листьев, жёлтые листья. Лечение: fungicide injection (Arbotect). |
| arborist.ops.oak_wilt_disease | Увядание дуба | METHOD | Ceratocystis fagacearum. Признаки: листья коричневеют с краёв. Не обрезать дубы весной (сок привлекает жуков). |
| arborist.ops.tree_survey_aerial | Обследование — осмотр с воздуха | METHOD | Осмотр с помощью дрона (UAV). Камера: высокое разрешение, thermal (стресс дерева). Диагностика: крона, поникшие ветви, сухостой. |
| arborist.ops.arborist_rope_whip | Стебель/плеть — очистка кроны | METHOD | Удаление мелких ветвей (deadwooding). Использование pole pruner (выдвижной секатор) или pole saw. |
| arborist.ops.wood_chipper_safety | Измельчитель веток — безопасность | METHOD | Wood chipper. Feed: крупные ветви первыми. НЕ: маленькие, мягкие (засоряют). Safety bar: stop на входе. |
| arborist.ops.branch_collar_cut | Срез у основания ветви | METHOD | Branch collar: утолщение у основания ветви. Срез: по внешней стороне collar (не flush с trunk). |
