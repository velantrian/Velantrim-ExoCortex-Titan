| pharmsci.ops.adme_bioavailability | ADME — Биодоступность | METHOD | Фармакокинетика (ADME): Absorption (всасывание): F% = AUCoral / AUCiv × 100%. Distribution: Vd (объём распределения). Metabolism: CYP450 (3A4, 2D6, 2C9 — большинство). Elimination: CL (клиренс), T½ = 0.693 × Vd / CL. High protein binding (>95%): снижает свободную фракцию, но может быть депо. | Классификация BCS: Класс I (высокая растворимость, высокая проницаемость) — наилучшее всасывание. |
| pharmsci.ops.tablet_formulation | Таблетированная форма — вспомогательные вещества | METHOD | Состав таблетки: Active Pharmaceutical Ingredient (API). Дилюент (Diluent): MCC (микрокристаллическая целлюлоза), лактоза, манитол. Дезинтегрант: SSG (sodium starch glycolate), croscarmellose — разрушение таблетки при контакте с водой. Смазывающее (Lubricant): магний стеарат (0.1-0.5%). Связывающее (Binder): PVP, HPMC. Покрытие (Film coat): HPMC + TiO2 + plasticizer. | Стеарат магния: гидрофобный → чрезмерное растворение. |
| pharmsci.ops.dissolution_testing | Испытание на растворение — аппарат USP | METHOD | Тест растворения (растворения): Аппарат USP 1 (корзина): таблетки, капсулы. Аппарат 2 (лопатка): наиболее распространённый. Аппарат 3 (цилиндр возвратно-поступательного движения): модифицированное высвобождение. Аппарат 4 (проточный): нерастворимые. Значение Q: % растворенных в местах (Q = 80% за 45 мин, Q = 85%). IVIVC (корреляция In-Vitro In-Vivo): связь между растворением и абсорбцией. | Биовейвер на основе BCS: класс I + класс III могут избежать исследования BE (некоторые). |
| pharmsci.ops.gmp_cgmp_compliance | cGMP — Системы качества | METHOD | Текущие GMP (cGMP): 21 CFR Parts 210-211 (США), EU GMP. Документация: каждый шаг, каждый гальванический момент. Пакетные записи. Отклонения: CAPA (Корректирующие и предупреждающие действия). Валидация: IQ (квалификация установки), OQ (эксплуатация), PQ (производительность). Несоответствие техническим требованиям (ООС): полное расследование. Мастер-файл по лекарственным средствам (DMF): конфиденциальная технологическая информация для FDA. | 483 observations (FDA инспекция): предупреждения. Warning Letter: серьёзнее. Import Alert. |
| pharmsci.ops.stability_testing_ich | Тестирование стабильности — ICH Q1 | METHOD | Стабильность лекарства (ICH Q1A(R2)): Долгосрочная (LT): 25°C/60% относительной влажности, 12-36 месяцев. Промежуточный: 30°C/65% относительной влажности. Ускоренное: 40°C/75% относительной влажности, 6 мес. Морозильная камера: -20°C (биотехнология). В охлажденном состоянии: 5°C±3. Стресс-тестирование: термика, фотолиза, кислота/основание/окисление. Срок годности: экстраполяция из стабильности данных. | Зона I (умеренный климат), зона IVb (жаркая/очень влажная): разные требования. |
| pharmsci.ops.bioequivalence_study | Биоэквивалентность — дизайн исследования | METHOD | Биоэквивалентность (BE): Непатентованный препарат = препарат из референтного списка (RLD) в пределах 80–125% (90% ДИ) для AUC и Cmax. Кроссоверное исследование: 2-периодное (Период 1 → размыв → Период 2). ANOVA с последовательность, период, лечение. ISCV (внутрипредметное резюме): → RSABE. Лог-преобразование: тест параметрическая. N предметов: по изменчивости. | BE failure: если 90% CI не в пределах 80-125%. |
| pharmsci.ops.nda_anda_submission | NDA против ANDA — нормативное регулирование | METHOD | Заявка при регистрации: NDA (заявка на новое лекарственное средство, 505(b)(1)): все данные о безопасности и эффективности самого заявителя. 505(b)(2): частично основано на опубликованной литературе или чужих данных (с правом ссылки). ANDA (сокращенно NDA): дженерик — только BE, никаких клинических исследований. eCTD: электронный формат. Проверка PDUFA: стандартная проверка 10-12 мес, приоритетная 6 мес. | Сертификация по параграфу IV: ANDA оспаривает действие патента. |
| pharmsci.ops.cytochrome_cyp450 | CYP450 — Лекарственное взаимодействие | METHOD | Взаимодействие CYP450: CYP3A4 (∼50% препаратов): Ингибиторы (кетоконазол, ритонавир, грейпфрут) → ↑ субстрат AUC. CYP2C19: ингибиторы протонной помпы, активация клопидогреля. | Варфарин: CYP2C9 + путь витамина К + высокая вариабельность TI → частый мониторинг. |
| pharmsci.ops.controlled_release | Контролируемый выпуск — матрица HPMC | METHOD | Матричная система с контролируемым высвобождением: HPMC (Hypromellose) гидрофильный матрикс: вода диффундирует → гель → гель-диффузия + эрозия.
