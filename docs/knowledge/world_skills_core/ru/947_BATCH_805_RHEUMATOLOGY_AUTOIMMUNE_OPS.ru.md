# BATCH 805: Rheumatology — Autoimmune Disease

**KnowledgeUnits:** 17
**Namespace:** `rheumatology.ops.*`
**Scope:** rheumatoid_arthritis, lupus, vasculitis, spondyloarthropathy, gout, Sjogrens, myositis, DMARD_treatment, biologic_therapy

| ID | KnowledgeUnit | Тип | Суть | Практический смысл |
|---|---|---|---|---|
| rheum.ops.rheumatoid_arthritis | Ревматоидный артрит — ACR/EULAR | METHOD | Ревматоидный артрит (РА): ACR/EULAR 2010 критерии: суставное поражение + серология (РФ, анти-ЦЦП) + острофазовые (CRP, СОЭ) + длительность. ≥6 баллов = РА. Симметричный полиартрит мелких суставов. Утренняя скованность >30 мин. Дефект «лебединой шеи», «бутоньерки». | Anti-ЦЦП антитела: высокая специфичность для РА (95%). |
| rheum.ops.dmard_therapy | Лечение БПВП — МТХ | METHOD | Базисные противовоспалительные (ДМАРП): Метотрексат (МТХ) — первая линия РА. Доза: 7.5-25 мг 1 раз/нед + фолиевая кислота. Мониторинг: CBC, функция печени. Противопоказания: беременность, тяжёлая почечная/печёночная. Leflunomide: альтернатива (тератоген). Hydroxychloroquine: для лёгкого РА + СКВ. | Treat-to-target: цель — ремиссия или низкая активность (DAS28 <2.6). |
| rheum.ops.anti_tnf_biologics | Биологические препараты — ингибиторы ФНО | METHOD | Биологические препараты при РА: анти-ТНФ: инфликсимаб, адалимумаб, этанерцепт, голимумаб, цертолизумаб. Скрининг: латентный ТБ (QuantiFERON), HBV, сердечная недостаточность (NYHA III-IV = противопоказание). JAK inhibitors: тофацитиниб, барицитиниб (венозный тромбоз риск). IL-6: тоцилизумаб. | Мониторинг биологиков: нет обязательного мониторинга уровней (vs ДМАРП). |
| rheum.ops.sle_management | СКВ — Алгоритм лечения | METHOD | Системная красная волчанка (СКВ): Все = гидроксихлорохин (базовый). Лёгкая = НПВП + стероиды. Умеренная = микофенолат. Тяжёлая = циклофосфамид + пульс стероиды. Белимумаб (анти-BAFF): рецидивирующее. Воцлоспан (Voclosporin): при нефрите. SLICC критерии 2012. | ЦНС-волчанка: острые психозы или судороги при СКВ = нейропсихиатрическая форма. |
| rheum.ops.gout_acute | Подагра — лечение острых приступов | METHOD | Острый подагрический артрит: 1-я линия: колхицин 1 мг затем 0.5 мг через 1 час (ранняя терапия = наиболее эффективно), или НПВП (индометацин), или кортикостероиды. Сустав: аспирация кристаллов = облегчение. Острый приступ: не начинать аллопуринол (усиливает). | Обратная логика подагры: начать аллопуринол только при разрешении острого приступа. |
| rheum.ops.ankylosing_spondylitis | Анкилозирующий спондилит — Диагностика | METHOD | Анкилозирующий спондилит (AS): боль в нижней части спины у молодых + утренняя скованность + улучшение при движении. HLA-B27+: 90%. Рентген: сакроилеит (Нью-Йоркские критерии). МРТ: ранние воспалительные изменения. NSAID: первая линия. Анти-ТНФ или IL-17 (секукинумаб): при неответе. | «Бамбуковый позвоночник»: поздний рентгеновский признак (синдесмофиты). |
| rheum.ops.vasculitis | Васкулит — Классификация | METHOD | Системные васкулиты: Крупные сосуды: гигантоклеточный (ГКА), артериит Такаясу. Средние: узелковый полиартериит (УПА), болезнь Кавасаки. Малые (ANCA-связанные): гранулематоз Вегенера (GPA), микроскопический полиангиит (MPA), эозинофильный гранулематоз (EGPA). ГКА: стероиды. ANCA-связанные: циклофосфамид + стероиды. | Temporal artery biopsy: золотой стандарт диагностики ГКА. |
| rheum.ops.sjogrens_syndrome | Синдром Шегрена — Диагностика | METHOD | Синдром Шегрена: сухость (sicca): ксеростомия + ксерофтальмия. ПСС (Primary Sjögren's Syndrome). АСС-ИПА: SSA/Ro, SSB/La антитела. Биопсия слюнной железы (малая слюнная): лимфоцитарная инфильтрация. Schirmer test: <5 мм/5 мин = ксерофтальмия. Осложнения: В-клеточная лимфома (40× риск). | Плоды при ССА (Ro/La антитела) + беременность: риск неонатальной волчанки + врождённого AV-блока. |
| rheum.ops.inflammatory_myopathy | Воспалительная миопатия — виды | METHOD | Воспалительные миопатии: Полимиозит (ПМ): проксимальная слабость без высыпаний. Дерматомиозит (ДМ): ПМ + Готтроновы бугорки + гелиотропная сыпь. ИНИМ (иммунно-медиированная некротизирующая миопатия). Anti-Jo-1: антисинтетазный синдром + ILD + механические руки. КФК: маркер активности. | Паранеопластический дерматомиозит: скрытая злокачественная опухоль у взрослых (>40 лет). |
| rheum.ops.psoriatic_arthritis | Псориатический артрит — закономерности | METHOD | Псориатический артрит (ПсА): CASPAR критерии. Паттерны: асимметричный олигоартрит (#1 у взрослых), ДИП (дистальный межфаланговый) + онихолизис, мутилирующий (arthritis mutilans), аксиальный (как AS), полиартрит (РА-like). Псориаз предшествует ПсА в 80%. NLCA (nail), SHINS: skin, heel enthesis, iritis, nail, Sausage digit (dactylitis). | Dactylitis (сосископодобный палец): высокоспецифичен для ПсА (отличие от РА). |
| rheum.ops.osteoarthritis_management | Остеоартрит — Управление | METHOD | Остеоартроз (ОА): немедикаментозное: снижение веса (высокая эффективность при ОА коленных суставов), физиотерапия, упражнения. Медикаментозное: парацетамол (мало доказательств), НПВП (локально или перорально), дулоксетин. Инъекции: стероиды (краткосрочный эффект), гиалуроновая кислота (спорно). Хирургия: ТЭП (TKA/THA). | Степень ОА: КЛ (Келлгрен-Лоуренс) I-IV степени. Степень IV = показание к замене сустава. |
| rheum.ops.fibromyalgia | Фибромиалгия — Диагностика и лечение | METHOD | Фибромиалгия: хроническая распространённая боль + усталость + когнитивные нарушения + нарушение сна. Диагностика (ACR 2010/2016): WPI + SS (Symptom Severity Scale) ≥7. Нет специфических тестов. Лечение: упражнения (Grade A), дулоксетин/прегабалин, CBT. | Fibromyalgia + RA: может сосуществовать → осложняет интерпретацию активности болезни. |
| rheum.ops.antiphospholipid | Антифосфолипидный синдром | METHOD | Антифосфолипидный синдром (АФС): тромбоз (артерий, вен или акушерские осложнения) + АФ антитела (Люпус антикоагулянт, кардиолипин IgG/IgM, β2-ГП1 IgG/IgM) × 2 измерения с интервалом ≥12 нед. SAPH: «slam first» antiphospholipid. Лечение: варфарин (INR 2-3). | Catastrofic APS (CAPS): быстрое множественное тромбирование. Смертность 50%. |
| rheum.ops.hydroxychloroquine_monitoring | HCQ — токсичность для сетчатки | METHOD | Мониторинг гидроксихлорохина: максимальная доза ≤5 мг/кг/сут (реальный вес). Базовый осмотр офтальмолога. Ежегодная проверка с 5 года приёма. OCT (HVF, мультифокальная ЭРГ): обнаружение ранних изменений. Токсичность: «Bull's eye» maculopathy. | 20-летний риск HCQ ретинопатии при стандартных дозах: ~7.5%. |
| rheum.ops.disease_activity_score | Активность заболевания — DAS28 | METHOD | Индекс активности болезни (DAS28): 28 суставов. DAS28 = 0.56√TJC28 + 0.28√SJC28 + 0.70ln(ESR) + 0.014GH. TJC = болезненные суставы. SJC = припухшие. GH = общая оценка пациентом. Ремиссия: DAS28 < 2.6. Низкая: 2.6-3.2. Умеренная: 3.2-5.1. Высокая: >5.1. | CDAI/SDAI: альтернативы без острофазовых (более быстрые). |
| rheum.ops.reactive_arthritis | Реактивный артрит — РеА | METHOD | Реактивный артрит (стараясь заменить «синдром Рейтера»): после инфекции (хламидия, кишечные). Триада Рейтера: артрит + уретрит + конъюнктивит («cant see, cant pee, cant climb a tree»). НLA-B27+. Самоограничивающийся (большинство). НПВП. При хроническом: ДМАРП. | Chlamydia trachomatis: #1 причина инфекционного ReA (ЗППП). |
| rheum.ops.crystal_arthritis | Кристаллическая артропатия — псевдоподагра | METHOD | Кристаллические артропатии: Подагра: кристаллы мочевой кислоты (негативная двулучепреломляемость, игольчатые). Псевдоподагра (CPPD): кристаллы кальция пирофосфата (положительная, ромбовидные). Сустав: колено (#1 псевдоподагра), большой палец стопы (#1 подагра). Аспират: идентификация кристаллов под поляризованным микроскопом. | Псевдоподагра: часто ≥70 лет при гиперпаратиреозе, гемохроматозе. |
