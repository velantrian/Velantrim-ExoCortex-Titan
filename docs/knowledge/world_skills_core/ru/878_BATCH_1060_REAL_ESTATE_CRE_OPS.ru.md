| realestate.ops.cap_rate_valuation | Ставка капитализации — оценка NOI | METHOD | Ставка капитализации: ставка капитализации = NOI / стоимость. Значение = NOI / предельная ставка. NOI (чистый операционный доход) = валовая потенциальная арендная плата – вакансии/кредитные убытки – операционные расходы (до обслуживания долга). Рыночная капитализация варьируется в зависимости от: класса активов (многоквартирные 4-6%, промышленные 4-5%, розничные 5-7%), местоположения, качества. Сжатие: ограничение скорости снижается → значения увеличиваются. | Кредитное плечо: если ставка по ипотеке > ставки предела = отрицательное кредитное плечо. |
| realestate.ops.dcr_debt_coverage | Коэффициент покрытия долга — CRE Lending | METHOD | Коэффициент покрытия долга (DCR/DSCR): NOI / Annual Debt Service. Минимум: большинство кредиторов требуют ≥1,20-1,25. 1,0 = безубыточность. <1,0 = имущество не покрывает кредит. LTV (отношение кредита к стоимости): 65-75% (коммерческий). Кредит на основе DSCR: рассчитывается на основе NOI, без проверки личного дохода. | DSCR 1.0: любое снижение NOI → по умолчанию. Буфер безопасности важен. |

Доходный подход: NOI / предельная ставка (или DCF). Затратный подход: земля + амортизированная стоимость улучшений. USPAP (Единые стандарты практики профессиональной оценки): стандарт. МАИ (Член Института Оценки): профессиональный титул. Настольная или полевая оценка. | Проданная сопоставимая недвижимость ("comparable sale"): должна быть arm's length transaction. |
| realestate.ops.lease_types | Типы аренды — брутто или NNN | METHOD | Типы аренды: Gross (full service): арендатор платит фиксированную аренду, арендодатель = все расходы. | realestate.ops.1031_exchange | 1031 Обмен — Отсрочка налога | METHOD | Секция 1031 (Like-Kind Exchange): продать investment property + реинвестировать в «like-kind» → отложить capital gains tax. | realestate.ops.gross_rent_multiplier | Мультипликатор валовой арендной платы — быстрая оценка | METHOD | Валовый рентный мультипликатор (GRM): GRM = Цена покупки / Валовая арендная плата.
