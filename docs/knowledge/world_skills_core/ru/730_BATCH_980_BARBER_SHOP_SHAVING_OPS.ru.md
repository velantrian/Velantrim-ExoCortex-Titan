| barber.ops.straight_razor_stropping | Опасная бритва — заточка и заточка | METHOD | Заточка и правка опасной бритвы. Hone (точильный камень): зернистость 4000-8000 grit (Norton, Naniwa) для восстановления режущей кромки. Водный камень: замочить 10 мин, угол 15-20°, 20-30 проходов каждой стороной. Strop (ремень для правки): кожаный (гладкая сторона) + canvas (грубая для очистки). Перед КАЖДЫМ клиентом: 20-30 проходов на canvas + 40-60 на коже. Техника: полотно ремня натянуто. Razor кладётся плашмя, двигается спинкой вперёд (не лезвием — перережешь ремень). Проверка остроты: Hanging Hair Test (HHT — подвешенный волос, при касании лезвия без давления перерезается). Shave-ready: бритва переданная клиенту должна быть стерильна (Barbicide). | Опасная бритва НЕ classical straight razor с заменяемым лезвием — shavette (одноразовые лезвия) — требует меньше ухода. Straight используется для престижного traditional shave. |
| barber.ops.hot_towel_facial_prep | Горячее полотенце — подготовка и применение | METHOD | Горячий компресс перед бритьём. Towel: хлопковый (размер салфетки). Температура: 60-75°C (проверить на запястье — комфортно жарко, не ошпаривающе). Towel steamer/warmer: шкаф с УФ для дезинфекции. Техника: обернуть лицо, оставить 30-60 сек. Цель: открыть поры, размягчить волосы, расслабить клиента. Pre-shave oil: нанести до первого горячего полотенца (массаж кожи). Shave cream: нанести кистью (badger/boar brush), взбить в чаше (scuttle) с горячей водой (warm lather). Бритьё (With the Grain — первый проход): короткие уверенные движения, 30° угол, натяжение кожи свободной рукой. Across и Against the Grain (опционально, sensitive skin — skip). Холодное полотенце после бритья: закрыть поры, тонизировать. Aftershave balm (без спирта — жжение). | Straight razor shave: требует лицензию барбера (в США — Barber license 1000-1500 часов, отдельно от cosmetology). Санитария: инструмент дезинфицируется после каждого клиента! |
| barber.ops.clipper_fade_techniques | Clipper Fade — коническое и лысое затухание | METHOD | Стрижка машинкой с переходом (fade). Уровни fade: Bald (zero-gapped trimmer — до кожи), Skin (trimmer), #0.5 guard, #1, #1.5, #2, #3. Линия перехода: начинать с бритвы/триммера на висках и шее → постепенно увеличивать guard, двигаясь вверх. Зоны: Base line (нижняя граница fade — вокруг ушей, шеи), Transition zone (смешение длин), Bulk (верхняя часть — ножницы). Blending: lever на машинке (открыт/закрыт) для промежуточных длин между guard-ами (Andis Master, Wahl Magic Clip). Детализация: триммер (Andis T-Outliner) для чёткой линии. Шея: razor clean-up (sub-zero линия). Консультация: фото желаемого стиля (номер guard, текстура). Форма головы/линия роста волос определяют где fade начинать. | Fade на кудрявых/вьющихся волосах требует другой техники — clipper-over-comb и scissor work. Не пытаться использовать guards на очень густых углах. |
| barber.ops.beard_sculpting_shaping | Скульптура бороды — форма и уход | METHOD | Моделирование бороды. Инструменты: scissors, clipper, trimmer, straight razor (для линий). Консультация: форма лица (round — острее книзу борода, square — мягче линии, oval — любой). Линии: Cheek line (upper cheek), Neck line (Adam's apple — два пальца выше кадыка). Стрижка: clipper с guard (#2-#4 for short, #5-#8 for longer), против роста для ровной длины. Текстура: thinning scissors для слишком густых участков. Усы: comb down, trim по линии губы (не стричь слишком коротко — щетинистость). Бальзам/масло для бороды: увлажнение, блеск, послушность. | Neck line — самое важное: слишком низко — messy, слишком высоко — double chin подчёркивает. Правило: от кадыка вверх два пальца. |
| barber.ops.barber_shop_hygiene_sanitation | Санитария для парикмахеров — Протокол Государственного совета | METHOD | Санитарные нормы барбершопа. Обязательные: Barbicide (на основе quaternary ammonium compounds) — расчёски/ножницы замачиваются 10 мин между клиентами. Clipper blades: очистка от волос (brush + spray disinfectant — Clippercide, 10 мин), смазка. Straight razor / shavette: одноразовое лезвие (новое для каждого клиента), держатель дезинфицируется. Hot towel: стирка с отбеливателем после каждого клиента (или одноразовые). Neck duster (кисточка для удаления волос с шеи): запрещена во многих штатах (невозможно дезинфицировать — заменена на одноразовые neck strips или blow dryer). Cape (накидка): стирка daily, не класть на нескольких клиентов подряд без смены. Руки: мытьё до и после каждого клиента (hand sanitizer between). Рабочая станция: дезинфекция поверхностей (Barbicide wipe). Лицензия: display на видном месте. | Подпольный барбер (no license): риск заражения (staph, ringworm, Hep B/C теоретически через микро-порезы). State Board inspections: random, штрафы >$1000 за нарушения. |
