| urology.ops.kidney_stone_workup | Камни в почках — обследование и лечение | METHOD | Мочекаменная болезнь: КТ без контраста — золотой стандарт (выявляет все типы). | urology.ops.prostate_cancer_staging | Рак простаты — TNM и риск | METHOD | Рак предстательной железы: стратификация риска по D'Amico/NCCN. Низкий риск: ПСА <10, GS 6, T1-T2a. Промежуточный: PSA 10-20, GS 7, T2b-T2c. Высокий: ПСА >20, GS 8-10, T3a+. Локализованное лечение: радикальная простатэктомия, лучевая терапия или активное наблюдение (низкий риск). Метастатические: АДТ (андрогенная депривационная терапия). | Группа оценок Глисона: 1 (3+3), 2 (3+4), 3 (4+3), 4 (4+4/3+5), 5 (4+5, 5+5). |
| urology.ops.bph_management | ДГПЖ — лечение СНМП | METHOD | Доброкачественная гиперплазия простаты (ДГПЖ): IPSS score (0-35). Медикаментозное: Alpha-1 blockers (тамсулозин, силодозин) = быстрый эффект (снижение outlet obstruction). 5α-reductase inhibitors (финастерид, дутастерид) = долгосрочный (снижение объёма). Комбо: лучше при больших железах. Хирургия: TURP (gold standard). | Retention: если >300 мл остаточной мочи → катетер → хирургия. |
| urology.ops.turp_procedure | ТУРП — Трансуретральная резекция | METHOD | Трансуретральная резекция простаты (TURP): резектоскоп через уретру. Монополярный (глициновый ирригант) или биполярный (физраствор). TURP syndrome (гипонатриемия): при монополярном. Биполярный: безопаснее. Кровотечение, ретроградная эякуляция, стриктура: основные осложнения. Holmium laser enucleation (HoLEP): альтернатива. | TURP по-прежнему эталон при объёме простаты 30-80 мл. |
| urology.ops.overactive_bladder | Гиперактивный мочевой пузырь — управление | METHOD | Гиперактивный мочевой пузырь (ОАБ): urgency, frequency, ±urgency incontinence. Первая линия: поведенческая терапия (мочевой дневник, тренировка мочевого пузыря). Вторая: anticholinergics (оксибутинин, солифенацин) или β3-agonist (мирабегрон). Ботулотоксин внутрипузырно: при рефрактерном. Нейромодуляция: SNM (sacral nerve modulation). | Anticholinergics у пожилых: когнитивные побочные = предпочтителен мирабегрон. |
| urology.ops.renal_cell_carcinoma | Почечно-клеточный рак — лечение | METHOD | Почечно-клеточный рак: Clear cell (75%), papillary, chromophobe. Стадирование: CT/MRI. T1a (<4 мм) = partial nephrectomy (цель). T2+ = radical nephrectomy. Метастатический: TKI (сунитиниб, пазопаниб) + иммунотерапия (нивулумаб + ипилимумаб — combo). RCC не чувствителен к химиотерапии. | Partial nephrectomy: сохранение нефронов (важно при CKD риске). |
| urology.ops.erectile_dysfunction | Эректильная дисфункция — лечение | METHOD | Эректильная дисфункция: IIEF score. Причины: vasculogenic, neurogenic, hormonal, psychogenic, anatomic. Первая линия: PDE5 inhibitors (силденафил, тадалафил, варденафил). Тадалафил 5 мг/день: для BPH + ED. Вторая: ВВ инъекции (пенильные — alprostadil). Третья: penile prosthesis (имплант). Hormonal: тестостерон при гипогонадизме. | «Cath-lab» warning: нитраты + PDE5i = жизнеопасная гипотензия. |
| urology.ops.stress_incontinence | Стрессовое недержание мочи — лечение | METHOD | Стрессовое недержание мочи: при кашле/чихании/усилии. Причина: слабость уретрального замыкательного аппарата + сфинктера. Женщины: послеродовое, постменопаузальное. Консервативно: упражнения Кегеля, физиотерапия тазового дна. Хирургия: TVT/TOT (midurethral sling). | TVT (вагинальная лента без натяжения): 80-90% излечения при стрессовом недержании. |
| urology.ops.testicular_cancer | Рак яичка — маркеры | METHOD | Рак яичка: молодые мужчины (15-35 лет). Семинома vs несеминома. Исследование давления-расхода: обструкция vs неудержание. Гиперактивность детрузора: непроизвольные сокращения. Гипоактивность детрузора: при ВОО/нейрогенная. Давление в точке утечки.
