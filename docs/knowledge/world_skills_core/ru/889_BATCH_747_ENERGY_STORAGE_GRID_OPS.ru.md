# BATCH 747: Renewable Energy — Energy Storage & Grid Integration

| energystorage.ops.battery_grid_types | Сетчатая батарея — сравнение технологий | METHOD | Сетевые системы хранения: Li-ion (NMC, LFP): высокая энергоплотность, быстрый отклик (<100 мс). Для frequency regulation + peak shaving. Flow batteries (Vanadium): бесконечный цикл (электролит не деградирует), длительное хранение (4-8 ч+). BESS (Battery Energy Storage System) = инвертор + батарея + BMS + EMS. Roundtrip efficiency: Li-ion 90-95%, Vanadium flow 75-80%. | LFP для коммунальных/общественных масштабов: безопаснее, чем NMC (отсутствие температурного разбега). |
| energystorage.ops.frequency_regulation | Регулирование частоты — первичный отклик | METHOD | Регулирование частоты: Первичная (primary response): автоматическая, <30 сек (governor control, BESS). Вторичная (AGC — Automatic Generation Control): 30 сек - 15 мин. Третичная: manually dispatched. BESS преимущество: реакция <100 мс vs thermal plant 30+ сек. FERC Order 841 (USA): storage участвует во всех рынках. | Частота 50 Гц (EU) / 60 Гц (US): ±0.5 Гц = допустимо. |
| energystorage.ops.virtual_power_plant | ВПП — Виртуальная Электростанция | METHOD | Виртуальная электростанция: агрегация distributed resources (домашние батареи, solar, EV, HVAC) → управляемый ресурс для сети. Demand Response: снижение нагрузки по команде оператора. Aggregator: управляет VPP, ставки на рынке. Tesla Virtual Power Plant: SA в Австралии. Granular контроль: 1-MW adjustments в реальном времени. | Распределенная гибкость: миллионы мелких ресурсов > несколько крупных заводов. |
| energystorage.ops.v2g_vehicle_grid | V2G — транспортное средство к сети | METHOD | Vehicle-to-Grid (V2G): EV разряжается в сеть во время пиков. CHAdeMO: первый стандарт V2G (Nissan Leaf). CCS Combo + ISO 15118-20: V2G для широкого внедрения. Grid services: frequency regulation, peak shaving. Требование: двунаправленный зарядник. Battery degradation concern: дополнительные циклы → но smart scheduling минимизирует. | V2G revenue: $500-1000/год от EV батареи (оценки). |
| energystorage.ops.hydrogen_storage | Водород — хранение и типы | METHOD | Хранение водорода: сжатый (350-700 бар), жидкий (-253°C), материал (металлогидриды). Green hydrogen: электролиз из ВИЭ. Grey hydrogen: steam methane reforming (с CO2). Blue hydrogen: SMR + CCS. Pink: ядерная энергия. Производительность электролизёра: PEM (80-90%), Alkaline (75-85%). Levelised cost: $5-15/кг (green, 2024). | КПД туда и обратно H2: ~30-40% (электричество → H2 → топливный элемент → электричество). |
| energystorage.ops.pumped_hydro_storage | Насосная гидросистема — Проектирование | METHOD | Гидроаккумулирующая электростанция (ГАЭС): насосный режим (дешёвая электроэнергия → закачка воды вверх) + генераторный (пиковая разгрузка). Efficiency: 75-85% round-trip. Capacity: 100 MW - 3 GW. Long duration storage (8-40 ч). Open-loop: реки. Closed-loop: автономные резервуары. Строительство: 5-10 лет, CAPEX $1000-3000/кW. | Накачиваемая гидросистема = 95% всей мощности накопления энергии (мощности). |
| energystorage.ops.microgrid_control | Микросеть — архитектура управления | METHOD | Микросеть: локальная система с собственным управлением. Режимы: grid-connected (параллельно с сетью) + island mode (автономный). Переход: синхронизация при переключении. Иерархическое управление: primary (droop control), secondary (frequency/voltage restoration), tertiary (economic dispatch). Black start: перезапуск без внешней сети. CERTS Microgrid: стандартная архитектура. | Droop control: пропорциональное распределение нагрузки между генераторами без коммуникации. |
| energystorage.ops.demand_response | Реакция спроса — типы | METHOD | Управление спросом: Dispatchable DR: сигнал от оператора → сокращение нагрузки (промышленность, HVAC). Automated DR: предпрограммированный отклик (OpenADR протокол). Voluntary DR: клиент решает. Time-of-use (TOU): ценовой сигнал. Critical Peak Pricing (CPP). Base Interruptible Program. Economic DR: реагирование на цены. | Ресурс реагирования на спрос: FERC как генерирующий ресурс (требуется Заказ 745). |
| energystorage.ops.energy_management_system | СЭМ — Энергоменеджмент | METHOD | Система управления деятельностью (EMS): оптимизирует диспетчеризацию генерации + хранения. Входные данные: цены на электроэнергию, прогноз нагрузки, прогноз погоды, SOC. Оптимизация: линейное программирование или MPC (Model Predictive Control). Цели: минимизировать затраты, максимизировать доход, поддерживать стабильность сети. SCADA + EMS: управление устойчивостью. | Оптимизация на сутки вперед vs оптимизация в реальном времени: на сутки вперед = плановый, в режиме реального времени = коррекция. |
| energystorage.ops.levelized_cost_storage | LCOS — приведенная стоимость хранения | METHOD | Приведённая стоимость хранения (LCOS): LCOS = (CAPEX + NPV операционных затрат) / NPV выходной энергии. Факторы: стоимость батареи, roundtrip efficiency, число циклов в год, срок службы. Li-ion (utility): $150-250/MWh (2024). Снижение: Li-ion cost -90% за 10 лет. Комбинация: solar + storage + grid = dispatchable renewable. | LCOS vs LCOE: storage добавляет value через flexibility (нельзя сравнивать напрямую). |
| energystorage.ops.bms_battery_management | BMS — система управления батареями | METHOD | Система управления батареями (BMS): Состояние заряда (SOC): оценка (подсчет Кулона, фильтр Калмана). Состояние здоровья (SOH): емкость по сравнению с исходной. Состояние мощности (SOP): максимальная доступная мощность. Балансировка ячеек: активная (перекачивает заряд) и пассивная (тратит излишки на тепло). Защита: перенапряжение, пониженное напряжение, перегрев, перегрузка по току. Связь: CAN-шина, Modbus. | Точность оценки SOC: ±1% критично для беспокойства по диапазону EV. |
| energystorage.ops.grid_inertia_synthetic | Инерция сетки — синтетическая инерция | METHOD | Инерция сети: традиционные генераторы (турбины) = физическая инерция → сглаживают изменения частоты. Снижение инерции: рост ВИЭ (invertors без инерции). Synthetic inertia: инверторы имитируют инерционный отклик (fast frequency response). FFR (Fast Frequency Response): BESS реагирует за <100 мс. ENTSOE: 30 ГВт·с требование. | RoCoF (Rate of Change of Frequency): ключевой параметр → при высоком RoCoF нарушения. |
| energystorage.ops.thermal_energy_storage | Термическое хранилище — расплавленная соль | METHOD | Термальное хранение энергии: Расплавленная соль (Molten Salt): CSP + TES (600°C, до 16 ч хранения). Охлаждение зданий: Ice storage (лёд ночью, охлаждение днём). Water tank thermal storage: тепло/холод в воде. PTES (Pit Thermal Energy Storage): сезонное. Carnot battery: тепловой насос + хранение → КПД 40-65%. | CSP + расплавленная соль: управляемая солнечная энергия (в отличие от фотоэлектрической). |
| energystorage.ops.capacity_market_storage | Рынки мощности — участие в хранении данных | METHOD | Участие накопителей в процессе развития: PJM, MISO, ISO-NE, CAISO. Приказ FERC 841: все участвуют в рынках мощности. Тест на продолжительность разряда: требование продолжительности 4 часа. Минимальная квалификация: 10 МВт. Коэффициент чистой мощности (NCF): доступность для диспетчеризации. Сумма доходов: энергия + вспомогательные услуги + мощность = общий доход. | Revenue stacking критично: один рынок не окупает storage capex в большинстве регионов. |
| energystorage.ops.grid_forming_inverter | Сетевой инвертор — GFM | METHOD | Формирующий сетевой инвертор (GFM): создаёт напряжение и колебания (vs Grid-following = следует). Grid-Forming = как синхронный генератор. Управление падением напряжения + управление виртуальным генератором (VOC) + виртуальная синхронная машина (VSM). Необходимые условия в режиме острова. Сетка следующая: только в наличии сетка. Сетевой стандарт: IEEE 2800 (для инверторных ресурсов). | Будущая сетка: 100% инверторы → все должны быть Grid-Forming (или что-то в этом роде). |
