# BATCH 630: Language School — Teaching Operations

**KnowledgeUnits:** 5
**Namespace:** `langschool.ops.*`
**Scope:** placement_test, lesson_plan, ESL, immersion, conversation, grammar, assessment, classroom

| ID | KnowledgeUnit | Тип | Суть | Практический смысл |
|---|---|---|---|---|
| langschool.ops.placement_test_interview | Вступительный тест — устный и письменный | METHOD | Тестирование уровня. Письмо: грамматика/словарный запас с множественным выбором (50–100 вопросов), понимание прочитанного, образец письма. Устно: 5-10 мин собеседование (тренированный оценщик). Уровни CEFR (A1-C2). Вопросы: от простых к конструкции (если студент не может ответить — стоп). Рубрика: беглость речи, точность, произношение, понимание. Решение о размещении: по самому слабому навыку (не завышать — студент будет страдать). Пробное занятие: иногда дают 1-2 урока в группе (проверка размещения). | Регулярный re-assessment (каждые 3-6 мес). |
| langschool.ops.communicative_approach | Коммуникативный подход — методология ГЧП | METHOD | Методика PPP: Presentation (учитель вводит новую грамматику/лексику — context, meaning, form), Practice (контролируемые упражнения: gap-fill, drills), Production (свободное использование: role-play, discussion). Error correction: immediate для accuracy stage, delayed для fluency stage. Eliciting: вовлекать студентов (не давать ответ, а задавать вопросы «как вы думаете почему?»). Concept checking (CCQs): проверка понимания без перевода (He used to smoke: Does he smoke now? No. Did he smoke in the past? Yes). STT (Student Talking Time): цель >70% времени урока. | ТТТ (время разговора учителя): минимизировать. |
| langschool.ops.correction_feedback_types | Исправление ошибок — типы и сроки | METHOD | Исправление ошибок. Непосредственно (на упражнение на точность): исправление пальцев (показать на пальцах слов), эхо с повышающейся интонацией, переформулирование. Отложенный (на беглость): записывать ошибки, разбирать после разговора (слот для исправления ошибок). Поправка от сверстников: «кто заметил?» Самокоррекция: «Попробуй ещё раз». Категории ошибок: произношение (звуки, ударение, интонация), грамматика (время, порядок слов), словарный запас (неправильное слово), регистр (формальный/неформальный). Не исправлять ВСЁ (студент доверия). Фокус на уроке целевого языка. | Запись доски: ошибка + правильный вариант (имя студента анонимно). Произношение: Транскрипция IPA. |
| langschool.ops.lesson_plan_stages | План урока — от разминки до заминки | METHOD | План урока 45-90 мин. 1) Разминка (5-10 мин — активация языка, ледокол, обзор прошлого). 2) Вводная часть (введение темы — картинка, видео, вопрос). 3) Презентация (10-15 мин). 4) Практика (15-20 мин). 5) Производство (15-20 мин). 6) Заминка (+ домашнее задание). Материалы: реалии (реальные предметы), аутентичные (меню, газеты). Дифференциация: для групп смешанного уровня — задание на расширение для сильных, подмостки для слабых. Хронометраж: план урока имеет примерные минуты (гибко!). | Переходы между стадиями: плавные (link). |
| langschool.ops.classroom_group_work | Групповая работа — Сопряжение и мониторинг | METHOD | Работа в парах/группах. Pair formation: случайный (по алфавиту имен), по уровню (strong+weak = peer tutoring), по интересам. Instruction: дать чёткое задание + example + time limit. ICQs (Instruction Checking Questions): «Сколько минут? В паре или один? Что делаете?». Monitoring: ходить, слушать, записывать ошибки, не вмешиваться без нужды (пусть говорят). Feedback: после task — praise успешной коммуникации, затем language feedback. Jigsaw task: каждая группа имеет часть информации, должны поделиться. | Если студенты переходят на L1 (родной язык) — напомнить, дать useful phrases на целевом языке. |
