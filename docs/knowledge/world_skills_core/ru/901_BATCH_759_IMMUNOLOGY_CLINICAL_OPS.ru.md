| immunology.ops.innate_immune_prr | Врожденный иммунитет — распознавание образов | METHOD | Врождённый иммунитет: Pattern Recognition Receptors (PRR). TLR (Toll-like receptors): TLR4 → LPS (грамм-отрицательные бактерии). TLR3: dsRNA (вирусы). NLR: внутриклеточные бактерии (NLRP3 = инфламмасома). RIG-I: вирусная РНК. PAMP (Pathogen-Associated Molecular Pattern). DAMP (Danger-Associated): из повреждённых клеток. | Инфламмасома NLRP3 → IL-1β → пирексия + воспаление. |
| immunology.ops.mhc_t_cell | MHC — Активация Т-клеток | METHOD | Главный комплекс гистосовместимости (MHC/HLA): MHC I (HLA-A, -B, -C): на всех ядросодержащих клетках → активирует CD8+ T cells (цитотоксические). MHC II (HLA-DR, -DP, -DQ): на APC (Макрофаги, DC, B cells) → активирует CD4+ T helpers. 2-сигнальная активация T cells: TCR + MHC + CD28/B7 костимуляция. CTLA-4: иммунологический checkpoint. | MHC I + вирусный пептид → CTL убивает инфицированную клетку. |
| immunology.ops.th1_th2_differentiation | Т-хелпер — Th1/Th2/Th17 | METHOD | Дифференцировка T-хелперов: Th1 (IL-12, IFN-γ): клеточный иммунитет, внутриклеточные патогены. Th2 (IL-4, IL-5, IL-13): гуморальный, аллергии, паразиты. Th17 (IL-6, TGF-β, IL-17): грибки, бактерии, аутоиммунные. Treg (TGF-β, IL-10): иммунная толерантность. Th1/Th2 balance: нарушение → аутоиммунные (Th1) или аллергии (Th2). | Treg дефицит: IPEX syndrome (X-linked; полиэндокринопатия + энтеропатия). |
| immunology.ops.complement_pathways | Дополнение — Пути | METHOD | Система комплемента: Классический путь: IgG/IgM + C1qrs → С4b2a (C3 convertase) → MAC (C5b-9). Лектиновый путь: MBL + MASP + MBL-associated serine proteases. Альтернативный: постоянная гидролиз С3 + усиление поверхностью бактерий. C3а, C5a: анафилатоксины (тучные клетки → гистамин). MAC: пробивает оболочку клетки. | C1 Ингибиторный дефицит: наследственный ангиоотёк. |
| immunology.ops.antibody_isotypes | Антитело — функции изотипа | METHOD | Изотипы иммуноглобулинов: IgG (70%): основной в крови, внедрение через плаценту, оптонизация, нейтрализация. IgA: слизистые (секреторный s-IgA), молозиво. IgM: первый ответ, пентамер, агглютинация. IgE: аллергии, паразиты (тучные клетки, базофилы). IgD: на B клетках (рецептор). | Ось IgM→IgG: переключение классов (class switching) в центрах зародышей. |
| immunology.ops.allergy_type1 | Аллергия — гиперчувствительность I типа | METHOD | Реакция гиперчувствительности тип I (немедленная): 1-я воздействие → IgE → Fc-εRI на тучных клетках. 2-я воздействие → сшивание IgE → дегрануляция → гистамин, лейкотриены, простагландины. Клиника: аллергический ринит, крапивница, анафилаксия. Лечение: антигистамины (H1), эпинефрин (анафилаксия). SCIT (allergen immunotherapy). | Аллергия → Th2 управляемый (ИЛ-4, ИЛ-5, ИЛ-13). |
| immunology.ops.sle_autoimmune | СКВ — Патогенез и диагностика | METHOD | Системная красная волчанка (СКВ): аутоантитела к ядерным антигенам. ANA (antinuclear antibody): скрининг (чувствительность 95%). Anti-dsDNA: специфичность 95%, коррелирует с активностью. Anti-Sm: специфичный. Диагностика: ACR/EULAR 2019 критерии (≥10 баллов). Критерии органных поражений: почки, кожа, сустав, серозит, ЦНС. C3/C4 снижение = комплемент потребляется. | Люпус-нефрит: наиболее тяжёлое осложнение. Anti-dsDNA + ↓C3/C4 = обострение. |
| immunology.ops.hiv_immunopathology | ВИЧ — истощение CD4 | METHOD | ВИЧ иммунопатология: HIV-1 gp120 → CD4 + CCR5/CXCR4 рецептор. Вирус в CD4+ T cells → лизис. Прогрессирование: при CD4 <500/мкл — симптомы. <200/мкл = AIDS. Оппортунистические инфекции: PCP (<200), CMV ретинит (<50), MAC (<50). Антиретровирусная терапия (АРТ): сохраняет CD4. HAART цель: вирусная нагрузка <50 копий/мл. | CCR5 ко-рецептор: CCR5-Δ32 мутация → устойчивость к ВИЧ. |
| immunology.ops.transplant_rejection | Отторжение трансплантата — виды | METHOD | Трансплантационное отторжение: Гиперострое (<24 ч): преформированные антитела против HLA/ABO → немедленная тромбоза сосудов. Острое (дни-мес): T cell mediated — иммуносупрессия. Хроническое (месяцы-годы): antibody-mediated (AMR) + fibrosis. Минимизация: HLA matching, иммуносупрессия (такролимус + MMF + стероиды). | DSA (донор-специфические антитела): предиктор хронического AMR. |
| immunology.ops.biologic_mechanisms | Биологические препараты — механизмы | METHOD | Биологические препараты: Anti-TNFα (инфликсимаб, адалимумаб, этанерцепт): ревматоидный артрит, ВЗК, псориаз. IL-6 блокаторы (тоцилизумаб): РА, цитокиновый шторм. IL-17 (секукинумаб): псориаз, анкилозирующий спондилит. IL-23 (устекинумаб, гуселькумаб): псориаз, Крон. Anti-CD20 (ритуксимаб): B-клетки → РА, онкогематология. JAK inhibitors: тофацитиниб → сигнальный каскад. | Screening перед анти-ТНФ: туберкулёз (QuantiFERON), гепатит B. |
| immunology.ops.cytokine_storm | Цитокиновый шторм — Управление | METHOD | Цитокиновый шторм: массивное высвобождение цитокинов → системное воспаление. Причины: сепсис, COVID-19, HLH (hemophagocytic lymphohistiocytosis), CAR-T терапия. Маркеры: ферритин >>1000 нг/мл, IL-6 ↑↑, CRP ↑↑. Лечение: тоцилизумаб (анти-IL-6R), кортикостероиды (дексаметазон). HLH: анакинра (анти-IL-1). | COVID-19 + цитокиновый шторм: поздняя фаза (не ранняя — вирусная). |
| immunology.ops.oral_tolerance | Пероральная толерантность — механизмы | METHOD | Оральная толерантность: антигены из пищи не вызывают иммунный ответ (обычно). Механизмы: анергия + супрессорные T cells (Treg). Нарушение: целиакия (глютен + HLA DQ2/DQ8 → реакция). Peanut oral immunotherapy (OIT): индуцировать толерантность к арахису. Аллерготерапия SCIT: анти-IgE + shift Th2 → Th1 + Treg. | Hygiene hypothesis: меньше инфекций → больше аллергий (недостаточная иммунная «тренировка»). |
| immunology.ops.secondary_immunodeficiency | Вторичный иммунодефицит — причины | METHOD | Вторичный иммунодефицит: ВИЧ (CD4 depletion). Иммуносупрессивные препараты (стероиды, циклоспорин). Малигнизация (CLL, лимфома). Трансплантация. Диабет. Недоедание (особенно Zn, Se, вит.А, D). Лучевая терапия. Сплен эктомия: риск капсулированных бактерий (Streptococcus, Haemophilus). | Аспления: профилактические вакцины (Pneumovax, Menactra, Hib) + антибиотики. |
| immunology.ops.vaccines_adjuvants | Вакцины — типы адъювантов | METHOD | Вакцинные адъюванты: Alum (квасцы): TLR4-independent, Th2, доминирует. MF59 (Novartis): эмульсия масло/вода, Th1 + Th2, для пожилых (Fluad). AS04 (GSK): MPL+Alum, HBV + HPV вакцины. AS01B: MPL + QS-21, малярийная вакцина RTS,S. AS03: H5N1, COVID. CpG ODN: TLR9 agonist, Heplisav-B. | Адъювант = «danger signal» → усиление врождённого иммунного ответа → лучшее антитело. |
| immunology.ops.regulatory_t_cells | Регуляторные Т-клетки — функция | METHOD | Трегуляторные клетки (Treg): CD4+FoxP3+CD25. Подавляют иммунный ответ: IL-10, TGF-β, CTLA-4. Центральная толерантность (тимус) + периферическая (индуцированная). FoxP3 мутация → IPEX syndrome. Опухоль: Treg инфильтрирует → иммунная ускользание. Anti-PD1/PD-L1: снимает PD-L1 ингибирование на T cells → иммунотерапия рака. | Treg в опухолях: мишень иммунотерапии (но осторожно: аутоиммунность). |
| immunology.ops.eosinophil_mechanisms | Эозинофилы — механизмы | METHOD | Эозинофилы: гранулярные лейкоциты. Медиаторы: MBP, ECP, EDN (токсичны для гельминтов + эпителия). Рекрутирование: IL-5 (ключевой хемокин). Гиперэозинофилия (>1500/мкл): аллергии, гельминтоз, HES (идиопатический), CEL. Целевая терапия: меполизумаб (анти-IL-5) для тяжёлой астмы + HES. | Белки эозинофильных гранул = токсичны для эпителия верхних путей → ремоделирование астмы. |
| immunology.ops.b_cell_lymphocyte | B-клетка — реакция зародышевого центра | METHOD | B-клетки: наивные B cells → активация в лимфатических узлах → центры зародышей (germinal centers). Соматическая гипермутация: повышает аффинность антитела. Переключение класса: IgM → IgG/IgA/IgE. Плазматические клетки: продуцируют антитела. Память B cells: быстрый вторичный ответ. | Т-зависимые против Т-независимых антигенов: полисахаридные антигены = Т-независимые (нет переключения класса, нет памяти → проблема у детей). |

| immunology.ops.checkpoint_inhibitors | Ингибиторы контрольных точек — побочные эффекты | METHOD | Ингибиторы иммунных контрольных точек: PD-1/PD-L1 (ниволумаб, пембролизумаб, атезолизумаб).
