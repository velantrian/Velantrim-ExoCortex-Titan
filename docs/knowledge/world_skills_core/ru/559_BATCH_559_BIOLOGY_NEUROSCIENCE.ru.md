| biology.neuroscience.neuron_types | Типы нейронов и глия | VARIANT | Пирамидальные (глутамат, кора — 70%), веретеновидные, Пуркинье (мозжечок, ГАМК), дофаминергические (чёрная субстанция, вентральная покрышка). | biology.neuroscience.resting_potential | Потенциал мембраны покоя | INVARIANT | −70 мВ, поддерживается Na⁺/K⁺-АТФазой (3Na⁺ out, 2K⁺ in) и K⁺-каналами утечки. Уравнение Гольдмана-Ходжкина-Катца (GHK): учитывает проницаемости для Na⁺, K⁺, Cl⁻. | При повышении внеклеточного K⁺ (судороги, эпилепсия) Vm деполяризуется → нейроны гипервозбудимы. |
| biology.neuroscience.synaptic_plasticity_ltd | LTP & LTD — Хеббианская пластичность | INVARIANT | LTP (долговременная потенциация): сильная стимуляция → Ca²⁺ через NMDA → CaMKII → фосфорилирование AMPA-рецепторов → больше в мембрану → усиление синапса. LTD (депрессия): слабая/длительная стимуляция → низкий Ca²⁺ → фосфатазы → эндоцитоз AMPA. | «Cells that fire together, wire together» (Hebb, 1949). LTP — клеточная модель памяти. NMDA-рецептор — молекулярный коинцидентный детектор (требует и глутамат, и деполяризацию). |
| biology.neuroscience.spike_timing | Пластичность, зависящая от времени скачка (STDP) | PROCESS | Временной порядок критичен: пресинаптический спайк ПЕРЕД постсинаптическим (Δt~10-20 мс положительное) → LTP. Пресинаптический ПОСЛЕ постсинаптического (Δt отрицательное) → LTD. S-образная кривая. | Более точная модель, чем частотная. Биологически правдоподобнее для обучения нейросетей. |
| biology.neuroscience.hippocampus_memory | Гиппокамп и эпизодическая память | INVARIANT | Триснаптический контур: энторинальная кора → зубчатая фасция (гранулярные клетки) → CA3 (пирамидные, коллатерали Шаффера) → CA1 → субикулум → обратно в энторинальную кору. | Двустороннее повреждение гиппокампа → антероградная амнезия (пациент H.M., 1953 — не мог запомнить нового, хотя интеллект сохранён). Консолидация памяти во сне: replay в гиппокампе → перенос в кору. |
| biology.neuroscience.place_cells | Размещение ячеек и ячеек сетки | PROCESS | Место-клетки (place cells, гиппокамп): активируются в конкретном месте пространства. Клетки решётки (grid cells, энторинальная кора): гексагональная решётка активации. Нобелевская премия 2014: О'Киф, Мозер, Мозер. | Головное направление (head direction cells), граничные клетки (border cells), скорость (speed cells). Внутренний GPS мозга. |
| biology.neuroscience.vision_retina | Сетчатка и фототрансдукция | PROCESS | Палочки (родопсин, низкий свет, ночь) и колбочки (3 типа: S/M/L — синий/зелёный/красный, день, цвет). Фотон → цис-транс изомеризация ретиналя → активация трансдуцина (G-белок) → фосфодиэстераза → ↓цГМФ → закрытие Na⁺-каналов → гиперполяризация. Усиление: 1 фотон → закрытие 100-300 каналов. | Сетчатка — часть ЦНС (вырост промежуточного мозга). Слои инвертированы (свет проходит через нейроны к фоторецепторам). |
| biology.neuroscience.primary_visual_cortex | Зрительная кора — V1 | INVARIANT | Хьюбел и Визел (Нобелевская премия 1981): простые клетки (ориентационная избирательность — полоска), сложные (движение), гиперсложные (концы линий). Колонки глазодоминантности + ориентационные колонки → гиперколонка (1 мм², все ориентации для обоих глаз). | Ретинотопическая карта: соседние точки сетчатки → соседние нейроны V1 (искажённая — фовеа занимает непропорционально много). Критический период (монокулярная депривация → амблиопия). |
| biology.neuroscience.dopamine_pathways | Дофаминовые пути | VARIANT | Нигростриатный (движение — Паркинсон). Мезолимбический (VTA→nucleus accumbens; награда, мотивация, аддикция). Мезокортикальный (VTA→ПФК; когнитивный контроль). Тубероинфундибулярный (гипоталамус→гипофиз; подавление пролактина). | Все наркотики вызывают выброс дофамина в NAc (кокаин — блокатор DAT, амфетамин — обратный транспорт через DAT). Reward prediction error: дофамин кодирует разницу между ожидаемой и полученной наградой (Шульц). |
| biology.neuroscience.fmri_bold | фМРТ и жирный сигнал | METHOD | BOLD (blood oxygenation level dependent): нейронная активность → ↑локальный кровоток → ↑оксигенированного Hb и ↓дезоксиHb (парамагнетик) → ↑сигнал T2*. Гемодинамический ответ запаздывает на ~5 сек. Пространственное разрешение ~2-3 мм. | fMRG — корреляция, не каузация (нейроваскулярное сопряжение). Ограничения: движение, артефакты, статистический порог (multiple comparisons problem), обратное умозаключение (reverse inference). |
| biology.neuroscience.eeg | ЭЭГ и мозговые волны | METHOD | Электрические потенциалы на скальпе от синхронной активности пирамидных нейронов. Ритмы: Дельта (<4 Гц — глубокий сон), Тета (4-8 — медитация, гиппокамп), Альфа (8-12 — расслабленное бодрствование, зрение закрыто), Бета (12-30 — активное), Гамма (>30 — связывание признаков). | ERP (event-related potential): усреднение по многим предъявлениям стимула → компоненты (P300 — новизна, N400 — семантическая неожиданность). Высокое временное (мс), низкое пространственное разрешение. |
| biology.neuroscience.basal_ganglia_loops | Базальные ганглии — выбор действия | PROCESS | Кортико-базальные петли: моторная (движение), окуломоторная (саккады), префронтальная (исполнительные функции), лимбическая (эмоции). Прямой путь (D1-стриосома): растормаживает таламус → облегчает движение. Непрямой (D2-стриосома): тормозит таламус → подавляет движение. | Болезнь Паркинсона: гибель дофаминовых нейронов → гиперактивность непрямого пути (избыточное торможение таламуса → гипокинезия). Глубокая стимуляция мозга (DBS) субталамического ядра → улучшение на 50-70%. |
| biology.neuroscience.cerebellum_motor | Мозжечок — моторное обучение | PROCESS | Кора мозжечка: молекулярный слой, слой Пуркинье (единственный выход коры — ГАМК-ергический, тормозной на глубокие ядра). Параллельные волокна (гранулярные клетки) + лиановидные волокна (нижняя олива — сигнал ошибки). LTD в синапсах параллельные волокна→Пуркинье — основа двигательного обучения. | Мозжечок содержит 80% нейронов мозга в 10% объёма (гранулярные клетки — 50 млрд). Атаксия, дисметрия, интенционный тремор. |
