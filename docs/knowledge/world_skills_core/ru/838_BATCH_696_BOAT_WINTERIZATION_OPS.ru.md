# BATCH 696: Boat Winterization — Marine Storage

**KnowledgeUnits:** 5
**Namespace:** `boatwinter.ops.*`
**Scope:** engine, fuel, plumbing, shrink_wrap, battery, storage, outdrive, trailer

| ID | KnowledgeUnit | Тип | Суть | Практический смысл |
|---|---|---|---|---|
| boatwinter.ops.engine_fogging_oil_spray | Запотевание двигателя — процедура | METHOD | Консервация двигателя туманом масла. Fogging oil spray: через карбюратор/воздухозаборник при работающем двигателе (последние секунды работы — обильно, пока не заглохнет). Для EFI: separate fogging port или через свечные отверстия (прокрутить стартер). Цилиндры: защита от ржавчины во время хранения. Свечи: снять, fog, закрутить обратно. | Без fogging: кольца приржавеют к цилиндрам за зиму. |
| boatwinter.ops.fuel_stabilizer_treatment | Топливо — обработка стабилизатора | METHOD | Обработка топлива для хранения. Marine STA-BIL: добавить в полный бак (предотвращает окисление ethanol phase separation). Запустить двигатель на 10-15 минут (распределить treated fuel по всей системе). Полный бак: меньше воздуха = меньше конденсата. Fuel filter: заменить (грязный + старая вода). E10 ethanol: особенно агрессивен (water absorption, corrosion). Drain carburetor bowls (остаток топлива превращается в лак). | Phase separation: вода + этанол образуют слой на дне бака. |
| boatwinter.ops.plumbing_rv_antifreeze | Сантехника — Антифриз | METHOD | Консервация водяной системы лодки. Слив: бак, водонагреватель (байпас), все краны (открыть). Насос: работать всухую (но не долго). Антифриз: розовый РВ (пропиленгликоль), залить в бачок, прокачать через все краны (пока не пойдёт розовый). Унитаз (голова): смыв антифриза. AC: сторона сырой воды — закачка антифриза через забортный клапан. Краник (забортная арматура): закрыть, слить. | Этилен-гликоль (зелёный) токсичен для морской жизни (запрещён!). |
| boatwinter.ops.outdrive_service_impeller | Выходной привод — осмотр и смазка | METHOD | Обслуживание привода (stern drive). Слить gear oil: проверить на water (молочный цвет) и metal particles. Заменить sealing washers. Новое gear oil: pump через нижнюю пробку (пока не пойдёт из верхней). Gimbal bearing: grease gun. U-joints: grease. Propeller: снять, очистить shaft, grease splines. Anodes (цинки): заменить если изношены >50%. Bellows: проверить на cracks (вода в лодку через порванные bellows). | Gear oil с водой: немедленный ремонт seal. |
| boatwinter.ops.shrink_wrap_frame_support | Термоусадочная пленка — рама и вентиляционное отверстие | METHOD | Укрытие лодки термоусадочной плёнкой. Frame: пластиковые или деревянные дуги (создают tent roof чтобы снег/вода скатывались). Straps: обвязка по периметру (heat-потери (shrink) tape). Shrink: propane heat gun — плёнка усаживается и натягивается. Vents (вентиляционные заслонки): несколько (для выхода влаги, плесень prevention). Access door: zipper для внутреннего доступа. Support: достаточно frame чтобы выдержать снеговую нагрузку. | Запаянная без вентиляции: конденсат внутри = плесень весной. |
