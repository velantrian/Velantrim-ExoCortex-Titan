| agriculture.soil_texture | Текстура почвы и треугольник | INVARIANT | Песок (0.05-2 мм), ил/пыль (0.002-0.05 мм), глина (<0.002 мм). Треугольник текстур (USDA). Суглинок (loam) — оптимальное соотношение: 40% песка, 40% ила, 20% глины. | Песок: отличный дренаж, но плохо удерживает воду и питательные вещества. Глина: отлично удерживает, но плохой дренаж, тяжела для обработки. Суглинок — золотая середина. |
| agriculture.cation_exchange | Катионообменная емкость (CEC) | INVARIANT | Способность почвы удерживать катионы (Ca²⁺, Mg²⁺, K⁺, NH₄⁺). Выражается в мэкв/100 г. Гумус CEC ~200, глина ~20-60, песок <5. Высокий CEC = плодородная почва (буфер питательных веществ). | Известкование кислых почв: CaCO₃ → Ca²⁺ вытесняет H⁺ и Al³⁺ с обменных позиций → повышение pH. Гипсование щелочных: CaSO₄ → Ca²⁺ вытесняет Na⁺. |
| agriculture.soil_ph | pH почвы и доступность питательных веществ | VARIANT | Оптимум для большинства культур: pH 6.0-7.0. При pH<5.5: доступность Al³⁺ (токсичен), Mn²⁺; дефицит P, Ca, Mg. При pH>7.5: дефицит Fe, Mn, Zn, Cu (карбонаты связывают). | pH влияет на доступность ВСЕХ элементов. Кислые почвы → известкование (CaCO₃, CaMg(CO₃)₂ — доломит). Щелочные → гипсование, внесение серы (S → H₂SO₄ бактериями). |
| agriculture.npk_fertilizer | NPK — Первичные Макронутриенты | INVARIANT | Азот N (рост, зелёная масса, белки — мочевина/карбамид CO(NH₂)₂ 46% N, аммиачная селитра), Фосфор P (корни, цветение, АТФ — суперфосфат, аммофос), Калий K (водный баланс, устойчивость к болезням — KCl, K₂SO₄). | Симптомы дефицита: N — хлороз старых листьев (мобильный), P — пурпурное окрашивание, K — краевой ожог листьев. Закон минимума Либиха: рост ограничен элементом в наименьшем количестве. |
| agriculture.fertilizer_application | Способы внесения удобрений | METHOD | Основное (перед посевом, заделка в почву), припосевное (рядковое — стартовая доза, на 2-3 см сбоку и глубже семян), подкормка (в период вегетации: разбросная, листовая — микроэлементы). | Precision agriculture: картограммы содержания элементов → дифференцированное внесение (VRT — Variable Rate Technology). Экономия удобрений 15-25%. |
| agriculture.irrigation_methods | Методы орошения | VARIANT | Поверхностная (по бороздам, полосам — КПД 50-60%), дождевание (спринклеры — 75-85%), капельное (эмиттеры — 90-95%, вода под корень, минимальное испарение), подпочвенное (капиллярное увлажнение). | Капельное орошение (Израиль, Netafim): экономия воды до 50%, повышение урожайности, фертигация (удобрения с поливной водой). |
| agriculture.evapotranspiration | Эвапотранспирация (ET) | VARIANT | ET = испарение с почвы + транспирация (растение). ET₀ — эталонная эвапотранспирация (по Пенману-Монтейту, FAO-56). ETc = ET₀ × Kc (культурный коэффициент, меняется по фазам роста). | Поливная норма = ETc − эффективные осадки. Датчики влажности почвы: тензиометры (давление всасывания, кПа), TDR/FDR (объёмная влажность). |
| agriculture.crop_rotation | Преимущества севооборота | METHOD | Чередование культур: азотфиксаторы (бобовые → соя, люцерна, клевер — N₂→NH₃ через симбиоз с Rhizobium) → азотпотребители (кукуруза, пшеница). Разрыв циклов вредителей и болезней. Разные корневые системы → структура почвы. | Культуры-сидераты (зелёное удобрение: горчица, редька масличная, фацелия) → запахиваются в почву → органика + подавление нематод и сорняков. |
| agriculture.integrated_pest_management | Комплексная борьба с вредителями (IPM) | METHOD | Мониторинг → экономический порог вредоносности → профилактика (севооборот, устойчивые сорта) → биологический контроль (энтомофаги: божьи коровки, златоглазки, трихограмма) → химический (пестициды — ПОСЛЕДНЕЕ средство, селективные, ротация групп для предотвращения резистентности). | Bacillus thuringiensis (Bt) — биопестицид: Cry-токсины, специфичные для гусениц чешуекрылых, безопасны для человека/пчёл. Bt-культуры (ГМО) — экспрессируют Cry-белки. |
| agriculture.plant_photosynthesis_c3_c4 | C3 против C4 против CAM-заводов | VARIANT | C3 (рис, пшеница, соя): RuBisCO фиксирует CO₂ → 3-фосфоглицерат (3С), фотодыхание (потери до 30% при жаре). C4 (кукуруза, сорго, сахарный тростник): пространственное разделение → PEP-карбоксилаза (сродство к CO₂ выше) → концентрация CO₂ в обкладке пучка → нет фотодыхания, эффективнее при высоких T и освещённости. CAM (кактусы, ананас): временное разделение (CO₂ ночью). | C4 растения дают урожай на 50% выше при тех же затратах воды. Ожидаемый сдвиг ареалов с глобальным потеплением. |
| agriculture.animal_digestive_systems | Жвачные против моногастрального пищеварения | VARIANT | Жвачные (коровы, овцы, козы): рубец (ферментация целлюлозы симбиотическими бактериями → летучие жирные кислоты: ацетат, пропионат, бутират), сетка, книжка, сычуг (истинный желудок). Моногастричные (свиньи, птица): простой желудок, ферментативное переваривание, не могут переваривать целлюлозу. | Корова: 1 кг концентратов → ~2 л молока (эффективная конверсия грубых кормов в белок). Курица: конверсия корма 1.6-1.8:1 — самая эффективная в животноводстве. |
| agriculture.cattle_breeding_index | Индексы селекции и геномика | METHOD | EBV (Estimated Breeding Value) — оценка племенной ценности по данным родословной и фенотипа. Признаки: надой молока, жир/белок, конверсия корма, устойчивость к маститу, плодовитость. | Геномная селекция сократила интервал поколения с 5-7 до 2 лет (бык может быть оценён при рождении, не дожидаясь потомства). |
