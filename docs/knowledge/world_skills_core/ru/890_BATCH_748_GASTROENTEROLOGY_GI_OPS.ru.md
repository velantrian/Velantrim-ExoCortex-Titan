# BATCH 748: Gastroenterology — GI Diagnosis & Management

| gastro.ops.gerd_diagnosis | ГЭРБ — Диагностика и лечение | METHOD | ГЭРБ (гастроэзофагеальная рефлюксная болезнь): Типичные: изжога, регургитация. Атипичные: кашель, дисфония, боли в груди. LINX/pH мониторинг: 24-ч. PPI тест (empiric): диагностический инструмент. Лечение: PPI 8 нед (первый эпизод). Long-term: ступенчатое снижение. ALARM симптомы: дисфагия, кровотечение, потеря веса → эндоскопия срочно. | Барретт пищевода: риск аденокарциномы. Скрининг при ГЭРБ >5 лет. |
| gastro.ops.upper_endoscopy | Верхняя эндоскопия — ФГДС | METHOD | Эзофагогастродуоденоскопия (ВЭГДС): показания — диспепсия при высоком риске (>45 лет или ALARM), дисфагия, кровотечение, Barrett мониторинг. Препарат: NPO 6 ч (жидкость 2 ч). Аппарат: гибкий эндоскоп. Биопсия: из подозрительных зон + Helicobacter pylori (antrum и тело). Seattle протокол для Barrett's. Ретрофлексия: осмотр дна желудка. | Эндоскопия при желудочном кровотечении: в течение 24 ч (острое кровотечение). |
| gastro.ops.h_pylori_testing | H. pylori — тестирование и искоренение | METHOD | Helicobacter pylori: тесты — Urea Breath Test (UBT): чувствительность 95%+ (неинвазивный, для контроля излечения). Stool Antigen Test (SAT): дешевле. Биопсия (EGD): с быстрым уреазным тестом (CLO). Серология: не для подтверждения ликвидации. Лечение (1-я линия): PPI + кларитромицин + амоксициллин × 14 дней. Квадротерапия при резистентности. | Тест на контроль: ≥4 нед после окончания лечения, >2 нед после PPI. |
| gastro.ops.colonoscopy_quality | Колоноскопия — показатели качества | METHOD | Качественные показатели колоноскопии: Частота обнаружения аденомы (ADR): ≥25% (мужчины ≥30%). Частота интубации слепой кишки (CIR): ≥95%. Время вывода: ≥6 мин. Бостонская шкала подготовки кишечника (BBPS): ≥6 (2+ в каждом сегменте). Обнаружение полипа. Скорость перфорации: <1/500. | ADR: лучший предиктор предотвращения смерти от колоректального рака. |
| gastro.ops.ibd_differentiation | ВЗК — ЯК против Крона | METHOD | ВЗК (воспалительные заболевания кишечника): UC (язвенный колит): только толстая кишка, непрерывное поражение, начинается с прямой кишки. Крон: любой отдел ЖКТ, трансмуральный, «скипы», гранулёмы. Различие: рентгенография (шнур — Crohn, кобровий «cobblestone»). Гистология: гранулёмы = Crohn. | Внекишечные проявления (ЭИМ): оба — артрит, увеит, ПЭ. PSC ассоциирован с UC. |
| gastro.ops.crohns_biologics | Болезнь Крона — биологическое лечение | METHOD | Биологическое лечение Крона: Anti-TNF (инфликсимаб, адалимумаб): 1-я линия. Anti-integrin (ведолизумаб): кишечно-селективный. Anti-IL-12/23 (устекинумаб). JAK inhibitors (тофацитиниб для UC). Комбинированная терапия: биологик + иммуносупрессант = снижение иммуногенности. Therapeutic drug monitoring (TDM): уровень инфликсимаба >5 мкг/мл = терапевтический. | Потеря ответа (LOR): высокий IFX trough = mechanistic failure. Низкий + антитела = иммуногенность. |
| gastro.ops.uc_surveillance | UC — наблюдение за дисплазией | METHOD | Скрининг дисплазии при UC: Начало скрининга: через 8-10 лет после диагноза (если паннолит). Хромоэндоскопия (dye-spray) + прицельная биопсия: предпочтительнее случайных биопсий. WLE (White Light Endoscopy) + случайные: альтернатива. PSC ассоциированная UC: ежегодный контроль с момента диагноза. Дисплазия HGD: колэктомия. | «Invisible dysplasia» — случайная биопсия может найти то чего не видно. |
| gastro.ops.ascites_management | Асцит — классификация и лечение | METHOD | Асцит при циррозе: Grade 1 (только на УЗИ), Grade 2 (умеренный, symmetrical), Grade 3 (массивный, тension). Лечение: ограничение соли (88 мэкв/день), диуретики (спиронолактон 100 + фуросемид 40). LVP (large volume paracentesis): при рефрактерном (>5 л, альбумин 6-8 г/L). TIPS (трансъюгулярный шунт): при рефрактерном. | SBP (спонтанный бактериальный перитонит): PMN >250 кл/мм³ в асцитной жидкости → ципрофлоксацин/цефотаксим. |
| gastro.ops.liver_disease_childs | Заболевания печени — шкала Чайлд-Пью | METHOD | Оценка функции печени (Child-Pugh): Билирубин (<2/2-3/>3), Альбумин (>3.5/2.8-3.5/<2.8), PT/INR (<1.7/1.7-2.3/>2.3), Асцит (нет/лёгкий/выраженный), Энцефалопатия (нет/I-II/III-IV). А (5-6): хорошая функция. В (7-9): умеренная. С (10-15): плохая. MELD (Model for End-Stage Liver Disease): для листа ожидания трансплантации. | MELD-Na: более точный чем MELD (включает Na). |
| gastro.ops.acute_pancreatitis | Острый панкреатит — степень тяжести | METHOD | Острый панкреатит: Revised Atlanta 2012: лёгкий (нет органной недостаточности), средне-тяжёлый (транзиторная недостаточность), тяжёлый (стойкая). Ranson's criteria (первые 48 ч). BISAP score. Лечение: agressive IV fluids (Ringer's lactate 250-500 мл/ч, 1-2 л болюс). NPO → энтеральное питание рано (в течение 24-48 ч). | Агрессивная инфузия первые 24 ч: снижает некроз и осложнения. |
| gastro.ops.gib_rockall_score | Желудочно-кишечное кровотечение — оценка Роколла | METHOD | Желудочно-кишечное кровотечение (Rockall Score): до/после эндоскопии. Параметры: возраст, наличие шока, сопутствующие заболевания, диагноз, стигмата кровотечения при эндоскопии. ≤2 = низкий риск. ≥5 = высокий. Glasgow-Blatchford: для тактики (выписка или госпитализация). | Активное кровотечение: PPI + эндоскопическая гемостаз + госпитализация. |
| gastro.ops.celiac_disease | Целиакия — протокол тестирования | METHOD | Целиакия: IgA тТГ (tissue transglutaminase): скрининговый. При положительном → биопсия тонкой кишки (Marsh grade III-IV). IgA дефицит: 2-3% → IgG based tests. HLA DQ2/DQ8: 99%+ у целиакии (но и у 35% общего населения). Безглютеновая диета: перед тестами НЕ начинать (ложноотрицательный). | Безглютеновая диета: нужна пожизненно. |
| gastro.ops.functional_dyspepsia | Функциональная диспепсия — Рим IV | METHOD | Функциональная диспепсия (Rome IV): PDS (Postprandial Distress Syndrome): раннее насыщение, постпрандиальная полнота. EPS (Epigastric Pain Syndrome): боль/жжение эпигастрия. PDS + EPS: перекрытие. Исключить органическую (ВЭГДС). Лечение: прокинетики (при PDS), PPI (при EPS), антидепрессанты низкие дозы, диета. | Совпадение с ГЭРБ и СРК: частое явление (расстройство оси мозг-кишечник). |
| gastro.ops.liver_biopsy_fibrosis | Фиброз печени — неинвазивный | METHOD | Неинвазивная оценка фиброза печени: FIB-4 index = (age × AST) / (platelets × √ALT). <1.3 = низкий фиброз. >2.67 = высокий. Эластография (FibroScan): кило-паскали. F0-F1 <7.1, F2 7.1-9.4, F3 9.5-12.4, F4 (цирроз) >12.5. NAFLD Fibrosis Score. Биопсия: при неопределённости. | VCTE (транзиентная эластография, контролируемая вибрацией): FibroScan. Пункт АРФИ: альтернатива. |
| gastro.ops.hepatitis_c_treatment | Гепатит С — лечение ПППД | METHOD | Лечение ГС (противовирусные препараты прямого действия): УВО (устойчивый вирусологический ответ) = излечение. Пангенотипический: Софосбувир/Велпатасвир (Эпклюза) × 12 нед = >95% УВО в большинстве случаев. Глекапревир/Пибрентасвир (Мавирет) × 8 нед (без цирроза). Ингибиторы NS5A + NS5B + NS3. Генотипирование перед лечением (старые режимы). Скрининг: все взрослые ≥18 лет минимум 1 раз. | ГС — излечим! Единственная хроническая вирусная инфекция с 95%+ cure rate. |
| gastro.ops.polyp_classification | Полипы толстой кишки — Парижская классификация | METHOD | Классификация полипов Парижа: Тип 0 (плоские и слегка выступающие). 0-Ip (педункулированный). 0-Is (сессильный). 0-IIa (слегка приподнятый). 0-IIb (плоский). 0-IIc (слегка вогнутый). 0-III (язвенный). | gastro.ops.eosinophilic_esophagitis | ЭоЭ — Диагностика и лечение | METHOD | Эозинофильный эзофагит: дисфагия (мужчины, молодые). Биопсия: ≥15 эозинофилов/hpf (после PPI). | gastro.ops.ibs_rome_criteria | IBS — Римские критерии IV | METHOD | Синдром раздражённого кишечника (Rome IV): боль в животе ≥1 день/нед × 3 мес + ≥2 из: связана с дефекацией, изменение частоты стула, изменение консистенции.
