| mediaprod.ops.script_coverage_format | Сценарий — отраслевой охват | METHOD | Coverage (скрипт-ридерский отчёт): Logline (1-2 предложения), Synopsis (1/2-1 страница), Comments (2-3 стр), Recommendations: Consider/Pass/Recommend. | mediaprod.ops.camera_exposure_triangle | Камера — Треугольник экспозиции | METHOD | Треугольник экспозиции: ISO × Aperture (f-stop) × Shutter speed. ISO: чувствительность (↑ISO = ↑шум). Aperture: f/2.8 = широко (мало ГРИП, много света), f/16 = узко (большая ГРИП, мало света). Shutter speed: 180° rule (кино) = 1/(2×fps): 24fps → 1/48 сек. ND filter: снижает свет без изменения aperture/shutter. | Гиперфокус: расстояние при котором всё от f/2 до ∞ в фокусе. |
| mediaprod.ops.three_point_lighting | Трехточечное освещение — настройка | METHOD | Трёхточечное освещение: Key light (основной): сильнейший источник, 45° по горизонтали, 45° по вертикали. Fill light (подсветка): снижает тени от key (0.5-1 ступень ниже key, с противоположной стороны). Back light/Hair light: выделяет субъект от фона. Lighting ratio: 3:1 (умеренный контраст), 8:1 (драматический). | Rembrandt lighting: key light под углом → треугольный «блик» под глазом. |
| mediaprod.ops.audio_boom_placement | Звук производства — размещение стрелы | METHOD | Микрофон-журавль (boom): тип — hypercardioid или shotgun. Room tone: запись тишины для монтажа. Wireless lavalier (петличный): backup, скрыть под одеждой (rustle protection). | Dead Cat (windscreen): для съёмок на ветру (внешний windscreen). |

EDL (Редактировать список решений) или AAF/XML: связь между оффлайн и онлайн. Онлайн-соответствие: высококачественный исходник (RAW, 4K+). Цветокоррекция (DaVinci Resolve). Звуковой микс. | mediaprod.ops.color_grading_lut | Цветокоррекция — приложение LUT | METHOD | Цветокоррекция: LUT (Справочная таблица) = цветовое преобразование. ACES (Академическая система кодирования цветов): стандартный конвейер. DCI-P3, Rec.709, HDR Rec.2020: пространство отображения. | Первичная коррекция: баланс белого, экспозиция. | mediaprod.ops.vfx_compositing_workflow | VFX — конвейер композитинга | METHOD | Визуальные эффекты: Live Action + CGI → композитинг (After Effects, Nuke). Хромакей (зеленый экран): зелёный фон → → удалить фон заменить. Ротоскопирование: ручная маска вокруг объекта. Отслеживание движения: CG следует за камерой. Движение матча: 3D-камера = настоящая камера. Соответствие цветов: элементы CGI = яркая съёмка. 2D и 3D-композитинг. | Освещение зеленого экрана: равномерный фон (нет тени) + отдельно освещенный актер. |
