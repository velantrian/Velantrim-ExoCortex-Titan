# BATCH 799: Human Physiology — Systems Review

| physiology.ops.cardiac_output | Сердечный выброс — Старлинг и Фик | METHOD | Сердечный выброс: CO = HR × SV. HR (ЧСС): симпатический → ↑, парасимпатический → ↓. SV (ударный объём): определяется преднагрузкой, контрактильностью, постнагрузкой. Закон Франка-Старлинга: ↑ растяжение миокарда → ↑ сила сокращения. Метод Фика: CO = VO2 / (Ca O2 - Cv O2). | Сердечная недостаточность: снижение CO → компенсаторная активация RAS + SNS. |
| physiology.ops.blood_pressure_regulation | Артериальное давление — барорецепторный рефлекс | METHOD | Регуляция АД: Барорецепторы (каротидный синус, дуга аорты) → ЦНС. При ↑ АД: вагус ↑ → ЧСС ↓ + СВ ↓. РААС: AngII → вазоконстрикция + альдостерон + жажда. Autoinhibition: гладкая мышца сосудов. Основная формула: MAP = CO × TPR. MAP = DBP + 1/3(PP). | MAP < 65: тканевая гипоперфузия. |
| physiology.ops.lung_surfactant | Дыхательная система — поверхностно-активное вещество | METHOD | Лёгочный сурфактант (DPPC, дипальмитоилфосфатилхолин): снижает поверхностное натяжение в альвеолах. Закон Лапласа: P = 2T/r → малые альвеолы без сурфактанта бы коллапсировали. Синтезируется пневмоцитами II типа. Дефицит: РДСН (у недоношенных). Alveolar stability: surfactant + interdependence. | RDS лечение: экзогенный сурфактант (берактант, кальфактант). |
| physiology.ops.renal_gfr | Почки — Регуляция СКФ | METHOD | GFR (клубочковая фильтрация): norma 125 мл/мин. GFR = Kf × (Pgc - Pbs - πgc). Авторегуляция: миогенный рефлекс + тубулогломерулярная обратная связь. Ангиотензин II: сужение эфферентных артериол → сохраняет GFR. При ↓ объёма: AngII → сужает эфферентные. NSAID блокируют простагландины → нет вазодилатации afferents. | ИАПФ/БРА при ХБП: снижают GFR краткосрочно но замедляют прогрессирование. |
| physiology.ops.hormonal_negative_feedback | Эндокринная система — отрицательная обратная связь | METHOD | Гипоталамо-гипофизарная ось: Hypothalamus → трофные гормоны (TRH, CRH, GnRH, GHRH) → Ant.Pituitary → TSH, ACTH, LH/FSH, GH → Target glands → T3/T4, cortisol, sex steroids, IGF-1 → отрицательная обратная связь на гипоталамус и гипофиз. Исключения: LH surge (положительная обратная связь эстрогена). | Положительная обратная связь редко: у пациентов во время овуляции и родов (окситоцин). |
| physiology.ops.action_potential | Потенциал действия — нейронный | METHOD | Потенциал действия: фазы. Resting potential: -70 мВ. Деполяризация: Na+ influx (voltage-gated). Peak: +30 мВ. Реполяризация: K+ efflux. После-гиперполяризация. Абсолютный рефрактерный период: нет следующего AP. Относительный: нужен более сильный стимул. Скорость: диаметр + миелинизация (saltatory conduction). | Нодовый токовый ток (сальтаторный): А-волокно 70-120 м/с, С-волокно (немиелинизированное) 0,5-2 м/с. |
| physiology.ops.muscle_cross_bridge | Скелетные мышцы — езда на велосипеде с поперечным мостом | METHOD | Перекрёстный цикл мышечного сокращения: Ca2+ выходит из SR → Ca2+ + Tn C → снятие торможения → актин + миозин (cross-bridge). ATP → ADP + Pi + power stroke. Pi высвобождение → силовой удар. ADP высвобождение. Новый ATP разрывает связь. Rigor mortis: нет ATP → постоянные cross-bridges. | Экскуляция-сокращение (связка E-C): Т-трубочки → RyR → высвобождение Ca²⁺. |
| physiology.ops.acid_base_henderson | Кислотно-основное — Хендерсон-Хассельбальх | METHOD | Кислотно-основное равновесие: pH = pKa + log([A⁻]/[HA]). Bicarbonate: pH = 6.1 + log([HCO3⁻] / 0.03 × pCO2). Нормальные значения: pH 7.35-7.45, pCO2 35-45 мм рт.ст., HCO3- 22-26 мэкв/л. Компенсация: respiratory (быстрая, мин-часы), metabolic (медленная, дни). | Правило Винтера: ожидаемый pCO2 при метаб.ацидозе = 1.5 × HCO3- + 8 ± 2. |
| physiology.ops.gi_motility_gastrin | Физиология ЖКТ — Гастрин | METHOD | Желудочно-кишечная физиология: Гастрин (G-клетки антрума): стимулируется белком + pH > 3, ингибируется pH < 2 (отрицательная обратная связь). Секретин (S-клетки дуоденума): кислота → бикарбонат из поджелудочной железы. CCK (I-клетки): жиры/белки → желчь + ферменты ПЖ. GIP: глюкоза → инсулин. | Мигрирующий миоэлектрический комплекс (MMC): «чистильщик» → между приёмами пищи. |
| physiology.ops.thermoregulation_sweat | Терморегуляция — Гипоталамус | METHOD | Терморегуляция: гипоталамус = «термостат». Перегрев: вазодилатация + потоотделение (эккринные железы, вода + NaCl). Охлаждение: вазоконстрикция + дрожь (термогенез) + НЖТ (некрожжевой термогенез — norэпинефрин + бурая жировая). Пироген: IL-1, TNF, PGE2 → сброс термостата вверх. | PGE2 блокируется NSAID (жаропонижающий механизм). |
| physiology.ops.renin_angiotensin | РААС — Ренин-Ангиотензин-Альдостерон | METHOD | РААС: снижение АД / NaCl в мактула денса → ренин (юкстагломерулярные клетки) → ангиотензиноген → Ang I → ACE (лёгкие) → Ang II. Ang II: вазоконстрикция + альдостерон + АДГ. Альдостерон: ↑ Na реабсорбция (дистальный тубул/собирательная трубочка) → ↑ ОЦК → ↑ АД. | Conn Syndrome: первичный гиперальдостеронизм = гипертензия + гипокалиемия + ↓ ренин. |
| physiology.ops.reproductive_menstrual | Менструальный цикл — фазы | METHOD | Менструальный цикл (28 дней): Фолликулярная фаза (1-14): FSH → рост фолликулов → ↑ эстроген → пик LH → овуляция. Лютеальная фаза (15-28): LH → жёлтое тело → прогестерон + эстроген. Нет беременности → регрессия ЖТ → ↓ прогестерон → менструация. | Базальная температура тела: повышается после овуляции (прогестерон). |
| physiology.ops.pulmonary_ventilation | Вентиляция-Перфузия — V/Q | METHOD | Вентиляция/перфузия: нормальное V/Q = 0.8. Верхушки лёгких: V/Q > 1 (вентиляция > перфузия). Основания: V/Q < 1. V/Q = ∞: мёртвое пространство (нет перфузии). V/Q = 0: шунт (нет вентиляции). Shunt: нет ответа на 100% O2 (vs high V/Q). | Pulmonary embolism: V/Q mismatch (нет перфузии при сохранённой вентиляции). |
| physiology.ops.sodium_reabsorption | Почечный натрий — сегменты | METHOD | Реабсорбция Na+ в нефроне: проксимальный каналец 65% (Na+/H+ exchanger, cotransporters). Петля Генле (восходящее толстое колено) 25% (NKCC2, блокируется фуросемидом). Дистальный каналец 5% (NCC, блокируется тиазидами). Собирательная трубочка 3-5% (ENaC, регулируется альдостероном, спиронолактон). | Место действия диуретиков: фуросемид (петля), тиазид (дистальный), спиронолактон (собирательная). |
| physiology.ops.blood_coagulation | Коагуляция — Каскады | METHOD | Каскад свёртывания крови: Внутренний (XII → XI → IX → X). Внешний (VII + Тканевой фактор → X). Часто: X + V → тромбин (IIa). Тромбин → фибриноген → фибрин. Витамин К-зависимые: II, VII, IX, X. Антагонист витамина К: варфарин (↑ PT). Гепарин: активирует антитромбин III (↑ АЧТВ). | ПТ (МНО): внешний путь (мониторинг Варфарина). АЧТВ: внутренний путь (мониторинг гепарина). |
| physiology.ops.erythropoiesis | Красные кровяные тельца — эритропоэз | METHOD | Эритропоэз: гипоксия → почки → ЭПО → стволовые клетки КМ → RBC. Кобальт: индуцирует ЭПО. Созревание RBC: 7 дней в КМ → ретикулоциты → выход в кровь. Нормальная продолжительность жизни RBC: 120 дней. Разрушение: ретикулоэндотелиальная система (селезёнка, печень). | ЭПО: применяется при анемии ХПБ, онкология. |
| physiology.ops.exercise_physiology | Упражнения — сердечно-сосудистая реакция | METHOD | Физиология упражнений: при нагрузке: CO ↑ (ЧСС + СВ), BP умеренно. VO2max: максимальная аэробная способность. Во время нагрузки: кровоток к мышцам ↑ (60-85% CO), кожа ↑. Местная регуляция: CO2, K+, лактат, H+, аденозин → вазодилатация мышц. | VO2max: 3.5 мл/кг/мин (1 MEТ) в покое. Тренированные спортсмены: 70-80 мл/кг/мин. |
| physiology.ops.sleep_physiology | Сон — этапы ЭЭГ | METHOD | Физиология сна: NREM (1-3): N1 (переход, тета-волны), N2 (К-комплексы, sleep spindles), N3 (дельта-волны, глубокий). REM: быстрые движения глаз, потеря мышечного тонуса, сны. Цикл: 90 мин. First half: больше N3. Second half: больше REM. | Аденозин: накапливается при бодрствовании → «давление сна». Кофеин блокирует аденозиновые рецепторы. |
| physiology.ops.immune_lymphocyte | Лимфоидная система — первичная и вторичная | METHOD | Лимфоидные органы: Первичные: тимус (T-клетки развиваются + селекция) и костный мозг (B-клетки, NK). Вторичные: лимфоузлы, селезёнка, Пейеровы бляшки, MALT. Лимфатические узлы: фильтрация лимфы + встреча антигена и наивных лимфоцитов. | Центральная толерантность: в тимусе удаляются аутореактивные T-клетки (негативная селекция). |
