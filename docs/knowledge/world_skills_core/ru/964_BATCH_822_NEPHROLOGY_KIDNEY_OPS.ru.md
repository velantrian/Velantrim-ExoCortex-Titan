| nephrology.ops.ckd_staging | CKD — Классификация G&A | METHOD | Хроническая болезнь почек (ХБП): Стадии по GFR (G1-G5) + Альбуминурия (A1-A3). G1: ≥90 (с маркерами повреждения). G2: 60-89. G3a: 45-59. G3b: 30-44. G4: 15-29. G5: <15. A1 (<30 мг/г), A2 (30-300), A3 (>300). G4A3: очень высокий риск прогрессирования. | Причина ХБП #1: диабет. #2: гипертония. Почечная биопсия: при неясной этиологии. |
| nephrology.ops.aki_criteria | ОПП — Критерии KDIGO | METHOD | Острое почечное повреждение (ОПП): KDIGO 2012 критерии: SCr ↑0.3 мг/дл за 48 ч ИЛИ SCr ×1.5 от baseline за 7 дней ИЛИ мочевой диурез <0.5 мл/кг/ч × 6 ч. Стадии 1-3. Причины: преренальные (гиповолемия), ренальные (ATN, нефриты), постренальные (обструкция). | ATN: наиболее частое ренальное ОПП (токсины, ишемия). Гранулярные цилиндры. |
| nephrology.ops.nephrotic_vs_nephritic | Нефротический против нефритического — особенности | METHOD | Нефротический синдром: протеинурия >3.5 г/день, гипоальбуминемия (<25 г/л), отёки, гиперлипидемия. Причины: нефропатия с минимальными изменениями (#1 у детей), FSGS, мембранозная (#1 у взрослых). Нефритический синдром: гематурия (акантоциты), цилиндры, гипертония, лёгкая протеинурия. Причины: IgA-нефропатия, постстрептококковый, ANCA-васкулит. | Отёки при нефрозе: гипоальбуминемия → ↓онкотическое → отёк. |
| nephrology.ops.iga_nephropathy | IgA-нефропатия — лечение | METHOD | ИгА-нефропатия (болезнь Берже): наиболее частый первичный гломерулонефрит. Гематурия (видимая при ОРВИ) + протеинурия. Отложения IgA в мезангии. MEST-C score. Лечение: РААС ингибиторы для ≥всех. Стероиды: при персистирующей протеинурии ≥0.75 г/сут. Спарсентан (новый препарат 2023). | Прогноз: 25-30% → ТПН за 20 лет при неблагоприятных факторах. |
| nephrology.ops.dialysis_adequacy | Гемодиализ — Адекватность | METHOD | Адекватность гемодиализа: Kt/V (уреа кинетика): K × t / V. Цель ≥1.2 (трижды в нед). Длительность: ≥4 ч на сеанс. CQAE (Continuous Quality Assurance): ежемесячная проверка Kt/V. PD (перитонеальный диализ): остаточная почечная функция важна. | Ultrafiltration limit: ≤13 мл/кг/ч (более агрессивная = гипотония). |
| nephrology.ops.hyponatremia_management | Гипонатриемия — коррекция | METHOD | Гипонатриемия (<135 мэкв/л): хроническая vs острая. Осторожная коррекция: не более 10-12 мэкв/л/сут (хроническая). Слишком быстрая: Осмотическая демиелинизация (ОДС). Гипоосмолярная: Euvolemic (SIADH), гиперволемическая (ХСН, цирроз), гиповолемическая (потери). Лечение SIADH: ограничение жидкости, торговтаптан. | 3% NaCl: только при тяжёлой симптоматической гипонатриемии (судороги, угнетение сознания). |
| nephrology.ops.hyperkalemia_management | Гиперкалиемия — неотложная помощь | METHOD | Гиперкалиемия (>5.5 мэкв/л): ЭКГ: острые T-зубцы → синусовый брадикардия → широкие QRS → фибрилляция. Лечение: 1) Ca глюконат 10% 10 мл IV (кардиопротекция, немедленно). 2) Инсулин + глюкоза (K+ в клетки). 3) NaHCO3 (при ацидозе). 4) Петлевые диуретики. 5) Диализ при ТПН. | Не забывать: Ca глюконат = только стабилизирует мембрану, не снижает K+. |
| nephrology.ops.renal_biopsy | Биопсия почки — показания | METHOD | Биопсия почки: показания — нефротический синдром у взрослых, нефритический, ОПП неясной этиологии, ХБП прогрессирующая неустановленной причины. Противопоказания: единственная почка, некоррегированная коагулопатия, поликистоз, гидронефроз. Методика: под УЗИ контролем. Осложнения: кровотечение (5-10%). | LM + IM + EM: три части биопсии при гломерулярной болезни. |
| nephrology.ops.diabetic_nephropathy | Диабетическая нефропатия — стадии | METHOD | Диабетическая нефропатия: Stade I (гиперфильтрация). II (нормоальбуминурия). III (микроальбуминурия 30-300 мг/г). IV (макроальбуминурия, снижение GFR). V (ТПН). Лечение: ИАПФ/БРА + SGLT2i (фарсинра, дапаглифлозин). Контроль АД <130/80. HbA1c <7%. Finerenone: добавка при ХБП + диабет. | SGLT2i: снижают прогрессирование ХБП независимо от HbA1c. |
| nephrology.ops.metabolic_acidosis | Метаболический ацидоз — анионная щель | METHOD | Метаболический ацидоз: AG = Na-(Cl + HCO3) норма 8-12 мэкв/л. Высокий АГ (ГРЯЗИ): метанол, уремия, ДКА, пропиленгликоль, изониазид/железо, молочная кислота, этанол/этиленгликоль, салицилаты. Нормальный АГ (HARDUP): переедание, синдром Аддисона, ДТП, диарея, отведение мочеточника, свищ поджелудочной железы. Дельта-дельта разрыв. | Delta-delta: выявление смешанного расстройства. |
| nephrology.ops.rta_types | Почечный канальцевый ацидоз — типы | METHOD | Почечный тубулярный ацидоз (RTA): Тип I (Distal): нарушение выведения H+ → нет снижения pH мочи (<5.5). Уролитиаз. Причины: СКВ, Шегрен. Тип II (Proximal): нарушение реабсорбции HCO3-. Синдром Фанкони. Тип IV (Гиперкалиемический): гипоальдостеронизм. | Тип I RTA: pH мочи >5.5 при ацидозе системы = ключевой диагностический признак. |
| nephrology.ops.polycystic_kidney | ПКД — АДПКД Менеджмент | METHOD | Аутосомно-доминантная поликистозная болезнь почек (АДПКБ): PKD1 (85%) и PKD2 мутации. Прогрессирующий рост кист. Экстраренальные: внутричерепные аневризмы (скрининг при семейном анамнезе), кисты печени. КТ: почечный объём. Толваптан (Jynarque): замедляет прогрессирование (при быстро прогрессирующей). | Hypertension: первое осложнение АДПКБ. РААС ингибиторы = стандарт. |
| nephrology.ops.nephrolithiasis_prevention | Камни в почках — профилактика | METHOD | Профилактика мочекаменной болезни: 24-часовой анализ мочи: кальций, оксалат, цитрат, мочевая кислота, натрий. Гидратация: диурез >2 л/день. Кальций оксалат: снизить соль + оксалат, добавить цитрат калия. Мочевая кислота: аллопуринол + подщелачивание мочи (pH >6.5). Struvite: антибиотики + хирургия. | Кальций не ограничивать: связывает оксалат в кишечнике → снижает урinou excretion. |
| nephrology.ops.contrast_nephropathy | Контраст-индуцированное ОПП — профилактика | METHOD | Контраст-индуцированная острая нефропатия: SC (≥0.3 мг/дл SCr) через 48-72 ч после контраста. Риск: ХБП G3b+, диабет, сердечная недостаточность. Профилактика: гидратация (500 мл нормального физраствора за 1ч до + 4 ч после). Низкоосмолярный или изоосмолярный контраст. Метформин: отменить за 48 ч при eGFR <60. | N-ацетилцистеин: нет убедительных доказательств для профилактики контрастной нефропатии. |
| nephrology.ops.glomerulonephritis_anca | АНЦА-васкулит — поражение почек | METHOD | ANCA-ассоциированный васкулит с поражением почек: GPA (c-ANCA/PR3), MPA (p-ANCA/MPO), EGPA. Пролиферативный очаговый некротизирующий гломерулонефрит. Клиника: быстро прогрессирующая ГН (RPGN). Лечение: ритуксимаб или циклофосфамид + стероиды. Плазмаферез: спорно (PEXIVAS trial). | «Почечный ANCA» без системных симптомов: не редкость, только биопсия помогает. |
| nephrology.ops.lupus_nephritis | Волчаночный нефрит — классы ISN/RPS | METHOD | Волчаночный нефрит: ISN/RPS классификация (2003). Class I: минимальный мезангиальный. II: пролиферативный мезангиальный. III: фокально-сегментарный. IV: диффузный (наиболее тяжёлый). V: мембранозный. VI: склерозирующий. Лечение IV: MMF + стероиды. Вокломодекс + voclosporin: новые. | Класс IV (диффузный): наиболее тяжёлый → ранняя интенсивная терапия. |
| nephrology.ops.secondary_hypertension | Вторичная гипертония — оценка | METHOD | Вторичная гипертония: Renovascular: стеноз почечной артерии (шум над почечной артерией + снижение функции одной почки). Первичный гиперальдостеронизм: гипокалиемия + ↓ренин. Феохромоцитома: пароксизмальная гипертензия + потливость + тахикардия. CKD: РААС активация. Апноэ сна: ночная. | «Resistant hypertension»: не контролируется ≥3 препаратами (включая диуретик) → исключить вторичные причины. |
