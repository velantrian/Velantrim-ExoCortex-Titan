| regaff.ops.fda_pma_510k | FDA — PMA против 510(k) | METHOD | Разрешение FDA медицинских устройств: Класс I (освобождение от налога, общий контроль), Класс II (510(k), специальный контроль), Класс III (PMA, предпродажное одобрение). 510(k): показать «существенную эквивалентность» предикатному. PMA: улучшенная безопасность и эффективность через клин. испытания. Де Ново: для новых Класс I/II без предикаты. | Class III: высокорисковые устройства (искусственные клапаны, имплантируемые дефибрилляторы). |
| regaff.ops.ema_centralized | EMA — Централизованная процедура | METHOD | Европейское медицинское агентство (EMA): Centralized Procedure: разрешение действует во всех 27 ЕС. Обязательно для: биологики, онкология, ВИЧ, диабет. Voluntary для других. Decentralized: несколько национальных одновременно. Mutual Recognition: после одной страны. E (Эффективность): E6 (GCP), E3 (отчеты об исследованиях). S (Безопасность): доклинический. M (Многопрофильный): M4 (CTD — Общий технический документ). eCTD: электронное CTD для подачи. | CTD (Common Technical Document): модульный формат заявки для регуляторов. |

Обязанности следователя. Обязанности спонсора. Мониторинг. Сохранение записи. Регулятор: FDA 21 CFR, часть 312 (IND), EMA.
