| corpfin.ops.dcf_valuation | Оценка DCF — свободный денежный поток | METHOD | Дисконтированный денежный поток (DCF): FCF = EBIT(1-t) + D&A - ΔWC - CapEx. WACC = wd×rd(1-t) + we×re. Терминальная стоимость (рост Гордона): TV = FCFn×(1+g) / (WACC-g). Стоимость предприятия = PV(FCF) + PV(TV). Стоимость акционерного капитала = EV – чистый долг. Чувствительность: профиль IRR, NPV. | DCF чувствителен к Terminal Value (обычно 60-80% EV). Даже малые изменения assumptions → большие изменения. |
| corpfin.ops.financial_statements_analysis | Финансовая отчетность — основа анализа | METHOD | Три отчёта: Отчет о прибылях и убытках (доходы-расходы = чистая прибыль). Балансовый отчет: Активы = Обязательства + Капитал. Отчет о движении денежных средств: Операционная деятельность + Инвестиции + Финансирование. DuPont: ROE = чистая прибыль × оборачиваемость активов × мультипликатор собственного капитала. Оборотный капитал = Текущие активы – Текущие обязательства. EBITDA: операционный денежный поток. | Non-GAAP EBITDA: компании корректируют (stock-based comp, restructuring) → читать с осторожностью. |
| corpfin.ops.wacc_components | WACC — Стоимость капитала | METHOD | Средневзвешенная стоимость капитала: WACC = wd×kd×(1-t) + we×ke. ke (CAPM): ke = rf + β×(rm-rf). rf = безрисковая ставка (10-летняя UST). β = чувствительность рынка. Премия за рыночный риск: 4-7% (историческая). Налоговый щит: процент по долгу вычитается из налогов (→ окончание экономики). Целевая структура капитала: устойчивость D/E. | Ограничения CAPM: историческая бета ≠ форвардная бета. Скорректированная бета: β_adj = 2/3×β_исторический + 1/3×1,0. |
| corpfin.ops.credit_analysis_5c | Кредитный анализ — 5 C | METHOD | Пять «С» кредитного анализа: Character (репутация, история платежей). Capacity (способность погасить: DSCR = NOI / debt service ≥1.25). Capital (собственный капитал в сделке). Conditions (рыночные условия). Collateral (залог, LTV). Ковенанты (Covenants): ограничения в кредитном договоре (leverage ratio <3×, min liquidity). | DSCR <1.0: кэш недостаточен для обслуживания долга без дополнительных средств. |
| corpfin.ops.merger_accretion_dilution | Слияния и поглощения — Анализ прироста/разбавления | METHOD | Анализ акреции/разводнения при слиянии: Прирост: покупатель EPS растёт. Разбавление: количество покупателей EPS падает. Расчёт: EPS после слияния = (Чистая прибыль приобретателя + Целевая чистая прибыль) / разводнённые акции в обращении. Синергии: выручка + затраты, синергия – затраты на интеграцию. Синергия безубыточности: минимальные синергии для нейтрального EPS. | Cash deals vs stock deals: stock — автоматическое dilution при высокой цене. |
| corpfin.ops.lbo_model_structure | LBO — Модель выкупа с кредитным плечом | METHOD | Выкуп с использованием заёмного капитала (LBO): Фонд PE выкупает компанию (75-80% долгом). Цели IRR: 20-30%+ за 5 лет. Погашение долга: свободный денежный поток → снижение долга. Коэффициент входа: EV/EBITDA покупки (7-10×). Выходной мультипликатор: EV/EBITDA продаж (7-10×). Создание стоимости: погашение долга + рост EBITDA + многократное расширение. | «Floor» IRR: гарантированный минимум → нужен доходный бизнес с предсказуемым FCF. |
| corpfin.ops.bonds_duration_convexity | Фиксированный доход — продолжительность | METHOD | Дюрация (Duration): чувствительность цены облигации к изменению процентных ставок. Modified Duration: ΔP/P ≈ -MD × Δy. Macaulay Duration: средневзвешенный срок потоков. Convexity: поправка на нелинейность. ΔP/P ≈ -MD × Δy + 0.5 × Convexity × Δy². Negative convexity: ипотечные ценные бумаги (prepayment risk). | Duration 7: при росте ставки на 1% цена облигации снижается на ≈7%. |
| corpfin.ops.ipo_process | IPO — этапы процесса | METHOD | Первичное публичное размещение: Выбор андеррайтеров (lead banker). S-1 registration statement (SEC). Roadshow: презентации инвесторам. Book building: заявки. Pricing: диапазон цен → финальная цена. Lockup period: 90-180 дней (insiders не могут продавать). Greenshoe option: over-allotment (15% дополнительных акций). SPAC: альтернатива IPO (merger with shell company). | Спред по андеррайтингу: 7% (типично для IPO в США) = основной доход банка. |
| corpfin.ops.derivatives_hedging | Производные финансовые инструменты — валютное хеджирование | METHOD | Валютное хеджирование: Forward contract: фиксация курса на будущую дату. FX Option: право (не обязательство) купить/продать по strike. Zero-cost collar: покупка put + продажа call (бесплатный hedge). Cross-currency swap: обмен основной суммы + процентов в разных валютах. Hedge ratio: % экспозиции, покрытой хеджем. | Natural hedge: совпадение доходов и расходов в той же валюте. |
| corpfin.ops.working_capital_management | Оборотный капитал — цикл конвертации денежных средств | METHOD | Цикл конвертации денежных средств (CCC) = DIO + DSO – DPO. DIO (неоплаченные запасы в днях) = Запасы × 365 / COGS. DSO (неоплаченные дни продаж) = AR × 365 / доход. DPO (дни задолженности по оплате) = AP × 365 / COGS. CCC < 0: Amazon, Walmart — получают деньги от клиентов до оплаты поставщикам. | Снижение CCC на 1 день: при $1B revenue = высвобождение $2.7M кэша. |
| corpfin.ops.interest_rate_swap | Процентный своп — структура | METHOD | Процентный своп (IRS): обмен фиксированного процента на плавающий (LIBOR/SOFR) или наоборот. Notional amount: номинал (не обменивается). Payer swap: платить fixed, получать floating. Receive swap: получать fixed, платить floating. Hedge: floating rate debt + receive-fixed IRS = synthetic fixed rate. ISDA Master Agreement: стандартный договор. | Поэтапный отказ от LIBOR (2023 г.): замена на SOFR (обеспеченная ставка финансирования овернайт). |
| corpfin.ops.black_scholes_options | Оценка опционов — Блэк-Шоулз | METHOD | Формула Блека-Шоулза: C = S×N(d1) - K×e^(-rT)×N(d2). d1 = (ln(S/K) + (r + σ²/2)×T) / (σ×√T). d2 = d1 - σ×√T. Переменные: S (спот), K (страйк), r (безрисковый), T (время), σ (волатильность). Греки: Дельта (∂C/∂S), Гамма, Тета, Вега, Ро. | Implied volatility: обратное решение B-S для известной рыночной цены опциона. |
| corpfin.ops.financial_ratios_profitability | Финансовые коэффициенты — Категория | METHOD | Финансовые коэффициенты: Рентабельность: Валовая прибыль = (Выручка - COGS)/Выручка, Операционная маржа = EBIT/Выручка, Чистая прибыль = Чистая прибыль/Выручка, ROE = Чистая прибыль/Капитал, ROA = Чистая прибыль/Активы. Ликвидность: Коэффициент текущей ликвидности = CA/CL (>2,0), Коэффициент быстрой ликвидности = (CA-Inventory)/CL (>1,0). Долг: D/E = Общий долг/Собственный капитал, Покрытие процентов = EBIT/Проценты. | Кредитное плечо: Покрытие процентов <3× = высокий риск дефолта. |
| corpfin.ops.equity_research_report | Исследование рынка акций — аналитический отчет | METHOD | Аналитический отчёт по акциям: Инвестиционные тезисы: 1-2 предложения.
