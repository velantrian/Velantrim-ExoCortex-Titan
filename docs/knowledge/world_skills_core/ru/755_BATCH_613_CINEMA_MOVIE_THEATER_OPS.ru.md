# BATCH 613: Cinema — Movie Theater Operations

**KnowledgeUnits:** 5
**Namespace:** `cinema.ops.*`
**Scope:** projection, digital, concession, ticketing, usher, cleaning, sound, screen, maintenance

| ID | KnowledgeUnit | Тип | Суть | Практический смысл |
|---|---|---|---|---|
| cinema.ops.digital_projection_booth | Цифровая проекция — DCP и плейлист | METHOD | Цифровая кинопроекция (DCI стандарт). Projector: DLP Cinema (Christie, Barco, NEC) на ксеноновой лампе (2-7 kW) или лазерный (RGB laser). Сервер (Doremi, GDC, Dolby): хранит DCP (Digital Cinema Package). DCP — набор файлов: MXF (video JPEG2000 + audio PCM), XML (плейлист), KDM (Key Delivery Message — ключ дешифровки на конкретный сервер, на даты). Playlist: TMS (Theatre Management System) управляет расписанием: pre-show ads, trailers, feature, lighting cues. Автоматизация: закрытие штор, dimming lights, начало projection — синхронизировано. Проверка: перед сеансом — test projection (геометрия, фокус, цвет, звук). Clean port window (стекло между booth и залом — пыль = blur). | Xenon lamp: life 1000-2000 часов, замена (опасность взрыва — защитный костюм!). Laser: 30000+ часов, no bulb changes. |
| cinema.ops.concession_sales_upsell | Концессия — методы продаж и дополнительных продаж | METHOD | Продажа попкорна и напитков. Suggestive selling (up sell): «желаете большой попкорн всего за 50 центов больше?» Техника: задавать вопросы по нарастанию (popcorn size → drink → candy → combo deal). Combo meal (popcorn + drink + candy) — дисконт, средний чек выше. Display: impulse items у кассы (candy on counter). Наполнение: попкорн (свежий — popping каждый час). Popper: масло кокосовое + Flavacol (соль спец. текстура). Butter dispenser: самообслуживание. Speed: transaction time <60-90 секунд. Pager system: для заказов hot food, выдача когда готово. Cleanliness: counter wiped, glass clean. Inventory: weekly count (popcorn kernels, oil, cups, lids). Waste: pop expired/несвежий попкорн выбросить (не продавать stale!). | Самая крупная маржа: попкорн (себестоимость 10-20 центов, продажа $6-9). |
| cinema.ops.theater_cleaning_turnover | Театральная чистота — оборот между спектаклями | METHOD | Уборка зала между сеансами. Time: 5-10 мин между shows (tight window). Crew: 3-5 человек на зал 200-300 мест. Инструменты: leaf blower (сдувает попкорн с рядов к экрану), wide broom, dustpan, trash bags. Порядок: 1) Зайти сразу после того как вышли последние зрители, 2) Пройти по рядам — собрать крупный мусор (вёдра, бутылки) в мешки, 3) Blower проход (сдуть попкорн/мелкий мусор вниз), 4) Подмести междурядья, 5) Влажная швабра spills (напитки). 6) Проверить сидения (крупные spills требуют deep clean — закрыть место). 7) Опустить сиденья вверх. Освещение: house lights full для уборки. Deep clean: между последним сеансом ночью и утренним — влажная уборка, vacuum, дезинфекция подлокотников. | Тёмный зал: пропущенный мусор под сиденьями — жалобы следующих зрителей. Фонарик обязателен. |
| cinema.ops.sound_system_calibration | Звуковая система — калибровка и эквалайзер | METHOD | Калибровка кинотеатрального звука. Система: Dolby Atmos / 7.1 / 5.1. Компоненты: Screen channels (L/C/R за экраном), Surrounds (боковые, задние на стенах), Subwoofers (LFE за экраном), Ceiling speakers (Atmos — объекты). Калибровка RTA (Real Time Analyzer): измерительный микрофон на месте слушателя (калибровочный центр), pink noise через каждый канал, analyse в ПО (Smaart, REW). EQ параметрический (31-band graphic, или DSP) для выравнивания частотной характеристики (плоская target X-curve ISO 2969 для кино). SPL: калибровочный уровень — 85 дБC для pink noise на каждый канал (reference level). После калибровки: diversity listener test. Регулярная проверка: каждый день — check все каналы (short test tone), ежемесячно — full calibration check. Аудио-процессор (Dolby CP950, QSC DCP): загружены room EQ кривые. | Деградация: speaker driver blown (хрипит на определённой сцене) — жалоба зрителя. |
| cinema.ops.crowd_control_premiere | Контроль толпы — Управление выходными на открытии | METHOD | Управление толпой на премьере. Ожидаемый sold-out show: дополнительный staff (security, ushers), queue management (stanchions, змеевидная очередь), line monitors. Вход: отдельные линии — Tickets (online scan) и Concessions (уже купившие билет). Билеты с назначенными местами (reserved seating) — меньше спешки. Уборка: additional cleaning crew для сокращения turnover. Wait time communication: estimated time. Аниматоры: для длинных очередей — contests, merch. Загрузка зала: посадка за 30 мин до showtime, usher помогает с местами. Flow: one-way traffic (Entrance door отдельно от Exit). Emergency egress: все двери открыты. После сеанса: выход через exit doors к парковке. | Превышение capacity (overselling): незаконно и опасно. |
