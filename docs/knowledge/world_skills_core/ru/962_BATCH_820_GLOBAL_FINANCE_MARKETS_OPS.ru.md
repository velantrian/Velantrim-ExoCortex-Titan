Third generation (Krugman): balance sheet + capital flows. «Impossible trinity»: фиксированный курс + открытый счёт капитала + независимая денежная политика. | Азиатский кризис 1997-98: currency mismatch (займы в долларах + активы в батах/рупиях). |

Collective Action Clauses (CAC): облегчают реструктуризацию. 2020-е: China = крупнейший официальный кредитор развивающихся. | Общая структура (G20+Парижский клуб): механизм погашения долгов, связанных с COVID. |
