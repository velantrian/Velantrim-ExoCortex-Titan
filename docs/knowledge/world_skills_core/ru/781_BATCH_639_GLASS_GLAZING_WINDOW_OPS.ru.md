# BATCH 639: Glass Installation — Glazing & Window Service

**KnowledgeUnits:** 5
**Namespace:** `glazing.ops.*`
**Scope:** glass_cutting, sealed_unit, storefront, shower_door, mirror, safety_glass, caulking, retrofit

| ID | KnowledgeUnit | Тип | Суть | Практический смысл |
|---|---|---|---|---|
| glazing.ops.glass_cutting_technique | Резка стекла — ручной инструмент | METHOD | Резка стекла ручным стеклорезом. Инструмент: carbide wheel (масляный self-oiling cutter). Техника: одно движение с постоянным давлением (слышен ровный хрустящий звук). Надлом: подложить рейку под линию реза, резкое нажатие обеими руками (толстое стекло >6 мм — tap под резаной линией). Зачистка края: алмазная губка или карборундовый камень (снять остроту). Прямые резы: по линейке. Кривые: свободной рукой (практика!). | НЕ проходить дважды по одной линии (крошит край). |
| glazing.ops.igu_sealed_unit_replacement | Стеклопакеты — Замена стеклопакета | METHOD | Замена стеклопакета (IGU). Измерение: ширина × высота × толщина (с точностью до 1 мм). Тип: Low-E (покрытие на внутренней стороне — какая surface?), Argon-filled (газ для лучшей изоляции). Демонтаж старого: снять stop beads (штапики), аккуратно не повредить раму. Установка: setting blocks (опорные колодки) внизу, side blocks. Герметизация: внешний seal (бутиловая лента), drainage holes не закрывать. Крепление stop beads (гвозди или clips). | Запотевание между стёклами: seal failure (влажность проникла) — замена IGU. |
| glazing.ops.shower_door_template | Душевая дверь — измерения и шаблон | METHOD | Замер душевой двери. Frameless: стекло калёное (tempered, 10-12 мм). Измерение: laser distance meter, отвес (стены НЕ вертикальны!). Ширина: в трёх точках (верх, середина, низ) — брать минимальную для зазора. Отклонение: если стена наклонна — стекло режется под углом (шаблон из картона). Фурнитура: hinges (петли), handle, clips (зажимы), seals. Крепление: в стену дюбелями (в плитку — алмазное сверло, в плитку с водой). U-channel на полу (силикон). Проверка: дверь открывается/закрывается без трения, зазоры 5-8 мм. | Закалённое стекло нельзя резать после tempering. |
| glazing.ops.storefront_glass_install | Витрина — алюминиевая система | METHOD | Установка витринного остекления. Алюминиевая рама (Kawneer, Tubelite). Setting blocks: EPDM резина. Внешнее стекло: 6-10 мм, часто ламинированное (laminate — safety!). Заполнение: rubber gasket (wet glaze — silicone, dry glaze — gasket). Doors: patch fittings (точечное крепление), bottom rail, closer (доводчик). Door threshold: ADA compliant (максимальный подъём 12 мм). Герметизация периметра: silicone. | Темперированное стекло для дверей (безопасность!). |
| glazing.ops.mirror_wall_install | Зеркало — установка на стену | METHOD | Монтаж зеркала на стену. Клей: mirror mastic (не разъедает амальгаму!). Подготовка стены: ровная, загрунтованная. Поддержка: временная планка снизу пока клей схватывается. J-channel (нижний профиль) для больших зеркал. Лента (mirror tape) + mastic комбинация (tape для немедленной фиксации, mastic для долгосрочной). Зазоры: 3 мм между панелями. Не резать зеркало на стене! | Обычный construction adhesive разъедает backing зеркала через месяцы. |
