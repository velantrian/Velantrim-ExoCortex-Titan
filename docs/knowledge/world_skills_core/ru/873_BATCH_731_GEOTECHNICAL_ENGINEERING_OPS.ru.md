| geotech.ops.uscs_soil_classification | Классификация почв USCS — унифицированная | METHOD | Унифицированная система классификации грунтов (USCS): Крупнозернистые (>50% частиц >0.075 мм): GW, GP, GM, GC (gravelы), SW, SP, SM, SC (пески). | geotech.ops.bearing_capacity_terzaghi | Несущая способность — уравнение Терцаги | METHOD | Несущая способность основания (Терзаги): qu = cNc + qNq + 0,5γBNγ. c = сцепление, q = эффективное давление горных пород, γ = вес единицы, B = ширина фундамента. Nc, Nq, Nγ = коэффициенты несущей способности (по φ, внутреннее помещение трения). Полоса, квадрат и круглая форма: разные формулы. | geotech.ops.spt_correlation | SPT — корреляция N-значений | METHOD | Стандартный тест на проникновение (SPT): N60 (количество ударов на 300 мм при эффективности 60%). Корреляции: Плотный песок: N60>30. Su (связность): Su ≈ N60/12 кПа (грубая). φ': N60 = 0-4 (рыхлый), 4-10 (средне-рыхлый), 10-30 (средне-плотный), >30 (плотный/очень плотный). Поправка: CN = 0,77 log(2000/σ'v) для давления вскрыши. N1(60) = нормированный. | SPT: единственный in-situ тест в России+странах СНГ для большинства проектов. |
| geotech.ops.slope_stability_bishop | Устойчивость склона — метод Бишопа | METHOD | Метод Бишопа (упрощённый): для кругового скольжения. Parametric analysis: изменение c', φ', water level. | FS >1,5 (статика), FS >1,2 (землетрясение) = требование устойчивости. |

Если OC: Cc → Cs (Индекс набухания). Cc = индекс сжатия. Первичная и вторичная консолидация. Скорость времени: Tv = cv×t/H². cv = коэффициент консолидации. Степень консолидации U vs Tv: U=50% при Tv=0,197. | Резкое снижение vo: скважина (deep excavation), снятие нагрузки → heave (swelling). |
| geotech.ops.liquefaction_assessment | Сжижение — CSR против CRR | METHOD | Оценка разжижения: CRR (Cyclic Resistance Ratio): сопротивление грунта разжижению. | geotech.ops.cone_penetration_test | КПТ — Интерпретация | METHOD | Конусное зондирование (КПТ): qc (сопротивление) + fs (трение) + u2 (поровое давление). FR = fs/qc × 100% (коэффициент трения): классификация грунтов. Ic (индекс поведения почвы): Ic <1,31 = гравий, 1,31-2,05 = песок, 2,05-2,6 = пылеватый песок/песчано-пылеватый грунт, 2,6-2,95 = илы, >2,95 = глины. Bq = (u2 - u0)/(qc - σv): коэффициент порового давления. Сплошные профили: детальная стратиграфия. | CPT vs SPT: CPT непрерывный, CPT более точный, нет образца (только в-situ). |
