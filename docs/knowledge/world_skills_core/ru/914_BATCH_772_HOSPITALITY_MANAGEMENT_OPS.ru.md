| hospitality.ops.revenue_management_hotel | Управление доходами — RevPAR | METHOD | Управление доходами отеля: RevPAR (Доход за доступный номер) = Вместимость × ADR. ADR (средняя дневная ставка) = доход от номеров / проданные номера. Управление доходностью: регулировка цен в зависимости от погоды. Ограничения: Min LOS (минимальная продолжительность пребывания), Close Out (закрытие даты для низкой ставки), BAR (лучшая доступная цена). Управление каналами: OTA, Direct или GDS. | Разрыв RevPAR по сравнению с набором показателей: отчет STAR (STR) для сравнительного анализа. |
| hospitality.ops.food_cost_percentage | F&B — Контроль стоимости продуктов питания | METHOD | Контроль стоимости продуктов: Фактическая стоимость продуктов питания, % = (Начальный запас + Закупки – Конечный запас) / Выручка × 100%. Цель: 28–35 % (высокая кухня 30–35 %, повседневная еда 25–30 %, фаст-повседневная еда 20–25 %). Анализ отклонений: фактическая и теоретическая стоимость. Контроль порций: точные весы + стандартные рецепты. Отходы плиты: снижение посредством обучения персонала. | Себестоимость = Еда + Затраты на рабочую силу = <60% оборота (цель для прибыльного ресторана). |

Стратегия овербукинга: защита от неявок (историческая статистика). Политика прогулки: если нет минусов → переселить + компенсировать. Регистрация: ВИМ (Очень важная встреча). Стандартная ставка по сравнению с BAR по сравнению с договорной. | CRS (Центральная система бронирования) → PMS → Менеджер каналов → OTA. |

| hospitality.ops.catering_cost_per_head | Кейтеринг — расчет цены за час | METHOD | Стоимость на человека (CPH) в кейтеринге: CPH = Общая стоимость / Количество обложек. Минимальная гарантия: клиент платит за минимальное количество (обычно 90-95% ожидаемой посещаемости). Стоимость пакета по сравнению с обслуживанием по меню. | Прибыль от мероприятия = (Цена пакета – Переменная стоимость) × Покрытия – Постоянные затраты. |
