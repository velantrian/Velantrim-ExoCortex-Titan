| airduct.ops.duct_inspection_camera | Осмотр воздуховодов — камера и зеркало | METHOD | Инспекция воздуховодов перед чисткой. Инспекционная камера (поворотно-наклонная, светодиодная), робот-гусеница для магистральных воздуховодов. Что искать: скопление пыли/мусора (>3-5 мм — требует чистки), влага (пятна, грибок), заражение вредителями (грызуны, насекомые — помет), несоединенные соединения, смятый гибкий воздуховод, повреждение изоляции, засор регистра. Регистрация: фото/видео доказательства. Область применения: приточные воздуховоды, возвратные воздуховоды, пленум, вентиляционная установка. | Без инспекции чистка может быть ненужной (scam). |
| airduct.ops.hepa_vacuum_negative_air | Отрицательный воздух — вакуумный метод HEPA | METHOD | Чистка с отрицательным давлением. Negative Air Machine (NAM): HEPA-фильтр, создаёт вакуум в воздуховоде (предотвращает выход пыли в помещение). Подключение: к одному register'у, остальные закрыты. Инструменты: pneumatic whip (пневмохлыст), rotary brush, compressed air nozzle (skipper ball). Процесс: проход инструментом от дальнего register'а к NAM. После механической очистки: vacuum loose debris. | Без отрицательное давление: пыль разлетается по всему дому. |
| airduct.ops.duct_leak_sealing_aeroseal | Герметизация воздуховодов — аэрозольный метод | METHOD | Герметизация воздуховодов изнутри. Aeroseal: аэрозольный виниловый герметик. Blower door нагнетает давление, частицы герметика выходят через утечки и оседают на краях отверстий (запечатывают). Процесс: блокировать registers, подключить Aeroseal machine, computer контролирует процесс (real-time leakage graph). Результат: снижение утечек на 60-90% за 1-3 часа. Для всех типов duct (metal, flex, fiberglass). Преимущества: без разборки стен, достигает недоступных мест. | Окупается через energy savings за 2-5 лет. |
| airduct.ops.filter_merv_selection | Фильтр — Выбор рейтинга MERV | METHOD | Выбор фильтра для HVAC. Рекомендация residential: MERV 8-11 (баланс фильтрации и airflow). MERV 13+: хорошо, но может перегружать blower (нужен достаточный static pressure). HEPA: обычно через bypass (отдельный fan). Замена: каждые 3 мес, в сезон аллергии — чаще. Направление: arrow on filter = airflow direction! | Грязный фильтр = ограничение воздушного потока = нагрузка на вентилятор + более высокая энергия. |
