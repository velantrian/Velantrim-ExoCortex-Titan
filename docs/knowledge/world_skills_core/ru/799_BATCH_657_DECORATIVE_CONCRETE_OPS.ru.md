# BATCH 657: Concrete — Decorative & Stamped Operations

**KnowledgeUnits:** 5
**Namespace:** `decconcrete.ops.*`
**Scope:** stamping, staining, polishing, overlay, engraving, epoxy, sealing, forming

| ID | KnowledgeUnit | Тип | Суть | Практический смысл |
|---|---|---|---|---|
| decconcrete.ops.stamp_timing_texture | Штампованный бетон — время и техника | METHOD | Штампованный бетон. Заливка: standard (slump 10-13 см), цвет добавлен интегрально (integral color) или colour hardener (порошок на surface). Timing: critical — палец оставляет отпечаток глубиной 3-5 мм (firm но plastic). Если слишком рано: штамп проваливается, слишком поздно: не оставляет текстуру. Release agent (пудра): нанести щёткой на бетон и на штамп. Штамповка: начиная с одного угла, плотно друг к другу, слегка утрамбовывая. Не наступать на свежеотштампованное! Снятие: поднять строго вертикально. Промывка release agent: через 24 часа (water wash + acid). Sealer: solvent-based acrylic (блеск, защита). | Дождь испортит незапечатанный stamped бетон. |
| decconcrete.ops.acid_stain_process | Кислотная морилка — эффект мраморности | METHOD | Кислотное окрашивание. Acid stain: металлические соли (iron, copper, manganese) в кислотном растворе — химическая реакция с кальцием бетона (не пигмент!). Цвет: непредсказуем (marbled эффект). Подготовка: очистка (degrease, acid etch), сушка. Нанесение: pump sprayer, два слоя (разные цвета для глубины). Время реакции: 4-24 часа. Нейтрализация: baking soda + water, промывка. Sealer: solvent-based acrylic. Полировка: burnisher для глянца. | Каждый бетон реагирует по-разному. Всегда test patch! |
| decconcrete.ops.polished_overlay_grind | Полированный бетон — измельчение и уплотнение | PROCESS | Шлифовка бетона. Grind: алмазные сегменты прогрессия grit (30 металл → 60/120 металл → 50/100 смола → 200/400 → 800 → 1500 → 3000 (полировка)). Каждый проход под разными углами. Densifier (литий-силикат): наносится после metal grind, проникает в бетон, укрепляет (hardness, dustproof). Grout coat (цементное молоко): заполнение пор и трещин. Полировка: 1500-3000 grit для глянца. Burnisher: для maintenance (оживление блеска). Мокрый способ: больше воды — меньше пыли, но грязнее. Сухой: HEPA vacuum обязательно. | Сланя шлифовка: алмазные диски на планетарной шлифмашинке (Lavina, Husqvarna). |
| decconcrete.ops.overlay_resurfacing | Наложение — система шлифовки | METHOD | Покрытие старого бетона новым слоем. Overlay: polymer-modified cement (толщина 3-6 мм spray-on, до 25 мм trowel-on). Bonding: primer (влажный бетон или специальная грунтовка). Подготовка: repair cracks, shot blast/griding (профиль поверхности). Нанесение: hopper gun (spray) или gauge rake для толстых. Текстура: broom, stamp, spray texture. Curing: wet 3-7 дней. Sealer: acrylic. | Без профиля (smooth surface): overlay отслаивается. |
| decconcrete.ops.vertical_overlay_walls | Вертикальное наложение — Настенное применение | METHOD | Декоративная штукатурка на бетонных стенах. Смесь: полимерцемент+песок (штукатурный). Толщина: 5-15 мм. Нанесение: шпателем (шпателем) или бункерным пистолетом. Резьба (резьба): при частичной закалке (твердость кожи) — вырезать линии, узоры. Морилка: после отверждения. Герметик: силоксан для наружных работ (водоотталкивающий). | Имитация кирпича, камня: carving + staining. |
