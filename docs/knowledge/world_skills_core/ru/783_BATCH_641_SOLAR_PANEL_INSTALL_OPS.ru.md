# BATCH 641: Solar Panel — Residential Installation

**KnowledgeUnits:** 5
**Namespace:** `solar.ops.*`
**Scope:** site_assessment, mounting, electrical, inverter, battery, grid_connection, permits, monitoring

| ID | KnowledgeUnit | Тип | Суть | Практический смысл |
|---|---|---|---|---|
| solar.ops.site_assessment_shading | Оценка места — анализ тени | METHOD | Оценка участка под солнечные панели. Sun path: южная экспозиция оптимальна (северное полушарие). Shade analysis: SunEye, Solmetric — fisheye фото горизонта, расчёт shading factor по месяцам. Критические часы: 9 AM - 3 PM (peak sun hours). Деревья: удалить ветки, затеняющие панели (зимой солнце ниже). Roof pitch: flat (балластная система), tilted. Azimuth: 180° юг оптимально, 90-270° приемлемо с потерей 10-20%. Tilt: широта локации ±15°. Irradiance: kWh/м²/день (PVWatts calculator). | Даже небольшое затенение одного модуля снижает выработку всей string (если нет оптимизаторов). |
| solar.ops.mounting_roof_flashing | Монтаж — рейка и оклад | METHOD | Крепление панелей на крышу. Типы: наклонная крыша (comp shingle — L-feet + flashing, tile — tile hook), плоская (балластная система с утяжелителями). Flashing: металлический подклад под каждый кронштейн для гидроизоляции (под shingle). Рельсы: алюминиевый профиль, крепится к кронштейнам болтами T-slot. Заземление: Weeb Lug (прорезает анодирование) или separate ground wire. Зазоры: 10-15 см от краёв крыши (ветровая нагрузка). Снеговая нагрузка: учитывать при расчёте кронштейнов. | Протечки: самая частая причина — неправильная установка flashing. |
| solar.ops.string_sizing_voltage | Выбор размера струны — напряжение и температура | METHOD | Проектирование string (последовательная цепь). Vmp × n + temp compensation = String Voltage. Voc × n × cold factor (1.18 для −20°C) < Inverter Max Input Voltage (иначе сгорит!). Vmp × hot factor (0.85 для +60°C) > Inverter MPPT Min Voltage. Оптимизаторы (SolarEdge, Tigo): каждый модуль индивидуально — исключение mismatch. Microinverters (Enphase): каждый модуль = мини-инвертер (AC сразу). Rapid shutdown (NEC 690.12): отключение DC в пределах массива за 10 сек. | Холодное солнечное утро: Voc максимальное — риск превышения напряжения. |
| solar.ops.inverter_selection_types | Инвертор — выбор и определение размеров | METHOD | Выбор инвертора. String inverter (один на весь массив): дёшево, но shading снижает всю string. DC/AC ratio: 1.1-1.4 (DC мощность модулей / AC мощность инвертера — clipping, оптимизация затрат). Hybrid (готов к батарее — DC coupled). Microinverter (на каждый модуль). 3-phase vs single-phase. NEM (Net Energy Metering) agreement с utility. Интернет: мониторинг (SolarEdge Monitoring, Enphase Enlighten). | Срок службы инвертора: 10-15 лет (замена среднего срока службы). |
| solar.ops.battery_backup_critical | Аккумулятор — панель критической нагрузки | METHOD | Система с батареей для резерва. AC coupled (Tesla Powerwall, Enphase) vs DC coupled. Critical Loads Panel: отдельная панель с выбранными цепями (холодильник, свет, интернет, отопление). Не критичные нагрузки (бассейн, EV charger) не на backup. Capacity: daily потребление × дни автономности. Chemistry: LiFePO4 (срок >10 лет, глубина разряда 80-90%). Power rating: peak (пусковой ток компрессора холодильника ×5). Автоматический transfer switch (<20 мс — seamless). | Lead-acid дешевле upfront, но обслуживание и короткий срок. |
