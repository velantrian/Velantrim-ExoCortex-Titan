# BATCH 1036: Soil Testing — Field & Lab Analysis

**KnowledgeUnits:** 5
**Namespace:** `soiltest.ops.*`
**Scope:** sampling, pH, NPK, texture, compaction, infiltration, organic, CEC

| ID | KnowledgeUnit | Тип | Суть | Практический смысл |
|---|---|---|---|---|
| soiltest.ops.sampling_zigzag_pattern | Выборка — зигзагообразный узор | METHOD | Отбор проб почвы. Инструмент: soil probe (пробоотборник, трубка 2 см). Глубина: 10-15 см для lawns/garden, 20-30 см для trees, 0-60 см для agriculture. Количество: 10-20 cores (объединённых в один composite sample). Паттерн: зигзаг или сетка по участку. Избегать: края, нетипичные места (куча золы, место старого костра). Ведро: plastic (не металл — цинк искажает micronutrient test). Смешивание: тщательное, отсыпать 200-500 г в bag. Label. | 1 проба на 1-2 га для поля, отдельно для разных зон. |
| soiltest.ops.ph_test_slurry_meter | pH-тест — суспензионный метод | METHOD | Определение кислотности почвы. Метод 1:1 (soil:water). 20 г soil + 20 мл дистиллированной воды, перемешать, отстаиваться 30 мин. Meter: pH electrode в slurry (не в супернатант!). Калибровка: pH 4.0 + 7.0 buffers. Альтернатива: test strips (приблизительно). Кислая почва: pH <5.5. Щелочная: >7.5. Target: 6.0-7.0 для большинства растений. | Известкование: повышение pH (dolomite lime). Сера: понижение pH. |
| soiltest.ops.texture_ribbon_test | Текстура — Тест ленты (Поле) | METHOD | Определение текстуры почвы вручную. Увлажнить образец (не паста, не сухо). Ribbon test: разминать между большим и указательным пальцем, формировать ленту. Глина: ribbon >5 см, песок: не формируется. Grittiness: песок (крупные частицы), smoothness: silt, stickiness: clay. Soil triangle: по %sand/silt/clay. Field метод даёт приблизительную классификацию (для точного — hydrometer lab test). | Глина: плохой дренаж. Песок: быстро высыхает. |
| soiltest.ops.compaction_penetrometer | Уплотнение — Пенетрометр | METHOD | Измерение плотности почвы (cone penetrometer). Probe: конический наконечник (ASAE standard), манометр. Усилие: psi. Интерпретация: <200 psi = good root growth, 200-300 = moderate restriction, >300 = severe compaction (корни не проходят). Глубина: каждые 5 см reading. Наилучшее время: field capacity (не сухо, не мокро — влияет на readings). | Уплотнение от construction equipment: долгосрочная проблема. |
| soiltest.ops.infiltration_perc_test | Проникновение — Perc-тест | METHOD | Тест водопроницаемости (для septic). Выкопать яму глубиной 30-40 см, диаметр 15-30 см. Замочить overnight (swelling clay). Залить воду на 30 см. Измерять падение уровня каждые 10-30 мин. Расчёт: мин/дюйм (или мин/см). Для septic: 3-60 мин/дюйм — приемлемо. >60 — слишком медленно (mound system). <3 — слишком быстро (contamination groundwater). | Perc test критичен для выбора septic system. |
