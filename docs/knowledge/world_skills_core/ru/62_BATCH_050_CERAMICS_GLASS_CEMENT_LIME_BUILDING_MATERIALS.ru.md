# Batch 050: Ceramics, Glass, Cement, Lime and Building Materials

Назначение: закрыть практический слой материалов, из которых строят цивилизацию: глина, кирпич, керамика, стекло, цемент, известь, гипс, утеплители, заполнители, асфальт и контроль качества.
