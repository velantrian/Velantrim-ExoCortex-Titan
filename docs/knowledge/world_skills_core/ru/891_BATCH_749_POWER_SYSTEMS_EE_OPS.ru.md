| powersys.ops.load_flow_analysis | Поток нагрузки — Ньютон-Рафсон | METHOD | Расчёт установившегося режима (Load Flow): Newton-Raphson: итерационный метод. Mismatch vector (ΔP, ΔQ) → Jacobian matrix → Δθ, ΔV. Сходимость: 3-5 итераций. Gauss-Seidel: простой но медленный. Fast Decoupled: использует отдельные P-θ и Q-V. Буснарская матрица (Ybus): узловая матрица проводимостей. | Плоский старт: все напряжения 1.0 + угол 0 → хорошая начальная точка. |
| powersys.ops.transformer_equivalent | Трансформатор — эквивалентная схема | METHOD | Схема замещения трансформатора: R1 + jX1 (первичное) → параллельный Rc, jXm (намагничивающая ветвь) → R2' + jX2' (вторичное приведённое). Приведение к первичной стороне: R2' = R2 × (n1/n2)². Нагрузочные потери (copper loss): I²R. Холостой ход (iron loss): Rc. Тест КЗ: нагрузочные. Тест ХХ: железные. | Per unit system: нормировка на базовые значения (унифицирует разные напряжения). |
| powersys.ops.per_unit_system | За единицу — базовые значения | METHOD | Система относительных единиц (p.u.): Sbase (единый для всей системы), Vbase (по уровням напряжения). Zbase = V²base / Sbase. Ibase = Sbase / (√3 × Vbase). Изменение базы: Znew = Zold × (Sbase,new / Sbase,old) × (Vbase,old / Vbase,new)². Стандартный Zbase: 100 MVA. | P.u. упрощает: трансформаторы теряют идеальный трансформатор в схеме. |
| powersys.ops.relay_protection | Реле защиты — сверхток | METHOD | Токовая защита: Трансформатор тока (ТТ): измеряет ток. Реле: сравнивается с уставкой. Реле максимального тока с обратнозависимой выдержкой времени (50/51): ток > уставка → задержка = к/(I/Iзад)^n. IDMT (обратное определенное минимальное время). Ток срабатывания: немного выше максимальной нагрузки. Координация: последнее средство (50/51 нисходящий поток) → следующий (52 восходящий поток). | Защита зоны 1: мгновенная (мгновенная). Зона 2-3: с задержкой (координация). |
| powersys.ops.symmetrical_components | Анализ неисправностей — симметричные компоненты | METHOD | Симметричные составляющие (Fortescue): несимметричная 3-фазная система = positive + negative + zero sequence. Positive: нормальная последовательность (A, B, C). Negative: обратная (A, C, B). Zero: одинаковые по величине и фазе. Three-phase fault: только положительная. Line-to-ground: все три. Преобразование: [A012] = [a][Aabc]. | Нулевая последовательность через нейтраль: при наличии заземлённого нейтралного провода. |
| powersys.ops.bus_bar_protection | Защита шин — дифференциальная | METHOD | Защита шин (87B): дифференциальная. Сумма токов в шину = 0 при нормальной работе. Неисправность на шине: ΔI = сумма ≠ 0 → отключение. CT насыщение: проблема (ложные срабатывания). Biased differential: торможение при насыщении. High-impedance busbar protection: более устойчивый к CT насыщению. | Шинная защита критична: отказ = отключение всего подстанционного оборудования. |
| powersys.ops.power_swing | Power Swing — потеря синхронизма | METHOD | Нарушение синхронизма: после крупного возмущения (КЗ) генераторы могут потерять синхронизм. Power Swing Blocking (PSB, функция 68): предотвращает ложное отключение при нормальном качании. Out-of-Step Tripping (OST, функция 78): отключение при потере синхронизма. Swing Locus: траектория R-X на плоскости импедансов. | PSB critical: distance relay 21 может ложно сработать при качании. |
| powersys.ops.voltage_stability | Стабильность напряжения — фотоэлектрические кривые | METHOD | Напряжённость по напряжению: PV curve (P vs V): nose point = maximum load transfer. Voltage collapse: при превышении nose point. Reactive power compensation (SVC, STATCOM): поддержание напряжения. Загрузка линии: мощность ограничена термически или по напряжённости. | Короновые потери: высокое напряжение → ионизация воздуха → потери в передаче. |
| powersys.ops.scada_energy_management | SCADA/EMS — Функции | METHOD | Диспетчерский контроль и сбор данных (SCADA): телемониторинг + управление. Система энергоменеджмента (СЭМ): диспетчеризация солнца, оценка состояния. OPF (оптимальный поток мощности): экономичная диспетчеризация с ограничениями. Оценка состояния: фильтрация измерений → оценка состояния сети. ICCP (Протокол межцентрового управления): обмен между диспетчерскими. | State Estimation = зеркало сети для оператора (не реальные измерения, а расчёт). |
| powersys.ops.short_circuit_calculation | Короткое замыкание — IEC 60909 | METHOD | Расчёт токов КЗ (IEC 60909): c × Vn / (√3 × | Зк | ). c = voltage factor (1.0-1.1). Максимальный ток: c=1.1, минимальный: c=1.0. Zk = суммарный импеданс до точки КЗ. Asy factor (κ): для ударного тока (peak). 3ф КЗ обычно самый большой (> 1ф КЗ при Zground=0). | Оборудование должно выдерживать токи КЗ (рейтинг ICW). |
| powersys.ops.generator_synchronization | Синхронизация генератора — Условия | METHOD | Синхронизация генератора: точные условия — одинаковые: напряжение, частота, порядок следования фаз, угловое положение. Sync-check relay (25): проверяет перед включением. Допустимый diff напряжения: ±10%. Diff частоты: ±0.5%. Угол: ±10°. Auto-synchronizer: автоматически выравнивает. | Неправильная синхронизация: ударный ток = 2× Inom → повреждение генератора. |
| powersys.ops.transformer_protection | Защита трансформатора — 87Т | METHOD | Дифференциальная защита трансформатора (87T): измеряет токи первичной и вторичной стороны (приведённые). Harmonic restraint: 2-я гармоника при намагничивании → не реагировать на бросок намагничивающего тока. 5-я гармоника: перенасыщение → restraint. Percentage differential: slope = 20-25% (bias). | Пуск трансформатора: ток намагничивания = 5-10×Iном → без 2nd harmonic block = ложное срабатывание. |
| powersys.ops.reactive_power_compensation | Реактивная мощность — SVC против СТАТКОМ | METHOD | Компенсация реактивной мощности: Батареи конденсаторов: дешёвый, ступенчатый. SVC (статический компенсатор реактивной мощности): TSC + TCR: быстрее, непрерывнее. СТАТКОМ (статический синхронный компенсатор): на основе VSC, лучше всего при низком напряжении. Конденсатор + реактор: шунтовая компенсация. Последовательный конденсатор: снижение Xlinha → увеличенная пропускная способность. | STATCOM: независим от напряжения шины (vs SVC → уменьшение Q при снижении V). |

LMP = Компоненты энергии + перегрузки + потерь. Рынок на сутки вперед (DAM) и рынок реального времени (RTM). Клиринговая цена мощности (ЦКМ): в динамике производительности. Touch voltage: между двумя точками на расстоянии 1 м (рука + нога). Step voltage: между двумя ногами при ходьбе. Grid resistance должна обеспечить безопасные напряжения.
