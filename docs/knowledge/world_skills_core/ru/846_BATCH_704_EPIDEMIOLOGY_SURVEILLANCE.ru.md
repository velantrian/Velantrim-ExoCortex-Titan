# BATCH 704: Epidemiology — Disease Surveillance & Control

**KnowledgeUnits:** 19
**Namespace:** `epidem.ops.*`
**Scope:** surveillance, outbreak_investigation, measures, study_design, vaccine_efficacy, contact_tracing, screening, NPI

| ID | KnowledgeUnit | Тип | Суть | Практический смысл |
|---|---|---|---|---|
| epidem.ops.attack_rate_calculation | Скорость атаки — расследование вспышки | METHOD | Показатель заболеваемости (attack rate): число заболевших / число подверженных риску × 100%. Вторичный (Secondary Attack Rate, SAR): заболевшие среди контактных / число контактных × 100%. Сравнительный attack rate: по экспозиции (food-specific AR в food outbreak). Relative risk: AR_exposed / AR_unexposed. | Cohort study при вспышке: собрать всех, выявить food/exposures. |
| epidem.ops.r0_serial_interval | R0 и последовательный интервал | METHOD | Базовое репродуктивное число R0: среднее число вторичных случаев от одного первичного в полностью восприимчивой популяции. R0 = β × D (transmission probability × infectious period). R0>1: распространение, R0<1: угасание. Serial interval: время между onset у первичного и вторичного случая. Herd immunity threshold: 1 - 1/R0. | Исходный штамм R0 COVID-19 ≈ 2,5-3,0. Омикрон ≈ 8-15. |
| epidem.ops.case_definition | Определение случая — надзор | METHOD | Определение случая: Suspect (подозрительный): клинические критерии. Probable (вероятный): + эпидемиологическая связь без лабораторного подтверждения. Confirmed (подтверждённый): лабораторное подтверждение. Используется единообразно для surveillance. Sensitivity vs specificity: широкое (ранняя вспышка) vs узкое (поздняя, контроль). | CDC/WHO case definitions: стандартизированы для сравнения между странами. |
| epidem.ops.odds_ratio_case_control | Отношение шансов — исследование «случай-контроль» | METHOD | Отношение шансов (OR): case-control study. OR = (a/c) / (b/d) = ad/bc (таблица 2×2). OR≈RR когда исход редкий. Mantel-Haenszel OR: для стратифицированных данных. Confounding: коррекция через стратификацию или logistic regression. CI (confidence interval): если включает 1.0 = нет статистически значимой ассоциации. | OR: интерпретируется как «в X раз выше шансы», не вероятность. |
| epidem.ops.sensitivity_specificity | Чувствительность и специфичность — Тест | METHOD | Чувствительность (sensitivity) = TP/(TP+FN): способность теста выявить больных. Специфичность (specificity) = TN/(TN+FP): способность выявить здоровых. PPV (Positive Predictive Value) = TP/(TP+FP): зависит от prevalence. NPV = TN/(TN+FN). ROC curve: баланс Se/Sp. AUC: общее качество теста. | При низкой prevalence: даже хороший тест имеет плохой PPV (много ложноположительных). |
| epidem.ops.contact_tracing_ring | Отслеживание контактов — кольцевая вакцинация | METHOD | Отслеживание контактов: идентификация, уведомление, карантин/изоляция. Ring vaccination: вакцинация контактов случая (оспа eradication). Generations: первичный → вторичные → третичные. Backward tracing: идентифицировать источник (не только downstream). Digital exposure notification: bluetooth proximity (COVID). | Обратная трассировка: ключ к выявлению событий суперраспространителя. |
| epidem.ops.vaccine_efficacy_calculation | Эффективность вакцины — дизайн исследования | METHOD | Эффективность вакцины (VE): VE = (1 - RR) × 100% = (1 - ARvac/ARcontrol) × 100%. RCT: плацебо-контролируемое двойное слепое. Endpoints: symptomatic disease, severe disease, death, infection. 95% CI. контрольный звонок period. ITT vs PP analysis. Correlates of protection: иммунологические маркеры коррелирующие с защитой (антитела, T-клетки). | VE от симптоматической ≠ VE от передачи. |
| epidem.ops.incubation_period_estimate | Инкубационный период — оценка | METHOD | Инкубационный период: время от экспозиции до появления симптомов. Лог-нормальное распределение обычно. Правило 3-х инкубационных периодов: время карантина (охватывает 99%+ случаев). Например COVID: медиана 5 дней, 97-й перцентиль = 11 дней. Уточнение: из исходных экспозиций с известным временем контакта. | Максимальное время карантина = 3× медианный инкубационный период. |
| epidem.ops.reproductive_number_rt | Эффективное Rt — оценка в реальном времени | METHOD | Эффективное Rt (рабочее репродуктивное число): R с учётом иммунитета. Rt = R0 × S/N (доля восприимчивых). Методы оценки: EpiEstim (R пакет), serial interval distribution. Rt >1: вспышка растёт. Rt <1: угасание. Временная задержка: Rt отражает передачу 1-2 недели назад (из-за задержки данных). | Rt ежедневное обновление: необходимо для принятия NPI решений. |
| epidem.ops.number_needed_to_vaccinate | NNV — количество, необходимое для вакцинации | METHOD | Число необходимых для вакцинации (NNV) = 1/ARR (absolute risk reduction). ARR = AR_unvaccinated - AR_vaccinated. NNV vs NNT (treated): тот же принцип. Применение: сравнение вакцин по эффективности. Пример: если ARR = 0.01 (1%), то NNV = 100. | NNV зависит от baseline risk: высокий риск → меньше NNV → более эффективно вакцинировать. |
| epidem.ops.epi_curve_shapes | Эпи-кривая — интерпретация закономерностей | METHOD | Эпидемическая кривая: ось X время, ось Y новые случаи. Common source single exposure: острый подъём + острый спад (пищевое отравление). Propagated (person-to-person): последовательные «волны» с интервалом = serial interval. Mixed outbreak: оба паттерна. Continuous source: длительный «хвост» (загрязнённый источник воды). Outlier case: точечный → ранний case-finding. | Форма кривой → тип вспышки → тип вмешательства. |
| epidem.ops.attributable_fraction | Атрибутивная доля населения — PAF | METHOD | Популяционная доля атрибутивного риска (PAF): PAF = (RR-1)/RR × pe (где pe = распространённость экспозиции в популяции). Интерпретация: % случаев в популяции, которые можно предотвратить устранением экспозиции. Пример: курение + PAF для рака лёгких = 85% (если устранить курение — 85% случаев предотвращено). | PAF важен для policy (public health priority), не для индивидуального риска. |
| epidem.ops.cross_sectional_prevalence | Поперечное исследование — исследование распространенности | METHOD | Поперечное исследование: одномоментный срез. Measures prevalence (не incidence). Подходит: для хронических заболеваний с длительным курсом. Не подходит: острые быстро проходящие. Causal direction: нельзя установить (причина или следствие?). Prevalence = incidence × duration. | Длинные болезни (хронические): «накапливаются» в prevalence, короткие — не накапливаются. |
| epidem.ops.syndromic_surveillance | Синдромное наблюдение — системы | METHOD | Синдромный надзор: мониторинг синдромов (гастроэнтерит, ILI) до лабораторного подтверждения. Источники: ED visits, pharmacy OTC sales, school absenteeism, 911 calls. BioSense Platform (CDC): USA синдромная. WHO EWARN: поле. Threshold alerts: CUSUM, scan statistics. Цель: раннее обнаружение вспышек (биотерроризм, пандемия). | Flu-like illness syndromic: неспецифичный, но ранний. SARS-CoV-2: первые сигналы через syndromic. |
| epidem.ops.one_health_approach | Единое здоровье — зоонозные заболевания | METHOD | Концепция «Единое здоровье»: здоровье людей + животных + окружающей среды взаимосвязаны. Зоонозы 60% инфекционных болезней. Трансмиссия: spillover event (SARS-CoV-2 → летучие мыши), amplification (intermediate host), establishment в популяции человека. Interfacies: Wildlife-Livestock-Human. FAO/WHO/OIE/UNEP. | 75% ЭИД (новые инфекционные заболевания): зоонотические. |
| epidem.ops.mathematical_sir_model | Модель SIR — динамика эпидемии | METHOD | Модель SIR: S (восприимчивый), I (инфекционный), R (выздоровевший). dS/dt = -βSI, dI/dt = βSI - γI, dR/dt = γI. β = скорость передачи, γ = скорость восстановления. R0 = β/γ. Коллективный иммунитет: S_final = 1/R0 (фракция остается восприимчивой). Ограничения: однородное смешение (не учитывает возрастную/географическую структуру). Расширения: SEIR (E = подвержен), SIRS (ослабленный иммунитет). | SIR аналитически: пиковое заражение когда S = 1/R0. |
| epidem.ops.phe_public_health_ethics | Этика общественного здравоохранения — Модель управления | METHOD | Этика общественного здравоохранения: Stewardship model (Nuffield Council): государство должно поощрять здоровье, не навязывать (ladder of intervention: от информирования до запрета). Принцип вреда Милля: свобода ограничивается только когда вред другим. Proportionality: мера должна быть пропорциональна угрозе. Equity: не только aggregate benefit, но и distributional effects. | Локдаун: баланс между пользой для общественного здравоохранения и вредом от ограничений. |
| epidem.ops.genomic_surveillance_pathogen | Геномный надзор — WGS | METHOD | Whole Genome Sequencing (WGS) патогенов: кластерный анализ → идентификация вспышки (PFGE, MLVA заменены). GISAID: глобальная база данных вирусных геномов. Nextstrain: филогенетика в реальном времени. Surveillance requirements: доля образцов, подвергшихся секвенированию. Variant tracking: мутации в key positions (spike protein). | SARS-CoV-2 варианты: идентифицируются через WGS (Delta, Omicron). |
| epidem.ops.multidrug_resistant_organism | MDRO — Надзор за здравоохранением | METHOD | Мультирезистентные организмы: MRSA (метициллин-резистентный золотистый стафилококк), VRE (ванкомицин-резистентный энтерококк), ESBL (бета-лактамазы расширенного спектра), CRE (карбапенем-резистентные энтеробактерии). Культуры активного наблюдения (ASC): скрининг поступающих пациентов. Меры предосторожности при контакте: халат + перчатки. | CRE: высокая летальность (40-50%), крайне ограниченные варианты лечения. |
