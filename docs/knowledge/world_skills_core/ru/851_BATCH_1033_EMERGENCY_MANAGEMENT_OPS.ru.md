# BATCH 1033: Emergency Management — Disaster Planning

| emergmgmt.ops.ics_structure | ICS — Структура управления инцидентами | METHOD | Система управления инцидентами (ICS): Incident Commander (IC) → Операции, Планирование, Логистика, Финансы/Администратор (четыре раздела). Командный состав: офицер безопасности, офицер общественной информации, офицер связи. Объем контроля: 3-7 подчинённых на одного руководителя. Единое командование: при мультиагентных происшествиях. Командование района: несколько инцидентов. | ICS применяется при ≥2 агентствах или многодневных инцидентах. |
| emergmgmt.ops.eoc_operations | EOC — Центр экстренных операций | METHOD | ЦУК (Center of Emergency Operations): координация ресурсов, не управление тактикой. Активация levels: Level 3 (мониторинг), Level 2 (частичная активация), Level 1 (полная). NIMS: National Incident Management System (USA). ESF (Emergency Support Functions) 1-15: транспорт, связь, ЖКХ, пожар, масс-сюрпризы. WebEOC/E-Team: программы управления ЦУК. | EOC ≠ ICG. EOC координирует ресурсы, IC управляет полем. |
| emergmgmt.ops.hazmat_ergrg | Опасные вещества — Справочник ERG | METHOD | Аварии с опасными грузами: ERG (Руководство по реагированию на чрезвычайные ситуации, DOT): оранжевый справочник. Идентификация: номер ООН, табличка (ромб), сопроводительные документы. Страница руководства: Начальное расстояние изоляции, расстояние защитного действия (день/ночь, малый/большой разлив). IDLH (непосредственная опасность для жизни и здоровья): 30-минутное воздействие без смерти/непоправимого вреда. Зона A (горячая), B (теплая), C (холодная/командная). | Placard 1017 (хлор): Guide 124 → выходить против ветра на 300 м (или больше при ночном инциденте). |
| emergmgmt.ops.mass_casualty_triage | MCI Triage — сортировка приоритетов | METHOD | Массовые потери (MCI): START/JumpSTART система. Теги цвета: Immediate (RED) — угроза жизни но выживет при немедленном лечении. Delayed (YELLOW) — тяжёлый, но не немедленная угроза. Minor (GREEN) — «ходячие раненые». Expectant (BLACK) — несовместимо с жизнью или мёртвый. Цель: максимальное число выживших с имеющимися ресурсами. | Expectant ≠ Dead. При появлении ресурсов: переоценить ожидаемых. |
| emergmgmt.ops.shelter_in_place | Укрытие на месте — протокол | METHOD | «Укройтесь в помещении» (Shelter-in-Place, SIP): при выбросах химических/радиологических веществ. Действия: войти, закрыть окна/двери, выключить вентиляцию/кондиционер, выбрать комнату с минимум окон, герметизировать щели (скотч + влажные полотенца). Мониторинг: радио/TV/Emergency Alerts. Выход по команде властей. | SIP для радиации: «Укрытие на месте значительно снижает дозу» (потолок, стена = 2-10× снижение). |
| emergmgmt.ops.evacuation_zones | Эвакуация — зональная система | METHOD | Зоны эвакуации: Hurricane (USA): Zone A (storm surge risk) → Zone B → Zone C (inland). Color coded (красный, оранжевый, жёлтый). Mandatory evacuation: приказ выехать. Voluntary: рекомендация. Contraflow: все полосы в одном направлении (от побережья). Clearance time: время необходимое для эвакуации зоны. Shadow evacuation: люди из незатронутых зон тоже уезжают (проблема пробок). | Уязвимые: медицинские учреждения, тюрьмы, бездомные требуют специальное планирование. |
| emergmgmt.ops.coop_plan | Непрерывность деятельности — КООП | METHOD | Обеспечение непрерывности деятельности (COOP): Essential Functions: определить какие функции критические. Mission Essential Functions (MEF). Alternate Facility: запасное место (за пределами первичной зоны угрозы). Orders of Succession: замена руководства. Personnel Accountability. Vital Records: защищены и доступны. Devolution: передача функций. | COOP активируется когда primary location недоступна. |
| emergmgmt.ops.warning_dissemination | Системы оповещения — EAS и WEA | METHOD | Системы оповещения: EAS (Emergency Alert System, USA): радио/TV каналы прерываются. WEA (Wireless Emergency Alerts): сотовые телефоны (Presidential, Imminent Threat, AMBER, Public Safety). NOAA Weather Radio: постоянные метеопредупреждения. Outdoor sirens: только для немедленной угрозы (не основной канал — многие не слышат). IP/WebSafety: интернет каналы. | Sirens alone are insufficient: 30-40% людей не слышат или не реагируют. |
| emergmgmt.ops.disaster_recovery_phases | Аварийное восстановление — этапы FEMA | METHOD | Фазы ликвидации последствий (FEMA): Краткосрочное восстановление: поиск и спасение, первая помощь, временное проживание, вывоз мусора (первые дни-недели). Промежуточный уровень: восстановление коммунальных услуг, временные убежища, оценка ущерба (недели-месяцы). Долгосрочная перспектива: постоянное жилье, восстановление экономики, меры по смягчению последствий (месяцы-годы). NDRF (Национальная система аварийного восстановления): RSF (Функции поддержки восстановления). | Long-term recovery: может занять годы (Katrina 2005 — Нью-Орлеан восстановлен к 2010+). |
| emergmgmt.ops.radiological_shelter | Радиационная аварийная ситуация — защитные меры | METHOD | Радиологические ЧС: категории действий — sheltering (убежище снижает дозу на 50-80%), KI (йодид калия): защита щитовидной железы при I-131 выбросе. Эвакуация: при высоких прогнозируемых дозах. Ingestion pathway: ограничение продуктов питания. EPZ zones: Plume Exposure Pathway (~16 км), Ingestion Pathway (~80 км). Emergency dose criteria: FDA PAG (Protective Action Guidelines). | KI эффективен только при I-131. Не защищает от других радионуклидов. |
| emergmgmt.ops.debris_management | Управление мусором — Категории | METHOD | Классификация обломков: Vegetative debris (деревья, ветки): обработка (chipper) → mulch. C&D (Construction & Demolition): сортировка, переработка. HHW (Household Hazardous Waste): специальная переработка. Putrescent waste (пищевые отходы): немедленное размещение. Ineligible: бизнес-debris (не FEMA помощь). TDSR (Temporary Debris Staging/Reduction sites). | Debris monitoring: отслеживание объёма → отчётность для FEMA reimbursement. |
| emergmgmt.ops.animal_emergency_plan | Планирование действий в чрезвычайных ситуациях для животных | METHOD | Планирование содержания животных: Закон о домашних животных (2006 г., США): планы эвакуации должны учитывать домашних животных и скот. ЖИВОТНЫЕ: Общественные, Домашние животные, животные-компаньоны. Аварийный приют для животных. Спасение крупных животных (лошади, крупный рогатый скот): специальное оборудование (стропы, прицепы). Спасение дикой природы: координация с Fish & Wildlife. Ветеринарная неотложная бригада. | 40% домовладельцев не эвакуируются из-за животных (Katrina study). |
| emergmgmt.ops.joint_information_center | JIC — Общественная информация | METHOD | Объединённый информационный центр (JIC): координация публичных коммуникаций при инцидентах. PIOs из каждого агентства → совместные релизы. Message consistency. Social media monitoring: tracking rumors, correcting misinformation. Press briefings: Incident Commander, не только PIO. Hotline: доступ для населения. | Crisis communication: proactive > reactive. Пустота информации = заполняется слухами. |
| emergmgmt.ops.after_action_review | Обзор после принятия мер — FEMA HSEEP | METHOD | Обзор после действия (AAR/IP): Программа учений и оценок национальной безопасности (HSEEP). Происходит после каждого упражнения или реального происшествия. Компоненты: сильные стороны, области для улучшения, рекомендации, корректирующие действия (с ответственным и дедлайном). План улучшения (ИП): предоставление предложений. Участие: весь ключевой персонал. | AAR без Плана реализации = пустая трата времени (извлеченные уроки ≠ извлеченные уроки). |
| emergmgmt.ops.emac_mutual_aid | EMAC — Межгосударственная взаимная помощь | METHOD | Emergency Management Assistance Compact (EMAC): США межгосударственная взаимопомощь. Requesting State: формальный запрос с описанием потребности. Assisting State: предложение ресурсов + reimbursement agreement. Mission Number: отслеживание. Liability waiver: предоставленные ресурсы покрываются принимающим штатом. NIMS compliance: обязательное условие. | EMAC реализован при Katrina: 67 000+ personnel из 54 юрисдикций. |
| emergmgmt.ops.hazard_vulnerability_analysis | HVA — Анализ уязвимостей к опасностям | METHOD | Анализ уязвимости к угрозам (HVA): для медицинских учреждений (модель Кайзера). Смягчение: снизить ограничения/последствие. Остаточный риск: принять. | HVA = ежегодное обновление (угрозы изменяются). |
