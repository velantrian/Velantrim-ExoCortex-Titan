# BATCH 1064: Green Roof — Vegetative Installation

**Namespace:** `greenroof.ops.*`

|---|---|---|---|---|
| greenroof.ops.root_barrier_protection_layer | Корневой барьер — курс защиты | METHOD | Укладка противокорневого барьера поверх гидроизоляционной мембраны для предотвращения прорастания корней растений в кровельный пирог и повреждения водонепроницаемого слоя. | Полиэтиленовая плёнка высокой плотности толщиной 0.4-0.8 мм с добавлением ингибитора корневого роста укладывается с перехлёстом швов 20-30 см и проклеивается специальной лентой создавая непрерывный защитный слой. |
| greenroof.ops.drainage_mat_reservoir_cups | Дренажный коврик — Резервуарные стаканы | METHOD | Монтаж дренажно-накопительного мата с профилированными углублениями для создания водного резервуара под корневой зоной и отвода избыточной влаги в водосточную систему. | Профилированный полиэтилен высокой плотности с чашеобразными углублениями укладывается на защитный слой выступами вниз, и каждая чаша удерживает 3-5 литров воды на квадратный метр для питания растений в засушливые периоды. |

| greenroof.ops.parapet_gravel_fire_break | Парапет — гравийный противопожарный барьер | METHOD | Устройство противопожарной гравийной полосы по периметру зелёной кровли и вокруг всех выступающих конструкций для предотвращения распространения огня. | Полоса промытого гравия фракции 20-40 мм шириной 50-60 см укладывается вдоль парапетов и вокруг вентиляционных шахт, создавая негорючий барьер соответствующий требованиям пожарной безопасности. |
| greenroof.ops.wind_uplift_ballast_edge | Подъем ветра — кромка балласта | METHOD | Усиление крепления краевых зон зелёной кровли дополнительной пригрузкой для противодействия ветровому подъёму незакреплённых слоёв кровельного пирога. | По периметру кровли на ширину 1-1.5 метра укладывается слой гравия или тротуарных плит увеличивающий пригрузку и предотвращающий отрыв краёв мембран и субстрата при штормовых ветрах. |
