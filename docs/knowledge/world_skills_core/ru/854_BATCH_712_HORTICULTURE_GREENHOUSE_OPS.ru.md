# BATCH 712: Horticulture — Greenhouse & Nursery Operations

| horticulture.ops.greenhouse_climate_zones | Теплица — зоны климат-контроля | METHOD | Зонирование климата в теплице: температура днём/ночью (DIF = день - ночь). Положительный DIF (день > ночь): удлинение стеблей. Отрицательный DIF (день < ночь): компактные растения (популярен в цветоводстве). Управление: вентиляция (вентиляторы + форточки), отопление (горячий воздух, трубы), затенение (shade cloth 30-70%). | DIF control: альтернатива химическим регуляторам роста. |
| horticulture.ops.vpd_humidity_management | VPD — дефицит давления паров | METHOD | VPD (Vapor Pressure Deficit): движущая сила транспирации. VPD = SVP(T) × (1 - RH). Оптимум: 0.8-1.2 кПа для большинства культур. Низкий VPD (<0.4 кПа): конденсация, болезни. Высокий VPD (>1.8 кПа): стресс, закрытие устьиц. Управление: туман (увлажнение), вентиляция (снижение влажности). | Ночная конденсация + Botrytis: VPD ночью важен (поддерживать >0.4). |
| horticulture.ops.hydroponic_nft | Гидропоника — Система NFT | METHOD | NFT (Nutrient Film Technique): тонкий слой питательного раствора стекает по каналам. pH: 5.5-6.5. EC (электропроводность): 1.5-3.0 мСм/см (зависит от культуры). Периодическое измерение: 2× в день. Root zone temperature: 18-22°C. Аварийное электропитание: насос не должен останавливаться (корни засыхают). | NFT: эффективен для листовых овощей (lettuce, basil). Не для томатов/огурцов (поверхностная корневая система). |
| horticulture.ops.nutrient_solution_mixing | Питательный раствор — формула | METHOD | Питательный раствор: макроэлементы (N, P, K, Ca, Mg, S), микроэлементы (Fe, Mn, Zn, B, Cu, Mo). Готовые концентраты: A+B (разделены Ca и сульфаты). Смешивание: сначала вода → A → B (не A+B одновременно — осадок CaSO4). Регуляция pH: HNO3 или H3PO4 снижает, KOH поднимает. Chelated iron: Fe-EDTA стабильно при рН 5-7. | Tip burn (ожог кончиков листьев): дефицит Ca при высоком росте (не дефицит Ca в растворе). |
| horticulture.ops.ipm_scouting | IPM — Протокол разведки | METHOD | Мониторинг IPM в теплице: желтые клейкие ловушки (thrips, whitefly, fungus gnats) — 1 ловушка на 100 м², еженедельная проверка. Threshold: 5 thrips/ловушку = низкий, 50 = высокий (действие). Ручная проверка: обратная сторона листьев (spider mite, aphid, scale). Biological indicators: Phytoseiulus (predatory mite) на листьях рядом с паутинным клещом. | Скаутинг — основа IPM. Без мониторинга нет управления. |
| horticulture.ops.propagation_cutting | Вегетативное размножение — стеблевыми черенками. | METHOD | Черенкование: виды — верхушечный (terminal), стеблевой (stem), листовой (leaf). Субстрат: perlite, rockwool, или peat:perlite 50:50. Гормон укоренения: IBA 1000-5000 мг/л (auxin). Туман (misting): интермиттирующий туман поддерживает влажность листьев до укоренения. Температура грунта: 21-24°C. Укрытие: humid propagation tent. | Этилен: стресс-гормон. Гниющий материал в пространстве размножения = этилен = плохое укоренение. |
| horticulture.ops.soil_ph_amending | Выращивание в контейнерах — регулировка pH | METHOD | Коррекция pH грунта: снижение — сера (elemental sulfur), сульфат железа (быстрее). Повышение — кальцит (CaCO3) или доломит (CaMgCO3). Тест: pH/EC метр для субстрата (1:2 водная экстракция). Кислотолюбивые (blueberry, rhododendron): pH 4.5-5.5. Нейтральные (tomato, pepper): pH 6.0-6.8. | Дефицит Fe при высоком pH (>7.0): хлороз молодых листьев (железо не усваивается). |
| horticulture.ops.supplemental_lighting | Дополнительное освещение — DLI | METHOD | DLI (Daily Light Integral): молей фотонов/м²/день. Световая потребность культур: розы = 20-30 mol/m²/day, томаты = 30-40, lettuce = 12-17. Зимой (север) DLI из солнца: 5-10 → добавить досвечивание. SON-T (HPS): 1000 Вт HPS = 12-13 мол/м²/день на 1 м²/час при 400 мкмол/м²/с. LED: кастомный спектр + 30% меньше электричества. | Фотосинтетически активная радиация (PAR): 400-700 нм (μmol/m²/s = PPFD). |
| horticulture.ops.controlled_atmosphere_storage | CA Storage — контролируемая атмосфера | METHOD | Управляемая атмосфера (CA): яблоки в хранилище: O2 1-2%, CO2 2-4%, T 1-3°C. Низкий O2 снижает дыхание. Повышенный CO2 ингибирует этилен → замедляет созревание. ULO (Ultra Low Oxygen): O2 <1% → ещё длиннее хранение. RCA (Rapid CA): быстро снизить O2 после уборки. Этиленовый скруббер (KMnO4). | Без CA: яблоко хранится 2-3 мес. С CA: 8-12 мес. |
| horticulture.ops.disease_identification_fungal | Грибковое заболевание — идентификация | METHOD | Идентификация грибковых болезней: Powdery mildew (мучнистая роса): белый порошок на поверхности листьев (Erysiphe, Oidium). Downy mildew (ложная): пушок снизу листа (Plasmopara, Peronospora). Botrytis (серая гниль): серый пушистый мицелий (при высокой влажности). Pythium (корневые гнили): бурые мокрые корни. Rost (ржавчина): бурые пустулы снизу. | Мучнистая роса против ложной мучнистой росы: милдью на верху → Мучнистая роса. На низу → Пуховый. |
| horticulture.ops.peat_alternatives | Среда выращивания — альтернативы торфу | METHOD | Замена торфа (торфа): экологическая проблема (добыча торфяников = выброс CO2). Альтернативы: кокосовая стружка: нейтральный pH, возобновляемый свет. Кора (коробовая кора): кислая pH, хорошая структура. Компост: питательный. Древесные волокна: богаты углеродом (иммобилизация N). Biochar: поправка pH, улучшение CEC. Запрет ЕС на продажу торфа в розницу (2026 г.). | Coir EC: высокий натрий/хлорид в дешевом coir (buffering required). |
| horticulture.ops.drip_irrigation_greenhouse | Капельное орошение — Равномерность | METHOD | Равномерность системы капельного полива (Distribution Uniformity, DU): DU = (Q min / Q average) × 100%. Target >90% для теплиц. Капельницы: pressure-compensated (0.5-3.0 бар → одинаковый расход). Flow rates: 0.5-4 L/hour. Flush lines: начало и конец сезона. Substrate saturation: % выхода дренажа (обычно 15-30%). | EC runoff > EC input: засоление субстрата → необходимо leaching. |
| horticulture.ops.substrate_analysis | Анализ подложки — PourThrough | METHOD | Метод «вытяжки»(PourThrough, PT): 100 мл воды на контейнер → через 30 мин собрать вытяжку. Измерить pH и EC. Нормы pH: 5.8-6.5. EC: 1.0-2.0 мСм/см (питательный), >3.5 = засоление. Сравнение с SME (Saturated Media Extract): PT pH на 0.2-0.5 выше, EC ×1.5-2.0 ниже SME. | EC >3.5 мСм/см (PT): немедленное leaching (полив до стока). |
| horticulture.ops.pollination_management | Опыление — Ульи шмелей | METHOD | Опыление шмелями в теплицах: Bombus terrestris, B. impatiens. Скорость: 1 улей на 500-1000 растений томата. Вибрационное (buzz pollination): шмель вибрирует цветок → высвобождение пыльцы. Электрическая ручная вибрация (Electric toothbrush): альтернатива. Hive placement: не под прямым солнечным светом, +23-26°C. | Geitonogamy: шмели опыляют соседние цветки одного растения (не cross-pollination). |
| horticulture.ops.fertigation_schedule | Фертигация — Планирование графика | METHOD | Расписание фертигации: feed-feed-water-water cycle (reducing salt accumulation). Утренний полив: лучше усвоение (stomata открыты). Ночной: корневые гнили риск. EC target при поливе: на 0.3-0.5 выше Ес субстрата. Осмотический стресс: EC > 5 → засоление. Leaching fraction 15-30%: предотвращение засоления. | «Feed with every irrigation» стратегия: в коммерческих теплицах (минимизация дефицитов). |
| horticulture.ops.grafting_tomato | Прививка томатов — метод расщелины | METHOD | Прививка томата: на устойчивый подвой (rootstock) для защиты от Fusarium, TSWV, нематод. Метод клефт (split-grafting): срезать привой и подвой под 90° → соединить клипсой. Камбиальный контакт: оба слоя должны совместиться. Aftercare: высокая влажность (95%) × 7-10 дней. Гетерозис корневой: высокая продуктивность при использовании F1 подвоев. | Grafted tomato стоит в 5× дороже обычного саженца, но повышает урожай на 20-40% при проблемном почвенном патогене. |
| horticulture.ops.crop_steering | Управление культурой — генеративное против вегетативного | METHOD | Управление направлением развития культур (crop steering): Generative (формирование плодов): снижение ирригации, высокий EC, высокий VPD → растение «думает» что в стрессе → плоды. Vegetative (вегетативный рост): высокая ирригация, низкий EC, низкий VPD → рост листьев/побегов. Cannabis: мощный инструмент. Tomato: балансирование вегетативный/генеративный на протяжении сезона. | P1 shoot stretch (первые ч/мин после включения света): Generative/Vegetative индикатор. |
| horticulture.ops.disease_monitoring_camera | Мониторинг заболеваний — камера с искусственным интеллектом | METHOD | ИИ-мониторинг болезней: PlantVillage (Penn State), Plantix, Scouting Platforms (Агробиотика). Камеры над рядами → распознавание изображений. Обнаружение плесени, пятен, вредителей. Набор обучающих данных: миллионы изображений с метками. Точность: 70-90% (зависит от освещения, угла, разрешения). Интеграция с поддержкой принятия решений IPM. | Ограничение: необходимо хорошее освещение, последовательное положение камеры. Не заменяет человеческую разведку. |
| horticulture.ops.biological_controls | Биоконтроль — полезные насекомые | METHOD | Биологические агенты для IPM в теплице: Phytoseiulus persimilis → Tetranychus (паутинный клещ). Encarsia formosa → Trialeurodes (белокрылка). Афидиус (оса-паразит) → тля. Steinernema Feltiae (нематода) → грибковые комары. Bacillus thuringiensis (Bt) → гусеницы. Триходерма → Питиум, Фузариум. Спиносад → трипсы. | Только биоконтроль + селективные пестициды: не использовать инсектициды широкого спектра действия (биоагенты). |
| horticulture.ops.ethylene_management | Этилен — Управление при хранении | METHOD | Управление этиленом: этилен = гормон созревания/старения. Продуцируют: яблоко, груша, бананы, помидоры, дыни. Чувствительны: цветы, огурец, брокколи, листовой салат. Разделять в хранении. Scrubbers: KMnO4 (Purafil), catalytic oxidizer (300-400°C). 1-MCP (SmartFresh): блокирует этиленовые рецепторы → задержка созревания. | 1 ppm ethylene в помещении в 12 часов = видимое пожелтение/старение чувствительных культур. |
