# BATCH 1035: Hydroseeding — Turf Establishment

**KnowledgeUnits:** 5
**Namespace:** `hydroseed.ops.*`
**Scope:** slurry, mulch, tackifier, seed_mix, application, water, germination

| ID | KnowledgeUnit | Тип | Суть | Практический смысл |
|---|---|---|---|---|
| hydroseed.ops.tank_mix_recipe | Баковая смесь — пропорции рецепта | METHOD | Состав смесей для гидропосева. На 1000 л воды: Семена (15-30 кг), Мульча из древесного волокна (40-60 кг — для укрытия и влагоудержания), Средство для клейкости (2-4 кг — органический клей), Удобрение (5-10 кг — NPK стартер), Биостимулятор (гуминовая кислота, ламинария). Перемешивание: механическая лопатка + рециркуляционный насос (постоянно! — семена и мульча оседают). Нанесение: помпа + шланг + насадка (вентилятор 25-40°). Расход: 1000 л на 200-400 м². | Mulch без tackifier: смывается первым дождём. |
| hydroseed.ops.nozzle_selection_pattern | Сопло — форма распыления | METHOD | Выбор распылительной насадки. Fan nozzle: 25-40° (широкий, medium velocity). Расстояние: 2-5 м до земли. Перекрытие: 50% (полосы). Толщина слоя: равномерный (не лужи, не голые пятна). Pump pressure: 2-4 бар (low — забивается nozzle, high — сдувает mulch). Очистка: nozzle забивается часто (прочистка wire). | Неравномерное нанесение: где тонко — не всходит, где толсто — плесень. |
| hydroseed.ops.watering_schedule_germination | Полив — график прорастания | METHOD | Полив после гидропосева. Первая неделя: 3-4 раза в день (короткие поливы — keep moist, не мокро!). Вторая неделя: 2 раза в день (длиннее). Третья: 1 раз в день. Четвёртая: через день. Длительность каждого полива: 5-15 мин (зависит от sprinkler). Признак всхода: через 5-10 дней для ryegrass, 10-14 для fescue, 3-4 недели для bluegrass. Не дать mulch высохнуть (сухой mulch = гидрофобный — вода не впитывается потом). | Жара >30°C: поливать чаще (mulch высыхает быстрее). |
| hydroseed.ops.seed_mix_blend_selection | Смесь семян — выбор смеси | METHOD | Подбор смесей семян. Солнце против тени: овсяница мелкая для теней, мятлик Кентукки для солнца. Пробка: райграс многолетний (быстрый износоустойчивый). Климат: прохладный сезон (север), теплый сезон (юг). Быстрое прорастание: райграс однолетний (культура-кормилица — защита остальных, но умирает после года). Пропорция: 3-5 видов. Расценка: 15-25 кг/1000 м². Местная экосистема: местные травы (бутелуа, буйволиная трава для прерий). | Annual rye быстро всходит (3-5 дней) — доверие клиента. |
| hydroseed.ops.slope_application_technique | Уклон — Применение | METHOD | Гидропосев на склоне. Угол: до 2:1 (26°) с mulch, до 1:1 (45°) с BFM (Bonded Fiber Matrix). BFM: mulch + порошковый tackifier замешан в tank — создаёт сплошной ковёр. Нанесение: сверху вниз! (вода стекает — не размывает нижнюю часть). Двойной проход: первый вертикальный, второй горизонтальный. Не ходить по свежей гидросмеси! | BFM дороже, но для крутых склонов обязательно. |
