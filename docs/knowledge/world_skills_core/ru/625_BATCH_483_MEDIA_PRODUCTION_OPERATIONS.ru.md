| media.ops.tv_studio_control_room | Телестудия — Операции диспетчерской | PROCESS | Производство телепрограммы. Роли: Director (художественное руководство — команды переключения камер), TD (Technical Director — нажимает кнопки на vision mixer по командам Director), Audio Engineer (микшер — баланс микрофонов, музыка, эффекты), Graphics Operator (титры, lower thirds, full-screen graphics), Teleprompter Operator (скорость прокрутки по speech rate ведущего), EVS Operator (instant replay — повторы), CCU Operator (Camera Control Unit — настройка диафрагмы, баланс белого для каждой камеры удалённо). Pre-production: script + rundown (помежутный план — тайминг каждого сегмента до секунд). Live-to-tape: программа записывается как живая (минимальные остановки, пересъёмка только при критических ошибках). live: transmission через playout server (спутник/оптика/стриминг). Время на передачу: 3-2-1 → black (2 сек) → bars & tone (1 кГц, 30 сек) → slate (название, дата, продолжительность) → countdown (10 to 0) → program start. | Comms: intercom system (RTS/Drake) — Director говорит всем одновременно («camera 3 готовь крупный план»), camera operators отвечают. Роль Floor Manager: связь между Control Room и студией через жесты (15 sec, 30 sec, wrap up, speak up) + гарнитуру. |
| media.ops.radio_broadcasting | Радио — прямая трансляция и автоматизация | METHOD | Эфирная аппаратная. On-air console (микшерный пульт — каналы: microphone, phone hybrid для звонков, CD/компьютер, сетевой фид, запасной). Processing (audio processor — Orban/Optimod: компрессия, эквализация, пик-лимитирование для максимальной громкости без искажений). Automation software (Zetta/RCS/DALET): playlist на основе clock (шаблон часа: news в начале, songs, sweeper/джингл между песнями, реклама в фиксированных блоках). Voice tracking: DJ записывает свои подводки к песням заранее (для ночных эфиров/выходных) → automation вставляет их между песнями с плавным fade. Live assist: automation играет songs, DJ живьём говорит поверх intro/outro. Emergency: silence detector — если тишина >30 сек → играет emergency playlist/mini-CD. EAS (Emergency Alert System): обязательное оборудование, мониторит alerts, перебивает эфир для экстренных сообщений. | Radio без человека: automation + voice tracking позволила одному DJ вести эфир на 3-5 станциях в разных городах. Fader start: открытие фейдера микрофона автоматически ставит на паузу/убавляет громкость других источников (automatic ducking). |
| media.ops.newsroom_editorial_workflow | Газета — Редакционный процесс | PROCESS | Производство газеты от идеи до печати. 1) Assignment (редактор распределяет темы журналистам — daily news meeting), 2) Research (интервью, документы, данные), 3) Writing (журналист пишет в CMS — Content Management System: K4, CUE), 4) Sub-editing (редактура — фактчекинг, стиль, grammar, legal check — libel risk?), 5) Photo desk (выбор/кадрирование фото, caption), 6) Page design (верстальщик размещает текст + фото + рекламу в InDesign/QuarkXPress по макету), 7) Proofreading (корректор читает полосы — орфография, переносы, widow/orphan lines), 8) Editor sign-off (редактор утверждает полосу), 9) Pre-press (цветоделение CMYK, растрирование, PDF/X-1a для печати), 10) Print (offset, web press — бумага из рулона 5-10 тонн, скорость 40000-80000 экз/час), 11) Distribution (автофургоны развозят пачки по киоскам/магазинам к 5-7 утра). Deadline: новости — до 23:00, спорт — до 00:30, последние новости (stop press) — до 01:30. | Libel check (клевета): sub-editor проверяет утверждения на предмет defamation (правда ли? можно ли доказать? public figure — надо доказать actual malice?). Ошибка = lawsuit на $100K+. Фотография: для публикации фото человека нужно разрешение (model release) для коммерческого использования (editorial — less strict). |
| media.ops.video_editing_workflow | Монтаж видео — нелинейный рабочий процесс | METHOD | NLE (Non-Linear Editing): Adobe Premiere Pro, Final Cut Pro, DaVinci Resolve. Пайплайн: 1) Ingest (перенос материала с карт памяти камер, перекодирование в editing codec — ProRes, DNxHD/HR, транскодирование H.264/HEVC долго редактировать), 2) Sync (аудио с внешнего рекордера синхронизируется с видео по waveform или timecode), 3) Assembly (черновой монтаж — все выбранные дубли подряд в хронологии), 4) Rough cut (убрать лишнее, сформировать структуру), 5) Fine cut (точный монтаж, pacing, ритм, J/L cuts — звук следующей сцены начинается до изображения), 6) Picture lock (видео зафиксировано, дальше sound и color), 7) Sound edit (чистка шумов, Foley, ADR — перезапись реплик, sound effects, music), 8) Sound mix (балансировка уровней, surround 5.1/7.1/Atmos), 9) Colour grade (DaVinci — первичная коррекция: exposure, white balance, контраст; вторичная: look/стиль — teal & orange, desaturated), 10) Export (master file ProRes 4444), 11) Deliverables (broadcast spec, web version, social media vertical). | Редактирование H.264 native — CPU-intensive (inter-frame compression — каждый кадр зависит от соседних). ProRes — intra-frame (каждый кадр независим) — плавное редактирование, но файлы в 3-5 раз больше. |
| media.ops.podcast_production | Подкаст — Рабочий процесс производства и публикации | PROCESS | Производство подкаста. Подготовка к производству: тема, сценарий/план, гости (предварительное интервью 15-20 минут для проверки химии). Запись: микрофоны (динамический — Shure SM7B, RE20 — стандарт; конденсаторный — более интенсивный, но ловит комнатный тон), аудиоинтерфейс (Focusrite, Rodecaster Pro), запись на 2-4 отдельных дорожках (мультидорожечный для пост-продакшн). Этикет записи: обязательно наушники (слышать себя и следить за обратной связью), микрофон на расстоянии 10-15 см от рта, поп-фильтр. Пост-продакшн: шумоподавление (iZotope RX), деэссер (убрать свистящие «с-с-с»), компрессия (выравнивание уровней), эквалайзер (обрезка низких частот <80 Гц — убрать гул), лимитер (пик −0,1 dBFS для предотвращения клиппинга). Экспорт: моно/стерео, 44,1 кГц 16-битный WAV мастер → сжатие в MP3 128-192 кбит/с моно для подкаста (голос не требует стерео). Показывать заметки: сводку, временные метки, ссылки. Публикация: RSS-канал (хостинг — Libsyn, Anchor, Buzzsprout) → автоматически распространяется на Apple Podcasts/Spotify/Google Podcasts через RSS. | Loudness стандарт для подкастов: −16 LUFS (Loudness Units Full Scale) для стерео, −19 LUFS для mono (Apple Podcasts, Spotify). Громче → платформа нормализует, звучит хуже. Room treatment: запись в необработанной комнате = эхо/реверберация (звучит как туалет). Решение: акустические панели (rockwool/fiberglass) на первых отражениях + ковёр. |
| media.ops.pre_press_color | Допечатная подготовка — управление цветом и PDF/X | METHOD | Подготовка макета к печати. Цветовая модель: RGB (экран) → CMYK (печать — голубой, пурпурный, жёлтый, чёрный). Конвертация: в Photoshop/InDesign/Acrobat при конвертации в CMYK использовать правильный ICC-профиль (FOGRA39 для Европы, GRACoL для США; зависит от типа бумаги и печатной машины). Total ink coverage: сумма C+M+Y+K не более 280-320% (зависит от бумаги — мелованная 300-320%, немелованная 260-280%). Rich black для крупных плашек: 60C/40M/40Y/100K (просто 100K даёт сероватый, не глубокий чёрный). Overprint vs knockout: белый текст на цветном фоне — должен быть knockout (не overprint — иначе не напечатается). Trapping: компенсация несовмещения красок (0.08-0.15 мм расширение светлой краски под тёмную). PDF/X-1a (стандарт обмена для печати): все шрифты встроены (embed), изображения 300 dpi, CMYK, trim box и bleed box (3-5 мм навылет). Preflight (проверка в Acrobat/PitStop): проверяет fonts, разрешение, overprint, bleed. | Самая частая ошибка: RGB-изображения в макете — при конвертации цвета становятся тусклыми (RGB имеет более широкий охват чем CMYK, особенно яркие зелёные/синие). Клиент видит на экране ярко, в печати тускло → недоволен. Soft proofing (View → Proof Colors в Photoshop с правильным профилем) показывает как будет выглядеть в печати. |
