| sportsanalytics.ops.expected_goals | Футбол — Ожидаемое количество голов (xG) | METHOD | Ожидаемые голы (xG): вероятность гола из конкретной позиции. Компоненты: расстояние, угол, тип удара, часть тела, предшествующее действие. Создаётся с помощью исторических данных + логистической регрессии. xG > Score: команда была лучше чем результат. Post-shot xG (PSxG): учитывает качество удара. | xG оверперформанс/андерперформанс: долгосрочная реверсия к среднему. |
| sportsanalytics.ops.war_baseball | Бейсбол — расчет WAR | METHOD | Победы выше замены (WAR): всё в одном хиттальном показателе. Для батеров: wRAA (ватин) + BsR (базовый бег) + UZR или DRS (филдинг) + корректировка положения. Для питчеров: WAR на базе FIP (FanGraphs). Замена: замена плеера уровня (уровень ААА). 2 WAR = стартер, 5+ WAR = Матч звезд, 8+ WAR = MVP. | FIP (Fielding Independent Pitching): только контролируемые результаты для питчера. |
| sportsanalytics.ops.player_tracking_gps | Отслеживание GPS-плеера — метрики | METHOD | GPS-мониторинг: VMAX (максимальная скорость). Общее расстояние. Высокоскоростной бег (ВСР) > 5,5 м/с. Спринт (SPR) > 7,0 м/с. Дистанция HML (высокая метаболическая нагрузка). Ускорения/замедления за игру. Управление нагрузкой: соотношение острой и хронической нагрузки (ACWR). Оптимальный ACWR: 0,8-1,3. | ACWR > 1.5: повышенный риск травмы (Gabbett research). |
| sportsanalytics.ops.nba_plus_minus | Баскетбол — варианты плюс-минус | METHOD | Показатели «плюс/минус» в баскетболе: Raw ±: разница очков при игре на площадке. BPM (блок плюс/минус): скорректированный по статистике. РАПТОР (FiveThirtyEight): отслеживание игроков + статистика бокса. EPM (расчетный плюс/минус). RPM (Реал Плюс-Минус, ESPN). ВОРП (Ценность выше замены). | On/Off splits: команда vs замена → реальный вклад. |
| sportsanalytics.ops.injury_prediction | Прогнозирование травм — модели машинного обучения | METHOD | Предсказание травм: Features: нагрузка (тренировка + игры), история травм, биомеханика, сон, мышечная асимметрия (FMS, Nordbord). ML алгоритмы: логистическая регрессия, случайный лес, XGBoost. Imbalanced dataset (мало травм). SMOTE (oversampling). ROC-AUC: метрика. Wearables data fusion. | Проблема: «пропускаемые» исходы (class imbalance), задержка получения данных. |
| sportsanalytics.ops.tennis_serving | Теннис — Сервис аналитики | METHOD | Аналитические предложения в теннисе: % эйсов, % двойных ошибок, % первой подачи/выигранных очков. Сохранение точки останова%. Возвратные игры выиграны. RPW (выигранные очки за возврат). Обороты топ-спина. Скорость мяча миль в час. Судебное освещение. Подача направлений оппонентом. | Hawk-Eye: точность позиций мяча ±2.6 мм. Ball tracking data. |
| sportsanalytics.ops.basketball_offensive_rating | Баскетбол — Рейтинг нападения | METHOD | OffRtg (рейтинг нападения) = очки за 100 владений. DefRtg = разрешенное количество очков за 100. NetRtg = OffRtg — DefRtg. Оценка по формуле: Poss = FGA - OREB + TO + 0,44 × FTA. Темп: # владений за 48 мин. % истинной стрельбы (TS%) = очки / (2 × (FGA + 0,44 × FTA)). | NetRtg — выигрыш%. Каждые +5 NetRtg ≈ +10 побед в НБА. |
| sportsanalytics.ops.soccer_progressive_passes | Футбол — Прогрессивные действия | METHOD | Прогрессивные действия в футболе (StatsBomb/Opta): Progressive passes: продвигают мяч ≥10 метров к воротам. Progressive carries: дриблинг с продвижением. Progressive distance: суммарная. Open play passes into final third. xA (Expected Assists): вероятность что пас приводит к голу. PPDA (Passes Allowed Per Defensive Action): intенсивность прессинга. | PPDA < 8: очень высокое прессинг. PPDA > 12: низкий прессинг. |
| sportsanalytics.ops.nfl_epa | Американский футбол — добавлено ожидаемое количество очков | METHOD | Добавлено ожидаемых очков (EPA): ожидаемые очки следующего тока (Expected Points) − очки после действия. EPA/Play: эффективные действия. DVOA (значение выше среднего, скорректированное на защиту): футбольные аутсайдеры. WPA (добавлена ​​вероятность победы): вклад в вероятность победы. EPA по позициям: DYAR, DPAR. | EPA на третий даун: наиболее ценный контекст. |
| sportsanalytics.ops.hockey_corsi | Хоккей — Корси и xG | METHOD | Хоккейная аналитика: Corsi (C+/C-): shot attempts включая миссы и блоки. CF% (Corsi For%): % shot attempts при команде на льду. Expected Goals (xG): вероятность гола по типу броска. Zone Entries: как часто входят в зону с контролем. Fenwick: как Corsi без блоков. | Corsi 50%: нейтральная. >55% = высокая контроль. |
| sportsanalytics.ops.cricket_drs | Крикет — DRS и аналитика | METHOD | Аналитика крикета: Средний уровень ударов, частота ударов. Эконом-тариф (боулинг). Колесо телеги: карта распределения выстрелов. Hawkeye: DRS (Decision Review System) — отслеживание мяча. Отслеживание мяча → Решение LBW. Червячная диаграмма: работает с течением времени. Ход подач матча. | Маржа DRS: в пределах 2,5 мм = «по решению судьи». |

Распознавание действия: временная CNN. Переидентификация игрока (ReID). Гомография: перспективное преобразование в 2D. Оптический поток: движение объектов. Автоматическое обнаружение событий (гол, отбор, спринт). | Замена компьютерного зрения вручную, разметка: в 10-20 раз быстрее. |
| sportsanalytics.ops.draft_value | Предварительное значение — модели оценки | METHOD | Оценка игроков на драфте: Исторические результаты → снизить производительность до позиции драфта. Прогнозирование физических качеств (бег на 40 ярдов, вертикальный прыжок). Оценка риска травм. Объедините балл + студенческую успеваемость + возраст. | sportsanalytics.ops.fatigue_monitoring | Мониторинг усталости — HRV | METHOD | Мониторинг усталости: ВСР (вариабельность сердечного ритма): rMSSD. ↓ ВСР = повышенная нагрузка/усталость. Оценочные листы: POMS (Профиль состояний настроения), RPE (Степень воспринимаемого напряжения). Маркеры крови: КК (мышечный распад), кортизол, коэффициент тестостерона. | sportsanalytics.ops.home_field_advantage | Преимущество домашнего поля — статистика | METHOD | Преимущество родного поля: НБА: ~3 очка за игру (с болельщиками). MLB: ~0,04 пробега за игру.
