# BATCH 818: Statistics — Biostatistics & Research Methods

**KnowledgeUnits:** 18
**Namespace:** `statistics.ops.*`
**Scope:** hypothesis_testing, confidence_intervals, regression, survival_analysis, systematic_review, RCT, cohort, case_control, Bayesian, power_calculation

| ID | KnowledgeUnit | Тип | Суть | Практический смысл |
|---|---|---|---|---|
| stats.ops.null_hypothesis_testing | Проверка гипотез — типы ошибок | METHOD | Проверка гипотез: H0 (нулевая) vs H1 (альтернативная). Ошибка типа I (α): отклонить H0 при её истинности (ложная тревога). Ошибка типа II (β): не отклонить H0 при ложной (пропустить эффект). Мощность (1-β): вероятность обнаружить истинный эффект. Стандартные: α = 0.05, 1-β = 0.80. | p < 0.05 НЕ = «важно» или «большой эффект». Только «маловероятно случайно». |
| stats.ops.confidence_interval | Доверительные интервалы — интерпретация | METHOD | Доверительный интервал: 95% CI = если бы мы повторили исследование многократно, 95% CI включали бы истинное значение. НЕ означает: «95% вероятность, что истинное значение здесь». ДИ НЕ содержит 1.0 (для RR/OR): статистически значимо. Width = precision. | Узкий ДИ = большая выборка + более точный. Широкий = неопределённость. |
| stats.ops.rct_design | RCT — ключевые особенности конструкции | METHOD | Рандомизированное контролируемое исследование: Randomization: снижает систематическую ошибку. Allocation concealment: последовательность скрыта до randomization. Double-blind: исследователь + пациент не знают. Intention-to-treat (ITT): анализируют всех рандомизированных. Per-protocol: только соответствующих. CONSORT diagram. | ITT сохраняет баланс рандомизации; ПП потенциально предвзят. |
| stats.ops.kaplan_meier | Анализ выживания — Каплан-Мейер | METHOD | Анализ выживаемости: Kaplan-Meier кривая: «лестничная» ступенчатая вероятность. Цензурирование: lost to контрольный звонок или конец исследования. Log-rank test: сравнение кривых. Медиана выживаемости: время при 50% вероятности. Cox proportional hazard: регрессия с covariates. HR (Hazard Ratio). | HR = 1: нет различия. HR < 1: снижение риска. HR > 1: повышение риска (при событии = плохое исходе). |
| stats.ops.number_needed_treat | NNT — количество, необходимое для лечения | METHOD | Число больных, которых необходимо лечить (NNT): NNT = 1/ARR. ARR = CER - EER (Частота контрольных событий - Частота экспериментальных событий). RRR = (CER - EER)/CER. NNH (число, необходимое для нанесения вреда) = 1/ARI. NNT < 10 = хороший эффект лечения. | NNT = 1: каждое рассматриваемое пособие. ЧННТ = 100:1 из 100. |
| stats.ops.cohort_study | Когортное исследование — Дизайн | METHOD | Когортное исследование: экспозированные vs неэкспозированные → контрольный звонок → исходы. Проспективное: вперёд во времени. Ретроспективное: на основе существующих записей. Relative Risk (RR): хорошо для частых событий. Attrition bias при потере к наблюдению. | Когорта: может измерить заболеваемость. Случай-контроль: только соотношение шансов. |
| stats.ops.systematic_review_meta | Систематический обзор — Методы | METHOD | Системный обзор + мета-анализ: PICO (Population, Intervention, Comparator, Outcome). Контрольный список ПРИЗМА. Поиск в нескольких базах данных (Medline, Cochrane, Embase). Оценка качества: ROB-2 (Кокрейн). Лесной участок: точечные оценки + ДИ. Неоднородность: I² (>50% = направления). Воронкообразный график: предвзятость публикации. | «Весовой анализ» в мета: большие исследования = больший вес. |
| stats.ops.regression_logistic | Логистическая регрессия — интерпретация | METHOD | Логистическая регрессия: для бинарных исходов. Коэффициент → Odds Ratio = e^β. Adjusted OR: учтены ковариаты. Hosmer-Lemeshow test: goodness of fit. ROC-AUC: дискриминационная способность. AUROC = 0.5 = не лучше случая, 1.0 = идеальная. С-statistic. | Многомерный: все covariates в модели одновременно → adjusted OR. |
| stats.ops.bayesian_inference | Байесовская статистика — основы | METHOD | Байесовская статистика: P(H | Д) = Р(Д | H) × P(H) / P(D). Prior probability × Likelihood = Posterior. Обновление убеждений. В отличие от frequentist: incorporates prior knowledge. Bayesian credible interval: «95% вероятность что параметр в интервале» (истинное утверждение). | «Bayesian» updating: как мы учимся на опыте — каждое новое исследование обновляет prior. |
| stats.ops.propensity_score | Оценка склонности — соответствие | METHOD | Метод оценки склонности (PSM): для наблюдательных исследований. Оценка склонности = вероятность получения лечения по ковариатам. Соответствие: парные экспонированные/неэкспонированные с одинаковым баллом. Взвешивание обратной вероятности (IPW). Проверка баланса после сопоставления. Ограничения: неизмеренные помехи. | ПСМ ≠ рандомизация. Только измеренные конфаундеры сбалансированы. |
| stats.ops.forest_plot | Лесной участок — Ридинг | METHOD | Лесная диаграмма (Forest Plot): каждая строка = исследование. Точка = эффект. Горизонтальные усы = ДИ. Ромб = суммарный эффект. Vertical line at 1 (RR/OR) или 0 (MD): нет эффекта. Если ДИ пересекает = нет статистически значимого. Вес: размер квадрата. | Forest plot «дом» правила: если ромб слева от 1 = benefit (снижение риска). |
| stats.ops.diagnostic_test_analysis | Диагностический тест — байесовский | METHOD | Диагностический тест: Претестовая вероятность (распространенность). LR+ = Чувствительность / (1-Специфичность). LR- = (1-Чувствительность)/Специфичность. Вероятность после теста: номограмма Фагана или Байеса. Стандарт: PPV и NPV зависят от распространенности. Номограмма Дикса и Альтмана: LR → изменения вероятности. | LR+ > 10: сильное подтверждение. LR- < 0.1: сильное исключение. |
| stats.ops.sample_size_power | Размер выборки — расчет мощности | METHOD | Расчёт размера выборки: зависит от ожидаемого эффекта, α, β (мощности), вариабельности. n = 2 × [(Z_α/2 + Z_β)² × σ²] / d². Одностороннее vs двустороннее. MCID (Minimal Clinically Important Difference). A priori vs post hoc мощность. Software: GPower, R, PASS. | «Недостаточная мощность»: пропускает эффекты. «Чрезмерная мощность»: этически — лишние участники. |
| stats.ops.bias_types | Предвзятость — типы в исследованиях | METHOD | Виды систематических ошибок: Предвзятость отбора: кто включен. Погрешность информации/измерений: по мере сбора данных. Предвзятость наблюдателя. Напомним, предвзятость: пациенты помнят иначе. Смещение времени выполнения заказа (скрининг). Смещение длины и времени (переоценка выживаемости). Предвзятость наблюдения. Эффект Хоторна: изменение поведения при наблюдении. | Confounding ≠ bias: confounding = третья переменная, связанная с обоими. |
| stats.ops.clinically_important_vs_statistical | Статистическая и клиническая значимость | METHOD | Статистическая ≠ клиническая значимость: при большой выборке малый эффект = статистически значимый. Клиническая значимость: измеряется MCID. GRADE: уровни доказательств (High/Moderate/Low/Very Low). Effect size measures: Cohen's d, NNT, RRR. P-value реформы: многие journals теперь требуют CI + effect size. | «Клинически незначимое, но статистически значимое»: при n>10 000 часто. |
| stats.ops.interrupted_time_series | Прерванный временной ряд — анализ | METHOD | Прерванные временные ряды (ITS): коэффициент регулирования без рандомизации. Тенденция до вмешательства и после вмешательства. Модели АРИМА. Автокорреляция: соседние точки зрения. ITS контролирует: исторические тенденции, сезонность. ITSA: Сегментированная регрессия. Ограничения: одновременные события. | ITS: когда RCT нецелесообразен (программа на всю популяцию). |
| stats.ops.cluster_randomized | Кластерное рандомизированное исследование | METHOD | Кластерно-рандомизированное исследование: рандомизируются группы (кластеры), не индивиды. Необходимо для интервенций на уровне кластера (школа, деревня). Intracluster Correlation Coefficient (ICC). Design Effect = 1 + (m-1) × ICC. Larger sample needed: inflate n by design effect. | ICC высокий: члены кластера похожи → меньше «эффективных» единиц. |
| stats.ops.measurement_validity | Валидность измерения — типы | METHOD | Валидность измерения: Content validity: измеряет все домены. Criterion validity: concurrent vs predictive. Construct validity: соответствует теоретическому конструкту. Face validity: кажется правильным. Convergent: коррелирует с аналогичными. Discriminant: не коррелирует с несвязанными. CFA (Confirmatory Factor Analysis). | Reliability ≠ validity: можно быть точным и неправильным. |
