# BATCH 849: Social Sciences — Research Methods & Theory

**KnowledgeUnits:** 14
**Namespace:** `socialscires.ops.*`
**Scope:** qualitative_methods, survey_design, ethnography, grounded_theory, discourse_analysis, mixed_methods, action_research, social_constructionism

| ID | KnowledgeUnit | Тип | Суть | Практический смысл |
|---|---|---|---|---|
| socialscires.ops.qualitative_validity | Качественные исследования — надежность | METHOD | Достоверность качественных исследований (Линкольн и Губа): Достоверность: длительность вовлечённости + триангуляция + проверка участников. Переносимость: толстое описание. Надежность: контрольный журнал. Подтверждаемость: рефлексивность. Аналоговая количественная надежность/валидность. | Member checking: подтвердить интерпретации у участников. |
| socialscires.ops.grounded_theory | Обоснованная теория — Штраус и Корбин | METHOD | Обоснованная теория (Glaser & Strauss): теория, возникающая из данных. Open coding → Axial coding (категории + свойства) → Selective coding (core category). Theoretical sampling: новые участники пока не достигнута теоретическая насыщенность. Constant comparison method. | Grounded theory ≠ inductive only: создаёт теорию (не проверяет). |
| socialscires.ops.ethnographic_fieldwork | Этнография — Полевая работа | METHOD | Этнография: посещение участия в изучаемой культуре. Эмическая (инсайдерская) точка зрения. Полевые примечания: описательные + аналитические. Ключевые информаторы. Культурные артефакты. Привратники: требования для доступа. Рефлексивность: роль исследователя влияет на данные. Эффект Хоторна. | Micro-ethnography: короткие, focусированные полевые исследования (не годы). |
| socialscires.ops.survey_response_bias | Опросное исследование — Типы предвзятости | METHOD | Систематические ошибки при опросах: Social desirability bias: социально желаемые ответы. Acquiescence bias: tendency to agree. Recall bias. Non-response bias: кто отказал. Leading questions. Pilot testing: необходимый перед развёртыванием. Randomized response technique: для чувствительных вопросов. | Likert scale: 5-7 пунктов. Нечётное число: нейтральный вариант. |
| socialscires.ops.discourse_analysis | Анализ дискурса — критический | METHOD | Критический дискурс-анализ (CDA, Fairclough): язык = социальная практика. Три измерения: Текст + Дискурсивная практика + Социальная практика. Властные отношения в тексте. Лексический выбор: что выбрано/исключено. Пассивизация: снятие ответственности. Предпосылки. | Ideological analysis: как текст натурализует власть? |
| socialscires.ops.focus_group_design | Фокус-группа — Дизайн и модерация | METHOD | Фокус-группа: 6-10 участников + модератор. Homogeneous group: лучше обсуждение. Пилотный guide: вопросы от широких к узким. Warm-up. Проявные вопросы. Note-taker. Recording. Analysis: thematic. Limitations: social conformity + dominant participants. | «Grand tour questions»: широкие открытые для начала. Не закрытые вопросы. |
| socialscires.ops.mixed_methods | Смешанные методы — триангуляция | METHOD | Смешанные методы: количество + качество. Последовательное пояснение: quan → qual (объяснить). Последовательное исследование: qual → quan (развить). Параллельная триангуляция: оба одновременно. Приоритет + Последовательность. Смешение: при сборе, анализе или интерпретации. | QUAN+qual vs quan+QUAL: прописные буквы = доминирующий. |
| socialscires.ops.action_research | Совместное исследование действий | METHOD | Партиципаторные исследования-действия: участники = исследователи. Решайте реальные проблемы. Циклы: планировать → действовать → наблюдать → размышлять. Критический эмансипаторский подход (Фрейре). CBPR (Исследования на уровне сообществ): в общественном здравоохранении. | «Nothing about us without us»: принцип включения маргинализованных. |
| socialscires.ops.interpretivism | Интерпретивизм — онтология и эпистемология | METHOD | Интерпретивизм: Социальная реальность = социально сконструированная. Множественные реальности. Герменевтика: интерпретация смысла. Верстехен (Вебер): Понимать социальное действие изнутри. Феноменология (Гуссерль, Хайдеггер): жизненный опыт. Символический интеракционизм (Мид, Блумер). | Позитивизм против интерпретивизма: война парадигм. Смешанные методы = прагматичный ответ. |
| socialscires.ops.narrative_research | Нарративное исследование — история | METHOD | Нарративные исследования: истории = первичные данные. Биографический подход. Исследование истории жизни. Нарративное исследование (Кландинин и Коннелли): исследование-история-опыт. Трехмерное пространство: временность + социальность + место. Ресторинг: пересказ повествований. | Нарративная идентичность: «Кто я?» = «Какова моя история?» |
| socialscires.ops.systematic_lit_review | Систематический обзор литературы — ПРИЗМА | METHOD | Системный обзор литературы: PRISMA 2020. Поиск по базам данных + серая литература. Критерии включения/исключения. ПРОСПЕРО регистрация. Показ: аннотация → полный текст. Таблица извлечения данных. Оценка качества: ROBINS-I (наблюдательная), ROB2 (РКИ). Гетерогенность: I²>50 % = метаанализ проблематичен. | Описательный или систематический обзор: описательный = экспертное заключение. Систематический = прозрачный, воспроизводимый. |
| socialscires.ops.constructivism_education | Конструктивизм — Теория образования | METHOD | Конструктивизм в образовании: знание строится активно. Когнитивная (Пиаже): ассимиляция + аккомодация. Социальный (Выготский): ЗПД + строительные леса. Проблемно-ориентированное обучение (PBL). Обучение, основанное на запросах. Экспериментальное обучение (Колб): конкретный опыт → размышление → абстрактная концептуализация → активное экспериментирование. | Рецептивное обучение (Ausubel): тоже конструктивистское (advance organizers). |
| socialscires.ops.sociological_imagination | Социологическое воображение — Миллс | METHOD | Социологическое воображение (Ч. Райт Миллс, 1959): связь между частными бедами и общественными проблемами. Личная биография + исторические условия. «Каждая индивидуальная жизненная проблема в некотором роде является результатом действия социальных сил». Исследование: перевод личных проблем в общественные проблемы. | Mills пример: безработица — не личная неудача, а структурная проблема. |
| socialscires.ops.feminist_research | Методология феминистских исследований | METHOD | Феминистские методы исследования: центрирование женского опыта. Теория точки зрения (Хартсок): знание позиционировано. Рефлексивность о власти исследователя. Антииерархические исследовательские отношения. Совместные подходы. Интерсекциональность (Креншоу). | «The personal is political» — феминистский слоган + методологический принцип. |
