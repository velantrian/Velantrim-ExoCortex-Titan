# BATCH 541: Medicine — Physiology & Pathophysiology

**KnowledgeUnits:** 21
**Namespace:** `medicine.physiology.*`
**Scope:** homeostasis, cardiovascular_physiology, respiratory_physiology, renal_physiology, acid_base, endocrine_physiology, neurophysiology, gastrointestinal_physiology.

| ID | KnowledgeUnit | Тип | Суть | Практический смысл |
|---|---|---|---|---|
| medicine.physiology.homeostasis | Гомеостаз | INVARIANT | Поддержание постоянства внутренней среды (Клод Бернар, Уолтер Кэннон). Отрицательная обратная связь: датчик → центр интеграции → эффектор → коррекция. Положительная обратная связь (редко): роды (окситоцин), потенциал действия. | Все системы организма работают на поддержание гомеостаза. Болезнь = нарушение гомеостаза. |
| medicine.physiology.cardiac_output | Сердечный выброс (CO) | INVARIANT | CO = HR × SV (частота сердечных сокращений × ударный объём). В покое ~5 л/мин. Определяется: преднагрузка (закон Франка-Старлинга: растяжение → сила), постнагрузка (сопротивление выбросу), сократимость (инотропия). | Сердечная недостаточность: снижение CO → гипоперфузия органов. Инотропы (добутамин) повышают сократимость. |
| medicine.physiology.blood_pressure_reg | Регулирование артериального давления | PROCESS | АД = CO × ОПСС (общее периферическое сопротивление). Барорефлекс: каротидный синус и дуга аорты → продолговатый мозг → автономная нервная система. Быстрая (секунды, нервная) и медленная (минуты-часы, RAAS, почки) регуляция. | Симпатическая система: ↑ЧСС, ↑сократимость, вазоконстрикция. Парасимпатическая (вагус): ↓ЧСС. |
| medicine.physiology.respiratory_mechanics | Механика легких и объемы | INVARIANT | Дыхательный объём (TV ~500 мл), резервный объём вдоха (IRV), выдоха (ERV), остаточный (RV ~1200 мл). ЖЕЛ = TV+IRV+ERV (~4.5 л). Функциональная остаточная ёмкость FRC = ERV+RV (≈ 2.5 л, точка равновесия лёгких и грудной клетки). | Рестриктивные заболевания (фиброз) — все объёмы снижены. Обструктивные (ХОБЛ, астма) — повышены RV и FRC (воздушная ловушка), снижена скорость выдоха ОФВ₁. |
| medicine.physiology.gas_exchange | Газообмен и согласование V/Q | PROCESS | Диффузия O₂ и CO₂ через альвеолокапиллярную мембрану (0.2-0.5 мкм). Вентиляционно-перфузионное соотношение V/Q. Идеально V/Q≈0.84. Шунт (V/Q=0, кровь не оксигенируется — ателектаз, пневмония). Мёртвое пространство (V/Q=∞, вентиляция без перфузии — ТЭЛА). | Гипоксемия: 5 механизмов (гиповентиляция, нарушение диффузии, шунт, V/Q несоответствие, снижение FiO₂). |
| medicine.physiology.glomerular_filtration | СКФ и функция почек | INVARIANT | СКФ = 120 мл/мин = 180 л/сут первичной мочи. 99% реабсорбируется! Определяется: гидростатическое давление в клубочке (↑), онкотическое давление плазмы (↓), давление в капсуле Боумена (↓). K_f — коэффициент фильтрации. | Креатинин — удобный маркер СКФ (вырабатывается с постоянной скоростью из мышц, фильтруется, не реабсорбируется). СКФ по CKD-EPI: учитывает креатинин, возраст, пол, расу. |
| medicine.physiology.tubular_function | Канальцевая реабсорбция и секреция | PROCESS | Проксимальный каналец: активный транспорт Na⁺ (и вода осмотически) — 65%, глюкоза (SGLT2) — 100% до порога (~10 ммоль/л), аминокислоты, HCO₃⁻. Петля Генле: восходящее колено активно реабсорбирует Na⁺, K⁺, Cl⁻ (NKCC2). Дистальный каналец + собирательная трубка: альдостерон (Na⁺), АДГ/вазопрессин (вода, аквапорины-2). | Фуросемид блокирует NKCC2 → мощный диуретик. SGLT2 ингибиторы (дапаглифлозин) → глюкозурия, новый класс для диабета и ХСН. |
| medicine.physiology.acid_base | Кислотно-щелочной баланс | INVARIANT | Нормальный pH артериальной крови 7.35-7.45. Буферы: бикарбонатный HCO₃⁻/CO₂ (основной внеклеточный), гемоглобин, фосфатный, белковый. Лёгкие регулируют CO₂ (минуты). Почки — HCO₃⁻ и экскрецию H⁺ (часы-дни). | Уравнение Гендерсона-Хассельбаха: pH = 6.1 + log([HCO₃⁻]/(0.03×pCO₂)). Метаболический ацидоз: ↓HCO₃⁻. Дыхательный: ↑pCO₂. |
| medicine.physiology.anion_gap | Анионный разрыв | CONTROL | AG = Na⁺ − (Cl⁻ + HCO₃⁻), норма 8-12 мЭкв/л. Повышенный AG → накопление нелетучих кислот (лактат, кетоны, уремия, токсины: метанол, этиленгликоль, салицилаты). Нормальный AG → потеря HCO₃⁻ (диарея, почечный канальцевый ацидоз). | Дифференциальный диагноз метаболического ацидоза. Кучи грязи (метанол, уремия, ДКА, паральдегид/изониазид, молочная кислота, этиленгликоль, салицилаты). |
| medicine.physiology.endocrine_feedback | Эндокринные петли обратной связи | INVARIANT | Гипоталамус (рилизинг-гормоны) → гипофиз (тропные гормоны) → периферическая железа → гормон → отрицательная обратная связь на гипоталамус и гипофиз. Пример: TRH → TSH → T3/T4 → ингибирование TRH и TSH. | Первичный гипотиреоз: ↑TSH (гипофиз «кричит»), ↓T4. Вторичный: ↓TSH, ↓T4 (проблема в гипофизе). |
| medicine.physiology.insulin_glucagon | Инсулин и глюкагон | INVARIANT | Инсулин (β-клетки): основной анаболический гормон. ↑после еды → захват глюкозы (GLUT4 в мышцах/жире), гликогенез, липогенез, синтез белка. Глюкагон (α-клетки): ↑при голодании → гликогенолиз, глюконеогенез, кетогенез. | СД1: аутоиммунное разрушение β-клеток, абсолютный дефицит инсулина. СД2: инсулинорезистентность + относительный дефицит. |
| medicine.physiology.neurotransmitters | Нейромедиаторные системы | VARIANT | Ацетилхолин (ACh): никотиновые (ионотропные) и мускариновые (метаботропные) рецепторы. Дофамин: D1-подобные (↑цАМФ) и D2-подобные (↓цАМФ) — нигростриатный (движение), мезолимбический (награда), мезокортикальный. Серотонин (5-HT): настроение, сон, аппетит. Норадреналин: бдительность, внимание. | Болезнь Паркинсона: ↓дофамин в нигростриатном пути → L-DOPA. Шизофрения: гипердофаминовая гипотеза → D2-антагонисты. Депрессия: моноаминовая гипотеза → СИОЗС. |
| medicine.physiology.action_potential_cardiac | Потенциал сердечного действия | PROCESS | Фаза 0: быстрый вход Na⁺ (I_Na). Ф1: ранняя реполяризация (K⁺, I_to). Ф2: плато (Ca²⁺ вход I_Ca-L, баланс с K⁺ выходом). Ф3: реполяризация (K⁺, I_Kr, I_Ks). Ф4: потенциал покоя (I_K1). Автоматия в пейсмекерных клетках: медленная диастолическая деполяризация (I_f — funny current, Na⁺/K⁺). | Антиаритмики класса I: блокаторы Na⁺-каналов (лидокаин — Ib, флекаинид — Ic). Класс III: блокаторы K⁺-каналов (амиодарон — удлиняет QT). |
| medicine.physiology.gi_motility | Моторика желудочно-кишечного тракта | PROCESS | Желудок: рецептивная релаксация (приём пищи), антральная систола (перемешивание и измельчение), пилорический сфинктер (порционный выброс химуса). Тонкая кишка: сегментирующие сокращения (перемешивание) + перистальтика (продвижение). Толстая: гаустрации, масс-сокращения (1-3 раза/день). | Мотилин — гормон, инициирующий мигрирующий моторный комплекс (ММК, «дворник» между приёмами пищи). Антибиотики (эритромицин) — агонисты мотилина → прокинетики. |
| medicine.physiology.liver_functions | Метаболические функции печени | INVARIANT | Глюконеогенез (из лактата, аминокислот, глицерола — поддержание глюкозы при голодании), синтез белков плазмы (альбумин — 12 г/день, факторы свёртывания II,VII,IX,X — витамин-K-зависимые), синтез желчных кислот из холестерина, детоксикация (цитохром P450), депо гликогена, витаминов (A, B12, D), железа (ферритин). | Цирроз → ↓альбумин → отёки/асцит. ↓факторов свёртывания → коагулопатия, ↑МНО. ↓детоксикация → печёночная энцефалопатия (аммиак). |
| medicine.physiology.bilirubin_metabolism | Метаболизм билирубина | PROCESS | Гем → биливердин (гемоксигеназа) → неконъюгированный билирубин (НБ, непрямой, нерастворим в воде, связывается с альбумином) → гепатоцит → конъюгация с глюкуроновой кислотой (UGT1A1) → конъюгированный (прямой, растворим) → желчь → кишечник → уробилиноген / стеркобилин (цвет стула). | Желтуха: надпечёночная (гемолиз → ↑НБ), печёночная (гепатит → ↑НБ+↑КБ), подпечёночная (обструкция → ↑КБ, бледный стул, тёмная моча). | medicine.physiology.bone_remodeling | Ремоделирование костей | PROCESS | Постоянный цикл: резорбция остеокластами (3 недели) → формирование остеобластами (3 месяца).
