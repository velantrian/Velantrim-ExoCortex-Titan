| lab.ops.sample_chain_of_custody | Образец цепочки поставок — юридическая документация | METHOD | Цепочка хранения образцов: юридически значимое документирование каждого перемещения образца. Record: отбор (кто, когда, где, условия — температура, preservatives), передача (от → кому, дата/время, подписи обеих сторон), хранение (где, условия, sealed/locked), анализ (кто, когда, метод), утилизация. CoC form: уникальный идентификатор образца, описание, matrix (вода/почва/воздух/кровь), requested tests. Каждое открытие/закрытие контейнера: новая пломба (tamper-evident seal) с ID. Хранение: secure, restricted access (замок + log), environmental monitoring (температура для биологических образцов — −20/−80°C). Отклонение в CoC (передача без подписи, нарушение температуры) делает образец inadmissible в суде. | CoC — фундамент аналитической работы с юридическими последствиями (environmental enforcement, criminal forensics, doping control, food safety). При environmental litigation: если лаборатория не может доказать CoC — доказательство отклонено, дело проиграно. |
| lab.ops.calibration_standards | Аналитические весы и пипетки — калибровка и проверка | METHOD | Калибровка измерительного оборудования. Весы: ежедневная проверка с certified weights (min 2 точки — near zero и near max capacity), tolerance ±0.1% или согласно производителю. Запись в log. Pipettes: gravimetric calibration (взвешивание выдаваемого объёма воды на calibrated balance с учётом плотности воды при данной температуре) — 6 повторений на каждый номинальный объём и на минимальный. Acceptance: mean error ±1% for fixed volume, ±2% for variable <50 мкл. Неисправные: ремонт/замена, перекалибровка после ремонта. Термометры: ледяная точка (0°C) + кипящая вода (100°C с поправкой на атмосферное давление −0.5°C на каждые 150 м высоты). Спектрофотометр: holmium oxide фильтр (длины волн) и нейтральные density фильтры (absorbance accuracy). | Калибровка градуированной посуды (мерные колбы, бюретки) — редкая ошибка: пластиковая посуда может давать systematic error из-за разных диаметров и hydrophobic стенок vs стекло. Допуск для Class A мерной колбы 100 мл — ±0.08 мл. |
| lab.ops.lims_workflow | LIMS — Система управления лабораторной информацией | METHOD | LIMS — центральная лаборатория IT-системы. Функции: 1) Пример входа в систему (регистрация выборки с метаданными — клиент, местоположение, дата, запрошенные тесты, срок выполнения), 2) Генерация этикетки (штрих-код для отслеживания), 3) Назначение работ (распределение тестов между аналитиками), 4) Ввод результатов (ручной или автоматический импорт с приборов через RS-232/USB/Ethernet), 5) Просмотр результатов (руководитель в начале: QC пройден? неожиданные значения?), 6) Утверждение и отчетность (CoA — Сертификат Генерация анализа, электронная подпись в соответствии с требованиями 21 CFR, часть 11), 7) Выставление счетов/фактур, 8) Инвентаризация (реагенты, стандарты — отслеживание истечения срока годности). Соответствие: контрольный журнал (каждое изменение — исходное значение, новое значение, кто, когда, почему), уровни доступа пользователей, электронные подписи (уникальный идентификатор пользователя + пароль). Интеграция: ERP (SAP), инструменты, SDMS (система управления научными данными). | LIMS без audit trail = не соответствует GLP/GMP. FDA Warning Letter: «ваша лаборатория не контролирует изменения данных» → shutdown. Замена LIMS: сложный процесс (data migration, валидация), 6-18 месяцев. Cloud LIMS (LabVantage, STARLIMS, Benchling) growing vs on-prem (безопасность данных). |
| lab.ops.method_validation_parameters | Валидация аналитического метода — параметры | METHOD | Валидация аналитического метода (ICH Q2(R1), USP 1225). Параметры: 1) Accuracy (близость к true value — сравнение с certified reference material или spike recovery 80-120%), 2) Precision: repeatability (одна лаборатория, один день, один аналитик — RSD <2-5%), intermediate precision (разные дни/аналитики — RSD <5-10%), reproducibility (межлабораторная — RSD <10-15%), 3) Specificity (способность различать analyte among impurities/degradants/products matrix), 4) Linearity (R² >0.995 в рабочем диапазоне), 5) Range (интервал где метод linear, accurate, precise), 6) LOD/LOQ: LOD = 3.3 × σ/slope (предел обнаружения), LOQ = 10 × σ/slope (предел количественного определения), 7) Robustness (устойчивость к малым изменениям — pH ±0.2, temperature ±5°C, mobile phase composition ±2% — метод всё ещё работает?), 8) System suitability test. Документация: Validation Protocol (заранее одобренный план) → Validation Report (результаты и заключение). | Метод не валидирован = результаты не надёжны юридически. Для GMP лабораторий — обязательное требование (21 CFR 211.194). Re-validation: при изменении метода, оборудования, исходного сырья API. |
| lab.ops.qc_chart_westgard | КК — Вестгардские правила для клинической лаборатории | METHOD | Westgard rules (multi-rule QC в клинических лабораториях). Контрольные материалы (QC samples) анализируются с каждой партией patient samples. Правила: 1₂s (warning — 1 control value >2 SD от mean), 1₃s (reject — >3 SD), 2₂s (reject — 2 последовательных values >2 SD в одном направлении), R₄s (reject — размах между двумя controls >4 SD), 4₁s (reject — 4 последовательных values >1 SD в одном направлении), 10x (reject — 10 последовательных по одну сторону от mean). При reject: остановка анализа, поиск причины (новый lot реагента? degradation? неправильная реконституция QC?), corrective action, перезапуск QC. Levey-Jennings chart: визуализация mean ±1/2/3 SD. QC lot change: при переходе на новый lot QC материала — параллельный анализ старого и нового (10-20 дней) для установления нового mean. | Систематическая ошибка (тренд/сдвиг) опаснее случайной (может долго не детектироваться 1₃s правилом). Westgard специально multi-rule чтобы детектировать systematic errors. Shift: 10x правило, trend: постепенное изменение за несколько дней. |
| lab.ops.hplc_troubleshooting | ВЭЖХ — уход за колонками и устранение неполадок | METHOD | Высокоэффективная жидкостная хроматография (высокоэффективная жидкостная хроматография). Колонка: на основе кремнезема (обратная фаза C18 — самая частая), диапазон pH 2-8 (крайний pH гидролизует связанную фазу), температура <60°С. Проблемы и решения: 1) Высокое противодавление (>400 бар/6000 psi) — забит входная фритта (обратная промывка колонки), осажденные буферные соли (промывка водой), матрица пробы с частицами (фильтрация пробы 0,45/0,22 мкм). 2) Пиковый хвост — вторичные соединения (силанолы), используют концевую колонку или модификатор подвижной фазы (ТЭА — триэтиламин для оснований). 3) Сплит-пики — частично забита входная фритта, канал в колонке (пустота в оголовке колонны). 4) Дрейф времени удерживания — колебания температуры колонки (целевое значение ±0,1°C), градиентная задержка, испарение подвижной фазы (органической фазы). Пригодность системы: перед каждым прогоном — разрешение Rs >2 между критической парой пиков, фактор хвостов <2, теоретические тарелки N >2000. Очистка: обратная промывка (противоположное направление) большим количеством растворителя (100% органического), затем уравновешивание. Охранная колонна: руководство аналитической колонкой (меняйте чаще, дешевле). | Mobile phase: фильтрация (0.45 µm) и дегазация (вакуум, helium sparging или in-line degasser) ОБЯЗАТЕЛЬНЫ. Пузырьки воздуха в детекторе = шум/дрейф baseline. Буферные растворы: не оставлять в колонке (соли выпадают в осадок), промывать водой перед organic flush. |
| lab.ops.microbiology_aseptic_technique | Микробиология — асептическая техника и подготовка среды | METHOD | Асептическая техника: стерильная работа с микробиологическими культурами. Принципы: 1) Рабочая поверхность дезинфицирована (70% этанол, 5-10 мин контакта), 2) Пламя Bunsen burner или working в ламинарном шкафу (BSC II — Biological Safety Cabinet), 3) ВСЁ что контактирует с культурой — стерильно (петли, пипетки, пробирки), 4) Фламинговка (стерилизация металлической петли в пламени до красного каления + охлаждение на воздухе или touching agar), 5) Работа быстро, но тщательно (крышки открыты минимальное время, пробирки наклонены под углом), 6) Никаких разговоров/кашля в направлении работы. Приготовление агаровых сред: rehydration порошка в дистиллированной воде, автоклавирование (121°C, 15 psi, 15-20 минут в зависимости от объёма), остужение до 45-50°C (можно держать рукой), добавление термолабильных добавок (антибиотики, blood/serum к blood agar — при <50°C чтобы не denature), разливка в чашки Петри (15-20 мл на чашку, застывание, переворот крышкой вниз — предотвращение конденсата) или скошенный агар в пробирках. Инкубация: 37°C для большинства mesophilic pathogens, инвертированные чашки (крышкой вниз — конденсат не капает на агар), 18-48 часов. Контроль стерильности: одна чашка из партии инкубируется без инокуляции — если рост → партия заражена, discarded. | Контаминация petri dish посторонними микроорганизмами (плесень, airborne bacteria) — самая частая проблема студентов. LAF (Laminar Air Flow) cabinet создаёт вертикальный поток HEPA-фильтрованного воздуха (класс ISO 5), защищает sample, но НЕ оператора (для pathogens — BSC II). |
| lab.ops.accreditation_iso17025 | ISO/IEC 17025 — Аккредитация лабораторий | METHOD | Международный стандарт для испытательных и калибровочных лабораторий (редакция 2017 г.). Требования: 1) Беспристрастность (лаборатория должна быть независимой, без конфликтных интересов), 2) Конфиденциальность (результаты клиента защищены), 3) Компетентность персонала (образование, обучение, опыт, демонстрация компетентности), 4) Помещения и окружающая среда (контроль температуры, влажности, вибрации, ЭМП — электромагнитные помехи), 5) Оборудование (программа защиты, техническое обслуживание, обращение), 6) Метрологическая прослеживаемость (калибровка прослеживается до SI через цепочку калибровок), 7) Внешние продукты и услуги (реагенты, эталонные материалы, субподрядчики — квалифицированные), 8) Валидация метода, 9) Отбор проб, 10) Обработка образцов для испытаний, 11) Технические записи, 12) Неопределенность измерения (оценка неопределенности для каждого калибровочного/испытательного метода), 13) Валидность результатов (проверка квалификации — межлабораторные сравнения, контроль качества, повторные испытания), 14) Отчетность (испытание) отчет/справка с определенными элементами). Аудит: орган по аккредитации (A2LA, ANAB, UKAS) проводит оценку на месте (1-4 дня) первичная + наблюдение за врачами 1-2 года + повторная оценка врачей 4 года. | ISO 17025 ≠ ISO 9001. 17025 — техническая компетентность (может ли лаба правильно измерить?), 9001 — управленческая система. Аккредитация mandatory для многих regulated industries (environmental compliance, food export). |
| lab.ops.lab_safety_chemical | Лабораторная безопасность — План химической гигиены | METHOD | План химической безопасности (OSHA 1910.1450). Компоненты: 1) Химический инвентарь (все химические вещества, номер CAS, количество, местоположение, паспорт безопасности для каждого доступного вещества), 2) Оценка рисков для каждого процесса (идентификация опасностей, оценка воздействия), 3) Средства контроля: Инженерные (вытяжной шкаф — скорость потока 0,4–0,6 м/с, высота створки ограничена, ежегодная сертификация; перчаточный бокс для пирофорных/кислородных материалов), Административный (стандартные операционные процедуры СОП, обучение), СИЗ (перчатки — проверка материала). с химикатами: нитриловые перчатки пробиваются дихлорметаном за 2-3 минуты!, серебряный щит для сильной органики), 4) Аварийные процедуры (комплект для разлива — нейтрализатор, абсорбент, СИЗ; станция для промывания глаз — 15 минут прохладной водой, тестируется еженедельно; аварийный душ — тестируется ежегодно), 5) Управление отходами (сортировка несовместимых отходов, сателлитная точка накопления <55 галлонов, маркировка «Опасные отходы» с датой). Неизвестный запах = эвакуация, а не «пойду посмотрю». Пить и есть в лаборатории — ОЧЕНЬ плохая идея (химикаты на поверхностях!). |
