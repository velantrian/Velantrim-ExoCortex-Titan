| genecounsel.ops.mendelian_patterns | Наследование — менделевские закономерности | METHOD | Менделевские паттерны: Аутосомно-доминантный (AD): 50% риск каждому ребёнку. Примеры: Марфан, Гантингтон, НФ1. Аутосомно-рецессивный (AR): 25% риск только при носительстве обоих родителей. Х-сцепленный рецессивный: сыновья носительниц = 50% больны. Х-сцепленный доминантный: редко. Митохондриальное: только от матери. | Новая мутация (de novo): родители не носители — риск сиблингов низкий (мозаицизм исключить). |
| genecounsel.ops.chromosome_disorders | Хромосомные заболевания — трисомии | METHOD | Хромосомные нарушения: Трисомия 21 (Синдром Дауна): 47, +21. Трисомия 18 (Эдвардса): 47, +18. Трисомия 13 (Патау): 47, +13. 45,X (Тёрнер): монозомия Х. 47,XXY (Клайнфелтер). Транслокационный Даун: риск 25% (Robertsonian t14;21). Мозаицизм: смягчённый фенотип. | Матерналный возраст: риск трисомий растёт после 35 лет (нондисъюнкция). |
| genecounsel.ops.prenatal_cfdna | Пренатальный — скрининг вкДНК | METHOD | Бесклеточная ДНК (cfDNA) пренатальный скрининг: фетальная ДНК в материнской крови. Обнаружение: трисомии 21, 18, 13. Фракция фетальной ДНК: ≥4% (минимально). Ложноположительные: confined placental mosaicism. Диагностический: хорионическая биопсия или амниоцентез. PPV зависит от prevalence (возраст матери + риск). | cfDNA = скрининг, НЕ диагноз. Положительный результат → инвазивная диагностика. |
| genecounsel.ops.variant_classification | Вариант интерпретации — ACMG | METHOD | Классификация вариантов (ACMG 2015): патогенный, вероятно патогенный, неопределённого значения (VUS), вероятно доброкачественный, доброкачественный. Критерии: population data, computational evidence, functional studies, segregation, allelic data, de novo data. VUS: не использовать для клинических решений. | VUS → рассмотреть повторно через 6-12 мес (данные накапливаются). |
| genecounsel.ops.hereditary_breast_cancer | BRCA — Оценка рисков | METHOD | Наследственный рак молочной железы: BRCA1 (17q21): риск РМЖ 65-70%, РЯ 39-46%. BRCA2 (13q12): РМЖ 45-65%, РЯ 12-20%. Критерии тестирования: семейный анамнез + ранний возраст + мужской РМЖ + ашкеназийское происхождение + тройной негативный РМЖ <60 лет. Управление: MRI + маммография, химиопрофилактика, рилупрогластика-ооферэктомия. | Ингибиторы поли-АДФ-рибозо-полимеразы (PARP): особенности опухолей с дефицитом BRCA. |
| genecounsel.ops.family_history_pedigree | Семейная история — Родословная | METHOD | Родословная (pedigree): квадрат = мужчина, круг = женщина. Заполненный = поражённый. Линия горизонтальная = брак. Вертикальная = потомок. Горизонтальная над братьями/сёстрами = сибшип. Стрелка = пробанд. Цифры = возраст/возраст смерти. Трёхпоколенческая минимально. | Генетические тревожные сигналы: множественные пораженные родственники, раннее начало заболевания, двусторонний, редкий рак. |
| genecounsel.ops.pharmacogenomics_p450 | Фармакогеномика — CYP2D6 | METHOD | Фармакогеномика CYP2D6: метаболизм 25%+ препаратов (кодеин, тамоксифен, ТЦА, нейролептики). Типы: Плохой метаболизатор (ПМ): 2 нефункциональных аллеля. Средний уровень (IM): 1 снижен. Нормальный (ЭМ). Сверхбыстрый (UM): ≥3 копий. Кодеин у ПМ: нет морфия, нет эффекта. УМ: чрезмерное употребление морфия → опасно. | Тамоксифен: CYP2D6 PM → снижение endoxifen → снижение эффективности. |
| genecounsel.ops.recurrence_risk | Риск повторения — Консультирование | METHOD | Расчёт риска рецидива: AD: 50% (если поражён родитель). AR: 25% (оба родителя носители). X-linked recessive: сыновья носительниц 50%, дочери 50% носительницы. Мультифакторный: эмпирический (из литературы), выше если тяжелее или много поражённых. Population risk (baseline). | Non-directive counseling: цель = информирование, не манипулирование выбором. |
| genecounsel.ops.lynch_syndrome | Синдром Линча — MLH1/MSH2 | METHOD | Синдром Линча (наследственная несполинная несравненная полипоза рак толстой кишки): мутации MMR генов (MLH1, MSH2, MSH6, PMS2). Риск: КРР 40-80%, матка 40-60%, яичники 6-12%. Скрининг: колоноскопия каждые 1-2 года с 25 лет. MSI тест или ИГХ MMR белков (тест от опухоли). Профилактическая гистерэктомия: опциональная. | Критерии Амстердама II и рекомендации Bethesda: критерии подозрения на Линча. |
| genecounsel.ops.trio_exome | Трио Экзом — Диагностика | METHOD | Экзомное секвенирование трио (тро-экзом): проверка мутаций у ребёнка + оба родителя. Позволяет de novo variant identification. Diagnostic yield: 25-40% для неизвестных синдромов. VUS: высокая частота (30-40%). IRO (incidental result): неожиданные патогенные варианты в других генах. Этические вопросы: что сообщать? | Рекомендации ACMG: сообщить о патогенных вариантах в 59 действующих генах. |
| genecounsel.ops.mitochondrial_disease | Митохондрии — Гетероплазмия | METHOD | Митохондриальные болезни: гетероплазмия = смесь нормальных и мутантных мтДНК. Threshold effect: при >60-70% мутантных = болезнь. Наследование: от матери (нет отцовского). Пирротвид ные болезни: MELAS, MERRF, Leber hereditary optic neuropathy. mtDNA copy number. Preimplantation genetic diagnosis. | Heteroplasmy levels: могут отличаться между тканями (кровь vs мышца). |
| genecounsel.ops.preimplantation_testing | ПГТ — преимплантационное тестирование | METHOD | Доимплантационное генетическое тестирование (PGT): ЭКО + биопсия эмбриона на 5-6 день. PGT-M: для монолитных болезней. PGT-A: анеуплоидии. PGT-SR: структурные перестройки. Технологии: NGS, SNP array. Неимплантация или дефектный эмбрион. | PGT-M: необходима предварительная семейная работа (разработка зонда per family). |
| genecounsel.ops.fragile_x | Хрупкий X — Расширение | METHOD | Синдром ломки Х-хромосомы (FXS): экспансия CGG-повторов в FMR1. Нормальный: <45 повторов. Премутация: 55-200 (FXPOI у женщин, FXTAS у мужчин). Полная мутация: >200 (FXS). Метилирование: полная мутация → метилирование → замалчивание FMR1. Диагностика: ПЦР + Саузерн-блоттинг. | Anticipation: премутация → экспансия при передаче через женщин. |
| genecounsel.ops.gene_therapy_aav | Генная терапия — Векторы AAV | METHOD | Генная терапия (ААВ): Аденоассоциированный вирус (ААВ) как вектор. Серосоветы: AAV9 для нервной системы. Капсидные белки: тропизм. ITR (инвертированные терминальные повторы): для интеграции или эписомально. Ограничения: иммунный ответ, ограничение размера (4,7 КБ), стоимость изготовления. Клинические примеры: Золгенсма (СМА), Люкстурна (врожденный амавроз Лебера). | Ex vivo vs in vivo gene therapy: клетки берутся из пациента и обрабатываются vs напрямую вводят. |
| genecounsel.ops.neonatal_screening | Скрининг новорожденных — Тандем МС | METHOD | Скрининг новорождённых: heel stick blood spot → tandem MS. USA (RUSP): >35 core условий. PKU (фенилкетонурия): фенилаланин = рано лечить = нормальное развитие. MCAD deficiency: жировой метаболизм. Hypothyroidism: TSH. CAH: 17-OHP. Cystic fibrosis: IRT → CFTR. Критическая для своевременного лечения. | Критическое окно терапии: лечение до появления симптомов = лучший исход. |
| genecounsel.ops.hemoglobinopathies | Гемоглобинопатии — серповидноклеточные | METHOD | Гемоглобинопатии: HbS (βGlu6Val). Серповидно-клеточная болезнь (SCD): HbSS, HbSC, HbSβ. HbS carrier: HbAS (бессимптомный). Диагноз: HPLC, электрофорез. Пренатальная диагностика: при носительстве обоих родителей. Screening программы. Hydroxyurea: снижает HbF дефицит. | Малярия + HbAS: HbS гетерозиготы = защита от малярии (натуральный отбор). |
| genecounsel.ops.genetic_test_types | Генетическое тестирование — виды | METHOD | Типы генетических тестов: Diagnostic: подтвердить диагноз. Predictive: риск развития болезни в будущем. Carrier testing: носительство рецессивных. Prenatal: пренатально. Pharmacogenomic: по лекарствам. Research: не для клинических решений. DTC (Direct-to-Consumer): 23andMe, AncestryDNA. | Presymptomatic testing (Huntington): психологическая оценка + 6 мес консультирование → сам пациент решает. |
| genecounsel.ops.chromosome_microarray | CMA — Хромосомный микрочип | METHOD | Хромосомный микроматричный анализ (CMA): обнаружение CNV (вариантов числа копий). Разрешение: 5-10 Кб (против кариотипа 5-10 Мб). Платформы: массив SNP (Affymetrix, Illumina). Показания: умственная отсталость, аутизм, множественные врожденные аномалии, мертворождение. Выход: на 15-20% выше кариотипа. | CMA не выявляет: сбалансированные транслокации, точковые мутации. |
