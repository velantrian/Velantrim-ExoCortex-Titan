| evidbased.ops.pico_framework | PICO — Структура клинических вопросов | METHOD | PICO: структурирование клинического вопроса. P (Population/Problem): кто пациент? I (Intervention): что рассматривается? C (Comparison): с чем сравнивать? O (Outcome): что важно? Варианты: PICOT (T=Time), PICOS (S=Study Design). PubMed: MeSH terms по PICO. | Плохой PICO → нерелевантный поиск. Хороший PICO → целевой поиск + критическая оценка. |
| evidbased.ops.levels_evidence | Уровни доказательности — Оксфорд | METHOD | Уровень доказательности (Оксфордский CEBM, 2011 г.): Уровень 1a: SR РКИ. Уровень 1b: индивидуальное РКИ. Уровень 2а: СР когортных. Уровень 2б: когортное. Уровень 3а: случай-контроль СР. Уровень 3б: индивидуальный случай-контроль. Уровень 4: Серия случаев. Уровень 5: Экспертное мнение. СТЕПЕНЬ (ВОЗ/Кокрейн): Высокая-Умеренная-Низкая-Очень низкая. | GRADE: более нюансированный (учитывает indirect, inconsistent evidence). |
| evidbased.ops.grade_certainty | GRADE — Оценка достоверности | METHOD | GRADE (Оценка оценки рекомендаций): Степени достоверности: Высокая (RCT = высокий старт) → понизить оценку, если: риск ошибок, непоследовательность, косвенность, неточность, предвзятость публикации. Наблюдение = низкий старт → повышение, если: значительный эффект, реакция на дозу, правдоподобное искажающее влияние. Сильная или условная рекомендация. | Условная рекомендация: «Предлагаем» vs Сильная «Рекомендуем». |
| evidbased.ops.critical_appraisal_rct | Критическая оценка — РКИ | METHOD | Критическая оценка RCT: Контрольный список CONSORT. Внутренняя валидность: рандомизация, сокрытие распределения, ослепление, полнота. Внешняя валидность: репрезентативная совокупность. Смещение отбора (antes de randomizar). Предвзятость истощения (пост). Предвзятость производительности. Предвзятость обнаружения. Предвзятость в отчетности. | Сокрытие распределения ≠ ослепление. Сокрытие собственной предвзятости при выборе. |
| evidbased.ops.clinical_guidelines | Клинические рекомендации — Разработка | METHOD | Разработка рекомендаций: Процесс GRADE. Мультидисциплинарная комиссия. Заявление о конфликте интересов. Систематический обзор. Клинический + взгляд пациента. Внешний обзор. Регулярное обновление. Инструментарий реализации. Оценка технологий NICE: экономика здравоохранения + клиника. | «Strong recommendation with weak evidence»: редкость — обычно обратное соотношение. |
| evidbased.ops.likelihood_ratios | Диагностическая точность — LRs | METHOD | Вероятностные коэффициенты (LR): LR+ = Чувствительность / (1 – Специфичность). LR- = (1 – Чувствительность)/Специфичность. Вероятность до теста → Вероятность после теста: через номограмму Байеса или Фагана. LR+ > 10: сильное подтверждение. LR- <0,1: сильное исключение. | Стрептококковый фарингит: Centor Score = вероятность перед тестом. |
| evidbased.ops.number_needed_harm | NNH — Метрика безопасности | METHOD | Число, необходимое для вреда (NNH): NNH = 1/ARI. ОРИ = Частота_лечения - Частота_контроля. Важен баланс пользы и риска. Лечение статинами 100 пациентов: предотвращено 1 событие (NNT=100) и 1 проблема с мышцами (NNH=100). Преимущество: контекст соотношения вреда. | Aspirin for primary prevention: NNT vs NNH = почти равны → не рекомендуется рутинно. |
| evidbased.ops.clinical_prediction_rule | Правило клинического прогнозирования — валидация | METHOD | Клинические прогностические правила: деривация (разработка модели), валидация (внешняя проверка). Оценка УЭЛЛСА (DVT), правила Оттавы. AUC (AUROC): дискриминация. Калибровка: прогнозируемая или наблюдаемая. Тест Хосмера-Лемешоу. Исследования влияния решений: определяет реальное поведение. | Ottawa Ankle Rules: validation многократная → высокая уверенность. |
| evidbased.ops.meta_analysis_heterogeneity | Мета-анализ — гетерогенность | METHOD | Гетерогенность в мета-анализе: I² статистика: 0% = нет, 25% = низкая, 50% = умеренная, 75% = высокая. Q-test: статистический тест. Subgroup analysis: объяснение. Random effects vs Fixed effects model: при наличии гетерогенности → Random effects. Funnel plot: publication bias. | При I² > 75%: мета-анализ сомнительной ценности. Лучше: narratively synthesize. |
| evidbased.ops.shared_decision_making | Совместное принятие решений | METHOD | Совместное принятие решений (SDM): фактические данные + предпочтения пациента + клиническая экспертиза. «Разговор о вариантах»: обсуждаем все варианты. «Разговор о решении»: определение предпочтений. Средства принятия решений для пациентов: стандарты IPDAS. Списки вопросов-подсказок. «Трехразговорная модель» (Элвин). | Инструменты SDM: Оттавская система поддержки принятия решений. |
| evidbased.ops.clinical_practice_guidelines_appraisal | Оценка рекомендаций — СОГЛАСЕН | METHOD | AGREE II (Анализ руководящих указаний по исследованиям и оценке): 6 областей. 1) Область применения + Цель. 2) Вовлечение заинтересованных сторон. 3) Строгость развития. 4) Ясность изложения. 5) Применимость. 6) Редакционная независимость. 23 шт. | AGREE II score < 40%: слабое качество руководства (не следует слепо). |
| evidbased.ops.implementation_science | Наука внедрения — CFIR | METHOD | Наука реализации (Implementation Science): разрыв между доказательствами и результатами. CFIR (Консолидированная структура исследований по внедрению): 5 областей. Характеристики вмешательства, Внешняя обстановка, Внутренняя обстановка, Характеристики отдельных лиц, Процесс. Теория процесса нормализации. RE-AIM: охват, эффективность, принятие, внедрение, поддержание. | «Знать не значит делать»: 17-летний разрыв знаний → практика. Наука о внедрении |
| evidbased.ops.qualitative_evidence_synthesis | Качественный синтез доказательств | METHOD | Синтез качественных доказательств: Метаэтнография (Noblit & Hare): синтез интерпретаций. Тематический синтез. Синтез фреймворка. Синтез обоснованной теории. Томас и Харден: систематические обзоры качественных исследований. GRADE-CERQual: надежность качества. | Качественные результаты → идеи реализации. Почему что-то не работает? |
| evidbased.ops.patient_reported_outcomes | Результаты, сообщаемые пациентами — PRO | METHOD | Исходы, сообщаемые пациентом (PRO): прямая оценка пациентом симптомов + функций + QoL без интерпретации. PROMIS (NIH): item bank + adaptive testing. SF-36: классический. EQ-5D: экономический. PRO-CTCAE (onkology). FDA guidance: PRO in clinical trials. | FDA требует PRO для маркировки заявлений + клиническая значимость. |
