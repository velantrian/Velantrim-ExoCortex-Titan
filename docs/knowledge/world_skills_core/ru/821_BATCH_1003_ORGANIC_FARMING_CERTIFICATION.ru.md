# BATCH 1003: Organic Farming — Certification & Practices

**Scope:** certification, cover_crops, composting, pest_control, rotation, soil_biology, marketing

|---|---|---|---|---|
| organicfarm.ops.usda_certification_process | Органическое Министерство сельского хозяйства США — процесс сертификации | METHOD | Сертификация органического производства (США). НОП (Национальная органическая программа): 3-летний переходный период (без запрещенных веществ). Сертификатор (CCOF, OCIA, MOFGA): аккредитован USDA/AMS. План органической системы (OSP): годовой документ (план земли, ресурсов, производства, продаж). Осмотр: ежегодная (внутрихозяйственная), выборочная проверка (почвы, воды, продукта). Запрещенные вещества: синтетические пестициды, удобрения, ГМО, облучение, осадки сточных вод. Разрешенные вещества: перечислены в NOP §205.601-205.606. | Затраты на переход: потеря дохода за 3 года (более низкая урожайность без химии, отсутствие надбавок до тех пор, пока не будет получена сертификация). |
| organicfarm.ops.cover_crop_selection | Покровные культуры — выбор вида | METHOD | Покровные культуры. Бобовые (бобовые): фиксируют азот (вика волосистая 90-200 кг н/га, клевер малиновый 60-100, горох озимый). Злаки (травы): рожь, пшеница (биомасса, предотвращает эрозию, подавляет сорняки). Крестоцветные: горчица, редис (биофумигация — предпочитает глюкозинолаты, подавляет нематод/возбудителей болезней). Смеси: 2-4 вида смеси = функции штабелирования (N бобовых + биомасса травы + борьба с вредителями крестоцветных). Прекращение: уничтожение морозом, прокатыванием (роликом) или гербицидом (неорганическим). Сроки: за 4-6 недель до заморозков для укоренения. | Бrassica: allelopathic (подавляет следующую культуру если не разложится). |
| organicfarm.ops.vermicomposting | Вермикомпостирование — Корзина для червей | METHOD | Вермикомпостирование. Черви: Eisenia fetida (красные вигглеры, необыкновенные дождевые черви). Контейнер: пластик/дерево, слив, температура 15-25°С. Подстилка: измельченная бумага/картон (первоначально), влажная (не мокрая). Сырье: пищевые отходы (без мяса/молочных продуктов, без лука/чеснока), кофейная гуща, измельченные листья. Соотношение C:N: баланс углерода (бумага) и азота (отходы). Обработка: черви переваривают материал → вермикаст (червячные отливки) = высококачественная органическая добавка. Сбор урожая: миграция (новая подстилка с одной стороны, сбор урожая с другой). Жидкость (фильтрат): разбавить 1:10, жидкое удобрение. | Вермикаст: превосходные питательные вещества, доступные для растений, + разнообразие микроорганизмов. |
| organicfarm.ops.soil_health_indicators | Здоровье почвы — полевая оценка | METHOD | Визуальная оценка состояния здоровья на поле. Количество дождевых червей: 10+ в кубике 30×30×30 см = здоров. Тест на разжижение: кубик кубика в воде (здоровая структура держится, не растворяется). Структура почвы: зернистая/комковатая = отличная, массивная глыба = плохая. Цвет: темно-коричневый/черный = органическое вещество, бледный = низкое ОВ. Запах: землистый (геосмин из актиномицетов) = хороший, затхлый/кислый = анаэробная проблема. Пенетрометр: сопротивление грунта <300 кПа = уплотнения нет. Покрытие: голая почва = подвержена эрозии/потере тепла. | Набор для тестирования здоровья почвы: Оценка здоровья почвы Корнелла (экономично). |
| organicfarm.ops.pest_monitoring_thresholds | Пороговые значения IPM — органический мониторинг | METHOD | Экономический порог конкурентности. Экономический порог (ET): освещение вредных веществ, стоимость которых превышает стоимость мер. Мониторинг: липкие ловушки (тля, белокрылка, трипсы), феромонные ловушки (яблочная плодожорка, непарный шелкопряд), разведка (каждые 7-10 дней). Порог действия (AT): обычно 70-80% от ET. Допустимые органические ограничения: пиретрин/спиносад/Bt (в списке), ним (в списке), каолиновая глина, медь/сера (ограниченное использование). Биоконтроль: Трихограммы, златоглазки, божьи коровки. Задержка действия: если естественных врагов достаточно. | Не всегда доходить до ET: если natural enemies активны, они могут контролировать ситуацию. |
