| clingenetics.ops.polygenic_risk | Полигенные шкалы риска — PRS | METHOD | Полигенный риск (PRS): суммарный эффект тысяч SNP с малыми эффектами. Методы: PRS-CS, LDpred. AUC: 0.6-0.8 для распространённых заболеваний. PRS для CAD: AUC 0.65-0.75. | PRS клиническое внедрение растёт: 23andMe, UK Biobank предлагают PRS для 10+ заболеваний. |
| clingenetics.ops.tmb_tumor | TMB — опухолевая мутационная нагрузка | METHOD | TMB (Tumor Mutational Burden): количество соматических мутаций/Mb. TMB-High (≥10 mut/Mb) → ответ на иммунотерапию (pembrolizumab FDA-approved). MSI-H/dMMR: универсальный биомаркер. TMB по FoundationOne: 0.8 Mb coding genome. | TMB в раке лёгкого: высокий TMB → лучший ответ на pembrolizumab (KEYNOTE-189). |
| clingenetics.ops.msi_microsatellite | MSI — микросателлитная нестабильность | METHOD | MSI (Microsatellite Instability): дефект MMR-системы. MSI-H → pembrolizumab (tissue-agnostic FDA approval 2017). Тестирование: PCR (5 маркеров BAT-25, BAT-26, D2S123, D5S346, D17S250) или IHC (MLH1, MSH2, MSH6, PMS2). MSI-H = ≥2/5 маркеров. | MSI-H при колоректальном раке: стадия II не лечится 5-FU (вредно). |
