| appliance.ops.refrigerator_sealed_system | Холодильник — Диагностика герметичных систем | METHOD | Диагностика герметичной системы холодильника. Симптомы: не охлаждает (freezer и/или fridge warm), компрессор работает но горячий, компрессор не запускается (hum, click — overload), компрессор пытается стартовать и вырубается. Инструменты: мультиметр (сопротивление обмоток: common-start + common-run = start-run), ампер клещи (ток компрессора — сравнивать с nameplate LRA — Locked Rotor Amps). Process of elimination: 1) Compressor start relay/PTC (терморезистор пускового реле): проверить омметром (должен иметь сопротивление 4-12 Ом при комнатной t). Если обрыв — замена. 2) Run capacitor: визуально (вздулся, потёк?), мультиметр с диапазоном ёмкости (должна быть в пределах ±5-10% номинала). 3) Overload protector: биметаллический диск — при остывании восстанавливается (если постоянно срабатывает — искать причину). 4) Compressor winding: resistance common-start (higher) + common-run (lower) = start-run (примерно). Open or short to ground (megger test) = compressor dead. Sealed system (утечка хладагента): frost pattern test — испаритель в freezer должен быть равномерно покрыт инеем (thin even frost). Если иней только в начале испарителя = low charge (утечка). Electronic leak detector / UV dye для поиска утечки. Доступ к sealed system: требуется EPA Section 608 certification (работа с хладагентами — recovery, vacuum, recharge). | Обычная причина «не работает»: загрязнены змеевики конденсатора (под/сзади) — перегрев, защита компрессора от перегрузки отключается. Очистка спиральной щетки + пылесос. Неисправность системы оттайки: испаритель замороженного льдом (холодный воздух не циркулирует). Нагреватель оттаивания, термостат оттаивания, таймер/плата управления оттаивания. |
| appliance.ops.washer_drain_pump | Стиральная машина — без слива/без отжима | METHOD | Диагностика «не сливает/не отжимает». Фильтр-ловушка (coin trap) — очистить. Провернуть крыльчатку pump (должна вращаться свободно). Мультиметр: сопротивление обмотки 10-25 Ом. Напряжение 120V AC при включении отжима (осторожно!). 3) Drain hose: перегиб, засор. 4) Pressure switch / Water Level sensor (прессостат): трубка к pressure chamber на дне бака (забита грязью/мылом — не чувствует пустой бак → не включает отжим). Прочистить. 5) Motor coupler (direct drive Whirlpool/Kenmore): резиновый соединитель между мотором и трансмиссией — частый износ (треснул). 6) Drive belt (передняя загрузка): порван/растянут. 7) Control board: если всё выше OK — замена board. | Front-load: drain pump filter чистить каждые 3-6 мес (монеты, пуговицы, носки). Не оставлять в карманах! Код ошибки: современные машины показывают error codes (F9E1 — drain issue по Whirlpool, E21 — Samsung). |
| appliance.ops.dryer_no_heat | Сушилка — без нагрева/без воздушного потока | METHOD | Диагностика сушильной машины. Электрическая: 1) Тестером проверить напряжение на клеммной колодке (должно быть 240V AC — L1-L2). Если 120V только на одном legs → сгорел один предохранитель/breaker — мотор крутит, нагрева нет. 2) Heating element: визуально (coil — витки целы? разрыв?), мультиметр continuity 10-50 Ом. 3) Thermal fuse (на корпусе нагревателя или воздуховоде): одноразовый — срабатывает при перегреве. Проверить continuity (0 Ом). Если обрыв — замена + найти причину перегрева (забит вентиляционный канал, lint screen не чищен). 4) Cycling thermostat / operating thermostat: биметаллический, test непрерывность при комнатной t. 5) High-limit thermostat: защитный (срабатывает при экстремальной t, обычно не перегорает). 6) Timer / Control board. Airflow: прочистить lint screen + exhaust duct до улицы (ежегодно — скопление lint = снижение airflow = перегрев + fire hazard). Blower wheel: не забит? | Вентиляционный канал: макс длина 7-8 м с учётом каждого колена (каждые 90° = +1.5 м). Lint — high fire hazard (2900 dryer fires/год в США по статистике NFPA). Соскрести крупные остатки, НЕ ополаскивать дочиста. |
| appliance.ops.microwave_no_heat | Микроволновая печь — без нагрева Диагностика | METHOD | Диагностика «крутится, но не греет». ПРЕДУПРЕЖДЕНИЕ: ВЫСОКОЕ НАПРЯЖЕНИЕ! Конденсатор хранит 2000V+ после отключения. Разряжать конденсатор отвёрткой с изолированной ручкой через резистор 10 Ом/10 Вт на корпус. Диагностика (после разрядки): 1) Дверные выключатели (interlock switches): минимум 3 (primary, secondary, monitor). При неправильной работе мониторный выключатель закорачивает и выбивает предохранитель (fuse). Проверить непрерывность (normally open закрыт когда дверь закрыта). 2) High-voltage fuse: керамический, 5 кВ, 0.5-0.8 А. Проверить омметром. 3) High-voltage capacitor: разрядить, измерить ёмкость (должна быть около 0.7-1.2 µF). 4) High-voltage diode: мультиметр не может проверить (слишком высокое падение напряжения 6-9V), используется тест с 9V батареей и лампочкой. 5) Magnetron: сопротивление накала (<1 Ом), сопротивление анод-корпус (должно быть бесконечность). Если пробито на корпус — замена magnetron. 6) High-voltage transformer: первичная обмотка ~0.5 Ом, вторичная ~100 Ом. Магнетрон: генерирует микроволны 2.45 ГГц. Антенна магнетрона (чистая, без нагара). Waveguide cover (слюдяная пластина в камере): нагар, подгорание (искры!). Замена если повреждена. | Работа микроволновки door open (проверка interlock с jumper) = СМЕРТЕЛЬНАЯ ОПАСНОСТЬ. Микроволны вызывают катаракту и ожоги.
