| medalgos.heart_score.detailed | HEART Score — подробные компоненты и протокол | METHOD | СЕРДЦЕ = Анамнез (2: очень подозрительно = 2 балла, умеренно = 1, слегка/нет = 0), ЭКГ (2: значительная депрессия ST = 2, неспецифическая реполяризация = 1, норма = 0), Возраст (2: >65 = 2, 45-65 = 1, <45 = 0), Факторы риска (2: ≥3 факторов риска или история атеросклеротического заболевания = 2, 1-2 фактора риска = 1, нет = 0), тропонин (2: ≥3x норма = 2, 1-3x = 1, ≤норма = 0). Лучше чем TIMI score для undifferentiated chest pain в неотложном отделении. TIMI разработан для confirmed ACS patients (другая популяция!). HEART = external validation в 15+ странах, pooled sensitivity 96% для MACE при cutoff ≤3. Не использовать HEART для пациентов с STEMI (очевидная ECG). |
| medalgos.wells_pe.two_tier_detailed | Оценка Wells PE — двухуровневый протокол (подробно) | METHOD | ТЭЛА Уэллса (модифицированный): Клинические признаки ТГВ (3,0 балла), ТЭЛА является диагнозом №1 или равновероятна (3,0), Частота сердечных сокращений >100 (1,5), Иммобилизация/хирургическое вмешательство в течение 4 недель (1,5), Перенесенный ТГВ/ТЭЛА (1,5), Кровохарканье (1,0), Рак при лечении в течение 6 месяцев или паллиативное лечение (1,0). ДВА уровня: ≤4 = ТЭЛА маловероятна (распространенность ~5–12%), >4 = ТЭЛА вероятна (распространенность ~35–45%). Путь ЛЭ маловероятен: D-димер → если отрицательный результат (<500 нг/мл с поправкой на возраст или стандартное пороговое значение) → ЛЭ исключена без КТ. Вероятный путь ЛЭ: пропустить D-димер → немедленно выполнить КТ-ангиографию легких (КТПА). ТРЕХУРОВНЕВЫЙ (упрощённый, без «диагноза ЛЭ №1»): ≤1 = низкий, 2-6 = средний, ≥7 = высокий. | Возраст-адаптированный D-dimer cutoff: возраст >50 лет → cutoff = age × 10 ng/mL (например, 75 лет → cutoff 750 вместо 500). Увеличивает специфичность на 5-10% без потери чувствительности (ADJUST-PE study, 2013). PERC rule: если пациент ≤50 лет, пульс ≤100, SpO2 ≥95%, нет гемоптизиса, нет оральных контрацептивов/эстрогена, нет предшествующего ТГВ/ТЭЛА, нет недавней операции/травмы → pre-test probability <2% → D-dimer не нужен (PERC-negative = PE excluded). |

Но WLUS требует больше времени и operator skill. У беременных: Wells невалидирован (отёк ног нормален для беременности) → сразу УЗИ. |

ВСЕ пациенты на SGLT2i с тошнотой/рвотой/недомоганием = DKA until proven otherwise (проверить кетоны, anion gap). |
