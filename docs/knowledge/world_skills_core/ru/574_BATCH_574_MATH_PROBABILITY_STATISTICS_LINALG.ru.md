| math.probability.kolmogorov_axioms | Аксиомы Колмогорова (1933) | INVARIANT | 1) Неотрицательность: P(A) ≥ 0. 2) Нормированность: P(Ω) = 1. 3) σ-аддитивность: для непересекающихся Aᵢ: P(∪Aᵢ) = ΣP(Aᵢ). Из этих трёх аксиом выводится ВСЯ теория вероятностей. | Формализация вероятности как меры. Условная вероятность: P(A | B) = P(A∩B)/P(B). |
| math.probability.law_large_numbers | Закон больших чисел | INVARIANT | Среднее арифметическое независимых одинаково распределённых случайных величин сходится к математическому ожиданию μ. Слабый ЗБЧ (сходимость по вероятности), Усиленный ЗБЧ (почти наверное). | Объясняет работу казино (преимущество заведения реализуется на большом числе игр). Страховые компании опираются на ЗБЧ для расчёта премий. |
| math.probability.central_limit | Центральная предельная теорема | INVARIANT | Сумма (или среднее) большого числа независимых случайных величин с конечной дисперсией приблизительно нормально распределена, независимо от исходного распределения. (X̄ − μ)/(σ/√n) → N(0,1). | Основа для почти всей параметрической статистики. Доверительные интервалы, тестирование гипотез — все опираются на ЦПТ для больших выборок. |
| math.probability.bayes_theorem | Теорема Байеса | INVARIANT | P(Н при Е) = P(Е при H)·P(H)/P(E). Позволяет обновлять вероятность гипотезы при получении новых данных. P(H) — априорная вероятность, P(H при E) — апостериорная. | Медицинская диагностика: тест с 99% специфичностью для болезни с 0.1% распространённостью → P(болезнь при положительном) ≈ 9%! (парадокс ложноположительных). |
| math.probability.bernoulli_binomial | Бернулли и биномиальные распределения | VARIANT | Бернулли: P(X=1)=p, P(X=0)=1−p. Одно испытание. Биномиальное: n независимых испытаний, P(X=k) = C(n,k)·p^k·(1-p)^(n−k). E[X]=np, Var[X]=np(1−p). | Подбрасывание монеты (n бросков) — биномиальное. Контроль качества (число дефектных деталей в выборке). |
| math.probability.poisson_distribution | Распределение Пуассона | VARIANT | P(X=k) = (λ^k/k!)·e^(−λ). E[X]=Var[X]=λ. Предельный случай биномиального при n→∞, p→0, np=λ=const. | Число звонков в колл-центр за час, число опечаток на странице, число распадов радиоактивного источника за интервал. |
| math.probability.exponential_distribution | Экспоненциальное распределение | VARIANT | f(t) = λ·e^(−λt) для t≥0. E[T]=1/λ, Var=1/λ². Свойство отсутствия памяти: P(T>t+s | T>s)=P(T>t). Единственное непрерывное распределение с этим свойством. | Время между событиями в пуассоновском процессе (время между звонками). Время жизни радиоактивного ядра. Время до поломки (при постоянной интенсивности отказов). |
| math.probability.normal_distribution | Нормальное (гауссово) распределение | INVARIANT | f(x) = (1/(σ√(2π)))·exp(−(x−μ)²/(2σ²)). 68-95-99.7 правило: μ±σ — 68%, μ±2σ — 95%, μ±3σ — 99.7%. Z-score = (x−μ)/σ. Стандартное нормальное N(0,1). | Рост, IQ, ошибки измерений — приблизительно нормальны. Многомерное нормальное: эллипсоид рассеяния, ковариационная матрица Σ. |
| math.probability.covariance_correlation | Ковариация и корреляция | VARIANT | Cov(X,Y) = E[(X−μₓ)(Y−μᵧ)]. Корреляция ≠ причинность (продажи мороженого и число утоплений коррелируют из-за летней жары). |
| math.statistics.sampling_distributions | Выборочные распределения | INVARIANT | t-распределение Стьюдента: (X̄−μ)/(s/√n) ~ t_{n−1} (неизвестна σ — используем выборочную s). Хи-квадрат χ²_{n−1}: (n−1)s²/σ² ~ χ². F-распределение: отношение χ², делённых на степени свободы (ANOVA). | При n→∞ t-распределение стремится к нормальному. Для малых выборок t-критические значения существенно шире. |
| math.statistics.confidence_interval | Доверительный интервал (ДИ) | METHOD | 95% CI для μ (σ известна): X̄ ± 1.96·σ/√n. Интерпретация: если повторить эксперимент много раз, 95% построенных интервалов накроют истинное μ. НЕ «вероятность, что μ в интервале = 95%» (μ — константа в частотном подходе). | Ширина CI зависит от n, доверительного уровня и вариабельности данных. CI — мера точности оценки. |
| math.statistics.hypothesis_testing | Проверка гипотез — Нейман-Пирсон | METHOD | H₀ (нулевая) vs H₁ (альтернативная). α = P(ошибка I рода) = P(отвергнуть H₀ | H₀ верна). β = P(ошибка II рода) = P(принять H₀ | H₁ верна). Мощность = 1−β. p-value: вероятность получить наблюдаемый или более экстремальный результат при условии H₀. | p < 0.05 ≠ «вероятность H₀ < 5%» (распространённое заблуждение). | math.statistics.t_test_types | t-тест — одновыборочный, независимый, парный | METHOD | Одновыборочный: H₀: μ = μ₀. Независимые выборки: t = (X̄₁−X̄₂)/SE_diff, пул или раздельные дисперсии (тест Уэлча — предпочтителен, не требует равных σ). Стьюдент vs Уэлч. | math.statistics.anova | ANOVA — дисперсионный анализ | METHOD | Однофакторный: H₀: μ₁=μ₂=...=μₖ. F = MS_between / MS_within. Разложение SS_total = SS_between + SS_within.
