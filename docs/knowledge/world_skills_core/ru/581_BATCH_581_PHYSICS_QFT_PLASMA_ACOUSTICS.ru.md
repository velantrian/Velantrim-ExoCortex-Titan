| physics.qft.lagrangian_field | Лагранжева теория поля — от классической к КТП | INVARIANT | Действие S = ∫ L(φ,∂_µφ) d⁴x. Уравнения Эйлера-Лагранжа для полей: ∂_µ(∂L/∂(∂_µφ)) − ∂L/∂φ = 0. Квантование: поля становятся операторами, коммутационные соотношения [φ(x,t), π(y,t)] = iħδ³(x−y). | Клейн-Гордон (скалярное поле, спин 0), Дирак (спинорное, спин ½), Максвелл (векторное, спин 1). Калибровочная инвариантность — фундаментальный принцип. |
| physics.qft.dirac_equation | Уравнение Дирака — спин и антиматерия | INVARIANT | (iħγ^µ∂_µ − mc)ψ = 0. Предсказание позитрона (Андерсон, 1932). Спин ½ естественно вытекает из релятивистской инвариантности. Море Дирака (отрицательные энергии, интерпретированные как античастицы). | Позитронно-эмиссионная томография (ПЭТ): β⁺ распад → позитрон + e⁻ → аннигиляция → 2 фотона 511 кэВ. |
| physics.qft.qed | Квантовая электродинамика (КЭД) | INVARIANT | Калибровочная теория U(1). Вершина взаимодействия: e⁻ + γ (электрон излучает/поглощает фотон). Бегущая константа связи α(Q²): на малых расстояниях (высокие энергии) эффективный заряд растёт. Точность: g-2 электрона совпадает с теорией до 10¹². | Лэмбовский сдвиг (2s₁/₂ − 2p₁/₂ = 1057 МГц). Аномальный магнитный момент: a_e = (g−2)/2 = 0.00115965218073(28) — самый точный расчет в науке! |
| physics.qft.renormalization | Перенормировка — укрощение бесконечностей | METHOD | Петлевые поправки бесконечны → регуляризация (cutoff/размерная) → перенормировка (поглощение бесконечностей в переопределение массы и заряда). Теория перенормируема, если конечное число контрчленов устраняет все расходимости. | КЭД перенормируема (Томонага, Швингер, Фейнман, Нобелевская премия 1965). Гравитация неперенормируема → нужна квантовая гравитация. |
| physics.qft.feynman_diagrams | Диаграммы Фейнмана — Теория возмущений | METHOD | Графическое представление членов ряда теории возмущений. Правила Фейнмана: каждой линии и вершине соответствует математический фактор. Петли → интегралы по виртуальным импульсам. | Древесной уровень (tree-level) — классика. Петли — квантовые поправки. Рождение пар из вакуума (поляризация вакуума, экранировка заряда). |
| physics.qft.higgs_mechanism | Спонтанное нарушение симметрии и Хиггс | INVARIANT | Лагранжиан симметричен, но вакуум — нет. Потенциал V(φ) = μ² | φ | ² + λ | φ | ⁴. При μ²<0: «мексиканская шляпа», минимум при ненулевом вакуумном среднем v = √(−μ²/λ). Голдстоуновский бозон «съедается» калибровочным бозоном → W⁺,W⁻,Z⁰ становятся массивными. | Higgs поле даёт массу кваркам и лептонам через взаимодействие Юкавы. Открытие бозона Хиггса (ATLAS/CMS, 4 июля 2012, m_H=125 ГэВ). |
| physics.qft.qcd_confinement_asymptotic | КХД — цвет, глюоны, джеты | INVARIANT | Кварки несут цвет (3 заряда). Глюоны — 8 типов (сами несут цвет → самовзаимодействие). На малых расстояниях — слабая связь (асимптотическая свобода). На больших — сильная (конфайнмент: энергия струны ~1 ГэВ/фм, разрыв → jets). | Открытие глюона: 3-jet события в e⁺e⁻ аннигиляции (PETRA, DESY, 1979). Решёточная КХД (lattice QCD): вычисление масс адронов из первых принципов. |
| physics.plasma.debye_shielding | Дебаевское экранирование — квазинейтральность плазмы | INVARIANT | Плазма экранирует электрические поля на расстоянии дебаевской длины λ_D = √(ε₀kTe/(nₑe²)). При L ≫ λ_D — плазма квазинейтральна. Число частиц в дебаевской сфере N_D ≫ 1 — критерий идеальной плазмы. | λ_D ~ 0.1 мм (термоядерная), ~10 м (межзвёздная). Ленгмюровские колебания: ω_p = √(nₑe²/(ε₀mₑ)) — плазменная частота. |
| physics.plasma.magnetic_confinement | Магнитное удержание — Токамак | METHOD | Заряженные частицы вращаются вокруг силовых линий (ларморовский радиус r_L = mv⊥/(qB)). Токамак: тороидальное поле B_T (катушки) + полоидальное B_P (ток плазмы) → винтовые силовые линии → замкнутые магнитные поверхности. ITER (строится): Q=10 (500 МВт термоядерной из 50 МВт нагрева). | Неустойчивости: пилообразные (sawtooth), ELM (edge localized modes — тепловые удары на дивертор). Удержание: H-mode (high confinement, с транспортным барьером). |
| physics.plasma.inertial_confinement | Инерционный термоядерный синтез (ICF) | METHOD | DT-мишень (криокапсула) облучается мощными лазерами (NIF, 192 луча, 2 МДж/20 нс) или ионными пучками. Абляция внешнего слоя → реактивная сила → сжатие (имплозия) → плотность ×1000 твёрдого тела, T~100 млн K → термоядерное горение. Критерий Лоусона: nτ_T > 3×10²¹ кэВ·с/м³. | NIF: 2022 — зажигание (fusion ignition) впервые: выход энергии 3.15 МДж > 2.05 МДж лазерной энергии в мишени. Но КПД лазера ~1% (300 МДж из сети), пока не реактор. |
| physics.acoustics.wave_equation_sound | Уравнение акустической волны | INVARIANT | ∂²p/∂t² = c²∇²p. Скорость звука: c = √(K/ρ). Для идеального газа: c = √(γRT/M) = 331+0.6T°C м/с. Плоская волна: p = p₀·e^(i(kx−ωt)). Интенсивность I = p²/(2ρc) [Вт/м²]. | Уровень звукового давления SPL = 20·log₁₀(p/p_ref) [дБ], p_ref=20 мкПа (порог слышимости). Болевой порог 120-130 дБ. |
| physics.acoustics.doppler_acoustic | Акустический эффект Доплера и шок | PROCESS | f' = f·c/(c − v_s) (источник приближается). При v_s > c (сверхзвуковой источник) — конус Маха: sinθ = c/v_s = 1/Ma. Звуковой удар (sonic boom): N-образная волна давления (скачок уплотнения → линейное падение → скачок разрежения). | Сверхзвуковой хлопок — ограничение на полёты над сушей (Concorde летал только над океаном). NASA X-59 QueSST: форма планера снижает громкость удара до «глухого стука» вместо грохота. |
| physics.acoustics.helmholtz_resonance | Резонанс Гельмгольца | PROCESS | Бутылка: объём полости V + горлышко (площадь S, длина L). Резонансная частота f = (c/2π)·√(S/(VL)). Аналогия: масса воздуха в горле (инерция) + пружина воздуха в полости (упругость). | Духовые инструменты, басовый порт колонок, архитектурная акустика (резонаторы Гельмгольца в стенах для поглощения определённых частот). |
| physics.acoustics.psychoacoustics_fletcher_munson | Кривые равной громкости Флетчера-Мансона | MODEL | Субъективная громкость (изофоны) зависит от частоты. Максимальная чувствительность: 3-4 кГц (резонанс слухового канала). На низких и высоких частотах требуется большее давление для той же громкости. Контур A (A-weighting, dBA) корректирует измерения под восприятие. | Кнопка «Loudness» на усилителе (поднимает низкие и высокие на малой громкости). Стандарты шума: dBA для большинства измерений. |
| physics.acoustics.ultrasound_imaging | Медицинское УЗИ — Пульс-Эхо | METHOD | Пьезоэлектрический преобразователь излучает короткий импульс УЗ (2-18 МГц) → эхо от границ тканей (разница акустических импедансов Z=ρc) → приём → B-mode (яркость) изображение. Глубина = c·t/2. Разрешение ~λ (0.15-1.5 мм). Доплер: сдвиг частоты → скорость кровотока. | Безопаснее рентгена (нет ионизации), реальное время, портативно.
