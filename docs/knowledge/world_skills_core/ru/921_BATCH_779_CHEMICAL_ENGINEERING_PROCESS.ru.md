| chemeng.ops.reactor_design_pfr_cstr | Проектирование реактора — PFR против CSTR | METHOD | Реакторы в химической технологии: CSTR (Continuous Stirred Tank Reactor): идеальное перемешивание, одинаковая концентрация везде. VCSTR = FAO × XA / (-rA(exit)). PFR (Plug Flow): нет аксиального перемешивания, концентрация изменяется по длине. VPFR = FAO × ∫dXA/(-rA). CSTR в серии → приближается к PFR. Поправочный коэффициент F (для не-противотока). U (общий коэффициент теплопередачи): 1/U = 1/ho + Rfo + t/k + Rfi + 1/hi. Метод NTU-ε: для неизвестных температур на выходе.
