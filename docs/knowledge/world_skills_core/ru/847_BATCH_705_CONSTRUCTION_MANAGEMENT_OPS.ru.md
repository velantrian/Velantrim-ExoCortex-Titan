| conmgmt.ops.cpm_schedule | CPM — метод критического пути | METHOD | Метод критического пути (CPM): ES (Ранний старт), EF (Ранний финиш), LS (Поздний старт), LF (Поздний финиш). Плавающее = LF - EF = LS - ES. Критический путь: Float = 0. Прямой проход: ES0 = 0, EF = ES + Продолжительность. Обратный проход: LF_last = EF_last, LS = LF — Продолжительность. Преемники: max(EF) → следующий ES. PDM (метод диаграммы приоритетов): зависимости FS, SS, FF, SF. | TF (Total Float) отрицательный: проект уже опаздывает. |
| conmgmt.ops.earned_value_cpi | Освоенный объем — SPI и CPI | METHOD | Освоенная стоимость (EVA): PV (плановая стоимость), EV (освоенная стоимость = % выполнения × BAC), AC (фактическая стоимость). SPI = EV/PV (Индекс эффективности графика >1 = опережение). ИПЦ = EV/AC (индекс эффективности затрат >1 = под бюджетом). Оценка на момент завершения (EAC) = BAC/CPI. TCPI = (BAC – EV)/(BAC – AC). | CPI <0.8 в середине проекта: статистически редко заканчивается >1.0. |
| conmgmt.ops.rfi_management | RFI — Запрос информации | METHOD | RFI (Request for Information): подрядчик направляет архитектору/владельцу при неясности в документах. Обязательные элементы: номер RFI, описание вопроса, ссылка на чертёж/спецификацию, предложенный вариант решения, запрашиваемый ответ, дата. Response time: 5-10 рабочих дней (по договору). Log: отслеживание всех RFI. | Больше RFI = больше документация для потенциальных претензий (claims). |
| conmgmt.ops.submittal_log | Отправления — обработка и отслеживание | METHOD | Процесс согласования материалов (представлений): подрядчик собирает рабочие чертежи, данные изделия, образцы → передает архитектору → рассмотрение → «Утверждено», «Утверждено с учетом», «Пересмотреть и повторно отправить», «Отклонено». Срок выполнения: критично для закупок. График подачи: перечень всех заявок + крайний срок. Войдите в Procore/Autodesk Construction Cloud. | «Approved as noted»: работа может продолжаться с условиями. «R&R»: нельзя заказывать до повторного утверждения. |
| conmgmt.ops.change_order_types | Заказы на изменение — типы | METHOD | Изменение объёма работ: дополнительное соглашение (CO) — согласованное изменение контрактной стоимости/срока. Construction Change Directive (CCD): немедленное выполнение до согласования стоимости (emergency). PCO (Potential дополнительное соглашение): идентифицирован но не согласован. Временная метка. Суперинтендант подписывает. Документ AIA G711: форма ежедневного отчета. | Daily reports: ключевой документ для delays и claims (доказательство фактических событий). |

Участники: собственник, архитектор, подрядчик. Каждый пункт: описание, локация, ответственный, дата исправления. Сертификат существенного завершения работ (AIA G704): официальный документ. | conmgmt.ops.bim_clash_detection | BIM — обнаружение коллизий | METHOD | BIM (Информационное моделирование зданий): обнаружение коллизий — Autodesk Navisworks, Revit. | conmgmt.ops.safety_site_plan | План безопасности — для конкретной площадки | METHOD | Проект производства организации работ по охране труда: СССП (План обеспечения безопасности объекта).
