| thermophys.ops.zeroth_law | Нулевой закон — тепловое равновесие | METHOD | Нулевой закон термодинамики: если A в ТР с B и B в ТР с C, то A в ТР с C. Определяет температуру как транзитивное свойство. Основа для температурного измерения. Fixed points: тройная точка воды = 273.16 К. | Тройная точка воды: единственная точка где лёд, вода, пар сосуществуют (используется для калибровки). |
| thermophys.ops.carnot_efficiency | Двигатель Карно — максимальная эффективность | METHOD | КПД цикла Карно: η_Carnot = 1 - T_cold/T_hot (в Кельвинах). Максимальный для тепловой машины между T_hot и T_cold. Необратимые процессы снижают КПД. ΔS_universe ≥ 0 (2-й закон). COP_refrigerator = T_cold/(T_hot - T_cold). | Паровая электростанция: T_steam = 500°C, T_cold = 20°C → η_max = 61%. Реально: ~40%. |
| thermophys.ops.entropy_boltzmann | Энтропия — Больцман | METHOD | Энтропия (Больцман): S = k_B ln W. W = число микросостояний. 2-й закон: ΔS_universe ≥ 0. Эндогенная монотонная функция. Максимальная энтропия = равновесие. 3-й закон: S → 0 при T → 0 (Nernst theorem). | S = k_B ln W: формула на надгробии Больцмана. Статистическое толкование. |
| thermophys.ops.maxwell_boltzmann | Распределение Максвелла-Больцмана | METHOD | Распределение Максвелла-Больцмана: скорости молекул идеального газа. f(v) = 4πn(m/2πkT)^(3/2) × v² × exp(-mv²/2kT). Средняя скорость: v̄ = √(8kT/πm). RMS скорость: v_rms = √(3kT/m). Most probable: v_p = √(2kT/m). | Тяжёлые молекулы (CO₂ vs H₂): более медленные при той же температуре. |
| thermophys.ops.gibbs_free_energy | Свободная энергия Гиббса — фазовое равновесие | METHOD | Энергия Гиббса: G = H - TS. dG = VdP - SdT. При P, T = const: ΔG < 0 (самопроизвольно). Фазовое равновесие: G_α = G_β (химические потенциалы равны). Phase rule (Гиббс): F = C - P + 2. F = degrees of freedom, C = components, P = phases. | При плавлении льда (P = const): ΔS > 0, ΔH > 0 но ΔG = 0 (равновесие при 0°C). |
| thermophys.ops.clausius_clapeyron | Фазовые переходы — Клаузиус-Клапейрон | METHOD | Уравнение Клаузиуса-Клапейрона: dP/dT = ΔH_vap/(TΔV). Для пар: dP/dT = PΔH_vap/(RT²). Интегрирование: ln(P₂/P₁) = ΔH_vap/R × (1/T₁ - 1/T₂). Предсказание давления пара как функция T. Воздействие давления на точку плавления (отрицательный наклон для льда). | Лёд тает при давлении (отрицательный dP/dT): ΔV < 0 для воды. Уникальное свойство! |
| thermophys.ops.statistical_ensembles | Статистическая механика — ансамбли | METHOD | Статические ансамбли: Микроканонические: E = const. Канонический (NVT): T = const, статистическая сумма Z = Σ e^(-βεᵢ). Большой канонический (μVT): μ = const. F = -kT ln Z. Внутренняя энергия U = -∂ln Z/∂β. Энтропия S = k(ln Z + βU). | Статистическая сумма Z: «все, что нужно знать о термодинамике» — содержит всё. |
| thermophys.ops.bose_einstein_statistics | Квантовая статистика — Ферми-Дирак против BE | METHOD | Квантовая статистика: Fermi-Dirac (фермионы, полуцелый спин): f(ε) = 1/(exp((ε-μ)/kT) + 1). Bose-Einstein (бозоны, целый спин): f(ε) = 1/(exp((ε-μ)/kT) - 1). Оба → Maxwell-Boltzmann при высоком T. Pauli exclusion: FD. BEC: бозоны конденсируются в основное состояние. | Электроны в металле: FD статистика. Фотоны: BE статистика (без химического потенциала). |
| thermophys.ops.specific_heat | Удельная теплоемкость — Дюлонг-Пти | METHOD | Теплоёмкость: Dulong-Petit law: C_v = 3Nk_B (= 3R per mole). Работает при высоких T. Einstein model: квантованные осцилляторы → снижение при низких T. Debye model: спектр фононов → C_v ∝ T³ при очень низких T. Electronic contribution: линейный в T (только для металлов). | Einstein model: первое квантово-механическое приложение к твёрдому телу (1907). |
| thermophys.ops.van_der_waals | Газ Ван-дер-Ваальса — уравнение | METHOD | Уравнение ван дер Ваальса: (P + an²/V²)(V - nb) = nRT. a: межмолекулярное притяжение. b: объём молекул. Критическая точка: T_c = 8a/27Rb, V_c = 3nb, P_c = a/27b². Maxwell construction: фазовое равновесие. Уравнение более реалистично чем идеальный газ. | Критический коэффициент: PcVc/RTc = 3/8 (для любого van der Waals gas). |
| thermophys.ops.heat_transfer | Теплопередача — три режима | METHOD | Передача тепла: Проводимость: q = -kA dT/dx (Fourier). k = теплопроводность. Конвекция: q = hA(T_s - T_∞). h = коэффициент конвективного теплообмена. Излучение: q = εσA(T₁⁴ - T₂⁴). σ = Stefan-Boltzmann = 5.67×10⁻⁸ Вт/(м²·К⁴). | Солнечная постоянная: 1361 Вт/м² = радиационный поток от Солнца. |
| thermophys.ops.refrigeration_cop | Тепловой насос против холодильника | METHOD | Тепловой насос vs холодильник: Refrigerator COP: Q_cold/W = T_cold/(T_hot-T_cold). Heat Pump COP: Q_hot/W = T_hot/(T_hot-T_cold). COP_HP = COP_R + 1. Всегда: COP_HP > 1. Тепловой насос эффективнее электронагревателя при T_hot не очень высокой. | Тепловой насос: Q_hot > W (использует тепло окружающей среды). Коэффициент > 1. |
| thermophys.ops.phase_diagram | Фазовая диаграмма — Вода | METHOD | Фазовая диаграмма воды: Triple point (0.01°C, 611.7 Па): все три фазы. Critical point (374°C, 22.1 МПа): надкритическая жидкость.
