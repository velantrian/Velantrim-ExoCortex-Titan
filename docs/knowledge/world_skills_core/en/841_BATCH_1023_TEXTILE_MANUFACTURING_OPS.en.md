# BATCH 699: Textile Manufacturing — Industrial Processes

| textmanuf.ops.yarn_count_system | Yarn Count — Tex, Ne, Nm Systems | METHOD | Системы счёта пряжи: Tex = масса (г) на 1000 м (metrical direct — чем выше, тем толще). Ne (English Cotton Count) = количество мотков по 840 ярдов на 1 фунт (indirect — чем выше, тем тоньше). Nm (метрический) = м/г. Конверсия: Ne × Nm = 1693. Денье = г/9000 м (шёлк/синтетика). dtex = г/10 000 м (EU стандарт). | Пряжа 20 Ne = грубая хлопчатобумажная (одежда для работы). 40 Ne = рубашечная. |
| textmanuf.ops.ring_spinning_process | Ring Spinning — Process Stages | METHOD | Кольцепрядение: хлопок → cleaning (очистка от сора) → carding (расчёска в ровницу) → drawing (вытягивание в лент) → roving (ровница, 1-2 Tex) → ring spinning (вытяжка + скручивание). Twist direction: Z-twist (clockwise, standard) vs S-twist. TPI (twists per inch): чем больше TPI, тем прочнее но жёстче. Ring speed: 15 000-25 000 RPM. | Hairiness (пушистость): кольцевая > air-jet (влияет на pilling tendency). |
| textmanuf.ops.weaving_shedding_types | Weaving — Shedding Mechanisms | METHOD | Ткацкие машины: образование зева. Tappet (эксцентрик): 4-8 ремизок, простые переплетения (plain, twill). Dobby (доббибord): до 20-32 ремизок, сложные раппорты. Jacquard: отдельное управление каждой нитью → фигурные ткани без ограничения раппорта. Shed: пространство между поднятыми и опущенными нитями для прокидки утка. Shuttleless: рапирный, пневматический (air-jet), гидравлический. | Air-jet: самая высокая производительность (1500 об/мин утки) но только для лёгких тканей. |
| textmanuf.ops.knitting_weft_warp | Knitting — Weft vs Warp | METHOD | Трикотаж: уточный (weft) — нити формируют петли по рядам (поперечно), растяжение по обеим направлениям (jersey, rib). Основовязаный (warp) — нити движутся продольно (tricot, raschel), стабильнее, нет распускания. Gauge (игольница): 28 gauge = 28 игл/дюйм = самые тонкие. Sinker loop + needle loop. Деньер нити должен соответствовать gauge. | Warp knitting: невозможно распустить (в отличие от weft). |
| textmanuf.ops.reactive_dyeing_cotton | Reactive Dyeing — Cotton Protocol | METHOD | Реактивное крашение хлопка: химическая связь краситель-целлюлоза. pH: щелочная (кальцинированная сода Na2CO3, pH 10-11). Температура: 40-80°C (зависит от красителя). Соль (NaCl/Na2SO4): способствует выбиранию в начале. Fixation: 20-60 мин при щелочной среде. Промывка: горячая мыловка (удаление гидролизованного красителя). Прочность к стирке: высокая (ковалентная связь). | Незафиксированный гидролизованный краситель = основная причина потери прочности к мокрой обработке. |
| textmanuf.ops.disperse_dyeing_polyester | Disperse Dyeing — Polyester | METHOD | Дисперсное крашение полиэфира (PET): не растворим в воде → краситель в виде дисперсии. Высокая температура: 125-135°C (автоклав), иначе 100°C в присутствии carrier. Давление: избыточное (не кипит при 130°C). Краситель диффундирует в аморфные зоны. Восстановительная чистка (reductive clearing): sodium hydrosulfite удаляет поверхностный краситель (прочность к сухому трению). | PES + хлопок (polyester/cotton blend): диспергированный + реактивный (два этапа). |
| textmanuf.ops.fabric_finishing_calendar | Finishing — Calendering | METHOD | Каландрирование ткани: пропускание между гладкими/нагретыми валами под давлением. Эффекты: soft touch (мягкость), lustre (блеск), reduction of hairiness. Schreinering: гравированный вал → microrib → шёлковый вид хлопка. Embossing: текстурный вал → рельефный рисунок. Ciré (эффект масляной поверхности): высокая температура + давление на синтетике. | Temporary vs permanent: без смолы → смывается в стирке. Permanent: смола + calendar. |
| textmanuf.ops.mercerization | Mercerization — Caustic Treatment | METHOD | Мерсеризация хлопка (Mercer, 1844): обработка 20-22% NaOH при T° 10-20°C. Эффекты: набухание волокна → увеличение ориентации молекул → lustre, прочность +20-25%, улучшение поглощения красителей. Натяжение во время обработки: обязательно (иначе нет lustre). Нейтрализация: промывка кислотой после. Yarn vs fabric mercerization. | Mercerized cotton: более дорогой, лучший блеск, прочность, размерная стабильность. |
| textmanuf.ops.nonwoven_spunbond | Nonwoven — Spunbond Process | METHOD | Спанбонд: расплав полимера → экструзия через фильеры → вытяжка воздухом → осаждение на транспортёр → термоскрепление (kalandrирование). Материал: PP, PET, PE. Basis weight: 10-200 г/м². Области: медицина, гигиена (подгузники), геотекстиль, агрофлис. Свойства: однородные по направлениям, не расслаивается. | Spunbond vs meltblown: meltblown = более тонкие волокна (<1 мкм) → фильтрация (N95). |
| textmanuf.ops.yarn_twist_strength | Twist — Effect on Properties | METHOD | Скручивание (twist): увеличение twist → повышение прочности до оптимума → затем снижение (перекрут). Оптимальный twist = twist multiplier (TM) = TPI / √Ne. TM for warp yarn: 3.5-4.5. TM for weft/knitting: 2.5-3.5 (мягче). Soft twist: ворсистая пряжа (швабрин). Crepe yarn: high twist → crepe effect в ткани. | Крутка против направления плетения (S+Z): предотвращает скручивание ткани (balanced twist). |
| textmanuf.ops.fiber_burn_test | Fiber Identification — Burn Test | METHOD | Идентификация волокон горением: хлопок/вискоза — горит с запахом жжёной бумаги/бумаги, пепел мягкий. Шерсть/шёлк — медленно горит, запах жжёных волос, рассыпается в порошок. Полиэфир — плавится, чёрный жёсткий шарик. Нейлон — плавится, олива/белая сфера. Акрил — плавится + горит быстро. Смеси: промежуточный. | Быстрый полевой тест: полоска ткани + зажигалка. Не точен для смесей. |
| textmanuf.ops.color_fastness_rating | Colour Fastness — Grey Scale | METHOD | Оценка прочности окраски: Grey Scale 1-5 (5 = нет изменения, 1 = максимальное). Метод: сравнение с оригиналом после воздействия (стирка, свет, пот, трение). Standard test ISO 105. Light fastness: Wool Blue Scale 1-8 (8 = очень устойчивый). Специфика: реактивный хлопок — хорошая к стирке (4-5), умеренная к свету (3-4). | Fastness requirements: одежда — 4 min for washing, 4 min for dry-rubbing. |
| textmanuf.ops.warp_preparation | Warp Preparation — Sizing | METHOD | Подготовка ниток основы: warping (снование: нити на сновальный вал). Sizing (шлихтование): покрытие основы крахмалом/PVA для защиты при ткачестве. Drawing-in: нити через ремиз + бёрдо. Yarn repair (узелковая): исправление обрывов. Beam (навой): крепится в ткацком станке. Sized warp: более жёсткий (защита от трения о бёрдо). | Desizing после ткачества: удалить крахм перед крашением (адсорбция красителя). |
| textmanuf.ops.screen_printing_technique | Textile Screen Printing — Rotary | METHOD | Ротационная трафаретная печать: металлические цилиндрические сетки (никелевые, 40-100 меш). Каждый цвет — отдельный цилиндр. Paste (pigment или discharge): прокачивается через ротор. Скорость: до 80 м/мин. Curing: thermofixation (pigment: 160°C, 2 мин) или steaming (reactive dye). Colour registration: точность ±0.2-0.5 мм. | Engraving цилиндра: лазерное гравирование (wax-out process). |
| textmanuf.ops.digital_inkjet_textile | Digital Inkjet — Textile Printing | METHOD | Цифровая печать тканей: пьезо-электрический inkjet (Mimaki, Kornit, EFI). Inks: reactive (хлопок), acid (шёлк/нейлон), disperse (полиэфир), pigment (universal). Pre-treatment: нанесение фиксирующего состава. Steaming (после печати): реактивное крашение. Wash-off. Производительность: 100-400 м²/ч (промышленный). | Mass customization: печать любого дизайна без минимума (vs rotary = минимум 1000 м). |
| textmanuf.ops.elastane_blending | Elastane — Stretch Fabric | METHOD | Эластан (Lycra/Spandex) в смеси: 2-5% придаёт stretch. Содержание 15-20%: бельё, спортивные. Свойства: возможность растяжения 400-700%, восстановление. Ограничения: хлорная вода (бассейн), высокая температура (> 150°C деградация). Плетение и вязание с эластаном: покрытая пряжа (core-spun) или голая нить. | Хлор разрушает эластан: разбухание → потеря эластичности за несколько месяцев. |
| textmanuf.ops.quality_gsm_measurement | Quality Control — GSM Testing | METHOD | Граммы на квадратный метр (GSM): плотность ткани. Измерение: вырезать круговой образец диаметром 113.1 мм (площадь 100 см²) → взвесить → × 100 = GSM. Alternately: Circular sample cutter. T-shirt: 150-180 GSM. Heavy shirt: 200-250. Canvas: 300-500. Denim: 280-380 GSM. | GSM влияет на hand-feel, wearability, производственный cost. |
| textmanuf.ops.fire_retardant_finish | FR Finishing — CPSC Standards | METHOD | Огнезащитная отделка (FR): хлопок — Proban (phosphonium salt) для одежды сварщиков. Дети (USA): 16 CFR Part 1615/1616 — sleepwear requirements. Inherently FR: aramid (Nomex), modacrylic. Wash durability: "durable FR" = 50+ стирок. Halogen-free phosphorus-based: preferred. NFPA 70E: дуговая защита (arc rating). | Нелечебная FR: мыло/детергент с фосфатами может снять обработку. |
| textmanuf.ops.antimicrobial_finish | Antimicrobial Textile Finish | METHOD | Антимикробная обработка: silver ions (коллоидное серебро, AgNPs) — широкий спектр. Zinc oxide nanoparticles (ZnO). Триклозан (снят из многих продуктов по EPA). Chitosan (природный, biodegradable). Применение: медицинский текстиль, спортивная одежда. OEKO-TEX: стандарт безопасности (нет вредных химикатов). | Нанопорошки серебра: эко-токсичность при смыве (нормируется ЕС). |
| textmanuf.ops.textile_recycling_fibre | Textile Recycling — Mechanical vs Chemical | METHOD | Механическая переработка: шредdering ткани → коротковолокнистая масса → nonwoven или низкокачественные продукты. Chemical recycling: растворение (Ioncell, Lyocell process) → regenerated fibres. Polyester: PET bottles → rPET yarn (Repreve). Cotton/cotton blend: сложнее (трудно разделить). Sorting: NIR (near infrared) по типу волокна. | Chemical recycling: сохраняет качество (mechanical = downgrade). |
