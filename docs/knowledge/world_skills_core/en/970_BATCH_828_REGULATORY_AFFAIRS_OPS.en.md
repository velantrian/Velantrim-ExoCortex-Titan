# BATCH 828: Regulatory Affairs — Medical Devices & Drugs

**KnowledgeUnits:** 50
**Namespace:** `regulaffairs.ops.*`
**Scope:** FDA_approval, EMA, ICH_guidelines, clinical_trial_phases, post_market_surveillance, IVD_regulation, MDR_EU, labeling, recall_procedures

| ID | KnowledgeUnit | Тип | Суть | Практический смысл |
|---|---|---|---|---|
| regaff.ops.fda_pma_510k | FDA — PMA vs 510(k) | METHOD | FDA пути разрешения медицинских устройств: Class I (exempt, general controls), Class II (510(k), special controls), Class III (PMA, premarket approval). 510(k): показать «substantial equivalence» к предикатному. PMA: доказать safety AND effectiveness через клин. испытания. De Novo: для новых Class I/II без предиката. | Class III: высокорисковые устройства (искусственные клапаны, имплантируемые дефибрилляторы). |
| regaff.ops.ema_centralized | EMA — Centralized Procedure | METHOD | Европейское медицинское агентство (EMA): Centralized Procedure: разрешение действует во всех 27 ЕС. Обязательно для: биологики, онкология, ВИЧ, диабет. Voluntary для других. Decentralized: несколько национальных одновременно. Mutual Recognition: после одной страны. CHMP (Committee for Medicinal Products). | EMEA единое решение: эффективнее чем 27 национальных заявок. |
| regaff.ops.ich_guidelines | ICH — Harmonisation | METHOD | ICH (International Council for Harmonisation): гармонизация между USA, EU, Japan. Q (Quality): Q1-Q14. E (Efficacy): E6 (GCP), E3 (study reports). S (Safety): preclinical. M (Multidisciplinary): M4 (CTD — Common Technical Document). eCTD: электронный CTD для подачи. | CTD (Common Technical Document): модульный формат заявки для регуляторов. |
| regaff.ops.clinical_trial_gcp | GCP — Good Clinical Practice | METHOD | Надлежащая клиническая практика (GCP, ICH E6): принципы. Informed consent. IRB/IEC review. Investigator obligations. Sponsor obligations. Monitoring. Record retention. Регулятор: FDA 21 CFR Part 312 (IND), EMA. GCP инспекции: важный аспект одобрения. | Protocol Amendment: изменение в ходе исследования → IRB + регулятор. |
| regaff.ops.postmarket_surveillance | Post-Market Surveillance — MDR/EU | METHOD | Пост-маркетинговый надзор: FDA Adverse Event Reports (MAUDE database). MedWatch: добровольная отчётность. Mandatory: производители + пользователи. EU MDR Article 83: PMS plan. PSUR (Periodic Safety Update Report). PMCF (Post-Market Clinical Follow-up). | PMS: проактивный (не только реакция на события). |
| regaff.ops.eu_ivd_regulation | IVD Regulation — EU IVDR | METHOD | EU IVDR (In Vitro Diagnostic Regulation 2017/746): заменил 98/79/EC. 4 класса (A-D) по рискам. Нотифицированные органы: сертификация для класса B-D. Transition: до 2025-2027. EUDAMED: база данных. Performance studies. | Класс D (наиболее высокий риск): HIV тесты, HBV тесты, тест на COVID (классифицируется по риску). |
| regaff.ops.drug_labeling | Drug Labeling — Prescribing Information | METHOD | Маркировка (Prescribing Information, USA): Highlights of Prescribing Information (PIR). Black Box Warning (если применимо). Indications, Usage, Dosage, Contraindications, Warnings, Adverse Reactions, Drug Interactions, Use in Specific Populations, Clinical Pharmacology. | PLR format (Physician Labeling Rule, 2006): стандартизированный формат. |
| regaff.ops.recall_procedures | Recall Classification — FDA | METHOD | Отзыв продукта: Class I Recall: серьёзный риск для здоровья или смерть. Class II Recall: обратимый вред. Class III Recall: маловероятный вред. Market Withdrawal: незначительный дефект. Health Hazard Evaluation (HHE). Recall Effectiveness Check. | Voluntary recall (99%+) vs FDA-mandated: FDA редко принуждает (MDD Act имеет полномочия). |
| regaff.ops.anda_bioequivalence | Generic Drugs — ANDA | METHOD | Сокращённая заявка на регистрацию (ANDA): биоэквивалентность к innovator + same active ingredient + same dose form. BE study: AUC + Cmax (90% CI 80-125%). Orange Book: FDA список одобренных препаратов + патенты. Para IV certification: оспаривает патент. | BE у пациентов vs healthy volunteers: некоторые лекарства требуют пациентов (узкий терапевтический индекс). |
| regaff.ops.orphan_drug | Orphan Drug — Designation | METHOD | Редкие (орфанные) заболевания: Orphan Drug Designation (FDA): <200 000 пациентов в США. Преимущества: 7-year market exclusivity, tax credit, user fee waiver, faster review. EMA: <5 per 10 000 в EU. OOPD (Office of Orphan Products Development). | Orphan drug development: значительный коммерческий прогресс (rare disease ≠ no market). |
| regaff.ops.regulatory_submission_ctd | Regulatory Submission — eCTD | METHOD | Электронный Common Technical Document (eCTD): модульная структура. Module 1: административный (regional). Module 2: summaries. Module 3: quality (химия, производство). Module 4: nonclinical. Module 5: clinical. Lifecycle management: sequences/amendments. RegEnvision, Veeva Vault: regulatory platforms. | eCTD hyperlinking: cross-references between documents = navigable. |
| regaff.ops.combination_product | Combination Products — Regulation | METHOD | Комбинированные продукты (Drug + Device или другие комбинации): FDA Office of Combination Products (OCP): определяет primary regulatory path. Drug-eluting stent: primary = device (CDRH). Prefilled syringe: primary = drug (CDER). Autoinjector: usually drug primary. Human Factors: usability engineering (IEC 62366). | Primary mode of action (PMOA): определяет ведущий центр FDA. |
| regaff.ops.regulatory_strategy | Regulatory Strategy — Development | METHOD | Регуляторная стратегия: ранние встречи с FDA (pre-IND, Type B, Type C). Breakthrough therapy designation: более частые взаимодействия. Fast Track: гибкий review. Accelerated Approval: surrogate endpoints. Priority Review. Rolling Review: поэтапная подача. | PDUFA goal date: FDA target (Standard Review = 12 мес, Priority = 6 мес). |
| regaff.ops.preclinical_testing | Nonclinical Safety — ICH S-Guidelines | METHOD | Нокалинические исследования безопасности: ICH S1 (carcinogenicity), S2 (genotoxicity), S3 (toxicokinetics), S4 (acute+chronic toxicity), S5 (reproductive), S6 (biotech), S7 (pharmacology), S9 (oncology). GLP: Good Laboratory Practice — регулирует нокалинические исследования. | ICH M3: nonclinical timing для клин. исследований. |
| regaff.ops.benefit_risk_assessment | Benefit-Risk Assessment | METHOD | Оценка пользы-риска (Benefit-Risk): FDA Structured Framework. BRAT (Benefit-Risk Action Team) methodology. Quantitative: multi-criteria decision analysis (MCDA). Stakeholders: patient perspective critical. Context: disease severity + alternatives. CIOMS XI: regulatory context. | Paxlovid пример: высокая польза (серьёзный COVID) > DDI риски = одобрено с ограничениями. |
| regaff.ops.medical_writing | Regulatory Medical Writing | METHOD | Медицинское письмо для регуляторных документов: CSR (Clinical Study Report, ICH E3): полный отчёт об исследовании. PSR (Periodic Safety Report). PSUR. SmPC (Summary of Product Characteristics). IB (Investigator Brochure). Structured writing. Compliance with guidelines. | «Регуляторный язык»: точный, поддающийся проверке, структурированный. |
| regaff.ops.fda_advisory_committee | FDA Advisory Committees | METHOD | Консультативные комитеты FDA: независимые эксперты. Публичные заседания: полезны для сложных решений. PDAC, BMRAC, ADPAC и другие. Голосование: рекомендательное. FDA может не следовать. Citizen petitions: внешние стороны. | FDA не обязан следовать рекомендациям advisory committee, но отклонение требует обоснования. |
