# BATCH 715: HVAC Ductless — Mini-Split Installation

**KnowledgeUnits:** 50
**Namespace:** `minisplit.ops.*`
**Scope:** wall_mount, ceiling_cassette, lineset, flare, vacuum, condensate, multi_zone

| ID | KnowledgeUnit | Тип | Суть | Практический смысл |
|---|---|---|---|---|
| minisplit.ops.wall_mount_position_clearance | Wall Mount — Position & Clearance | METHOD | Выбор места для внутреннего блока. Расстояние от потолка: 15-20 см (air intake). От стен: 5-10 см с каждой стороны. Высота: 2-2.5 м от пола (для optimal air distribution). Не над кроватью/диваном (прямой поток). Не за шторами/мебелью. Не на внешней стене (сложнее drain). Не рядом с источниками тепла (плита, электроника — искажает thermostat). | Drain gravity (уклон): обязательно для отвода конденсата. |
| minisplit.ops.lineset_flaring_tool | Lineset — Flaring | METHOD | Развальцовка медных труб. Tool: eccentric flaring tool (эксцентриковый — ровнее). Процесс: надеть flare nut, зачистить торец (deburring tool), вставить в clamp (выступает на высоту die). Flare cone: затянуть до формирования 45° flare. Проверка: flare ровный, без трещин, симметричен. Flare соединение: nut затянут динамометрическим ключом (spec: 34-42 Нм для 1/4", 68-82 Нм для 1/2"). | Некачественный flare: медленная утечка refrigerant. |
| minisplit.ops.vacuum_pump_micron_gauge | Vacuum — Micron Gauge | METHOD | Вакуумирование системы. Vacuum pump: двухступенчатая (до 15-25 microns). Manifold gauge + vacuum-rated hoses. Core removal tool: для ускорения (выкрутить Schrader core). Процесс: vacuum до 500 microns, valve off, wait 10-15 min (decay test — рост <200-300 microns). Если растёт >500: утечка (или влага). Triple evacuation (oil-lubricated pump): nitrogen sweep + vacuum (3 раза) для глубокого обезвоживания. Заправка: release refrigerant (pre-charged outdoor unit). | Воздух + влага в системе: acid formation (разрушает compressor oil). |
| minisplit.ops.condensate_drain_gravity | Condensate Drain — Gravity | METHOD | Отвод конденсата от внутреннего блока. Graded: уклон min 1% вниз. Без сифона (trap) — у мини-сплитов дренаж самотёчный, не под давлением. Drain hose: пластиковая corrugated, изолирована (sweating). Защита от насекомых: drain cap. Проверка: залить воду в поддон испарителя (должна свободно течь). Condensate pump (если drain не gravity): с резервуаром + float switch. | Забитый drain: вода капает с indoor unit (damage wall). |
| minisplit.ops.multi_zone_branch_box | Multi-Zone — Branch Box | METHOD | Мульти-сплит система (до 5-8 indoor units на один outdoor). Branch box (распределительная коробка): электронные expansion valves (EEV) для каждого indoor. Lineset: 1 пара от outdoor к branch box, затем отдельные пары к каждому indoor. Refrigerant control: individual EEV регулирует поток в зависимости от нагрузки каждой зоны. Все indoor работают в одном режиме (все cool или все heat — heat pump). | Mixed mode (одна unit heat, другая cool): только с heat recovery системой (дороже). |
