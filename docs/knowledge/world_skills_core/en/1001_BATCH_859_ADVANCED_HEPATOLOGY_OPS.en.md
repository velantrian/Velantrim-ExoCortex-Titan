# BATCH 859: Gastroenterology — Advanced Hepatology

**KnowledgeUnits:** 50
**Namespace:** `hepatology.ops.*`
**Scope:** liver_failure, cirrhosis_complications, NAFLD_MASLD, hepatitis_viruses, portal_hypertension, liver_transplant, biliary_disease, autoimmune_liver

| ID | KnowledgeUnit | Тип | Суть | Практический смысл |
|---|---|---|---|---|
| hepatology.ops.acute_liver_failure | Acute Liver Failure — King's College Criteria | METHOD | Острая печёночная недостаточность (ОПН): King's College Criteria: Paracetamol: pH<7.3 OR coagulopathy (INR>6.5) + creatinine>300 + Grade III/IV encephalopathy. Non-paracetamol: INR>6.5 OR any 3 of: Age<10/≥40, Drug-related etiology, Duration jaundice-encephalopathy >7d, INR>3.5, Bilirubin>300. Лечение: ОИТ + NAC (парацетамол) + трансплантация. | KCC: критерии для листа ожидания трансплантации при ОПН. |
| hepatology.ops.cirrhosis_decompensation | Cirrhosis — Decompensation | METHOD | Декомпенсация цирроза: цирроз + асцит / варикозное кровотечение / печёночная энцефалопатия / желтуха. ACLF (Acute-on-Chronic Liver Failure): декомпенсация + органная недостаточность. CLIF-C score. 28-дневная смертность ACLF grade 3 = >70%. TIPS: снижение портального давления. | ACLF триггеры: инфекция, кровотечение, алкоголь, лекарства. |
| hepatology.ops.varices_prevention | Varices — Primary Prophylaxis | METHOD | Профилактика кровотечения из варикозных вен пищевода: Первичная (до первого эпизода): β-блокаторы (карведилол или пропранолол/надолол). EBL (Endoscopic Band Ligation): если непереносимость β-блокаторов. Вторичная (после эпизода): β-блокаторы + EBL. TIPS: рефрактерные случаи. | Non-selective β-blockers: также снижают SBP риск и почечную недостаточность. |
| hepatology.ops.nafld_masld | MASLD — New Nomenclature | METHOD | MASLD (Metabolic dysfunction-Associated Steatotic Liver Disease): новое название NAFLD (2023 многообщественный консенсус). Диагностика: стеатоз + ≥1 кардиометаболический фактор риска. MASH (ранее NASH): воспаление + баллонирование. FIB-4: <1.3 → низкий риск фиброза. >2.67: высокий (биопсия). | Ресметиром (Rezdiffra): первый одобренный FDA препарат для MASH (2024). |
| hepatology.ops.hepatitis_b_monitoring | Hepatitis B — HBsAg Monitoring | METHOD | Хронический гепатит B: HBeAg+ (Immune Tolerant или Immune Active). HBeAg- (Immune Inactive). HBsAg quantification. Мониторинг: HBV DNA + ALT каждые 3-6 мес. Лечение (цель: подавление HBV DNA): тенофовир АФ или энтекавир. HBsAg loss = functional cure (редко). | HBsAg > 1000 МЕ/мл при нормальном ALT = иммунная толерантная (лечение обычно не требуется). |
| hepatology.ops.wilson_disease | Wilson Disease — ATP7B | METHOD | Болезнь Вильсона: нарушение метаболизма меди (ATP7B мутация). Накопление Cu в печени, мозге, роговице. Kayser-Fleischer кольца: в роговице (при нейропсихиатрических). Диагностика: сывороточный церулоплазмин ↓ + мочевая Cu ↑ + печёночная Cu биопсия. Лечение: D-пеницилламин, триентин, цинк. | Острая печёночная недостаточность + Coombs-negative гемолитическая анемия + Cu очень высокая = Wilson. |
| hepatology.ops.hepatocellular_carcinoma | HCC — Screening & LI-RADS | METHOD | Гепатоцеллюлярная карцинома: скрининг каждые 6 мес (УЗИ ± AFP). LI-RADS: 1-5 (5=definitely HCC). Диагностика: типичный arterial enhancement + washout = LR-5 → биопсия не нужна. Лечение: Milan criteria → трансплантация. Ablation (RFA, MWA). TACE. Sorafenib/Lenvatinib: advanced. | AFP ненадёжный: нормальная у 30-40% HCC. Увеличение >400 нг/мл = высоко специфическое. |
| hepatology.ops.autoimmune_hepatitis | Autoimmune Hepatitis — Types | METHOD | Аутоиммунный гепатит (АИГ): Тип 1: ANA/ASMA (анти-SMA). Тип 2: анти-LKM-1 (Liver Kidney Microsomes). Гистология: розеткообразование гепатоцитов, плазмоцитарная инфильтрация. Score: Simplified Diagnostic Criteria. Лечение: преднизолон + азатиоприн. Ремиссия: АЛТ + IgG норм + нет воспаления. | АИГ + PBC или PSC = Overlap syndrome. Особое лечение требуется. |
| hepatology.ops.primary_biliary_cholangitis | PBC — Diagnosis | METHOD | Первичный билиарный холангит (ПБХ): аутоиммунный холестатический. AMA (Antimitochondrial antibodies): AMA-M2 в 95%. Повышение ЩФ + гамма-ГТ. Биопсия: грануломатозный холангит. Лечение: урсодезоксихолевая кислота (УДХК). При недостаточном ответе: обетихолевая кислота. | Шейнберг-Крайн: мнемоника для ПБХ — Pruritus, Bilirubin (elevated ALP). |
| hepatology.ops.psc_ibd | Primary Sclerosing Cholangitis — IBD | METHOD | Первичный склерозирующий холангит (ПСК): ассоциирован с ЯК (75-90%). Стриктуры и дилатация внутри- и внепеченочных желчных протоков. MRCP: «beaded» вид. Мониторинг: ежегодная колоноскопия (риск КРР). CCA (cholangiocarcinoma): 10-20% за жизнь. Трансплантация: единственное лечение. | ПСК = НЕТ медикаментозного лечения. Ursodiol: не рекомендуется (высокие дозы — вред). |
| hepatology.ops.hepatorenal_syndrome | Hepatorenal Syndrome — Terlipressin | METHOD | Гепаторенальный синдром (ГРС): тяжёлое ОПП у цирроза. Критерии: ОПП в цирозе без другой причины + не улучшается после 48ч диуретики отмена + albumin нагрузка. Тип 1 (HRS-AKI): быстрое прогрессирование. Тип 2 (HRS-NAKI): более медленное. Лечение: терлипрессин + альбумин (FDA approved 2022). | Терлипрессин: сужает спланхнические сосуды → ↑ почечная перфузия. |
| hepatology.ops.cholestatic_liver | Cholestasis — Intrahepatic vs Extrahepatic | METHOD | Холестаз: Внутрипечёночный (интрогепатический): гепатит, лекарственный, ПБХ, ПСК (маленький проток), беременность. Внепечёночный (экстрагепатический): холедохолитиаз, рак головки ПЖ, стриктура. MRCP: визуализация без инвазии. ERCP: диагностика + лечение. | Желтуха + холедохолитиаз = Charcot's triad: желтуха + боль + лихорадка. |
| hepatology.ops.drug_induced_liver | DILI — Causality Assessment | METHOD | Лекарственное повреждение печени (ДИЛИ): третья ведущая причина ОПН в США. RUCAM (Roussel Uclaf Causality Assessment Method): score. Типы: гепатоцеллюлярное (ALT/ULN / ALP/ULN > 5), холестатическое (<2), смешанное (2-5). Чёрный ящик: изониазид, ацетаминофен, статины. LiverTox: NIH база данных. | Остановить препарат немедленно + мониторинг. Не принимать снова (rechallenge = опасно). |
| hepatology.ops.portopulmonary | Portopulmonary Hypertension | METHOD | Портопульмональная гипертензия (ПоПУ): портальная гипертензия + ЛГ. Диагностика: MРАР > 25 мм рт.ст. + PCWP <15 + PVR >240. Лечение: ERА + PDE5i + простациклин. Трансплантация: противопоказана если МРАР > 35 (высокий операционный риск). TIPS: контраиндицирован (усиливает ЛГ). | Hepatopulmonary syndrome (HPS): ≠ portopulmonary. HPS = расширение сосудов (PO2 снижен). |
