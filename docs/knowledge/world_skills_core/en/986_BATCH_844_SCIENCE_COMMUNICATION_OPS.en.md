# BATCH 844: Science Communication — Research & Media

|---|---|---|---|---|
| scicomm.ops.imrad_structure | Scientific Paper — IMRaD | METHOD | Структура научной статьи (IMRaD): Introduction (почему?), Methods (как?), Results (что обнаружено?), Discussion (что это значит?). Abstract: 150-250 слов. Keywords: 5-10. Supplementary materials. Preprint servers: bioRxiv, arXiv, medRxiv. | IMRaD: стандарт для большинства эмпирических исследований в биомедицине. |
| scicomm.ops.peer_review_process | Peer Review — Types | METHOD | Рецензирование: Single-blind: рецензенты знают авторов, не наоборот. Double-blind: оба не знают. Open review: прозрачный. Post-publication peer review: PubPeer. Registered Reports: pre-registration перед данными. Ускоренные (expedited) reviews. Predatory journals: платят за публикацию без рецензий. | Predatory journals: Beall's list → проверять журнал. |
| scicomm.ops.statistical_reporting | Statistical Reporting — Standards | METHOD | Отчётность по статистике: CONSORT (RCTs), STROBE (наблюдательные), PRISMA (систематические обзоры), ARRIVE (животные), TRIPOD (прогностические). Effect sizes обязательны (не только p-value). CI обязательны. Отрицательные исследования: публиковать (publication bias). JAMA, NEJM: строгие статистические требования. | p-hacking: тестировать до значимости → pre-registration предотвращает. |
| scicomm.ops.research_ethics | Research Ethics — Principles | METHOD | Исследовательская этика (Belmont Report): Respect for persons (автономия + информированное согласие). Beneficence (максимизировать пользу). Justice (справедливое распределение). IRB (Institutional Review Board): USA. Ethics Committee: EU. Helsinki Declaration: международные принципы. | Tuskegee Syphilis Study (1932-72): этический скандал → стимул для Belmont Report. |
| scicomm.ops.grant_writing | Grant Writing — NIH Format | METHOD | Заявки на гранты (NIH): Specific Aims (1 страница): критичная. Research Strategy: Significance, Innovation, Approach. Biosketch. Environment. Human subjects. R01: основной грант исследования (~$250 000/год × 5 лет). R21: exploratory ($275 000/год × 2 года). K-awards: career development. | Scoring: 1-9 (1 = лучший). Только top ~20% получают финансирование. |
| scicomm.ops.open_access_publishing | Open Access — Models | METHOD | Открытый доступ (Open Access): Gold OA: финансирование автором (APC) → немедленный открытый доступ. Green OA: self-archiving в репозитории. Diamond OA: нет ни APC ни подписки (финансирование фондами). Hybrid OA: статьи оплачиваются в закрытых журналах. Plan S: мандат ОА в EU. | FAIR data principles: Findable, Accessible, Interoperable, Reusable. |
| scicomm.ops.science_media_relations | Science Communication — Media | METHOD | Взаимодействие с СМИ: Пресс-релиз: ключевое сообщение + цитаты + контакт. «Science by press conference»: минуя рецензирование. Social media: Twitter/X + LinkedIn = direct access. SciLine (SPJ): помощь ученым в работе с медиа. Embargo: единовременный выпуск для журналистов. | Миссия пресс-релиза: донести сущность без жаргона. Кому: general public. |
| scicomm.ops.data_visualization_principles | Data Visualization — Principles | METHOD | Принципы визуализации данных: Tufte принципы: maximize data-ink ratio, minimize chartjunk. Избегать: 3D charts, pie charts (трудно сравнивать). Colorblind friendly: ColorBrewer, viridis. Error bars: SD vs SE vs CI (указать какое). Figure captions: self-explanatory. | «Lie factor»: Tufte = visual distortion / data distortion. Стремиться к 1.0. |
| scicomm.ops.preregistration | Study Preregistration — OSF | METHOD | Предрегистрация исследования: Open Science Framework (OSF). ClinicalTrials.gov: обязательно для клинических. PROSPERO: систематические обзоры. Чёткое разграничение: confirmatory (primary) vs exploratory (secondary) hypotheses. Prevents HARKing (Hypothesizing After Results Known). | Registered Report: журнал принимает до сбора данных → устраняет publication bias. |
| scicomm.ops.science_policy | Science Policy — Evidence Use | METHOD | Доказательства в политике: NICE (UK): HTA (Health Technology Assessment). Evidence synthesis для policy makers. Science advice (Chief Science Advisors). Evidence-based policy vs Policy-based evidence. Politicization of science. IPCC: научный консенсус для climate policy. | Lancet Countdown: ежегодный трекинг climate + health indicators. |
| scicomm.ops.systematic_review_methods | Systematic Review — Protocol | METHOD | Систематический обзор: PROSPERO registration. Search strategy (OVID, PubMed, Embase, Cochrane). Inclusion/exclusion criteria. PRISMA flow diagram. Data extraction tool. Quality assessment (GRADE). Meta-analysis (if feasible). Narrative synthesis (if heterogeneous). | Cochrane Reviews: «gold standard» систематических обзоров. |
| scicomm.ops.research_misconduct | Research Misconduct — FFP | METHOD | Научная недобросовестность: FFP — Fabrication, Falsification, Plagiarism. Fabrication: придумывать данные. Falsification: изменять данные. Plagiarism: использовать чужие без ссылки. Self-plagiarism: повторная публикация. Retraction: отзыв публикации. Retraction Watch: база данных. | Replication crisis: большинство громких результатов не воспроизводятся (Reproducibility Project). |
| scicomm.ops.knowledge_translation | Knowledge Translation — KTA | METHOD | Перевод знаний (Knowledge Translation): разрыв between research и практикой. KTA Framework: Knowledge Creation → Action Cycle (Identify problem → Adapt knowledge → Assess barriers → Implement → Monitor → Sustain). Implementation Science: CFIR framework. | «17 years» myth: среднее время от исследования до клинической практики. Реально: 2-17 лет (зависит от области). |
| scicomm.ops.altmetrics | Altmetrics — Research Impact | METHOD | Альтметрики: альтернативные показатели влияния помимо цитирований. Altmetric.com score: внимание в СМИ, социальных сетях, политических документах. Readership (Mendeley). Patent citations. Downloads. H-index: Hirsch (научный + продуктивный). Impact Factor журнала: среднее число цитирований за 2 года. | H-index vs Total citations: H-index сбалансированный. Citations = один хорошо-цитируемый paper. |
| scicomm.ops.science_journalism | Science Journalism — Best Practices | METHOD | Научная журналистика: Проверять: peer-reviewed vs preprint. Учитывать: sample size + RCT vs observational. Не: «Correlation = causation» ошибки. SPJ Code of Ethics. Association of Health Care Journalists. Fact-checking: HealthNewsReview.org. | «Breakthrough of the decade»: журналисты выбирают громкие, но 80%+ не подтверждаются. |
