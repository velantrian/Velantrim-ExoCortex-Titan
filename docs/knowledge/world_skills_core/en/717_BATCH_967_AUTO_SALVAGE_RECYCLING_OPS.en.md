# BATCH 575: Auto Salvage — Dismantling & Recycling Operations

**KnowledgeUnits:** 44
**Namespace:** `autosalvage.ops.*`
**Scope:** yard, depollution, parts, inventory, acquisition, crushing, recycling, core_return

| ID | KnowledgeUnit | Тип | Суть | Практический смысл |
|---|---|---|---|---|
| autosalvage.ops.depollution_procedure | Depollution — Fluid & Hazardous Removal | PROCESS | Обезвреживание автомобиля перед разборкой. Жидкости: топливо, масло, трансмиссионное, тормозная, антифриз, хладагент AC (recovery machine — EPA certification). Аккумулятор: снять и отправить на recycling. Подушки безопасности: деактивировать. Шины: сортировка. Катализатор: извлечь (драгметаллы Pt, Pd, Rh). Процесс: draining station с поддонами для каждого типа жидкости. Запись в log: VIN, дата, жидкости удалены. | Не смешивать жидкости! Антифриз: recycled on-site или sold. Электромобили (EV): высоковольтная батарея — отдельный процесс. |
| autosalvage.ops.part_inventory_grading | Used Parts — Grading & Inventory System | METHOD | Каталогизация б/у запчастей. Grading: A-Grade (как новый), B-Grade (нормальный износ), C-Grade (повреждён но функциональный), X (cores), Scrap. Каждая деталь: уникальный номер, VIN донора, год/модель, пробег, дата, локация. Inventory system с interchange (Hollander). Фото детали. Warranty: 30-90 дней стандарт. Возврат: core return (клиент возвращает старую деталь). | Interchange: один двигатель стоял на 5 моделях. Hollander указывает прямой bolt-on или с модификациями. |
| autosalvage.ops.vehicle_acquisition | Vehicle Acquisition — Auctions & Direct | METHOD | Приобретение под разборку. Источники: Insurance Auto Auctions (IAA, Copart), direct insurance, charity, private sellers. Оценка: стоимость ключевых деталей (Engine $500-3000, Transmission $300-2000). Bidding online. Title: Salvage (Parts Only) или Clean. Документация (VIN, photo). | Flood cars: скрытые electrical проблемы. Оценка salvage yard: risk vs reward. |
| autosalvage.ops.vehicle_crushing_baler | Vehicle Crushing — Baler & Shredder | PROCESS | Переработка stripped hulk. Baler: гидравлический пресс сжимает кузов в плоский пакет. Shredder: молотковая дробилка разрывает на мелкие куски. Сепарация: магнитная (чёрные металлы), eddy current (цветные), воздушная (fluff — ASR). Металлы продаются: steel mill, aluminium smelter, copper refinery. | Не шредировать неподготовленный автомобиль — пожары, загрязнение. Depollution ПЕРЕД shredding обязательно. |
| autosalvage.ops.core_return_program | Core Return — Rebuildable Parts Exchange | METHOD | Программа возврата cores. Cores: двигатели, трансмиссии, генераторы, стартеры. Клиент платит core charge ($50-500), при возврате старого core — возврат charge. Core condition: должен быть complete, rebuildable. Restoration: разобрать, очистить, измерить, заменить изношенные части. Rebuilt parts: гарантия 12-24 мес. | Core charge — incentive для возврата. Не каждый core годен (cracked block — scrap). |
