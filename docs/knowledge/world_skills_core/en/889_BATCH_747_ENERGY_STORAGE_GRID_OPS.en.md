| energystorage.ops.battery_grid_types | Grid-Scale Battery — Technology Comparison | METHOD | Сетевые системы хранения: Li-ion (NMC, LFP): высокая энергоплотность, быстрый отклик (<100 мс). Для frequency regulation + peak shaving. Flow batteries (Vanadium): бесконечный цикл (электролит не деградирует), длительное хранение (4-8 ч+). BESS (Battery Energy Storage System) = инвертор + батарея + BMS + EMS. Roundtrip efficiency: Li-ion 90-95%, Vanadium flow 75-80%. | LFP для community/utility scale: более безопасный чем NMC (no thermal runaway). |
| energystorage.ops.frequency_regulation | Frequency Regulation — Primary Response | METHOD | Регулирование частоты: Первичная (primary response): автоматическая, <30 сек (governor control, BESS). Вторичная (AGC — Automatic Generation Control): 30 сек - 15 мин. Третичная: manually dispatched. BESS преимущество: реакция <100 мс vs thermal plant 30+ сек. FERC Order 841 (USA): storage участвует во всех рынках. | Частота 50 Гц (EU) / 60 Гц (US): ±0.5 Гц = допустимо. |
| energystorage.ops.virtual_power_plant | VPP — Virtual Power Plant | METHOD | Виртуальная электростанция: агрегация distributed resources (домашние батареи, solar, EV, HVAC) → управляемый ресурс для сети. Demand Response: снижение нагрузки по команде оператора. Aggregator: управляет VPP, ставки на рынке. Tesla Virtual Power Plant: SA в Австралии. Granular контроль: 1-MW adjustments в реальном времени. | Distributed Flexibility: millions of small resources > few large plants. |
| energystorage.ops.v2g_vehicle_grid | V2G — Vehicle-to-Grid | METHOD | Vehicle-to-Grid (V2G): EV разряжается в сеть во время пиков. CHAdeMO: первый стандарт V2G (Nissan Leaf). CCS Combo + ISO 15118-20: V2G для широкого внедрения. Grid services: frequency regulation, peak shaving. Требование: двунаправленный зарядник. Battery degradation concern: дополнительные циклы → но smart scheduling минимизирует. | V2G revenue: $500-1000/год от EV батареи (оценки). |
| energystorage.ops.hydrogen_storage | Hydrogen — Storage & Types | METHOD | Хранение водорода: сжатый (350-700 бар), жидкий (-253°C), материал (металлогидриды). Green hydrogen: электролиз из ВИЭ. Grey hydrogen: steam methane reforming (с CO2). Blue hydrogen: SMR + CCS. Pink: ядерная энергия. Производительность электролизёра: PEM (80-90%), Alkaline (75-85%). Levelised cost: $5-15/кг (green, 2024). | Round-trip efficiency H2: ~30-40% (electricity → H2 → fuel cell → electricity). |
| energystorage.ops.pumped_hydro_storage | Pumped Hydro — Design | METHOD | Гидроаккумулирующая электростанция (ГАЭС): насосный режим (дешёвая электроэнергия → закачка воды вверх) + генераторный (пиковая разгрузка). Efficiency: 75-85% round-trip. Capacity: 100 MW - 3 GW. Long duration storage (8-40 ч). Open-loop: реки. Closed-loop: автономные резервуары. Строительство: 5-10 лет, CAPEX $1000-3000/кW. | Pumped hydro = 95% всех глобальных energy storage capacity (мощность). |
| energystorage.ops.microgrid_control | Microgrid — Control Architecture | METHOD | Микросеть: локальная система с собственным управлением. Режимы: grid-connected (параллельно с сетью) + island mode (автономный). Переход: синхронизация при переключении. Иерархическое управление: primary (droop control), secondary (frequency/voltage restoration), tertiary (economic dispatch). Black start: перезапуск без внешней сети. CERTS Microgrid: стандартная архитектура. | Droop control: пропорциональное распределение нагрузки между генераторами без коммуникации. |
| energystorage.ops.demand_response | Demand Response — Types | METHOD | Управление спросом: Dispatchable DR: сигнал от оператора → сокращение нагрузки (промышленность, HVAC). Automated DR: предпрограммированный отклик (OpenADR протокол). Voluntary DR: клиент решает. Time-of-use (TOU): ценовой сигнал. Critical Peak Pricing (CPP). Base Interruptible Program. Economic DR: реагирование на цены. | Demand Response Resource: FERC требует компенсацию как generating resource (Order 745). |
| energystorage.ops.energy_management_system | EMS — Energy Management | METHOD | Система управления энергией (EMS): оптимизирует диспетчеризацию генерации + хранения. Inputs: electricity prices, load forecast, weather forecast, SOC. Optimization: linear programming или MPC (Model Predictive Control). Objectives: minimize cost, maximize revenue, support grid stability. SCADA + EMS: управление большими системами. | Day-ahead vs real-time optimization: day-ahead = плановый, real-time = коррекция. |
| energystorage.ops.levelized_cost_storage | LCOS — Levelized Cost of Storage | METHOD | Приведённая стоимость хранения (LCOS): LCOS = (CAPEX + NPV операционных затрат) / NPV выходной энергии. Факторы: стоимость батареи, roundtrip efficiency, число циклов в год, срок службы. Li-ion (utility): $150-250/MWh (2024). Снижение: Li-ion cost -90% за 10 лет. Комбинация: solar + storage + grid = dispatchable renewable. | LCOS vs LCOE: storage добавляет value через flexibility (нельзя сравнивать напрямую). |
| energystorage.ops.bms_battery_management | BMS — Battery Management System | METHOD | Система управления батареями (BMS): State of Charge (SOC): estimation (Coulomb counting, Kalman filter). State of Health (SOH): capacity vs. original. State of Power (SOP): max available power. Cell balancing: active (перекачивает заряд) vs passive (тратит излишки на heat). Protection: over-voltage, under-voltage, over-temperature, over-current. Communication: CAN bus, Modbus. | SOC estimation precision: ±1% критично для EV range anxiety. |
| energystorage.ops.grid_inertia_synthetic | Grid Inertia — Synthetic Inertia | METHOD | Инерция сети: традиционные генераторы (турбины) = физическая инерция → сглаживают изменения частоты. Снижение инерции: рост ВИЭ (invertors без инерции). Synthetic inertia: инверторы имитируют инерционный отклик (fast frequency response). FFR (Fast Frequency Response): BESS реагирует за <100 мс. ENTSOE: 30 ГВт·с требование. | RoCoF (Rate of Change of Frequency): ключевой параметр → при высоком RoCoF нарушения. |
| energystorage.ops.thermal_energy_storage | Thermal Storage — Molten Salt | METHOD | Термальное хранение энергии: Расплавленная соль (Molten Salt): CSP + TES (600°C, до 16 ч хранения). Охлаждение зданий: Ice storage (лёд ночью, охлаждение днём). Water tank thermal storage: тепло/холод в воде. PTES (Pit Thermal Energy Storage): сезонное. Carnot battery: тепловой насос + хранение → КПД 40-65%. | CSP + Molten Salt: dispatchable solar (в отличие от PV). |
| energystorage.ops.capacity_market_storage | Capacity Markets — Storage Participation | METHOD | Участие накопителей в рынке мощности: PJM, MISO, ISO-NE, CAISO. FERC Order 841: все хранилища участвуют в capacity markets. Discharge duration test: 4-hour duration requirement. Minimum qualification: 10 MW. Net Capacity Factor (NCF): доступность для диспетчеризации. Revenue stacking: energy + ancillary services + capacity = total revenue. | Revenue stacking критично: один рынок не окупает storage capex в большинстве регионов. |
| energystorage.ops.grid_forming_inverter | Grid-Forming Inverter — GFM | METHOD | Формирующий сеть инвертор (GFM): создаёт напряжение и частоту (vs grid-following = следует). Grid-Forming = как синхронный генератор. Droop control + virtual oscillator control (VOC) + Virtual Synchronous Machine (VSM). Необходим в Island mode. Grid following: только при наличии grid. Сетевой стандарт: IEEE 2800 (для inverter-based resources). | Future grid: 100% invertors → все должны быть Grid-Forming (or some). |
| energystorage.ops.battery_recycling | Battery Recycling — Li-ion End of Life | METHOD | Утилизация литий-ионных батарей: Second-life: EV battery → stationary storage (деградировала до 70-80% SOH). Recycling: Pyrometallurgy (термический: простой, теряет Li/Al). Hydrometallurgy (кислотный: более полное извлечение). Direct recycling (cathode reuse): перспективный. Recover: Co, Ni, Mn, Li. EU Battery Regulation 2023: требования к переработанному содержанию. | Battery passport (ЕС): цифровой паспорт батареи для отслеживания. |
| energystorage.ops.compressed_air_caes | CAES — Compressed Air Energy Storage | METHOD | Хранение сжатого воздуха (CAES): электроэнергия → компрессор → подземная полость (соляная каверна, шахта). Discharge: газовая турбина без компрессора (экономия 2/3 топлива). Advanced CAES (ACAES): без природного газа (adiabatic). Diabatic CAES: с газом (Huntorf, 390 MW). Round-trip efficiency: diabatic 50-70%. | CAES требует специальную геологию (соляные купола, пористые скальные образования). |
| energystorage.ops.islanding_detection | Islanding — Protection | METHOD | Обнаружение «островизации» (islanding): отключение сети → DER continues → опасность для ремонтных бригад. Passive methods: под/перенапряжение, под/перечастота. Active methods: frequency drift, reactive power perturbation. Communication-based: SCADA сигнал. Anti-islanding: IEEE 1547, IEEE 929. Trip time: <100 мс при опасных условиях. | Inverter certification: IEEE 1547.1 compliance testing обязателен для grid interconnection. |

Privacy concerns: detailed usage patterns. Cybersecurity: IEC 62351. | AMI data: 35 000 data points/year per customer vs 12 manually (before). |
