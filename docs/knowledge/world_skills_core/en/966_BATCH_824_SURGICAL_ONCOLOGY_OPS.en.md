# BATCH 824: Surgical Oncology — Cancer Surgery

**KnowledgeUnits:** 50
**Namespace:** `surgiconc.ops.*`
**Scope:** colorectal_cancer, hepatectomy, pancreatectomy, breast_surgery, melanoma_surgery, sarcoma, esophagectomy, sentinel_node, margin_status, staging_surgery

| ID | KnowledgeUnit | Тип | Суть | Практический смысл |
|---|---|---|---|---|
| surgiconc.ops.colorectal_staging | Colorectal Cancer — Surgical Staging | METHOD | Стадирование колоректального рака: ТНМ (AJCC 8th Ed). T1-4: глубина инвазии. N0-N2: регионарные лимфоузлы (N1=1-3, N2=≥4). M0-1: метастазы. Стадия I (T1-2N0) → IV (M1). MSI-H/dMMR: прогностический и предиктивный маркер. «Синдром Линча»: мутации MLH1/MSH2. | Неоадъювантная ХЛТ для прямой кишки: снижает локальный рецидив при cT3-4 или N+. |
| surgiconc.ops.whipple_procedure | Pancreaticoduodenectomy — Whipple | METHOD | Операция Уиппла: головка поджелудочной железы + дуоденум + дистальный желудок (стандартный) + общий желчный проток. Pylorus-preserving Whipple (PPPD): сохраняет привратник. Реконструкция: панкреатоеюностомия + гепатикоеюностомия + гастроеюностомия. Осложнения: POPF (pancreatic fistula), DGE (delayed gastric emptying). | «Resectability»: нет инвазии SMA/celiac axis, нет отдалённых метастазов. |
| surgiconc.ops.hepatectomy | Hepatic Resection — Margins | METHOD | Резекция печени: анатомическая (по сегментам Куино) vs неанатомическая. Минимальный хирургический край: R0 = нет опухоли на крае. R1 = микроскопическое. R2 = макроскопическое. FLR (Future Liver Remnant): должен быть ≥20-25% для нормальной печени, ≥30-40% при повреждённой. Portal vein embolization (PVE): гипертрофия FLR перед резекцией. | R0 резекция = наиболее важный прогностический фактор при гепатоцеллюлярной карциноме. |
| surgiconc.ops.breast_conserving | Breast Cancer — Conservation Surgery | METHOD | Органосохраняющая операция (ОСО): BCT = partial mastectomy + лучевая терапия. Показания: одиночная опухоль, нет BRCA1/2 (относительное), нет предшествующей лучевой. Margin: «no ink on tumor» = достаточный. Sentinel lymph node biopsy (SLNB): стандарт при клинически N0. SLNB ±ALND (axillary lymph node dissection). | SLNB без ALND при ≤2 positive sentinel nodes (ACOSOG Z0011 trial): одинаковые исходы. |
| surgiconc.ops.melanoma_wide_excision | Melanoma — Wide Local Excision | METHOD | Широкое местное иссечение меланомы: Margins по Breslow depth. <1 мм: 1 см margin. 1-2 мм: 1-2 см. >2 мм: 2 см. SLNB: при Breslow ≥0.8 мм или с микроскопической ульцерацией. Completion ALND при +SLNB: MSLT-II trial показал: не улучшает выживаемость. Targeted therapy/immunotherapy. | BRAF V600E мутация: 50% меланом → BRAF ингибиторы. |
| surgiconc.ops.esophagectomy | Esophagectomy — Approaches | METHOD | Эзофагэктомия: Ivor Lewis: right thoracotomy + laparotomy. McKeown (3-field): + cervical anastomosis. Transhiatal (без thoracotomy): blunt dissection. Minimally invasive esophagectomy (MIE). Anastomotic leak: наиболее серьёзное осложнение. Respiratory: риск 10-20%. | Ортопедическая схема (Неоадъювантная): ХЛТ → эзофагэктомия = улучшает 5-year survival (CROSS trial). |
| surgiconc.ops.sarcoma_surgery | Soft Tissue Sarcoma — Surgery | METHOD | Хирургия сарком мягких тканей: Wide local excision: R0 margin (>1 см). Конечность: limb-sparing (95%+ случаев). Radiation: снижает local recurrence. Retroperitoneal: R0 = часто нереально, margin широко от крупных сосудов. Gastrointestinal Stromal Tumor (GIST): imatinib неоадъювантно → резекция. | «Compartment resection» для саркомы конечностей: вся анатомическая зона — для редких случаев. |
| surgiconc.ops.gastric_cancer_d2 | Gastric Cancer — D2 Lymphadenectomy | METHOD | Рак желудка — D2 лимфаденэктомия: D1 (перигастральные) + D2 (региональные бассейны = 25+ узлов). D2 = стандарт в Японии/Корее. В Европе: D1+ или D2 (без рутинной спленэктомии-панкреатэктомии). R0 + D2: улучшает выживаемость. Total vs subtotal gastrectomy. | FLOT: предпочтительная периоперационная химиотерапия в Европе. |
| surgiconc.ops.lung_cancer_lobectomy | Lung Cancer — Surgical Resection | METHOD | Хирургическое лечение НМРЛ: Лобэктомия: стандарт для операбельного. Sublobar resection (wedge/segmentectomy): при VATS + T1 (≤2 см). Bilobectomy или пневмонэктомия: распространённые. FEV1 >40% прогнозируемого послеоперационного = хирургически безопасно. Mediastinal lymph node dissection. VATS vs open. | Stereotactic Body Radiation (SBRT): для неоперабельных (медицинских). |
| surgiconc.ops.thyroid_cancer_management | Thyroid Cancer — Surgical | METHOD | Хирургия рака щитовидной железы: Papillary thyroid cancer (ПТК): Total thyroidectomy (при опухоли >1 см). Hemithyroidectomy: при микрокарциноме (<1 см). Central neck dissection: при клиническом N1a. Lateral neck dissection (Berry picking): при N1b. RAI: после тотальной резекции для оценки. | Active surveillance: для ПТК <1 см у подходящих пациентов. |
| surgiconc.ops.peritoneal_carcinomatosis | CRS + HIPEC | METHOD | Циторедуктивная хирургия + гипертермическая интраперитонеальная химиотерапия: Карциноматоз брюшины (колоректальный, аппендикулярный, мезотелиома). Cytoreduction Score (CC): CC-0 (no residual), CC-1 (<2.5 мм). CC-0 → лучший исход. HIPEC: митомицин C или оксалиплатин при 41-42°C, 90 мин. | PCI (Peritoneal Cancer Index): распределение карциноматоза. PCI >20 = высокий риск. |
| surgiconc.ops.laparoscopic_oncology | Laparoscopic Oncology — Principles | METHOD | Лапароскопическая онкохирургия: рак ободочной кишки: COLON trial = нет разницы oncological outcomes vs open. Ретальный: спорно (TME quality). Adrenalectomy: предпочтительно лапароскопически. Port site metastases: редкость при правильной технике. «No touch» isolation technique. | Laparoscopic colectomy: снижает боль, быстрее восстановление, те же онкологические исходы. |
| surgiconc.ops.neoadjuvant_benefit | Neoadjuvant — Benefit Assessment | METHOD | Оценка неоадъювантной терапии: pCR (pathological Complete Response): нет опухоли в операционном препарате. pCR = суррогатный маркер улучшения выживаемости. Rectal cancer: pCR 25-30% при CCRT. Breast: pCR 40-60% при TNBC. Капрекситабин-чиперацитин. Downstaging: возможна хирургия ранее нерезектабельного. | Rectal cancer watch-and-wait: cCR после CCRT → нет операции (в специализированных центрах). |
| surgiconc.ops.surgical_staging_melanoma | Sentinel Node — Radiolabeled | METHOD | Биопсия сторожевого узла с радиоизотопом: 99mTc-коллоид + синий краситель → SLNB. Гамма-зонд: интраоперационная навигация. Патология: IHC для микрометастазов. Micrometastasis в SLNB: не нужна completion ALND. Нет ALND при 1-2 +SN: ACOSOG Z0011 (рак молочной железы). | SLNB при меланоме: прогностическая ценность, но не показана для лечения (нет survival benefit при ALND). |
| surgiconc.ops.colorectal_liver_metastasis | Colorectal Liver Mets — Resectability | METHOD | Метастазы КРР в печени: 30-40% пациентов с mCRC. Резектабельность: FLR >20-30% + возможность R0. Двухэтапная гепатэктомия. Portal vein embolization (PVE). «Conversion chemotherapy»: при первично нерезектабельных. KRAS/RAS статус. Синхронные vs метахронные. | Резекция mCRC печени: 5-year survival 40-60% при R0. Без хирургии: <5%. |
