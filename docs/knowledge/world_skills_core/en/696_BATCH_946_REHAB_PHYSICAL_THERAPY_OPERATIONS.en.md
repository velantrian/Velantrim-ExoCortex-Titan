| rehab.ops.orthopedic_evaluation | PT Orthopedic Evaluation — SOAP Note | METHOD | Обследование в физической терапии. Subjective: история (механизм травмы, onset, aggravating/easing factors, previous treatment), боль (NPRS 0-10, характер — острая/тупая/стреляющая), функциональные ограничения (не могу поднять руку чтобы причесаться). Objective: AROM/PROM (диапазон движения — гониометрия, нормы: плечо flex 180°, abduction 180°, external rotation 90°), MMT (Manual Muscle Testing 0-5), специальные ортопедические тесты (Neer's, Hawkin's для shoulder impingement, Lachman для ACL, McMurray для meniscus, SLR для lumbar radiculopathy), palpation (trigger points, swelling), posture assessment (forward head, rounded shoulders), gait analysis. Assessment: PT diagnosis («Rotator cuff tendinopathy with secondary impingement»), problem list, prognosis. Plan: short-term goals (2-4 нед — увеличить ROM на X°, снизить боль до Y), long-term goals (6-8 нед — возврат к поднятию Z кг над головой). Interventions: therapeutic exercise, manual therapy, modalities, patient education. | SOAP Note: документооборот (legal document + insurance reimbursement обоснование). Medical Necessity: каждый intervention должен быть обоснован (не «потому что я так решил», а «для восстановления ROM плеча для повседневного использования»). |
| rehab.ops.therapeutic_exercise_progression | Therapeutic Exercise — Progression & Prescription | METHOD | Лечебная физкультура. Параметры FITT-VP. Frequency: 3-5 раз/нед. Intensity: RPE (Borg Scale 6-20 или CR10). Time: удержание 10-30 сек для stretch, количество повторений (2-3 sets × 10-15 reps для strength). Type: изометрические → концентрические → эксцентрические (eccentric особо для tendinopathy — Alfredson protocol: 3×15 reps, 2x/день, 12 недель для Achilles). Progression: по боли (NPRS ≤3/10 допустимо во время, 0/10 после 24 часов), не «no pain no gain». Open chain (стопа свободна — leg extension) vs Closed chain (стопа на земле — squat). Closed chain более функциональны и безопасны для суставов. Принцип специфичности: тренировать то что пациент хочет делать (спортсмен → sport-specific движения, офисный работник → posture + core stability). Home exercise program (HEP): дать пациенту напечатанные инструкции с картинками + видео по QR-коду. Дневник самоконтроля (pain, reps, sets). | Compliance: средний пациент выполняет HEP на 60-70% предписанного. Факторы: простота (1-3 упражнения, не 10), объяснение значимости (почему это помогает), болевой feedback. |
| rehab.ops.manual_therapy_joint_mobilization | Manual Therapy — Joint Mobilization | METHOD | Мануальная мобилизация суставов (Maitland Grades). Grade I: малая амплитуда, лёгкие ритмичные колебания в начале диапазона (для боли, muscle guarding). Grade II: большая амплитуда, без достижения барьера сопротивления (для боли + ROM). Grade III: большая амплитуда до сопротивления ткани и через него (для stiffness). Grade IV: малая амплитуда на пределе сопротивления (для stiffness в конечном диапазоне). Grade V: малая амплитуда, высокоскоростной толчок (thrust — манипуляция, «хруст» — cavitation gas release в суставе). Применение: глено-плечевой (заднее скольжение для улучшения флексии и внутренней ротации — convex-concave правило: плечо — convex, мобилизация в противоположном направлении от ограничения). Hip: posterior-anterior glide для разгибания. Дозировка: 30-60 сек × 1-3 подхода, Reassessment после (изменение боли, ROM, MMT). Противопоказания: fracture, metastasis (до мобилизации — скрининг red flags: ночная боль, необъяснимая потеря веса, история рака), inflammatory arthritis в острой стадии, instability (hypermobility синдромы). | Суставной шум (click/grind) без боли — не противопоказание. Золотое правило: reassessment после интервенции немедленно. Если пациенту хуже через 24 часа — снизить интенсивность. |
| rehab.ops.modalities_ultrasound_tens | Modalities — Ultrasound & TENS | METHOD | Физиотерапевтические методы. Therapeutic Ultrasound (УЗТ): 1 МГц (глубокие ткани — до 5 см), 3 МГц (поверхностные — до 2 см). Интенсивность: 0.5-2.0 Вт/см². Duty cycle: continuous (тепловой эффект, для chronic) или pulsed 20-50% (non-thermal, для acute воспаления). Площадь излучателя: 5-10 см² (размер transducer head). Техника: постоянное движение (circles, overlapping), coupling gel. Время: 5-10 мин. TENS (чрезкожная электронейростимуляция): Conventional (High frequency 50-100 Гц, низкая интенсивность — comfort, gate control theory для acute pain), Acupuncture-like (Low 2-4 Гц, высокая интенсивность — motor level, contraction, эндорфины для chronic). Электроды расположение: по ходу нерва/дерматома. IFC (Интерференционный ток): две пересекающиеся среднечастотные волны, глубже проникает чем TENS, comfortable. Cryotherapy: Ice pack 15-20 мин, ice massage (бумажный стаканчик со льдом по кругу 5-10 мин — до hemostasis). Heat (Hot Pack): 20 мин, влажное тепло, 6-8 слоёв полотенца между pack и кожей. | УЗТ + гель: необходимо постоянное движение, иначе standing wave перегревает надкостницу (боль!). Большинство modalities имеют weak evidence в сравнении с exercise (но placebo + patient expectation играют роль). |
| rehab.ops.neuro_stroke_gait_training | Neuro — Post-Stroke Gait Training | METHOD | Восстановление ходьбы после инсульта. Фазы gait: Stance (60% цикла — heel strike → foot flat → midstance → heel off → toe off), Swing (40% — acceleration → midswing → deceleration). Компоненты нарушений после stroke: foot drop (слабость tibialis anterior — не может поднять стопу в swing → AFO brace ± FES), knee hyperextension в stance (слабость quadriceps — колено прогибается назад), hip hiking (компенсация слабого hip flexor — таз поднимается чтобы протащить ногу). Interventions: 1) Weight shifting exercises (перенос веса на поражённую сторону), 2) Single leg stance practice (поражённая нога), 3) Sit-to-stand (ключевое функциональное движение), 4) Gait training с параллельными брусьями → walker → quad cane → single point cane, 5) Treadmill training (body weight support BWS если нужно), 6) CIMT (constraint-induced movement therapy) для upper extremity — ограничение здоровой руки для форсирования использования поражённой. FES (функциональная электростимуляция): электроды стимулируют dorsiflexors в swing фазе по сигналу от heel switch в обуви. Дозировка: интенсивно (high repetition, massed practice — 300-800 repetitions за сессию). | Нейропластичность: мозг перестраивается через повторяющуюся практику. 10000+ повторений для моторного обучения. Mirror therapy (зеркальная коробка): для upper extremity, визуальная иллюзия движения поражённой конечности. |
