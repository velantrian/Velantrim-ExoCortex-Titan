| chemeng.ops.reactor_design_pfr_cstr | Reactor Design — PFR vs CSTR | METHOD | Реакторы в химической технологии: CSTR (Continuous Stirred Tank Reactor): идеальное перемешивание, одинаковая концентрация везде. VCSTR = FAO × XA / (-rA(exit)). PFR (Plug Flow): нет аксиального перемешивания, концентрация изменяется по длине. VPFR = FAO × ∫dXA/(-rA). CSTR в серии → приближается к PFR. Levenspiel plot: 1/(-rA) vs XA. | PFR всегда меньше CSTR для одного конверсии (для одного порядка + нет авто каталитической). |
| chemeng.ops.heat_exchanger_lmtd | Heat Exchanger — LMTD Method | METHOD | Теплообменник: Q = U × A × ΔTlm. LMTD (Log Mean Temperature Difference): ΔTlm = (ΔT1 - ΔT2) / ln(ΔT1/ΔT2). Correction factor F (для не-противотока). U (overall heat transfer coefficient): 1/U = 1/ho + Rfo + t/k + Rfi + 1/hi. NTU-ε method: для unknown outlet temps. Fouling resistance (Rf): снижает U со временем. | Теплообменник в параллельном потоке: меньший LMTD чем противоток. |
| chemeng.ops.distillation_mccabe_thiele | Distillation — McCabe-Thiele | METHOD | Метод МакКейба-Тила: графическое построение теоретических тарелок. Равновесная кривая (y vs x). Рабочие линии: верхняя (rectifying): y = L/V × x + D×xD/V. Нижняя (stripping). Подача: питательная линия (q-line). Отступ от оптимального: несовпадение входа. Reflux ratio R = L/D. Минимальный рефлюкс R_min: «прижимание» к равновесной кривой. | Теоретическое число тарелок vs фактическое: η = эффективность тарелки (Murphree). |
| chemeng.ops.mass_transfer_flooding | Packed Column — Flooding | METHOD | Насадочные колонны (массообменные): Flooding velocity: max скорость газа перед заливанием жидкостью. Операционная точка: 70-80% от flooding. Generalized Pressure Drop Correlation (GPDC): номограмма для flood prediction. HETP (Height Equivalent to a Theoretical Plate): определяет высоту колонны. HOG vs HOL: высота единицы переноса. Packing: Random (Raschig rings) vs Structured (Mellapak). | Structured packing: меньший pressure drop + более низкое HETP vs random. |
| chemeng.ops.process_control_pid | Process Control — Feedback PID | METHOD | ПИД-регулирование в технологии: Error: e(t) = Setpoint - Measurement. PID Controller: u(t) = Kp×e + Ki×∫e dt + Kd×de/dt. Process Transfer Functions. Laplace domain. Closed-loop stability: characteristic equation 1+GcGp = 0. Ziegler-Nichols tuning. Control valve: linear vs equal-percentage. | Equal-percentage valve: лучше для процессов с переменным давлением. |
| chemeng.ops.hazop_guidewords | HAZOP — Guide Words | METHOD | Анализ опасности и работоспособности (HAZOP): For each process node, apply guide words: NO/NOT (completely negative), MORE (quantitative increase), LESS (quantitative decrease), AS WELL AS (qualitative addition), PART OF (qualitative reduction), REVERSE, OTHER THAN. Deviations from design intent. Causes → Consequences → Safeguards → Action. | HAZOP: обязателен для всех новых установок Класса A (SEVESO, PSMA, OSHA PSM). |
| chemeng.ops.flash_drum_vle | Flash Drum — VLE Calculation | METHOD | Flash drum: жидкость + пар в равновесии. Рачфорд-Райс: Σzᵢ(Kᵢ - 1) / (1 + ψ(Kᵢ - 1)) = 0. ψ = V/F (vapour fraction). Kᵢ = yᵢ/xᵢ. Модели активности: Raoult (ideal), Modified Raoult (NRTL, UNIQUAC). Dew point: начало конденсации. Bubble point: начало испарения. | Bubble point calculation: начало кипения смеси при данном давлении. |
| chemeng.ops.psychrometric | Psychrometrics — Humidity Chart | METHOD | Психрометрическая диаграмма: влажность воздуха. Dry bulb temperature (DBT). Wet bulb temperature (WBT). Relative Humidity (RH). Specific Humidity (ω): кг вода/кг сухого воздуха. Dew Point Temperature. Enthalpy of moist air. Cooling + Dehumidification process. Humidification/Heating. | HVAC расчёты: психрометрика = основа проектирования систем вентиляции. |
| chemeng.ops.crystallization_operations | Crystallization — Nucleation & Growth | METHOD | Кристаллизация: Nucleation (зародышеобразование): первичное (без затравки) vs вторичное (с затравкой). Washing: удаление маточного раствора. | Пересыщение S <0.01: медленная нуклеация, крупные кристаллы. |
| chemeng.ops.membrane_separation | Membrane Separation — Types | METHOD | Мембранные процессы разделения: Microfiltration (0.1-10 мкм): микроорганизмы. | chemeng.ops.exothermic_reactor_safety | Exothermic Reactor — Runaway | METHOD | Тепловой разнос экзотермического реактора: Тепловыделение Qr = (-ΔHr) × (-rV). Теплоотвод Qc = UA(T-Tc).
