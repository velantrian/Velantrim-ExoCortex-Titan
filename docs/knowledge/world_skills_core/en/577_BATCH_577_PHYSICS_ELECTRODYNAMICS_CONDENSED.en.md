| physics.electrodynamics.maxwell_differential | Maxwell's Equations — Differential Form | INVARIANT | ∇·D = ρ свободная, ∇·B = 0, ∇×E = −∂B/∂t (Фарадей), ∇×H = J + ∂D/∂t (Ампер-Максвелл). D=ε₀E+P, H=B/μ₀−M. Граничные условия: D⊥, E∥, B⊥, H∥. | Наиболее общая форма, применимая в материальных средах. Ток смещения Максвелла (∂D/∂t) замыкает контур и предсказывает ЭМВ. |
| physics.electrodynamics.scalar_vector_potential | Scalar & Vector Potential | INVARIANT | B = ∇×A (по определению, гарантирует ∇·B=0). E = −∇φ − ∂A/∂t. Калибровочная свобода: A' = A + ∇χ, φ' = φ − ∂χ/∂t — физические поля E и B не меняются. | Кулоновская калибровка (∇·A=0) и калибровка Лоренца (∇·A + (1/c²)∂φ/∂t=0) удобны для разных задач. Эффект Ааронова-Бома: потенциалы физически реальны. |
| physics.electrodynamics.poynting_vector | Poynting Theorem — Energy Flow | INVARIANT | Вектор Пойнтинга S = E×H [Вт/м²] — плотность потока электромагнитной энергии. ∂u/∂t + ∇·S = −J·E, где u = ½(ε₀E² + B²/μ₀). | Энергия ЭМВ передаётся через пространство вектором S. Солнечная постоянная 1361 Вт/м² = S на орбите Земли. |
| physics.electrodynamics.wave_equation_em | Deriving EM Wave Equation | PROCESS | Из curl(∇×E) = −∂(∇×B)/∂t, подстановка ∇×B = μ₀ε₀∂E/∂t → ∇²E = (1/c²)∂²E/∂t². c = 1/√(μ₀ε₀) ≈ 3×10⁸ м/с — электрослабое предсказание. | Решение: E = E₀ e^(i(k·r−ωt)), поперечная волна k·E = 0. Импеданс вакуума Z₀ = √(μ₀/ε₀) ≈ 377 Ω. |
| physics.electrodynamics.waveguide | Rectangular Waveguide — TE/TM Modes | METHOD | Металлическая труба направляет ЭМВ. Граничные условия E∥=0. Режимы: TE_mn (H_z≠0, E_z=0), TM_mn (E_z≠0). Частота отсечки f_c: ниже — экспоненциальное затухание, выше — распространение. | Преобладающая мода в стандартном волноводе WR-90 (X-band 8-12 ГГц): TE₁₀, a=22.86 мм. Оптоволокно — диэлектрический волновод. |
| physics.electrodynamics.antenna_dipole | Half-Wave Dipole Antenna | METHOD | Длина L=λ/2. Распределение тока синусоидальное. Диаграмма направленности: «бублик» (ноль вдоль оси). Сопротивление излучения ~73 Ω. Усиление 2.15 dBi. | Базовый элемент большинства антенн. Yagi-Uda (диполь + рефлектор + директоры). Phased array: электронное сканирование луча (радары, 5G). |
| physics.electrodynamics.skin_effect | Skin Effect | PROCESS | Высокочастотный ток течёт в тонком поверхностном слое проводника. Глубина скин-слоя: δ = √(2ρ/(ωμ₀)). На 50 Гц для Cu δ≈9 мм, на 1 МГц δ≈65 мкм. | Многожильные провода Литцендрата (Litz — изолированные жилы переплетены) для высокочастотных катушек. Трубчатые проводники (экономия материала). |
| physics.condensed_matter.drude_model | Drude Model — Free Electron Gas | MODEL | Классическая модель: электроны как идеальный газ, рассеиваются на ионах со средним временем τ. Проводимость σ = ne²τ/m, подвижность μ = eτ/m. Закон Ома j = σE. | Объясняет DC-проводимость. НЕ объясняет: независимость σ от T (в чистых металлах), знак константы Холла (и дырки!), теплоёмкость электронов (100× ниже классического предсказания). |
| physics.condensed_matter.sommerfeld | Sommerfeld Model — Fermi Gas | MODEL | Электроны как квантовый ферми-газ (принцип Паули). Fermi energy E_F = ħ²(3π²n)^(2/3)/(2mе) ~ 2-10 эВ. Температура Ферми T_F = E_F/k ≈ 10⁴-10⁵ K. При комнатной T лишь малая доля электронов (~T/T_F) возбуждается. | Решает проблему теплоёмкости (C_V ∝ T, не константа). Fermi surface, Fermi velocity v_F ~ 10⁶ м/с. |
| physics.condensed_matter.band_theory | Band Theory — Bloch Theorem | INVARIANT | Электрон в периодическом потенциале: ψ_к(r) = u_k(r)·e^(ik·r) (Bloch wave). Разрешённые и запрещённые зоны (band gap). Металлы: зона частично заполнена E_F внутри зоны. Полупроводники/изоляторы: E_F в запрещённой зоне (gap). | Brillouin zone, reduced zone scheme. Effective mass m* = ħ²/(∂²E/∂k²). Дырки — вакантные состояния у верха валентной зоны — ведут себя как положительно заряженные частицы. |
| physics.condensed_matter.doping | Semiconductor Doping | PROCESS | Si (4 валентных). P (5e⁻): донор → лишний e⁻ → n-тип. B (3e⁻): акцептор → дырка → p-тип. Донорная энергия чуть ниже зоны проводимости (~0.045 эВ для P в Si), легко ионизуется при комнатной T. | Легирование ~1 ppm (10¹⁵-10²⁰ см⁻³) меняет проводимость на 6+ порядков. p-n переход: диффузия → обеднённый слой → встроенное поле → диод. |
| physics.condensed_matter.pn_junction | p-n Junction & Diode | INVARIANT | Обеднённый слой (depletion region): нет подвижных носителей, ионизованные примеси создают встроенное поле. I = I₀(e^(eV/kT)−1) — уравнение Шокли. Прямое смещение: барьер снижен → экспоненциальный ток. Обратное: пробой (Зенера — туннелирование, лавинный — ударная ионизация). | Светодиод (LED): рекомбинация e⁻ + h⁺ → фотон. Солнечная ячейка: фотон → e⁻-h⁺ → разделение полем → фототок. |
| physics.condensed_matter.bjt_vs_fet | BJT vs FET — Operation Principle | VARIANT | BJT: управление током (I_C = β·I_B), биполярный (e⁻ и h⁺), быстродействие, аналоговые схемы, low-noise. MOSFET: управление напряжением (поле, V_GS > V_th → канал), униполярный, низкое энергопотребление в статике (вход почти бесконечное сопротивление). | КМОП (CMOS): комплементарная пара n-MOS + p-MOS → только при переключении течёт ток (динамическая мощность P = CV²f). Основа цифровой логики. |
| physics.condensed_matter.superconductivity_bcs | BCS Theory — Cooper Pairs | INVARIANT | Электроны образуют пары (Куперовские) через обмен фононами (притяжение, перевешивающее кулоновское отталкивание). Ниже T_c: конденсация в единое квантовое состояние → сверхпроводимость (R=0). Энергетическая щель 2Δ (разрушение пары = минимальная энергия). | Изотопический эффект: T_c ∝ M^(−1/2) (доказательство роли фононов). Магнитное поле вытесняется (эффект Мейсснера — идеальный диамагнетизм). |
| physics.condensed_matter.meissner_effect | Meissner Effect & Flux Quantization | PROCESS | Сверхпроводник выталкивает магнитное поле из объёма при переходе в сверхпроводящее состояние (B=0 внутри). Отличие от идеального проводника. Квант магнитного потока Φ₀ = h/(2e) — заряд 2e доказывает Куперовские пары! | Левитация сверхпроводника над магнитом. SQUID (SQUID магнитометр) — измерение магнитного поля с точностью до кванта потока (~10⁻¹⁵ Тл), магнитоэнцефалография. |
| physics.condensed_matter.type_i_ii | Type I vs Type II Superconductors | VARIANT | Тип I: большинство чистых металлов (Pb, Hg, Al), низкая T_c, полный эффект Мейсснера до H_c (термодинамическое критическое поле, <0.2 Тл). Тип II: сплавы (NbTi, Nb₃Sn), керамики (YBCO), два критических поля: H_c1 (начало проникновения) и H_c2 (полное разрушение >10 Тл). Вихри Абрикосова. | NbTi: МРТ магниты (9.4 Т), LHC магниты (8.3 Т). YBCO: HTS, охлаждение жидким N₂ (77 K — дешевле He). |
| physics.condensed_matter.quantum_hall | Quantum Hall Effect | PROCESS | Двумерный электронный газ (2DEG) в сильном магнитном поле при низких T: холловское сопротивление квантуется σ_xy = ν·e²/h. Плато с точностью 10⁻⁹. Целочисленный QHE (von Klitzing, 1980, Нобелевская премия 1985). Дробный QHE (Tsui, Störmer, Laughlin, 1982, Нобелевская премия 1998): ν = 1/3, 2/5... | Дробный QHE: композитные фермионы, топологический порядок, энионы (anyons) — fractional statistics! Квантовый эталон сопротивления h/e². |
| physics.condensed_matter.topological_insulator | Topological Insulators | INVARIANT | Объём — изолятор (gap), поверхность — проводник (бесщелевые краевые состояния, топологически защищённые — не разрушаются при дефектах/примесях, если сохраняется time-reversal symmetry). Z₂ топологический инвариант. | Спиновый ток без диссипации (спинтроника). Майорановские фермионы в сверхпроводящих топологических системах → топологические квантовые вычисления. |
