# BATCH 503: Physics — Thermodynamics (Laws, Temperature & Heat)

**KnowledgeUnits:** 52  
**Namespace:** `physics.thermodynamics.*`  
**Scope:** zeroth_law, first_law, second_law, third_law, temperature, heat_capacity, internal_energy, enthalpy, entropy, heat_transfer.

| ID | KnowledgeUnit | Тип | Суть | Практический смысл |
|---|---|---|---|---|
| physics.thermodynamics.zeroth_law | Zeroth Law | INVARIANT | Если два тела находятся в тепловом равновесии с третьим, то они в равновесии друг с другом. Обосновывает понятие температуры. | Основа термометрии: термометр должен находиться в тепловом равновесии с измеряемой средой. |
| physics.thermodynamics.temperature | Temperature | INVARIANT | Температура — мера средней кинетической энергии молекул: Eср = (3/2)kT. Абсолютный ноль 0 K = −273.15°C недостижим. | Термометры, технологические процессы (плавка, закалка, пастеризация), климат-контроль. |
| physics.thermodynamics.temperature_scales | Temperature Scales | VARIANT | Шкалы: Цельсий (°C), Кельвин (K, T = t°C + 273.15), Фаренгейт (°F, t°F = 1.8t°C + 32). K — термодинамическая. | Международные стандарты: наука — Кельвин, быт — Цельсий, США — Фаренгейт. |
| physics.thermodynamics.thermal_equilibrium | Thermal Equilibrium | INVARIANT | Состояние, при котором макроскопические параметры системы постоянны и нет потоков энергии. Выравнивание температур при контакте. | Расчёт времени остывания, калибровка термометров, теплообменники, термостатирование. |
| physics.thermodynamics.heat | Heat | INVARIANT | Теплота Q — энергия, передаваемая вследствие разности температур (не путать с внутренней энергией). [Дж]. Не является свойством системы — это процесс. | Расчёт нагревателей, холодильников, теплопотерь зданий, теплообменников, калориметрия. |
| physics.thermodynamics.internal_energy | Internal Energy | INVARIANT | Внутренняя энергия U — сумма кинетической и потенциальной энергии всех частиц системы. Функция состояния. Для идеального газа U = (i/2)nRT. | Определение энергоёмкости топлива, КПД двигателей, расчёт тепловых процессов в химии. |
| physics.thermodynamics.first_law | First Law of Thermodynamics | INVARIANT | ΔU = Q − A (или Q = ΔU + A). Изменение внутренней энергии = подведённое тепло минус совершённая работа. Закон сохранения энергии. | Расчёт тепловых машин, холодильников, энергобаланс любых термодинамических систем. |
| physics.thermodynamics.work_in_thermo | Thermodynamic Work | VARIANT | Работа газа при изменении объёма: A = ∫p dV. Для изобарного процесса: A = pΔV. Работа положительна при расширении. | Цилиндры двигателей, компрессоры, пневматика, расчёт выходной мощности тепловых машин. |
| physics.thermodynamics.heat_capacity | Heat Capacity | VARIANT | Теплоёмкость C = dQ/dT [Дж/К]. Удельная c [Дж/(кг·К)], молярная Cм [Дж/(моль·К)]. Зависит от процесса: Cp ≠ Cv. | Выбор материала для теплоаккумуляторов, расчёт нагрева/охлаждения, теплоносители. |
| physics.thermodynamics.molar_heat_capacity | Molar Heat Capacities | VARIANT | Cv = (i/2)R — при постоянном объёме. Cp = Cv + R (соотношение Майера). Показатель адиабаты γ = Cp/Cv. Для одноатомного газа γ = 5/3. | Расчёт адиабатических процессов, скорости звука в газах, проектирование двигателей. |
| physics.thermodynamics.ideal_gas_law | Ideal Gas Law | INVARIANT | Уравнение Менделеева-Клапейрона: pV = nRT = (m/M)RT. R = 8.314 Дж/(моль·К). Объединяет законы Бойля-Мариотта, Гей-Люссака, Шарля. | Расчёт баллонов, шин, пневмосистем, дыхательных аппаратов, аэростатов, химических реакторов. |
| physics.thermodynamics.real_gas | Real Gas Equation | VARIANT | Уравнение Ван-дер-Ваальса: (p + a·n²/V²)(V − nb) = nRT. Параметры a (притяжение) и b (объём молекул). | Расчёт сжижения газов, поведения при высоких давлениях, глубинная добыча газа. |
| physics.thermodynamics.isothermal_process | Isothermal Process | PROCESS | Изотермический процесс: T = const, pV = const. ΔU = 0, Q = A. Медленный процесс с хорошим теплообменом. | Изотермическое сжатие/расширение в компрессорах, медленное накачивание шины. |
| physics.thermodynamics.isobaric_process | Isobaric Process | PROCESS | Изобарный процесс: p = const, V/T = const. A = pΔV. Q = ΔU + pΔV = ΔH (изменение энтальпии). | Нагревание в открытой посуде, расширение газа в цилиндре с постоянной нагрузкой. |
| physics.thermodynamics.isochoric_process | Isochoric Process | PROCESS | Изохорный процесс: V = const, p/T = const. A = 0, Q = ΔU. Нагревание/охлаждение в замкнутом жёстком объёме. | Взрыв в закрытом сосуде, скороварка, автоклав, нагрев баллона на солнце. |
| physics.thermodynamics.adiabatic_process | Adiabatic Process | PROCESS | Адиабатный процесс: Q = 0, быстрый без теплообмена. pV^γ = const, TV^(γ−1) = const. | Сжатие в дизеле (воспламенение от сжатия), расширение в турбине, звуковые волны. |
| physics.thermodynamics.enthalpy | Enthalpy | INVARIANT | Энтальпия H = U + pV. Функция состояния, удобна для изобарных процессов: ΔH = Qₚ. | Расчёт тепловых эффектов реакции, паровых котлов, кондиционирования, теплота сгорания. |
| physics.thermodynamics.second_law | Second Law of Thermodynamics | INVARIANT | Энтропия изолированной системы не убывает: ΔS ≥ 0. Теплота не может самопроизвольно переходить от холодного тела к горячему. | Определяет направление процессов, невозможность вечного двигателя 2-го рода, эффективность машин. |
| physics.thermodynamics.entropy | Entropy | INVARIANT | Энтропия S [Дж/К] — мера неупорядоченности системы. ΔS = ∫dQ/T (обр.). Статистически: S = k·ln(W). | Предсказание направления реакций, анализ необратимости, тепловая смерть Вселенной. |
| physics.thermodynamics.third_law | Third Law of Thermodynamics | INVARIANT | Энтропия идеального кристалла при абсолютном нуле равна нулю. Абсолютный ноль недостижим за конечное число шагов. | Криогеника, сверхпроводимость, калибровка энтропийных шкал, стандартные энтропии веществ. |
| physics.thermodynamics.heat_engine | Heat Engine | PROCESS | Тепловой двигатель преобразует теплоту в работу: КПД η = A/Q₁ = 1 − Q₂/Q₁. Требует нагревателя и холодильника. | ДВС, паровые и газовые турбины, реактивные двигатели, Стирлинг. Все работают между двумя T. |
| physics.thermodynamics.carnot_cycle | Carnot Cycle | MODEL | Идеальный цикл Карно — максимальный КПД между T₁ и T₂: η = 1 − T₂/T₁. Состоит из двух изотерм и двух адиабат. | Верхний предел эффективности любой тепловой машины. Эталон для сравнения реальных циклов. |
| physics.thermodynamics.carnot_theorem | Carnot's Theorem | INVARIANT | КПД любой тепловой машины не может превышать КПД цикла Карно при тех же температурах нагревателя и холодильника. | При T₁=500°C и T₂=30°C: ηмакс = 1−303/773 = 60.8%. Реальные ДВС — 25-40%. |
| physics.thermodynamics.otto_cycle | Otto Cycle | MODEL | Цикл Отто (бензиновый ДВС): адиабата сжатия → изохора сгорания → адиабата расширения → изохора выпуска. η = 1 − 1/r^(γ−1). | Бензиновые двигатели: r ~10 даёт КПД ~60% (теор), реально 25-30%. Повышение r увеличивает КПД. |
| physics.thermodynamics.diesel_cycle | Diesel Cycle | MODEL | Цикл Дизеля: адиабата сжатия → изобара сгорания → адиабата расширения → изохора выпуска. Степень сжатия выше (~20). | Дизели: КПД 35-45%, эффективнее бензиновых за счёт высокого сжатия (нет детонации). |
| physics.thermodynamics.brayton_cycle | Brayton Cycle | MODEL | Цикл Брайтона (ГТУ): адиабата сжатия в компрессоре → изобара подвода тепла → адиабата расширения в турбине → изобара охлаждения. | Газотурбинные установки, реактивные двигатели, энергетика. |
| physics.thermodynamics.rankine_cycle | Rankine Cycle | MODEL | Цикл Ренкина (паротурбинная установка, ПТУ): насос → котёл (изобара) → турбина (адиабата) → конденсатор (изобара). С фазовым переходом жидкость-пар. | ТЭС, АЭС — 80% мировой электроэнергии. КПД ~35-42%. |
| physics.thermodynamics.heat_pump | Heat Pump | PROCESS | Тепловой насос переносит тепло от холодного источника к горячему (обратный цикл): COPнагрев = Q₁/A > 1. | Отопление, кондиционеры, холодильники. COP 3-5: на 1 кВт электричества — 3-5 кВт тепла. |
| physics.thermodynamics.cop | Coefficient of Performance | VARIANT | Холодильный коэффициент: COPхол = Q₂/A. Отопительный: COPнаг = Q₁/A = 1 + COPхол. | Выбор климатической техники: чем выше COP — тем экономичнее. |
| physics.thermodynamics.conduction | Heat Conduction | PROCESS | Теплопроводность: закон Фурье q = −λ·dT/dx [Вт/м²], λ [Вт/(м·К)]. Стационарная: Q = λA·ΔT·t/d. | Теплоизоляция, радиаторы, тепловые трубки, расчёт теплопотерь через стены и окна. |
| physics.thermodynamics.thermal_conductivity | Thermal Conductivity | VARIANT | Коэффициент теплопроводности λ: медь ~400, сталь ~50, вода ~0.6, воздух ~0.026, пенопласт ~0.03 Вт/(м·К). | Выбор теплоизоляции (λ мин), радиаторов (λ макс), одежды, строительных материалов. |
| physics.thermodynamics.convection | Convection | PROCESS | Конвекция — теплоперенос движущейся жидкостью или газом. Q = αA·ΔT, α — коэффициент теплоотдачи. Свободная и вынужденная. | Отопление помещений, охлаждение электроники (вентиляторы), атмосферная циркуляция, океанские течения. |
| physics.thermodynamics.nusselt_number | Nusselt Number | VARIANT | Число Нуссельта Nu = αL/λ — безразмерный коэффициент теплоотдачи. Nu > 1 означает, что конвекция усиливает теплоперенос. | Расчёт теплообменников, радиаторов, эффективности охлаждения. |
| physics.thermodynamics.radiation | Thermal Radiation | PROCESS | Излучение — теплоперенос электромагнитными волнами, не требует среды. Закон Стефана-Больцмана: P = εσT⁴A. σ = 5.67×10⁻⁸. | Солнечные панели, инфракрасные обогреватели, тепловизоры, охлаждение в космосе (только излучением). |
| physics.thermodynamics.stefan_boltzmann_law | Stefan-Boltzmann Law | INVARIANT | Мощность излучения абсолютно чёрного тела: P = σT⁴A. Реальные тела: P = εσT⁴A, где ε < 1. | Расчёт теплового баланса Земли, температуры звёзд, радиационного охлаждения. |
| physics.thermodynamics.wiens_displacement | Wien's Displacement Law | INVARIANT | Длина волны максимума излучения: λмакс = b/T, b = 2.9×10⁻³ м·К. Чем горячее тело, тем короче волна. | Цвет звёзд, лампы накаливания, пирометрия (измерение T по излучению), инфракрасная астрономия. |
| physics.thermodynamics.black_body | Black Body | MODEL | Абсолютно чёрное тело поглощает всё падающее излучение (ε=1). Модель для законов теплового излучения. | Калибровка пирометров, эталон излучения, модель для расчёта звёздной фотосферы. |
| physics.thermodynamics.greenhouse_effect | Greenhouse Effect | PROCESS | Парниковый эффект: атмосфера прозрачна для видимого света Солнца, но задерживает инфракрасное излучение Земли (CO₂, H₂O, CH₄). | Без парникового эффекта T Земли была бы −18°C (сейчас +15°C). | physics.thermodynamics.latent_heat | Latent Heat | VARIANT | Скрытая теплота фазового перехода: плавления Lпл, парообразования Lпар [Дж/кг]. Поглощается без изменения температуры. | Таяние льда (334 кДж/кг), кипение воды (2260 кДж/кг). Аккумуляторы холода, паровые котлы. |
| physics.thermodynamics.phase_transition | Phase Transition | PROCESS | Фазовый переход 1-го рода со скачком энтропии и объёма: тв-жидк, жидк-газ. 2-го рода без скрытой теплоты (сверхпроводимость). | Плавление, испарение, конденсация, сублимация. Диаграмма состояний вещества. |
| physics.thermodynamics.triple_point | Triple Point | INVARIANT | Тройная точка — состояние, где сосуществуют три фазы. Для воды: Tтр = 273.16 K (0.01°C), pтр = 611.73 Па. | Эталон температуры: определение Кельвина исторически через тройную точку воды. |
| physics.thermodynamics.critical_point | Critical Point | INVARIANT | Критическая точка: исчезает различие жидкость-газ. Для воды Tкр = 647 K, pкр = 22.1 МПа. Выше — сверхкритический флюид. | Сверхкритическая экстракция (кофе без кофеина), сверхкритические котлы ТЭС. |
