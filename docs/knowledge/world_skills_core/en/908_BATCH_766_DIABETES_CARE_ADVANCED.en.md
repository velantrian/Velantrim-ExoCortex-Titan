| diabcare.ops.insulin_pump_basal_bolus | Insulin Pump — Basal/Bolus | METHOD | Инсулиновая помпа (CSII): непрерывная подкожная инфузия. Базальная скорость: подбирается по 3 тестам голодания. Болюс: пищевой (по C:I ratio — карбогидратный коэффициент) + коррекционный (по ISF — фактору чувствительности к инсулину). C:I ratio: г углеводов на 1 ед. инсулина. ISF: снижение ГК (мг/дл) на 1 ед. инсулина. | C:I ratio = 1:500 / TDD. ISF (мг/дл) = 1700 / TDD (RR Правило 1800). |
| diabcare.ops.cgm_calibration_alarms | CGM — Alarms & Calibration | METHOD | Непрерывный мониторинг глюкозы (CGM): Dexcom G7, FreeStyle Libre 3, Medtronic Guardian. Алармы: низкая (≤70 мг/дл + rate of change), высокая, urgent low. MARD: ±10% = клинически точный. Calibration free (G7, Libre): заводская калибровка. Compression lows: давление на сенсор → ложное снижение. Time in Range (TIR): целевой >70% (70-180 мг/дл). | TIR 70%: примерно соответствует HbA1c ≈7.0%. |
| diabcare.ops.closed_loop_ahcl | Closed Loop — Advanced Hybrid | METHOD | Замкнутая петля (Closed Loop / AID): CGM → алгоритм → инсулиновая помпа → автоматическая регулировка базала + болюсы. AHCL (Advanced Hybrid Closed Loop): Medtronic 780G, Omnipod 5, Control-IQ. Алгоритм: модель прогнозирования → минимизация гипо+гипергликемии. User action: только пищевые болюсы (не базал). TIR: 70%+ (без пользователя). | AHCL снижает бремя управления диабетом + улучшает TIR/HbA1c в исследованиях. |
| diabcare.ops.hypoglycemia_unawareness | Hypoglycemia Unawareness | METHOD | Потеря ощущения гипогликемии (HAAF): Hypoglycemia-Associated Autonomic Failure. При частой гипо: притупление симптомов (adrenergic). Порог для CGM alert: 70 мг/дл (или 80 при HAAF). Лечение HAAF: строгое предотвращение гипогликемий × 2-3 нед → восстановление осознания. Blood Glucose Awareness Training (BGAT). | Опасность вождения при HAAF: нарушение когниции без ощущения гипо. |
| diabcare.ops.sick_day_rules | Sick Day Rules — DKA Prevention | METHOD | Правила болезни при СД: Insulin must not be stopped (Type 1 + Type 2 insulintreated). Monitoring: ГК + кетоны каждые 2 ч. Дополнительный инсулин при гипергликемии: 10-20% суточной дозы (коррекционный). Жидкости: 250 мл/час при рвоте. Обратиться к врачу: рвота + не удерживает жидкость, кетоны ++, ГК >14 ммоль/л при кетонах. | Стероиды: временно увеличивают ГК → кратковременное увеличение инсулина. |
| diabcare.ops.foot_care_diabetic | Diabetic Foot Care — Inspection | METHOD | Уход за стопами при диабете: ежедневный осмотр (зеркало для подошвы). Клиника: нейропатия (жжение, онемение) + сосудистые нарушения (перемежающаяся хромота, плохое заживление). ABI (Ankle Brachial Index): <0.9 = ПАБ. Проверка у врача: 10г монофиламент + вибрация. Лечение язв: debridement, разгрузка (offloading), влажная среда. | Чарко-суставе: нейроартропатия при сниженной чувствительности. |
| diabcare.ops.gestational_diabetes | Gestational Diabetes — Diagnosis | METHOD | Гестационный диабет (ГСД): скрининг 24-28 нед. Однощаговый тест (IADPSG): OGTT 75г; ГГ ≥5.1, 1ч ≥10.0, 2ч ≥8.5 ммоль/л. Двущаговый (USA ACOG): 50 г нагрузка → если ≥7.8 ммоль/л → 100г 3-часовой тест. Целевые ГК: натощак <5.3, через 1ч <7.8, через 2ч <6.7. Инсулин при неэффективности диеты. | ГСД: риск макросомии, дистоции плеч, будущего T2DM у матери и ребёнка. |
| diabcare.ops.bariatric_diabetes | Bariatric Surgery — Diabetes Remission | METHOD | Бариатрическая хирургия и диабет T2: Roux-en-Y gastric bypass (RYGB): ремиссия T2DM 40-80%. Sleeve gastrectomy: 35-60%. Метаболические механизмы: изменение инкретинов (GLP-1 ↑), снижение веса, изменение микробиоты. DiRECT trial (2019): низкокалорийная диета = ремиссия у 50% без хирургии. | Microvascular complications: необходимость мониторинга после барьерной хирургии. |
| diabcare.ops.type1_management_ratios | T1DM — Insulin Ratios | METHOD | Управление T1DM инсулиновыми соотношениями: TDD (Total Daily Dose) = (0.5 × весккг) как начальный расчёт. 50% базальный, 50% болюсный. C:I ratio = 450 / TDD (g carbs per unit). ISF (Correction Factor) = 1700 / TDD (мг/дл) или 94 / TDD (ммоль/л). Glucagon kit: для тяжёлых гипо (родственники). Ketone testing: при ГК >14 ммоль/л. | Honeymoon period: остаточная β-cell function → нестабильная потребность в инсулине. |
| diabcare.ops.dka_hhs_management | DKA vs HHS — Differential | METHOD | ДКА: Диабетический кетоацидоз. ГК умеренное (14-33 ммоль/л). Кетоны +++. pH <7.3 (ацидоз). Преимущественно T1DM. Лечение: жидкости IV (NS 1 л/час), инсулин инфузия, KCl. ГГС (Гиперосмолярный гипергликемический синдром): ГК >33 ммоль/л, нет/малые кетоны, pH ≥7.3. Дегидратация выраженная. T2DM/пожилые. | Гипокалиемия в ДКА: инсулин гонит K+ в клетки → восполнить K до инсулина (K <3.5). |
| diabcare.ops.diabetes_technology_comparison | Diabetes Technology — CGM vs Flash | METHOD | Технологии мониторинга: CGM (настоящий): Dexcom G7/G6, Medtronic Guardian → непрерывные данные + алармы. Flash monitoring (FreeStyle Libre): сканирование для чтения (нет автоматических алармов на Libre 2 — опциональные). rtCGM vs isCGM: real-time vs intermittently scanned. wearable sensors. Professional CGM: маскированный 14-дней для диагностики. | Libre 3 → AutoApply →rtCGM с постоянным передачей (алармы встроены). |
| diabcare.ops.glycemic_index | Glycemic Index — Practical Application | METHOD | Гликемический индекс (ГИ): скорость подъёма ГК после приёма пищи относительно глюкозы (ГИ=100). Низкий ГИ (<55): медленное переваривание. Высокий (>70): быстрый. ГН (гликемическая нагрузка): ГИ × г углеводов / 100 = реальная нагрузка порции. Fibre: снижает ГИ. Glycemic variability: CV% <36% (от CGM) = стабильный контроль. | ГИ vs ГН: арбуз высокий ГИ но низкий ГН (мало углеводов в порции). |
| diabcare.ops.continuous_glucose_ambulatory | AGP — Ambulatory Glucose Profile | METHOD | Амбулаторный профиль глюкозы (AGP): стандартизированный отчёт из CGM (2 нед данных). Показатели: TIR (Time in Range 70-180 мг/дл), TAR (time above range >180), TBR (time below range <70 и <54). GMI (Glucose Management Indicator): оценочный HbA1c из CGM. CV% (coefficient of variation): измерение вариабельности. | AGP = стандарт отчётности для CGM (ATTD Consensus 2017). |
| diabcare.ops.diabetic_retinopathy_screening | Retinopathy Screening — Diabetic | METHOD | Диабетическая ретинопатия: T1DM: офтальмология через 5 лет после диагноза. T2DM: с момента диагноза. Ежегодно: при нет ретинопатии. При NPDR: каждые 6 мес. PDR + CSME: лечение (лазер / анти-VEGF). Telephotoretinoscopy: скрининговый инструмент. | Потеря зрения при ДР: предотвратима при раннем лечении в >90%. |
| diabcare.ops.diabetic_kidney_disease | Diabetic Kidney Disease — Monitoring | METHOD | Диабетическая нефропатия: скрининг: uACR (соотношение альбумин-креатинин мочи) ≥ежегодно + eGFR. Стадии ХБП: по eGFR (G1-G5). Альбуминурия: A1 (<3 мг/г), A2 (3-300), A3 (>300). Замедление прогрессии: RAAS-ингибитор (ИАПФ/БРА) + SGLT2i (при eGFR ≥20 мл/мин). Контроль АД: <130/80 при нефропатии. | Finerenone (FINEARTS, FIGARO): RAAS + SGLT2i = дополнительная нефропротекция. |
| diabcare.ops.t2dm_lifestyle_intervention | T2DM — Lifestyle Intervention | METHOD | Программы изменения образа жизни при T2DM: Diabetes Prevention Program (DPP): 5-7% снижение веса + 150 мин физической активности/нед = снижение прогрессии предиабета в T2DM на 58%. Структурированные программы: Finnish DPS, NHS Diabetes Prevention Programme (UK). Mediterranean Diet: улучшение HbA1c, CVD risk. Low Carb diets: снижение ГК и инсулина быстро. | DiRECT: 12 мес на 820 ккал VLCD → 46% ремиссия T2DM. |

AADE7: 7 навыков самоведения (здоровое питание, физическая активность, самомониторинг, прием лекарств, снижение риска, устранение проблем, здоровые способы справления). Diabetes summer camps (T1DM): безопасная социализация. Peer support. | Diabetes distress: эмоциональная нагрузка управления диабетом (отличается от депрессии). |
