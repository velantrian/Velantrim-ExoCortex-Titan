# BATCH 509: Computer Science — Sorting & Searching Algorithms

| ID | KnowledgeUnit | Тип | Суть | Практический смысл |
|---|---|---|---|---|
| cs.algorithms.sorting.bubble_sort | Bubble Sort | METHOD | Попарное сравнение соседей, обмен при нарушении порядка. Сложность O(n²). На каждом проходе максимум «всплывает» в конец. | Простейший для понимания. Никогда не применяется в продакшене кроме как для почти отсортированных массивов (с оптимизацией остановки). |
| cs.algorithms.sorting.selection_sort | Selection Sort | METHOD | Находит минимальный элемент в неотсортированной части и меняет с первой позицией. O(n²) всегда. Минимальное число обменов (O(n)). | Применим когда обмены дороги (запись на флеш-память), а сравнения дёшевы. |
| cs.algorithms.sorting.insertion_sort | Insertion Sort | METHOD | Вставляет очередной элемент в отсортированную часть. O(n²) в худшем, O(n) в лучшем (уже отсортирован). Стабилен, in-place. | Лучший выбор для малых n (<50). TimSort (Python, Java) использует insertion sort для маленьких подмассивов. |
| cs.algorithms.sorting.merge_sort | Merge Sort | METHOD | Разделяй-и-властвуй: рекурсивно делим пополам, сортируем, сливаем за O(n). T(n)=2T(n/2)+O(n) → O(nlogn). Стабилен. | Гарантированный nlogn. Внешняя сортировка (файлы на диске). Основа MapReduce. |
| cs.algorithms.sorting.quick_sort | Quick Sort | METHOD | Выбираем опорный элемент (pivot), разделяем на <pivot и >pivot, рекурсивно сортируем части. Среднее O(nlogn), худшее O(n²). In-place. | Стандартная библиотека C (qsort), Java, Go (sort). Худший случай избегается рандомизированным pivot или median-of-three. |
| cs.algorithms.sorting.quick_sort_partition | Quick Sort: Lomuto vs Hoare | VARIANT | Разбиение Ломуто: pivot в конце, один указатель. Проще, но больше обменов. Хоара: два указателя с двух концов, меньше обменов. | Важно для понимания реализации. Хоара обычно эффективнее. |
| cs.algorithms.sorting.median_of_three | Median-of-Three Pivot | METHOD | Выбор pivot'а: медиана из первого, среднего и последнего элементов. Снижает вероятность худшего случая до экспоненциально малой. | Стандартная оптимизация QuickSort в большинстве библиотек. |
| cs.algorithms.sorting.three_way_quicksort | 3-Way QuickSort | METHOD | Разбиение на три части: меньше, равно и больше pivot'а (Dijkstra, 1976). O(n) для массивов с повторениями. | Сортировка строк с повторениями. Эффективен для данных с небольшим числом уникальных ключей. |
| cs.algorithms.sorting.heap_sort | Heap Sort | METHOD | Строим max-heap, затем n раз извлекаем максимум в конец. O(nlogn) всегда, O(1) доп. память, НЕ стабилен. | Гарантированный nlogn без рекурсии. Медленнее QuickSort на практике (плохая локальность кэша). |
| cs.algorithms.sorting.intro_sort | IntroSort | METHOD | Гибрид: QuickSort с переходом на HeapSort при глубине рекурсии > 2logn (защита от O(n²)), и на InsertionSort для малых n. | Стандартная сортировка C++ STL (std::sort). Лучшее из трёх миров. |
| cs.algorithms.sorting.timsort | TimSort | METHOD | Гибрид Merge + Insertion sort. Находит естественные упорядоченные подмассивы (runs), сливает их. Стабилен, адаптивен к частичной упорядоченности. | Python (sorted, list.sort), Java (Arrays.sort объектов), Android. Лучший для реальных данных. |
| cs.algorithms.sorting.counting_sort | Counting Sort | METHOD | Подсчитывает частоту каждого значения, затем вычисляет позиции. O(n+k) где k — диапазон значений. НЕ сравнение. Требует целочисленные ключи. | Сортировка оценок, возрастов, байтов. k ≤ n — эффективнее nlogn. |
| cs.algorithms.sorting.radix_sort | Radix Sort | METHOD | Сортировка по разрядам: от младшего к старшему (LSD) или наоборот (MSD). Использует стабильную сортировку (Counting) для каждого разряда. O(d·(n+k)). | Сортировка целых чисел, строк фиксированной длины. 64-битные числа: 8 проходов по байту. |
| cs.algorithms.sorting.bucket_sort | Bucket Sort | METHOD | Распределяет элементы по корзинам (buckets), сортирует каждую, собирает. O(n) в среднем при равномерном распределении. | Сортировка вещественных чисел [0,1) с равномерным распределением. |
| cs.algorithms.sorting.stability | Sort Stability | VARIANT | Стабильная сортировка сохраняет относительный порядок равных элементов. Merge, Insertion, Counting, Radix — стабильны. Quick, Heap — нет. | Сортировка по нескольким полям (сначала по имени, затем по возрасту). Второй проход не должен ломать первый. |
| cs.algorithms.sorting.in_place | In-Place Sort | VARIANT | In-place сортировка использует O(1) дополнительной памяти (кроме стека рекурсии). QuickSort, HeapSort. MergeSort — нет (O(n)). | Ограниченная память (встроенные системы, GPU). |
| cs.algorithms.sorting.lower_bound | Comparison Sort Lower Bound | INVARIANT | Нижняя граница сортировки сравнениями: Ω(n log n) в worst-case. Дерево решений имеет n! листьев → высота ≥ log₂(n!) ≈ n log n. | Доказательство оптимальности MergeSort и HeapSort. Сортировки без сравнений могут быть быстрее (O(n)). |
| cs.algorithms.searching.linear_search | Linear Search | METHOD | Последовательный перебор элементов до нахождения искомого. O(n) в худшем, O(1) в лучшем. | Простой поиск в неотсортированном массиве. |
| cs.algorithms.searching.binary_search | Binary Search | METHOD | Деление отсортированного массива пополам, сравнение со средним элементом. O(log n). Требует произвольного доступа. | Стандартный поиск в отсортированных данных. Arrays.binarySearch, bisect в Python. |
| cs.algorithms.searching.binary_search_correct | Binary Search Correctness | CONTROL | Корректная реализация: mid = left + (right-left)/2 (избегает переполнения left+right). Инвариант: искомый элемент в [left, right]. | Баг в реализации binary search в Java (2006) — переполнение int для больших массивов. 9 лет до обнаружения. |
| cs.algorithms.searching.interpolation_search | Interpolation Search | METHOD | Оценивает позицию искомого элемента по линейной интерполяции значений в границах. O(log log n) при равномерном распределении, O(n) в худшем. | Поиск в телефонном справочнике (фамилия «Зайцев» — ближе к концу). Неравномерные данные — деградация. |
| cs.algorithms.searching.exponential_search | Exponential Search | METHOD | Находит диапазон экспоненциальным расширением [1,2,4,8...] затем binary search. O(log n). Полезен при неизвестном размере или неограниченных массивах. | Поиск в потоковых данных, поиск первого true в бесконечном монотонном предикате. |
| cs.algorithms.searching.quickselect | QuickSelect | METHOD | Поиск k-й порядковой статистики за среднее O(n). Модификация QuickSort: рекурсия только в нужную часть. | Медиана за O(n). Процентили, квантили в аналитике. |
| cs.algorithms.searching.median_of_medians | Median of Medians | METHOD | Гарантированный линейный выбор (Blum-Floyd-Pratt-Rivest-Tarjan, 1973). Делим на группы по 5, находим медиану медиан как pivot. O(n) worst-case. | Теоретическая гарантия. Практически — константа велика, используют QuickSelect с рандомизацией. |
| cs.algorithms.searching.sentinel_search | Sentinel Search | METHOD | Добавление искомого элемента в конец массива (sentinel). Исключает проверку границы в цикле → меньше сравнений, быстрее. | Оптимизация linear search для низкоуровневых реализаций. |
| cs.algorithms.searching.ternary_search | Ternary Search | METHOD | Поиск максимума унимодальной функции делением на три части. Каждая итерация выбрасывает 1/3 отрезка. | Золотое сечение эффективнее (одно вычисление функции вместо двух). Применение: оптимизация выпуклых функций. |
| cs.algorithms.searching.jump_search | Jump Search | METHOD | Прыжки на √n с последующим линейным поиском в блоке. O(√n). Оптимален для однопроходного поиска в отсортированном массиве без произвольного доступа. | Поиск в связных списках, данных на магнитной ленте. |
| cs.algorithms.sorting.external_sort | External Sorting | METHOD | Сортировка данных, не помещающихся в память: фаза сортировки блоков в памяти → фаза многопутевого слияния. | Сортировка гигабайтных и терабайтных файлов. Базы данных, ETL, MapReduce. |
| cs.algorithms.sorting.k_way_merge | K-Way Merge | METHOD | Многопутевое слияние k отсортированных последовательностей с использованием кучи (min-heap). O(n log k). | External sort фаза 2, слияние логов, merge в MapReduce. |
