# BATCH 660: Fence — Installation & Gate Operations

**KnowledgeUnits:** 50
**Namespace:** `fence.ops.*`
**Scope:** post_setting, chain_link, wood, vinyl, gate, automatic_opener, layout, code

| ID | KnowledgeUnit | Тип | Суть | Практический смысл |
|---|---|---|---|---|
| fence.ops.post_hole_digging | Post Hole — Digging & Setting | METHOD | Копка ям под столбы. Глубина: 1/3-1/2 длины столба (ниже линии промерзания для холодных регионов). Диаметр: 3× диаметр столба. Digging: auger (ручной — post hole digger, бензобур). Concrete: fast-setting (dry pour — засыпать сухой бетон в яму, залить водой). Альтернатива: gravel (устанавливать post, утрамбовывая гравий слоями — drainage лучше, но менее прочно на изгиб). Выравнивание: level (spirit level) — вертикаль дважды под 90°. Струна (string line): для ровной линии забора. Spacing: 2.4-3 м для деревянного, 3-4 м для chain link. Corner posts: толще (диаметр больше, глубина глубже). | Не бетонировать в мороз (бетон не наберёт прочность). |
| fence.ops.chainlink_tension_band | Chain Link — Stretching & Tie | METHOD | Натяжка сетки-рабицы. Terminal posts (угловые, концевые, воротные): tension bands (полосы) закреплены. Топ rail (верхняя труба): вставлена в rail end cups. Сетка: размотать вдоль забора. Tension bar (натяжной прут): продеть через крайние ячейки сетки. Крепление tension bar к tension bands. Stretching: come-along (лебёдка) или stretch bar with pull — натянуть до deflection 3-5 см при нажатии. Tie wires (алюминиевые): каждая ячейка на top rail + каждая вторая на line posts. Подрезать излишки сетки (bolt cutters). Нижний зазор: 5 см от земли (трава). | Не перетянуть (вырвет post). |
| fence.ops.wood_privacy_board_on_board | Wood Privacy — Board-on-Board | METHOD | Деревянный забор (шахматная доска). Posts: 4×4" (10×10 см), treated. Rails (лаги): 2×4" (5×10 см), 3 ряда (top, middle, bottom). Pickets (штакетник): 1×6" (2.5×15 см). Board-on-board: pickets с обеих сторон перекрывают щели (полная privacy). Зазор между pickets: 5-10 мм (расширение). Крепление: нержавеющие screws или гальванизированные nails (не обычные — ржавчина). Верх: flat или cut на угол для water runoff. Sealer/stain: каждые 2-3 года. | Кедр (cedar) — лучшая древесина для забора (природная гнилостойкость). |
| fence.ops.gate_sag_prevention | Gate — Sag Prevention | METHOD | Предотвращение провисания ворот. Frame gate: diagonal brace от нижнего угла на стороне петель к верхнему углу на стороне ручки (сжатие). Cable & turnbuckle: от верхнего угла петель к нижнему углу ручки (натяжение). Регулируемый тёрнбакл позволяет подтянуть против sag. Hinges: heavy-duty (strap hinges длиннее для распределения веса). Latch: self-latching gravity latch. Drop rod: фиксация второй створки в землю. | Ворота весят много — слабый post наклонится. |
| fence.ops.automatic_gate_opener | Automatic Gate — Opener Install | METHOD | Установка электропривода ворот. Типы: sliding gate (откатные), swing gate (распашные). Оператор: electromechanical ram (linear actuator) или articulated arm. Power: 120/240V AC, 24V DC backup battery. Safety: photoelectric sensors (photo beam — stops/reverses gate), edge sensor (pressure strip), loop detector (индукционная петля). UL 325 compliant. Мануальный release: ключ для аварийного открытия. Solar: для удалённых gates (панель + deep cycle battery). | Без safety сенсоров: gate может зажать ребёнка/автомобиль. |
