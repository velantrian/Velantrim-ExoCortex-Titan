# BATCH 739: Forging — Blacksmith Operations

**KnowledgeUnits:** 10
**Namespace:** `blacksmith.ops.*`

| ID | KnowledgeUnit | Тип | Суть | Практический смысл |
|---|---|---|---|---|
| blacksmith.ops.forge_fire_management_coke | Forge Fire — Coke Fire Management | METHOD | Управление кузнечным горном на каменноугольном коксе для создания зоны максимального жара с контролируемой окислительной или восстановительной атмосферой вокруг нагреваемой заготовки. | Кокс увлажняется по периметру огня для формирования изолирующей корки направляющей жар в центр, а заготовка помещается на уровне чуть выше фурмы где температура достигает 1200-1400°C в окислительной зоне. |
| blacksmith.ops.anvil_rebound_hammer_test | Anvil — Rebound Test | METHOD | Определение качества наковальни по отскоку молотка при ударе для оценки твёрдости закалённой поверхности и эффективности передачи энергии удара на заготовку. | Молоток сбрасывается с высоты 25 см на поверхность наковальни без заготовки, и свободный отскок должен составлять 70-90% от высоты падения для качественной кованой наковальни с закалённой рабочей поверхностью. |
| blacksmith.ops.drawing_out_taper_technique | Drawing Out — Taper Forging | METHOD | Удлинение и утонение заготовки путём последовательных ударов молотом по нагретому металлу с поворотом заготовки на ребро наковальни для формирования конусного профиля. | Заготовка кладётся под углом к ребру наковальни и каждый удар смещает металл в продольном направлении уменьшая сечение с одновременным удлинением заготовки без образования складок на поверхности. |
| blacksmith.ops.upsetting_thickening_end | Upsetting — End Thickening | METHOD | Увеличение сечения конца заготовки путём осаживания нагретого металла ударами в продольном направлении для формирования утолщения под последующую обработку. | Нагретый до ярко-жёлтого каления конец заготовки упирается в поверхность наковальни и ударами молотка по противоположному торцу металл осаживается увеличиваясь в диаметре с образованием равномерного утолщения. |
| blacksmith.ops.quenching_oil_water_brine | Quenching — Medium Selection | METHOD | Выбор закалочной среды в зависимости от марки стали и требуемой скорости охлаждения для получения нужной твёрдости без образования трещин и чрезмерных деформаций детали. | Вода даёт самую быструю закалку для простых углеродистых сталей, масло обеспечивает среднюю скорость для легированных сталей с меньшим риском трещин, а соляной раствор ускоряет охлаждение по сравнению с чистой водой. |
| blacksmith.ops.temper_color_oxidation_guide | Tempering — Color Oxidation Guide | METHOD | Определение температуры отпуска закалённой стали по цветам побежалости оксидной плёнки на зачищенной поверхности нагреваемой детали для визуального контроля без пирометра. | Соломенный цвет при 220-240°C указывает на твёрдость подходящую для режущего инструмента, коричнево-пурпурный при 260-280°C для топоров и зубил, а синий цвет при 290-310°C для пружин и рессор. |
| blacksmith.ops.forge_welding_flux_borax | Forge Welding — Borax Flux | METHOD | Соединение двух нагретых стальных заготовок в монолитную деталь путём проковки в кузнечном горне с использованием буры в качестве флюса для растворения окалины. | Порошок буры посыпается на нагретые до сварочного жара поверхности, расплавляется растворяя окислы, после чего детали накладываются друг на друга и проковываются лёгкими частыми ударами выжимающими шлак и создающими металлургическое соединение. |
| blacksmith.ops.fullering_groove_cutting | Fullering — Groove Cutting | METHOD | Формирование канавки или шейки на заготовке с помощью подкладного инструмента-подбойки для разделения массы металла и создания переходов между сечениями поковки. | Подбойка помещается на нагретую заготовку в нужном месте, и удары молотка по подбойке вдавливают её в металл формируя углубление с одновременным смещением металла в стороны для последующей формовки. |
| blacksmith.ops.spiral_twist_decorative | Twist — Decorative Spiral | METHOD | Скручивание нагретого участка квадратного прутка вдоль продольной оси для создания декоративного спирального узора на перилах, воротах и художественных изделиях. | Нагретый докрасна участок заготовки зажимается в тиски, а свободный конец поворачивается разводным ключом на нужный угол, при этом равномерность нагрева определяет равномерность шага спирали. |
| blacksmith.ops.punching_drifting_hole | Punch & Drift — Hole Making | METHOD | Пробивка и расширение отверстия в горячей заготовке последовательным использованием пробойника и развёртки для получения точного круглого отверстия без сверления. | Пробойник вгоняется в нагретый металл почти насквозь оставляя тонкую перемычку, затем заготовка переворачивается и пробойник выбивает высечку, после чего развёртка расширяет отверстие до нужного диаметра. |
