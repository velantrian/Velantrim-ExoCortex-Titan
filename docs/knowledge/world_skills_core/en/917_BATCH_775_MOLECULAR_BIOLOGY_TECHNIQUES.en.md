|---|---|---|---|---|
| molbio.ops.restriction_cloning | Restriction Cloning — Methods | METHOD | Рестрикционное клонирование: рестриктаза разрезает ДНК по специфической последовательности → Insert + Vector с совместимыми концами → лигирование (T4 ДНК-лигаза). Несовместимые концы: тупые (blunt) vs липкие (sticky). Синяя/белая селекция (lacZ). Трансформация компетентными E. coli. Midiprep/Maxiprep: выделение плазмиды. | Gibson Assembly: более эффективная (нет ограничений одного рестриктора). |
| molbio.ops.crispr_cas9 | CRISPR-Cas9 — Mechanism | METHOD | CRISPR-Cas9: sgRNA (направляющая) → Cas9 нуклеаза → NGG PAM последовательность. DSB (double-strand break) → NHEJ (удаление/вставка, нокаут) или HDR (точная замена с матрицей). Delivery: плазмида, RNP (ribonucleoprotein), lentivirus, AAV. Off-target effects: HiSeq + GUIDE-seq. Prime editing: nick + RTase. | Base editing: замена одного нуклеотида без DSB (более точный). |
| molbio.ops.western_blot_protocol | Western Blot — Protocol | METHOD | Вестерн-блот: SDS-PAGE (белки разделяются по молекулярному весу) → Transfer (PVDF/NC membrane) → Blocking (BSA или молоко, 5%, 1 ч) → Primary antibody (4°C, overnight) → Secondary Ab (HRP-conjugated) → ECL (Enhanced Chemiluminescence). Membrane stripping: ТМБ wash → повторный зонд. | Total protein stain (Ponceau): до антитело = loading control. |
| molbio.ops.flow_cytometry_gating | Flow Cytometry — Gating | METHOD | Проточная цитометрия: FSC (размер) + SSC (гранулярность) → scatter plot. Gating стратегия: scatter → singlets (устранение дублетов) → live/dead exclusion → population of interest. Compensation: коррекция spectral overlap. Positive control + FMO (Fluorescence Minus One): определение gate borders. FACS: sorting by fluorescence signal. | Doublet exclusion: FSC-H vs FSC-A (высота vs площадь). |
| molbio.ops.pcr_touchdown | PCR — Touchdown PCR | METHOD | ПЦР вариации: Touchdown PCR: начало с высокой Ta → постепенное снижение → повышение специфичности. Nested PCR: два последовательных ПЦР (inner primers → повышение специфичности). Hot-Start PCR: антитела ингибируют полимеразу до нагрева (снижение неспецифических продуктов). Digital PCR (ddPCR): абсолютная количественная оценка (капли). | LAMP (Loop-Mediated Amplification): изотермальная → не нужен термоциклер. |
| molbio.ops.rna_seq_workflow | RNA-seq — Workflow | METHOD | RNA-seq: Total RNA extraction → rRNA depletion (Ribo-Zero) или PolyA selection → Library preparation (fragmentation + cDNA synthesis + ligation adapters) → NGS sequencing → QC (FastQC) → Alignment (STAR/HISAT2) → Quantification (featureCounts, DESeq2) → Differential Expression. | CPM, RPKM, FPKM, TPM: нормализация в RNA-seq. TPM = наиболее корректный для сравнения. |
| molbio.ops.cell_culture_aseptic | Cell Culture — Aseptic Technique | METHOD | Клеточная культура: асептика в BSC (Grade A). Медицинская среда с сывороткой (DMEM, RPMI + 10% FBS). Субкультивирование (passaging): трипсинизация при ~80% конфлюентности. Seeding density: зависит от типа клеток. Mycoplasma testing: PCR или ELISA ежемесячно. Криоконсервация: DMSO 10% в жидком азоте. | Mycoplasma: «невидимый загрязнитель» клеточных культур (50%+ contaminant). |
| molbio.ops.sanger_sequencing | DNA Sequencing — Sanger | METHOD | Секвенирование по Сэнгеру: PCR продукт + четыре dideoxy-NTP (chain terminators) + флуоресцентные dNTPs → fragments of different lengths → капиллярный электрофорез → чтение последовательности. Длина прочтения: 800-1000 нт. Применение: точечные мутации, клонов проверка. NGS: параллельное секвенирование миллиардов фрагментов. | Primer design: Tm 55-65°C, no hairpin/dimers (Primer3, IDT oligo analyser). |
| molbio.ops.protein_expression_e_coli | Protein Expression — E. coli | METHOD | Экспрессия белков в E. coli: pet vectors + BL21(DE3). IPTG индукция: 0.1-1 мМ. Temperature: 37°C (high expression, inclusion bodies) или 16-25°C (soluble). Inclusion bodies: рефолдинг (гуанидин-HCl → dialysis). His-tag + IMAC Ni-column: purification. SDS-PAGE анализ: expression check. | Solubility screening: trial inductions at different temps + IPTG conc. |
| molbio.ops.co_immunoprecipitation | Co-IP — Protein-Protein Interaction | METHOD | Ко-иммунопреципитация (Co-IP): лизат клеток + первичное антитело к белку A → инкубация с Protein A/G beads → отмывка → SDS-PAGE + Western Blot для обнаружения белка B. Контроль IgG: нет специфического белка. Crosslinking (crosslink-IP): для транзиентных взаимодействий. Proximity ligation (BioID): модификация биотином. | False positive Co-IP: высокая концентрация = hydrophobic interactions (clean beads важны). |
| molbio.ops.chromatin_chip | ChIP — Chromatin Immunoprecipitation | METHOD | Хроматин-иммунопреципитация (ChIP): клетки фиксируются формальдегидом (protein-DNA crosslinks) → ультразвуковая фрагментация хроматина → инкубация с антителом к гистонам/TF → декроссссылки → ПЦР (ChIP-PCR) или секвенирование (ChIP-seq). Input control: 10% лизата до IP. | ChIP-seq: genome-wide mapping of TF binding sites / histone modifications. |
| molbio.ops.gel_electrophoresis | Agarose Gel — DNA Analysis | METHOD | Гель-электрофорез ДНК: агаро 0.5-2% + TBE/TAE + EtBr или SYBR Safe. 1% = хорошо для 200-5000 bp. Буфер TAE: лучше для ДНК (TBE = RNA, крупные фрагменты). Маркер (ladder): 100 bp, 1 kb. Voltage 5-10 В/см (слишком высокое = размытость). UV transilluminator + gel documentation. | Страсть ДНК: отрицательно заряжена → движется к аноду (+). |
| molbio.ops.yeast_two_hybrid | Yeast Two-Hybrid — Y2H | METHOD | Дрожжевой двойной гибридный скрининг (Y2H): GAL4 DBD-Bait + GAL4 AD-Prey → если взаимодействуют → репортёр HIS3/β-gal. cDNA library screening: поиск партнёров. False positives: sticky proteins (high background). Validation required: Co-IP или BiFC. Split-TEV: альтернативный метод. | Y2H: высокая чувствительность, но много ложноположительных. |
| molbio.ops.confocal_microscopy | Confocal Microscopy — Principles | METHOD | Конфокальная микроскопия: лазерное возбуждение + pinholes для оптических срезов (z-stacks). Lateral resolution: ~200 нм (vs TIRF 100 нм, STORM 20 нм). Fluorescence: GFP (488 нм), RFP (561 нм), Far-red (647 нм). Fixed cells: paraformaldehyde fixation, permeabilization. Live imaging: CO2 + temperature controlled stage. | DAPI: ядра (UV). Phalloidin (F-actin). Mitotracker: митохондрии. |
| molbio.ops.electroporation | Cell Transfection — Methods | METHOD | Трансфекция: Lipofection (liposome): лёгкий, низкая токсичность, не для все клетки. Electroporation: высокая эффективность, высокая токсичность. Nucleofection (Lonza): адаптированная электропорация для трудных клеток. Viral transduction: lentivirus (stable), AAV (не интегрируется). Efficiency check: GFP reporter. | Primary cells (T cells, neurons): лучший результат с nucleofection или viral vectors. |
| molbio.ops.northern_blot | Northern Blot — RNA Detection | METHOD | Нозерн-блот: РНК-электрофорез (denatured agarose gel) → Transfer → Hybridization with probe (complementary to target RNA). Размер mRNA + expression level. Replaced largely by qRT-PCR (более чувствительный). Применение: isoform detection, RNA size. | qRT-PCR: более чувствительный + быстрый vs Northern. Northern: показывает размер + интактность. |
| molbio.ops.3d_organoid_culture | Organoids — 3D Cell Culture | METHOD | Органоиды: 3D культура самоорганизующихся клеток, имитирующих орган. Кишечник (Clevers lab): кишечные эпителиальные стволовые клетки + Matrigel + EGF + Noggin + R-spondin. Brain organoids: iPSCs → 3D. Применение: drug screening, personalized medicine, disease modelling. Patient-derived organoids (PDOs): от биопсии. | Matrigel: ламинин + EGF + другие = ECM матрикс для 3D культуры. |
| molbio.ops.proteomics_mass_spec | Proteomics — LC-MS/MS | METHOD | Протеомика: LC-MS/MS (жидкостная хроматография + тандем масс-спектрометрия). Протокол: лизат → SDS-PAGE or in-solution digest → trypsin digestion → LC (C18 column) → Electrospray ionization → MS/MS spectra → database search (Mascot, SEQUEST). Label-free vs TMT/iTRAQ (isobaric labeling). | Shotgun proteomics: идентификация тысяч белков в одном образце. |
| molbio.ops.chromosome_karyotyping | Cytogenetics — Karyotype | METHOD | Кариотипирование: колхицин → остановка митоза в метафазе → гипотоническое набухание → фиксация → G-banding (Гимза) → микроскопия + анализ. Нормальный кариотип: 46, XX или 46, XY. Anomalies: трисомия (47,+21 = Дауна), делеции, транслокации. Флуоресцентная in-situ гибридизация (FISH): для специфических локусов. | SKY (Spectral Karyotyping): разные цвета каждой хромосоме → сложные перестройки. |
