# BATCH 841: Geographic Information Systems — GIS & Remote Sensing

**KnowledgeUnits:** 50
**Namespace:** `gis.ops.*`
**Scope:** coordinate_systems, vector_raster, spatial_analysis, remote_sensing_platforms, lidar, digital_elevation, geodatabase, cartography, urban_GIS

| ID | KnowledgeUnit | Тип | Суть | Практический смысл |
|---|---|---|---|---|
| gis.ops.coordinate_systems | Coordinate Systems — WGS84 vs UTM | METHOD | Системы координат: Geographic (Geographic Coordinate System, GCS): широта/долгота (угловые). Datum: WGS84 (GPS стандарт), NAD83 (Северная Америка). Projected: линейные единицы (метры). UTM (Universal Transverse Mercator): 60 зон × 6°, EPSG:32610 и т.д. State Plane (USA): более точная для малых регионов. | EPSG коды: 4326 = WGS84, 4269 = NAD83. Всегда указывать систему координат. |
| gis.ops.vector_raster | Vector vs Raster — Data Models | METHOD | Векторные данные: точки, линии, полигоны. Шейпфайлы (.shp), GeoJSON, GeoPackage (.gpkg). Растровые: сетка пикселей. GeoTIFF, NetCDF, HDF5. Vector: точные границы. Raster: непрерывные поля (высоты, температура). Конверсия: Feature to Raster, Raster to Polygon. | Размер пикселя растра: определяет разрешение анализа. |
| gis.ops.spatial_operations | Spatial Analysis — Overlay | METHOD | Пространственный анализ: Intersect: общая область двух слоёв. Union: объединение. Clip: обрезать по маске. Buffer: зоны вокруг объектов. Spatial Join: атрибуты из близкого объекта. Suitability Analysis: weighted overlay. Network Analysis: маршрутизация, изохроны. | Proximity Analysis: Near, Point Distance, Thiessen Polygons. |
| gis.ops.dem_dtm | Digital Elevation Model — Analysis | METHOD | Цифровые модели рельефа (DEM/DTM): DEM: поверхность земли. DSM: верхняя поверхность (включая здания/деревья). DTM: только земная поверхность (без растительности). Уклон (Slope), экспозиция (Aspect), TPI, TRI. Flow direction, Flow accumulation. Watershed delineation. | LiDAR DEM: 1м разрешение (vs SRTM 30м). |
| gis.ops.lidar_point_cloud | LiDAR — Point Cloud Processing | METHOD | LiDAR облако точек: LAS/LAZ формат. Classifications: ground, low/med/high vegetation, building, noise. Наземное (terrestrial) vs воздушное (airborne). Intensity values. Normalized height above ground. Point density (pts/m²). Software: PDAL, LAStools, CloudCompare, ArcGIS, QGIS. | Ground filtering: отделение наземных точек от растительности. |
| gis.ops.remote_sensing_spectral | Remote Sensing — Spectral Bands | METHOD | Спектральные диапазоны: Landsat 8/9: 11 bands (0.43-12 мкм). Band 4 (Red) + Band 5 (NIR) → NDVI. SWIR: обнаружение влажности почвы/растительности. Thermal: T° поверхности. Sentinel-2: 13 bands (10м, 20м, 60м). Planet Labs: daily global coverage. | NDVI = (NIR-Red)/(NIR+Red): -1 до +1. >0.3 = растительность. |
| gis.ops.geodatabase | Geodatabase — Design | METHOD | Геобаза данных: feature classes, feature datasets, rasters, tables. Topology: spatial relationships (must not overlap). ESRI File Geodatabase vs Personal vs Enterprise (ArcGIS). OGC GeoPackage: SQLite-based, open standard. PostGIS: PostgreSQL extension (FOSS). | QGIS + PostGIS: бесплатная альтернатива ArcGIS для геопространственного анализа. |
| gis.ops.cartography_principles | Cartography — Map Design | METHOD | Принципы картографии: Figure-ground: карта должна «выделяться» от фона. Иерархия визуальная. Надписи (annotation) + шрифты. Legend clarity. North arrow + scale bar. Projection choice: Mercator (navigation), Mollweide (area equal), Robinson (aesthetic). Color: color blind friendly. | Цветовые палитры: ColorBrewer: научно-обоснованные цвета для карт. |
| gis.ops.network_analysis | Network Analysis — Routing | METHOD | Сетевой анализ: Closest Facility, Service Area (isochrones), OD Cost Matrix, Vehicle Routing Problem. Turn restrictions. One-way streets. Network dataset (ESRI) или pgRouting (PostGIS). OpenStreetMap + OSMnx (Python). Time-dependent networks. | OSRM, GraphHopper, Valhalla: open-source routing engines. |
| gis.ops.arcgis_online | ArcGIS Online — Web GIS | METHOD | Веб-ГИС (ArcGIS Online): AGOL для публикации Feature Services, Map Services. Dashboards, StoryMaps, Survey123 (data collection). Experience Builder. ArcGIS API for JavaScript. Living Atlas: готовые данные. Esri token-based licensing. | QGIS Field Maps: мобильный сбор данных. |
| gis.ops.spatial_interpolation | Spatial Interpolation — Kriging | METHOD | Пространственная интерполяция: IDW (Inverse Distance Weighting): вес обратно пропорционален расстоянию. Kriging: геостатистическая (семивариограмма → оптимальная). Spline: минимум кривизны. Natural Neighbour. TIN (Triangulated Irregular Network). Cross-validation: оценка точности. | Kriging: предпочтителен при spatial autocorrelation (пространственная зависимость данных). |
| gis.ops.drone_mapping | Drone (UAV) Mapping | METHOD | Картирование дронами: Structure from Motion (SfM): перекрытие фото → 3D. Ground Control Points (GCPs): геопривязка. Orthoimage, DEM. GNSS RTK: без GCPs. DJI Phantom, Matrice, Parrot. Agisoft Metashape, Pix4D: SfM software. FAA Part 107 (USA): regulatory. | PPK (Post-Processing Kinematic) vs RTK: PPK = более точный в post-flight. |
| gis.ops.satellite_imagery_analysis | Satellite Imagery — Object Detection | METHOD | Анализ спутниковых снимков: Supervised Classification: обучающие выборки → SVM, RF, CNN. Unsupervised: K-means, ISODATA. Object-Based Image Analysis (OBIA): сегментация + классификация. Change Detection: post-classification, image differencing. Very High Resolution (VHR): WorldView, Planet (30-50см). | Google Earth Engine (GEE): облачная платформа для анализа больших объёмов спутниковых данных. |
| gis.ops.spatial_statistics | Spatial Statistics — Moran's I | METHOD | Пространственная статистика: Spatial Autocorrelation (Moran's I): кластеризация vs рассеивание. Local Moran's I (LISA): горячие/холодные точки. Getis-Ord Gi*: Hot Spot Analysis. Ripley's K-function: точечные паттерны. Spatial Regression: OLS vs Spatial Lag vs Spatial Error. | Z-score >2.58 (Moran's): статистически значимая пространственная автокорреляция. |
| gis.ops.urban_gis | Urban GIS — Land Use Analysis | METHOD | Городской ГИС: Land Use / Land Cover (LULC) classification. Building footprint extraction. Population density mapping. Urban Heat Island (UHI) mapping using thermal. Accessibility analysis (transport). Green space analysis. Smart City data layers. 3D city models (CityGML). | OpenStreetMap: крупнейшая бесплатная географическая база данных (7 млн+ участников). |
| gis.ops.gnss_gps | GNSS — Accuracy | METHOD | Глобальные навигационные системы: GPS (USA), GLONASS (Россия), Galileo (EU), BeiDou (Китай). GNSS: обобщающий термин. Стандартная точность: 3-5 м (consumer). DGPS (Differential GPS): поправки → субметр. RTK (Real-Time Kinematic): 1-2 см. PPP (Precise Point Positioning): 2-5 см без сети. | E-GNSS: Европейский EGNOS — wide-area correction system. |
| gis.ops.floodplain_mapping | Floodplain Mapping — FEMA | METHOD | Картирование паводков (FEMA, USA): FIRM (Flood Insurance Rate Map). 100-year flood (1% AEP). 500-year flood (0.2%). Zone A: 100-year floodplain (no BFE). Zone AE: базовая отметка затопления. Zone X: вне 500-year. NFIP (National Flood Insurance Program). | Mapping updates: FEMA РискMAP programme. 2D hydraulic modeling. |
| gis.ops.geoprocessing_python | Geoprocessing — Python | METHOD | Автоматизация ГИС с Python: ArcPy (ESRI): arcpy.env.workspace + geoprocessing tools. GeoPandas: векторные операды (pandas + shapely). Rasterio: растровые операции. Shapely: геометрические операции. Fiona: чтение/запись векторных форматов. PyProj: проекции. | GeoPandas + Matplotlib: визуализация пространственных данных в Python. |
