# BATCH 748: Gastroenterology — GI Diagnosis & Management

**Scope:** endoscopy, colonoscopy, IBD, GERD, liver_disease, pancreatitis, GI_bleeding, hepatitis, H_pylori, motility

| gastro.ops.gerd_diagnosis | GERD — Diagnosis & Management | METHOD | ГЭРБ (гастроэзофагеальная рефлюксная болезнь): Типичные: изжога, регургитация. Атипичные: кашель, дисфония, боли в груди. LINX/pH мониторинг: 24-ч. PPI тест (empiric): диагностический инструмент. Лечение: PPI 8 нед (первый эпизод). Long-term: ступенчатое снижение. ALARM симптомы: дисфагия, кровотечение, потеря веса → эндоскопия срочно. | Барретт пищевода: риск аденокарциномы. Скрининг при ГЭРБ >5 лет. |
| gastro.ops.upper_endoscopy | Upper Endoscopy — EGD | METHOD | Эзофагогастродуоденоскопия (ВЭГДС): показания — диспепсия при высоком риске (>45 лет или ALARM), дисфагия, кровотечение, Barrett мониторинг. Препарат: NPO 6 ч (жидкость 2 ч). Аппарат: гибкий эндоскоп. Биопсия: из подозрительных зон + Helicobacter pylori (antrum и тело). Seattle протокол для Barrett's. Ретрофлексия: осмотр дна желудка. | Эндоскопия при желудочном кровотечении: в течение 24 ч (острое кровотечение). |
| gastro.ops.h_pylori_testing | H. pylori — Testing & Eradication | METHOD | Helicobacter pylori: тесты — Urea Breath Test (UBT): чувствительность 95%+ (неинвазивный, для контроля излечения). Stool Antigen Test (SAT): дешевле. Биопсия (EGD): с быстрым уреазным тестом (CLO). Серология: не для подтверждения ликвидации. Лечение (1-я линия): PPI + кларитромицин + амоксициллин × 14 дней. Квадротерапия при резистентности. | Тест на контроль: ≥4 нед после окончания лечения, >2 нед после PPI. |
| gastro.ops.colonoscopy_quality | Colonoscopy — Quality Indicators | METHOD | Качественные показатели колоноскопии: Adenoma Detection Rate (ADR): ≥25% (мужчины ≥30%). Cecal Intubation Rate (CIR): ≥95%. Withdrawal time: ≥6 мин. Boston Bowel Preparation Scale (BBPS): ≥6 (2+ в каждом сегменте). Polyp detection. Perforation rate: <1/500. | ADR: лучший предиктор предотвращения смерти от колоректального рака. |
| gastro.ops.ibd_differentiation | IBD — UC vs Crohn's | METHOD | ВЗК (воспалительные заболевания кишечника): UC (язвенный колит): только толстая кишка, непрерывное поражение, начинается с прямой кишки. Крон: любой отдел ЖКТ, трансмуральный, «скипы», гранулёмы. Различие: рентгенография (шнур — Crohn, кобровий «cobblestone»). Гистология: гранулёмы = Crohn. | Extraintestinal manifestations (EIM): оба — артрит, увеит, ПЭ. PSC ассоциирован с UC. |
| gastro.ops.crohns_biologics | Crohn's — Biologic Treatment | METHOD | Биологическое лечение Крона: Anti-TNF (инфликсимаб, адалимумаб): 1-я линия. Anti-integrin (ведолизумаб): кишечно-селективный. Anti-IL-12/23 (устекинумаб). JAK inhibitors (тофацитиниб для UC). Комбинированная терапия: биологик + иммуносупрессант = снижение иммуногенности. Therapeutic drug monitoring (TDM): уровень инфликсимаба >5 мкг/мл = терапевтический. | Потеря ответа (LOR): высокий IFX trough = mechanistic failure. Низкий + антитела = иммуногенность. |
| gastro.ops.uc_surveillance | UC — Dysplasia Surveillance | METHOD | Скрининг дисплазии при UC: Начало скрининга: через 8-10 лет после диагноза (если паннолит). Хромоэндоскопия (dye-spray) + прицельная биопсия: предпочтительнее случайных биопсий. WLE (White Light Endoscopy) + случайные: альтернатива. PSC ассоциированная UC: ежегодный контроль с момента диагноза. Дисплазия HGD: колэктомия. | «Invisible dysplasia» — случайная биопсия может найти то чего не видно. |
| gastro.ops.ascites_management | Ascites — Grading & Treatment | METHOD | Асцит при циррозе: Grade 1 (только на УЗИ), Grade 2 (умеренный, symmetrical), Grade 3 (массивный, тension). Лечение: ограничение соли (88 мэкв/день), диуретики (спиронолактон 100 + фуросемид 40). LVP (large volume paracentesis): при рефрактерном (>5 л, альбумин 6-8 г/L). TIPS (трансъюгулярный шунт): при рефрактерном. | SBP (спонтанный бактериальный перитонит): PMN >250 кл/мм³ в асцитной жидкости → ципрофлоксацин/цефотаксим. |
| gastro.ops.liver_disease_childs | Liver Disease — Child-Pugh Score | METHOD | Оценка функции печени (Child-Pugh): Билирубин (<2/2-3/>3), Альбумин (>3.5/2.8-3.5/<2.8), PT/INR (<1.7/1.7-2.3/>2.3), Асцит (нет/лёгкий/выраженный), Энцефалопатия (нет/I-II/III-IV). А (5-6): хорошая функция. В (7-9): умеренная. С (10-15): плохая. MELD (Model for End-Stage Liver Disease): для листа ожидания трансплантации. | MELD-Na: более точный чем MELD (включает Na). |
| gastro.ops.acute_pancreatitis | Acute Pancreatitis — Severity | METHOD | Острый панкреатит: Revised Atlanta 2012: лёгкий (нет органной недостаточности), средне-тяжёлый (транзиторная недостаточность), тяжёлый (стойкая). Ranson's criteria (первые 48 ч). BISAP score. Лечение: agressive IV fluids (Ringer's lactate 250-500 мл/ч, 1-2 л болюс). NPO → энтеральное питание рано (в течение 24-48 ч). | Агрессивная инфузия первые 24 ч: снижает некроз и осложнения. |
| gastro.ops.gib_rockall_score | GI Bleeding — Rockall Score | METHOD | Желудочно-кишечное кровотечение (Rockall Score): до/после эндоскопии. Параметры: возраст, наличие шока, сопутствующие заболевания, диагноз, стигмата кровотечения при эндоскопии. ≤2 = низкий риск. ≥5 = высокий. Glasgow-Blatchford: для тактики (выписка или госпитализация). | Активное кровотечение: PPI + эндоскопическая гемостаз + госпитализация. |
| gastro.ops.celiac_disease | Celiac — Testing Protocol | METHOD | Целиакия: IgA тТГ (tissue transglutaminase): скрининговый. При положительном → биопсия тонкой кишки (Marsh grade III-IV). IgA дефицит: 2-3% → IgG based tests. HLA DQ2/DQ8: 99%+ у целиакии (но и у 35% общего населения). Безглютеновая диета: перед тестами НЕ начинать (ложноотрицательный). | Безглютеновая диета: нужна пожизненно. |
| gastro.ops.functional_dyspepsia | Functional Dyspepsia — Rome IV | METHOD | Функциональная диспепсия (Rome IV): PDS (Postprandial Distress Syndrome): раннее насыщение, постпрандиальная полнота. EPS (Epigastric Pain Syndrome): боль/жжение эпигастрия. PDS + EPS: перекрытие. Исключить органическую (ВЭГДС). Лечение: прокинетики (при PDS), PPI (при EPS), антидепрессанты низкие дозы, диета. | Overlap с ГЭРБ и IBS: частое явление (Brain-Gut Axis Disorder). |
| gastro.ops.liver_biopsy_fibrosis | Liver Fibrosis — Non-Invasive | METHOD | Неинвазивная оценка фиброза печени: FIB-4 index = (age × AST) / (platelets × √ALT). <1.3 = низкий фиброз. >2.67 = высокий. Эластография (FibroScan): кило-паскали. F0-F1 <7.1, F2 7.1-9.4, F3 9.5-12.4, F4 (цирроз) >12.5. NAFLD Fibrosis Score. Биопсия: при неопределённости. | VCTE (Vibration Controlled Transient Elastography): FibroScan. Point ARFI: альтернатива. |
| gastro.ops.hepatitis_c_treatment | Hepatitis C — DAA Treatment | METHOD | Лечение ГС (direct-acting antivirals): SVR (sustained virologic response) = cure. Pan-genotypic: Sofosbuvir/Velpatasvir (Epclusa) × 12 нед = >95% SVR у большинства. Glecaprevir/Pibrentasvir (Mavyret) × 8 нед (без цирроза). NS5A + NS5B + NS3 inhibitors. Генотипирование перед лечением (старые режимы). Скрининг: все взрослые ≥18 лет минимум 1 раз. | ГС — излечим! Единственная хроническая вирусная инфекция с 95%+ cure rate. |
| gastro.ops.polyp_classification | Colon Polyps — Paris Classification | METHOD | Классификация полипов Парижа: Тип 0 (плоские и слегка выступающие). 0-Ip (педункулированный). 0-Is (сессильный). 0-IIa (слегка приподнятый). 0-IIb (плоский). 0-IIc (слегка вогнутый). 0-III (язвенный). Большинство аденом: 0-Is или 0-IIa. Тип 0-IIc: высокий риск подслизистой инвазии. | Paris type + NICE/JNET: предсказание гистологии до биопсии. |
| gastro.ops.motility_disorders | Esophageal Motility — Chicago Classfication | METHOD | Двигательные расстройства пищевода (Chicago Classification v4.0): Achalasia Types I-III (Jackhammer — гиперконтрактильный). EGJOO (elevated EGJ pressure). Diffuse Esophageal Spasm (DES). Fragmented peristalsis. HRM (Манометрия пищевода высокого разрешения): измерение IRP (интегрированного релаксационного давления). Лечение ахалазии: POEM (пероральная эндоскопическая миотомия), Heller myotomy, dilation. | Ахалазия тип II: лучший прогноз. Тип III: POEM предпочтительнее (спазм). |
| gastro.ops.eosinophilic_esophagitis | EoE — Diagnosis & Treatment | METHOD | Эозинофильный эзофагит: дисфагия (мужчины, молодые). Биопсия: ≥15 эозинофилов/hpf (после PPI). Эндоскопия: кольца (trachealization), борозды, экссудат. Лечение: PPI пробный курс, топические кортикостероиды (флутиказон, будесонид). Диетические элиминации (молоко, пшеница). Дупилумаб. | Первичная причина дисфагии у молодых взрослых → «не только ГЭРБ». |
| gastro.ops.ibs_rome_criteria | IBS — Rome IV Criteria | METHOD | Синдром раздражённого кишечника (Rome IV): боль в животе ≥1 день/нед × 3 мес + ≥2 из: связана с дефекацией, изменение частоты стула, изменение консистенции. IBS-C, IBS-D, IBS-M, IBS-U. Биомаркеры: нет специфических (исключение диагностики). Лечение: по типу (IBS-D: лоперамид, элуксадолин; IBS-C: линаклотид, PEG; боль: антидепрессанты, спазмолитики). | SIBO overdiagnosis: lactulose breath test низкая специфичность → нельзя рутинно при IBS. |
