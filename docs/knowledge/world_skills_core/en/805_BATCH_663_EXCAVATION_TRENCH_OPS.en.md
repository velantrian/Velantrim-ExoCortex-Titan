# BATCH 663: Excavation — Trenching & Shoring

**KnowledgeUnits:** 50
**Namespace:** `excavate.ops.*`
**Scope:** trenching, shoring, sloping, benching, underground, locate, dewatering

| ID | KnowledgeUnit | Тип | Суть | Практический смысл |
|---|---|---|---|---|
| excavate.ops.one_call_811_procedure | 811 — Locate & Marking Procedure | METHOD | Вызов службы разметки подземных коммуникаций. Позвонить 811 минимум за 48-72 часа до копки (working days). Сообщить: адрес, extent of work, тип работ. Utility companies приезжают, размечают цветными флагами/краской: Red (электричество), Yellow (газ), Orange (связь), Blue (вода), Green (канализация). Белая разметка (white lining) от excavator для обозначения зоны работ. Positive Response: все utility ответили (Clear/Conflict/Marked). Depth: markings только горизонтальные, глубина неизвестна! Осторожно вблизи marks (tolerance zone 60 см с каждой стороны). Hand dig (ручная копка) в tolerance zone. | Повреждение газопровода = эвакуация, взрыв, штрафы $50K+. |
| excavate.ops.shoring_hydraulic_vertical | Shoring — Hydraulic Vertical Shores | METHOD | Крепление стен траншеи гидравлическими распорками. Vertical hydraulic shore: алюминиевые стойки (вертикальные) + цилиндры с давлением (горизонтальные). Установка: опустить в траншею краном, накачать давление (ручной насос). Щиты (walers): стальные или алюминиевые. Расстояние между shores: по таблице производителя. Для траншей глубиной >1.5 м — обязательно (OSHA). Ежедневная инспекция competent person: до начала работ и после каждого изменения условий (дождь, вибрация). | Каждый год гибнут десятки рабочих в обрушившихся траншеях (1 куб грунта = 1.5 тонны). |
| excavate.ops.sloping_type_soil | Sloping — Soil Type Classification | METHOD | Откос стен траншеи по типу грунта. Type A (глина, cemented soils): compressive strength >1.5 т/м². Угол откоса: 53° (1.5:1 run/rise). Type B (суглинок, silt): 1.0-1.5 т/м². Угол: 45° (1:1). Type C (песок, гравий): <0.5 т/м². Угол: 34° (1.5:1). Классификация: visual + manual tests (penetrometer, thumb penetration, dry strength). Нельзя sloping в Type C с водой (flow). Benching (ступенчатый откос): только для Type A/B (не C!). | Классификация — ответственность competent person. |
| excavate.ops.trench_box_assembly | Trench Box — Assembly & Placement | METHOD | Установка trench box (стальная защитная коробка). Компоненты: sidewalls (стальные листы), spreaders (распорки). Сборка наверху: болтовое соединение, проверка pins (стопорные штифты). Подъём: экскаватор с lifting slings. Опускание в траншею: ровно, без перекоса. Рабочие внутри box'a: никогда над ними не опускать bucket! Лестница (каждые 7.5 м). Перемещение box'a по мере продвижения траншеи: сдвинуть экскаватором. Нахлёст: двухсекционный box для глубоких траншей (один поверх другого). | Trench box — самый используемый метод в городских условиях. |
| excavate.ops.dewatering_wellpoint | Dewatering — Wellpoint System | METHOD | Водопонижение для сухой траншеи. Wellpoint: перфорированная труба с фильтром, вакуумный насос. Расстановка: по периметру траншеи (2-5 м между wellpoint). Глубина: до 6 м (single stage). Вакуум: 20-25" Hg. Water discharge: отстойник (silt removal) перед сбросом. Deep wells: для глубины >6 м (submersible pumps). Sump pumping: для малых объёмов (выкопать приямок, насос). Контроль: мониторинг уровня грунтовых вод (пьезометр). | Без водопонижения: стенки обрушаются, дно размокает. |
