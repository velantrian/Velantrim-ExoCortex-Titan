| drone.ops.preflight_checklist | Preflight — Checklist & Weather | METHOD | Предполётная проверка. Weather: METAR/TAF (ветер <10-15 м/с, visibility >5 км, no precipitation), UAV Forecast (для высоты полёта), Kp index (геомагнитная активность <5 для GPS). Equipment: drone battery (100% + self-discharge OK), RC battery, spare props, memory card (отформатирована), phone/tablet charged. Airspace: LAANC authorization через app (AirMap, Kittyhawk) — мгновенно в controlled airspace до определенных высот, дальше manual FAA. NOTAMs (временные ограничения). Visual inspection: drone arms, motors (провернуть рукой — свободно, без скрежета), propellers (трещины, баланс), gimbal (свободно движется), lens clean. Compass calibration: если moved far от последнего полёта (перекалибровка). Home point set: GPS lock (минимум 10-12 satellites). RTH (Return-to-Home) altitude: установить выше всех препятствий в зоне полёта. | LiPo батарея: swollen (вздутие) — немедленно утилизировать (fire risk!). Хранение при storage voltage (3.7-3.85V/ячейка). |
| drone.ops.mapping_flight_planning | Mapping — Flight Planning & Overlap | METHOD | Планирование фотограмметрической миссии. ПО: DJI Pilot, DroneDeploy, Pix4Dcapture. Параметры: Altitude (выше = больше coverage, ниже = лучше resolution GSD — ground sampling distance). GSD (см/пиксель) = (высота × ширина сенсора) / (фокусное × ширина изображения). Overlap: front 75-80%, side 65-75% (для 3D reconstruction). Тип миссии: Grid (над ровной поверхностью), Circle (для башен, башен), Double Grid (крест-накрест — для лучшей accuracy на плоской местности). Terrain follow (если изменения высоты — дрон поднимается/опускается по DEM). Контрольные точки (GCPs — Ground Control Points): маркеры на земле с известными координатами (survey-grade GNSS), для accuracy геопривязки. Speed: 5-10 м/с (медленнее = меньше motion blur). Shutter: mechanical (global shutter) > rolling shutter для mapping. | Фотограмметрия: требует >60% overlap для orthomosaic, >80% для 3D. Количество фотографий: 50-500 на проект (в зависимости от площади). |
| drone.ops.thermal_inspection_roof | Thermal — Roof & Solar Panel Inspection | METHOD | Тепловизионная инспекция с дрона. Камера: Radiometric thermal (FLIR Vue, Zenmuse H20T), разрешение 640×512, sensitivity <50 mK. Солнечные панели: проход над массивом, detection hot cells (перегрев — дефект bypass diode, cell crack). Кровля: влажная изоляция (теплее ночью, холоднее днём — thermal anomaly). Поиск утечек тепла в здании (missing insulation). Настройки: Emissivity (0.90-0.95 для большинства строительных материалов). Отражение: angle (не прямо перпендикулярно — собственное отражение sky), palettes (Ironbow, Greyscale, Isotherm для выделения anomaly). Время: для крыш — after sunset (solar gain dissipated, anomalies visible). RTK (Real-Time Kinematic): для точного позиционирования дефекта (±2-3 см). Отчёт: thermal image overlaid на RGB orthomosaic. | Температурный span: narrow (auto adjust) для detection малых разниц (1-2°C). |
| drone.ops.part107_compliance | Part 107 — FAA Small UAS Rule | METHOD | Коммерческие операции (США). Требования: 1) Remote Pilot Certificate (тест в FAA центре — 60 вопросов, 2 часа, 70% pass). 2) Drone registration ($5). 3) Максимальный вес <25 кг (55 lb). 4) Высота <120 м (400 ft) AGL (выше с waiver). 5) Скорость <160 км/ч (87 kts). 6) VLOS (Visual Line of Sight) — всегда видеть дрон невооружённым глазом (или с observer корректировкой). 7) No flight over people (исключение — Part 107 over people rules Category 1-4). 8) Daylight only (30 мин до восхода/после заката с anti-collision lights). 9) Yield to manned aircraft. 10) No operation from moving vehicle (except sparsely populated area). Waivers: подать на waiver (Night, BVLOS, over people). TRUST (The Recreational UAS Safety Test) для recreational flyers. | BVLOS (Beyond Visual Line of Sight): наиболее желаемый waiver для industry (инспекция трубопроводов, линейной инфраструктуры). |
| drone.ops.post_flight_log_data | Post-Flight — Data Management & Log | METHOD | Обработка после полёта. Log: flight time, battery serial, location, purpose, issues (incident?). UAV log — для maintenance. Данные: копирование с SD на компьютер/облако. Backup: правило 3-2-1. Photogrammetry processing: загрузка фото в Pix4D/Agisoft/Dronedeploy → alignment → point cloud → mesh → orthomosaic. Время: часы на processing (зависит от числа фото). Thermography: ПО FLIR Tools. Батарея: охладить до ambient t, затем зарядка до storage voltage если не полетит завтра. Drone cleaning: сухая ткань, проверка sensors. Logbook запись (законодательно для commercial ops — maintenance log). | Data privacy: фото могут непреднамеренно захватывать людей/private property. GDPR/Privacy considerations. |
