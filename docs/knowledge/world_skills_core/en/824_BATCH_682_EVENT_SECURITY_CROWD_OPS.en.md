# BATCH 682: Event Security — Crowd & Venue Management

**KnowledgeUnits:** 50
**Namespace:** `eventsecurity.ops.*`
**Scope:** crowd_dynamics, ingress_egress, access_control, emergency_response, threat_assessment, CCTV, communication

| ID | KnowledgeUnit | Тип | Суть | Практический смысл |
|---|---|---|---|---|
| eventsecurity.ops.crowd_density_thresholds | Crowd Density — Safety Thresholds | METHOD | Безопасная плотность толпы. Fruin level of service (LOS): A (>1.2 м²/чел, free flow), B (1.0-1.2 м², comfortable), C (0.7-1.0 м², restricted movement), D (0.4-0.7 м², very restricted), E (0.2-0.4 м², body contact), F (<0.2 м², crowd crush risk). Мониторинг: overhead cameras + real-time people counting (AI analytics). Density actions: LOS D → slow ingress, LOS E → stop entry, F → immediate evacuation. Crowd push: forward surging crowd can exert force >4.5 kN/m (fatal). Bottlenecks: gates, narrow corridors — critical design points. | Hillsborough (1989): 96 погибших от compressive asphyxia в толпе. |
| eventsecurity.ops.ingress_screening_ops | Ingress — Screening Operations | METHOD | Досмотр на входе. Walk-through metal detector (WTMD): все посетители, расстановка с учётом throughput (600-900 чел/час per lane). Hand wand: выборочный или при тревоге. Ticket scanning: барьер + staff, anti-queue design. Bag check: X-ray или physical inspection, prohibited items list posted. Coat check: снятие тяжёлой верхней одежды до прохода. Credential check (VIP/backstage): laminate + wristband. Staffing ratio: 1 screener на 500 attendees (minimum). | Throughput management: arrive windows, early bird incentives, staged entry. |
| eventsecurity.ops.radio_comms_protocol | Radio Communications — Event Protocol | METHOD | Радиосвязь на мероприятии. Каналы: command (руководство безопасности, менеджмент), floor (staff на полу), medical (EMS), VIP/backstage. Discipline: PTT (push-to-talk) — ждать щелчка, identify unit («это East Gate 3»), pause before speaking. 10-codes или clear text (современный стандарт — clear text, избегать коды при межсистемной работе). Code words: медицинское (Alpha+), fire (Delta), public disturbance (Echo). Supervisor override: priority interrupt. Radio check schedule: каждые 30-60 мин. Dead zones: mapping radio coverage (critical!) до события. | Encrypted channel: для sensitive ops (anti-leakage). |
| eventsecurity.ops.threat_matrix_assessment | Threat Assessment — Event Risk Matrix | METHOD | Матрица рисков мероприятия. Категории: внешняя угроза (terrorism, hostile vehicle attack, protest), внутренняя (intoxicated patron, domestic violence, mental health), аварийная (fire, structural, medical mass casualty). Вероятность (1-5) × Последствие (1-5) = Risk score. Приоритизация mitigation. Mitigations: concrete barriers (vehicle), K9 sweep, plainclothes security, coordination with police, active shooter protocol (Run/Hide/Fight). Briefing: все staff до события (threat level, code words, emergency contacts). After-action report: после события. | DHS resources: CISA protective measures for events (free). |
| eventsecurity.ops.post_event_sweep | Post-Event — Venue Sweep | METHOD | Осмотр площадки после мероприятия. Цель: проверить нет ли оставленных подозрительных предметов, оставленных посетителей (unconscious), security violations. Teams: парами (в одиночку — нельзя). Systematic grid: кресло за креслом в рядах (stadium), нет пропущенных зон. Medical: медики с командой (sleeping/intoxicated persons). Suspicious items: не трогать, оцепить, позвонить EOD (bomb squad). Documentation: time complete, any items found, persons assisted. Lost and found: сбор и регистрация. | Suspicious unattended bag rule: нельзя открывать, перемещать (EOD только). |
