# BATCH 701: Fuel Storage — Tank Installation & Compliance

**KnowledgeUnits:** 50
**Namespace:** `fueltank.ops.*`
**Scope:** UST, AST, double_wall, leak_detection, cathodic, spill_bucket, overfill, registration

| ID | KnowledgeUnit | Тип | Суть | Практический смысл |
|---|---|---|---|---|
| fueltank.ops.double_wall_interstitial | Double Wall — Interstitial Monitoring | METHOD | Контроль межстенного пространства. Double-wall tank (сталь/FRP): между внутренним и внешним tank есть зазор (interstitial space). Interstitial monitor: датчик жидкости (float switch) или вакуум/pressure. Если leak — сигнал на контроллер (alarm). Методы: continuous vacuum, continuous pressure, hydrostatic, electronic sensor. SIR (Statistical Inventory Reconciliation): ежемесячный анализ данных (inventory + delivery + dispensing = unaccounted loss). | UST regulation: leak detection required (EPA 40 CFR 280). |
| fueltank.ops.spill_bucket_testing | Spill Bucket — Testing & Repair | METHOD | Тест поддона заливной горловины. Spill bucket: резервуар под fill cap (собирает spilled fuel при доставке). Тест: заполнить водой, наблюдать уровень через 5-10 мин (утечка?). Если leak — замена резинового уплотнителя (boot seal). Двойной bucket (содержимое не проникает в грунт). Drain valve: слив жидкости обратно в tank. Периодичность: каждые 3 года гидротест, ежегодный визуальный. | Leaking spill bucket = топливо в грунт при каждой заправке. |
| fueltank.ops.overfill_prevention_valve | Overfill Prevention — Flapper | METHOD | Автоматический клапан перелива. Drop tube с flapper valve: при заполнении до 90-95% tank capacity — flapper закрывается, ограничивает flow (оператор delivery truck слышит изменение потока и останавливается). Auto shutoff: полностью перекрывает flow при 98%. Alarm: звуковой/световой при 90%. All devices должны быть UL listed. Тест: functional test ежегодно. | Без overfill: spill при переполнении (большие штрафы). |
| fueltank.ops.line_leak_detection | Line Leak Detector — Pressurized | METHOD | Контроль утечек в трубопроводе. Pressurized line (до 10 GPH): Mechanical LLD (Line Leak Detector) ежегодный тест. Electronic LLD: continuous monitoring (3.0 GPH hourly, 0.2 GPH monthly, 0.1 GPH annual). ELD тест требует shut down dispensers на время теста. Secondary containment (double-wall pipe): interstitial monitor. Sumps (приямки под dispenser): датчик жидкости. | Single-wall pipe: strict leak test. |
| fueltank.ops.cathodic_protection_test | Cathodic Protection — Test | METHOD | Тест катодной защиты UST. Sacrificial anodes (магний/цинк) — каждые 3 года тест structure-to-soil potential (Cu/CuSO4 reference, −850 mV). Impressed current (rectifier) — каждые 60 дней проверка rectifier log (volts, amps). Тест: structure + reference electrode, измерение потенциала. Если не достигает −850 mV — добавить/заменить аноды. | Без CP: стальной tank rusts through (leak). |
