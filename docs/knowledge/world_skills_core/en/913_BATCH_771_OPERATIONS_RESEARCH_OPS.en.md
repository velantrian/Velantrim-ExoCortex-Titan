| opsresearch.ops.simplex_method | Linear Programming — Simplex | METHOD | Симплекс-метод: Стандартная форма LP: max cᵀx, Ax ≤ b, x ≥ 0. Основные допустимые решения: вершины многогранника. Алгоритм: двигаться по рёбрам к лучшей вершине. Simplex tableau: итерационные шаги. Dual problem: экономические интерпретации (shadow prices). Bland's rule: предотвращение зацикливания. | Shadow price = marginal value of loosening constraint. |
| opsresearch.ops.integer_programming | Integer Programming — Branch & Bound | METHOD | Целочисленное линейное программирование (ILP): требует целых значений переменных. Branch & Bound: решить LP relaxation → если нецелое → разветвить по переменной (добавить ограничения). Cutting planes (Gomory cuts): обрезание нецелых областей. NP-hard в общем случае. Binary variables: расписание, назначение. MIP (Mixed Integer Programming). | ILP на практике: CPLEX, Gurobi, OR-Tools. |
| opsresearch.ops.transportation_assignment | Network Flow — Transportation Problem | METHOD | Транспортная задача: m источников + n потребителей, найти min cost routing. Балансировка: сумма supply = сумма demand (добавить dummy). Initial BFS: Northwest Corner, Minimum Cost, Vogel's Approximation. Optimality: stepping-stone или MODI. Degenerate: n+m-1 базисных переменных. Assignment Problem: n×n транспортная → Hungarian algorithm. | Transportation: O(n³) сложность. Hungarian: O(n³). |
| opsresearch.ops.queuing_theory_mm1 | Queuing Theory — M/M/1 | METHOD | Система массового обслуживания M/M/1: Пуассоновский вход (λ), экспоненциальное обслуживание (μ). ρ = λ/μ < 1 (устойчивость). Ls = ρ/(1-ρ) (среднее число в системе). Lq = ρ²/(1-ρ). Ws = Ls/λ (среднее время в системе). Wq = Lq/λ. Little's Law: L = λW. M/M/c: c серверов. M/G/1: общее обслуживание. | Little's Law: универсален для любой устойчивой очереди (не только M/M/1). |
| opsresearch.ops.shortest_path_dijkstra | Shortest Path — Dijkstra | METHOD | Алгоритм Дейкстры: нахождение кратчайшего пути в взвешенном графе (неотрицательные веса). Инициализация: d[source]=0, остальные=∞. Итерация: выбрать непосещённый с мин d, обновить соседей. O((V+E)logV) с binary heap. Bellman-Ford: отрицательные веса. Floyd-Warshall: все пары. | Dijkstra: хорошо для sparse graphs. Floyd-Warshall: для dense (O(V³)). |
| opsresearch.ops.dynamic_programming | Dynamic Programming — Optimal Substructure | METHOD | Динамическое программирование: принцип оптимальности (Беллман). Optimal substructure: оптимальное решение содержит оптимальные подзадачи. Overlapping subproblems: мемоизация или bottom-up. Классические задачи: Knapsack (0/1), LCS, LIS, Coin Change, Matrix Chain Multiplication. State space reduction. | DP vs Greedy: DP всегда оптимален (если opt substructure), Greedy иногда ошибается. |
| opsresearch.ops.simulation_montecarlo | Simulation — Monte Carlo | METHOD | Метод Монте-Карло: случайная выборка из вероятностных распределений. Используется когда аналитическое решение трудно/невозможно. LHS (Latin Hypercube Sampling): более эффективная выборка. Соотношение доверительного интервала к n: CI ∝ 1/√n (удвоить точность = 4× runs). Applications: Financial risk, engineering reliability, supply chain. | Variance reduction techniques: antithetic variates, control variates. |
| opsresearch.ops.scheduling_job_shop | Scheduling — Johnson's Algorithm | METHOD | Планирование производства: Johnson's Algorithm (2 машины, n jobs): оптимально минимизирует makespan. Критерии: Cmax (makespan), total flow time, lateness, tardiness. SPT (Shortest Processing Time): min average flow time. EDD (Earliest Due Date): min max lateness. Complexity: O(nlogn) для 1 machine, NP-hard для job shop. | Critical path analysis: для project scheduling (нет resource constraints). |
| opsresearch.ops.stochastic_optimization | Stochastic Programming — Two-Stage | METHOD | Стохастическое программирование: Two-Stage Recourse: 1-й этап (до сценариев), 2-й этап (коррекция в каждом сценарии). Expected Value Problem (EEV) vs Wait-and-See (WS) vs here-and-now. EVPI (Expected Value of Perfect Information): цена неопределённости. VSS (Value of Stochastic Solution). Sample Average Approximation (SAA). | Scenario tree: дискретизация распределений для stochastic DP. |
| opsresearch.ops.nonlinear_programming | NLP — KKT Conditions | METHOD | Нелинейное программирование: условия KKT (Karush-Kuhn-Tucker): необходимые для оптимальности при ограничениях. ∇f = Σλᵢ∇gᵢ + Σμⱼ∇hⱼ. Complementary slackness: λᵢ ≥ 0, λᵢgᵢ = 0. Convex NLP: KKT достаточны для глобального оптимума. SLSQP, interior-point methods. SQP (Sequential Quadratic Programming): для general NLP. | Lagrangian relaxation: убрать сложные ограничения с штрафом → lower bound. |
| opsresearch.ops.markov_chains | Markov Chains — Steady State | METHOD | Цепи Маркова: конечное состояние Markov chain (дискретное время). Матрица переходов P: строки суммируются в 1. Установившееся состояние: πP = π. Absorbing state: поглощающее состояние. Chapman-Kolmogorov: P(n) = Pⁿ. DTMC vs CTMC (Continuous Time): different analysis. Ergodic: единственное установившееся состояние. | Markov Property: будущее зависит только от текущего состояния (не истории). |
| opsresearch.ops.maxflow_mincut | Network Flow — Max-Flow Min-Cut | METHOD | Максимальный поток/Минимальный разрез: Max-flow min-cut theorem: max flow = min capacity of any cut. Ford-Fulkerson algorithm: augmenting paths. Edmonds-Karp: BFS для augmenting path = O(VE²). Bipartite matching: max-flow application. Network simplex: linear min-cost flow. Menger's theorem: k vertex-disjoint paths = min k-vertex cut. | Max-flow applications: bipartite matching, routing, supply chain, baseball elimination. |
| opsresearch.ops.goal_programming | Goal Programming — Deviation | METHOD | Целевое программирование: несколько целей = нельзя одновременно оптимизировать. Goals: допустимые целевые значения + отклонения (d⁺, d⁻). Minimize deviations от целей. Lexicographic: приоритет между целями. Weighted: одна агрегированная целевая функция. Applications: планирование производства, портфель активов, распределение ресурсов. | Pareto front: множество оптимальных решений при нескольких целях. |
| opsresearch.ops.inventory_eoq_model | Inventory — Economic Order Quantity | METHOD | EOQ (оптимальный размер заказа): Q* = √(2DS/H). D = ежегодный спрос. S = стоимость заказа. H = стоимость хранения/ед. TC(Q) = DS/Q + QH/2 (min at Q*). Reorder Point: ROP = d × LT (где d = спрос/день, LT = lead time). Safety Stock: z × σ(d) × √LT. Newsvendor model: one-period stochastic. | EOQ sensitive: S обычно трудно оценить (often overestimated). |
| opsresearch.ops.vehicle_routing | Vehicle Routing Problem — VRP | METHOD | Задача маршрутизации транспортных средств (VRP): доставить всем клиентам с min cost fleet. NP-hard. Variants: CVRP (capacitated), VRPTW (time windows), VRP with multiple depots. Heuristics: Clarke-Wright Savings, Nearest Neighbour. Metaheuristics: Genetic Algorithm, Simulated Annealing, Tabu Search. Google OR-Tools: routing solver. | VRPTW на практике: logistic companies use commercial solvers (Gurobi + OR-Tools). |
| opsresearch.ops.robust_optimization | Robust Optimization — Uncertainty Sets | METHOD | Устойчивая оптимизация: решение, хорошо работающее при любом сценарии из задан. uncertainty set. Box uncertainty: параметр ∈ [nominal - δ, nominal + δ]. Ellipsoidal uncertainty: Ben-Tal & Nemirovski. Budget uncertainty (Bertsimas & Sim): ограниченное число параметров отклоняются. Conservative approach: трейд-офф между оптимальностью и надёжностью. | Robust vs Stochastic: Robust = worst-case, Stochastic = expected value. |
| opsresearch.ops.benders_decomposition | Decomposition — Benders | METHOD | Декомпозиция Бендерса: для MIP с сложной структурой. Master problem: integer variables. Subproblem: LP для фиксированных integer vars. Benders cuts: обратная связь от subproblem к master. Applications: facility location, network design. Dantzig-Wolfe: column generation. Lagrangian relaxation: добавить dual vars к objective. | Benders: эффективен когда subproblem решается быстрее полного MIP. |
| opsresearch.ops.reliability_engineering_or | Reliability — MTTF & Redundancy | METHOD | Надёжность систем: MTTF (Mean Time to Failure) = ∫₀^∞ R(t) dt. Экспоненциальное распределение отказов: R(t) = e^(-λt), MTTF = 1/λ. Series system: Rs = ∏ Rᵢ. Parallel system: Rs = 1 - ∏(1-Rᵢ). k-out-of-n: система работает если ≥k компонентов работают. Fault tree analysis (FTA): логические диаграммы. | Active redundancy vs standby: active = все работают параллельно, standby = резерв. |

Super-efficiency: ранжирование эффективных. Applications: hospitals, banks, universities efficiency. | DEA: не абсолютная, а ОТНОСИТЕЛЬНАЯ оценка (лучший ≠ оптимальный). |
