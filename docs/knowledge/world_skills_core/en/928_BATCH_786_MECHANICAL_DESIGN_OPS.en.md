| mechengdesign.ops.gear_tooth_load | Gear — Lewis Equation | METHOD | Уравнение Льюиса (изгибная прочность зуба): W_t = σ_b × F × m × Y. W_t = tangential load. σ_b = допустимое изгибное напряжение. AGMA добавляет коэффициенты: динамический, нагрузки, жёсткости. | AGMA (American Gear Manufacturers Association): промышленный стандарт расчёта зубчатых передач. |
| mechengdesign.ops.shaft_power_speed | Shaft Design — Torsion | METHOD | Проектирование вала: τ = T×r/J. T = крутящий момент. J = полярный момент. Для кругового сечения: τ_max = 16T/(πd³). При изгибе + кручении: σ_eq = √(σ² + 3τ²). Von Mises criterion. | mechengdesign.ops.rolling_bearing_selection | Rolling Element Bearings — L10 Life | METHOD | Выбор подшипников качения: L10 life (нагруженность). L10 = (C/P)^p × 10⁶/n / 60. C = dynamic load rating (из каталога). P = equivalent dynamic load. p = 3 (ball bearings), 10/3 (roller). L10 = число оборотов при 10% chance of failure (90% survive). SKF, FAG, NSK каталоги. | Значение нагрузки P с учётом радиальной и осевой: P = X×Fr + Y×Fa. |
| mechengdesign.ops.spring_design_tension | Helical Springs — Wahl Factor | METHOD | Витые цилиндрические пружины: Напряжение кручения в витке τ = K_W × 8FD / πd³. K_W (Wahl Correction Factor): K_W = (4C-1)/(4C-4) + 0.615/C. C = D/d (spring index). Spring rate k = Gd⁴/(8D³n). Deflection δ = F/k. Solid length L_s = n×d. | Spring index C 6-12: оптимальная зона (ниже = трудно намотать, выше = нестабильность). |
| mechengdesign.ops.bolted_joint_preload | Bolted Joint — Preload & Fatigue | METHOD | Болтовые соединения: Preload F_i = (0.75-0.9) × S_p × A_t (S_p = proof strength, A_t = tensile stress area). Bolt stiffness k_b, joint stiffness k_m. Load sharing: F_bolt = C × F_external, где C = k_b/(k_b + k_m). Separator load: joint открывается при F_ext > F_i/C. Fatigue: Goodman диаграмма. | С = 0.1-0.3 типично: большинство внешней нагрузки поглощается фланцем. |
| mechengdesign.ops.hertz_contact_stress | Contact Stress — Hertzian | METHOD | Контактные напряжения (Герц): для двух сферических тел σ_max = -0.578 × √(F/πb²L). Half-contact width b. Контакт цилиндр-цилиндр: σ_H = √(2FE*/πL × 1/R*). E* = приведённый модуль. Subsurface fatigue: crack begins below surface at τ_max. Pitting: повреждение поверхности. | Gear surface pitting: критически важно при недостаточной контактной прочности. |
| mechengdesign.ops.vibration_natural_freq | Vibration — Natural Frequency | METHOD | Собственная частота колебаний: ω_n = √(k/m). f_n = ω_n / (2π). Критическая скорость вала: ω_crit = ω_n. Resonance: избегать в рабочем диапазоне скоростей. Dunkerley's equation: приблизительный расчёт. Rayleigh's method: энергетический подход. Damping ratio ζ: если ζ < 1 = underdamped. | Vortex-induced vibration: у труб в потоке жидкости при совпадении f_vortex = f_n. |
| mechengdesign.ops.key_interference_fit | Interference Fit — Stresses | METHOD | Прессовые соединения: давление на поверхности раздела p = δ × E / (d × C₁/C₂). δ = натяг. Сборка: пресс или тепловой. | Тепловое разжимание: нагреть ступицу → охладить вал перед сборкой. |
| mechengdesign.ops.cam_follower | Cam Design — Motion Laws | METHOD | Кулачковые механизмы: SHM (Simple Harmonic Motion): sin profile. Constant acceleration (Parabolic). Follower types: flat, roller, spherical. | Cycloidal cam: наилучший для высоких скоростей (нет jerk). |
| mechengdesign.ops.clutch_brake_design | Clutch — Design | METHOD | Дисковая муфта: T = μ × F × n × R_mean × f. F = осевая нагрузка. μ = коэффициент трения. n = число пар. R_mean = средний радиус. Uniform pressure: p = const = F/(π(r_o²-r_i²)). Uniform wear: p = C/r → R_mean = 2/3 × (r_o³-r_i³)/(r_o²-r_i²). | Dry friction materials: μ ≈ 0.3-0.5. Wet: 0.05-0.15. |
| mechengdesign.ops.belt_drive | Belt Drive — Power Transmission | METHOD | Ременные передачи: Open belt: θ_min = 180° - 2arcsin((d₂-d₁)/2C). Tension ratio: F₁/F₂ = e^(μθ). Power = (F₁ - F₂) × v.
