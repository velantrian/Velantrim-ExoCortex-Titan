# BATCH 792: Computer Networks — Advanced Concepts

**KnowledgeUnits:** 50
**Namespace:** `compnet.ops.*`
**Scope:** TCP_IP_deep, OSPF_BGP, MPLS, SDN_NFV, VLAN, QoS, wireless_protocols, network_security_deep, cloud_networking, monitoring

| ID | KnowledgeUnit | Тип | Суть | Практический смысл |
|---|---|---|---|---|
| compnet.ops.ospf_areas | OSPF — Area Design | METHOD | OSPF (Open Shortest Path First): link-state протокол. Areas: Area 0 (Backbone), другие areas подключаются через ABR (Area Border Router). Router types: IR (Internal Router), ABR, ASBR (Autonomous System Boundary Router). LSA types: Type 1 (Router), 2 (Network), 3 (Summary), 4, 5 (External). SPF algorithm: Dijkstra. | OSPF stub area: Type 5 LSA не разрешены. Totally stubby: только Type 1+2+3. |
| compnet.ops.vlan_trunking | VLAN — 802.1Q Trunking | METHOD | VLAN (Virtual LAN): логическое разделение Ethernet. 802.1Q tag: 4-байтовый в Ethernet frame (VLAN ID 12 bit = 4094 VLANs). Native VLAN: без тега на trunk. Access port: один VLAN. Trunk port: несколько VLANs. Inter-VLAN routing: Router on a Stick (sub-interfaces) или Layer 3 switch (SVI). | Default VLAN 1: небезопасно оставлять для данных. |
| compnet.ops.tcp_three_way | TCP — Three-Way Handshake | METHOD | TCP 3-шаговое рукопожатие: SYN → SYN-ACK → ACK. SYN: SEQ = ISN (Initial Sequence Number). SYN-ACK: SEQ = server ISN, ACK = client ISN+1. ACK: завершение. Finite State Machine: LISTEN → SYN_RECEIVED → ESTABLISHED. Congestion window (cwnd). Half-close: одна сторона закрывает (FIN-WAIT). | TIME_WAIT: 2×MSL (максимум 4 мин) предотвращает коллизии с новым соединением. |
| compnet.ops.sdn_openflow | SDN — OpenFlow Protocol | METHOD | Software-Defined Networking (SDN): отделение control plane от data plane. Controller (логическое): Ryu, ONOS, OpenDaylight. Switch (data plane): OpenFlow (1.0, 1.3). Match fields: Destination MAC, IP, VLAN, Port. Actions: forward, drop, modify. Flow table: набор правил. Разделение: больше программируемости. | OpenFlow vs NETCONF/RESTCONF: OpenFlow = low-level dataplane, NETCONF = configuration management. |
| compnet.ops.wireless_802_11 | Wi-Fi — 802.11 Standards | METHOD | Стандарты Wi-Fi: 802.11a/g: 54 Mbps. 802.11n (Wi-Fi 4): до 600 Mbps, MIMO. 802.11ac (Wi-Fi 5): 6.9 Gbps, MU-MIMO, 5 GHz only. 802.11ax (Wi-Fi 6): 9.6 Gbps, OFDMA, BSS Coloring, TWT. Wi-Fi 6E: 6 GHz band. Wi-Fi 7 (802.11be): 46 Gbps, MLO. CSMA/CA: access protocol (vs CSMA/CD in Ethernet). | OFDMA (Wi-Fi 6): разделяет канал между устройствами (улучшает Dense environments). |
| compnet.ops.spanning_tree_rstp | Spanning Tree — RSTP | METHOD | RSTP (Rapid Spanning Tree Protocol, 802.1w): конвергенция <1 сек (vs STP 30-50 сек). Port roles: Root, Designated, Alternate, Backup. Port states: Discarding, Learning, Forwarding. Proposal-Agreement mechanism: быстрая синхронизация. MSTP (Multiple STP): разные STP инстанции для разных VLANs. | STPloop: сеть перегружается от broadcast storm. STP предотвращает. |
| compnet.ops.multicast_pim | Multicast — PIM | METHOD | IP Multicast: один источник → несколько получателей. IGMP: host → router join/leave. PIM (Protocol Independent Multicast): Dense Mode (flood+prune) vs Sparse Mode (shared tree + SPT). Rendezvous Point (RP): точка встречи. Source-Specific Multicast (SSM): PIM SSM. IGMP snooping: switch понимает multicast groups. | IP multicast address range: 224.0.0.0/4 (D class). |
| compnet.ops.nat_pat_detail | NAT — Types & Implementation | METHOD | NAT (Network Address Translation): Static NAT: 1:1 постоянный. Dynamic NAT: пул адресов. PAT (Port Address Translation/Overload): много:1 (с портами). CGNAT (Carrier-Grade): ISP-level. ALG (Application Layer Gateway): для SIP, FTP (меняет payload). NAT hairpinning: internal host → public IP → назад. | DNS ALG: необходим для split-DNS с NAT. |
| compnet.ops.network_security_ids | Network Security — IDS/IPS | METHOD | Обнаружение/предотвращение вторжений (IDS/IPS): Signature-based: известные паттерны (быстрое). Anomaly-based: отклонение от нормы (находит novel attacks). SNORT: open-source IPS. Inline (IPS) vs Passive (IDS). Next-Gen Firewall (NGFW): DPI + application awareness + SSL inspection. Zeek/Bro: network analysis framework. | Deep Packet Inspection (DPI): смотрит внутрь пакета (не только заголовки). |
| compnet.ops.cloud_vpc | Cloud Networking — VPC | METHOD | Virtual Private Cloud (VPC): изолированная сеть в облаке. Subnets: public (IGW route) vs private (NAT gateway). Security Groups: stateful (разрешения). Network ACLs: stateless (allow/deny per rule). VPC Peering: связь VPCs. Transit Gateway: hub-and-spoke для многих VPCs. Direct Connect/ExpressRoute: выделенный канал. | Security Group: нет explicit deny → default deny (NACL = explicit). |
| compnet.ops.network_automation_ansible | Network Automation — Ansible | METHOD | Сетевая автоматизация с Ansible: Playbooks (YAML). Network modules: ios_command, eos_config, junos_config. Inventory: hosts файл или dynamic. Idempotent: повторные запуски безопасны. Templates (Jinja2): генерация конфигов. NAPALM: multi-vendor network automation. Ansible AWX/Tower: GUI + scheduling. | Infrastructure as Code (IaC): конфигурация как код = версионность + reproducibility. |
| compnet.ops.ntp_clock_sync | NTP — Time Synchronization | METHOD | Network Time Protocol (NTP): Stratum 0 (atomic clocks) → Stratum 1 (directly connected) → Stratum 2 → ... → Stratum 16 (unsync). Клиент синхронизируется с NTP server. Accuracy: <1 мс (LAN), <10 мс (WAN). PTP (IEEE 1588): точнее (наносекунды). Leap second: осложнение для NTP. | Правильное время: обязательно для TLS certificates, logs, Kerberos. |
| compnet.ops.dhcp_operation | DHCP — Message Types | METHOD | DHCP операция: DORA (Discover, Offer, Request, Acknowledge). UDP: client 68, server 67. Lease time: клиент запрашивает renewal при 50% истечения. DHCP relay agent: для inter-VLAN DHCP. DHCP snooping: безопасность (блокирует rogue DHCP servers). Dynamic ARP inspection (DAI): связанный механизм защиты. | DHCP starvation attack: заполнить DHCP pool → DoS. DHCP snooping предотвращает. |
| compnet.ops.mpls_vpn_l3 | MPLS L3 VPN — Architecture | METHOD | MPLS L3 VPN: PE (Provider Edge) + P (Provider core) + CE (Customer Edge). VRF (Virtual Routing and Forwarding): изолированные таблицы маршрутизации. MP-BGP: обмен VPN маршрутами между PE. Route Distinguisher (RD): уникализация префиксов. Route Target (RT): распределение в правильные VRFs. 2-label stack: transport label + VPN label. | VRF lite: L3 VPN без MPLS (на одном маршрутизаторе). |
| compnet.ops.tcp_optimization | TCP — Performance Tuning | METHOD | Оптимизация TCP: Window Scaling (RFC 7323): окно >65535 байт. Timestamps: RTT measurement + PAWS (защита от wrap-around). SACK (Selective Acknowledgement): эффективное recovery. ECN (Explicit Congestion Notification): не дожидаться drop. TCP buffer sizes: net.core.rmem_max, net.ipv4.tcp_rmem. | TCP Offload Engine (TOE): перенести TCP на NIC (снижает CPU нагрузку). |
| compnet.ops.network_monitoring_snmpv3 | Network Monitoring — SNMPv3 | METHOD | SNMPv3 security: Authentication: HMAC-MD5 или HMAC-SHA. Encryption: DES или AES (предпочтительнее). USM (User-based Security Model). View-based Access Control (VACM). SNMPv3 users: authPriv (auth + encryption), authNoPriv, noAuthNoPriv. Trap destination: SNMPv3 informs (подтверждение). | NetFlow/sFlow/IPFIX: трафик аналитика (дополнение к SNMP). |
| compnet.ops.bgp_route_policy | BGP — Route Policy | METHOD | BGP policy manipulation: Route Maps: match + set (применяется при import/export). Prefix-lists: фильтрация по IP prefix. AS-path ACL: фильтрация по AS path. Community: маркировка для policy. Attribute manipulation: local-preference, MED, weight (only local effect). AS-path prepending: удлинение → сигнализация less preferred path. | iBGP: Full mesh или Route Reflector (RR) для масштабируемости. |
| compnet.ops.vxlan_overlay | VXLAN — Data Center Overlay | METHOD | VXLAN (Virtual Extensible LAN): overlay protocol (RFC 7348). 24-bit VNI (Virtual Network Identifier): 16 млн VLANs. Encapsulation: original frame → UDP header (port 4789). VTEP (VXLAN Tunnel Endpoint): leaf switches. BGP EVPN: control plane для VXLAN. Multi-tenant overlay. | VXLAN vs MPLS: VXLAN = UDP-based (simpler), MPLS = label-based (more mature). |
| compnet.ops.zero_trust_network | Zero Trust Networking | METHOD | Zero Trust Network Access (ZTNA): не доверять сети по умолчанию. Принципы: verify identity + device + access. Micro-segmentation: каждый workload изолирован. Software-defined perimeter (SDP). BeyondCorp (Google): реализация без VPN. SaaS + identity-centric: SASE (Secure Access Service Edge). | «Trust but verify» → «Never Trust, Always Verify». |
