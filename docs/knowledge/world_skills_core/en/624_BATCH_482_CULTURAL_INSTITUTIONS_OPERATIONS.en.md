| culture.ops.library_circulation_desk | Library — Circulation Desk Operations | PROCESS | Выдача и возврат материалов. Выдача: сканирование читательского билета → сканирование barcode/RFID на книге → система записывает выдачу (due date = сегодня + loan period — 14/21/30 дней). Возврат: сканирование книги → система снимает выдачу → проверка на повреждения/отсутствие страниц → автоматическая сортировочная машина (RFID антенна считывает, конвейер распределяет по тележкам для разных отделов: fiction, non-fiction, children, holds). Holds: читатель заказал книгу онлайн → система генерирует pick list → staff снимает с полки → помещает на hold shelf (по фамилии читателя, privacy — last name + last 4 digits card) → уведомление (email/SMS/phone) → 7 дней на получение, потом возврат в фонд. Renewals: автоматическое продление если нет holds от других читателей (до 3-5 раз). Overdue: gentle reminders (pre-overdue за 3 дня, overdue day 1, day 7, day 14, bill for replacement day 30-60 с admin fee). | RFID заменило barcode + EM-полоски: одно сканирование = security деактивация + выдача, скорость в 3-5 раз выше. Fine-free movement (библиотеки отказываются от штрафов): увеличивает возврат на 10-20%, снижает барьер для малоимущих. |
| culture.ops.cataloging_marc | Cataloging — MARC21 & RDA | METHOD | Создание библиографической записи. MARC21 (Machine-Readable Cataloging): стандарт обмена библиографическими данными с 1960-х. Поля: 1xx Main entry (автор), 245 Title + subtitle + statement of responsibility, 250 Edition, 260/264 Publication info, 300 Physical description (pages, illustrations, size), 490/830 Series, 5xx Notes, 6xx Subject headings (LCSH — Library of Congress Subject Headings, MESH для медицины), 7xx Added entries (co-authors, illustrators, translators), 8xx Series added entry. RDA (Resource Description and Access, заменил AACR2): фреймворк, а не жёсткие правила — описывает relationships между works, expressions, manifestations, items (FRBR model). Authority control: нормализация имён авторов (единая форма Фамилия, Имя, даты: Orwell, George, 1903-1950), cross-references от вариантов (Blair, Eric Arthur → Orwell, George). | Каталогизация одной книги занимает 20-60 минут опытным каталогизатором. Copy cataloging: импорт готовой записи из OCLC WorldCat (95%+ книг уже кем-то откаталогизированы). Original cataloging только для местных/уникальных материалов. |
| culture.ops.rare_book_conservation | Rare Book & Paper Conservation | METHOD | Консервация (стабилизация, предотвращение дальнейшего разрушения) vs реставрация (восстановление до первоначального вида). Условия хранения: температура 18-20°C (±1°C), влажность 45-50% (±5%) — мониторинг data loggers. Свет: <50 lux для paper/текстиля, <200 lux для картин, UV <75 µW/lumen. Кислотность: бумага 1800-х — деревянная масса (pH 4-5) — самодеструкция. Deacidification: водный или безводный (Bookkeeper — MgO в перфторуглероде, оставляет щелочной резерв). Ремонт разрывов: японская бумага (washi, kozo fibers — долговечная, pH neutral) + wheat starch paste (обратимо в воде, архивисты могут отменить через 100 лет). Инкапсуляция: между листами полиэстера (Mylar/Melinex) — не ламинация! (ламинат необратим). Оцифровка: scanning без разворота на 180° (>120° угрожает переплёту) — cradle scanner, LED (не UV/IR), 300-600 dpi, TIFF master (JPEG derivative для доступа). | Кража и замена rare book: воры вырезают страницы (maps, illustrations). Защита: page count при выдаче/возврате, RFID в переплёте. Самая дорогая ошибка: amateur repair скотчем (non-archival, желтеет, необратимо повреждает бумагу). |
| culture.ops.museum_exhibit_installation | Museum — Exhibit Installation & Mount-Making | METHOD | Монтаж выставки. Mount-making: крепления для экспонатов (brass rods, acrylic mounts, ethafoam padding — all archival, chemically inert). Безопасность: крепление выдерживает 3× вес экспоната (сейсмический запас). Климат в витрине: silica gel (Art-Sorb, Prosorb) для буферизации влажности, Ageless (oxygen scavenger для предотвращения окисления металлов). Освещение: fibre optic или LED (без UV/IR), направленное на экспонат, не на этикетку (блики). Высота этикетки: 1-1.2 м от пола (чтение без наклона). Flow: посетитель движется против часовой стрелки (естественная tendency). Deinstallation: reverse process, condition report при возврате (сравнение с condition report при получении экспоната — новые повреждения?). | Condition report: фото до, описание каждого дефекта (foxing, craquelure, loss), подписи обеих сторон (lender и borrower), дата. Является юридическим документом при споре о повреждении. Loan agreement: museum несёт ответственность «nail-to-nail» (от снятия со стены в lender до повески обратно). |
| culture.ops.archive_arrangement | Archival Arrangement & Description | METHOD | Организация архивного фонда согласно принципам provenance (происхождение — фонды разных создателей не смешиваются) и original order (оригинальный порядок дел сохраняется, если он understandable). Уровни описания (ISAD(G)): Fonds (весь фонд организации) → Series (группа дел — переписка, финансы, проекты) → File (дело — папка с документами по одной теме) → Item (единица — отдельный документ). Finding aid: описание фонда/серии для исследователей (административная история, scope and content, dates, extent в линейных метрах, условия доступа, язык). Контейнеризация: acid-free folders + Hollinger boxes (buffered/unbuffered depends on material). Условия хранения: аналогичны rare books (T 18-20°C, RH 45-50%). Обработка: удаление металлических скрепок/скоб (ржавеют), замена на пластиковые (полипропилен), разворачивание сложенных документов. | Цифровой архив: born-digital materials (email, social media, databases) — сложность в том, что нет физического носителя + формат устаревает (floppy disk, WordStar). Форматы для preservation: PDF/A, TIFF, WAV, CSV, XML. Эмуляция (воссоздание оригинальной программной среды для доступа). |
