| applsci1.ops.semiconductor_transistor | Semiconductor — MOSFET Operations | METHOD | MOSFET (Metal-Oxide-Semiconductor Field-Effect Transistor): Enhancement mode NMOS: Vgs > Vth → channel forms. Regimes: Linear (Vds < Vgs-Vth), Saturation (Vds ≥ Vgs-Vth). Id = μCox(W/L)(Vgs-Vth)Vds (linear). Id = μCox(W/L)(Vgs-Vth)²/2 (saturation). CMOS inverter: NMOS + PMOS. | Technology node: 3 нм (TSMC/Samsung 2022). Transistor density ↑ → Moore's Law. |
| applsci1.ops.nanotube_properties | Carbon Nanotubes — Properties | METHOD | Углеродные нанотрубки (CNT): Armchair (metallic), Zigzag, Chiral (can be either). Mechanical: ~100 GPa tensile strength. Electrical: metallic CNT = ballistic conductor (~mm без рассеяния). Single-Wall (SWCNT) vs Multi-Wall (MWCNT). Synthesis: CVD (Chemical Vapour Deposition). Graphene: 2D аналог. | Применение CNT: электронные устройства, композиты, биосенсоры. |
| applsci1.ops.mems_fabrication | MEMS — Fabrication | METHOD | МЭМС (Microelectromechanical Systems): Bulk micromachining: etch through silicon wafer (KOH, DRIE). Surface micromachining: deposit + pattern + release sacrificial layers. LIGA: X-ray lithography + electroplating. Stiction: поверхностное натяжение при release. Application: accelerometers, pressure sensors, MEMS mirrors. | MEMS accelerometer в смартфоне: MEMS capacitive sensing. |
| applsci1.ops.optical_fiber_telecom | Photonics — Fiber Optic Loss | METHOD | Потери в оптическом волокне: Rayleigh scattering: 1/λ⁴ (dominant <1300 нм). Absorption: OH- peaks (1400 нм). Total: SMF28 ≤0.2 дБ/км при 1550 нм. Chromatic Dispersion: different wavelengths → different speeds. Polarization Mode Dispersion (PMD). Erbium Doped Fiber Amplifier (EDFA): 1530-1565 нм. | Telecommunications window: 1310 нм (zero dispersion) и 1550 нм (min loss). |

NISQ era: Noisy Intermediate-Scale Quantum. | Google Sycamore (2019): «quantum supremacy» = 200 сек vs 10 000 лет. |
| applsci1.ops.bioinformatics_blast | Bioinformatics — Sequence Alignment | METHOD | Биоинформатика: BLAST (Basic Local Alignment Search Tool): поиск схожих последовательностей в базах данных. Multiple Sequence Alignment: ClustalW, MUSCLE. | GenBank: NCBI база данных нуклеотидов (225 млрд+ нуклеотидов, 2024). |
| applsci1.ops.genomics_ngs | Next-Gen Sequencing — Platforms | METHOD | Платформы NGS: Illumina: Sequencing by Synthesis (SBS) — флуоресцентные reversible terminators. ONT (Oxford Nanopore): real-time, long reads, portable. | Short reads vs Long reads trade-off: short = высокая точность. Long = сборка генома + структурные варианты. |
| applsci1.ops.proteomics_mass_spectrometry | Proteomics — Tandem MS | METHOD | Тандемная масс-спектрометрия (MS/MS): ESI (Electrospray Ionization): ионизация белков. Orbitrap: высокое разрешение. Q-TOF: квадруполь + время пролёта. Database Search (Mascot, SEQUEST): пептид → белок. Quantitative proteomics: iTRAQ, TMT, SILAC. Метаболомика: HMDB database. | Proteomics vs genomics: геном = возможности. Протеом = реальность. |
| applsci1.ops.crispr_base_editing | CRISPR — Advanced Tools | METHOD | Advanced CRISPR: Base Editing (David Liu): C→T или A→G без DSB. Prime Editing: поиск-замена без donor (pegRNA + PE2). CRISPR diagnostics: SHERLOCK, DETECTR. | Prime editing: более точный чем base editing — может делать любые single nucleotide changes + small insertions/deletions. |
| applsci1.ops.plasma_physics | Plasma Physics — Debye Length | METHOD | Физика плазмы: четвёртое состояние материи. Debye Length (λD): расстояние, на котором экранируется заряд. λD = √(ε₀kT/ne²).
