Sedimentation: осаждение. Filtration: через песок/гравий. Disinfection: хлор + озон + UV. Fluoridation. | envchem.ops.ddt_organochlorine | Organochlorine Pesticides — Fate | METHOD | Органохлоридные пестициды: DDT, хлордан, дильдрин, линдан. Характеристики: высокие log Kow (>5) → биоаккумуляция в жирах. Persistentные (годы-десятилетия). Биомагнификация в пищевой цепи. POPs (Persistent Organic Pollutants): Стокгольмская конвенция (2001). | DDT запрещён в большинстве стран с 1970-80-х. Исключение: малярия-эндемичные регионы. |
| envchem.ops.heavy_metals_speciation | Heavy Metals — Chemical Speciation | METHOD | Спецификация тяжёлых металлов: форма (speciation) определяет токсичность. Methylmercury (CH3Hg+): наиболее токсичная форма Hg. Arsenite As(III) > Arsenate As(V). Hexavalent Cr(VI): карциноген. Trivalent Cr(III): менее токсичный. Cadmium: накапливается в почках. Lead: нейротоксичен при всех уровнях. | Methylmercury: образуется анаэробными бактериями из Hg²⁺ в осадках водоёмов. |
| envchem.ops.henry_constant | Henry's Law — Volatilization | METHOD | Закон Генри: Kh = Pgas / Caq (Па·м³/моль). Летучесть из воды: Kh > 10⁻³ = значительная. TCE (Kh = 10⁻² Па·м³/моль): умеренная. Benzene: высокая. Хлороформ: умеренная. Применение: vapor intrusion assessment, air stripping design. | Air stripping tower: для VOCS из воды (Kh высокий → легко удалить). |
| envchem.ops.octanol_water_kow | Kow — Bioaccumulation Indicator | METHOD | Коэффициент распределения октанол-вода (log Kow): Kow = C_octanol / C_water. Высокий log Kow (>4): биоаккумуляция в жирах. BCF (Bioconcentration Factor): Kow модель. log BCF ≈ 0.85 log Kow - 0.70 (Mackay). Токсичность неполярная: narcosis → QSAR. | Log Kow < 1: гидрофильный, не биоаккумулируется. Log Kow > 6: очень гидрофобный. |
| envchem.ops.soil_organic_carbon | Soil-Water Partition — Koc | METHOD | Распределение в почве: Koc = Kd / foc. foc = fraction of organic carbon в почве. Koc = Kow × 0.41 (простая оппроксимация для неполярных). Бензен Koc = 83. PCB Koc = 10⁵. Сильная корреляция с Kow. | Atrazine в песчаных почвах: высокая вымываемость (низкий Koc). |
| envchem.ops.phytoremediation | Phytoremediation — Types | METHOD | Фиторемедиация: Phytoextraction: растения накапливают металлы (Thlaspi caerulescens для Zn/Cd). Phytodegradation: растения разлагают органические. Phytostabilization: предотвращение миграции. Phytovolatilization: испарение (Hg, Se). Rhizofiltration: корни поглощают металлы из воды. | Populus (тополь): широко используется для phytoremediation VOCs. |
| envchem.ops.ozone_depletion | Stratospheric Ozone — Catalytic Destruction | METHOD | Разрушение озона: Cl (из CFCs) + O3 → ClO + O2. ClO + O → Cl + O2 (Cl регенерируется). Один атом Cl → 100 000 молекул O3. Montreal Protocol (1987): поэтапный отказ от CFCs. HFCs замена: не разрушают но GWP высокий (Kigali Amendment, 2016). | Ozone hole: Антарктика каждую весну → UV увеличивается → рак кожи. |

| envchem.ops.pcbs_fate | PCBs — Environmental Fate | METHOD | Полихлорированные бифенилы (ПХБ): 209 конгенеров по числу хлоров. Применение: трансформаторное масло, огнеупорное. Персистентны. | envchem.ops.dissolved_oxygen_bod | BOD — Biochemical Oxygen Demand | METHOD | Биохимическая потребность в кислороде (BOD): количество O2 необходимое для разложения органики. BOD5 (5 дней, 20°C): стандарт. COD (Chemical Oxygen Demand): включает все окисляемые. BOD/COD ratio: >0.5 = хорошо биоразлагаемый. Стандарт выброса сточных вод: BOD <30 мг/л (вторичная очистка). | Снижение DO в водоёме: algal bloom → decomposition → fish kill (hypoxia). |

Effluent standards: NPDES permit. | Activated sludge: bacteria в suspension + aeriation. 90%+ BOD removal. |
| envchem.ops.nano_pollutants | Emerging Contaminants — PFAS | METHOD | PFAS (Per- и полифторалкильные вещества): PFOA, PFOS + 12 000+ соединений. «Forever chemicals»: исключительно стойкие.
