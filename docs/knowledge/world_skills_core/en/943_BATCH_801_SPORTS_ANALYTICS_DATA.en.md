| sportsanalytics.ops.expected_goals | Football — Expected Goals (xG) | METHOD | Ожидаемые голы (xG): вероятность гола из конкретной позиции. Компоненты: расстояние, угол, тип удара, часть тела, предшествующее действие. Создаётся с помощью исторических данных + логистической регрессии. xG > Score: команда была лучше чем результат. Post-shot xG (PSxG): учитывает качество удара. | xG оверперформанс/андерперформанс: долгосрочная реверсия к среднему. |
| sportsanalytics.ops.war_baseball | Baseball — WAR Calculation | METHOD | Wins Above Replacement (WAR): всё в одном хитталлном показателе. Для батеров: wRAA (batting) + BsR (baserunning) + UZR или DRS (fielding) + positional adjustment. Для питчеров: FIP-based WAR (FanGraphs). Замена: replacement level player (AAA уровень). 2 WAR = starter, 5+ WAR = All-Star, 8+ WAR = MVP. | FIP (Fielding Independent Pitching): только controlled outcomes для питчера. |
| sportsanalytics.ops.player_tracking_gps | GPS Player Tracking — Metrics | METHOD | GPS мониторинг: VMAX (максимальная скорость). Total distance. High-Speed Running (HSR) > 5.5 м/с. Sprint (SPR) > 7.0 м/с. HML (High-Metabolic Load) distance. Accelerations/decelerations per game. Load management: acute:chronic workload ratio (ACWR). Optimal ACWR: 0.8-1.3. | ACWR > 1.5: повышенный риск травмы (Gabbett research). |
| sportsanalytics.ops.nba_plus_minus | Basketball — Plus-Minus Variants | METHOD | Показатели «плюс/минус» в баскетболе: Raw ±: разница очков при игроке на площадке. BPM (Box Plus/Minus): скорректированный по статистике. RAPTOR (FiveThirtyEight): player tracking + box stats. EPM (Estimated Plus/Minus). RPM (Real Plus-Minus, ESPN). VORP (Value Over Replacement). | On/Off splits: команда vs замена → реальный вклад. |
| sportsanalytics.ops.injury_prediction | Injury Prediction — ML Models | METHOD | Предсказание травм: Features: нагрузка (тренировка + игры), история травм, биомеханика, сон, мышечная асимметрия (FMS, Nordbord). ML алгоритмы: логистическая регрессия, случайный лес, XGBoost. Imbalanced dataset (мало травм). SMOTE (oversampling). ROC-AUC: метрика. Wearables data fusion. | Проблема: «пропускаемые» исходы (class imbalance), задержка получения данных. |
| sportsanalytics.ops.tennis_serving | Tennis — Serve Analytics | METHOD | Аналитика подачи в теннисе: Ace%, Double Fault%, 1st Serve%/Points Won. Break point save%. Return Games Won. RPW (Return Points Won). Top Spin rpm. Ball speed mph. Court coverage. Serve direction patterns by opponent. | Hawk-Eye: точность позиций мяча ±2.6 мм. Ball tracking data. |
| sportsanalytics.ops.basketball_offensive_rating | Basketball — Offensive Rating | METHOD | OffRtg (Offensive Rating) = Points per 100 possessions. DefRtg = Points Allowed per 100. NetRtg = OffRtg - DefRtg. Estimated via: Poss = FGA - OREB + TO + 0.44 × FTA. Pace: # possessions per 48 мин. True Shooting % (TS%) = Points / (2 × (FGA + 0.44 × FTA)). | NetRtg ≈ win%. Каждые +5 NetRtg ≈ +10 wins в NBA. |
| sportsanalytics.ops.soccer_progressive_passes | Soccer — Progressive Actions | METHOD | Прогрессивные действия в футболе (StatsBomb/Opta): Progressive passes: продвигают мяч ≥10 метров к воротам. Progressive carries: дриблинг с продвижением. Progressive distance: суммарная. Open play passes into final third. xA (Expected Assists): вероятность что пас приводит к голу. PPDA (Passes Allowed Per Defensive Action): intенсивность прессинга. | PPDA < 8: очень высокое прессинг. PPDA > 12: низкий прессинг. |
| sportsanalytics.ops.nfl_epa | American Football — Expected Points Added | METHOD | Expected Points Added (EPA): ожидаемые очки следующего тока (Expected Points) − очки после действия. EPA/Play: эффективность действий. DVOA (Defense-Adjusted Value Over Average): Football Outsiders. WPA (Win Probability Added): вклад в вероятность победы. EPA по позициям: DYAR, DPAR. | EPA на третий даун: наиболее ценный контекст. |
| sportsanalytics.ops.hockey_corsi | Hockey — Corsi & xG | METHOD | Хоккейная аналитика: Corsi (C+/C-): shot attempts включая миссы и блоки. CF% (Corsi For%): % shot attempts при команде на льду. Expected Goals (xG): вероятность гола по типу броска. Zone Entries: как часто входят в зону с контролем. Fenwick: как Corsi без блоков. | Corsi 50%: нейтральная. >55% = высокая контроль. |
| sportsanalytics.ops.cricket_drs | Cricket — DRS & Analytics | METHOD | Аналитика крикета: Batting Average, Strike Rate. Economy Rate (bowling). Wagon wheel: shot distribution map. Hawkeye: DRS (Decision Review System) — отслеживание мяча. Ball tracking → LBW decision. Wormgraph: runs over time. Match innings progression. | DRS Margin: within 2.5 мм = «umpire's call». |
| sportsanalytics.ops.video_analysis_ocr | Video Analysis — OCR & Object Tracking | METHOD | Видеоаналитика: YOLO/Detectron для обнаружения игроков. Pose estimation: body keypoints. Automatic event detection (goal, tackle, sprint). | Computer vision замена manual tagging: 10-20× быстрее. |
| sportsanalytics.ops.draft_value | Draft Value — Evaluation Models | METHOD | Оценка игроков на драфте: Historical outcomes → regress performance to draft position. RAS (Relative Athletic Score): стандартизированный. | Comps (comparables): исторически похожие игроки как ориентир. |
| sportsanalytics.ops.fatigue_monitoring | Fatigue Monitoring — HRV | METHOD | Мониторинг усталости: HRV (Heart Rate Variability): rMSSD. ↓ HRV = повышенная нагрузка/усталость. Оценочные листы: POMS (Profile of Mood States), RPE (Rate of Perceived Exertion). Blood markers: CK (мышечный распад), cortisol, testosterone ratio. | sportsanalytics.ops.home_field_advantage | Home Field Advantage — Statistical | METHOD | Преимущество родного поля: НБА: ~3 pts/game (с болельщиками). MLB: ~0.04 runs/game. Без болельщиков (COVID): почти исчезает. Факторы: psychological, sleep disruption for visitors, referee bias, crowd noise impact. 2020 COVID analysis: strongest evidence for referee effects. | Referee bias: при шумной толпе судьи дают 0.1-0.2 больше жёлтых карточек гостям (Soccernomics). |
