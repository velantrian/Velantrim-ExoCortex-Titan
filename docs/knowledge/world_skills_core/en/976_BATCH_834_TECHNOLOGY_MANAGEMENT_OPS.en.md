| techmanage.ops.technology_roadmap | Technology Roadmap — TRM | METHOD | Технологическая дорожная карта (TRM): согласование бизнес-стратегии + технологии. Layers: Market/Business layer, Product layer, Technology layer. Time horizon: 1-3-5-10 лет. Методы: SCAMP (Strategic Alignment, Communications, Action Plans, Measures, Portfolio). | Motorola TRM: базовая разработка 1987 → сейчас стандарт. |
| techmanage.ops.disruptive_innovation | Technology S-Curve — Adoption | METHOD | S-кривая технологий: технология рождается → медленный рост → экспоненциальный рост (adoption) → насыщение. Rogers Diffusion of Innovations: Innovators 2.5% → Early Adopters → Early Majority → Late Majority → Laggards. Chasm: разрыв между Early Adopters и Early Majority. | Crossing the Chasm (Moore): технологические продукты часто застревают в chasm. |
| techmanage.ops.rd_management | R&D Management — Stage Gate | METHOD | Управление R&D: Stage-Gate Process (Cooper): Gate 1 (идея) → Stage 1 (предварительное расследование) → Gate 2 → Stage 2 (детальное) → Gate 3 → Stage 3 (разработка) → Gate 4 → Stage 4 → Gate 5 → Launch. Fuzzy Front End: первые нечёткие этапы = наибольшая неопределённость. R&D intensity = R&D / Revenue. | High R&D intensity: фарма (~15%), software (~15%), technology. Low: retail, oil&gas. |
| techmanage.ops.vc_startup_funding | Startup Ecosystem — Funding Stages | METHOD | Финансирование стартапов: Pre-seed: FFF (Friends, Family, Fools) + angel. Seed: angel rounds (€500K-€2M). Series A: institutional VC ($2M-$15M), prove model. Series B: scaling ($15M-$50M). Series C+: expansion. IPO: public markets. Unicorn: >$1B valuation. Decacorn: >$10B. | Growth equity (PE): не early-stage, не LBO. Minority + fast-growing. |
| techmanage.ops.open_innovation | Open Innovation — Chesbrough | METHOD | Открытые инновации (Chesbrough, 2003): использование внешних идей + путей в инновационных процессах. Inbound (inside-out): лицензировать чужие идеи. Outbound (outside-in): лицензировать свои. Coupled: взаимный обмен. Corporate Venture Capital (CVC). Innovation hubs. API economy. | Procter & Gamble «Connect & Develop»: 50%+ инноваций извне (как цель). |
| techmanage.ops.digital_twin | Digital Twin — Technology | METHOD | Цифровой двойник: виртуальная копия физической системы в реальном времени. Применение: промышленное оборудование, здания, человеческое тело. IoT sensors → Model. Simulation: «что если». Predictive maintenance. NASA: первый пользователь (Apollo). | Siemens Industrial Metaverse: digital twins в производстве. |
| techmanage.ops.technology_transfer | Technology Transfer — University | METHOD | Трансфер технологий из университетов: TTO (Technology Transfer Office). Disclosure → evaluation → patent → licensing → spinoff. Bayh-Dole Act (1980, США): университеты могут присваивать IP от федерального финансирования. License types: exclusive, non-exclusive, field-of-use. | США: 20 000+ изобретений из университетов ежегодно. Патенты монетизируются через лицензии + стартапы. |
| techmanage.ops.innovation_culture | Innovation Culture — Ambidexterity | METHOD | Инновационная культура: Psychological Safety (Эдмондсон): «можно экспериментировать + провалиться». «Fail fast»: iterative learning. Skunkworks: отдельные команды для радикальных проектов. 20% time (Google): независимое исследование. Innovation Sprints. Hackathons. | Организационная ambidexterity: explore + exploit одновременно (сложно, нужны структурные условия). |
| techmanage.ops.ip_strategy | IP Strategy — Patent Portfolio | METHOD | Стратегия интеллектуальной собственности: Offensive патентная стратегия: блокировать конкурентов. Defensive: защитить себя (Patent Thicket). Patent Pools: объединение связанных патентов. Trolls: NPE (Non-Practising Entities). FRAND: для стандартных патентов. FTO (Freedom to Operate) analysis. | Patent portfolio: стоимость компании — особенно для биотех/фарма/хайтек. |
| techmanage.ops.iot_management | IoT — Industrial Internet of Things | METHOD | Промышленный Интернет вещей (IIoT): Edge computing: обработка данных у источника. Connectivity: MQTT, AMQP, OPC-UA. Protocol: Modbus, Profibus, EtherNet/IP (промышленные). Digital supply chain. Predictive maintenance через sensor analytics. OT/IT convergence. | Cybersecurity OT/IIoT: исторически изолированные системы → теперь подключены = risk. |
| techmanage.ops.emerging_technology | Emerging Technology — Gartner Hype Cycle | METHOD | Цикл зрелости технологий Gartner: Innovation Trigger → Peak of Inflated Expectations → Trough of Disillusionment → Slope of Enlightenment → Plateau of Productivity. Не каждая технология выходит на Plateau. 2024 Hype Peak: GenAI, connected cloud, AI-TRiSM. | Generative AI (ChatGPT): вышел на пик Hype 2023 → раннее разочарование 2024. |
| techmanage.ops.product_lifecycle | PLM — Product Lifecycle Management | METHOD | Управление жизненным циклом продукта: Introduction → Growth → Maturity → Decline. Стратегии по стадиям: intro = invest + build awareness, growth = market share, maturity = defend + optimize, decline = harvest or exit. Product renewal: перезапуск до начала decline. | Длинный хвост (Long Tail, Anderson): нишевые продукты в decline могут продолжать существовать в цифровых рынках. |
| techmanage.ops.technology_standardization | Standards — Development Process | METHOD | Разработка технологических стандартов: ISO/IEC (международные), ANSI (США), BSI (UK), DIN (Germany). Propreitary → Open Standard: browser wars → W3C. IEEE: электро-технические стандарты. IETF: интернет-протоколы (RFC). First-mover advantage в стандарт = конкурентное преимущество. | De facto стандарт (рыночный): BluRay vs HD-DVD = рыночная победа. |
| techmanage.ops.lean_startup | Lean Startup — Build-Measure-Learn | METHOD | Lean Startup (Рис): MVP (Minimum Viable Product) → Learn → Iterate. Build-Measure-Learn цикл: максимально быстро. Validated Learning: фактические данные vs предположения. Pivot vs Persevere. Innovation Accounting: alternative metrics. | MVP ≠ плохой продукт: минимально жизнеспособный для проверки гипотезы. |
