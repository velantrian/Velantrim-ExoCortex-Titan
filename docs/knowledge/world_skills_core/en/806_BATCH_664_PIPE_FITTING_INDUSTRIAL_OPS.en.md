# BATCH 664: Pipe Fitting — Industrial Plumbing & Gas

| ID | KnowledgeUnit | Тип | Суть | Практический смысл |
|---|---|---|---|---|
| pipefitting.ops.butt_weld_alignment | Butt Weld — Alignment & Hi-Lo | METHOD | Стыковая сварка трубопровода. Alignment clamp (прихватки). Hi-Lo (несовпадение кромок): max 1/16" (1.5 мм) для труб <12", max 1/8" для больших. Root gap: 1/16-3/32" (1.5-2.5 мм) для GTAW root. Land (притупление): 1/32-1/16" (0.8-1.5 мм). Bevel: 37.5° ± 2.5° (итого угол разделки 75°). Прихватки (tack weld): 3-4 равномерно, длина 1" (25 мм). Induction preheating (подогрев): P91 требует 200-250°C perheating. Purging (газовая защита корня): аргон для SS. | Hi-Lo — основная причина отклонения в рентгенографии шва. |
| pipefitting.ops.isometric_drawing_read | Isometric Drawing — Reading & Mark-Up | METHOD | Чтение изометрических чертежей трубопровода. Изометрия: 30° проекция, отображает трубы, фитинги, клапаны, опоры. BOM (Bill of Materials): спецификация компонентов. Spool (катушка): монтажный блок (изготавливается в мастерской). Flow direction стрелка. Valve symbols: gate, globe, check, butterfly, ball. Slope indication (уклон): 1:100 или дробь. Weld symbols: стандарт AWS. Pipe class: определяет материал, schedule, давление. Hold point: точка инспекции до следующего шага. | Изометрия ≠ реальные размеры (пропорции условные). |
| pipefitting.ops.valve_types_selection | Valve Types — Selection & Application | METHOD | Типы клапанов. Gate valve (задвижка): fully open/close, не для регулирования. Globe valve (вентиль): регулирование, flow resistance high. Check valve (обратный): предотвращает обратный поток. Ball valve (шаровой): быстрое открытие, 1/4 поворот. Butterfly valve (бабочка): большие диаметры, lightweight. Pressure relief valve (предохранительный): открывается при превышении давления. Control valve (регулирующий): с приводом для автоматики. Fire protection: backflow preventer, OS&Y gate valve (наружный шпиндель с ходовым колесом). | Globe valve: много turbulence, high ΔP. Ball valve: low ΔP. |
| pipefitting.ops.pressure_test_hydrostatic | Pressure Test — Hydrostatic | METHOD | Гидроиспытание трубопровода. Стандарт: ASME B31.3 — 1.5× MAWP (максимальное рабочее давление). Подготовка: fill с водой (bottom-up, удалить воздух через top vent). Изолировать: насос + датчик давления (calibrated, >0.25% accuracy). Подъём давления: медленно (до 50%, проверка, до 100%, проверка, до test pressure). Hold time: minimum 10 мин, при обнаружении — 30+ мин. Поиск утечек: soap test, visual. Снижение давления: постепенно, slew rate <10 psi/мин. Документация: pressure test record (start/end/hold pressure + time). | Freezing: никогда не оставлять voidu water в трубе зимой. |
| pipefitting.ops.thread_sealant_types | Thread Sealant — Types & Application | METHOD | Уплотнение резьбовых соединений. PTFE tape (Teflon): намотка по часовой стрелке (по резьбе), 2-3 слоя для water, 4-5 для gas. Pipe dope (thread sealant paste): для всех металлических соединений. Anaerobic (Loctite 565/577): gas/chemical services. Никогда не на: hydraulic union connections, compression fittings. Дозировка: тонкий слой (излишек загрязнит line). Отверждение: анаэробик — 24 часа до pressure test. | PTFE + dope: не вместе (skipping принятых стандартов). |
