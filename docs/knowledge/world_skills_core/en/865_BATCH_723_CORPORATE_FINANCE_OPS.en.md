| corpfin.ops.dcf_valuation | DCF Valuation — Free Cash Flow | METHOD | Дисконтированный денежный поток (DCF): FCF = EBIT(1-t) + D&A - ΔWC - CapEx. WACC = wd×rd(1-t) + we×re. Terminal Value (Gordon Growth): TV = FCFn×(1+g) / (WACC-g). Enterprise Value = PV(FCFs) + PV(TV). Equity Value = EV - Net Debt. Sensitivity: IRR, NPV profile. | DCF чувствителен к Terminal Value (обычно 60-80% EV). Даже малые изменения assumptions → большие изменения. |
| corpfin.ops.financial_statements_analysis | Financial Statements — Analysis Framework | METHOD | Три отчёта: Income Statement (доходы-расходы = чистая прибыль). Balance Sheet: Assets = Liabilities + Equity. Cash Flow Statement: Operating + Investing + Financing. DuPont: ROE = Net Margin × Asset Turnover × Equity Multiplier. Working Capital = Current Assets - Current Liabilities. EBITDA: операционный proxy cash flow. | Non-GAAP EBITDA: компании корректируют (stock-based comp, restructuring) → читать с осторожностью. |
| corpfin.ops.wacc_components | WACC — Cost of Capital | METHOD | Средневзвешенная стоимость капитала: WACC = wd×kd×(1-t) + we×ke. ke (CAPM): ke = rf + β×(rm-rf). rf = risk-free rate (10-year UST). β = market sensitivity. Market risk premium: 4-7% (historic). Tax shield: процент по долгу вычитается из налогов (→ значительная экономия). Target capital structure: оптимальный D/E. | CAPM limitations: historical beta ≠ forward beta. Adjusted beta: β_adj = 2/3×β_historical + 1/3×1.0. |
| corpfin.ops.credit_analysis_5c | Credit Analysis — 5 C's | METHOD | Пять «С» кредитного анализа: Character (репутация, история платежей). Capacity (способность погасить: DSCR = NOI / debt service ≥1.25). Capital (собственный капитал в сделке). Conditions (рыночные условия). Collateral (залог, LTV). Ковенанты (Covenants): ограничения в кредитном договоре (leverage ratio <3×, min liquidity). | DSCR <1.0: кэш недостаточен для обслуживания долга без дополнительных средств. |
| corpfin.ops.merger_accretion_dilution | M&A — Accretion/Dilution Analysis | METHOD | Анализ акреции/разводнения при слиянии: Accretion: EPS покупателя растёт. Dilution: EPS покупателя снижается. Расчёт: Post-merger EPS = (Net income acquirer + Net income target) / diluted shares outstanding pro-forma. Синергии: revenue + cost synergies - integration costs. Break-even synergies: минимальные синергии для нейтрального EPS. | Cash deals vs stock deals: stock — автоматическое dilution при высокой цене. |
| corpfin.ops.lbo_model_structure | LBO — Leveraged Buyout Model | METHOD | Выкуп с использованием заёмного капитала (LBO): PE fund выкупает компанию (75-80% долгом). Цели IRR: 20-30%+ за 5 лет. Debt repayment: free cash flow → снижение долга. Entry multiple: EV/EBITDA покупка (7-10×). Exit multiple: EV/EBITDA продажа (7-10×). Value creation: debt paydown + EBITDA growth + multiple expansion. | «Floor» IRR: гарантированный минимум → нужен доходный бизнес с предсказуемым FCF. |
| corpfin.ops.bonds_duration_convexity | Fixed Income — Duration | METHOD | Дюрация (Duration): чувствительность цены облигации к изменению процентных ставок. Modified Duration: ΔP/P ≈ -MD × Δy. Macaulay Duration: средневзвешенный срок потоков. Convexity: поправка на нелинейность. ΔP/P ≈ -MD × Δy + 0.5 × Convexity × Δy². Negative convexity: ипотечные ценные бумаги (prepayment risk). | Duration 7: при росте ставки на 1% цена облигации снижается на ≈7%. |
| corpfin.ops.ipo_process | IPO — Process Steps | METHOD | Первичное публичное размещение: Выбор андеррайтеров (lead banker). S-1 registration statement (SEC). Roadshow: презентации инвесторам. Book building: заявки. Pricing: диапазон цен → финальная цена. Lockup period: 90-180 дней (insiders не могут продавать). Greenshoe option: over-allotment (15% дополнительных акций). SPAC: альтернатива IPO (merger with shell company). | Underwriting spread: 7% (typical for U.S. IPO) = основной доход банка. |
| corpfin.ops.derivatives_hedging | Derivatives — FX Hedging | METHOD | Валютное хеджирование: Forward contract: фиксация курса на будущую дату. FX Option: право (не обязательство) купить/продать по strike. Zero-cost collar: покупка put + продажа call (бесплатный hedge). Cross-currency swap: обмен основной суммы + процентов в разных валютах. Hedge ratio: % экспозиции, покрытой хеджем. | Natural hedge: совпадение доходов и расходов в той же валюте. |
| corpfin.ops.working_capital_management | Working Capital — Cash Conversion Cycle | METHOD | Cash Conversion Cycle (CCC) = DIO + DSO - DPO. DIO (days inventory outstanding) = Inventory × 365 / COGS. DSO (days sales outstanding) = AR × 365 / Revenue. DPO (days payable outstanding) = AP × 365 / COGS. CCC < 0: Amazon, Walmart — получают деньги от клиентов до оплаты поставщикам. | Снижение CCC на 1 день: при $1B revenue = высвобождение $2.7M кэша. |
| corpfin.ops.interest_rate_swap | Interest Rate Swap — Structure | METHOD | Процентный своп (IRS): обмен фиксированного процента на плавающий (LIBOR/SOFR) или наоборот. Notional amount: номинал (не обменивается). Payer swap: платить fixed, получать floating. Receive swap: получать fixed, платить floating. Hedge: floating rate debt + receive-fixed IRS = synthetic fixed rate. ISDA Master Agreement: стандартный договор. | LIBOR phase-out (2023): замена на SOFR (Secured Overnight Financing Rate). |
| corpfin.ops.black_scholes_options | Options Pricing — Black-Scholes | METHOD | Формула Блека-Шоулза: C = S×N(d1) - K×e^(-rT)×N(d2). d1 = (ln(S/K) + (r + σ²/2)×T) / (σ×√T). d2 = d1 - σ×√T. Variables: S (spot), K (strike), r (risk-free), T (time), σ (volatility). Greeks: Delta (∂C/∂S), Gamma, Theta, Vega, Rho. | Implied volatility: обратное решение B-S для известной рыночной цены опциона. |
| corpfin.ops.financial_ratios_profitability | Financial Ratios — Category | METHOD | Финансовые коэффициенты: Рентабельность: Gross Margin = (Revenue - COGS)/Revenue, Operating Margin = EBIT/Revenue, Net Margin = NI/Revenue, ROE = NI/Equity, ROA = NI/Assets. Ликвидность: Current Ratio = CA/CL (>2.0), Quick Ratio = (CA-Inventory)/CL (>1.0). Долг: D/E = Total Debt/Equity, Interest Coverage = EBIT/Interest. | Leverage: Interest Coverage <3× = high risk of default. |
| corpfin.ops.equity_research_report | Equity Research — Analyst Report | METHOD | Аналитический отчёт по акциям: Investment Thesis: 1-2 предложения. Valuation: DCF + Comps (EV/EBITDA, P/E). Risk factors. Target price. Rating: Buy, Hold, Sell (или Outperform, Neutral, Underperform). Comps analysis: выбрать 5-10 comparable companies. EV/EBITDA multiple: сравнить с Peers. Sum-of-the-parts (SOTP): конгломераты. | Sell-side analyst conflicts: инвестиционный банкинг давит на «Buy» рейтинги. |
| corpfin.ops.treasury_cash_management | Corporate Treasury — Cash Management | METHOD | Управление денежными средствами: Cash pooling (notional или физическое): объединение счетов группы. Target balance: min/max limits per account. Investment policy: короткосрочные инструменты (T-Bills, MMF, CP). FX exposure: balance sheet hedge vs cash flow hedge. Bank Relationship Management. KPIs: cash forecast accuracy, cost of borrowing. | Repatriation risk: заблокированный кэш в странах с ограничениями. |
| corpfin.ops.deferred_revenue_analysis | Accounting — Deferred Revenue | METHOD | Отложенная выручка (Deferred Revenue): получены деньги до оказания услуги. Признание: по мере оказания услуги. SaaS: ежемесячное/квартальное признание. Booking vs Revenue: booking = новый контракт. Billings vs Revenue: billing = выставлен счёт. ARR (Annual Recurring Revenue): SaaS метрика. NRR (Net Revenue Retention): >100% = рост внутри клиентской базы. | High deferred revenue = future revenue visibility (bullish signal для SaaS). |
| corpfin.ops.impairment_test_goodwill | Goodwill — Impairment Testing | METHOD | Тест на обесценение гудвила: ASC 350 (US GAAP), IAS 36 (IFRS). Ежегодно: сравнить fair value of reporting unit с carrying value. Если fair value < carrying value → impairment loss = difference (limited to goodwill balance). Qualitative assessment (Step 0): можно пропустить количественный если «more likely than not» не impaired. | Крупные impairment charges (AT&T $45B в 2022): часто признак дорогого acquisitions. |
| corpfin.ops.leveraged_finance_covenants | Leveraged Finance — Covenants | METHOD | Ковенанты при синдицированном кредите: Maintenance covenants (incurrence for bonds): Leverage ratio, Interest Coverage, Fixed Charge Coverage, Min EBITDA. Incurrence covenants (high yield): триггерируются только при новом действии (новый долг, дивиденды). Springing covenants: только при определённых условиях. EBITDA adjustments: «add-backs» (спорные). | Covenant holiday: во время COVID компании получали «holiday» (suspended maintenance tests). |
| corpfin.ops.financial_modeling_best | Financial Modeling — Best Practices | METHOD | Лучшие практики финансового моделирования: Structure: clear assumptions, formula-driven, consistent formatting. Hard-coded numbers: только в assumption section (синий шрифт). Formulas: только в formula cells (чёрный). Error checks: balance sheet checks ($0 = balanced), circular reference. Scenario manager. Version control. CFA Institute: модельный анализ. | Hardcoding in formulas: неисправимая ошибка моделирования. |
| corpfin.ops.venture_capital_metrics | Venture Capital — Key Metrics | METHOD | Метрики венчурного капитала: IRR: внутренняя норма доходности. MOIC (Multiple of Invested Capital): возврат × в 2.5-5× (target). TVPI (Total Value to Paid-In): unrealized + realized / paid-in. DPI (Distributions to Paid-In): реальные выплаты. PME (Public Market Equivalent): сравнение с публичным рынком. J-curve: отрицательный IRR в первые годы. | VC fund J-curve: первые 2-3 года negative (инвестируем, нет exits). |
