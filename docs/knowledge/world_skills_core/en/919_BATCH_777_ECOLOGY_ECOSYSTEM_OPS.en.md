| ecology.ops.population_growth_models | Population Growth — Logistic Model | METHOD | Модели роста популяций: Экспоненциальный: dN/dt = rN (неограниченные ресурсы). Логистический (Verhulst): dN/dt = rN(K-N)/K. K = ёмкость среды (carrying capacity). S-кривая. r-стратеги vs K-стратеги: r = высокое r, много потомков, нестабильные среды. K = низкое r, мало потомков, стабильные среды. Демографический momentum. | Allee effect: при малой популяции r снижается → коллапс (не логистический). |
| ecology.ops.food_web_trophic | Food Web — Trophic Levels | METHOD | Пищевые сети: производители (P) → первичные потребители (C1) → вторичные (C2) → третичные (C3). Правило 10%: только 10% энергии передаётся на следующий уровень. Биомасса пирамиды. Трофический каскад: хищники контролируют растительноядных (Yellowstone wolves → elk → vegetation). Omnivory: связи между уровнями. | Keystone species: несоразмерно большое влияние (sea otters → urchins → kelp). |
| ecology.ops.nitrogen_cycle | Nitrogen Cycle — Microbe Roles | METHOD | Круговорот азота: Fixation: N2 → NH3 (Rhizobium, Azotobacter, Cyanobacteria). Nitrification: NH3 → NO2 → NO3 (Nitrosomonas, Nitrobacter). Denitrification: NO3 → N2 (Pseudomonas, анаэробные). Assimilation: растения поглощают NH4+ и NO3−. Ammonification: органика → NH3 (гетеротрофы). | Антропогенное нарушение: синтетические удобрения → избыток N → эвтрофикация. |
| ecology.ops.biodiversity_indices | Biodiversity — Simpson's Index | METHOD | Индексы биоразнообразия: Richness (S): число видов. Shannon-Wiener (H'): H' = -Σpᵢ ln(pᵢ). Simpson's (D): D = 1 - Σ(nᵢ(nᵢ-1)/(N(N-1))). Equitability (Evenness): E = H'/ln(S). Alpha diversity: внутри участка. Beta diversity: разница между участками. Gamma: тотальное региональное. | Shannon index: чувствителен к редким видам. Simpson's: чувствителен к доминантным. |
| ecology.ops.invasive_species | Invasive Species — Impact | METHOD | Инвазивные виды: характеристики: быстрое размножение, широкая толерантность, эффективное распространение. Mechanisms of invasion success: enemy release hypothesis (без естественных врагов), empty niche, novel weapon. Воздействие: конкуренция, хищничество, гибридизация, болезни. Управление: biocontrol, mechanical, chemical. | Zebra mussels (Dreissena): Great Lakes — фильтруют фитопланктон → изменение пищевой цепи. |
| ecology.ops.island_biogeography | Island Biogeography — MacArthur Wilson | METHOD | Теория островной биогеографии (MacArthur & Wilson, 1967): видовое богатство = баланс иммиграции и вымирания. Большой остров: высокое vidovoe богатство (больше microhabitat). Близкий к материку: высокая иммиграция. Species-area: S = cA^z (z≈0.25-0.35). Equilibrium theory: динамическое равновесие. | Reservation design (SLOSS): применение к заповедникам → fragment size critical. |
| ecology.ops.succession_primary | Ecological Succession | METHOD | Экологическая сукцессия: первичная (primary): голая скала/земля. Пионерные виды (лишайники, мхи) → трава → кустарник → лес. Вторичная (secondary): быстрее (есть почва). Climax community: устойчивое конечное состояние (спорная концепция). Facilitation vs Tolerance vs Inhibition: механизмы смены видов. | Сукцессия после вулкана (Krakatoa): наблюдение восстановления биоразнообразия. |
| ecology.ops.eutrophication | Eutrophication — Process | METHOD | Эвтрофикация водоёмов: избыточные питательные вещества (N, P) → бурное размножение водорослей (algal bloom) → отмирание водорослей → бактериальное разложение → потребление О2 (hypoxia) → гибель рыбы. Лимитирующий ресурс: Р в пресных водах, N в морских. Мёртвые зоны (dead zones): Gulf of Mexico. | Phosphorus loading: сельское хозяйство → поверхностный сток → озёра. |
| ecology.ops.keystone_engineer | Ecosystem Engineers — Beaver | METHOD | Инженеры экосистем (Ecosystem Engineers): виды, существенно изменяющие физическую среду. Бобёр: строит плотины → водоёмы → увлажнение → изменение видового состава. Earthworms (Lumbricus): изменяют почвенную структуру. Elephants: создают просеки в лесах → мозаика сред. Facilitator: создаёт условия для других видов. | Elaphants «engineers of the savanna»: поддерживают открытые пространства. |
| ecology.ops.carbon_cycle | Carbon Cycle — Anthropogenic | METHOD | Круговорот углерода: фотосинтез (атмосфера → биота), дыхание (биота → атмосфера), разложение, сжигание ископаемого топлива. Резервуары (Gt C): Атмосфера 830, Океан 37 000, Почва 1 500, Биота 550. Антропогенные выбросы: ≈10 Гт C/год. Океан + суша поглощают ≈50%. Net в атмосферу: ≈5 Гт/год. | Почвенный углерод: самый большой наземный запас. Деградация почв → выброс. |
| ecology.ops.metapopulation | Metapopulation Theory — Levins | METHOD | Метапопуляционная теория (Левинс, 1969): сеть субпопуляций на разных участках (patches). Локальное вымирание компенсируется реколонизацией. Занятость патчей: dp/dt = cp(1-p) - ep. При E > C: вымирание. Incidence function model: Hanski. Применение: проектирование коридоров для связи. | Метапопуляция видов с ограниченной дисперсией: без коридоров = фрагментация → вымирание. |
| ecology.ops.remote_sensing_ndvi | Remote Sensing — NDVI | METHOD | Дистанционное зондирование Земли: NDVI (Normalized Difference Vegetation Index): (NIR - Red) / (NIR + Red). NDVI -1 до +1. Отрицательный: вода, снег. 0-0.3: голая почва. 0.3-0.6: умеренная растительность. >0.6: густая. Landsat, Sentinel-2, MODIS. GEE (Google Earth Engine): анализ временных рядов. | NDVI trend: снижение во времени → деградация экосистемы. |
| ecology.ops.habitat_fragmentation | Habitat Fragmentation — Effects | METHOD | Фрагментация местообитаний: разделение непрерывного местообитания → острова. Края (edges): другая среда на границе → edge effect (уязвимость). Area effects: меньше видов. Isolation: снижение dispersal. Road mortality. Minimum viable population (MVP). Wildlife corridors: соединить фрагменты. | Edge effect: больше на малых фрагментах → «все edge и нет core». |
| ecology.ops.trophic_cascade | Trophic Cascade — Wolf Reintroduction | METHOD | Трофический каскад (Yellowstone wolves): Wolves (1995 возвращение) → снизили elk feeding behaviour (fear) → восстановление кустарников и деревьев вдоль рек → стабилизация берегов → beavers → влажные местообитания. Lethal vs behavioural effects. Top-down vs bottom-up control. | «Landscape of fear»: хищники изменяют поведение жертв → изменение пастбищных режимов. |
| ecology.ops.community_competition | Community Ecology — Competitive Exclusion | METHOD | Конкурентное исключение (Gause): два вида с одинаковой экологической нишей не могут сосуществовать. Coexistence mechanisms: niche partitioning (разделение ресурсов), keystone predation, temporal partitioning. Resource ratio hypothesis (Tilman): разные виды доминируют при разных соотношениях ресурсов. | Разнообразие поддерживается нарушениями (intermediate disturbance hypothesis). |
| ecology.ops.fire_ecology | Fire Ecology — Role | METHOD | Роль пожара в экосистемах: «естественный нарушитель». Fire-adapted species: пироколлекторы (lodgepole pine, eucalyptus). Nutrient cycling: удаляет накопившиеся отмершие ткани → высвобождает питательные вещества. Chaparral: обязан пожарам. Fire suppression: накопление топлива → крупные катастрофические пожары. | Prescribed burning: намеренные контролируемые пожары → снижение катастрофического риска. |
| ecology.ops.soil_ecology | Soil Ecology — Food Web | METHOD | Почвенная экология: почвенная пищевая сеть. Производители → бактерии/грибки (сапрофиты) → простейшие/нематоды → коллемболы/клещи → хищные членистоногие. Mycorrhizae: взаимосимбиоз (ECM, AM). Decomposition rates: зависит от температуры, влажности, C:N соотношения. | Earthworm biomass: индикатор здоровья почвы. В здоровой почве = 1-2 т/га (живой вес). |
| ecology.ops.phenology_climate | Phenology — Climate Change | METHOD | Фенология (временные паттерны биологических событий): Spring phenology advancing: +/6 дней/decade. Mismatches: птицы прилетают, но гусеницы уже отложены → снижение репродуктивного успеха (great tit vs winter moth). Длина вегетационного сезона. Cherry blossom Japan: proxy data для температуры. | Frog calls и дата появления butterflies: populationlevel phenological indicators. |
| ecology.ops.pollution_bioaccumulation | Bioaccumulation — Biomagnification | METHOD | Биоакккумуляция и биомагнификация: жирорастворимые загрязнители (ДДТ, ПХБ, ртуть). Bioaccumulation: накопление в организме. Biomagnification: концентрация увеличивается в пищевой цепи. ДДТ: планктон → рыба → хищники (орёл) → 10⁶× концентрация. DDT + eggshell thinning: снижение популяций птиц. | Biomagnification: Hg в тунце → Mercury Advisory (беременным ограничить). |
