| solarpv.ops.panel_efficiency_types | Panel Efficiency — Technology Types | METHOD | Типы солнечных панелей: Monocrystalline (22-24% eff.): высокоэффективный, занимает меньше места, дороже. Polycrystalline (17-19%): дешевле, менее эффективный. Thin-film (CdTe, CIGS, a-Si): 10-16%, гибкие, хорошо при диффузном свете. Bifacial: улучшенная производительность при отражении от поверхности (+5-30% albedo). HJT (Heterojunction): 24%+, низкий temperature coefficient. | Temperature coefficient (Pmax): -0.35%/°C monocrystalline. При 50°C → -10% vs STC. |
| solarpv.ops.string_sizing | String Sizing — Voc & Vmp | METHOD | Размер строки (string): Voc (Open Circuit Voltage) × N modules < inverter Vmax. Vmp × N modules > inverter Vstart. Temperature correction: Voc увеличивается при низкой T (T coeff ≈ -0.3%/°C). Min string voltage в coldest day: Voc(coldest) = Voc(STC) × (1 + |Tcoeff| × (Tmin - 25)). Max modules per string: floor(Vmax_inv / Voc(coldest)). Min modules: ceil(Vstart_inv / Vmp(hottest)). | NEC 690.7: Voc × 1.25 safety factor для wiring rating. |
| solarpv.ops.shading_analysis | Shading — Impact & Mitigation | METHOD | Затенение: одна заштренённая панель снижает весь string (при series connection). Bypass diodes: встроены в панель (каждые 1/3 панели) — ограничивают потери. Module level power electronics (MLPE): microinverters или DC optimizers (SolarEdge, Enphase) — каждый модуль независим. Shading threshold: <20% shading on 5% of array = acceptable for standard systems. PVsyst shading analysis. | Chimney, HVAC, tree shadows: анализировать annual shading losses (Winter = worse). |
| solarpv.ops.mppt_operation | MPPT — Maximum Power Point Tracking | METHOD | MPPT (Maximum Power Point Tracking): алгоритм отслеживает максимальную точку мощности I-V кривой. Методы: Perturb & Observe (P&O), Incremental Conductance. Efficiency: 99%+ у современных инверторов. Rapid shutdown (NEC 690.12): система снижает напряжение на модуле при аварии. Ground fault protection (GFPD): мониторинг тока на землю. | I-V curve tracing: инструмент для диагностики (отклонение от STC curve = дефект). |
| solarpv.ops.battery_chemistry_storage | Battery Chemistry — Solar Storage | METHOD | Аккумуляторы: Lead-acid (flooded, AGM, Gel): дешёвый, 50-80% DoD (Depth of Discharge). LFP (Lithium Iron Phosphate): безопасный, 80-100% DoD, cycle life 3000-6000. NMC (Lithium Nickel Manganese Cobalt): энергоплотный, более нестабильный. Sizing: usable capacity (kWh) = load × autonomy days / DoD. C-rate: C/20 = 20-часовой разряд. | LFP: предпочтительный для residential (Tesla Powerwall, Enphase IQ Battery). |
| solarpv.ops.inverter_types | Inverter Types — String vs Micro | METHOD | String inverter: одна unit на весь array (или несколько strings). Простой, дешевле, один MPP. Disadvantage: shading/mismatch affects all. Microinverter (Enphase): один на каждый модуль — независимый MPPT, мониторинг, no high DC voltage. Power optimizer (SolarEdge): DC-DC converter per module + string inverter. Hybrid inverter: battery + grid + solar management. | String inverter lifetime: 10-15 лет (vs panel 25 лет). Замена ≥1 раз за срок панелей. |
| solarpv.ops.soiling_degradation | Soiling & Degradation — Maintenance | METHOD | Загрязнение панелей (soiling): пыль, птичий помёт, листья снижают output 1-10% (сухой климат: хуже). Cleaning: деминерализованная вода + мягкая щётка (утром/вечером — не горячие панели). Degradation rate: LID (Light Induced Degradation, первый год -0.5-1%), annual degradation -0.5%/год (monocrystalline). 25-year warranty: обычно 80% nominal power. | PAN файлы PVsyst: моделирование с degradation. |
| solarpv.ops.grid_tie_protection | Grid-Tie — Anti-Islanding | METHOD | Сетевая инвертор (grid-tie): защита от изолирования (anti-islanding). IEEE 1547: при потере сети — инвертор отключается в 2 сек. Islanding: инвертор продолжает работать при отключённой сети (опасность для ремонтных бригад). Active anti-islanding: frequency shift, phase shift. Interconnection agreement: utility approval required. Net metering: продажа излишков в сеть. | Smart inverter (Rule 21, IEEE 1547-2018): volt-var control, voltage ride-through. |
| solarpv.ops.off_grid_sizing | Off-Grid — Autonomy Sizing | METHOD | Автономная система: суточная потребность (Wh) / PSH (Peak Sun Hours) = PV array Wp. Battery: суточная нагрузка × autonomy days / DoD / system efficiency. Charge controller: MPPT (15-30% energy gain vs PWM). Temperature correction: battery derating в холоде. Load analysis: AC + DC loads, efficiency of inverter (90-95%). Backup generator: для low-sun periods. | PSH (Peak Sun Hours): среднее количество часов при 1000 Вт/м² в день (по региону, PVWatts). |
| solarpv.ops.arc_flash_dc_hazard | DC Arc Flash — Safety | METHOD | Дуговой разряд в DC цепях: DC arc не гасится самостоятельно (переменный ток гасится при переходе через ноль). Opасность: V × I — при 600 VDC высокая. NEC 690.12: rapid shutdown. NFPA 70E: arc flash hazard assessment для PV системы. PPE: arc-rated при работе с DC > 50V. Disconnect: at array combiner box and inverter. | Пожаротушение: не вода на PV панели под напряжением (проводит электричество к шлангу). |
| solarpv.ops.roof_structural_assessment | Rooftop Solar — Structural Load | METHOD | Структурная нагрузка от PV: добавляемая нагрузка — 10-20 кг/м² (стандартная система). Rooftop check: кровля должна выдерживать дополнительную постоянную нагрузку (dead load). Engineering assessment: для >25 лет зданий или спорных конструкций. Wind uplift: attachment pattern (zones — edge, corner zone имеют 2-3× нагрузки). Anchor: rafter/purlin attachment (не к обшивке). | Building permit: требует structural report для коммерческих и часто residential. |
| solarpv.ops.thermal_management_module | Thermal Management — Module Temp | METHOD | Температура модуля: NOCT (Nominal Operating Cell Temperature): 44-48°C при 800 Вт/м², 20°C air, 1 м/с ветер. Cell temperature = Tamb + NOCT-20 × Irradiance/800. Mounting: flush rooftop vs elevated (standoff): flush = +10-15°C vs air-cooled. Backside ventilation: снижает temperature → улучшает performance. | Bifacial panels: elevated mounting лучше (backside irradiance + cooling). |
| solarpv.ops.monitoring_system | Monitoring — Production Tracking | METHOD | Мониторинг солнечной системы: production (kWh), specific yield (kWh/kWp), PR (Performance Ratio = E_actual/E_theoretical). Alerts: Production below threshold, grid failure, inverter fault. Platforms: SolarEdge, Enphase, Fronius Solar. Weather compensation: normalize по irradiance. Degradation tracking: year-over-year specific yield decline. | PR >80%: хорошая система. PR <75%: исследовать причины (soiling, shading, MPPT fault). |
| solarpv.ops.commissioning_testing | PV Commissioning — Tests | METHOD | Ввод в эксплуатацию PV системы: Polarity check (Voc полярность каждой string). Voc measurement (каждый string): сравнить с ожидаемым. Isc measurement. I-V curve tracing. Insulation resistance (Megger): >1 МОм. GFPD test. Inverter startup: check LCD/monitoring display. Ground continuity. Final: witness производительности при sunshine (compare to calculated). | IEC 62446-1: стандарт commissioning и документации. |
| solarpv.ops.agrivoltaics | Agrivoltaics — Dual Land Use | METHOD | Агровольтаика: совместное использование земли для сельского хозяйства и солнечной генерации. Spacing: поднятые конструкции (2-4 м высота) позволяют трактору. Crops: оптимально для культур с shade tolerance (lettuce, herbs, berry). Water use: снижение эвапотранспирации под панелями (-20-50%). Bifacial panels: двусторонний свет. | Нидерланды/Германия: государственная поддержка agrivoltaics. |
| solarpv.ops.floating_solar | Floating Solar — Design Considerations | METHOD | Плавучая солнечная электростанция (FPV): на водоёмах (резервуары, карьерные озёра, рисовые поля). Преимущества: снижение испарения воды (-30%), охлаждение панелей (более высокая выработка vs ground-mount +5-10%). Challenges: коррозия (морская вода), якорная система, кабели. Pontoon material: HDPE float. EMF: подводные кабели. | Бангладеш, Нидерланды: крупнейшие мировые проекты FPV (0.1-500 МВт). |
| solarpv.ops.perc_topcon_technology | PERC vs TOPCon — Cell Technology | METHOD | PERC (Passivated Emitter and Rear Cell): passivation слой на задней стороне → снижение рекомбинации. Текущий mainstream. TOPCon (Tunnel Oxide Passivated Contact): тонкий oxide туннель + poly-Si layer. Более высокая эффективность (24-25%), быстро захватывает рынок (2024+). HJT: аморфный кремний → 24-26%, лучший температурный коэф. IBC (Interdigitated Back Contact): все контакты на задней стороне → 24%+. | Рыночный тренд 2025-2026: TOPCon заменяет PERC как standard. |
| solarpv.ops.bifacial_gain_calculation | Bifacial Gain — Calculation | METHOD | Бифациальный коэффициент выработки: Bifacial Gain (%) = backside irradiance × bifaciality factor / frontside irradiance. Bifaciality factor: 0.65-0.80 (зависит от ячейки). Ground reflectance (albedo): белый гравий/снег 0.8, трава 0.2. Elevation: чем выше от земли — тем больше backside irradiance. PVsyst bifacial module. | Bifacial gain +5-15%: важно учитывать при финансовом моделировании. |
| solarpv.ops.pv_degradation_lid | LID — Light Induced Degradation | METHOD | LID (Light Induced Degradation): в первые несколько дней облучения при high carrier injection → образование boron-oxygen complexes → снижение Voc, FF, power. Стандартные p-type mono/poly: LID 1-3%. Уменьшение: gallium-doped p-type: минимальный LID. TOPCon/HJT (n-type base): нет LID. LeTID (Light and Elevated Temperature Induced Degradation): при 50-75°C. | Первые данные мониторинга: дать 2-4 недели после commissioning для стабилизации LID. |
| solarpv.ops.solar_resource_assessment | Solar Resource — GHI, DNI, DHI | METHOD | Солнечный ресурс: GHI (Global Horizontal Irradiance) = сумма DNI + DHI. DNI (Direct Normal Irradiance): прямой пучковый свет (важен для CPV, CSP). DHI (Diffuse Horizontal Irradiance): рассеянное. TMY (Typical Meteorological Year): статистический репрезентативный год. Sources: NASA POWER, PVGIS, SolarAnywhere, Meteonorm. P50/P90: вероятностные сценарии для финансирования (P90 = консервативный). | P50 производительность: 50% вероятность достижения. P90: 90% вероятность. |
