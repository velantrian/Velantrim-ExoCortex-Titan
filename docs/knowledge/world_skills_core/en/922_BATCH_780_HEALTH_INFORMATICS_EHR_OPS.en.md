# BATCH 780: Health Informatics — EHR & Clinical Systems

| ID | KnowledgeUnit | Тип | Суть | Практический смысл |
|---|---|---|---|---|
| healthit.ops.ehr_implementation | EHR Implementation — Phases | METHOD | Внедрение EHR (Electronic Health Record): Планирование (governance, stakeholder analysis, vendor selection, go-live date). Дизайн (workflow redesign, build configuration, content development). Обучение (user training, super-users). Тестирование (integrated testing, user acceptance). Переход (go-live, at-elbow support). Оптимизация (post-live improvement). | Big bang go-live vs Phased: Big bang = единовременно, рискованнее. |
| healthit.ops.hl7_fhir | FHIR — HL7 Standard | METHOD | FHIR (Fast Healthcare Interoperability Resources): стандарт обмена медицинскими данными. Resources: пациент (Patient), врач (Practitioner), медикамент (Medication), наблюдение (Observation). REST API: GET/POST/PUT/DELETE. JSON/XML форматы. SMART on FHIR: OAuth2 для EHR-приложений. US Core profiles: минимальные требования для USA. | FHIR R4: последняя стабильная версия (2019). R5 = в разработке. |
| healthit.ops.cds_hooks | CDS — Clinical Decision Support | METHOD | Система поддержки клинических решений (CDS): passive (alerts, reminders) vs active (mandatory confirmation). CDS Hooks: открытый стандарт для FHIR-based CDS. Alert fatigue: слишком много алертов → игнорирование. Informatics principle: «Only fire when actionable». Drug-Drug interactions: основное применение. Best Practice Advisories (BPA): настраиваемые в Epic/Cerner. | Alert fatigue: 95%+ overridden алертов = неэффективность системы. |
| healthit.ops.hipaa_privacy_rule | HIPAA — Privacy & Security | METHOD | HIPAA Privacy Rule: Protected Health Information (PHI) — 18 идентификаторов. Разрешённое использование: лечение, оплата, операции. Authorization required: маркетинг, исследования (за исключениями). Minimum Necessary standard: только необходимая информация. Security Rule: Administrative, Physical, Technical safeguards. Breach notification: 60 дней. | De-identification: Safe Harbor (18 identifiers removed) или Expert Determination. |
| healthit.ops.interoperability_levels | Interoperability — Levels | METHOD | Уровни интероперабельности (HIMSS): Foundational: data exchange without interpretation. Structural: format and syntax defined (HL7 v2). Semantic: common underlying models/codebooks (SNOMED, LOINC, RxNorm). Organizational: policy, governance, social. TEFCA (USA): Trusted Exchange Framework and Common Agreement. | Semantic interoperability требует: стандартизированные коды (LOINC для лабораторий, RxNorm для медикаментов). |
| healthit.ops.cpoe_medication_safety | CPOE — Medication Safety | METHOD | Компьютерный ввод врачебных назначений (CPOE): электронное назначение vs бумажное. Преимущества: снижение ошибок транскрибирования, drug-drug interactions проверка, dosing alerts. Five Rights check: Right patient, drug, dose, route, time. Pharmacy verification. Barcoding at bedside (BCMA): последний барьер перед введением. | BCMA снижает medication errors на 83% (Barker study, 2003). |
| healthit.ops.health_analytics_real_world | Health Analytics — Real-World Data | METHOD | Аналитика здоровья: Real-World Data (RWD): EHR, claims, patient-reported, device data. Real-World Evidence (RWE): выводы из RWD. Comparative effectiveness research. NLP: извлечение структурированных данных из клинических заметок. Readmission prediction: ML модели (LACE score). | SDoH (Social Determinants of Health): интеграция в аналитику предиктивного риска. |
| healthit.ops.telemedicine_platform | Telehealth — Regulatory Framework | METHOD | Телемедицина: Synchronous vs Asynchronous. Store-and-Forward: изображения/данные без синхронного контакта. Remote Patient Monitoring (RPM): хронические заболевания. Licensure: большинство штатов требуют лицензию в штате пациента. Prescribing: Ryan Haight Act (controlled substances). Reimbursement: Medicare, Medicaid coverage (COVID expanded). | Post-COVID: телемедицина = mainstream (10× рост). Нормализация регулирования. |
| healthit.ops.health_data_standards | Clinical Terminologies — SNOMED | METHOD | Медицинские терминологии: SNOMED CT: клинические концепты (350 000+ активных концептов). LOINC: лабораторные тесты + наблюдения. RxNorm: препараты. ICD-10-CM: диагнозы. CPT: процедуры (USA billing). NDC (National Drug Code): уникальный код лекарств. Value Sets: подмножества терминологии для конкретных целей. | ICD-11 (WHO): переход с 2022 globally (ICD-10-CM в USA пока основной). |
| healthit.ops.usability_ehr_burden | EHR Usability — Physician Burnout | METHOD | Удобство EHR: Physician burnout связан с EHR burden. Time in EHR: врачи тратят >2 ч в EHR на 1 ч клиники. «Pajama time»: работа дома после смены. Inbasket overload: слишком много сообщений. Solutions: scribes, AI ambient clinical documentation (Suki, Nuance DAX), reduced clicks. | Time on EHR documentation: 49% рабочего времени physicians (Arndt study, JAMA 2017). |
| healthit.ops.health_information_exchange | HIE — Types | METHOD | Обмен медицинской информацией (HIE): Directed Exchange: отправка к известному получателю. Query-Based Exchange: запрос к неизвестному источнику. Consumer-Mediated Exchange: пациент контролирует. Commonwell Health Alliance, Carequality: крупнейшие HIE Networks. Fast Healthcare Interoperability. | Одна из проблем: patient matching без единого ID (USA нет национального идентификатора). |
| healthit.ops.clinical_workflow_redesign | Workflow Redesign — EHR | METHOD | Перепроектирование рабочих процессов: EHR не должен просто автоматизировать «плохой» процесс. Current state map → waste identification → future state. Epic's PocketList vs Cerner's Organizer. Role-specific workflows: Physician vs Nurse vs Pharmacist. Training for workflow, not just system clicks. | Change management: самый сложный аспект EHR-внедрения. Resistance to change. |
| healthit.ops.ai_natural_language | Clinical NLP — Information Extraction | METHOD | Медицинские NLP: Named Entity Recognition (NER): диагнозы, лекарства, симптомы. Relation Extraction. Negation detection: «no chest pain» ≠ chest pain. De-identification: HIPAA compliance. Pre-trained models: BioBERT, ClinicalBERT. Ambient AI documentation: Nuance DAX, Suki. UCSF NLP study: depression detection from EHR notes. | Structured vs Unstructured EHR: 80% данных = неструктурированный текст (notes, reports). |
| healthit.ops.population_health_management | Population Health — Platform | METHOD | Управление здоровьем популяций: Risk stratification: низкий / средний / высокий риск. Care management programs: для высокого риска. Preventive care gaps: missed screenings, immunizations. Social determinants screening (PRAPARE, SDOH). CHW (Community Health Worker): интервенции. Value-based care (VBC): оплата за результаты. | PCMH (Patient-Centered Medical Home): модель для population health в первичной помощи. |
| healthit.ops.digital_health_fda | Digital Health — FDA Regulation | METHOD | Регулирование цифровых медицинских приложений (FDA): De Novo, 510(k), PMA: зависит от класса. Software as Medical Device (SaMD): IMDRF guidance. Digital Health Center of Excellence (FDA). AI/ML-based SaMD: predetermined change control plan. DSCSA (Drug Supply Chain Security Act): blockchain для лекарств. | FDA cleared vs approved: SaMD может быть cleared (510k) без clinical trial. |
| healthit.ops.remote_monitoring_rpm | Remote Patient Monitoring — Implementation | METHOD | Удалённый мониторинг пациентов (RPM): устройства (BP cuff, glucometer, pulse ox, weight scale, ECG patch). Data transmission: Bluetooth → смартфон → облако. Dashboard for clinicians. Thresholds → alerts. CMS CPT codes: 99453-99458 (reimbursement). Patient engagement: adherence challenge. | RPM для ХСН: снижение повторных госпитализаций на 25-35% (mHealth research). |
| healthit.ops.mhealth_app_evidence | mHealth — Evidence Grading | METHOD | Доказательная база мобильных приложений здоровья: 325 000+ health apps в stores. FDA-cleared: только небольшая часть. Evidence quality varies vastly. Evidence-based app criteria: randomized trials, peer-reviewed. IMS Institute: только 40% popular apps = evidence-based. OrCHA (Organisation for the Review of Care and Health Apps): evaluation. | Рекомендация: не использовать mHealth app без peer-reviewed evidence. |
| healthit.ops.health_data_governance | Health Data Governance — Framework | METHOD | Управление данными здоровья: Data Governance Office (DGO). Data Stewards: ответственность за quality и access. Data Quality dimensions: completeness, accuracy, timeliness, consistency. Master Data Management (MDM): единый источник truth. Data catalog: inventory of datasets. Enterprise Information Management. | Data quality in EHR: «Garbage In, Garbage Out» = неверные аналитические выводы. |
| healthit.ops.precision_medicine | Precision Medicine — Genomics | METHOD | Точная медицина: правильное лечение + правильный пациент + правильное время. NGS (Next-Generation Sequencing): геном + транскриптом. Pharmacogenomics (PGx): CYP450 → предсказание лекарственного метаболизма. eMERGE Network: EHR + геномика. ALL of US (NIH): 1 миллион+ участников. ClinVar: клинически значимые варианты. | PGx в клинике: warfarin дозирование (CYP2C9 + VKORC1). |
