| medicine.pharmacology.adme | ADME — Pharmacokinetics | INVARIANT | Абсорбция (всасывание: биодоступность F=AUC_oral/AUC_iv), Распределение (V_d = доза/C₀, жирорастворимость), Метаболизм (печень: фаза I — Cyt P450 окисление/восстановление; фаза II — конъюгация), Экскреция (почки: клубочковая фильтрация + канальцевая секреция/реабсорбция). | Почечная недостаточность → кумуляция препаратов, выводимых почками (коррекция дозы). Печёночная → осторожность с препаратами первого прохождения. |
| medicine.pharmacology.volume_distribution | Volume of Distribution | VARIANT | V_d = количество препарата в теле / концентрация в плазме. Низкое V_d (~3-5 л) — препарат в плазме (варфарин, связан с альбумином). Высокое V_d (>100 л) — накопление в тканях (дигоксин, хлорохин). | При передозировке: низкое V_d → гемодиализ эффективен. Высокое V_d → диализ бесполезен. |
| medicine.pharmacology.half_life | Drug Half-Life & Steady State | INVARIANT | t₁/₂ = 0.693·V_d/Cl. Постоянная концентрация (steady state) достигается через ~4-5 t₁/₂ при регулярном дозировании. Нагрузочная доза = C_target·V_d для быстрого достижения. | Амиодарон t₁/₂ = 25-110 дней → загрузка насыщением. Варфарин: задержка эффекта (не t₁/₂ препарата, а t₁/₂ факторов свёртывания). |
| medicine.pharmacology.therapeutic_index | Therapeutic Index | CONTROL | TI = TD₅₀/ED₅₀ (или LD₅₀/ED₅₀). Узкий терапевтический индекс (дигоксин, варфарин, литий, теофиллин, фенитоин, аминогликозиды) требует мониторинга концентрации. | Терапевтический лекарственный мониторинг (TDM): trough перед следующей дозой. |
| medicine.pharmacology.receptor_theory | Receptor Theory & Affinity | INVARIANT | Kd = [L][R]/[LR] — концентрация лиганда при 50% занятости рецепторов (мера аффинности). EC₅₀ — концентрация для 50% максимального эффекта. Эффективность (efficacy) — способность активировать рецептор (агонист). Потенция (potency) — доза для эффекта. Агонист, антагонист, частичный агонист, обратный агонист. | Морфин — полный агонист μ-опиоидных рецепторов. Бупренорфин — частичный агонист (эффект «потолка» — безопаснее при передозировке). Налоксон — антагонист (антидот). |
| medicine.pharmacology.g_protein | G-Protein Coupled Receptors (GPCR) | INVARIANT | 7-трансмембранных доменов. Gs (↑цАМФ), Gi (↓цАМФ), Gq (↑IP3/DAG → ↑Ca²⁺). ~35% всех лекарств действуют на GPCR. Десенситизация: фосфорилирование GRK → аррестин → интернализация. | β-блокаторы (Gi-связанные), антигистаминные H1 (Gq), опиоиды (Gi/Go). Тахифилаксия — быстрое снижение ответа при повторном введении (десенситизация). |
| medicine.pharmacology.enzyme_inhibitors | Enzyme Inhibition Types | VARIANT | Конкурентный (связывается в активном центре, V_max не меняется, K_m↑ — обратимо, статины: HMG-CoA редуктаза). Неконкурентный (аллостерический сайт, V_max↓, K_m не меняется). Неконкурентный необратимый (аспирин — ацетилирование COX, омепразол — ковалентно H⁺/K⁺-АТФазу). | АСЕ ингибиторы конкурентно блокируют ангиотензин-превращающий фермент. |
| medicine.pharmacology.antibiotics_cell_wall | Cell Wall Synthesis Inhibitors | METHOD | β-лактамы (пенициллины, цефалоспорины, карбапенемы): связывают пенициллин-связывающие белки (PBP), блокируют транспептидацию пептидогликана → автолиз. Гликопептиды (ванкомицин): связывают D-Ala-D-Ala → стерически блокируют. | Устойчивость: β-лактамазы (расщепляют кольцо), модификация PBP (MRSA — mecA ген → PBP2a), замена D-Ala-D-Ala на D-Ala-D-Lac (VRE — ванкомицин-резистентные энтерококки). |
| medicine.pharmacology.antibiotics_ribosome | Ribosome-Targeting Antibiotics | METHOD | 30S субъединица: тетрациклины (блок tRNA), аминогликозиды (ошибки трансляции → дефектные белки). 50S: макролиды, клиндамицин (блок туннеля выхода пептида), хлорамфеникол (пептидилтрансфераза), линезолид (блок инициации). Бактериальный рибосом — 70S (30S+50S), человеческий — 80S (селективность). | Аминогликозиды — бактерицидные (ошибки → мембранный коллапс). Ототоксичность/нефротоксичность (кумуляция в эндолимфе уха). |
| medicine.pharmacology.chemotherapy_principles | Chemotherapy Principles | METHOD | Алкилирующие агенты (циклофосфамид — сшивки ДНК), антиметаболиты (метотрексат — ингибитор DHFR → ↓синтез тимидилата; 5-FU), антимитотические (винкристин — ингибитор полимеризации тубулина, таксаны — стабилизация микротрубочек), ингибиторы топоизомеразы, таргетные (иматиниб — ингибитор BCR-ABL тирозинкиназы). | Принцип: максимально переносимая доза (убить максимальное число опухолевых клеток с допустимой токсичностью для здоровых). Резистентность: MDR1 (P-гликопротеин) выкачивает препарат. |
| medicine.pathology.cell_injury_reversible | Reversible Cell Injury | PROCESS | Клеточное набухание (↓АТФ → ↓Na⁺/K⁺-АТФаза → Na⁺ в клетку → вода осмотически). Жировая дистрофия (стеатоз печени при алкоголизме). Ультраструктурные изменения: набухание митохондрий и ЭПР, отрыв рибосом, пузырьки плазматической мембраны (blebbing). | Ключевые триггеры: гипоксия (↓окислительного фосфорилирования), токсины, свободные радикалы (АФК). Восстановление возможно при устранении причины. |
| medicine.pathology.cell_death_necrosis | Necrosis | PROCESS | Неконтролируемая гибель: набухание клетки, разрыв мембраны → выход содержимого → воспаление. Типы: коагуляционный (ишемия всех органов кроме мозга — денатурация белков), колликвационный (мозг — богат ферментами и жирами, разжижение), казеозный (туберкулёз — творожистый), жировой (панкреатит — липазы переваривают жир → омыление). | Инфаркт миокарда: коагуляционный некроз → воспаление → грануляционная ткань → рубец. Необратимость: дефицит АТФ → потеря кальциевого гомеостаза → активация фосфолипаз, протеаз, эндонуклеаз. |
| medicine.pathology.apoptosis_path | Apoptosis & Necroptosis | PROCESS | Апоптоз — программируемая смерть: сморщивание, конденсация хроматина, фрагментация ДНК (лестница 180-200 п.о. фрагментов), апоптотические тельца, фагоцитоз, НЕТ воспаления. Некроптоз (запрограммированный некроз): RIPK1/RIPK3/MLKL → пермеабилизация мембраны → выход содержимого → воспаление. | Физиологический апоптоз: эмбриогенез (исчезновение межпальцевых перепонок), менструация, удаление аутореактивных лимфоцитов. |
| medicine.pathology.thrombosis_virchow | Virchow's Triad & Thrombosis | INVARIANT | Триада Вирхова: повреждение эндотелия, стаз (застой) крови, гиперкоагуляция. Артериальный тромб (быстрый поток → «белый тромб» — тромбоциты + фибрин). Венозный (медленный поток → «красный тромб» — эритроциты + фибрин, хвост кометы). | ТЭЛА: тромб из глубоких вен ног (DVT) отрывается → лёгочная артерия. Профилактика: ранняя мобилизация, компрессионный трикотаж, НМГ. |
| medicine.pathology.atherosclerosis | Atherosclerosis | PROCESS | Повреждение эндотелия → окисление ЛПНП (oxLDL) → захват макрофагами через scavenger-рецепторы → пенистые клетки → жировые полоски → атероматозная бляшка (липидное ядро + фиброзная покрышка). Кальцификация. | Осложнения: разрыв бляшки → тромбоз → ОКС/инфаркт/инсульт. Статины стабилизируют покрышку (↓воспаление) помимо снижения холестерина. |
| medicine.pathology.inflammation_chronic | Chronic Inflammation | PROCESS | Персистенция стимула (>недель-месяцев). Инфильтрат: макрофаги, лимфоциты, плазматические клетки. Гранулематозное воспаление: эпителиоидные макрофаги + гигантские клетки + лимфоцитарный вал (туберкулёз, саркоидоз, болезнь Крона, инородное тело). Фиброз: TGF-β → пролиферация фибробластов → коллаген. | Хроническое воспаление → рак (гепатоцеллюлярная карцинома при гепатите B/C, аденокарцинома пищевода при рефлюксе Барретта, колоректальный рак при ВЗК). |
| medicine.pathology.neoplasia_characteristics | Neoplasia — Benign vs Malignant | VARIANT | Доброкачественные: дифференцированные клетки, медленный рост, капсула, нет инвазии/метастазов, суффикс «-ома». Злокачественные: анаплазия (дедифференцировка), быстрый рост, инвазия, метастазы (лимфогенные, гематогенные, имплантационные). | Опухолевый ангиогенез (VEGF) — опухоль >1-2 мм³ требует новообразования сосудов. Бевацизумаб — anti-VEGF антитело. |
| medicine.pathology.hypersensitivity_types | Hypersensitivity Reactions | PROCESS | Тип I (IgE, немедленный): тучные клетки → гистамин → анафилаксия. Тип II (антитело-опосредованная цитотоксичность): IgG/IgM против клеток → комплемент/ADCC → гемолитическая анемия. Тип III (иммунные комплексы): отложение в тканях → активация комплемента → васкулит (СКВ). Тип IV (клеточный, отсроченный, 48-72ч): T-клетки → активация макрофагов → гранулема (туберкулиновая проба, контактный дерматит). | Пенициллин: I тип (редко анафилаксия), II тип (гемолиз — редко), III (сывороточная болезнь), IV (сыпь — наиболее часто). |
