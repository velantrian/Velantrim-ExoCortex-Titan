| auto.ops.obd2_diagnostics | OBD-II Engine Diagnostics — Systematic Approach | METHOD | On-Board Diagnostics II: стандартный 16-pin разъём, протокол (CAN, ISO 9141, KWP2000). Systematic diagnostic: 1) Verify complaint (воспроизвести проблему), 2) Visual inspection (вакуумные шланги, электрические разъёмы, утечки масла/охлаждающей жидкости), 3) Scan tool (читать DTC — Diagnostic Trouble Codes + Freeze Frame — параметры в момент ошибки), 4) Live data (смотреть параметры датчиков в реальном времени: STFT/LTFT — short/long-term fuel trim ±10% норма, >±25% = проблема; O2 sensor voltage oscillates 0.1-0.9V), 5) Isolate (отключение подозрительных компонентов, проверка проводки), 6) Repair, 7) Clear DTC + drive cycle (проверка что code не возвращается). Priority: P0xxx (generic), P1xxx (manufacturer-specific). Symptoms: misfire (P0300-P0306), catalyst efficiency (P0420/P0430), O2 sensor (P0130-P0167), EVAP leak (P0440-P0457). | Самая частая ошибка: замена датчика по коду. Код P0420 «Catalyst below threshold» — НЕ значит что катализатор плохой. Чаще: утечка выхлопа до датчика, бедная смесь (vacuum leak), масло в цилиндрах. Диагностика от кода, не замена по коду. |
| auto.ops.brake_pad_replacement | Brake Pad Replacement — Procedure & Inspection | METHOD | Замена передних/задних колодок: 1) loosen lug nuts (не снимать колёса пока авто на земле), 2) поднять авто, установить на stands, 3) снять колесо, 4) снять суппорт (болты крепления, подвесить на крючке — не висеть на тормозном шланге!), 5) Сжать поршень суппорта (C-clamp или специальный инструмент — для задних с электростояночным тормозом нужен scan tool для отвода EPB), 6) снять старые колодки, 7) очистить bracket (проволочной щёткой, смазать направляющие high-temp grease — не на friction поверхности!), 8) установить новые колодки (если есть wear indicator — на внутреннюю колодку, обычно скоба), 9) установить суппорт, заменить hardware (скобы/пружины из комплекта), 10) повторить на другой стороне. После замены: прокачка тормозов? (если система не открывалась — нет, иначе да). Bedding-in: 5-10 плавных торможений с 50 до 10 км/ч (не останавливаться полностью!) для приработки колодок к дискам. | Минимальная толщина колодок: 2-3 мм (закон требует 1.6 мм в EU). Если меньше — замена немедленно. Индикатор износа (скоба) издаёт визг при торможении — НЕ игнорировать! Торможение на износ — повреждение тормозного диска → стоимость диска $80-200 vs колодки $30-60. |
| auto.ops.engine_oil_change | Engine Oil & Filter Change — Standard | METHOD | Замена масла: 1) прогреть двигатель 3-5 мин (масло текучее, примеси во взвеси), 2) поднять авто (ramps/stands — безопасность!), 3) снять сливную пробку (подставить ёмкость >5L), 4) пока сливается — открутить масляный фильтр (filter wrench, если руками не идёт), 5) смазать резиновое уплотнение нового фильтра свежим маслом, 6) закрутить фильтр от руки (НЕ ключом — перетяжка деформирует уплотнение), 7) закрутить сливную пробку с новой медной/алюминиевой шайбой, 8) залить новое масло (объём по спецификации, проверить щупом), 9) запустить двигатель — проверить давление масла (лампочка гаснет за 2-3 сек), 10) проверить под фильтром и пробкой на утечки. Интервал: mineral 5,000-7,500 км, synthetic 10,000-15,000 км (или по рекомендации производителя). Утилизация отработанного масла: сдать в пункт приёма (не в канализацию/почву — 1 литр отработанного масла загрязняет 1 млн литров воды). | Перетяжка фильтра — частая ошибка (затяжка ключом «до хруста» деформирует уплотнение → течь). Сливная пробка: момент затяжки 30-40 Нм (не больше — сорванная резьба в поддоне = замена поддона или helicoil). Масло-голодание: низкий уровень → масляный насос хватает воздух → масляное голодание → задир подшипников → капитальный ремонт. |
| auto.ops.ac_recharge_service | Automotive AC — Recharge & Diagnostics | METHOD | Диагностика автокондиционера: 1) Визуальный осмотр (компрессор включается? муфта щёлкает? вентилятор конденсатора работает? трубки — масляные пятна = утечка?), 2) Подключение манометрического коллектора (синий — низкое давление, красный — высокое), 3) Чтение давления при работающем компрессоре (R-134a: низкое 1.5-2.5 бар, высокое 14-20 бар при 25-30°C наружного воздуха; R-1234yf аналогично), 4) ΔT на выходе центральных дефлекторов: цель <10°C, хорошее 5-7°C. Если хладагента мало: утечка. Поиск утечки: electronic leak detector, UV dye + UV light, азот под давлением + мыльный раствор. Заправка по весу: указано на табличке под капотом (обычно 500-800 г). Не перезаправить! (высокое давление на высокой стороне, компрессор перегружен). PAG oil: компрессор требует масла; при замене компонента — добавить объём масла, соответствующий компоненту. | R-1234yf (GWP=4, vs R-134a GWP=1430) стал стандартом для новых авто с 2017 (EPA). Оборудование для R-1234yf — дороже (слабо flammable, нужен вентилируемый шкаф). Смешивать нельзя! (разные масла, разные фиттинги). |
| auto.ops.timing_belt_replacement | Timing Belt Replacement — Interference Engines | METHOD | Замена ремня ГРМ: critical процедура. Интерференционный двигатель: при обрыве ремня поршни сталкиваются с клапанами (зазор <2 мм при открытых клапанах) → клапаны гнутся, поршни/гильзы повреждаются → капитальный ремонт $3000-6000. Неинтерференционный: обрыв = двигатель глохнет без повреждений. Процедура: 1) снять навесное оборудование (генератор, насос ГУР, компрессор AC), 2) снять крышки ГРМ, 3) выставить коленвал и распредвал(ы) по меткам (timing marks), 4) ослабить натяжитель, 5) снять старый ремень, 6) критически: НЕ поворачивать коленвал и распредвал относительно друг друга!, 7) заменить водяной насос (помпу) если приводится ремнём ГРМ (доступ — пока ремень снят, помпа доступна, экономия $300-500 работы позже), 8) заменить натяжитель + обводные ролики, 9) установить новый ремень по меткам, 10) натянуть (натяжитель автоматический или динамометрический ключ для ручного), 11) провернуть коленвал вручную на 2 оборота — метки совпали? (если нет — переделать, не пытаться завести «авось»!). Интервал: 60,000-100,000 миль (зависит от производителя). | Самая дорогая ошибка: «ремень выглядит нормально» — он изнашивается изнутри (зубья). Срок замены по времени (5-7 лет) так же важен как по пробегу (резина стареет). Kit (ремень + помпа + натяжитель + ролики) стоит $150-400, работа $300-800. |
| auto.ops.hev_ev_safety | Hybrid / EV — High-Voltage Safety Procedures | METHOD | Работа на гибридах и электромобилях (200-800V DC). Смертельная опасность! Процедура обесточивания: 1) перевести авто в PARK, выключить зажигание, убрать ключ/брелок на расстояние >5 м (smart key может включить систему), 2) отсоединить 12V аккумулятор (отрицательная клемма первой!), 3) найти service plug / safety disconnect (оранжевый разъём в high-voltage battery pack — размыкает цепь батареи посредине), 4) снять service plug, изолировать разъём, 5) подождать 5-10 минут (конденсаторы в инверторе разряжаются), 6) измерить напряжение на высоковольтных компонентах (CAT III/1000V мультиметр!) — должно быть <30V, 7) только после этого начинать работу. PPE: изолирующие перчатки Class 0 (до 1000V) с кожаными крагами поверх, диэлектрический инструмент (изолированные ручки до 1000V), face shield, insulating mat. Золотое правило: относиться к каждому оранжевому кабелю как к 400V+ живому, пока не доказано обратное измерением. | Никогда: не касаться оранжевых кабелей/разъёмов без полного обесточивания! HV DC дуга не гаснет сама (в отличие от AC) — может поддерживаться пока есть напряжение. Если авария: человек поражён током → НЕ касаться его! Отключить питание, вызвать emergency. |
