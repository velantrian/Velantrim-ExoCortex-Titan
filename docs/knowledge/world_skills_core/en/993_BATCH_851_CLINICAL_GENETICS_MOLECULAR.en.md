# BATCH 851: Clinical Genetics — Molecular Diagnosis

**KnowledgeUnits:** 50
**Namespace:** `clingenetics.ops.*`
**Scope:** genetic_testing_clinical, cancer_genetics_clinical, pharmacogenomics_clinical, inherited_metabolic, chromosome_analysis, ngs_clinical, gene_therapy_clinical

| ID | KnowledgeUnit | Тип | Суть | Практический смысл |
|---|---|---|---|---|
| clingenetics.ops.clinical_wgs | Whole Genome Sequencing — Clinical | METHOD | Клиническое WGS: расширение от WES (Exome). Coverage: 30× standard. Variants: SNPs, indels, SVs, CNVs. WGS vs WES: WGS обнаруживает non-coding variants + regulatory + repeat expansion. Diagnostic yield: rare disease 40-50% (WES), 5-10% higher (WGS). Turnaround: 2-4 недели (rapid WGS). | Rapid WGS NICU: <24 ч turnaround для критически больных новорождённых (снижает ICU stay). |
| clingenetics.ops.somatic_vs_germline | Somatic vs Germline — Distinction | METHOD | Соматическая vs зародышевая мутация: Germline: в каждой клетке тела, наследуется. Somatic: только в опухоли (или ткани). Cancer genetics: tumor sequencing (somatic) + germline testing (для hereditary risk). Lynch syndrome: germline MMR. Tumor-only vs tumor-normal paired sequencing. | Germline path variant в опухоли: важен для семьи (cascade testing). |
| clingenetics.ops.hereditary_cancer_syndromes | Hereditary Cancer — Syndromes | METHOD | Наследственные онкологические синдромы: HBOC: BRCA1/2 (грудь, яичник, простата, поджелудочная). Lynch: MLH1/MSH2/MSH6/PMS2 (ТКЖ, матка, яичник, уролог). FAP: APC (полипоз ободочной). Cowden: PTEN (молочная железа, щитовидная). Li-Fraumeni: TP53 (много типов). | Каждый синдром = свой скрининговый протокол + профилактические хирургии. |
| clingenetics.ops.newborn_screening_expanded | Expanded Newborn Screening | METHOD | Расширенный скрининг новорождённых: USA RUSP (Recommended Uniform Screening Panel): 35+ core + 26 secondary. Методы: dried blood spot (PKU, органические ацидемии), pulse oximetry (CCHD), hearing (DPOAE, AABR). Сроки: 24-48ч после рождения. Ложные положительные: чаще при premature. | Лечение PKU (диета) с рождения: нормальное когнитивное развитие. Без лечения: умственная отсталость. |
| clingenetics.ops.chromosomal_microarray_cma | CMA — Clinical Indication | METHOD | CMA (Chromosomal Microarray): показания — ID/ASD (15-20% yield), multiple congenital anomalies (>20% yield), stillbirth, recurrent miscarriage. Технологии: aCGH (CNVs только), SNP array (CNV + UPD + низкий LOH). Limitations: balanced rearrangements не обнаруживаются. | CMA как first-tier test для ID/MCA: ACMG recommendations. |
| clingenetics.ops.pharmacogenomics_cyp | Pharmacogenomics — CPIC | METHOD | Клиническая фармакогеномика: CPIC (Clinical Pharmacogenomics Implementation Consortium): алгоритмы для конкретных препаратов + генотипов. PharmGKB: база данных PGx. Important pairs: CYP2D6+codeine (toxicity in UMs), HLA-B*5701+abacavir (hypersensitivity), TPMT+azathioprine (bone marrow toxicity). | Pre-emptive pharmacogenomic testing: test once, benefit many times. |
| clingenetics.ops.mitochondrial_genetics | Mitochondrial Disease — Diagnosis | METHOD | Диагностика митохондриальных болезней: Mito-targeted NGS panel vs mtDNA-только. Лейко cell mtDNA vs ткань (muscle). Heteroplasmy % varies between tissues. NGS pitfall: nuclear mitochondrial DNA segments (NUMTs). Biomarkers: лактат, пируват, lactate/pyruvate ratio, amino acids (plasma), organic acids (urine). | Раздельное наследование ядерного и митохондриального геномов: разные паттерны наследования. |
| clingenetics.ops.trinucleotide_repeat | Trinucleotide Repeat — Expansion | METHOD | Трипленукнеотидное расширение: HTT (Huntington, CAG), DMPK (Myotonic Dystrophy, CTG), FMR1 (Fragile X, CGG), ATXN (Spinocerebellar ataxia). Anticipation: расширение в последующих поколениях. Смотреть: fragile X = maternal expansion. Huntington = патernal. | PCR для repeat size: стандартный. TP-PCR или Southern Blot: для больших expansions. |
| clingenetics.ops.rna_diagnostics | RNA Diagnostics — Splicing | METHOD | РНК-диагностика: RNA sequencing для обнаружения splicing variants. Аберрантный сплайсинг: VUS может быть патогенным. Outlier approach: поиск статистически выбивающихся генов. Cryptic splice site activation. RT-PCR для подтверждения. Трудность: ткань-специфическая экспрессия. | RNAseq for undiagnosed disease: дополнительные 10-15% диагнозов (KING study). |
| clingenetics.ops.cardiac_genetics | Cardiac Genetics — Channelopathies | METHOD | Сердечные каналопатии: Long QT Syndrome (LQTS): SCN5A (LQT3), KCNQ1 (LQT1), KCNH2 (LQT2). Brugada: SCN5A. CPVT: RYR2. Penetrance: variable. Family cascade testing. Genetic testing changes management: beta-blockers (LQT1/2), avoid triggers. | Exercise triggers: LQT1 (swimming). Auditory (LQT2). Sleep (LQT3). |
| clingenetics.ops.prenatal_chromosomal | Prenatal Diagnosis — NIPT | METHOD | Пренатальная диагностика: NIPT (Non-Invasive Prenatal Testing): cfDNA из крови матери. Скрининг: T21, T18, T13, sex chromosomes. PPV зависит от prevalence (возраст). Диагностические (invasive): CVS (11-13 нед, риск miscarriage 0.5-1%), Amniocentesis (16-18 нед, риск 0.1-0.5%). | Expanded NIPT (SNP-based): обнаруживает rare autosomal trisomies, UPD, some CNVs. |
| clingenetics.ops.gene_panel_testing | Gene Panel — Clinical Selection | METHOD | Клинические генетические панели: Disease-specific gene panels: лучший diagnostic yield + clinical actionability (vs WES/WGS). Examples: cardiomyopathy panel (100+ genes), epilepsy panel (400+ genes), hearing loss panel. Coverage: 99%+ для подтверждённых pathogenic. Tiered approach: panel → WES → WGS. | Comprehensive panels: снижение времени диагностики без полного WGS. |
| clingenetics.ops.genetic_counseling_process | Genetic Counseling — Process | METHOD | Процесс генетического консультирования: Assessment (family history + clinical). Information (risk + inheritance + testing). Decision support (non-directive). Psychological support. Re-contact policy. Case coordination. Post-test counseling: результаты + implications. Board certification (ABGC/ABMG). | «Uncertainty counseling»: VUS результаты — наиболее сложная ситуация для пациентов. |
| clingenetics.ops.recontact_policy | Recontact — Variant Reclassification | METHOD | Политика обратной связи при рекласификации варианта: VUS → Pathogenic или Pathogenic → Benign. ACMG 2019 реcommendations: laboratories должны иметь recontact policy. Responsibility: laboratory + clinician. Automated notification systems. Patient impact: медицинские решения могут измениться. | ClinVar: публичная база данных классификаций вариантов (>2 млн вариантов). |
