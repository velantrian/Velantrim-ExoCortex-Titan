# BATCH 676: Traffic Control — Road Work Zone Protection

**KnowledgeUnits:** 50
**Namespace:** `traffic.ops.*`
**Scope:** MUTCD, signs, cones, flagging, TMA, arrow_board, lane_closure, taper, channelizer

| ID | KnowledgeUnit | Тип | Суть | Практический смысл |
|---|---|---|---|---|
| traffic.ops.taper_cone_spacing | Taper — Cone & Sign Layout | METHOD | Расстановка конусов в зоне сужения. Advance warning area: знаки за 200-500 м (город-трасса). Transition area (taper): смещение потока. Taper length L = (W × S²) / 60 для S<70 км/ч, или L = W × S для S>70, где W = ширина закрытой полосы, S = скорость. Buffer space: между taper и work area (пустой участок). Для городских улиц (V<50 км/ч): taper 10-20 конусов. Конусы: через 2-5 м на taper, через 7-15 м на tangent. Высота: 70 см минимум (ночью с reflective band). | Недостаточный taper: водитель не успевает перестроиться (последний момент). |
| traffic.ops.flagging_stop_slow | Flagging — Stop/Slow Paddle | METHOD | Регулировщик с жезлом STOP/SLOW. При остановке: поднять STOP, стоять на обочине (НЕ на дороге!), свободная рука поднята. Slow: повернуть SLOW, махать свободной рукой медленно. Позиция: виден approaching traffic за 100-200 м. Одежда: ANSI Class 2/3 hi-vis (флуоресцентный оранжевый/жёлтый + reflective). Оборудование: радио с другим флагманом для координации. Ночью: illuminated paddle или flashlights с red wand. Одиночный flagger: только для low-speed, low-volume (<500 авто/час). | Запрещено: сидеть, использовать телефон, отвлекаться. |
| traffic.ops.tma_truck_placement | TMA — Truck Mounted Attenuator | METHOD | Размещение амортизирующего грузовика. TMA (скорпион): энергопоглощающая конструкция на прицепе. Позиция: 30-50 м перед рабочими (buffer zone). Парковочный тормоз: затянут. Вес TMA: 10-15 тонн. При ударе: TMA сминается, защищая рабочих. Направление: строго по полосе (не под углом — может отбросить в workers). Warning lights: activated. Стрела arrow board на TMA: указывает направление объезда. | Без TMA: любой заехавший в зону автомобиль напрямую ударяет рабочих. |
| traffic.ops.lane_closure_signing | Lane Closure — Sign Sequence | METHOD | Последовательность знаков при закрытии полосы. MUTCD требует: Road Work Ahead → Lane Closed Ahead (символ) → arrow board → cones. Расстояния: зависит от скорости. Установка знаков: с плеча или из машины (безопасность!). Знаки должны быть стабильны (sandbags на ножках). Roll-up signs vs rigid. Ночью: освещение зоны работ (balloon light, portable light tower). Снятие: обратный порядок. | Неправильное размещение знаков = liability для contractor. |
| traffic.ops.channelizer_barrier_types | Channelizer — Types & Ballast | METHOD | Направляющие устройства. Cones (70-90 см), tubes (цилиндрические), barrels (бочки), vertical panels, barricades. Ballast (утяжелитель): конусы до 7 кг (не сдует ветром). Barrels: заполнены водой/песком. Установка: обочина в тандеме (один ставит, второй подаёт из кузова). Не выбегать на проезжую часть! Осмотр: после storm — проверить, не сбиты ли. | Сдутый конус на проезжей части = hazard. |
