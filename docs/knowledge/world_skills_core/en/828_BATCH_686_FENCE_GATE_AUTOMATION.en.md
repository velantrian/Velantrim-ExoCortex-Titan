# BATCH 686: Gate Automation — Slide & Swing Operator

**KnowledgeUnits:** 50
**Namespace:** `gateauto.ops.*`
**Scope:** slide, swing, hydraulic, electromechanical, loop, photocell, safety_edge, battery

| ID | KnowledgeUnit | Тип | Суть | Практический смысл |
|---|---|---|---|---|
| gateauto.ops.slide_gate_track_v_groove | Slide Gate — Track & V-Wheels | METHOD | Монтаж откатных ворот. Track: стальной рельс (V-образный) или flat bar. Основание: бетонная балка (20-30 см ширина, 20-30 см глубина, армированная). V-wheels на воротах катятся по track. Cantilever gate: без track в земле (ролики на столбах поддерживают), для мест где track забивается снегом/грязью. Нижний guide roller: предотвращает боковое раскачивание. End stops: на обоих концах track (позитивный стоп). Крышка track: пластиковая для защиты от debris. Смазка wheels: lithium grease. | Track забитый снегом = gate не движется. |
| gateauto.ops.motor_gearing_torque_calc | Motor — Torque & Duty Cycle | METHOD | Подбор привода. Swing gate: articulated arm (рычаг) или linear ram (гидравлический/электромеханический). Torque: для swing — вес створки × расстояние от петель. Duty cycle: residential (10-20 циклов/день), commercial (50-100+). Motor: 24V DC (безопаснее) с редуктором. Backup battery: 12V 7Ah (несколько циклов при отключении). Solar: для удалённых gate (panel 40-80W + charge controller + deep cycle battery 100Ah). Inherent entrapment protection: RPM sensor (detect obstruction), current sensing. | 120V AC motor с capacitor: выше начальный крутящий момент. |
| gateauto.ops.loop_detector_inductance | Induction Loop — Detector Settings | METHOD | Настройка индукционной петли. Провод (16-18 AWG, XLPE изоляция) укладывается в пропил (saw cut) в асфальте 3-4 витка (loop). Глубина пропила: 3-5 см. Герметик (loop sealant): гибкий, bitumen. Подключение к loop detector: twisted pair до контроллера. Frequency: настройка (чтобы соседние loops не интерферировали). Sensitivity: регулировка (низкая — не детектит мотоцикл, высокая — ложняки от помех). Presence: hold (пока авто над loop). Функции: Free exit loop (внутренняя), Safety loop (reversing), Shadow loop (под gate). | Loop передаёт сигнал когда металлическая масса проезжает над ним. |
| gateauto.ops.photocell_alignment_sync | Photocell — Alignment | METHOD | Установка фотоэлементов безопасности. Transmitter (TX) и Receiver (RX), normally-closed (NC) контакт. Высота: 15-20 см над землёй. Alignment: механическая юстировка (bracket) + электронная (LED indicator green = aligned). Расстояние: до 10-15 м. Солнечный свет: не направлять на прямой солнечный свет (насыщение). Retro-reflective: transmitter + reflector (один прибор). Synchronised: TX и RX синхронизированы (не реагируют на другие источники). При нарушении луча во время закрытия: gate немедленно реверсирует. | UL 325 требует два независимых метода entrapment protection. |
| gateauto.ops.wireless_keypad_programming | Keypad — Programming & Codes | METHOD | Кодовый замок (Linear, Doorking, Viking). Programming: master code, adding user PIN (2-6 digits). Wiegand output: соединение с контроллером (data0/data1). Хранение кодов: EEPROM (не стирается при отключении). Transmitter (remote clicker): DIP switch или learning mode (rolling code для security). Реле: 1-2 канала (relay 1 = open, relay 2 = pedestrian). Battery: alkaline или литиевая (3V CR2032). Замена: раз в 1-2 года. | Не программировать простые коды (0000, 1234, год рождения). |
