| lab.ops.sample_chain_of_custody | Sample Chain of Custody — Legal Documentation | METHOD | Цепочка хранения образцов: юридически значимое документирование каждого перемещения образца. Record: отбор (кто, когда, где, условия — температура, preservatives), передача (от → кому, дата/время, подписи обеих сторон), хранение (где, условия, sealed/locked), анализ (кто, когда, метод), утилизация. CoC form: уникальный идентификатор образца, описание, matrix (вода/почва/воздух/кровь), requested tests. Каждое открытие/закрытие контейнера: новая пломба (tamper-evident seal) с ID. Хранение: secure, restricted access (замок + log), environmental monitoring (температура для биологических образцов — −20/−80°C). Отклонение в CoC (передача без подписи, нарушение температуры) делает образец inadmissible в суде. | CoC — фундамент аналитической работы с юридическими последствиями (environmental enforcement, criminal forensics, doping control, food safety). При environmental litigation: если лаборатория не может доказать CoC — доказательство отклонено, дело проиграно. |
| lab.ops.calibration_standards | Analytical Balance & Pipette — Calibration & Verification | METHOD | Калибровка измерительного оборудования. Весы: ежедневная проверка с certified weights (min 2 точки — near zero и near max capacity), tolerance ±0.1% или согласно производителю. Запись в log. Pipettes: gravimetric calibration (взвешивание выдаваемого объёма воды на calibrated balance с учётом плотности воды при данной температуре) — 6 повторений на каждый номинальный объём и на минимальный. Acceptance: mean error ±1% for fixed volume, ±2% for variable <50 мкл. Неисправные: ремонт/замена, перекалибровка после ремонта. Термометры: ледяная точка (0°C) + кипящая вода (100°C с поправкой на атмосферное давление −0.5°C на каждые 150 м высоты). Спектрофотометр: holmium oxide фильтр (длины волн) и нейтральные density фильтры (absorbance accuracy). | Калибровка градуированной посуды (мерные колбы, бюретки) — редкая ошибка: пластиковая посуда может давать systematic error из-за разных диаметров и hydrophobic стенок vs стекло. Допуск для Class A мерной колбы 100 мл — ±0.08 мл. |
| lab.ops.lims_workflow | LIMS — Laboratory Information Management System | METHOD | LIMS — центральная IT-система лаборатории. Функции: 1) Sample login (регистрация образца с metadata — customer, location, date, tests requested, due date), 2) Label generation (barcode for tracking), 3) Work assignment (распределение тестов между аналитиками), 4) Result entry (ручной или автоматический импорт с приборов через RS-232/USB/Ethernet), 5) Result review (supervisor проверяет: QC passed? неожиданные значения?), 6) Approval & reporting (CoA — Certificate of Analysis generation, electronic signature 21 CFR Part 11 compliant), 7) Billing/Invoicing, 8) Inventory (reagents, standards — expiration tracking). Compliance: audit trail (каждое изменение — original value, new value, who, when, why), user access levels, electronic signatures (unique user ID + password). Integrations: ERP (SAP), instruments, SDMS (Scientific Data Management System). | LIMS без audit trail = не соответствует GLP/GMP. FDA Warning Letter: «ваша лаборатория не контролирует изменения данных» → shutdown. Замена LIMS: сложный процесс (data migration, валидация), 6-18 месяцев. Cloud LIMS (LabVantage, STARLIMS, Benchling) growing vs on-prem (безопасность данных). |
| lab.ops.method_validation_parameters | Analytical Method Validation — Parameters | METHOD | Валидация аналитического метода (ICH Q2(R1), USP 1225). Параметры: 1) Accuracy (близость к true value — сравнение с certified reference material или spike recovery 80-120%), 2) Precision: repeatability (одна лаборатория, один день, один аналитик — RSD <2-5%), intermediate precision (разные дни/аналитики — RSD <5-10%), reproducibility (межлабораторная — RSD <10-15%), 3) Specificity (способность различать analyte among impurities/degradants/products matrix), 4) Linearity (R² >0.995 в рабочем диапазоне), 5) Range (интервал где метод linear, accurate, precise), 6) LOD/LOQ: LOD = 3.3 × σ/slope (предел обнаружения), LOQ = 10 × σ/slope (предел количественного определения), 7) Robustness (устойчивость к малым изменениям — pH ±0.2, temperature ±5°C, mobile phase composition ±2% — метод всё ещё работает?), 8) System suitability test. Документация: Validation Protocol (заранее одобренный план) → Validation Report (результаты и заключение). | Метод не валидирован = результаты не надёжны юридически. Для GMP лабораторий — обязательное требование (21 CFR 211.194). Re-validation: при изменении метода, оборудования, исходного сырья API. |
| lab.ops.qc_chart_westgard | QC — Westgard Rules for Clinical Lab | METHOD | Westgard rules (multi-rule QC в клинических лабораториях). Контрольные материалы (QC samples) анализируются с каждой партией patient samples. Правила: 1₂s (warning — 1 control value >2 SD от mean), 1₃s (reject — >3 SD), 2₂s (reject — 2 последовательных values >2 SD в одном направлении), R₄s (reject — размах между двумя controls >4 SD), 4₁s (reject — 4 последовательных values >1 SD в одном направлении), 10x (reject — 10 последовательных по одну сторону от mean). При reject: остановка анализа, поиск причины (новый lot реагента? degradation? неправильная реконституция QC?), corrective action, перезапуск QC. Levey-Jennings chart: визуализация mean ±1/2/3 SD. QC lot change: при переходе на новый lot QC материала — параллельный анализ старого и нового (10-20 дней) для установления нового mean. | Систематическая ошибка (тренд/сдвиг) опаснее случайной (может долго не детектироваться 1₃s правилом). Westgard специально multi-rule чтобы детектировать systematic errors. Shift: 10x правило, trend: постепенное изменение за несколько дней. |
| lab.ops.hplc_troubleshooting | HPLC — Column Care & Troubleshooting | METHOD | High-Performance Liquid Chromatography (высокоэффективная жидкостная хроматография). Колонка: silica-based (C18 reverse phase — самая частая), pH range 2-8 (extreme pH гидролизует bonded phase), temperature <60°C. Проблемы и решения: 1) High backpressure (>400 bar/6000 psi) — забит inlet frit (обратная промывка колонки), precipitated buffer salts (промывка водой), sample matrix with particulates (фильтрация sample 0.45/0.22 µm). 2) Peak tailing — вторичные взаимодействия (силанолы), используют endcapped колонку или mobile phase modifier (TEA — triethylamine для оснований). 3) Split peaks — частично забита inlet frit, канал в колонке (void at head of column). 4) Retention time drift — column temperature fluctuation (±0.1°C target), gradient delay, mobile phase evaporation (organic phase). System suitability: перед каждым run — resolution Rs >2 между критической парой пиков, tailing factor <2, theoretical plates N >2000. Очистка: reverse flush (противоположное направление) с сильным solvent (100% organic), затем equilibration. Guard column: защищает аналитическую колонку (менять чаще, дешевле). | Mobile phase: фильтрация (0.45 µm) и дегазация (вакуум, helium sparging или in-line degasser) ОБЯЗАТЕЛЬНЫ. Пузырьки воздуха в детекторе = шум/дрейф baseline. Буферные растворы: не оставлять в колонке (соли выпадают в осадок), промывать водой перед organic flush. |
| lab.ops.microbiology_aseptic_technique | Microbiology — Aseptic Technique & Media Prep | METHOD | Асептическая техника: стерильная работа с микробиологическими культурами. Принципы: 1) Рабочая поверхность дезинфицирована (70% этанол, 5-10 мин контакта), 2) Пламя Bunsen burner или working в ламинарном шкафу (BSC II — Biological Safety Cabinet), 3) ВСЁ что контактирует с культурой — стерильно (петли, пипетки, пробирки), 4) Фламинговка (стерилизация металлической петли в пламени до красного каления + охлаждение на воздухе или touching agar), 5) Работа быстро, но тщательно (крышки открыты минимальное время, пробирки наклонены под углом), 6) Никаких разговоров/кашля в направлении работы. Приготовление агаровых сред: rehydration порошка в дистиллированной воде, автоклавирование (121°C, 15 psi, 15-20 минут в зависимости от объёма), остужение до 45-50°C (можно держать рукой), добавление термолабильных добавок (антибиотики, blood/serum к blood agar — при <50°C чтобы не denature), разливка в чашки Петри (15-20 мл на чашку, застывание, переворот крышкой вниз — предотвращение конденсата) или скошенный агар в пробирках. Инкубация: 37°C для большинства mesophilic pathogens, инвертированные чашки (крышкой вниз — конденсат не капает на агар), 18-48 часов. Контроль стерильности: одна чашка из партии инкубируется без инокуляции — если рост → партия заражена, discarded. | Контаминация petri dish посторонними микроорганизмами (плесень, airborne bacteria) — самая частая проблема студентов. LAF (Laminar Air Flow) cabinet создаёт вертикальный поток HEPA-фильтрованного воздуха (класс ISO 5), защищает sample, но НЕ оператора (для pathogens — BSC II). |
| lab.ops.accreditation_iso17025 | ISO/IEC 17025 — Laboratory Accreditation | METHOD | Международный стандарт для испытательных и калибровочных лабораторий (2017 версия). Требования: 1) Impartiality (лаборатория должна быть независима, без конфликта интересов), 2) Confidentiality (результаты клиента защищены), 3) Personnel competence (образование, training, experience, demonstration of competence), 4) Facilities & environment (контроль температуры, влажности, vibration, EMI — electromagnetic interference), 5) Equipment (программа калибровки, maintenance, handling), 6) Metrological traceability (калибровка прослеживается до SI единиц через цепочку калибровок), 7) Externally provided products and services (reagents, reference materials, subcontractors — qualified), 8) Method validation, 9) Sampling, 10) Handling of test items, 11) Technical records, 12) Measurement uncertainty (оценка uncertainty для каждого калибровочного/испытательного метода), 13) Validity of results (proficiency testing — межлабораторные сравнения, QC, replicate testing), 14) Reporting (test report/certificate с определёнными элементами). Аудит: accreditation body (A2LA, ANAB, UKAS) проводит on-site assessment (1-4 дня) initial + surveillance каждые 1-2 года + re-assessment каждые 4 года. | ISO 17025 ≠ ISO 9001. 17025 — техническая компетентность (может ли лаба правильно измерить?), 9001 — управленческая система. Аккредитация mandatory для многих regulated industries (environmental compliance, food export). |
| lab.ops.lab_safety_chemical | Laboratory Safety — Chemical Hygiene Plan | METHOD | План химической безопасности (OSHA 1910.1450). Компоненты: 1) Chemical inventory (все chemicals, CAS number, количество, location, SDS на каждое вещество доступны), 2) Risk assessment для каждого процесса (hazard identification, exposure assessment), 3) Controls: Engineering (fume hood — face velocity 0.4-0.6 м/с, sash height limited, annual certification; glove box для pyrophoric/oxygen-sensitive), Administrative (стандартные операционные процедуры SOP, training), PPE (gloves — проверять совместимость материала с chemical: нитриловые перчатки пробиваются дихлорметаном за 2-3 мин!, silver shield для сильных organics), 4) Emergency procedures (spill kit — neutraliser, absorbent, PPE; eyewash station — 15 мин tepid water, tested еженедельно; safety shower — tested ежегодно), 5) Waste management (segregation incompatible wastes, satellite accumulation point <55 галлонов, label "Hazardous Waste" с датой). Особо опасные: HF (плавиковая кислота — проникает через кожу, связывает кальций в костях → fatal cardiac arrhythmia; calcium gluconate gel на месте контакта + ER немедленно), perchloric acid (образует взрывчатые перхлораты в вентиляции если нет water wash-down fume hood). | Работа в одиночку в лаборатории с опасными chemicals — запрещено (buddy system). Неизвестный запах = эвакуация, а не «пойду посмотрю». Пить и есть в лаборатории — ОЧЕНЬ плохая идея (химикаты на поверхностях!). |
