# BATCH 635: Pest Control — Exterminator Operations

**KnowledgeUnits:** 44
**Namespace:** `pest.ops.*`
**Scope:** inspection, termite, rodent, bed_bug, cockroach, mosquito_service, IPM, pesticide_safety

| ID | KnowledgeUnit | Тип | Суть | Практический смысл |
|---|---|---|---|---|
| pest.ops.inspection_termite | Termite Inspection — WDI Report | METHOD | Осмотр на термитов (WDI — Wood Destroying Insect). Инструменты: фонарик, пробивной инструмент (probe), влагомер. Признаки: mud tubes (земляные ходы на фундаменте), swarmers (крылатые особи + сброшенные крылья), frass (экскременты), hollow wood (стук). Осмотр: фундамент, crawl space, sill plates, окна/двери, чердак. WDI report: для ипотеки (VA/FHA требование). Treatment: soil termiticide (барьер), bait stations (Sentricon — медленного действия, colony elimination), foam для стен. | Mud tubes размером с карандаш. |
| pest.ops.bed_bug_treatment | Bed Bug — Heat Treatment | METHOD | Уничтожение клопов. Инспекция: seams mattresses, baseboards, electric outlets (чёрные пятна фекалий). Heat treatment: industrial heaters поднимают температуру в помещении до 50-60°C (30-90 мин, lethal для всех стадий). Вентиляторы для равномерного прогрева. Мониторинг: термопары в труднодоступных местах (подтверждение достижения температуры). Альтернатива: химическая (spray + dust) + steaming. Подготовка клиента: стирка/сушка вещей, vacuum, declutter. Follow-up: через 2 недели. | Клопы в электрических розетках! |
| pest.ops.rodent_exclusion_seal | Rodent Exclusion — Sealing Entry Points | METHOD | Запечатывание входов грызунов. Инспекция: все точки входа (отверстия >6 мм для мыши, >12 мм для крысы). Уплотнение: стальная вата + герметик, copper mesh, sheet metal, цемент. Door sweeps. Вентиляционные сетки. После exclusion: trapping внутри (убрать оставшихся). Bait stations (наружные): tamper-proof, monthly проверка. Sanitation: убрать источники еды (мусор). | Грызуны протискиваются в очень маленькие щели. |
| pest.ops.cockroach_gel_baiting | Cockroach — Gel Bait Application | METHOD | Гель-приманка от тараканов. Inspection: preferred hiding (под раковиной, за холодильником, в motor appliances). Gel bait: инсектицид + attractant, наносится точками (размером с горошину) в углы, петли, трещины. Placement: in cracks/crevices (не на открытых поверхностях!). Разные гели для разных видов (немецкий vs американский таракан). IGR (Insect Growth Regulator): стерилизует, предотвращает размножение. Follow-up: 2-4 недели. Мониторинг: glue traps. | Не spray в местах где bait! (отпугнёт, не съедят). |
| pest.ops.pesticide_ppe_application | Pesticide — Safety & PPE | METHOD | Безопасная работа с пестицидами. Чтение label (the law). PPE: chemical-resistant gloves (nitrile 14+ mil), respirator (organic vapour cartridge), goggles, coverall. Mixing: designated area (не кухня!), measuring cups. Application: направление ветра (upwind), не в дождь (wash off). Re-entry interval (REI): 2-4 часа (или по label). Не spraying near water sources (fish toxic). Хранение: locked, away from food/feed, оригинальная упаковка. Disposal: triple-rinse empty container. Запись: Application record (date, chemical, rate, target, location, weather). | Нарушение label = федеральное преступление (FIFRA). |
