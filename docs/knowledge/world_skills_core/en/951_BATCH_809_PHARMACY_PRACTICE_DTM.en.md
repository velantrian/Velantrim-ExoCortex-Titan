| pharmacyprac.ops.warfarin_dosing | Warfarin — Dosing & Monitoring | METHOD | Варфарин: Цель INR: AF = 2.0-3.0, механические клапаны = 2.5-3.5, VTE = 2.0-3.0. Мониторинг: INR при каждой корректировке, затем каждые 4-6 нед при стабильности. Взаимодействия: кларитромицин, флуконазол → ↑ INR. Амиодарон → ↑. Рифампин → ↓. Витамин К: нейтрализует. | INR > 10 без кровотечения: пероральный витамин К (не IV). |
| pharmacyprac.ops.vancomycin_dosing | Vancomycin — AUC/MIC Dosing | METHOD | Ванкомицин: Новые руководства (ASHP/IDSA/SIDP 2020): цель AUC/MIC 400-600 (не трофный уровень >15 мг/л). Мониторинг: AUC/MIC через 2 дозы (при тяжёлых инфекциях). Тяжёлая нефротоксичность при трофном >20 мг/л. MRSA инфекции: первая линия. | VISA/VRSA: ванкомицин-промежуточный/резистентный S. aureus → необходим MIC определение. |
| pharmacyprac.ops.therapeutic_drug_monitoring | TDM — Aminoglycosides | METHOD | Терапевтический мониторинг лекарств (аминогликозиды): Гентамицин/тобрамицин. Extended-interval dosing: 4-7 мг/кг каждые 24-36-48 ч (зависит от GFR). Peak: 8-10 мкг/мл (для сепсиса). Trough: <2 мкг/мл (снижение нефро/ototoxicity). Hartford nomogram: определение интервала. Традиционный мониторинг: 6-8 час после дозы. | Синергия с β-лактамом: при Enterococcal endocarditis. |
| pharmacyprac.ops.anticoagulation_management | Anticoagulation — NOAC vs Warfarin | METHOD | NOAC vs варфарин: NOACs (ривароксабан, апиксабан, дабигатран, эдоксабан): фиксированная доза, нет мониторинга, лучший профиль безопасности. Дабигатран: почечный клиренс 80% → при ХБП противопоказан. Ривароксабан: однократный приём с едой. Апиксабан: наименее почечный. Reversal: андексанет альфа (anti-Xa), идаруцизумаб (дабигатран). | Периоперационный мост (bridging): не рекомендован рутинно при NOAC. |
| pharmacyprac.ops.methotrexate_rescue | Methotrexate — Leucovorin Rescue | METHOD | Высокодозный метотрексат (HD-MTX): в онкологии (>1 г/м²). Лейковорин (кальций фолинат): спасательная терапия. Гидратация + подщелачивание мочи (pH > 7). Мониторинг уровня МТХ: через 24, 48, 72 ч. Цель: <0.1 мкмоль/л. Нефротоксический → задержка выведения → токсичность (мукозит, панцитопения). | Глюкарпидаза (Carboxypeptidase G2): при почечной задержке МТХ. |
| pharmacyprac.ops.drug_drug_interactions | Critical Drug Interactions | METHOD | Критические лекарственные взаимодействия: MAOI + серотонинергические = серотониновый синдром. Варфарин + NSAIDs = кровотечение. SSRIs + тромбоцитарные = кровотечение. Статины + мощные CYP3A4 ингибиторы (нефазодон, циклоспорин) = рабдомиолиз. Левадопа + неселективные MAOIs = гипертонический криз. | QT-удлиняющие: галоперидол + азитромицин → TdP (риск). |
| pharmacyprac.ops.polypharmacy | Polypharmacy — Deprescribing | METHOD | Полипрагмазия: ≥5 препаратов (определение). У пожилых: ≥10 очень распространено. STOPP/START criteria: инструмент для депрескрибинга. Beers Criteria: потенциально неподходящие лекарства для пожилых. «Prescribing cascade»: побочный → новый препарат (снежный ком). Депрескрибинг: постепенная отмена под контролем. | Benzodiazepines + elderly: падения, переломы, деменция — в Beers Criteria. |
| pharmacyprac.ops.heparin_dose_weight | Heparin — Weight-Based Protocol | METHOD | Нефракционированный гепарин (НФГ): Нагрузочная доза: 80 ед/кг IV болюс (максимум 5000-10000 ед). Поддержание: 18 ед/кг/ч. Мониторинг: aPTT через 6 ч (цель 60-100 сек или 1.5-2.5× контроль). Низкомолекулярный (НМГ): эноксапарин 1 мг/кг SC каждые 12 ч. ПТТ для НМГ: обычно не требуется (за исключением беременности, ожирения, ХБП). | Гепарин-индуцированная тромбоцитопения (HIT): тромбоциты ↓ + тромбоз → немедленно отменить гепарин. |
| pharmacyprac.ops.pain_management_opioid | Opioid Therapy — Equianalgesic | METHOD | Эквианальгетическая таблица: морфин 30 мг PO = оксикодон 20 мг PO = гидроморфон 7.5 мг PO = фентанил 25 мкг/ч (трансдермальный). Морфин 30 мг PO = морфин 10 мг IV. Конверсия при ротации: снизить расчётную дозу на 25-50% (неполная перекрёстная толерантность). Налоксон: 0.04-0.4 мг IV (не весь антидот сразу при хронических). | Гидрокодон не имеет IV формы. Фентанил = только дериваты для хронической боли (не при острой). |
| pharmacyprac.ops.chemotherapy_premedication | Chemotherapy — Antiemetic Protocol | METHOD | Химиотерапия: контроль тошноты/рвоты. Высокоэметогенный (HEC, > 90%, цисплатин): APF125 (fosaprepitant) + 5-HT3 антагонист (ондансетрон) + дексаметазон + оланзапин. Умеренно (MEC): 5-HT3 + дексаметазон. Низко: дексаметазон или прохлоперазин. Breakthrough: прохлоперазин, ондансетрон. | Апрепитант (NK1 блокатор): снижает рвоту отсроченную (>24 ч). |
| pharmacyprac.ops.medication_error_types | Medication Errors — Root Cause | METHOD | Виды ошибок с лекарствами: Wrong medication, Wrong dose, Wrong patient, Wrong route, Wrong time, Omission, Unauthorized drug. Near miss: обнаружено до вреда. Активные vs Латентные ошибки (System vs Individual). ISMP high-alert medications: инсулин, антикоагулянты, опиоиды, концентрированные электролиты. | Swiss cheese model (Reason): множественные барьеры. Отверстие = сбой. Совпадение = ошибка. |
| pharmacyprac.ops.renal_dose_adjustment | Renal Dosing — Cockroft-Gault | METHOD | Коррекция дозы при почечной недостаточности: Клиренс креатинина (CrCl, мл/мин) по Кокрофту-Голту: CrCl = (140-возраст) × вес / (72 × SCr) × 0.85 (женщины). Для лекарств, выводимых почками, снижать дозу или удлинять интервал. GFR stages: G1 ≥90, G2 60-89, G3 30-59, G4 15-29, G5 <15. | Digoxin: очень narrow TI + почечный клиренс → опасность при ХБП. |
| pharmacyprac.ops.hypersensitivity_penicillin | Penicillin Allergy — Cross-Reactivity | METHOD | Аллергия на пенициллин: 80-90% заявленной «аллергии» — не истинная (толерантность появилась). Перекрёстная реактивность с цефалоспоринами: <1% при настоящей аллергии. Карбапенемы: ещё меньше. Кожное тестирование: направляет к де-лейблингу. | Пенициллиновое де-лейблирование: снижает устойчивость к антибиотикам + улучшает исходы. |
| pharmacyprac.ops.insulin_types_timing | Insulin Regimens — Basal-Bolus | METHOD | Схемы инсулина: Базально-болюсная: базальный (гларгин/деглудек) + прандиальный (аспарт/лиспро/глулизин). Коррекционный: по формуле 1700/TDD (ISF). Premixed (70/30): удобство но менее гибкие. Инсулиновые помпы: CSII. HbA1c цель: <7% (большинство пациентов), <7.5% (пожилые). | Гипогликемия ночью: базальный слишком высокий → уменьшить. |
| pharmacyprac.ops.antimicrobial_stewardship | Antimicrobial Stewardship | METHOD | Программы антимикробной стратегии (ASP): снижение нерационального использования антибиотиков. Core strategies: Prospective audit + feedback, Preauthorization. De-escalation: к узкому спектру при идентификации. Duration optimization: коротко-курсовая (5-7 дней вместо 14). IV-to-oral switch. Carbapenem stewardship. | ASP: CDC Core Elements of Hospital Antibiotic Stewardship Programs. |

Высоко метаболизируемые препараты (first pass): снизить дозу. Высокая связь с белками: при гипоальбуминемии активная фракция ↑. Нет единого простого теста как GFR. FDA рекомендует: изучать в PK исследованиях. | Морфин и опиоиды при ЦП: накопление активных метаболитов → ошибочная доза. |
