# BATCH 818: Statistics — Biostatistics & Research Methods

**KnowledgeUnits:** 50
**Namespace:** `statistics.ops.*`
**Scope:** hypothesis_testing, confidence_intervals, regression, survival_analysis, systematic_review, RCT, cohort, case_control, Bayesian, power_calculation

| ID | KnowledgeUnit | Тип | Суть | Практический смысл |
|---|---|---|---|---|
| stats.ops.null_hypothesis_testing | Hypothesis Testing — Error Types | METHOD | Проверка гипотез: H0 (нулевая) vs H1 (альтернативная). Ошибка типа I (α): отклонить H0 при её истинности (ложная тревога). Ошибка типа II (β): не отклонить H0 при ложной (пропустить эффект). Мощность (1-β): вероятность обнаружить истинный эффект. Стандартные: α = 0.05, 1-β = 0.80. | p < 0.05 НЕ = «важно» или «большой эффект». Только «маловероятно случайно». |
| stats.ops.confidence_interval | Confidence Intervals — Interpretation | METHOD | Доверительный интервал: 95% CI = если бы мы повторили исследование многократно, 95% CI включали бы истинное значение. НЕ означает: «95% вероятность, что истинное значение здесь». ДИ НЕ содержит 1.0 (для RR/OR): статистически значимо. Width = precision. | Узкий ДИ = большая выборка + более точный. Широкий = неопределённость. |
| stats.ops.rct_design | RCT — Key Design Features | METHOD | Рандомизированное контролируемое исследование: Randomization: снижает систематическую ошибку. Allocation concealment: последовательность скрыта до randomization. Double-blind: исследователь + пациент не знают. Intention-to-treat (ITT): анализируют всех рандомизированных. Per-protocol: только соответствующих. CONSORT diagram. | ITT preserves randomization balance; PP potentially biased. |
| stats.ops.kaplan_meier | Survival Analysis — Kaplan-Meier | METHOD | Анализ выживаемости: Kaplan-Meier кривая: «лестничная» ступенчатая вероятность. Цензурирование: lost to follow-up или конец исследования. Log-rank test: сравнение кривых. Медиана выживаемости: время при 50% вероятности. Cox proportional hazard: регрессия с covariates. HR (Hazard Ratio). | HR = 1: нет различия. HR < 1: снижение риска. HR > 1: повышение риска (при событии = плохое исходе). |
| stats.ops.number_needed_treat | NNT — Number Needed to Treat | METHOD | Число больных, которых нужно лечить (NNT): NNT = 1/ARR. ARR = CER - EER (Control Event Rate - Experimental Event Rate). RRR = (CER - EER) / CER. NNH (Number Needed to Harm) = 1/ARI. NNT < 10 = хороший эффект лечения. | NNT = 1: каждый treated benefits. NNT = 100: 1 из 100. |
| stats.ops.cohort_study | Cohort Study — Design | METHOD | Когортное исследование: экспозированные vs неэкспозированные → follow-up → исходы. Проспективное: вперёд во времени. Ретроспективное: на основе существующих записей. Relative Risk (RR): хорошо для частых событий. Attrition bias при потере к наблюдению. | Cohort: может измерить Incidence. Case-control: только Odds Ratio. |
| stats.ops.systematic_review_meta | Systematic Review — Methods | METHOD | Систематический обзор + мета-анализ: PICO (Population, Intervention, Comparator, Outcome). PRISMA checklist. Поиск в нескольких базах данных (Medline, Cochrane, Embase). Оценка качества: ROB-2 (Cochrane). Forest plot: точечные оценки + ДИ. Heterogeneity: I² (>50% = значительная). Funnel plot: publication bias. | «Весовой анализ» в мета: большие исследования = больший вес. |
| stats.ops.regression_logistic | Logistic Regression — Interpretation | METHOD | Логистическая регрессия: для бинарных исходов. Коэффициент → Odds Ratio = e^β. Adjusted OR: учтены ковариаты. Hosmer-Lemeshow test: goodness of fit. ROC-AUC: дискриминационная способность. AUROC = 0.5 = не лучше случая, 1.0 = идеальная. С-statistic. | Многомерный: все covariates в модели одновременно → adjusted OR. |
| stats.ops.bayesian_inference | Bayesian Statistics — Basics | METHOD | Байесовская статистика: P(H|D) = P(D|H) × P(H) / P(D). Prior probability × Likelihood = Posterior. Обновление убеждений. В отличие от frequentist: incorporates prior knowledge. Bayesian credible interval: «95% вероятность что параметр в интервале» (истинное утверждение). | «Bayesian» updating: как мы учимся на опыте — каждое новое исследование обновляет prior. |
| stats.ops.propensity_score | Propensity Score — Matching | METHOD | Метод оценки склонности (PSM): для наблюдательных исследований. Propensity score = вероятность получения лечения по ковариатам. Matching: paired exposed/unexposed с похожим score. Inverse probability weighting (IPW). Balance check after matching. Limitations: unmeasured confounders. | PSM ≠ рандомизация. Только measured confounders balanced. |
| stats.ops.forest_plot | Forest Plot — Reading | METHOD | Лесная диаграмма (Forest Plot): каждая строка = исследование. Точка = эффект. Горизонтальные усы = ДИ. Ромб = суммарный эффект. Vertical line at 1 (RR/OR) или 0 (MD): нет эффекта. Если ДИ пересекает = нет статистически значимого. Вес: размер квадрата. | Forest plot «дом» правила: если ромб слева от 1 = benefit (снижение риска). |
| stats.ops.diagnostic_test_analysis | Diagnostic Test — Bayesian | METHOD | Диагностический тест: Pre-test probability (prevalence). LR+ = Sensitivity / (1-Specificity). LR- = (1-Sensitivity) / Specificity. Post-test probability: Fagan nomogram или Bayes. Стандарт: PPV и NPV зависят от prevalence. Deeks & Altman nomogram: LR → changes in probability. | LR+ > 10: сильное подтверждение. LR- < 0.1: сильное исключение. |
| stats.ops.sample_size_power | Sample Size — Power Calculation | METHOD | Расчёт размера выборки: зависит от ожидаемого эффекта, α, β (мощности), вариабельности. n = 2 × [(Z_α/2 + Z_β)² × σ²] / d². Одностороннее vs двустороннее. MCID (Minimal Clinically Important Difference). A priori vs post hoc мощность. Software: GPower, R, PASS. | «Недостаточная мощность»: пропускает эффекты. «Чрезмерная мощность»: этически — лишние участники. |
| stats.ops.bias_types | Bias — Types in Research | METHOD | Виды систематических ошибок: Selection bias: кто включён. Information/measurement bias: как данные собраны. Observer bias. Recall bias: пациенты помнят иначе. Lead-time bias (screening). Length-time bias (overestimation survival). Surveillance bias. Hawthorne effect: изменение поведения при наблюдении. | Confounding ≠ bias: confounding = третья переменная, связанная с обоими. |
| stats.ops.clinically_important_vs_statistical | Statistical vs Clinical Significance | METHOD | Статистическая ≠ клиническая значимость: при большой выборке малый эффект = статистически значимый. Клиническая значимость: измеряется MCID. GRADE: уровни доказательств (High/Moderate/Low/Very Low). Effect size measures: Cohen's d, NNT, RRR. P-value реформы: многие journals теперь требуют CI + effect size. | «Клинически незначимое, но статистически значимое»: при n>10 000 часто. |
| stats.ops.interrupted_time_series | Interrupted Time Series — Analysis | METHOD | Прерванные временные ряды (ITS): оценка вмешательства без рандомизации. Pre-intervention vs Post-intervention trend. ARIMA models. Autocorrelation: соседние точки связаны. ITS controls for: historical trends, seasonality. ITSA: Segmented regression. Limitations: concurrent events. | ITS: когда RCT нецелесообразен (программа на всю популяцию). |
| stats.ops.cluster_randomized | Cluster Randomized Trial | METHOD | Кластерно-рандомизированное исследование: рандомизируются группы (кластеры), не индивиды. Необходимо для интервенций на уровне кластера (школа, деревня). Intracluster Correlation Coefficient (ICC). Design Effect = 1 + (m-1) × ICC. Larger sample needed: inflate n by design effect. | ICC высокий: члены кластера похожи → меньше «эффективных» единиц. |
| stats.ops.measurement_validity | Measurement Validity — Types | METHOD | Валидность измерения: Content validity: измеряет все домены. Criterion validity: concurrent vs predictive. Construct validity: соответствует теоретическому конструкту. Face validity: кажется правильным. Convergent: коррелирует с аналогичными. Discriminant: не коррелирует с несвязанными. CFA (Confirmatory Factor Analysis). | Reliability ≠ validity: можно быть точным и неправильным. |
