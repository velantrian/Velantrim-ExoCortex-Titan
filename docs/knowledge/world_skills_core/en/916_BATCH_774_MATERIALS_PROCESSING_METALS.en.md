| metalproc.ops.sand_casting | Sand Casting — Process | METHOD | Песчаное литьё: шаблон (pattern) → формообразование в формовочной смеси (green sand: кварц + бентонит + вода). Две полуформы (cope + drag). Литниковая система: стояк (sprue) + литниковый канал (runner) + питатель (gate). Прибыль (riser): резервуар для компенсации усадки. Заливка → охлаждение → выбивка. Уклон (draft): 1-3° для извлечения. | Усадка: 1.5-2.5% (сталь), 1% (серый чугун), 2% (алюминий). |
| metalproc.ops.investment_casting | Investment Casting — Wax Process | METHOD | Литьё по выплавляемым моделям: восковая модель → кластер → нанесение керамической оболочки (несколько слоёв) → расплавление воска → обжиг → заливка расплава → удаление оболочки → отделка. Точность: IT4-IT7 (без обработки). Шероховатость: Ra 1.5-3 мкм. Для сложных деталей с тонкими стенками. | Авиационные турбинные лопатки: investment casting + directional solidification. |
| metalproc.ops.forging_types | Forging — Types & Terminology | METHOD | Ковка: Open die forging: деформация между плоскими плитами (крупные заготовки). Closed die forging: в штампах → хорошее качество поверхности + точность. Flash: излишек металла в плоскости разъёма. Trimming: удаление облоя. Cold forging: без нагрева (<Tr = 0.3×Tm). Hot forging: при 0.5-0.75×Tm. Closed draft die: угол уклона 3-10°. | Прочность кованых деталей выше литых: ориентированная макроструктура + нет пор. |
| metalproc.ops.turning_machining | Turning — Parameters | METHOD | Токарная обработка: Скорость резания: Vc = π × D × n / 1000 (м/мин). Подача: f (мм/об). Глубина резания: ap (мм). Инструментальный материал: HSS (High Speed Steel), твёрдосплавные (Carbide, TiCN, TiAlN coating), керамика (высокие скорости). MRR (Material Removal Rate) = Vc × f × ap. Tool life Taylor's equation: VT^n = C. | Прерывистое резание: ударные нагрузки → предпочтителен Co-содержащий carbide. |
| metalproc.ops.shot_peening_surface | Shot Peening — Process | METHOD | Дробеструйная обработка: маленькие сферические дроби (стальные, стеклянные, керамические) бомбардируют поверхность → остаточные сжимающие напряжения → улучшение усталостной прочности. Almen strip: измерение интенсивности обработки. Coverage: 98%+ для полноценной обработки. Shot size: 0.1-2 мм. Fatigue improvement: +25-60%. | Усталостные трещины начинаются с поверхности → сжимающие напряжения предотвращают рост. |
| metalproc.ops.electroplating | Electroplating — Principles | METHOD | Гальваническое нанесение: электролит + анод (металл покрытия) + катод (деталь) + постоянный ток. Закон Фарадея: m = M × I × t / (n × F). Равномерность покрытия: зависит от геометрии + тока. Хромирование: CrO3 + H2SO4. Никелирование: NiSO4 + NiCl2. Кадмирование: авиация (коррозионная защита). Barrel plating: для малых деталей. | Высокая плотность тока в краях и выступах (burning effect). |
| metalproc.ops.mig_gmaw_welding | MIG/GMAW — Process Parameters | METHOD | Полуавтоматическая сварка в защитных газах (GMAW/MIG): проволока = плавящийся электрод. Защитный газ: Ar, CO2 (или смеси Ar+CO2). Короткое замыкание (short circuit): тонкие металлы. Глобулярный перенос: средний ток. Струйный (spray): высокий ток. Проволока диаметр: 0.6-1.6 мм. Скорость подачи проволоки (WFS). Параметры: Volts + Amps + WFS. | Ar+CO2 (75/25): хороший баланс цена/качество сварочного шва (С-стали). |
| metalproc.ops.powder_metallurgy_hip | Powder Metallurgy — HIP | METHOD | Порошковая металлургия: прессование + спекание (Conventional). HIP (Hot Isostatic Pressing): высокое давление (100-200 МПа) + температура (1000-1200°C) → 100% плотность. Преимущества: сложные формы, однородная структура, узкий состав. Применение: Ni-superalloys для турбин, инструментальные стали, биомедицинские Ti. | Atomized powder: газовое или водное атомизирование → сферические vs нерегулярные частицы. |
| metalproc.ops.anodizing_aluminum | Anodizing — Process | METHOD | Анодирование алюминия: Al как анод + H2SO4 (5-15%): Al→Al2O3 (пористый оксидный слой). Type II (decorative/protective): 5-25 мкм. Type III (hard anodize): 25-50 мкм (tough). Dyeing: красители заполняют поры. Sealing: горячая вода или хромат закрывают поры. Твёрдость: HV 300-500. Диэлектрик: 10-20 В/мкм. | Рабочий диапазон pH: 2-8 (алюминий корродирует в кислых/щелочных условиях — защита необходима). |
| metalproc.ops.cnc_milling_operations | CNC Milling — Operations | METHOD | Фрезерная обработка с ЧПУ: End mill: торцевое и боковое фрезерование. Face mill: плоские поверхности. Ball end mill: 3D поверхности. Climb milling (попутный): лучшее качество поверхности (нет обратной вибрации). Conventional milling (встречный): старые машины с люфтом. Cutting speed, feed rate, DOC. G-code: стандарт программирования. | Chatter: вибрации → плохое качество. Решение: rigid setup, shorter tool, adjusted speed. |
| metalproc.ops.case_hardening | Case Hardening — Carburizing | METHOD | Поверхностное упрочнение: Цементирование (Carburizing): нагрев в углеродсодержащей атмосфере → диффузия C в поверхность → высокий C → твёрдость при закалке. Carburizing depth: 0.5-2 мм. Gas carburizing: CH4, CO. Азотирование (Nitriding): N диффундирует при 500-600°C → не нужна закалка. Induration hardness: HV 600-1000. | Case depth measurement: тест микротвёрдости поперечного сечения (Vickers). |
| metalproc.ops.wire_edm | Wire EDM — Process | METHOD | Электроэрозионная обработка проволокой (Wire EDM): медная/латунная проволока + диэлектрик (деионизированная вода). Искры эрозии → удаление металла. Точность: ±0.005-0.025 мм. Скорость: 10-50 мм²/мин. Конические срезы возможны. Материал: любой электропроводящий. Нет механических напряжений = лучше для твёрдых/хрупких материалов. | Для: инструментальная сталь, carbide, конически сложные формы. |
| metalproc.ops.weld_inspection_vt_ut | Weld Inspection — Visual & UT | METHOD | Контроль качества сварных швов: VT (визуальный): 100% (минимальный). UT (ультразвуковой): TOFD, Phased Array для внутренних дефектов. RT (рентгенографический): плёнка/цифровой. MT (магнитопорошковый): поверхностные трещины в ферромагнитных. PT (пенетрантный): поверхностные трещины в немагнитных. AWS D1.1: стандарт оценки. | Radiography vs PAUT: RT = ионизирующее облучение, PAUT = более безопасный, better sizing. |
| metalproc.ops.deformation_cold_work | Cold Working — Work Hardening | METHOD | Холодная деформация: пластическая деформация ниже Tr (0.3×Tm). Дислокации накапливаются → блокируют движение → рост твёрдости/прочности (work hardening). Дробеструйное выглаживание, cold rolling, wire drawing. Наклёп % = (A0 - Af) / A0 × 100. Ограничение: трещины при избыточной деформации. Отжиг: снятие наклёпа. | Стальная проволока (cold drawn): прочность 1500+ МПа (vs hot rolled ≈500 МПа). |
| metalproc.ops.hot_rolling_defects | Hot Rolling — Defects | METHOD | Дефекты горячей прокатки: Расслоение (lamination): внутренние включения → слои расслаиваются. Морщины (laps): материал загибается → склеивается. Окалина (scale): оксидные плёнки → вкатаны. Волнистость (warping): неравномерное охлаждение. Плены (slivers): трещины поверхности. Контроль: температура, смазка, скорость. | Закаленная сталь (pickled and oiled, P&O): удалена окалина → чистая поверхность. |
| metalproc.ops.superalloy_machining | Superalloy Machining — Challenges | METHOD | Обработка жаропрочных сплавов: High strength, work hardening, low thermal conductivity → тяжёлые условия. Nickel superalloys (IN718, Waspaloy): CBN tools, ceramic inserts. Cutting speed: 50-100 м/мин (vs 200+ для стали). Coolant: высокое давление (флуид под давлением → охлаждение). Grain boundary oxidation: минимизировать T. Ti-6Al-4V: химически активный → задиры. | Superalloy machining cost: в 5-10× дороже обычной стали (tool wear). |
| metalproc.ops.grinding_abrasive | Grinding — Wheel Selection | METHOD | Шлифование: абразивный материал (Al2O3, SiC, CBN, алмаз), связка (vitrified, resin), размер зерна (FEPA). Burns: перегрев поверхности → остаточные растягивающие напряжения → усталость. Dress: алмазный накатник → восстановление формы. Spark-out: несколько проходов без подачи. Peripheral vs Surface grinding. G-ratio: металл/инструмент removal ratio. | Grinding burn + tensile residual stress: в поверхности = усталостный риск. |
| metalproc.ops.thixoforming | Semi-Solid Processing — Thixoforming | METHOD | Тиксоформование: металл в полутвёрдом состоянии (30-50% жидкого). Структура: тиксотропная (перемешивание снижает вязкость). Преимущества: меньше пористости чем литьё, более высокая точность. Сплавы: Al (A356, A357), Mg. Нагрев в mushy zone: температура точно контролируется. Производительность: меньше отходов + ближе к конечной форме. | Ограничение: только сплавы с широким pasty range. |
