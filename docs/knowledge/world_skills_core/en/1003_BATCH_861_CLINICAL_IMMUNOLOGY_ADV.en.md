# BATCH 861: Advanced Topics — Immunology Clinical

|---|---|---|---|---|
| clinimmune.ops.allergen_immunotherapy | Allergen Immunotherapy — SCIT | METHOD | Специфическая иммунотерапия (SCIT): подкожные инъекции аллергена. Механизм: ↑ IgG blocking antibodies + ↑ Treg + ↓ Th2. Эффективность: аллергический ринит, астма, насекомые. Доза эскалация: 6-12 мес → поддержка 3-5 лет. Systemic reactions: ~1/1 млн инъекций (смертельные). SLIT (сублингвально): не так эффективно как SCIT, более безопасно. | Ожидать 20 минут после SCIT инъекции (поздняя реакция). |
| clinimmune.ops.csid_treatment | Primary Immunodeficiency — Treatment | METHOD | Лечение ПИД: XLA (Bruton's): ВВИГ (Intravenous Immunoglobulin) каждые 3-4 нед. SCID: трансплантация стволовых клеток. ADA дефицит SCID: ERT (Revcovi, PEG-ADA) или генная терапия. CGD: профилактические антибиотики (TMP-SMX) + антифунгальные + IFN-γ. IVIG: при большинстве антительных дефицитов. | IVIG цель: IgG тrough ≥ 500-800 мг/дл (функционального уровня). |
| clinimmune.ops.rejection_types | Transplant Rejection — Types | METHOD | Виды отторжения трансплантата: Hyperacute (<24ч): ABO несовместимость + преформированные антитела → тромбоз. Острое клеточное (≤3 мес): T-клетки. Острое AMR (антительное): DSA + C4d. Хроническое: обструктивная бронхиолите (лёгкие), хроническая нефропатия (почки). Tx: Hyperacute = нет лечения. ACR: стероиды. | DSA (Donor Specific Antibodies): критичный маркер риска AMR. |
| clinimmune.ops.gvhd_prevention | GvHD — Prevention Strategies | METHOD | Профилактика РТПХ: метотрексат + такролимус (стандарт). Циклофосфамид (post-transplant): альтернатива. T-клеточное деплеция. ATG (anti-thymocyte globulin): для mismatched или unrelated. Острая РТПХ Grade I-IV: кожа + ЖКТ + печень. Лечение: стероиды. Рефрактерная: руксолитиниб. | Chronic GvHD: резкое снижение качества жизни. Может имитировать многие аутоиммунные. |
| clinimmune.ops.ivig_clinical_use | IVIG — Clinical Indications | METHOD | Внутривенный иммуноглобулин (IVIG): иммунозаместительная терапия (ГИПО-гаммаглобулинемия). Иммуномодулирующая: ITP, GBS, Kawasaki, MG crisis, AIE, HAE (профилактика). Доза: 2 г/кг при иммуномодулирующей vs 0.4 г/кг/мес при заместительной. Побочные: головная боль, тромбоз, гемолиз, TRALI, почечная недостаточность. | Sucrose-containing IVIG: ↑ риск почечной недостаточности. Избегать у почечно-недостаточных. |
| clinimmune.ops.biological_screening | Biologics — Pre-Treatment Screening | METHOD | Скрининг перед биологической терапией: Все биологики: ТБ (QuantiFERON/TST), CBC, HBV serologies, HIV, HCV. Анти-ТНФ дополнительно: кожный тест на ТБ (хотя предпочтителен IGRA). Ритуксимаб: Hepatitis B surface antigen + core antibody (реактивация без профилактики → смертоносная). JAK inhibitors: тромбоз + MACE риск. | HBsAg+ при ритуксимабе → антивирусная профилактика: энтекавир. |
| clinimmune.ops.anaphylaxis_pathophysiology | Anaphylaxis — Biphasic Reaction | METHOD | Анафилаксия: бифазная реакция в 20%. Рецидив через 1-72 ч (обычно 4-12 ч). Поэтому наблюдение ≥4-6 ч. Кортикостероиды: для предотвращения бифазной (спорные данные). Фенилэфрин: НЕ используется при анафилаксии (нет бета-адренергического действия). Только Эпинефрин первая линия. | EpiPen техника: внешняя поверхность бедра, через одежду. Позиция: не стоять (вазодилатация). |
| clinimmune.ops.hereditary_angioedema | HAE — Bradykinin-Mediated | METHOD | Наследственный ангиоотёк (НАО): дефицит C1-ингибитора. НЕ гистамин-опосредованный → антигистамины НЕ работают. Острые атаки: иктибант (B2-рецептор антагонист), C1-INH concentrate, калликреин ингибитор (экаллантид). Профилактика: транексамовая кислота, ланадолумаб. | НАО на адреналин НЕ реагирует — критически важно знать для ER. |
| clinimmune.ops.eosinophilic_disease | Eosinophilic Disorders — Clinical | METHOD | Эозинофилия: паразиты (#1 в мире), астма/аллергии (#1 в развитых), DRESS, eosinophilic pneumonia, eosinophilic GI disease. AEC (Absolute Eosinophil Count) > 1500: исследование причины. HES (Hyper-Eosinophilic Syndrome): > 1500 + органное поражение. Лечение: стероиды, меполизумаб (anti-IL-5). | FIP1L1-PDGFRA мутация при HES: иматиниб эффективен (TKI). |
| clinimmune.ops.systemic_vasculitis | ANCA Vasculitis — GPA vs MPA | METHOD | ANCA васкулит: GPA (Granulomatosis with Polyangiitis): c-ANCA/PR3. Granulomas. Upper respiratory tract + lungs + kidneys. MPA (Microscopic Polyangiitis): p-ANCA/MPO. Нет granulomas. Pulmonary hemorrhage. EGPA: эозинофилия + astma + p-ANCA. Индукция: ритуксимаб (GPA/MPA) или циклофосфамид. | ANCA testing: ELISA PR3/MPO specific (не immunofluorescence alone). |
| clinimmune.ops.systemic_sclerosis | Systemic Sclerosis — Subtypes | METHOD | Системная склеродермия (SSc): Limited cutaneous (lcSSc): кожа distal extremities + CREST. Диффузная (dcSSc): проксимальные конечности + туловище. Autoantibodies: ATA/anti-Scl-70 (dcSSc + ILD), anti-centromere (lcSSc + PAH), anti-RNA polymerase III (diffuse + renal crisis). | Склеродермический почечный криз: ARB/ИАПФ + NO антигипертензивные. Стероиды → риск криза. |
| clinimmune.ops.immunology_aging | Immunosenescence — Clinical | METHOD | Иммунное старение: ↓ Наивные T- и B-клетки. ↑ Memory cells. Thymic involution: ↓ новые T-клетки. Inflammaging: хроническое субклиническое воспаление. Вакцинация: ↓ ответ у пожилых (высокодозная инфлюенза вакцина). Герпес зостер: из-за ↓ иммунного контроля VZV. | Shingrix (рекомбинантная): >90% эффективность против зостера у >50 лет (vs Zostavax 50-60%). |
| clinimmune.ops.drug_desensitization | Drug Desensitization — Mechanism | METHOD | Десенсибилизация к лекарствам: для пациентов с IgE-опосредованной аллергией к необходимым препаратам (аспирин, цисплатин, пенициллин). Постепенная эскалация дозы → исчерпание тучных клеток → толерантность. Временная: прекратить → повторить десенсибилизацию. Only for: IgE-mediated, non-severe reactions. | Аспириновая десенсибилизация: при NSAID-exacerbated respiratory disease. |
| clinimmune.ops.cold_agglutinin | Cold Agglutinin Disease | METHOD | Болезнь холодовых агглютининов (CAD): гемолитическая анемия. Аутоантитела IgM + холодовая активность + комплемент. Первичная (идиопатическая) vs вторичная (инфекция, лимфома). Смотреть: ретикулоцитоз + ↑ LDH + ↓ гаптоглобин. Лечение: избегать холода + ритуксимаб. | Тест Кумбса: прямой+ (C3d) — потому что IgM стирается при умывании. |
