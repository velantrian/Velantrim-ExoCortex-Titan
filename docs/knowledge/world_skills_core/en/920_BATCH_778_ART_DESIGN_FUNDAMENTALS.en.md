Similarity (схожесть): похожие — как группа. Continuity: взгляд следует по кривой/линии. Closure: мозг «закрывает» неполные формы. Figure/Ground (фигура/фон): различение объекта от фона. Phi grid (сетка Фибоначчи) vs Rule of Thirds: схожи но точнее. | Логотипы (Twitter bird, Apple logo): используют золотое сечение. |

| artdesign.ops.photography_composition | Photography — Rule of Thirds | METHOD | Правило третей (фотографи): главный объект на линиях 1/3 или в точках пересечения. Eye-level: на уровне глаз (портрет). Horizon: не по центру (ниже = больше неба, выше = больше земли). Leading lines: направляют взгляд. Framing: использовать элементы как рамку. Depth of field: контроль над фокусировкой. | «Breaking the rule»: если знаешь правила, можешь нарушать их намеренно. |
| artdesign.ops.color_modes | Color Modes — RGB vs CMYK | METHOD | Цветовые режимы: RGB (экраны): Red, Green, Blue. Additive (white = all). Gamut: широкий, sRGB vs AdobeRGB. Hex code (#RRGGBB). HSL: Hue, Saturation, Lightness. CMYK (печать): Cyan, Magenta, Yellow, Key/Black. Subtractive. Конвертация RGB→CMYK: не идеальна (gamut). PMS (Pantone): стандартизированные краски. | Разработка для экрана: RGB. Печать: CMYK. Без конвертации = неожиданные цвета. |

Follow Through. Slow In/Slow Out (Ease). Arc. Secondary Action. Timing. Exaggeration. Solid Drawing. Appeal. Easing functions: linear, ease-in, ease-out, ease-in-out. | After Effects easing: F9 = auto ease. Custom bezier для organic motion. |
