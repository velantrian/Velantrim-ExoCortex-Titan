# BATCH 716: Media Production — Film & Video

**Namespace:** `mediaprod.ops.*`
**Scope:** preproduction, cinematography, lighting, sound, editing, color_grading, distribution, VFX, streaming, script

| ID | KnowledgeUnit | Тип | Суть | Практический смысл |
|---|---|---|---|---|
| mediaprod.ops.script_coverage_format | Script — Industry Coverage | METHOD | Coverage (скрипт-ридерский отчёт): Logline (1-2 предложения), Synopsis (1/2-1 страница), Comments (2-3 стр), Recommendations: Consider/Pass/Recommend. Форматный стандарт: Final Draft, Courier 12pt (1 страница ≈ 1 мин экранного времени). ACT structure: 3-актная. Turning points: конец 1-го акта (25%), midpoint (50%), конец 2-го (75%). | Spec script: написан для продажи/самостоятельно. Shooting script: с scene numbering для производства. |
| mediaprod.ops.camera_exposure_triangle | Camera — Exposure Triangle | METHOD | Треугольник экспозиции: ISO × Aperture (f-stop) × Shutter speed. ISO: чувствительность (↑ISO = ↑шум). Aperture: f/2.8 = широко (мало ГРИП, много света), f/16 = узко (большая ГРИП, мало света). Shutter speed: 180° rule (кино) = 1/(2×fps): 24fps → 1/48 сек. ND filter: снижает свет без изменения aperture/shutter. | Гиперфокус: расстояние при котором всё от f/2 до ∞ в фокусе. |
| mediaprod.ops.three_point_lighting | Three-Point Lighting — Setup | METHOD | Трёхточечное освещение: Key light (основной): сильнейший источник, 45° по горизонтали, 45° по вертикали. Fill light (подсветка): снижает тени от key (0.5-1 ступень ниже key, с противоположной стороны). Back light/Hair light: выделяет субъект от фона. Lighting ratio: 3:1 (умеренный контраст), 8:1 (драматический). | Rembrandt lighting: key light под углом → треугольный «блик» под глазом. |
| mediaprod.ops.audio_boom_placement | Production Sound — Boom Placement | METHOD | Микрофон-журавль (boom): тип — hypercardioid или shotgun. Позиция: как можно ближе к субъекту (вне кадра), угол 45° сверху вниз. Boom operator: ориентировать нулевой угол на рот. Rejection lobe: 90°+ = максимальное подавление. Room tone: запись тишины для монтажа. Wireless lavalier (петличный): backup, скрыть под одеждой (rustle protection). | Dead Cat (windscreen): для съёмок на ветру (внешний windscreen). |
| mediaprod.ops.editing_timeline_workflow | Editing — Offline/Online Workflow | METHOD | Монтажный рабочий процесс: Offline editing (низкое разрешение, прокси): Avid, Premiere, Final Cut. EDL (Edit Decision List) или AAF/XML: связь между offline и online. Online conform: высококачественный исходник (RAW, 4K+). Color grading (DaVinci Resolve). Sound mix. VFX shots. Mastering. DCP (Digital Cinema Package): для кинотеатров. | Proxy workflow: 4K RAW → 1/4 размер прокси для монтажа → conform при финализации. |
| mediaprod.ops.color_grading_lut | Color Grading — LUT Application | METHOD | Цветокоррекция: LUT (Look-Up Table) = цветовое преобразование. Types: Technical LUT (camera log → display), Creative LUT (стилизация). Log-C, S-Log, Log3G10: камерные цветовые пространства (высокий динамический диапазон → нужна конвертация). ACES (Academy Color Encoding System): industry standard pipeline. DCI-P3, Rec.709, HDR Rec.2020: display spaces. | Первичная коррекция: баланс белого, экспозиция. Вторичная: маска, отдельные цвета. |
| mediaprod.ops.vfx_compositing_workflow | VFX — Compositing Pipeline | METHOD | VFX: Live Action plate + CGI → compositing (After Effects, Nuke). Chroma key (green screen): зелёный фон → удалить → background replace. Rotoscoping: ручная маска вокруг объекта. Motion tracking: CG следует за camera. Match moving: 3D camera = real camera. Colour matching: CGI элементы = живой съёмке. 2D vs 3D compositing. | Green screen lighting: равномерный фон (нет shadow) + actor lit separately. |
| mediaprod.ops.documentary_shooting_ratio | Documentary — Shooting Ratio | METHOD | Съёмочное соотношение (shooting ratio): снятые минуты / мин в финальном фильме. Drama: 10:1-20:1. Documentary: 50:1-200:1. Cinéma vérité: max ratio (наблюдение). Структура: observational, participatory, reflexive, poetic, performative, expository. Release форматы: theatrical, streaming (OTT), broadcast. | B-roll: cutaway footage для покрытия (не интервью). |
| mediaprod.ops.streaming_bitrate | Streaming — Bitrate & Codec | METHOD | Стриминговые форматы: H.264 (AVC): 4-8 Мбит/с (1080p). H.265 (HEVC): в 2× сжатие при том же качестве. AV1: лучше HEVC, открытый (YouTube, Netflix). Adaptive bitrate (ABR): HLS/DASH автоматически выбирают качество. CDN (Content Delivery Network): кэширование для уменьшения latency. Container: MP4, MKV, MOV. | VMAF (Video Multi-Method Assessment Fusion): Netflix метрика качества. |
| mediaprod.ops.production_budget_breakdown | Production Budget — Line Items | METHOD | Бюджет производства: Above-the-line (ATL): режиссёр, сценарист, продюсер, актёры. Below-the-line (BTL): все остальные (crew, equipment, locations, catering, insurance). Post-production. Contingency (резерв): 10-15%. Above/Below ratio: drama ~30/70, indie vs studio varies. SAG-AFTRA rates: scale + 10% (стандартные гонорары). | Дополнительные расходы: CGI, music rights, E&O insurance — недооценены в бюджетах. |
| mediaprod.ops.music_licensing | Music Licensing — Sync Rights | METHOD | Синхронизационные права (Sync License): использование музыки в visual media. Нужны два права: Sync (от издателя), Master (от звукозаписывающей компании). Фоновая музыка: clearance обязательна. Festival premiere: temp track права. Public domain: before 1928 (USA). Creative Commons: некоторые права разрешены. Royalty-free vs rights-managed: не одно и то же! | «Royalty-free» = купил однажды, используй без доп.роялти. Не значит бесплатно. |
| mediaprod.ops.audio_mix_levels | Audio Post — Broadcast Standards | METHOD | Аудио-стандарты: Broadcast (USA): ATSC A/85, R128 (Europe). Loudness: -23 LUFS (integrated, TV). Peaks: -2 dBFS. Netflix: -27 LUFS (film). Диалог: -27 dBFS. True Peak: -1 dBFS. Stereo vs 5.1 vs Dolby Atmos. Mix elements: dialogue, music, effects (DME). | LUFS vs dBFS: LUFS = perceptual (closer to hearing). dBFS = peak (digital). |
| mediaprod.ops.drone_aerial_filming | Aerial Filming — FAA Part 107 | METHOD | Аэросъёмка дроном (USA FAA Part 107): сертификат Remote Pilot Certificate. Ограничения: max 400 ft AGL, daylight или twilight (anti-collision lights), LOS (Line of Sight). BVLOS: требует waiver. Class B/C/D/E airspace: нужна авторизация (LAANCIE app или DroneZone). Class G: разрешено. Запрет: над людьми (без waiver), moving vehicles. | Certificate of Waiver: до 400 ft в airspace → заявка за 90 дней. |
| mediaprod.ops.script_supervisor | Script Supervisor — Continuity | METHOD | Монтажница (Script Supervisor): ответственна за непрерывность (continuity) съёмок. On-set notes: который дубль (take), какие изменения в диалоге, входы/выходы актёров (слева/справа), позиция Props (sightline). Editor's log: передаётся в монтаж. Continuity photos: каждый кадр. Match cut: two angle должны «совпасть». | Eyeline: куда смотрит актёр должно соответствовать тому что он «видит» в следующем кадре. |
| mediaprod.ops.production_design_concept | Production Design — Concept Development | METHOD | Художник-постановщик (Production Designer): создаёт визуальный мир фильма. Lookbook: референсы (art, photography, films). Colour palette per scene/act. Props master: реквизит (hero props = крупные планы). Set Decorator: обстановка. Art Director: техническое исполнение. Collaboration: Director + DP (Director of Photography) + PD. | Production Design budget: small indie 2-5% of total budget. Blockbuster: 15-20%. |
| mediaprod.ops.camera_movement_types | Camera Movements — Types | METHOD | Типы движения камеры: Pan (поворот горизонтально). Tilt (поворот вертикально). Dolly (движение вдоль рельс). Track (с рельсами — smooth). Handheld (ручная — organic). Steadicam: стабилизатор для ходьбы. Crane/Jib: вертикальный подъём. Dutch angle (наклон): дезориентация. Zoom vs Dolly-Zoom (Hitchcock zoom/Vertigo effect). | Каждое движение камеры = смысловое (не только aesthetic). |
| mediaprod.ops.distribution_windows | Distribution — Release Windows | METHOD | Окна дистрибуции: Theatrical (театральный прокат): 45-90 дней эксклюзивности (уменьшается). PVOD (Premium Video On Demand): premium early rental. EST (Electronic Sell Through): download to own. SVOD (Subscription): Netflix, Disney+. AVOD (Ad-supported): Peacock, Pluto. Free TV (broadcast): последнее окно. International: separate licensing deals per territory. | Day-and-date release: театр + streaming одновременно (спорно, COVID ускорил). |
| mediaprod.ops.aspect_ratio_format | Aspect Ratio — Format Selection | METHOD | Соотношение сторон: 1.33:1 (4:3): классическое TV. 1.78:1 (16:9): HD television, streaming. 1.85:1: North American theatrical standard. 2.39:1 (Scope/Anamorphic): widescreen theatrical. 4:3 → letterbox effect на 16:9 экране. Super 16: 1.66:1. IMAX: 1.43:1 (full frame). | Anamorphic lens: горизонтальное сжатие на съёмке, «rasтягивается» при проекции → специфическое боке. |
| mediaprod.ops.crew_hierarchy | Film Crew — Hierarchy | METHOD | Съёмочная группа: Director (режиссёр), Producer, Line Producer (бюджет+логистика). Director of Photography (DoP/DP), Camera Operator, First AC (фокус), Second AC (клапперборд). Gaffer (chief electrician), Key Grip, Best Boy (assistants). Sound Mixer, Boom Operator. 1st AD (Assistant Director: schedule on set). Script Supervisor. Crafty: catering. | 1st AD: режим сета — «мотор!», «стоп!», порядок на площадке. |
