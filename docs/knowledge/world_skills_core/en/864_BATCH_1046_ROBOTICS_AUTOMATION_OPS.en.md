| robotics.ops.forward_kinematics | Forward Kinematics — DH Parameters | METHOD | Прямая кинематика (FK): из углов суставов → положение конечного эффектора. Метод Denavit-Hartenberg (DH): 4 параметра на каждый сустав: d (offset), θ (joint angle), a (link length), α (twist). Матрица преобразования T = Rot(z,θ) × Trans(z,d) × Trans(x,a) × Rot(x,α). Цепочка матриц: T_0_n = T_01 × T_12 × ... × T_{n-1}_n. | Для 6-DOF robot: 6 матриц перемножить → pose end-effector. |
| robotics.ops.inverse_kinematics_solutions | Inverse Kinematics — Multiple Solutions | METHOD | Обратная кинематика (IK): из заданной позиции/ориентации → углы суставов. Аналитическое решение: для простых конфигураций. Numerical (Jacobian pseudoinverse): J†Δx = Δq. Multiple solutions: «локоть вверх/вниз», «запястье флип» — нужно выбрать. Singularities: det(J) = 0 → неопределённость. Workspace limitations: не все позиции достижимы. | IKFast (ROS): fast analytical IK для конкретных конфигураций. |
| robotics.ops.lidar_slam | SLAM — LiDAR Odometry | METHOD | SLAM (Simultaneous Localization and Mapping): Pose estimation (odometry: wheel encoder, IMU) + map building. LiDAR SLAM: 2D (Hector, Gmapping) или 3D (Cartographer, LIO-SAM). LOAM (LiDAR Odometry and Mapping): edge/plane feature extraction. Loop closure: обнаружение уже виденного места → коррекция drift. Point cloud: облако точек. | IMU + LiDAR fusion: IMU высокая частота (100-400 Hz), LiDAR точность (10-20 Hz). |
| robotics.ops.pid_controller_tuning | PID — Tuning Methods | METHOD | ПИД-регулятор: u(t) = Kp×e(t) + Ki×∫e(t)dt + Kd×de/dt. Kp: пропорциональный (прямой отклик). Ki: интегральный (устраняет steady-state error). Kd: дифференциальный (предсказание). Ziegler-Nichols: медленно поднимать Kp до незатухающих колебаний (Ku) → Ki = 0.6Ku, Ti = 0.5Tu, Td = 0.125Tu. Auto-tune (Astrom & Hagglund). | Интегральное насыщение (windup): ограничение интеграла → anti-windup. |
| robotics.ops.ros2_node_topics | ROS 2 — Nodes, Topics, Services | METHOD | ROS 2 (Robot Operating System): Node = исполняемая единица. Topic = asyncronous pub/sub (sensor_msgs/LaserScan). Service = synchronous req/res (std_srvs/Trigger). Action = goal/feedback/result для long-running tasks. DDS (Data Distribution Service): middleware. Parameters: runtime configurable (ros2 param set). Launch files: Python-based (vs XML в ROS1). | ROS 2 vs ROS 1: real-time capable, no rosmaster, DDS multicast. |
| robotics.ops.gripper_types | Grippers — Types Selection | METHOD | Захватные устройства: Parallel jaw gripper: простые, 2D, metal/plastic parts. Vacuum cup: плоские поверхности, быстро. Magnetic: ferro-metal parts. Soft gripper (pneumatic, form-fitting): fragile objects (fruit, PCB). Adaptive (Robotiq 2F/3F): конформные пальцы. Pincer (hook): cables. Force/torque sensor: качество захвата, slip detection. | Vacuum + non-porous surface: leakage check перед lift (suction cup) |
| robotics.ops.industrial_robot_programming | Industrial Robot — Teach Pendant | METHOD | Программирование промышленного робота: Teach Pendant: ручной контроллер (FANUC TP, KUKA KRC). Режимы: T1 (медленно, <250 мм/сек), T2 (полная скорость, ручной контроль), Auto. Точки: JOINT (углы) vs CARTESIAN (X/Y/Z/R/P/W). Команды: MOVE, IF/ELSE, WAIT, CALL. Offline programming (OLP): RobotStudio (ABB), KUKA Sim Pro. | Координатная система инструмента (TCP): обязательно настроить перед программированием путей. |
| robotics.ops.torque_sensing_cobot | Collaborative Robot — Safety | METHOD | Коллаборативный робот (Cobot): ISO/TS 15066: Power and Force Limiting (PFL), Speed and Separation Monitoring (SSM). Мощность/сила: допустимое контактное давление <50 Н (голова). Force sensing at joints: Рexterix (внутренний). Фиксация по нагрузке: при контакте → стоп. | robotics.ops.vision_system_calibration | Machine Vision — Camera Calibration | METHOD | Калибровка камеры: шахматная доска → обнаружение углов. Zhang's method: несколько ракурсов. Stereo calibration: R, T, E, F (essential, fundamental matrix). OpenCV calibrateCamera(). | Distortion correction: особенно важна для широкоугольных объективов. |
| robotics.ops.trajectory_planning_trapezoidal | Trajectory Planning — Trapezoidal Profile | METHOD | Трапециевидный профиль скорости: разгон → постоянная скорость → торможение. Параметры: jerk, acceleration, max velocity. Переходные расчёты: t_acc = v_max / a_max, t_const = (d - 2×v_max²/2a_max) / v_max. При малом расстоянии: треугольный профиль (нет constant section). S-curve (jerk-limited): более плавный. | Рвок (jerk) = ускорение ускорения: ограничение снижает вибрации → лучшая точность позиционирования. |
| robotics.ops.motor_encoder_feedback | Encoder — Feedback Types | METHOD | Датчики положения: Encoder (incremental): квадратурный сигнал A/B → направление + количество. Backlash: мёртвая зона (gear play → позиционный error). | Home position: incremental encoder требует home routine при включении. |
