| flightcater.ops.cook_chill_production | Cook-Chill — Production Method | PROCESS | Приготовление еды для авиакейтеринга (cook-chill). Еда готовится за 24-72 часа до вылета. Процесс: Cook (приготовить как обычно) → Portion (порционировать) → Blast Chill (быстрое охлаждение: 70°C → 3°C за 90 мин, FDA code). Хранение: 0-3°C до загрузки в лотки. Reheat на борту: convection oven 150-170°C, 20-30 мин (или steam oven). Blast chiller: мощное охлаждение (liquid nitrogen или mechanical), застывание в ядре продукта за 90 мин. Почему: предотвращение bacterial growth (Clostridium perfringens — быстро размножается в медленно остывающей еде). Micro testing: каждая партия sample отбирается (incubate 48 ч), если pathogens — партия discarded. Shelf-life cook-chill: 5 дней при 0-3°C. | Альтернатива: Cook-Freeze (заморозка после приготовления до −18°C, shelf-life 6+ мес, разморозка/регенерация перед рейсом). Но текстура хуже. |
| flightcater.ops.trolley_load_plan | Trolley — Loading & Weight Distribution | METHOD | Комплектация тележек для рейса. Trolley Types: ATLAS (стандартный, полу-размерные лотки), KSSU (узкие контейнеры). Загрузка: Galley Loading Plan (GLP) — документ на каждый рейс, определяет какие тележки и где (Forward/Mid/Aft galley). Каждый trolley: maximum weight загрузки (100-150 кг полная). Bar trolley: напитки + glassware. Meal trolley: trays (meal tray set). Dry stores trolley: чай/кофе, закуски, duty-free. Drawer layout: tray stacked в drawers. First/Business Class: a la carte trolley (presentation dishes, show plating). Подсчёт: catering uplift = number of passengers + crew + extra (5-10% buffer для special meals, spills). Last-minute changes: load control сообщает final passenger count за 60-90 мин до вылета (после закрытия регистрации) — catering может скорректировать uplift (add/remove trolleys). Вес: catering входит в aircraft weight & balance (dry operating weight). | Special meals (SPML): заказ за 24-48 часов. Категории: VGML (vegan), KSML (kosher), MOML (muslim), GFML (gluten-free), CHML (child), LSML (low-sodium). Загружаются отдельно с биркой «SPML — seat 23A». |
| flightcater.ops.ramp_security_seal | Vehicle Security — Seal & Access Control | METHOD | Безопасность доставки питания. Gate check: catering truck at security gate → driver ID + biometric (airport badge). Vehicle search: random inspection, mirrors underneath. Seal: каждый trolley и контейнер закрыт на security seal (numbered plastic/metal tag). Seal log: номер seal записан в GLP. При передаче экипажу: crew проверяет seal intact. Если seal broken — содержимое не принимается (security risk, sabotage). Catering truck: lift raises box to aircraft door (A320/A330/A340 door 1R или 2R). One loading door. Truck driver only: trained in airside driving + aircraft approach safety. Vehicle clearance: under wing (A320: truck height max 3.4 м при опущенной платформе). | Известный случай: sabotage через catering (закладка взрывчатки/наркотиков). Seal контроль — часть многослойной авиационной security. |
| flightcater.ops.tray_assembly_line | Tray Set — Assembly Line Production | PROCESS | Компоновка подносов на конвейере. Линейная сборка: staff расставлены по stations. Tray (base) → Appetizer/salad → Main course (casserole) → Dessert → Bread/butter → Cutlery wrap (Knife/Fork/Spoon, салфетка, соль/перец) → Cup/glass → Lid cover + date sticker. Скорость: trays/мин на линии (10-20 trays/мин). Разные конфигурации подносов для разных классов (Y — economy: pre-set tray, C — business: отдельная сервировка). First Class: набор не на tray, на стол белой скатертью (как ресторан). Tray recycling: trays моются в industrial dishwasher (tunnel) 80°C, затем возврат в production line. Linen: салфетки/скатерти меняются between flights (стирка). Cutlery: металл (business/first) — wash + repolish, пластик (economy) — single use. | Meal count: tray должен соответствовать загрузке рейса. Не доложить: passenger без еды — complaint. Переложить: waste + вес. |
| flightcater.ops.galley_equipment_standard | Galley Equipment — Standard Insert Sizing | METHOD | Оборудование кухни в самолёте. Стандарт ATLAS (Air Transport Association of America): inserts (GN pans, trays). Размеры GN 1/1 (530×325 мм), 1/2, 1/3, 2/3. Совместимы с trolleys, ovens, chillers. Ovens: конвекционные или steam. Beverage makers: кофе-машина (Bunn/Curtis) + горячая вода. Galley waste management: мусор утрамбовывается назад в trolley. После приземления: trolley с мусором возвращается в flight kitchen (очистка). Galley equipment на борту — часть Supplemental Type Certificate (STC). Нельзя переставлять без engineering approval (weight & balance, emergency egress). Проверка перед вылетом: galley secure (все trolleys locked, ovens empty, coffee maker off). | Galley equipment: каждая airline имеет свою конфигурацию galley на конкретном типе воздушного судна (Layout of Passenger Accommodations — LOPA). |
