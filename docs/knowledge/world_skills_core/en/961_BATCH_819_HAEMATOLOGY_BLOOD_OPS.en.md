# BATCH 819: Haematology — Blood Disorders

**KnowledgeUnits:** 50
**Namespace:** `haematology.ops.*`
**Scope:** anaemia, coagulation_disorders, leukemia, lymphoma, bone_marrow_transplant, anticoagulation, thrombocytopenia, blood_transfusion, myeloma

| ID | KnowledgeUnit | Тип | Суть | Практический смысл |
|---|---|---|---|---|
| haem.ops.anaemia_classification | Anaemia — MCV Classification | METHOD | Классификация анемии по MCV: Микроцитарная (<80 fL): Fe-дефицит (самая частая), талассемия, сидеробластная. Нормоцитарная (80-100 fL): хроническое заболевание, апластическая, гемолитическая, ранний дефицит Fe. Макроцитарная (>100 fL): дефицит B12, фолиевой кислоты, алкоголь, гипотиреоз. | Ретикулоциты: при гемолитической = высокие. При апластической = низкие (гипорегенераторная). |
| haem.ops.iron_deficiency | Iron Deficiency Anaemia — Diagnosis | METHOD | Анемия железодефицитная: снижение Hb + низкий MCV. Ферритин <30 нг/мл: диагностический (если не воспаление). TIBC ↑. Сывороточное железо ↓. Причины: кровопотеря (#1 у взрослых), мальабсорбция, беременность. Лечение: пероральное Fe (сульфат, фумарат). IV Fe: при мальабсорбции или нарушении переносимости. | Ферритин острофазовый реагент: при воспалении ложно «нормальный». |
| haem.ops.b12_folate_deficiency | B12/Folate — Deficiency | METHOD | Мегалобластная анемия: дефицит B12 или фолиевой кислоты → нарушение синтеза ДНК → макроцитоз. B12 нейтропения: нейропатия (subacute combined degeneration of spinal cord). Дефицит фолата: нет нейропатии. Тест на метилмалоновую кислоту: повышена при B12, не при фолиевой. Лечение: цианокобаламин IM или высокие пероральные дозы. | Нельзя давать только фолат при B12 дефиците: улучшает анемию но не неврологию. |
| haem.ops.itp_immune_thrombocytopenia | ITP — Diagnosis | METHOD | Иммунная тромбоцитопения (ИТП): тромбоциты <100 000 без другой причины. Первичный vs вторичный (СКВ, ВИЧ, H. pylori). ИТП острая (дети): чаще после вирусной инфекции. Хроническая (взрослые): чаще женщины. Лечение: при тромбоцитах >30 000 без симптомов — наблюдение. Стероиды (преднизолон). ВВИГ: при кровотечении. ТПО-агонисты: при хронической. | ITP ≠ TTP. TTP: тромбоциты ↓ + гемолитическая анемия + неврология + почки. |
| haem.ops.cml_bcr_abl | CML — BCR-ABL & TKI | METHOD | Хронический миелоидный лейкоз: BCR-ABL1 (Philadelphia chromosome t(9;22)). Три фазы: хроническая → акселерация → бластный криз. Лечение: TKI (иматиниб 1-я поколение, нилотиниб/дазатиниб 2-е, поnatinib 3-е). Молекулярный ответ: BCR-ABL < 0.1% (Major Molecular Response). | Иматиниб: революция в ХМЛ. До 2001: медиана выживаемости 5 лет. После: >90% 10-летняя. |
| haem.ops.hodgkin_lymphoma | Hodgkin Lymphoma — Staging | METHOD | Лимфома Ходжкина: Клетки Рид-Штернберга (owl-eye). Стадирование (Ann Arbor): I (одна зона), II (2+ зоны одной стороны диафрагмы), III (обеих сторон), IV (диссеминация). B-симптомы: лихорадка, ночной пот, потеря >10% веса. Лечение: ABVD химиотерапия + лучевая. ПЭТ-адаптированная терапия. | PET-adapted: если ПЭТ-негативен после 2 цикла → продолжить. ПЭТ-позитивен → интенсификация. |
| haem.ops.nhl_diffuse_large_b | Non-Hodgkin Lymphoma — DLBCL | METHOD | Диффузная В-крупноклеточная лимфома (ДBKК/DLBCL): наиболее частая НХЛ. IPI (International Prognostic Index): возраст, LDH, статус, стадия, экстрановые области. Лечение: R-CHOP (ритуксимаб + CHOP). CAR-T клетки: при рецидиве. GCB vs Non-GCB: молекулярные подтипы. | ЛДГ: суррогатный маркер tumor burden и активности в лимфоме. |
| haem.ops.multiple_myeloma | Multiple Myeloma — CRAB Criteria | METHOD | Множественная миелома: CRAB критерии = гиперCалькциемия, Почечная недостаточность (Renal), Анемия, Костная болезнь (Bone). M-белок в крови/моче. BM биопсия ≥10% плазматических клеток. Лечение: VRd (бортезомиб + леналидомид + дексаметазон). Трансплантация стволовых клеток для подходящих. ASCT + поддерживающий леналидомид. | MGUS: 1 из 100 пациентов/год прогрессирует в миелому. |
| haem.ops.bone_marrow_transplant | BMT — Allogeneic vs Autologous | METHOD | Трансплантация костного мозга: Аллогенная (AlloSCT): донор = HLA-совпадающий (брат/сестра, неродственный). «Трансплантат против лейкоза» (GVL) эффект. РТПХ (GvHD): потенциальное смертельное осложнение. Аутологичная (Auto-SCT): собственные стволовые клетки = после высоких доз химиотерапии. Нет GvHD. | Алло-SCT: для лейкозов (используют GVL). Авто-SCT: для лимфом/миеломы (нет GVL). |
| haem.ops.dic_disseminated_intravascular | DIC — Management | METHOD | Диссеминированное внутрисосудистое свертывание (ДВС): активация как коагуляции, так и фибринолиза. Thrombotic (тромботическая форма) + haemorrhagic. Причины: сепсис, trauma, obstetric. Лабораторно: ↓тромбоциты + ↑PT/aPTT + ↓ фибриноген + ↑D-dimers. Лечение: устранить причину + заместительная (FFP, криопреципитат, тромбоциты). | ДВС = не просто «кровотечение»: пациент одновременно может тромбировать. |
| haem.ops.hemophilia_treatment | Haemophilia — Factor Replacement | METHOD | Гемофилия: A = дефицит фактора VIII (X-linked). B = фактор IX. Диагностика: ↑aPTT при нормальном PT. Лечение: заместительная терапия факторами. Hemophilia A: рекомбинантный FVIII. Ингибиторы: антитела к FVIII → bypass agents (NovoSeven). Emicizumab (Hemlibra): бисспецифическое антитело (не фактор). | Профилактика: regular factor infusions → снижение эпизодов кровотечений. |
| haem.ops.sickle_cell_crisis_management | Sickle Cell Disease — Crisis Management | METHOD | Острый вазоокклюзивный криз: сильная боль в костях + спине + груди. Лечение: обезболивание (опиоиды + НПВП). Гидратация (IV или PO). О2 только при гипоксемии <95%. Exchange transfusion: при ACS, инсульте, тяжёлом. HbS < 30% цель при обменном переливании. | Острый грудной синдром: лихорадка + боль + инфильтрат = опасный для жизни. |
| haem.ops.warfarin_reversal | Anticoagulation Reversal — Emergent | METHOD | Экстренная реверсия антикоагуляции: Варфарин: 4-factor PCC (концентрат протромбинового комплекса) + витамин K IV. FFP: менее эффективно + объём. INR цель: <1.5 для неотложной операции. NOACs: андексанет альфа (анти-Xa) или идаруцизумаб (дабигатран). Протамин сульфат: для НФГ. | Андексанет: дорогостоящий. Idarucizumab: специфичный для дабигатрана. |
| haem.ops.transfusion_reactions | Blood Transfusion — Adverse Reactions | METHOD | Реакции на переливание: Острый гемолиз: несовместимость AB0 → шок + ДВС. Немедленно: остановить + сообщить. FNHTR: лихорадка (чаще). TRALI: острое повреждение лёгких в течение 6 ч. TACO: перегрузка объёмом. Aллергическая: крапивница. ТА-GvHD (облучённая кровь для иммуносупрессированных). | TRALI vs TACO: TRALI = non-cardiogenic pulmonary oedema. TACO = cardiogenic. |
| haem.ops.red_cell_disorders | Red Cell Disorders — Haemolytic | METHOD | Гемолитические анемии: Внутрисосудистый (intravascular): гемоглобинурия + ↑ свободный Hb. Внесосудистый (extravascular): спленомегалия. Причины: аутоиммунные (AIHA) = тест Кумбса (прямой +). Механические: mikroangiopathic (TTP, HUS). Hereditary (сферосфероцитоз, G6PD). | Тест Кумбса (DAT): определяет антитела/комплемент на эритроцитах. |
| haem.ops.apla_syndrome | APLA — Antiphospholipid Antibodies | METHOD | Антифосфолипидный синдром: aPL: Lupus Anticoagulant (LA) + Anticardiolipin IgG/IgM + β2GPI IgG/IgM. LA = paradox: удлинённое aPTT но тромбоз (не кровотечение). Тест: DRVVT (Dilute Russell's Viper Venom Time). Антикоагулянция: варфарин INR 2-3. | «LA ≠ anticoagulant»: несмотря на название, LA = протромботичный. |
| haem.ops.thalassemia_types | Thalassaemia — Types | METHOD | Талассемии: α-талассемия: делеции α-генов (4 гена). Одно удаление = носитель. Два = лёгкая. Три = HbH болезнь. Четыре = водянка плода (несовместима с жизнью). β-талассемия: мутации β-гена. Малая: гетерозиготная (лёгкая). Большая: гомозиготная (тяжёлая, зависит от трансфузий). Лечение большой: регулярные трансфузии + дефероксамин (хелация железа). | β-таласемия + малярия: защищает от малярии Plasmodium falciparum. |
