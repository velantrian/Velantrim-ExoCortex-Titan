| orgchem.ops.sn1_sn2_comparison | SN1 vs SN2 — Reaction Conditions | METHOD | Нуклеофильное замещение: SN2: одна стадия, инверсия конфигурации (Walden inversion). Primary substrate + strong nucleophile + polar aprotic solvent (DMF, DMSO, acetone). SN1: две стадии (карбокатион-промежуточное), рацемизация. Tertiary substrate + weak nucleophile + polar protic solvent (EtOH, H2O). | Nuc: I⁻ > Br⁻ > Cl⁻ (polarizability). Hard nucleophile: по заряду (OH⁻). Soft: по поляризуемости (I⁻). |
| orgchem.ops.alkene_reactions | Alkene Reactions — Markovnikov | METHOD | Реакции алкенов: Hydrohalogenation (HX): Markovnikov — галоген к менее гидрированному C. Anti-Markovnikov (hydroboration-oxidation): бор к менее гидрированному. Halogenation (X2, Br2): транс-добавление (anti). Epoxidation (mCPBA): cis (syn addition). Ozonolysis: разрыв двойной связи → альдегид/кетон. | Марковников: H присоединяется к C с большим числом H. |
| orgchem.ops.carbonyl_chemistry | Carbonyl — Nucleophilic Addition | METHOD | Карбонильные соединения: Aldehydes > Ketones (реактивность). Нуклеофилы: CN⁻ → cyanohydrin. RMgX → alcohol. Wittig (Ph3P=CHR): алкен из альдегида/кетона. | Enolate: кетон + strong base (LDA) → α-carbon alkylation. |
| orgchem.ops.retrosynthesis | Retrosynthesis — Disconnection | METHOD | Ретросинтез (Corey): работаем назад от целевой молекулы. Disconnection: где разорвать. FGI (Functional Group Interconversion). Synthon: синтетический эквивалент. д-синтон: нуклеофильный (negative charge). а-синтон: электрофильный. Умпонунг: полярность переключается (1,3-dithiane). | TM → всё проще → building blocks. |
| orgchem.ops.nmr_spectroscopy | NMR — ¹H Interpretation | METHOD | ЯМР-спектроскопия (¹H): Chemical shift (δ, мд): TMS = 0. CH3-: 0.8-1. CH2-: 1.2-1.4. =CH-: 4.5-6.5 (vinyl). ArH: 6.5-8.5. CHO: 9-10. COOH: 10-12. J coupling (Гц): n+1 rule (n соседних H). DEPT: определяет тип C (CH, CH2, CH3). COSY: H-H корреляция. HSQC: H-C. | orgchem.ops.aromatic_substitution | EAS — Substituent Effects | METHOD | Электрофильное ароматическое замещение (EAS): Активирующие/орто-пара Directors: OH, OR, NH2, NHCOR (через донирование неподелённой пары). Дезактивирующие/meta Directors: NO2, CF3, COOH, CHO (оттяжка e⁻). Галогены: дезактивирующие но orto-para directors. | orgchem.ops.stereochemistry_chirality | Stereochemistry — R/S Configuration | METHOD | Хиральность: R/S-конфигурация (CIP rules): приоритеты групп по атомному номеру. Расставить по убыванию (1>2>3>4). Повернуть молекулу так чтобы наименьший приоритет (4) смотрел от нас. По часовой = R. Против = S. Диастереомеры: разные конфигурации, но не зеркальные. | orgchem.ops.grignard_synthesis | Grignard Reagent — Applications | METHOD | Реагент Гриньяра (RMgX): мощный нуклеофил. Синтез: R-X + Mg в Et2O → RMgX (требует сухие условия, нет воды/протонных). Реакции: + Formaldehyde → 1° alcohol. + Aldehyde → 2° alcohol. + Ketone → 3° alcohol. + CO2 → carboxylic acid. + Ester → 3° alcohol (2 эквивалента). + Oxirane → 2° alcohol (удлинение цепи на 2С). | Электрофильный углерод = сайт атаки Гриньяра. |
| orgchem.ops.aldol_condensation | Aldol — Condensation Mechanism | METHOD | Альдольная конденсация: енолят + альдегид/кетон → β-гидрокси карбонил → дегидратация → α,β-ненасыщенный. Реакция Клайзена (Claisen condensation): сложные эфиры. | Альдоль: C-C связь + удлинение цепи. Ключевая реакция в биосинтезе. |
