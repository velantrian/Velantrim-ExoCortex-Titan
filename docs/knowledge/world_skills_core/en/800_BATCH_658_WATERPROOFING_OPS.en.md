# BATCH 658: Waterproofing — Below-Grade & Deck

**KnowledgeUnits:** 50
**Namespace:** `waterproof.ops.*`
**Scope:** foundation, deck, balcony, coating, membrane, drainage_board, leak_detection, injection

| ID | KnowledgeUnit | Тип | Суть | Практический смысл |
|---|---|---|---|---|
| waterproof.ops.foundation_membrane_dimple | Foundation — Dimple Board Membrane | METHOD | Гидроизоляция фундамента. Dimpled membrane (High-density polyethylene HDPE): воздушный зазор + дренаж. Установка: на бетонную стену (после curing), dimples facing wall (air gap). Примыкания: лента/герметик по верху (termination bar). Drainage board: вода стекает по air gap в footing drain (перфорированная труба). Footing drain: гравийная обсыпка + geotextile filter. Backfill: clean gravel (10-20 см у стены). Защита: protection board (для защиты мембраны от камней при backfill). | Не путать с damp-proofing (только битумная обмазка — не waterproofing!). |
| waterproof.ops.liquid_applied_membrane | Liquid Applied — Polyurethane Coating | METHOD | Жидкая гидроизоляция. Подготовка: clean, dry, primed. Нанесение: roller/squeegee (толщина 1-2 мм, 2+ слоя). Армирование: polyester fleece между слоями на стыках/углах. PU (полиуретан): эластичный, перекрывает трещины. PMMA (полиметилметакрилат): быстрое отверждение (30-60 мин), для ремонта в сжатые сроки. Водонепроницаемый тест: flood test 24-48 часов. | Пузыри (blisters): из-за влажности в substrate при нанесении. |
| waterproof.ops.deck_coating_system | Deck — Pedestrian Coating | METHOD | Гидроизоляция балкона/террасы. Слои: primer → liquid membrane (PU/PMMA) → wear course (quartz sand broadcast или rubber mat). Уклон: >1.5% к drain. Flashing: заворот на стены (10-15 см). Металлический drip edge. Drain: clamping ring. Expansion joints: специальная лента/герметик. Traffic: полная load capacity после полного curing (48-72 часов). | Standing water (лужи >48 часов после дождя) — недопустимо. |
| waterproof.ops.epoxy_injection_crack | Crack Injection — Epoxy & Polyurethane | METHOD | Ремонт трещин в бетоне инъектированием. Epoxy injection (structural — восстановление монолитности). Подготовка: V-groove (расширение crack), clean, install injection ports (plastic nipples через 15-30 см). Поверхностная заделка: epoxy paste (чтобы injection не вытек). Injection: epoxy pump (давление 200-300 psi), начиная с нижнего порта (пока не выйдет из соседнего). Polyurethane foam injection (non-structural — остановка active water leak): PU реагирует с водой, вспенивается, герметизирует. | Epoxy для сухих трещин, PU для мокрых/текущих. |
| waterproof.ops.blindside_waterproofing | Blindside — Pre-Applied System | METHOD | Гидроизоляция до заливки бетона. Bentonite sheet (Volclay): натриевый бентонит между геотекстилями — при контакте с водой набухает. HDPE sheet: high-density polyethylene (пластик). Укладка на soil retention system (shoring): перед установкой арматуры и заливкой стены. Лапсы: сварка горячим воздухом. Защита: protection course. Преимущество: можно waterproof когда нет доступа снаружи (zero-lot line). | Bentonite нельзя использовать в условиях wet-dry циклов (разрушается). |
