# BATCH 662: Stone Masonry — Natural & Cultured Stone

**KnowledgeUnits:** 50
**Namespace:** `stone.ops.*`
**Scope:** dry_stack, mortar_setting, veneer, chimney_stone, flagstone, selection, pointing

| ID | KnowledgeUnit | Тип | Суть | Практический смысл |
|---|---|---|---|---|
| stone.ops.dry_stack_wall_batter | Dry Stack Wall — Batter & Stability | METHOD | Строительство сухой кладки (без раствора). Batter (наклон к земле): 1" горизонтальных на каждые 12" вертикальных (около 5°). Каждый камень опирается на два нижних (running bond). Through stones (тычки): длинные камни поперёк для связи каждые 0.5-1 м. Cornerstone (угловой): выбрать самые большие, плоские. Chinking (мелкие вставки): заполнение зазоров мелкими камнями. База: 2-3 камня широкие, ниже линии промерзания. Дренаж: гравий позади стены (capillary break). | Осадка (shifting): frost heave без дренажа. |
| stone.ops.mortar_setting_flagstone | Flagstone — Mortar Setting | METHOD | Укладка плоских камней на раствор. Основание: бетон 10 см или щебень 15-20 см. Раствор: тип S (1 часть цемент + 0.5 известь + 4.5 песок). Подготовка камня: смочить (сухой камень вытянет воду из раствора). Установка: trowel slap (нанести раствор на камень, поставить), leveling. Зазоры: 10-30 мм (рустованная кладка) или плотно. Затирка через 24-48 часов: dry pack mortar, tamper. Expansion joint: каждые 3-4 м. Sealer: penetrating stone sealer. | Нет уклона: стоячая вода вымывает раствор. |
| stone.ops.cultured_stone_installation | Cultured Stone — Metal Lath Method | METHOD | Установка искусственного камня (Cultured Stone, Canyon Stone). Каркас: metal lath (1/2") на WRB (barrier). Scratch coat: type S mortar или spec scratch coat, keyed surface (ridges). Дать затвердеть 24-48 часов. Камни: pre-sorted (size/color mixing), примерка без раствора. Back butter: mortar on stone back + wall. Установка: прижать, подвигать для полного контакта. Joints: не все выровнены (varied pattern). Pointing: tooled mortar joint. | Не давать высохнуть слишком быстро: moist cure. |
| stone.ops.natural_stone_selection | Stone Selection — Type Properties | METHOD | Свойства природных камней. Granite: igneous, очень твёрдый, кислостойкий, морозостойкий. Limestone: sedimentary, мягче (acid sensitive), подходит для стен (не кислых условий). Bluestone: dense sandstone, хорошо для terraces. Slate: foliated, расслаивается, хорош для stepping stones (не для veneers — spalling). Fieldstone: разнородный, для dry stack. Ashlar: обработанный прямоугольный (точная кладка). Absorbency test: капля воды, если впитывается <60 сек = пористый (sealing обязателен). | Известняк + кислотный дождь = растворение (не для городских фасадов). |
| stone.ops.tuckpointing_stone_joint | Tuckpointing — Stone Joint Repair | METHOD | Ремонт швов каменной кладки. Удаление: угловая шлифмашинка + diamond blade (только старый раствор, не камень!), глубина 2-3 см. Очистка: щётка, сжатый воздух, вода. Новый раствор: Type S или Type N (для выше расположенных). Укладка: tuck pointer tool, заполнить полностью, без пустот. Tooling: профиль шва (concave, raked, weathered). Влажная доводка (через 30-60 мин). Защита: от дождя и прямого солнца 48-72 часов. | Тип раствора мягче камня (иначе камень расколется от разного расширения). |
