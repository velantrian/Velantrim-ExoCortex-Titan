# BATCH 539: Psychology — Cognitive & Behavioral Science

**KnowledgeUnits:** 50
**Namespace:** `psychology.*`
**Scope:** perception, attention, memory_psych, learning_theory, conditioning, motivation, emotion_psych, cognitive_biases, social_psychology.

| ID | KnowledgeUnit | Тип | Суть | Практический смысл |
|---|---|---|---|---|
| psychology.classical_conditioning | Classical Conditioning (Pavlov) | PROCESS | Безусловный стимул (еда) → безусловный рефлекс (слюна). Нейтральный стимул (звонок) + еда → условный стимул → условный рефлекс. Угасание, спонтанное восстановление, генерализация. | Фобии (условная реакция страха), реклама (приятный образ + продукт), плацебо. |
| psychology.operant_conditioning | Operant Conditioning (Skinner) | PROCESS | Поведение формируется последствиями. Подкрепление (увеличивает частоту): позитивное (награда), негативное (избавление от неприятного). Наказание (уменьшает): позитивное (неприятность), негативное (лишение). | Работа, учёба (зарплата/оценки = позитивное подкрепление). Воспитание (тайм-аут). |
| psychology.reinforcement_schedules | Reinforcement Schedules | VARIANT | Непрерывное, фиксированный интервал (зарплата), переменный интервал (проверка email), фиксированное отношение (сдельная оплата), переменное отношение (игровые автоматы). | Переменное отношение → самая высокая и устойчивая частота поведения (азартные игры). |
| psychology.working_memory | Working Memory | INVARIANT | Baddeley & Hitch: центральный исполнитель + фонологическая петля (речь, ~2 сек) + визуально-пространственный блокнот + эпизодический буфер. Объём: 7±2 элемента (Миллер, 1956). | Чанкинг (группировка: 149217761945 → 1492, 1776, 1945). Номер телефона помним пока набираем. |
| psychology.long_term_memory | Long-Term Memory | INVARIANT | Декларативная (эксплицитная): эпизодическая (события) + семантическая (факты). Недекларативная (имплицитная): процедурная (навыки), прайминг, условные рефлексы. | Гиппокамп — консолидация эпизодической памяти. Повреждение (H.M.) → антероградная амнезия (не может запомнить новое). |
| psychology.encoding_specificity | Encoding Specificity Principle | PROCESS | Вспоминание лучше в том же контексте, что и запоминание (Tulving). Среда, настроение, состояние. | Экзамен: учить в тишине, сдавать в тишине. Дайверы: запомнили под водой лучше вспоминали под водой. |
| psychology.forgetting_curve | Ebbinghaus Forgetting Curve | MODEL | Экспоненциальное забывание: ~50% за 1 час, ~70% за 24 часа без повторения. Spaced repetition (интервальные повторения) — наиболее эффективно для долговременного запоминания. | Кривая забывания Эббингауза (1885): бессмысленные слоги. Anki, SuperMemo. |
| psychology.memory_fallibility | Memory Fallibility & False Memories | PROCESS | Память реконструктивна, а не репродуктивна. Эффект дезинформации (Loftus): последующая информация изменяет воспоминание. Имплантация ложных воспоминаний (потерялся в торговом центре — 25% участников «вспомнили»). | Свидетельские показания: наводящие вопросы меняют память. Терапия восстановленной памяти (риск внушения). |
| psychology.attention_selective | Selective Attention | PROCESS | Фильтрация: ранняя (Broadbent) или поздняя (Deutsch). Эффект коктейльной вечеринки (своё имя слышим). Изменённая слепота (change blindness), слепота невнимания (inattentional blindness). | Горилла на баскетбольном поле (Simons & Chabris, 1999): 50% не замечают человека в костюме гориллы, считая пасы! |
| psychology.perception_top_down | Bottom-Up vs Top-Down Processing | PROCESS | Bottom-up: от сенсорных данных к интерпретации (буквы → слово). Top-down: ожидания и контекст влияют на восприятие (прочитали «THE CAT» даже если написано «TAE CAT» — эффект превосходства слова). | Оптические иллюзии (куб Неккера, ваза Рубина) — неоднозначность стимула, мозг выбирает интерпретацию. |
| psychology.maslow_hierarchy | Maslow's Hierarchy of Needs | MODEL | Пирамида: физиология → безопасность → принадлежность/любовь → уважение → самоактуализация (→ самотрансценденция). Низшие потребности должны быть удовлетворены перед высшими (критика: не всегда строго иерархично). | Мотивация сотрудников (не только зарплата — уважение, рост). Маркетинг (апелляция к разным уровням). |
| psychology.self_determination | Self-Determination Theory (SDT) | MODEL | Внутренняя мотивация (интерес, удовольствие) сильнее внешней (награды/наказания). Три базовые потребности: автономия, компетентность, связанность. | Деньги за хобби могут подорвать внутреннюю мотивацию (эффект сверхоправдания — Lepper, Greene, Nisbett). |
| psychology.cognitive_dissonance | Cognitive Dissonance (Festinger) | PROCESS | Дискомфорт от противоречащих убеждений/поведения → изменение одного из них для восстановления консистентности. «Лисица и виноград» (Эзоп), «Я курю, но это не так вредно». | Постпокупочное оправдание, эффект недостаточного оправдания ($1 vs $20 за скучную задачу — $1 оценили выше). |
| psychology.confirmation_bias | Confirmation Bias | CONTROL | Поиск и интерпретация информации, подтверждающей существующие убеждения. Игнорирование противоречащих данных. | Политика: читаем только «свои» источники. Инвестиции: держим падающие акции (ищем подтверждение, что они вырастут). |
| psychology.fundamental_attribution | Fundamental Attribution Error | PROCESS | Объясняя поведение других, переоцениваем личностные факторы и недооцениваем ситуационные. Наблюдатель: «он опоздал — безответственный»; участник: «пробка». | Судебная система, оценка сотрудников. Знание эффекта → более справедливые суждения. |
| psychology.stanford_prison | Stanford Prison Experiment | RECORD | Зимбардо, 1971: студенты случайно распределены на «охранников» и «заключённых». За 6 дней охранники стали жестокими, заключённые — пассивными/депрессивными. Сила ситуации и ролей. | Этические вопросы (прекращён досрочно). Ситуация может превратить обычных людей в жестоких (Абу-Грейб). |
| psychology.milgram_obedience | Milgram Obedience Experiment | RECORD | Милгрэм, 1963: испытуемые («учителя») наносили удары током «ученику» (актёру) по требованию экспериментатора. 65% дошли до максимальных 450В («смертельно»). | Подчинение авторитету. Объясняет военные преступления, корпоративные скандалы. |
| psychology.bystander_effect | Bystander Effect | PROCESS | Чем больше свидетелей, тем меньше вероятность помощи (диффузия ответственности). Убийство Китти Дженовезе (1964) — 38 свидетелей, никто не вмешался (хотя история преувеличена). | Первая помощь: «Вы, в красной куртке, вызывайте скорую!» — персонализация преодолевает эффект. |
| psychology.learned_helplessness | Learned Helplessness (Seligman) | PROCESS | После неконтролируемого негативного опыта животное/человек перестаёт пытаться, даже когда контроль возможен. Модель депрессии. | Важность чувства контроля. Воспитание: не делать ВСЁ за ребёнка (лишаем автономии). |
| psychology.stereotype_threat | Stereotype Threat | PROCESS | Страх подтвердить негативный стереотип о своей группе ухудшает выполнение задачи. | Математика: женщины показывают худшие результаты, если напомнить стереотип. Black students и IQ-тесты (Steele и Aronson). |
