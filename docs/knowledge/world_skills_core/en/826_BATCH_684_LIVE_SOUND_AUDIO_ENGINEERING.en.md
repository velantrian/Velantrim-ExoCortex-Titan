| livesound.ops.pa_system_design_outdoor | PA System — Outdoor Design | METHOD | Проектирование системы озвучения открытых площадок. SPL requirements: 100-105 dB SPL @ audience (festival main stage), 85-95 dB (conference). Coverage: горизонтальное (ГР) 90°, вертикальное (ВР) 10-15° (line array). Line array: columns of speakers (high-frequency coupling, +6 dB per doubling arrays). Subwoofer: cardioid array (снижение уровня позади) или ground stack. Delay towers: когда coverage >60 м (задержка = расстояние/343 + 5-10 мс). SPL falloff: -6 dB per doubling distance (free field). | Nearfield delay line: delay = distance (м) × 2.94 мс. |
| livesound.ops.gain_structure_snr | Gain Structure — Signal to Noise | METHOD | Выстраивание уровней сигнала. Microphone preamp gain: установить так чтобы signal занимал -18 до -12 dBFS при peak (headroom). Insert gains: каждое устройство в chain (compressor, EQ) — gain match (output = input level). Mixer master: unity gain или +4 dBu для pro balanced. Amplifier input sensitivity: при max program → amp выдаёт rated output (не поднимать до clipping). Clipping check: каждый stage в chain. SNR improvement: каждые +6 dB gain before noise source. Noise floor: mixer+snake+amp ≤-90 dBu (pro system). | Gain structure 101: шум добавляется, уровень держится высоко в цепи. |
| livesound.ops.eq_feedback_elimination | Feedback — Systematic Elimination | METHOD | Борьба с акустической обратной связью. Ringing out monitors: тихо поднять gain до начала feedback → notch filter (-6 dB narrow Q) на feedback frequency → повторить 6-10 раз. RTA (real-time analyzer): показывает частоту. Sweep EQ: медленный 1/3 oct gain sweep для поиска. System gain before feedback (GBF): cтарайтесь держать 6+ dB margin. Automatic feedback eliminators (BSS, DBX Drive Rack): автоматически notch при feedback detection. Mic placement: дальше от speaker, не за speaker. Directional: cardioid mike→ null позади (speaker). | Рабочий запас: ≥6 dB перед feedback = надёжный уровень мониторов. |
| livesound.ops.monitor_mixing_workflow | Monitor Mixing — Workflow & Mixes | METHOD | Работа монитор-инженера. IEM (In-Ear Monitor): indivudual mix → персональная UHF система (Sennheiser, Shure PSM). Wedge monitors: общие mix → по группам (drums, bass, guitar, vocals). 6-12 independent monitor mixes на крупной сцене. Workflow: soundcheck — каждый музыкант слышит что просит (vocals up, more kick etc.). Line check: каждый mic/DI. Gain shared: если FOH (Front of House) и monitor совместно используют preamp — coordinate gain setting. Digital console advantage: recall scenes, eq/compress per channel. | Главное правило: каждый слышит то что ему нужно, не то что удобно инженеру. |
| livesound.ops.digital_snake_latency | Digital Snake — Latency & Patching | METHOD | Цифровой аудиоснейк. Systems: Dante (AES67 compliant, Audinate), AVB/TSN (audio video bridging), MADI (64ch optical). Latency: Dante low latency preset 0.25 мс (sample rate dependent), standard 1-5 мс. Sampling rate: 48 kHz (live production standard), 96 kHz (reduced channel count в Dante). Patching: virtual (routed via software). Redundant network: dual-port NIC, ring topology. Gain sharing: remote stage box → preamp control at FOH. Rollout: Cat6/Cat6A cabling, EtherCon connectors (Neutrik). | Dante Vs mains: если network switch fails — full system down (importance of backup). |
