| forensic.ops.crime_scene_documentation | Crime Scene — Initial Documentation | METHOD | Документация места происшествия: фотография (overview, mid-range, close-up); sketching (масштаб, compass direction, measurements, North arrow); video walk-through. Photo log: номер снимка, направление, объект. Measurements: baseline, triangulation, 360° от reference points. Evidence markers: numbered flags/placards, all photographed before collection. | Правило: «document before you disturb» — никакое перемещение до фиксации. |
| forensic.ops.chain_of_custody | Chain of Custody — Protocol | METHOD | Цепочка хранения доказательств: каждый, кто прикасался к доказательству → запись (имя, дата, время, цель). Packaging: бумажные пакеты (для биологических, дышащих), пластик (для инертных). Seals: tamper-evident tape + initials. Evidence log: поступление, хранение, лабораторный анализ, суд. Разрыв цепочки: может сделать доказательство недопустимым. | Latent fingerprints на бумаге: бумажный конверт (не пластик — деградация). |
| forensic.ops.dna_str_profiling | DNA — STR Profiling | METHOD | Профилирование ДНК (STR — Short Tandem Repeats): ПЦР-амплификация до 20+ STR локусов. CODIS (Combined DNA Index System, USA): 20 core STR loci. Вероятность совпадения случайного: 1:квадриллион. Touch DNA: <5 клеток (ненадёжно, загрязнение). Degraded samples: mitochrondrial DNA (maternal line, hair without root). LCN (Low Copy Number): усиленное профилирование (повышен риск контаминации). | Elimination database: образцы всех investigator для вычитания. |
| forensic.ops.fingerprint_types | Fingerprint — Types & Latent Development | METHOD | Типы отпечатков: patent (видимые — кровь, грязь), plastic (в пластилине, воске), latent (невидимые, жир/пот). Обнаружение latent: cyanoacrylate fuming (суперклей — на пластике), powder (aluminium = светлые поверхности, black = тёмные), ninhydrin (аминокислоты на бумаге, violet colour), DFO/1,8-diazofluorenone (fluorescence). AFIS (Automated Fingerprint Identification System): сравнение с базой. | Порошок на месте (only once): нельзя стереть и повторить. |
| forensic.ops.blood_spatter_analysis | Blood Spatter — Pattern Analysis | METHOD | Анализ следов крови: area of origin (точка происхождения): каждое пятно имеет угол удара (impact angle = arcsin(width/length × ratio)). Strings: натянуть нити от пятен назад к точке пересечения. Low velocity: round drops (gravity). Medium: slightly elongated. High velocity (gunshot): mist. Spines: направление движения по шипам. Castoff: дуги при замахе оружия. | Area of origin ≠ exact location of victim (body moves). |
| forensic.ops.toxicology_postmortem | Toxicology — Post-Mortem Sampling | METHOD | Токсикологический анализ посмертно: femoral blood (предпочтительный — менее подвержен redistribution). Vitreous humor (стекловидное тело глаза): медленное разложение, этанол reference. Liver: концентрирует многие яды. Gastric contents: нераспределённые вещества. Redistribution: сердечная кровь завышает концентрации (из liver/GI). Post-mortem interval: core temp drop 1°C/ч (nomogram). | PMI оценка по температуре: зависит от ambient условий (не прямая). |
| forensic.ops.entomology_pmi | Forensic Entomology — PMI Estimation | METHOD | Судебная энтомология: насекомые заселяют труп в предсказуемой последовательности. Blow flies (Calliphoridae): первые (в течение минут-часов). Succession: eggs → larvae (3 instars) → puparia → adult. PMI минимальная: back-calculate от oldest stage (ADD — Accumulated Degree Days, ≥10°C base). Weather data (temp record): критично для calculation. Species: vary by geography. | PMI minimum, не exact time of death. |
| forensic.ops.digital_forensics_hash | Digital Forensics — Hash Verification | METHOD | Цифровая криминалистика: MD5/SHA-256 hash-сумма → проверяет целостность доказательства (любое изменение меняет hash). Write blocker: аппаратный или программный (не записывать на улики). Forensic image (bit-by-bit): EnCase E01, FTK, DD format. Chain of custody: hash при acquisition + verification hash. Live collection: RAM (volatile data, encryption keys). | NIST tool validation: использовать только validated forensic tools (NSRL). |
| forensic.ops.ballistics_striation | Ballistics — Firearm Identification | METHOD | Криминалистическая баллистика: ствол оставляет уникальные нарезы (striation) на пуле — как fingerprint. Comparison microscope: сравнение test bullet vs crime bullet. IBIS (Integrated Ballistic Identification System): картотека. Toolmark: штемпельные марки на гильзе от ударника, экстрактора. Gunshot residue (GSR): barium, antimony, lead (primer) → на руке/одежде → SEM/EDX. | GSR быстро исчезает: смывается за 1-2 ч мытья рук. |
| forensic.ops.arson_fire_patterns | Arson Investigation — Burn Patterns | METHOD | Анализ поджога: V-pattern (конус выгорания): вершина указывает на начало пожара. Pour patterns (следы горючего): irregular edge burning (пожар идёт по пролитому ускорителю). Alligatoring (крокодиловая кожа): нет прямой корреляции с ускорителем (устаревшая теория). К-9 accelerant detection. GC/MS: идентификация ускорителя в образцах. Low burn: следы горения у пола = accelerant (vs нормальный пожар горит сверху вниз). | NFPA 921: научный standard для fire investigation. |
| forensic.ops.document_examination | Questioned Document — Examination | METHOD | Криминалистическое исследование документов: почерковедение (сравнение + особенности + automatics). VSC (Video Spectral Comparator): IR, UV, transmitted light — чернила, добавления, стёртое. ESDA (Electrostatic Detection Apparatus): скрытые вдавления от листа выше (last impression). Ink dating: GC/MS-анализ растворителей. Printer identification: typography steganography (printer dots pattern). | Electrostatic detection: документ с написанными поверх него данными. |
| forensic.ops.cause_manner_death | Cause & Manner of Death — Definitions | METHOD | Причина смерти (Cause): непосредственная (gunshot wound) + механизм (blood loss). Непосредственная причина + механизм + обстоятельство (на сертификате). Вид смерти (Manner): Natural, Accident, Suicide, Homicide, Undetermined. Судебно-медицинский эксперт vs коронер: ME = врач-специалист, coroner = выборный должностный. Autopsy: external + internal + histology + toxicology. | Коронер (non-MD): ограниченные полномочия. Медицинский эксперт (MD): более тщательный. |
| forensic.ops.glass_fracture_analysis | Glass Fracture Analysis | METHOD | Анализ разрушения стекла: concentric rings (из точки удара). Radial cracks: от точки удара наружу. Sequence: стороны Radial — RTOF (Rib marks on Radial On First break). Пулевое отверстие: конус расширяется в сторону движения. Putback reconstruction: фрагменты восстанавливаются в frame (3D puzzle). Direction of impact: large conic fracture on exit side. | Radial до concentric: «R отец, C дочь» — radial раньше. |
| forensic.ops.fingerprint_comparison_acei | ACEI — Fingerprint Comparison | METHOD | ACEI метод (Analysis-Comparison-Evaluation-Interpretation): Analysis — детальное изучение latent print (level 1: pattern, level 2: minutiae, level 3: pore/edge detail). Comparison — против известного образца. Evaluation — identification (individualization), exclusion, or inconclusive. Interpretation — контекст и значение. ACE-V: verification (V) — независимый blind review. | 12 точек сходства — нет международного стандарта (SWGFAST 2012: no minimum count). |
| forensic.ops.trace_evidence_collection | Trace Evidence — Fibres & Hair | METHOD | Микроследы: волокна (fibre) — тип (natural/synthetic), цвет (microscopical + MSP), producer (comparison set). Волос: animal vs human (scalp/pubic), race characterization (not genetic). Микроскопия SEM/EDX: elemental analysis. Primer: tape lifts с одежды. Packaging: druggist fold (protect from contamination). Locard's Principle: каждый контакт оставляет след. | Волос без луковицы: no nuclear DNA (только митохондриальная ДНК, не индивидуализирует). |
| forensic.ops.soil_analysis | Soil Analysis — Geographical Profiling | METHOD | Судебный анализ почвы: сравнение почвы на обуви с локацией. Physical: цвет (Munsell), текстура, минералы. Chemical: ICP-MS элементный состав. Biological: микрофлора, пыльца (palynology). Diatoms (диатомовые водоросли): специфичны для водоёма. Database: почвенные регионы. Квалифицированный анализ: probabilistic matching. | Pollen analysis: место нахождения жертвы/подозреваемого по пыльце (уникальная региональная). |
| forensic.ops.bite_mark_controversy | Bite Mark Evidence — Scientific Controversy | METHOD | Следы укуса: исторически использовались в суде (Ted Bundy). Проблемы: skin deforms, healing changes marks, значительная субъективность анализа. PCAST (President's Council) 2016: «foundational validity not established». SWGMAT: guidelines существуют но спорные. ABFO (American Board of Forensic Odontology): минимальный стандарт сравнения. | Невинно осуждённые: несколько случаев только на основе bite mark evidence. |
| forensic.ops.expert_witness_daubert | Expert Witness — Daubert Standard | METHOD | Daubert standard (USA, 1993, Daubert v. Merrell Dow Pharmaceuticals): научная методология должна быть 1) тестируема (tested), 2) подвергнута peer review, 3) с известным уровнем ошибки, 4) принята в scientific community. Frye standard (older): «generally accepted» в community. Expert Opinion: должен базироваться на достаточных фактах + надёжных методах правильно применённых. | Rule 702 FRE: всё это кодифицировано в Federal Rules of Evidence. |
| forensic.ops.shoe_print_toolmark | Shoe Print — Class vs Individual | METHOD | Следы обуви: класс характеристики (бренд/модель/размер — из базы данных). Случайные (individual): порезы, потёртости (уникальные). Casting: Dental Stone (sulfur-free) для трасологии. Photography: oblique light (rake light) для 3D impression. Comparison: side-by-side с suspect shoe impression. | Wear patterns: одинаковая модель обуви (class) не идентифицирует person, wear+damage — может. |
| forensic.ops.explosives_residue | Explosives Residue — Detection | METHOD | Остатки взрывчатки: PETN, RDX (military), TATP (homemade). Collection: swabs с руками/одеждой. GC-MS/MS, LC-MS/MS: определение и количество. Ion mobility spectrometry (IMS): аэропорт screening. TATP: очень летучий (samples degrade quickly), GC-FID or MS detection. Negative control: обязателен (contamination of lab). | Cross-reactivity: TATP imagers могут ложно срабатывать на ацетон (nail polish remover). |
| forensic.ops.forensic_accounting | Forensic Accounting — Fraud Detection | METHOD | Судебная бухгалтерия: Benford's Law (первая значащая цифра чисел: 1 = 30%, 2 = 18%...) — выявляет нетипичные цифры при мошенничестве. Bank statement analysis: unexpected large round-number transactions. Asset hiding: shell companies, off-shore. Tracing: follow money through layers. Litigation support: expert witness testimony. | Benford's Law violation: инициирует дальнейший анализ, не доказательство. |
| forensic.ops.victimology_profiling | Victimology — Profiling Tool | METHOD | Виктимология: изучение жертвы для профилирования преступника. High-risk lifestyle: drug use, sex work, night activity. Low risk: lifestyle изолирован, домашний. Risk increases: вероятность контакта с хищником. В серийных убийствах: тип жертвы позволяет сузить geographic/social profile offender. School-aged victims: обычно known offender (family, acquaintance). | Ошибка атрибуции: жертва не виновата в том, что выбрана. |
| forensic.ops.lividity_rigor_mortis | Lividity & Rigor Mortis — PMI Signs | METHOD | Livor mortis (трупные пятна): начало через 1-2 ч (hypostasis), фиксация через 8-12 ч. Если тело перемещено позже фиксации: пятна не соответствуют положению тела. Rigor mortis: начало 2-6 ч (ATP истощение), максимум 12-24 ч, исчезает 48-72 ч. Algor mortis: снижение температуры (см. PMI calculation). Decomposition stages: fresh, bloat, active decay, advanced, dry/skeletal. | Rigor + pятна + temperature: триада — оценка PMI (грубо). |
| forensic.ops.serology_presumptive_tests | Serology — Presumptive Tests | METHOD | Серологические тесты: Kastle-Meyer (KM) = presumptive для крови (phenolphthalein + H2O2): розовый → положительный. False positives: растительные пероксидазы. Confirmatory: Takayama/Teichmann (кристаллы). Species (ABO): immunoelectrophoresis. Semen: acid phosphatase (presumptive), p30/PSA (confirmatory). Saliva: amylase (PGM). | Позитивный presumptive не доказывает кровь — только confirmatory test. |
| forensic.ops.staged_scene_recognition | Staged Crime Scene — Recognition | METHOD | Инсценировка (staging): преступник изменяет место происшествия для введения следствия в заблуждение. Признаки: несоответствие физических доказательств инсценировке (ворвались → но дверь не взломана изнутри), «слишком очевидно» (TV-версия), неестественное положение тела, отсутствие ожидаемых доказательств. Undetermined ≠ staging. | Сначала исключить: не staging до полного следственного обследования. |
| forensic.ops.toxicology_drug_classes | Drug Classes — Toxicological Effects | METHOD | Опиоиды: miosis, угнетение дыхания, sedation, coma. Stimulants (cocaine/amphetamine): мидриаз, тахикардия, гипертермия. Benzodiazepines: седация, amnesia, reduced coordination. Cannabis: conjunctival injection, time distortion, увеличенный аппетит. Alcohol: ataxia, slurred speech, GI effects. Serotonin syndrome (MDMA+SSRI): fever, clonus, agitation. | GHB (дата rape drug): быстрое всасывание, окно 4-8 ч → тест мочи часто отрицательный. |
| forensic.ops.forensic_odontology | Forensic Odontology — ID Methods | METHOD | Идентификация по зубам: сравнение зубов unknown vs antemortem dental records (X-rays, charts). Unique features: restorations, implants, extractions, root canal, crown. Mass disaster (DVI, Disaster Victim ID): INTERPOL DVI Forms Yellow (PM) + Pink (AM). DNA из зубов: пульпа содержит ДНК (деградация устойчивая). | Авиакатастрофа: зубные карты — быстрейший путь ID (чем ДНК занимает дни). |
| forensic.ops.lidar_3d_scene | LiDAR — Scene Documentation | METHOD | LiDAR (3D scanner) для документации места происшествия: FARO Focus, Leica ScanStation. Point cloud: миллионы точек за минуты. Virtual walkthrough: для суда (jurors voir dira virtual scene). Measurements: точность ±2 мм. Registration: overlap ≥30% между сканами (автосшивка). Time stamp: каждая точка + temperature data. | 3D scene reconstruction: неопровержимо vs sketch (который может быть ошибочным). |
| forensic.ops.false_confession_psychology | False Confessions — Psychological Factors | METHOD | Ложные признания (false confessions): voluntary (добровольные без давления), compliant (поддались давлению — знают правду), internalized (полагают, что совершили, не помнят). Reid Technique: «behaviourally based» — критикуется (ложный positive/negative). PEACE (UK): info-gathering без accusatory. Stress inoculation: длительный допрос → когнитивное изнурение. | Невинно осуждённые (Innocence Project): >200 human cases, 25% — false confession involved. |
| forensic.ops.impression_evidence_casting | Impression Evidence — Tyre Tracks | METHOD | Следы шин: документация (рейка сбоку + photography with oblique light). Cardinal axes: на диаграммах BODY MAP правые-левые в анатомической позиции (viewer's right = body's left). | Toxicology pending: предварительный отчёт без finalized MoD/CoD. |
| forensic.ops.forensic_psychology_sanity | Forensic Psychology — Sanity Evaluation | METHOD | Оценка вменяемости (Criminal Responsibility): M'Naghten rule (USA): не знал природы действия ИЛИ не понимал что неправильно.
