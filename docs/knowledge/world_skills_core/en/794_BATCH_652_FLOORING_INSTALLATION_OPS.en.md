# BATCH 652: Flooring — Hardwood, Laminate & Vinyl Install

**KnowledgeUnits:** 50
**Namespace:** `flooring.ops.*`
**Scope:** hardwood, laminate, vinyl, subfloor, underlayment, tile, carpet, transitions, moisture

| ID | KnowledgeUnit | Тип | Суть | Практический смысл |
|---|---|---|---|---|
| flooring.ops.hardwood_acclimation | Hardwood — Acclimation & Moisture | METHOD | Акклиматизация деревянного пола. Коробки открыть, разложить в помещении на 5-14 дней (до установки). HVAC должен работать (нормальные жилые условия). Moisture meter: измерение влажности доски (6-9% для большинства регионов) и subfloor (деревянный: <12%, бетон: <4.5% по calcium chloride или <80% RH по in-situ probe). Разница влажности subfloor и hardwood: <2% для narrow, <4% для wide planks. Запись: все замеры (warranty требует). | Без акклиматизации: gaps (зимой), buckling (летом). |
| flooring.ops.expansion_gap_perimeter | Expansion Gap — Perimeter Spacing | METHOD | Компенсационный зазор по периметру. Зазор: 10-15 мм от стен/фиксированных объектов. Spacers (клинья): устанавливаются через каждые 20-30 см вдоль стен. Плинтус/четверть (baseboard/shoe molding) закрывает зазор. В дверных проёмах: T-molding переходник (разрыв для expansion). Для больших помещений (>10 м ширина): дополнительный expansion joint в поле. Under-cut door casings: jamb saw (подрезка под высоту пола + подложки + зазор). | Без зазора: пол упирается в стену → buckling. |
| flooring.ops.laminate_click_install | Laminate — Click-Lock Installation | METHOD | Укладка ламината замковым методом. Направление: длинная сторона параллельно главному источнику света (окну). Первый ряд: паз к стене, spacers. Соединение: angle-in (длинная сторона под углом) → drop down. Короткая сторона: tap block + hammer (не бить прямо по планке!). Последний ряд: rip cut (циркулярная пила), pull bar для затяжки. Stagger: смещение стыков минимум на 30 см (избегать H-паттерн). Random pattern: использовать обрезки для следующего ряда (экономия + естественный вид). | Underlayment: обязательный слой (влагоизоляция + звукоизоляция). |
| flooring.ops.vinyl_plank_glue_down | Luxury Vinyl — Glue-Down | METHOD | Приклеиваемый виниловый пол (LVT/LVP). Клей: pressure-sensitive acrylic, наносится зубчатым шпателем (notch size по рекомендации производителя). Open time: 20-30 мин (пока клей станет tacky — прозрачный, липкий на ощупь, не пачкает руку). Планка укладывается, rolling (30-50 кг ролик) для полного контакта. Стыки: плотно, без зазоров. Влажная уборка: через 24 часа. Тяжёлая мебель: через 48 часов. Подготовка subfloor: ровный (перепад <3 мм на 3 м), зашпаклёван. | Не ходить по свежему клею (смещение планок). |
| flooring.ops.subfloor_preparation_patch | Subfloor — Leveling Compound | METHOD | Выравнивание основания под напольное покрытие. Дефекты: трещины, углубления, неровности. Patching compound: cement-based (заполнение локальных дефектов). Self-leveling compound: жидкая смесь для выравнивания всего пола (заливается, самовыравнивается). Primer: нанести на base перед self-leveler для адгезии и предотвращения пузырей. Gauge rake и spiked roller для удаления воздушных пузырей. Время застывания: 2-24 часа (зависит от продукта и толщины). Проверка: 2-метровая линейка (зазор <3 мм). Шлифовка высоких точек: бетонная шлифмашинка. | Влажность бетона: слишком высокая = отслоение клея. |
