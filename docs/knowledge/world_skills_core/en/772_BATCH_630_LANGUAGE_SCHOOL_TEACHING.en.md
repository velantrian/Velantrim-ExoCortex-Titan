# BATCH 630: Language School — Teaching Operations

**KnowledgeUnits:** 44
**Namespace:** `langschool.ops.*`
**Scope:** placement_test, lesson_plan, ESL, immersion, conversation, grammar, assessment, classroom

| ID | KnowledgeUnit | Тип | Суть | Практический смысл |
|---|---|---|---|---|
| langschool.ops.placement_test_interview | Placement Test — Oral & Written | METHOD | Тестирование уровня. Written: multiple-choice grammar/vocab (50-100 Q), reading comprehension, writing sample. Oral: 5-10 мин interview (trained assessor). CEFR уровни (A1-C2). Questions: от простых к сложным (если студент не может ответить — стоп). Rubric: fluency, accuracy, pronunciation, comprehension. Placement decision: по weakest skill (не завышать — студент будет страдать). Trial lesson: иногда дают 1-2 урока в группе (проверка placement). | Регулярный re-assessment (каждые 3-6 мес). |
| langschool.ops.communicative_approach | Communicative Approach — PPP Methodology | METHOD | Методика PPP: Presentation (учитель вводит новую грамматику/лексику — context, meaning, form), Practice (контролируемые упражнения: gap-fill, drills), Production (свободное использование: role-play, discussion). Error correction: immediate для accuracy stage, delayed для fluency stage. Eliciting: вовлекать студентов (не давать ответ, а задавать вопросы «как вы думаете почему?»). Concept checking (CCQs): проверка понимания без перевода (He used to smoke: Does he smoke now? No. Did he smoke in the past? Yes). STT (Student Talking Time): цель >70% времени урока. | TTT (Teacher Talking Time): минимизировать. |
| langschool.ops.correction_feedback_types | Error Correction — Types & Timing | METHOD | Исправление ошибок. Immediate (на accuracy exercise): finger correction (показать на пальцах слова), echo with rising intonation, reformulation. Delayed (на fluency): записывать ошибки, разбирать после speaking (error correction slot). Peer correction: «кто заметил?» Self-correction: «попробуй ещё раз». Категории ошибок: pronunciation (звуки, stress, intonation), grammar (tense, word order), vocabulary (wrong word), register (formal/informal). Не исправлять ВСЁ (студент теряет confidence). Фокус на target language урока. | Запись board: error + correct version (student name anonymous). Произношение: IPA транскрипция. |
| langschool.ops.lesson_plan_stages | Lesson Plan — Warm-Up to Cool-Down | METHOD | План урока 45-90 мин. 1) Warm-up (5-10 мин — активация языка, icebreaker, review прошлого). 2) Lead-in (введение темы — картинка, видео, вопрос). 3) Presentation (10-15 мин). 4) Practice (15-20 мин). 5) Production (15-20 мин). 6) Cool-down (+ homework assignment). Materials: realia (реальные предметы), authentic (меню, газеты). Differentiation: для mixed-level группы — extension task для сильных, scaffolding для слабых. Timing: lesson plan имеет approximate minutes (гибко!). | Переходы между стадиями: плавные (link). |
| langschool.ops.classroom_group_work | Group Work — Pairing & Monitoring | METHOD | Работа в парах/группах. Pair formation: случайный (по алфавиту имен), по уровню (strong+weak = peer tutoring), по интересам. Instruction: дать чёткое задание + example + time limit. ICQs (Instruction Checking Questions): «Сколько минут? В паре или один? Что делаете?». Monitoring: ходить, слушать, записывать ошибки, не вмешиваться без нужды (пусть говорят). Feedback: после task — praise успешной коммуникации, затем language feedback. Jigsaw task: каждая группа имеет часть информации, должны поделиться. | Если студенты переходят на L1 (родной язык) — напомнить, дать useful phrases на целевом языке. |
