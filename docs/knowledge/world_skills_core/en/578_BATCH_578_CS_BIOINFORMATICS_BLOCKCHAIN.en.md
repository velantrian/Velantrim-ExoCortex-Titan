| cs.bioinformatics.sequence_alignment | Sequence Alignment — Needleman-Wunsch & Smith-Waterman | METHOD | Глобальное выравнивание: Needleman-Wunsch (DP, O(mn)). Локальное: Smith-Waterman. Матрица замен (BLOSUM62, PAM). Gap penalty (линейный/аффинный: открытие + продолжение). | Сравнение генов/белков из разных организмов. Высокая схожесть → функциональная или эволюционная связь. |
| cs.bioinformatics.blast | BLAST Algorithm (Basic Local Alignment) | METHOD | Эвристический поиск: находит короткие точные совпадения (seeds, word size W=3 для белка, 11 для ДНК и более), затем расширяет без гэпов (HSP), затем Smith-Waterman для лучших. Жертвует чувствительностью ради скорости. | Поиск в GenBank (~10¹² нуклеотидов, 2024). BLASTn (ДНК), BLASTp (белок), tBLASTn (трансляция). E-value: ожидаемое число случайных совпадений с таким счётом. |
| cs.bioinformatics.genome_assembly | Genome Assembly — de Bruijn Graphs | METHOD | Разбиение ридов (чтений) на k-меры → граф де Брёйна: k-меры = рёбра, k-1-меры = узлы. Эйлеров путь = контиг (непрерывная последовательность). Проблемы: повторы (длиннее k → разрывы), гетерозиготность, ошибки. SPAdes, Velvet. | Геном человека: 3.2 млрд п.о. технологией NGS (Illumina, короткие риды 150 п.о.) → тысячи контигов (разрывы из-за повторов). Hi-C + длинные риды (PacBio HiFi, ONT) → T2T (telomere-to-telomere, 2022) — первый полный геном без пробелов. |
| cs.bioinformatics.hidden_markov | Hidden Markov Models (HMM) in Bioinformatics | METHOD | Скрытые состояния (гены, экзоны, структурные элементы), наблюдаемые эмиссии (нуклеотиды/аминокислоты). Алгоритмы: Viterbi (оптимальный путь), Forward/Backward (вероятности состояний), Baum-Welch (обучение). HMMER (профили HMM белковых семейств). | Поиск генов в геномной ДНК (GENSCAN). Pfam — база белковых семейств на основе профилей HMM (>19,000 семейств). |
| cs.bioinformatics.phylogenetic_tree_methods | Phylogenetic Tree Algorithms | METHOD | Distance-based: UPGMA (ультраметрические), Neighbor-Joining (NJ — не ультраметрические, быстрее). Character-based: Maximum Parsimony (MP — мин. число мутаций), Maximum Likelihood (ML — модель эволюции GTR+Γ+I), Bayesian (MCMC, MrBayes). | Bootstrap (>100 репликаций) для оценки поддержки узлов (>70% — хорошая). Модели замен: JC69 (1 параметр) → GTR (6). Гамма-распределение скоростей по сайтам. |
| cs.bioinformatics.protein_structure_prediction | Protein Structure Prediction — AlphaFold | RECORD | CASP (Critical Assessment): AlphaFold2 (DeepMind, 2020) — революция: точность GDT_TS >90 для многих белков (конкурентно рентгеновской кристаллографии!). Использует attention-based архитектуру (Evoformer), MSA (multiple sequence alignment) + структурные шаблоны. | 200 млн+ структур предсказано и открыто (AlphaFold Protein Structure Database). Не решает: динамику, взаимодействие с лигандами, мультидоменные. |
| cs.blockchain.bitcoin_consensus | Nakamoto Consensus — Proof-of-Work | INVARIANT | Узлы соревнуются в решении криптографической головоломки (SHA-256, nonce). Целевая сложность → среднее время блока 10 мин. Самая длинная цепочка побеждает. Атака 51%: двойная трата. | BTC: вознаграждение за блок 3.125 BTC (после halving 2024, с 50 BTC → 6.25 → 3.125). 21 млн BTC максимум. Потребление энергии: ~150 ТВт·ч/год (как Аргентина). |
| cs.blockchain.ethereum_smart_contracts | Ethereum — Smart Contracts & Solidity | METHOD | EVM (Ethereum Virtual Machine): тьюринг-полный байт-код. Solidity: контракт = код + состояние. Газ (gas): каждая операция стоит газ, ограничение на блок (30M gas). EIP-1559: базовая плата + чаевые, сжигание. Proof-of-Stake (The Merge, 2022): валидаторы вместо майнеров, ↓энергопотребление 99.95%. | DeFi (децентрализованные финансы): Uniswap (AMM — Automated Market Maker), Aave (лендинг). NFT (ERC-721). DAO (децентрализованные автономные организации). |
| cs.blockchain.consensus_bft | BFT Consensus (Tendermint, HotStuff) | METHOD | Византийская отказоустойчивость (≤f из 3f+1 узлов злонамерены). Tendermint (Cosmos): proposer + 3 раунда голосования, finality (необратимость). HotStuff (Libra/Diem): оптимизирован для pipeline, O(n) сообщений. | Преимущество над PoW: finality (не ждать 6 блоков для подтверждения BTC), высокая пропускная способность, энергоэффективность. |
| cs.blockchain.merkle_patricia_trie | Merkle Patricia Trie — Ethereum State | METHOD | Криптографическое аккумулирующее дерево: каждый узел хешируется (keccak256). Доказательство Меркла: log₂N размера. Хранение состояния (account balances, contract storage). | Легковесные клиенты (light clients): проверка транзакции без загрузки всей цепи (проверяют Merkle proof). |
| cs.blockchain.zero_knowledge | Zero-Knowledge Proofs — zk-SNARKs | METHOD | Доказывающий убеждает проверяющего в истинности утверждения, не раскрывая ничего сверх этого факта. 3 свойства: полнота, корректность, нулевое разглашение. zk-SNARK: Succinct (короткое доказательство, ~200 байт), Non-interactive, ARgument of Knowledge. | Zcash (анонимные транзакции). zk-rollups: масштабирование Ethereum (валидность доказательства вместо выполнения всех транзакций). Dark Forest (игра с ZK). |
