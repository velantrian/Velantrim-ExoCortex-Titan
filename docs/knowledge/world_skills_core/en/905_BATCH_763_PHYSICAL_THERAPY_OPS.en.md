| physther.ops.exercise_prescription_fitt | Exercise Prescription — FITT-VP | METHOD | FITT-VP для терапевтических упражнений: Frequency (частота), Intensity (интенсивность), Time (продолжительность), Type (тип), Volume (объём), Progression (прогрессия). | physther.ops.joint_mobilization | Joint Mobilization — Maitland Grades | METHOD | Суставная мобилизация: Grade I-II (болевое уменьшение), III-IV (tightness, range увеличение), V (manipulation/thrust). Convex-concave rule: мобилизация в направлении ограничения. Kaltenborn: рackage/slack. Противопоказания: нестабильность, остеопороз, инфекция, злокачественное. Тест перед мобилизацией: нейро обследование. | Konvex rule: concave surface moves same direction as bone. Concave: opposite. |
| physther.ops.ultrasound_therapeutic | Therapeutic Ultrasound — Parameters | METHOD | Терапевтический ультразвук: частота 1 или 3 МГц (3 МГц = поверхностнее, 1 МГц = глубже). Intensity: 0.5-2 Вт/см². Duty cycle: непрерывный (continuous) = тепловой + нетепловой, пульсирующий 20-50% = преимущественно нетепловой (cavitation). ERA (Effective Radiating Area). BNR (Beam Non-uniformity Ratio): ≤8:1. | ERA → рассчитать время обработки: (2× ERA × время/см²). |
| physther.ops.neurological_bobath | Neurological PT — Bobath Concept | METHOD | Концепция Бобата (нейроразвитие): задержать патологические рефлекторные паттерны + стимулировать нормальные. Key points of control (KPC): проксимальные и дистальные. Inhibition abnormal tone → facilitation of normal movement. PNF (Proprioceptive Neuromuscular Facilitation): diagonal patterns, hold-relax, contract-relax. | Инсульт реабилитация: современное = task-specific training выше чем Bobath (Cochrane). |
| physther.ops.gait_analysis | Gait Analysis — Normal Parameters | METHOD | Анализ походки: 8 фаз цикла (Rancho Los Amigos): Initial Contact, Loading Response, Mid Stance, Terminal Stance, Pre-Swing, Initial Swing, Mid Swing, Terminal Swing. Нормальная скорость: 1.4 м/с. Cadence: 110-120 шагов/мин. Step length: 0.7-0.8 м. Stride length: 1.4-1.6 м. TUG (Timed Up and Go): ≤12 с норм (пожилые). | TUG >15 с = повышенный риск падений. |
| physther.ops.mcmurray_meniscus_ortho | Orthopedic Tests — Special Tests | METHOD | Специальные ортопедические тесты (Special Tests): Anterior Drawer Test / Lachman: ACL. McMurray: мениск. FABER / FADIR: тазобедренный. Thomas: сгибатели бедра tight. Trendelenburg: слабость ГСМ. Straight Leg Raise (SLR): nerve root compression. SLUMP test: dural tension. Sensitivity vs Specificity таблицы для клинического принятия решений. | Никогда не делать special test единственным диагнозом. Совокупность признаков. |
| physther.ops.balance_single_leg | Balance — Vestibular Rehabilitation | METHOD | Вестибулярная реабилитация: для BPPV (Epley манёвр), вестибулярный неврит (VRT — Vestibular Rehabilitation Therapy), двустороннее повреждение (substitution). Exercises: gaze stabilisation (VOR cancellation), balance training, habituation. Single-Leg Stance: <5 с у пожилых = высокий риск падений. Romberg: с закрытыми глазами. BESS. | Упражнения для глаз при вестибулярном нарушении: начинать с малых движений (не вызывают сильное головокружение). |
| physther.ops.dry_needling_PT | Dry Needling — Physical Therapy | METHOD | Сухая игла в ФТ: для мышечно-фасциальных болевых синдромов. Mтриггерные точки (TrP): taut band + twitch response. Техника: локализация TrP пальпацией → игла in-situ (needle stick) или piston (угловые движения). Местный TrP → распространение боли (referral pattern). Отличие от акупунктуры: western neuroanatomical basis. | In некоторых странах: dry needling = только для физиотерапевтов (legislation varies). |
| physther.ops.taping_kinesiotaping | Kinesiotaping — Application | METHOD | Кинезиотейпирование: эластичный тейп с акриловым клеем. Применения: снижение боли (decompression), улучшение проприоцепции, лимфодренаж, поддержка мышц. Muscle technique: от origin к insertion (activation) или от insertion к origin (inhibition). Tension: 0-25% (lymph/sensory), 25-50% (structural). Противопоказания: открытые раны, аллергия, DVT. | Доказательная база: умеренная (лучше чем плацебо для боли при ПФС и миофасциальных). |
| physther.ops.iontophoresis_electrotherapy | Iontophoresis — Drug Delivery | METHOD | Ионтофорез: введение лекарства через кожу с помощью постоянного тока. Анод (+): доставка катионов (лидокаин, акетикислота, Zn). Катод (-): анионы (дексаметазон — снижает воспаление). Параметры: 1-4 mA/cm² (безопасно). Длительность: 20-40 мА·мин. Противопоказания: аллергия на лекарство, кожные повреждения. | Дексаметазон по катоду: стандарт при воспалительных тендинопатиях. |
| physther.ops.aquatic_therapy | Aquatic Therapy — Properties | METHOD | Гидротерапия: свойства воды. Плавучесть: Архимеда (уменьшает нагрузку на суставы). Turbulence сопротивление: пропорционально скорости² (прогрессирование). Hydrostatic pressure: снижает отёк (периферический). Температура: тёплая (28-34°C) = расслабляет спазм. Waist deep = 50% снижение нагрузки. | Подходит для: ранняя реабилитация после замены сустава, остеоартрит, фибромиалгия. |
| physther.ops.strengthening_grades | Manual Muscle Testing — Grades | METHOD | Мануальное тестирование мышц (MMT): Grade 0: нет сокращения. Grade 1: видимое/пальпируемое сокращение, нет движения. Grade 2: движение в полном объёме без гравитации. Grade 3: движение в полном объёме против гравитации. Grade 4: движение против умеренного сопротивления. Grade 5: нормальная сила против максимального сопротивления. | Точность MMT: ограничена при сравнении (subjective). Динамометр = объективнее. |
