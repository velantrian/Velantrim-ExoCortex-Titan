| mlops.ops.feature_engineering | Feature Engineering — Transformation | METHOD | Трансформация признаков: Normalization (Min-Max Scaler: [0,1]). Standardization (StandardScaler: μ=0, σ=1). Log transform: при скошенных распределениях. Box-Cox: оптимальная λ для нормализации. Binning: числовые → категориальные. Interaction features: A×B. Polynomial features. Missing value imputation: mean/median/mode/KNN. | Feature leakage: информация из будущего в обучающих данных → завышенная performance. |
| mlops.ops.bias_variance_tradeoff | Bias-Variance — Tradeoff | METHOD | Ошибка обобщения = Bias² + Variance + Irreducible Error. Высокий bias: underfitting (простая модель). Высокая variance: overfitting (сложная модель). Regularization: Ridge (L2, weight decay), Lasso (L1, feature selection). ElasticNet: оба. Dropout (NN): варьирует ансамбль. Ensemble methods: снижают variance. | Learning curves: train error, validation error vs training size = диагностика bias/variance. |
| mlops.ops.cross_validation_strategies | Cross-Validation — Strategies | METHOD | Кросс-валидация: K-Fold (k=5 или 10): делит данные на k частей, ротация. Stratified K-Fold: сохраняет class distribution. Leave-One-Out (LOO): крайний случай. Time Series: TimeSeriesSplit (нельзя допускать data leakage). Nested CV: внешний для оценки, внутренний для tuning. GroupKFold: исключить одну группу (пациент, пользователь). | Кросс-валидация на тест-сете = data leakage (invalidates estimation). |
| mlops.ops.hyperparameter_tuning | Hyperparameter Tuning — Strategies | METHOD | Подбор гиперпараметров: Grid Search: полный перебор. Random Search (более эффективен). Bayesian Optimization (Optuna, Hyperopt): суррогатная модель предсказывает лучшие параметры. Successive Halving: прерывать плохих кандидатов рано. Population Based Training (Deepmind): параллельный + evolutionary. BOHB (Bayesian Optimization + Hyperband). | Random Search vs Grid: 60-80% лучше за то же время (Bergstra & Bengio). |
| mlops.ops.mlflow_experiment_tracking | MLflow — Experiment Tracking | METHOD | MLflow: open-source platform для ML lifecycle. Tracking: log parameters, metrics, artifacts. Projects: воспроизводимые запуски. Models: model registry (staging/production). Model Serving: REST API, Docker. Tracking URI: MLflow server. run_id: уникальный идентификатор. Autolog: sklearn, TensorFlow, PyTorch автоматически. | Эксперимент без tracking: «что было параметром при лучшем результате?» — не вспомнить. |
| mlops.ops.model_deployment_patterns | Model Deployment — Patterns | METHOD | Паттерны деплоя ML-моделей: Batch prediction: периодические, bulk, не real-time. Online prediction: REST API, low-latency. Shadow deployment: production трафик проходит через оба (без последствий от новой модели). Canary: постепенное переключение (5% → 20% → 100%). Blue-Green: мгновенное переключение между версиями. A/B test: явное сравнение двух версий. | Feature store: централизованное хранение признаков (Feast, Tecton). |
| mlops.ops.data_drift_detection | Data Drift — Detection Methods | METHOD | Дрейф данных (data drift): distribution shift → модель деградирует. Covariate shift: p(X) изменилось. Label shift: p(Y) изменилось. Concept drift: p(Y|X) изменилось. Методы: Population Stability Index (PSI), KS-test, Maximum Mean Discrepancy (MMD), EVIDENTLY AI. Triggers: retrain when PSI >0.2 or performance drops. | PSI 0-0.1: нет изменений. 0.1-0.2: умеренный. >0.2: значительный дрейф. |
| mlops.ops.class_imbalance | Class Imbalance — Techniques | METHOD | Дисбаланс классов: Resampling: SMOTE (Synthetic Minority Oversampling Technique) — создаёт синтетические примеры меньшего класса. Random Undersampling: удалить из большего. Class weights: penalize minority class mistakes. Threshold tuning: не 0.5 порог. Ensemble: BalancedBaggingClassifier. Метрики: Precision-Recall AUC (вместо ROC AUC при imbalance). | Accuracy paradox: 95% accuracy при 95% класс A → модель может просто всегда предсказывать A. |
| mlops.ops.shap_model_explanation | SHAP — Model Explainability | METHOD | SHAP (SHapley Additive exPlanations): unified framework для feature importances. Shapley values из теории игр. SHAP values: вклад каждого признака в предсказание. Summary plot: глобальная важность. Force plot: индивидуальное предсказание. Dependence plot: SHAP vs feature value. TreeSHAP: эффективно для деревьев. DeepSHAP: для нейронных сетей. | LIME (Local Interpretable Model-Agnostic Explanations): альтернатива (аппроксимация локально). |
| mlops.ops.neural_architecture_search | Neural Architecture — Transfer Learning | METHOD | Transfer Learning: предобученные веса на большом датасете → дообучение на малом. Fine-tuning: разморозить последние слои. Feature extraction: заморозить всё, только classifier обучается. ImageNet weights (ResNet, EfficientNet, ViT): для vision. BERT/GPT: для NLP. Few-shot learning: обучение из малого числа примеров. Zero-shot: без примеров (LLM prompting). | Предобученные модели: экономят недели обучения. |
| mlops.ops.recommender_system | Recommendation Systems — Types | METHOD | Рекомендательные системы: Collaborative Filtering: на основе поведения похожих пользователей (user-based, item-based). Matrix Factorization (SVD, ALS): разложение матрицы user-item. Content-based: на основе атрибутов item и user. Hybrid. Cold start problem: новый пользователь/item. Evaluation: NDCG, Precision@K, MRR. | Popularity bias: рекомендуются популярные → diversity снижается. |
| mlops.ops.causal_inference_ml | Causal Inference — ML Methods | METHOD | Каузальный вывод в ML: correlation ≠ causation. Potential Outcomes Framework (Rubin): Y(1), Y(0). Average Treatment Effect (ATE). Instrumental Variables (IV). Difference-in-Differences (DiD). Regression Discontinuity (RD). DoWhy: Python библиотека для каузального вывода. Confounders: добавляют spurious correlations. | A/B test = randomized experiment → causation. Observational = correlation (confounders). |
| mlops.ops.time_series_forecasting | Time Series — Forecasting Models | METHOD | Прогнозирование временных рядов: ARIMA: AutoRegressive Integrated Moving Average (p,d,q). SARIMA: seasonal. Prophet (Meta): holiday effects, trend changepoints. LightGBM/XGBoost с lag features. LSTM для nonclinear. N-BEATS (pure DL). Evaluation: MAPE, RMSE, MAE, sMAPE, MASE. Backtesting: expanding vs rolling window. | Избежать: тест на тренировочных данных после parameter tuning (look-ahead bias). |
| mlops.ops.fairness_ml | ML Fairness — Metrics | METHOD | Справедливость в ML: Demographic Parity: P(ŷ=1|A=0) = P(ŷ=1|A=1) (равный positives rate). Equalized Odds: TPR + FPR равны по группам. Individual Fairness: похожие люди → похожие предсказания. Trade-offs: нельзя одновременно выполнить все критерии (Arrow's impossibility). Аудит моделей: Aequitas, Fairlearn, IBM AI Fairness 360. | Proxy variables: даже без protected attribute → могут кодировать race (zip code → race in USA). |
| mlops.ops.federated_learning | Federated Learning — Privacy | METHOD | Федеративное обучение (FL): обучение на децентрализованных данных (не собирать в единое место). FedAvg: локальное обучение на узлах → усреднение весов. Differential Privacy: добавить noise для privacy protection (ε-differential privacy). Secure Aggregation: криптографическое агрегирование (никто не видит индивидуальные градиенты). Challenges: non-IID data (heterogeneous devices). | Google Gboard: FL для text prediction на Android без отправки текстов на сервер. |
| mlops.ops.gpt_prompting | LLM Prompting — Engineering | METHOD | Prompt Engineering: Zero-shot: просто задача без примеров. Few-shot (in-context learning): 2-5 примеров в prompt. Chain-of-Thought (CoT): «Let's think step by step» → улучшает reasoning. ReAct: Reasoning + Acting (tools). Self-Consistency: сэмплировать несколько CoT → голосование. Tree of Thoughts. RAG (Retrieval-Augmented Generation): документы добавляются в context. | Prompt injection: вредоносный ввод перезаписывает инструкции. |
| mlops.ops.graph_neural_networks | Graph Neural Networks — Types | METHOD | Графовые нейронные сети (GNN): Message Passing Neural Network (MPNN). GCN (Graph Convolutional Network). GAT (Graph Attention Network): веса рёбер. GraphSAGE: inductive (новые узлы без переобучения). Применение: молекулярные свойства, рекомендации, fraud detection, knowledge graphs. Node/Edge/Graph-level tasks. PyG (PyTorch Geometric), DGL. | Heterogeneous graphs: разные типы узлов и рёбер (HAN, R-GCN). |
| mlops.ops.anomaly_detection_types | Anomaly Detection — Methods | METHOD | Обнаружение аномалий: Point anomaly: единичное отклонение. Contextual: аномально в контексте (тепература летом). Collective: группа аномалий. Methods: Isolation Forest, LOF (Local Outlier Factor), DBSCAN (noise points), Autoencoder (reconstruction error high). Time series: LSTM reconstruction, STL decomposition. Threshold: fixed vs adaptive. | Unsupervised anomaly detection: нет labels (типично для real-world). |
| mlops.ops.model_compression | Model Compression — Techniques | METHOD | Сжатие модели: Pruning (обрезка): удалить малозначимые веса (unstructured vs structured). Quantization: FP32 → INT8 (в 4× меньше, быстрее). Knowledge Distillation: маленькая student модель учится у большой teacher. Low-rank factorization: разложить матрицы весов. ONNX: формат для cross-platform deployment. TensorRT: NVIDIA оптимизация для inference. | Quantization-Aware Training (QAT): лучшее качество чем Post-Training Quantization (PTQ). |
| mlops.ops.evaluation_metrics_classification | Evaluation Metrics — Classification | METHOD | Метрики классификации: Accuracy = (TP+TN)/(TP+TN+FP+FN). Precision = TP/(TP+FP). Recall (Sensitivity) = TP/(TP+FN). F1 = 2×(P×R)/(P+R). ROC-AUC: threshold-free. Confusion Matrix: полная картина. Matthews Correlation Coefficient (MCC): для imbalanced. Calibration: Brier Score, reliability diagram. | F1-macro: среднее по классам (равный вес). F1-weighted: взвешенное по поддержке. |
