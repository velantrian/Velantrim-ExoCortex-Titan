| cognsci.ops.working_memory_baddeley | Working Memory — Baddeley Model | METHOD | Рабочая память (Баддели): Центральный исполнитель (Central Executive): контроль и координация. Фонологическая петля (Phonological Loop): кратковременное удержание звуковой информации. Визуально-пространственный блокнот (Visuospatial Sketchpad): зрительная информация. Эпизодический буфер (Episodic Buffer): интеграция с долгосрочной памятью. Ёмкость: 7±2 элементов (Миллер) или 4±1 (Коуэн). | Cognitive load theory: управление рабочей памятью в обучении. |
| cognsci.ops.dual_process_theory | Dual Process Theory — System 1/2 | METHOD | Двухпроцессная теория (Канеман): System 1 (Быстрое): автоматическое, быстрое, бессознательное, эвристики + эмоции. System 2 (Медленное): медленное, преднамеренное, сознательное, рациональное. Cognitive bias: ошибки System 1 (anchoring, availability heuristic). Thinking, Fast and Slow (2011). Переутомление: истощение System 2 → больше System 1. | «Эвристика доступности»: оцениваем вероятность по лёгкости вспоминания. |
| cognsci.ops.cognitive_biases | Cognitive Biases — Catalogue | METHOD | Когнитивные искажения: Anchoring (эффект привязки): первое число влияет на оценку. Confirmation bias: ищем подтверждение своих убеждений. Dunning-Kruger: неопытные переоценивают, опытные недооценивают. Sunk cost fallacy: продолжаем из-за вложений. Framing effect: как подана информация влияет на решение. Overconfidence: систематическая переоценка точности. | Debiasing techniques: pre-mortem analysis (Клейн), devil's advocate, perspective-taking. |
| cognsci.ops.long_term_memory_types | Long-term Memory — Explicit vs Implicit | METHOD | Долгосрочная память: Эксплицитная (декларативная): Эпизодическая (автобиографические события) + Семантическая (общие знания). Имплицитная (процедурная): Процедурная (навыки) + Прайминг + Классическое обусловливание. Консолидация: гиппокамп → неокортекс. Sleep consolidation: медленный сон = декларативная, REM = процедурная. | Амнезия: ретроградная (до травмы) vs антероградная (после). H.M.: не мог формировать новые эпизодические. |
| cognsci.ops.attention_spotlight | Attention — Spotlight Model | METHOD | Внимание: Прожекторная модель (Posner): внимание = прожектор, может перемещаться. Экзогенное (bottom-up, рефлексивное): привлекается стимулом. Эндогенное (top-down, волевое): направляется намеренно. Cocktail party effect: фильтрация нерелевантного (Cherry). Attentional blink: второй целевой объект не замечается. Change blindness: невидение изменений без внимания. | Visual attention: «инвентарь» всего поля (~4 объекта в параллели). |
| cognsci.ops.executive_function | Executive Function — Inhibition | METHOD | Исполнительные функции (Diamond 2013): Inhibition (торможение): контроль ответных реакций и мыслей. Working Memory: удержание и манипуляция. Cognitive Flexibility: переключение. Более высокого уровня: planning, reasoning, problem-solving. Prefrontal cortex (PFC): основная база EF. «Cool» EF (когнитивные) vs «Hot» EF (эмоциональные). | Развитие EF у детей: продолжается до 25 лет (PFC последний зреет). |
| cognsci.ops.schemas_mental_models | Schemas — Mental Models | METHOD | Схемы (Бартлетт) + Ментальные модели: организованные структуры знаний, влияющие на восприятие и память. Schema-driven errors: вспоминаем то что ожидаем, не то что было. Script: схема для событий (restaurant script). Expert vs novice differences: эксперты имеют более богатые схемы. | Schema interference: ошибки памяти из-за «дополнения» шаблоном (Loftus eyewitness). |
| cognsci.ops.neuroplasticity_learning | Neuroplasticity — Hebbian Learning | METHOD | Нейропластичность: «Нейроны, которые срабатывают вместе, связываются вместе» (Хебб). LTP (Long-Term Potentiation): укрепление синапсов при одновременной активации. LTD (Long-Term Depression): ослабление. BDNF (brain-derived neurotrophic factor): стимулируется физическими упражнениями → улучшает пластичность. Perirhinal cortex: объединяет информацию с разных сенсорных модальностей. | Аэробные упражнения 20 мин: повышают BDNF, улучшают когниции (краткосрочный эффект). |
| cognsci.ops.language_cognition_sapir_whorf | Language and Cognition — Linguistic Relativity | METHOD | Лингвистическая относительность (Сапир-Уорф): Strong hypothesis: язык определяет мышление. Weak hypothesis: язык влияет на мышление. Evidence for weak version: цветовые категории, число слов для цветов (Boroditsky). Counter-evidence: невербальное мышление, translation. Theory of mind: понимание ментальных состояний других. | Pirahã (Амазония): нет числительных → ограниченный точный счёт. |
| cognsci.ops.decision_making_prospect | Prospect Theory — Kahneman & Tversky | METHOD | Теория перспектив (Канеман, Тверски 1979): Индивиды оценивают исходы относительно reference point, не абсолютно. Loss aversion: потеря ощущается сильнее выигрыша одинакового размера (λ≈2.25). Value function: вогнута для выигрышей, выпукла для потерь. Probability weighting: маленькие вероятности переоцениваются. | Framing effects: «200 из 600 выживут» vs «400 из 600 умрут» → разные выборы. |
| cognsci.ops.metacognition | Metacognition — Monitoring | METHOD | Метакогниция: «мышление о мышлении». Monitoring (мониторинг): оценка собственного понимания (KOJ — Judgments of Knowledge). Control: управление учением на основе мониторинга. Feeling-of-Knowing (FOK). Calibration: соответствие уверенности реальности. Overconfidence effect: люди систематически считают себя точнее, чем они есть. | Метакогнитивные стратегии: retrieval practice, self-explanation, interleaving. |
| cognsci.ops.embodied_cognition | Embodied Cognition — Body-Mind | METHOD | Воплощённое познание: когниция не только в голове — тело и окружающая среда участвуют. Conceptual metaphors (Lakoff & Johnson): «warm personality» — тепло руки → симпатия. Motor simulation: понимание действий через моторные зоны. Grounded cognition (Barsalou): концепты = моторные симуляции. Extended mind (Clark): инструменты = часть когнитивной системы. | Embodied effect: держать теплый напиток → воспринимают незнакомца теплее. |
| cognsci.ops.flow_state | Flow — Optimal Experience | METHOD | Поток (Flow, Чиксентмихайи): оптимальное состояние полного погружения в деятельность. Условия: навыки ≈ challenge (не слишком легко/сложно). Признаки: концентрация, потеря времени, внутреннее вознаграждение. Аутотелическое переживание. Flow в работе: требует clear goals + immediate feedback + challenge/skill balance. | Слишком лёгкая задача: скука. Слишком сложная: тревога. Баланс = поток. |
| cognsci.ops.forgetting_curve | Forgetting — Ebbinghaus Curve | METHOD | Кривая забывания (Эббингауз): память снижается по экспоненте. 20 мин → 42% потеряно. 1 час → 56%. 1 день → 66%. 1 неделя → 75%. 1 месяц → 79%. Spaced repetition: повторение с нарастающим интервалом → удержание на плато. Retrieval practice: активное вспоминание > пассивное перечитывание. | Поколение информации: собственная генерация > чтение (Generation Effect). |
| cognsci.ops.tversky_availability | Heuristics — Availability & Representativeness | METHOD | Эвристики (Тверски, Канеман): Availability (Доступность): оцениваем вероятность по лёгкости вспоминания. Representativeness: оцениваем вероятность по сходству с прототипом. Base rate neglect: игнорирование базовых частот (conjunctive fallacy). Gambler's fallacy: прошлые случайные события влияют на будущие. | Availability: после авиакатастрофы страх летать растёт (доступный образ). |
| cognsci.ops.attention_adhd_neuropsychology | ADHD — Neuropsychological Profile | METHOD | СДВГ с нейропсихологической точки зрения: дефицит executive functions (inhibition, working memory) + reward processing (dopamine pathways). Prefrontal cortex hypoactivation. Default Mode Network (DMN): гиперактивен при СДВГ = mind-wandering. Methylphenidate: блокирует reuptake DA + NE → улучшает EF. Neurocognitive profile: heterogeneous (нет одного профиля). | СДВГ = не только внимание — executive function + motivation + time perception. |
| cognsci.ops.cognitive_load_theory | Cognitive Load — Instructional Design | METHOD | Теория когнитивной нагрузки (Свеллер): Intrinsic load: сложность материала. Extraneous load: плохой дизайн (усиливает нагрузку). Germane load: усилие для формирования схем. Принципы уменьшения: worked examples → fade (self-explanation effect), modality principle (аудио + визуал), split-attention effect. Element interactivity: высокая = более высокий intrinsic load. | Redundancy effect: избыток информации = перегрузка (не «больше = лучше»). |
| cognsci.ops.concept_learning_prototype | Concept Learning — Prototype Theory | METHOD | Обучение концептам: Classical view: необходимые и достаточные условия. Prototype theory (Rosch): концепт = прототипный пример + степени принадлежности. Family resemblance (Витгенштейн). Graded membership: robin = best bird, penguin = poor bird. Exemplar theory: концепты хранятся как конкретные примеры. Category knowledge: влияет на умозаключения. | Прототипический эффект: «типичное» распознаётся быстрее/легче. |
| cognsci.ops.mirror_neurons | Mirror Neurons — Social Cognition | METHOD | Зеркальные нейроны (Риццолатти): нейроны, активирующиеся как при выполнении, так и при наблюдении действия. Область F5 макак → человеческий аналог (IFG, SMA). Гипотезы: эмпатия, имитационное обучение, понимание действий. Критика: зеркальные нейроны у людей = косвенное доказательство (fMRI, not single-cell). | Mirror neuron «broken» теория аутизма: не подтверждена (slick neuroscience). |
