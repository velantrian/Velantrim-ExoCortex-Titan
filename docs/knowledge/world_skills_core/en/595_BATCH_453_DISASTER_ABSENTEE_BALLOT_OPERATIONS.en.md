| disasterballot.intake.voter_identification | Disaster Voter Identification & Verification | METHOD | Идентификация избирателя в зоне ЧС: проверка личности через множественные каналы (фото ID если сохранился, свидетельство 2 знающих избирателей под присягой, affidavit of identity с проверкой подписи против voter registration database, временные ID выданные shelter management). Если документы утеряны при ЧС — упрощённая верификация: имя + адрес + дата рождения против регистрационной базы, с пометкой «disaster-verified» в системе. | Без стандартной верификации избиратель не может получить бюллетень, но в ЧС документы часто утеряны. Важно: электронная сверка с statewide voter registration system (SVRS) даже при повреждении локальной инфраструктуры через спутниковый/резервный канал связи. |
| disasterballot.intake.eligibility_screening | Absentee Eligibility Screening in Disaster | METHOD | Проверка права на disaster absentee ballot: 1) был ли зарегистрирован в пострадавшем округе ДО ЧС, 2) находится ли вне места жительства из-за эвакуации/повреждения жилья, 3) не подавал ли уже заявление на обычный absentee в текущем избирательном цикле. Отсев: перемещён временно ≠ переехал навсегда (change of residence intent test). Screening form: checklist с флагами для ручного review (e.g., адрес shelter совпадает с адресом вне округа → вероятный эвакуированный, approve). | Самая частая ошибка: студенты и военнослужащие, уже подавшие absentee через UOCAVA (Uniformed and Overseas Citizens Absentee Voting Act), дублируют заявку через disaster-канал. Cross-reference с UOCAVA-базой обязателен. Second-home owners, покинувшие зону ЧС на зимний сезон, не проходят eligibility (displacement не из-за disaster). |
| disasterballot.intake.registration_status_check | Real-Time Registration Status Verification | METHOD | Проверка статуса регистрации через statewide voter registration database (VRDB): active, inactive, cancelled, pending. Если inactive (не голосовал 2 последних федеральных цикла) — право на disaster ballot сохраняется (disaster exception), но требуется подтверждение адреса. Если cancelled (переехал/умер/duplicate) — передать на supervisor review: возможно, cancellation был ошибочным (двойная регистрация при переезде). Если не зарегистрирован — информировать о возможности same-day registration там, где разрешено законом штата. | VRDB могут быть недоступны из-за повреждения дата-центров в зоне ЧС. Резервная процедура: offline-копия базы на защищённом ноутбуке, обновляемая ежедневно до ЧС. Альтернатива: provisional ballot с последующей верификацией регистрации после восстановления систем (counted only if registration confirmed). |
| disasterballot.forms.application_completion | Absentee Ballot Application — Assisted Completion | METHOD | Форма FPCA (Federal Post Card Application) или эквивалент штата. Ключевые поля: Full Name (match registration exactly — middle name/initial matters), Date of Birth (MM/DD/YYYY), Registration Address (где зарегистрирован, не где сейчас), Mailing Address (куда отправить бюллетень: shelter, hotel, родственники, P.O. Box, e-mail/online portal для electronic delivery), Party Affiliation (для праймериз), Reason for Absentee (disaster displacement). Подпись: wet signature или электронная (зависит от штата). Помощник заполняет ТОЛЬКО под диктовку избирателя, подписывает раздел «assistor» с указанием причины помощи (language, disability, disaster stress). | Несовпадение имени с регистрацией (девичья фамилия vs married, Jr./Sr., hyphenated) — причина №1 отклонения заявки. Всегда проверять VRDB на точное написание имени. Адрес для отправки — критично: если shelter временный и бюллетень придёт после закрытия shelter — потеря голоса. Рекомендовать permanent mailing address (родственники вне зоны ЧС, P.O. Box). |
| disasterballot.forms.language_access | Language Access & Translation Support | METHOD | Section 203 of Voting Rights Act: юрисдикции со значительным языковым меньшинством (>5% или >10,000 граждан с limited English proficiency) обязаны предоставлять материалы на языке меньшинства. В disaster setting дополнительно: ситуативные языки (эвакуированные из других штатов/стран), языки без подготовленных материалов (срочный устный перевод через телефонного переводчика LanguageLine или волонтёра). Формы: предоставить translated application + English original side-by-side. Устная помощь: interpreter oath («клянусь переводить точно и полно, не влиять на выбор избирателя»). | Использование детей как переводчиков — нарушение (давление на избирателя + неточный перевод юридических терминов). Волонтёр-переводчик должен быть НЕ из семьи избирателя (конфликт интересов — может влиять на выбор). Для языков без письменности — устное заполнение под запись (запись сохраняется как аудиторский след). |
| disasterballot.forms.disability_accommodation | Disability Accommodation in Absentee Voting | METHOD | Help America Vote Act (HAVA) 2002: каждый polling place должен иметь accessible voting system. Для absentee/disaster: 1) избиратель с нарушением зрения — electronic ballot delivery (screen-reader совместимый PDF/HTML), возможность отметить бюллетень на своём устройстве с assistive technology и распечатать; 2) нарушение подвижности — curbside application assistance, помощь в заполнении (2 человека разных партий или sworn election worker); 3) когнитивные нарушения — упрощённая инструкция plain language, дополнительное время. Remote accessible vote-by-mail (RAVBM) — система, позволяющая отметить и вернуть бюллетень полностью онлайн (разрешено не во всех штатах). | Проблема: electronic ballot delivery требует доступа к интернету и принтеру, которых у перемещённого лица может не быть. Решение: mobile print station в shelter с избирательной урной (mailbox) для возврата. Signature stamps и digital signatures: разрешены для voters с постоянной инвалидностью, но требуют предварительной регистрации signature device с election office. |
| disasterballot.deadlines.registration_cutoff | Voter Registration & Absentee Request Deadlines | VARIANT | Деадлайны варьируются по штатам: регистрация — от 30 дней до дня выборов (same-day registration: 21 штат + DC). Absentee ballot request: от 30 дней до дня выборов (в некоторых штатах — за 7-10 дней). Disaster exception: во многих штатах губернатор или secretary of state могут издать emergency order, продлевающий дедлайны для пострадавших округов (typical: +7-14 дней на регистрацию и запрос). Federal write-in absentee ballot (FWAB) — резервный бюллетень для военных и overseas, может использоваться как backup если обычный absentee не пришёл вовремя (НЕ disaster-specific, но может применяться перемещёнными UOCAVA voters). | Отслеживание дедлайнов в реальном времени при множественных юрисдикциях (эвакуированные из разных штатов в одном shelter) — логистический кошмар. Решение: disaster voting hotline с lookup-таблицей дедлайнов по zip-коду регистрации + автоматический калькулятор (если сегодня подать, когда бюллетень придёт? можно ли успеть вернуть?). Emergency orders публикуются на сайте secretary of state и NASS (National Association of Secretaries of State). |
| disasterballot.deadlines.ballot_return_timeline | Ballot Return Timeline & Postal Delays | PROCESS | Критический путь: запрос подан → обработка election office (1-3 дня) → отправка бюллетеня избирателю (почтовый транзит 2-5 дней внутри штата, до 10 дней out-of-state) → избиратель отмечает и возвращает → почтовый транзит обратно (ещё 2-10 дней) → получено election office до закрытия участков в день выборов. В disaster setting: почтовые отделения могут быть закрыты, перегружены или разрушены. Резервные каналы: электронная доставка бюллетеня (email/portal — избиратель распечатывает), возврат курьером (FedEx/UPS overnight), drop-off в ближайшем election office (даже в другом округе — forwarded). Postmark rule: в некоторых штатах бюллетень считается поданным вовремя, если отправлен (postmark) до дня выборов и получен в течение X дней после (правило «postmark + N дней»). | Военные и overseas voters имеют 45-дневный цикл под MOVE Act (Military and Overseas Voter Empowerment Act, 2009). Для disaster voters таких федеральных гарантий нет — зависит от emergency order штата. Самая частая причина disenfranchisement в ЧС: бюллетень ПРИХОДИТ после дня выборов из-за почтовых задержек. Решение: encourage electronic delivery + drop-off return там, где разрешено. |
| disasterballot.submission.bundle_tracking | Ballot Application Bundle Tracking | METHOD | Каждая application получает tracking ID при подаче (barcode/QR sticker на бумажной форме, confirmation number для электронной). Реестр: spreadsheet/database с полями: Tracking ID, Voter Name, DOB, Reg Address, Mailing Address, Application Date, Ballot Sent Date, Ballot Return Date, Status (submitted/approved/rejected/sent/returned/counted). Обновление статуса: election office вводит данные в VRDB при каждой смене статуса → избиратель может проверить онлайн. В disaster — mobile tracking station: волонтёры с ноутбуками и cellular/спутниковым интернетом проверяют статус заявки избирателя. | Прозрачность статуса — ключ к доверию. Избиратель, потерявший всё в огне/наводнении, должен знать, что его голос посчитан. Automated alerts (SMS/email): «Ваш запрос получен [date], бюллетень отправлен [date], ожидаемое получение [date-range], бюллетень получен office [date], статус counted [date]». Wildfire example (California 2018, 2020): mobile voting centers развёрнуты в shelters, избиратели могли отследить статус через государственный портал. |
| disasterballot.submission.chain_of_custody | Chain of Custody — Absentee Ballot Handling | METHOD | Документированная передача каждого бюллетеня на каждом этапе: избиратель → application → election office → printing/mailing room → почтовый поток → получение избирателем → избиратель заполняет → возврат → почтовый поток → election office receiving → signature verification → envelope opening → ballot extraction → tabulation. Каждый этап: timestamp, handler ID, location, witnessed by. Двухпартийный контроль (bipartisan teams): на этапах вскрытия конвертов и tabulation — минимум 1 демократ + 1 республиканец (или эквивалент из основных партий в других странах). В disaster — mobile bipartisan teams с видеозаписью всех действий (body cameras). | Логи: каждый бюллетень имеет цифровой след в election management system (EMS). Печать chain of custody log по окончании выборов — юридический документ, сохраняемый на период contest period (обычно 22 месяца для федеральных выборов под Civil Rights Act). Disaster exception: если оборудование EMS повреждено, бумажные chain of custody logs — единственный proof → хранить в fireproof safe. |
| disasterballot.submission.signature_verification | Signature Verification Process | METHOD | Сравнение подписи на absentee ballot envelope с подписью в voter registration record (оригинальная регистрационная форма, DMV signature, предыдущая absentee ballot). Критерии: общая форма, наклон, размер, петли, connecting strokes, baseline. Кто проверяет: trained election workers (не волонтёры), часто с bipartisan supervision. При несовпадении (mismatch) — НЕ reject автоматически. Процесс: notified voter (phone, email, mail) → voter предоставляет affidavit of identity (cure process) → deadline для cure (обычно 2-8 дней после выборов, зависит от штата). | Проблема disaster: подпись изменилась из-за травмы? стресса? спешки? Пожилые избиратели — signature drift со временем (DMV signature 20-летней давности). Cure process — критично: без уведомления и времени на исправление signature mismatch = disenfranchisement. Автоматическая сверка подписей ИИ (некоторые штаты) — спорно: risk of false mismatch для minority voters. |
| disasterballot.ballot_types.multiple_jurisdictions | Multi-Jurisdiction Ballot Logistics | METHOD | Эвакуированные из разных округов в одном shelter → нужны разные бюллетени (разные конгрессиональные округа, штатные легислатуры, county меры). On-demand ballot printing (ODBP): принтер печатает правильный ballot style по адресу регистрации избирателя из электронной базы. Ballot style lookup: zip+4 или полный адрес регистрации → определяет precinct → определяет ballot style ID. В disaster — привезти 50-100 разных ballot styles в shelter невозможно → ODBP через защищённый ноутбук + принтер с encrypted hard drive. | Без ODBP избиратель получает неправильный бюллетень (чужой конгрессмен) → голос не считается для локальных выборов → disenfranchisement по местным вопросам. Вызов: каждый принтер должен быть протестирован на все ballot styles (бывают ошибки alignment → vote scanner не читает). Paper stock requirements: толщина, цвет, watermarks — не все бумаги подходят для vote tabulation machines. |
| disasterballot.ballot_types.fwab_backup | Federal Write-In Absentee Ballot (FWAB) Usage | METHOD | FWAB (Standard Form 186) — резервный бюллетень для UOCAVA voters. Может использоваться disaster voters только если они также UOCAVA (military/overseas) или если штат явно разрешил FWAB для disaster displaced. Содержит только федеральные офисы (President, Senate, House). Для state/local — blank lines для write-in. Ограничение: FWAB действителен только если regular absentee был запрошен вовремя, но не получен. FWAB НЕ заменяет регистрацию (нужно быть зарегистрированным). | FWAB — last resort, не первый выбор. Его считают, только если regular absentee бюллетень не получен к дедлайну (проверяют через VRDB). Если оба пришли — считается regular. Рекомендация: всегда подать regular absentee application + FWAB как страховку, если regular не придёт вовремя. |
| disasterballot.accessibility.mobile_voting_center | Mobile Voting Center Operations | METHOD | Развёртывание мобильного избирательного участка в shelter/evacuation center. Компоненты: 1) voter check-in station (ноутбук с VRDB, ID scanner, принтер для application), 2) ballot-on-demand printer (ODBP), 3) voting booth (складная, приватность, ADA-compliant), 4) ballot marking device (для accessible voting), 5) secure ballot box (locked, tamper-evident seals, chain of custody log). Персонал: 2+ trained election workers (bipartisan), переводчики, ADA-специалист. Безопасность: physical security (locked room/container overnight), alarm, video surveillance. | Мобильный центр ≠ полноценное early voting (early voting требует notice period, публикации location, и т.д., что невозможно в disaster). Это — facilitated absentee voting: избиратель получает и подаёт absentee-бюллетень на месте, бюллетени транспортируются в соответствующий county election office. Но избиратель должен понимать: это absentee, не in-person early vote (разные юридические последствия для сроков, cure process, etc.). |
| disasterballot.accessibility.curbside_triage | Curbside / Drive-Through Voting Assistance | METHOD | Для избирателей, не могущих войти в voting center/mobile unit: election worker выходит к автомобилю, проверяет ID, приносит application → избиратель заполняет → worker относит в помещение для печати бюллетеня → бюллетень + clipboard + privacy sleeve → избиратель голосует в автомобиле → worker возвращает запечатанный конверт в ballot box. Двухпартийность: 2 worker разных партий выходят вместе. Curbside log: имя избирателя, причина (disability, injury, contamination fear), время, workers present. | Проблемы: ветер/дождь (защита бюллетеня от элементов), конфиденциальность (другие пассажиры в авто), chain of custody (worker проходит путь автомобиль→помещение с бюллетенем один? или с bipartisan witness?). COVID-19 precedent: drive-through voting в некоторых штатах оказалась популярной среди избирателей, не только для accessibility, и теперь permanent option. |
| disasterballot.privacy.voter_anonymity | Voter Anonymity & Ballot Secrecy | INVARIANT | Двухконвертная система: внешний конверт (с информацией избирателя — имя, адрес, подпись) и внутренний secrecy envelope/sleeve (анонимный, содержит ТОЛЬКО бюллетень). При получении election office: внешний конверт вскрывается, подпись сверяется, внутренний конверт отделяется и помещается в кучу для tabulation. Разделение во времени и пространстве: signature verification team ≠ ballot counting team, они не общаются. Бюллетень не может быть связан с избирателем после отделения от внешнего конверта. | Нарушение: некоторые штаты печатают штрих-код избирателя на самом бюллетене для «auditing» — это разрушает secrecy и незаконно. Challenged в судах (PA, NC). Disaster risk: в спешке волонтёр может не вложить secrecy sleeve → бюллетень visible через окошко конверта → нарушение. Аудит: при получении проверять наличие secrecy sleeve, фотографировать конверт с окошком до вскрытия. |
| disasterballot.privacy.data_protection | Voter Data Privacy & Retention | METHOD | Данные избирателя (name, address, DOB, party, signature, contact info, disability status, assistor info) защищены: Election Security regulations, state data breach laws. Хранение: application forms — locked cabinet, 22 месяца; electronic records — encrypted database, access logged, role-based access control (RBAC). Sharing: voter registration list может быть предоставлен политическим партиям и кандидатам (public record), но absentee application info (reason, mailing address) — restricted (не для political mailings). Disaster specific: shelter address НЕ публикуется в voter file (privacy + safety). | GDPR/CCPA эквивалент в election data — нет единого федерального закона, patchwork state laws. California: CCPA даёт право на удаление, но voter registration data — government record, удаление невозможно (можно отменить регистрацию). Disaster complication: временные адреса (shelter, hotel) записываются в voter file и могут стать permanent если не очищены → voter получает почту на shelter через год. |
| disasterballot.education.voter_information | Disaster Voter Information Campaign | METHOD | Распространение информации в зоне ЧС: FEMA + election office совместный пресс-релиз, flyers в shelters, social media (Twitter/Facebook local election office), SMS alerts через emergency alert system (WEA — Wireless Emergency Alerts), радио (особенно в зонах без интернета). Ключевые сообщения на 3 вопроса: «Могу ли я голосовать?» (check registration status), «Как получить бюллетень?» (absentee request инструкция), «Где дедлайны?» (конкретные даты). Hotline: бесплатный номер, multilingual, с живым оператором (не только автоответчик), часы работы расширены за 2 нед до выборов. | Самое большое препятствие — дезинформация (displaced voter hears «выборы отложены в нашем округе» — почти всегда ложь, выборы НЕ откладываются для целого округа без extraordinary circumstances). Кампания должна атаковать мифы проактивно. FEMA может предоставить списки shelters и контакты shelter managers для доставки материалов. Избиратели без интернета — самая труднодоступная группа, радио и бумага всё ещё критичны. |
| disasterballot.education.poll_worker_training | Disaster Poll Worker & Volunteer Training | METHOD | Специализированное обучение для election workers, работающих в disaster setting: 1) disaster-specific election law (emergency orders, изменённые дедлайны и процедуры), 2) психологическая первая помощь (избиратель пережил травму — как распознать дистресс, как перенаправить к mental health resources, как не навредить), 3) работа с portable election equipment (ODBP printer, mobile VRDB, спутниковый интернет), 4) chain of custody в нестандартных условиях, 5) de-escalation (конфликтные избиратели — стресс ЧС делает людей раздражительными). Сертификация: тест по окончании, действует на текущий электоральный цикл, ежегодное переобучение. | Обычные poll workers training (4-8 часов на правила) недостаточно для disaster. Добавление модуля психологической помощи и мобильной технологии удваивает время обучения. Стандартный подход: опытные election workers (supervisors) + волонтёры-помощники (под supervision). Минимальный состав мобильного центра: 1 certified supervisor + 2 assistants + 1 tech support. |
| disasterballot.integrity.audit_procedure | Post-Election Disaster Absentee Audit | METHOD | Risk-limiting audit (RLA) для disaster absentee ballots: статистическая выборка из disaster absentee pool, ручной пересчёт и сравнение с machine count. Цель: проверить, что machine tabulation правильная в пределах заданного risk limit (обычно 5-10%). Дополнительно: сравнение количества disaster absentee applications vs бюллетеней отправленных vs бюллетеней полученных vs counted — пропавшие бюллетени? Объяснить каждый расхождение. Provisional ballots от disaster voters: проверка регистрации постфактум, включение в финальный canvass если верифицированы. Отчёт: публичный документ с разбивкой по precinct, method (mail, electronic, drop-off), и disaster designation. | Прозрачный аудит — единственный способ сохранить доверие к результатам в пострадавших округах (где turnout может быть аномально низким или высоким, или необычные паттерны — e.g., все из одного shelter голосуют одинаково). RLA математически обоснован (Philip Stark, UC Berkeley), внедрён в CO, GA, PA, VA. Стоимость: ~10-20 центов на бюллетень, доступно для любого округа. |
| disasterballot.integrity.fraud_prevention | Absentee Ballot Fraud Prevention | METHOD | Основные риски и контрмеры: 1) Duplicate voting — cross-check всех absentee applications против уже проголосовавших (in-person early voting, mail ballot received, другой absentee application); решение — real-time VRDB update при каждом действии. 2) Impersonation — кто-то голосует за перемещённого избирателя; контрмеры — signature verification, affidavit of identity с penalty of perjury, ID check где возможно. 3) Ballot harvesting — третья сторона собирает и подаёт чужие бюллетени; контрмеры — limit на количество бюллетеней, которые один человек может подать за других (семья — безлимитно, не-семья — 0-10 в зависимости от штата), обязательная подпись assistor, уголовная ответственность. 4) Inside fraud — election worker manipulating ballots; контрмеры — bipartisan teams, видеонаблюдение, audit. | Fraud prevention должен балансировать с доступом: избыточно жёсткие антифрод-меры disenfranchise законных избирателей (особенно minority, elderly, disabled). В disaster нужно документировать КАЖДОЕ исключение из правил: если ID не предъявлен — affidavit подписан? кто witness? где запись? Отклонение от процедуры — не proof of fraud, но требует обоснования в audit. |

Проблема координации: FEMA говорит на языке logistics/operations, election office — на языке law/procedure → нужен liaison officer, понимающий оба. |

| disasterballot.technology.odbp_system | On-Demand Ballot Printing (ODBP) — Technical Specs | METHOD | Система: ноутбук с encrypted hard drive + ballot style database (все precincts штата) + высокоскоростной принтер (duplex, 50+ ppm, laser для точности alignment) + redundant power (UPS + generator). Процесс: worker вводит адрес регистрации избирателя → ПО определяет precinct и ballot style → генерирует PDF с уникальным ballot ID (barcode) → принтер печатает на сертифицированной бумаге → worker проверяет качество печати (alignment test pattern, barcode readability) → избиратель получает бюллетень + secrecy sleeve + return envelope. Каждый напечатанный бюллетень логируется: ballot ID, voter ID (hashed), timestamp, operator ID, printer serial number. | Бумага должна точно соответствовать спецификации vote tabulation machine: размер, толщина (обычно 80 lb text), цвет, opacity (чтобы отметки не просвечивали на другую сторону при фотографировании). Неправильная бумага → scanner jam → все бюллетени из этого центра забракованы → ручной пересчёт (в 10-20 раз дороже). Тестовая печать каждое утро перед открытием: alignment page + test ballot → scan on reference scanner → compare hash. |
| disasterballot.technology.mesh_network | Emergency Communication — Mesh Network for VRDB Access | METHOD | Когда сотовая связь и интернет разрушены → развернуть mesh network (Wi-Fi узлы GoTenna Pro, Silvus, или Ubiquiti на elevated mast) между mobile voting centres и command vehicle → command vehicle имеет спутниковый терминал (Starlink, BGAN, VSAT) как backhaul → соединение с statewide VRDB. Пропускная способность: mesh обычно 5-50 Mbps shared, достаточно для VRDB queries (текст) и ballot PDF downloads (0.5-2 MB на бюллетень). Caching: VRDB snapshot загружается на локальный сервер в command vehicle при наличии спутникового соединения, обновляется периодически → mesh-узлы запрашивают локальный сервер (быстрее, меньше спутникового трафика). Offline mode: если спутниковое соединение тоже упало — локальный snapshot VRBD + offline-очередь транзакций (синхронизируется при восстановлении). | Тестирование mesh сети ДО ЧС (tabletop exercise) — критично. Дальность mesh-узла в городской застройке — 0.5-2 км, на открытой местности — до 15 км. Требуется line-of-sight. Команда технической поддержки на каждый mesh-узел (1 техник + 1 security для охраны оборудования, работающего на elevated mast или крыше). Шифрование: WPA3-Enterprise, VPN-туннель до state data center. |
