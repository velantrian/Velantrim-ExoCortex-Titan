| logic.nonclassical.relevance_logic_detail | Relevance Logic — Anderson & Belnap | INVARIANT | Требует содержательной связи посылки и заключения (relevance). Аксиома: только если A релевантно для B, то A→B допустимо. Избегает парадоксов материальной импликации (¬A → (A→B): «если 2+2=5, то Луна из сыра» — абсурдно для релевантной логики). | Применима в рассуждениях, где важна содержательная связь (право: «если обвиняемый невиновен, то его генетический профиль не имеет значения для приговора»). |
| logic.nonclassical.paraconsistent_detail | Paraconsistent Logic — Explosion Control | INVARIANT | Ex contradictione sequitur quodlibet (из противоречия следует всё что угодно) — НЕ работает в паранепротиворечивой логике. Допускает противоречия без тривиализации всей системы. Системы: LP (Logic of Paradox, Прист), RM3. | Базы данных с противоречивыми данными (разные источники, исправление). Диалектический материализм (противоречие как движущая сила). |
| logic.nonclassical.free_logic | Free Logic — Non-Denoting Terms | VARIANT | Допускает термы, которые ничего не обозначают (пустые имена: «Пегас», «нынешний король Франции»). Отказ от экзистенциального предположения (каждый терм что-то обозначает) классической логики. ∃!τ → τ существует. | «Пегас — крылатый конь» — истинно? Ложно? Ни то ни другое? Проблематика: Рассел (On Denoting, 1905), теория определённых дескрипций vs free logic. |
| logic.nonclassical.vagueness_sorites | Vagueness & Sorites Paradox | PROCESS | Куча (sorites): одно зерно — не куча. Добавление одного зерна не делает не-кучу кучей → по индукции любое число зёрен — не куча (парадокс). Проблема нечётких предикатов (лысый, высокий, куча). | fuzzy logic: степени истинности. Супервалиционизм: допускает размытость применения предикатов. Epistemicism: граница существует, но мы не знаем где. |
| logic.nonclassical.erotetic_logic | Erotetic Logic — Logic of Questions | MODEL | Вопросы как лингвистические объекты с логической структурой. Прямые ответы, presuppositions (пресуппозиции), релевантность. Императивы и вопросы в едином формализме. | «Ты перестал бить свою жену?» — loaded question, содержит ложную пресуппозицию. |
| architecture.roman_concrete | Roman Concrete (Opus Caementicium) | RECORD | Смесь извести (CaO), пуццоланы (вулканический пепел, реактивный SiO₂/Al₂O₃) + заполнитель. Отвердевает под водой (процесс гидравлический — кальциево-алюмосиликатные гидраты, C-A-S-H). Пантеон (118-128 н.э.): купол 43.3 м пролёта, облегчённый заполнитель к вершине (туф→пемза). | Самовосстановление: CaO + вода в трещинах → Ca(OH)₂ + CO₂ → CaCO₃ (кальцит), закрывает трещины. Современный портландцемент не обладает этим свойством. |
| architecture.gothic_structure | Gothic Structural System | INVARIANT | Стрельчатая арка (распор меньше полуциркульной), нервюрный свод (рёбра → точечная нагрузка на столбы), аркбутаны (внешние распорки передают горизонтальный распор на контрфорсы). Вертикальность, каменное кружево, максимум стекла. | Бове: обрушение хора 1284 г. (амбиции превысили допустимые напряжения) — предел возможностей каменной конструкции. |
| architecture.renaissance_palladio | Palladio — Four Books of Architecture (1570) | RECORD | Виллы Венето: симметрия, храмовый фронтон на жилом доме (Вилла Ротонда — купольный центр, 4 идентичных портика). Пропорции: математическая гармония (музыкальные интервалы — 3:4, 4:9, 9:16 для размеров комнат). | Огромное влияние на англо-американскую архитектуру (палладианство: Иниго Джонс, Томас Джефферсон — Монтичелло, Капитолий в Ричмонде). |
| architecture.modern_movement | Modern Movement — Bauhaus & Le Corbusier | RECORD | «Форма следует функции» (Салливен). Ле Корбюзье (5 принципов новой архитектуры, 1927): столбы-пилотис (дом над землёй), плоская крыша-сад, свободный план (нет несущих стен — каркас), ленточные окна, свободный фасад. Бетон, стекло, сталь. | Ville Savoye (1929) — манифест. Марсельская жилая единица (Unité d'Habitation, 1952) — брутализм (béton brut, необработанный бетон). Критика: безличность, стерильность. |
| architecture.sustainable_design | Sustainable Architecture Principles | METHOD | Пассивный дом (Passivhaus): сверхизоляция, тройные окна, рекуперация тепла (вентиляция с теплообменником >80%), герметичность, ≤15 кВт·ч/м²·год на отопление. Активный: солнечные панели (BIPV — интегрированные в фасад/крышу), геотермальные тепловые насосы, сбор дождевой воды, зелёная крыша. | LEED, BREEAM — рейтинговые системы сертификации. Биофильный дизайн (связь с природой — дневной свет, растения, натуральные материалы). |
