| labsafety.ops.ghs_hazard_pictograms | GHS — Hazard Pictograms | METHOD | Глобально гармонизированная система (GHS): 9 пиктограмм. Взрывчатый (бомба). Воспламеняющийся (пламя). Окисляющий (пламя над кругом). Газ под давлением (цилиндр). Коррозионный (руки с кислотой). Острая токсичность (череп). Опасность для здоровья (восклицательный). Хроническая опасность (здоровье экс. мере). Экологическая (дерево+рыба). | SDS Section 2: классификация GHS опасностей. |
| labsafety.ops.sds_key_sections | SDS — Key Sections | METHOD | Паспорт безопасности (SDS, Safety Data Sheet): 16 разделов. Section 1: идентификация. Section 2: опасности GHS. Section 3: состав. Section 4: первая помощь. Section 5: пожаротушение. Section 6: при утечке. Section 7: хранение/транспортировка. Section 8: средства защиты + exposure limits. Section 9: физические/химические свойства. | PEL (Permissible Exposure Limit) vs TLV (Threshold Limit Value): OSHA vs ACGIH. |
| labsafety.ops.chemical_segregation | Chemical Segregation — Storage | METHOD | Сегрегация химических веществ при хранении: НЕ хранить вместе: кислоты + основания, окислители + горючие, несовместимые химикаты. Примеры несовместимостей: HNO3 + органика (взрыв), KMnO4 + глицерин (пожар), NaOH + Al (водород). Кислоты под локером, основания отдельно. Хранить в надлежащих контейнерах. | Неправильное хранение химикатов: причина 30%+ лабораторных инцидентов. |
| labsafety.ops.ppe_selection | PPE Selection — Hierarchy | METHOD | Средства защиты (СИЗ/PPE): Иерархия контроля: Elimination → Substitution → Engineering Controls → Administrative → PPE (последнее!). Перчатки: нитрил (общий), хлоропрен (органические растворители), бутил (газы), ламинат (широкий спектр). Не использовать латекс (аллергия). Eye protection: очки, щиток. | Проверка перчаток: воздушный тест или пузырьковый тест ежесменно. |
| labsafety.ops.acid_spill | Chemical Spill Response — Acid | METHOD | Ликвидация разлива кислоты: Эвакуировать, уведомить. PPE (перчатки, очки, фартук, дыхательная защита). Нейтрализовать: натрий бикарбонат (NaHCO3). Не использовать воду для концентрированных кислот (тепловыделение). Собрать сорбентом. Утилизировать как химические отходы. Кислота на коже: промыть водой 15 минут немедленно. | Mercury spill: немедленно call environmental health; NO вакуум (пары Hg опасны). |
| labsafety.ops.eyewash_shower | Eyewash & Emergency Shower | METHOD | Промывные устройства: Emergency eyewash: в пределах 10 сек ходьбы (ANSI Z358.1). Промывать 15-20 мин непрерывно. Температура: 16-38°C. Еженедельная проверка (прохождение воды). Safety shower: 150 л/мин при 30 psi. Никогда не надевать одежду обратно после химикатов. | «Panic removal» одежды при разливе: Gears strip — может занять 20-30 сек — каждая секунда важна. |
| labsafety.ops.fire_extinguisher_classes | Fire Extinguisher — Classes | METHOD | Типы огнетушителей: Class A: обычные горючие (дерево, бумага) — вода, ABC dry chem. Class B: горючие жидкости (бензин) — CO2, ABC, BC. Class C: электрические — CO2, ABC (нет воды). Class D: металлы (Na, Mg) — специальный порошок. Class K: кухня (масла) — wet chemical. Мнемоника: PASS — Pull, Aim, Squeeze, Sweep. | ABC: универсальный для большинства помещений. НЕ воду на электрических. |
| labsafety.ops.biosafety_cabinet | Biosafety Cabinet — Types | METHOD | Боксы биологической безопасности: Class I BSC: защита только персонала (воздух в помещение). Class II (подтипы): Type A1/A2: 70% re-circulation, 30% exhaust. Type B1/B2: полная вытяжка (для химикатов + биологии). Class III: полностью закрытый (для BSL-4). Работать в центре BSC. Не хранить материалы под решёткой. | BSC ≠ chemical fume hood: BSC = биологическая защита. Fume hood = химическая. |
| labsafety.ops.cryogenic_liquid | Cryogenic Liquids — Safety | METHOD | Криогенные жидкости: LN2 (-196°C), LHe (-269°C). Опасности: холодные ожоги (криоожоги), расширение объёма (LN2 → 700×), удушье в закрытом пространстве (O2 displacement). PPE: криогенные перчатки, защитные очки, лабораторный халат. Никогда не закрывать крышкой LN2 дьюар. | LN2 explosion: closed container + warming = catastrophic rupture. |
| labsafety.ops.laser_safety | Laser Safety — Classes | METHOD | Безопасность лазеров: Class 1: безопасный. Class 2: видимый (<1 мВт), мигательный рефлекс защищает. Class 3R: 1-5 мВт, осторожно. Class 3B: 5-500 мВт, опасен для глаз. Class 4: >500 мВт, пожар + кожа. Laser Safety Officer (LSO). OD (Optical Density) очков: выбирать по длине волны + мощности. | Стекло/контакт не защищает от лазера. Специальные OD-сертифицированные очки. |
| labsafety.ops.compressed_gas_lab | Compressed Gas — Cylinder Safety | METHOD | Газовые баллоны в лаборатории: Всегда закреплять (цепь к стене/стойке). Колпак на вентиль при транспортировке. Газовый детектор для toxic/flammable. Двухступенчатый регулятор давления. Промаркировать: пустой/полный (синяя/красная метка). Никогда не укладывать горизонтально без фиксатора. | O2 + жирная смазка = пожар (никаких масел на кислородных фитингах). |
| labsafety.ops.laboratory_exposure_limits | Exposure Limits — TLV/PEL | METHOD | Пределы воздействия химикатов: TLV-TWA (ACGIH): 8-часовая средневзвешенная. TLV-STEL: 15-минутная краткосрочная (не более 4 раз в день). TLV-C: моментальная (ни при каком обстоятельстве). OSHA PEL: юридически обязательный. NIOSH REL: рекомендуемый. IDLH: немедленная опасность для жизни. | Приоритет: IDLH > NIOSH REL > OSHA PEL > ACGIH TLV (от более строгого). |
| labsafety.ops.radiation_dosimetry_lab | Radiation Dosimetry — Lab | METHOD | Дозиметрия в лаборатории: TLD (Thermoluminescent Dosimeter): квартальный. OSL (Optically Stimulated Luminescence): более точный. Film badge: устарел. Wrist badge: для работы рядом с источником. Extremity badge: при ручном обращении. RM-сигнализатор: при непосредственной работе. Дозы доводить до ALARA. | Annual dose limits: occupational 50 mSv/year (whole body). |
| labsafety.ops.nanoparticle_exposure | Nanoparticles — Exposure Control | METHOD | Наночастицы: повышенная токсичность за счёт высокой поверхностной площади. Inhalation: наибольший путь. Контроль воздействия: BSC (для биол. нано) или fume hood + N100 respirator. Мониторинг: частично счётчик (CPC). NIOSH Current Intelligence Bulletin: руководство по нано. REACH: регуляция в ЕС. | Нано-TiO2 и нано-SiO2: предположительные канцерогены группы 2B (IARC). |
| labsafety.ops.ergonomics_pipetting | Lab Ergonomics — Pipetting | METHOD | Эргономика в лаборатории: Повторяющиеся движения (многочасовое пипетирование) → RSI (Repetitive Strain Injury). Пипетки с облегчённым trigger. Многоканальные пипетки. Автоматические системы. Micro-breaks каждые 20-30 мин. Рабочая высота: локоть 90°. Seating: регулируемый стул. | RSI профилактика: 20% снижения усилия = значительная снижение риска. |
| labsafety.ops.chemical_waste_disposal | Chemical Waste — Segregation & Disposal | METHOD | Утилизация химических отходов: По EPA RCRA: характеристические отходы (F, K, P, U lists). Маркировка: Chemical Waste (тип + концентрация + дата). Контейнер: совместимый. Halogenated органика отдельно от Non-halogenated. Aqueous waste: pH 2-12 может идти в канализацию (местные нормы). Heavy metals: строгая утилизация. | Нельзя «разбавлять» чтобы снизить концентрацию (dilution is not disposal). |
| labsafety.ops.chemical_hygiene_plan | Chemical Hygiene Plan — OSHA | METHOD | Лабораторный стандарт OSHA (29 CFR 1910.1450): Chemical Hygiene Plan (CHP) = обязателен. Компоненты: SOPs, criteria for use of protective equipment, CHO (Chemical Hygiene Officer), employee training, exposure monitoring. PI ответственность. Annual review. | CHP: документирует ответственность + процедуры для каждого типа химикатов. |
