| copyshop.ops.digital_press_production | Digital Press — Production Workflow | PROCESS | Работа в цифровой типографии (копицентр). Приём заказа: клиент приносит файл (USB, email, cloud link) или оригинал (hardcopy для копирования). Preflight: проверка файла (разрешение >300 dpi, fonts embedded, bleed 3 мм, размер документа). Если проблемы — звонок клиенту (не печатать вслепую!). Print: Xerox/Konica Minolta/Canon production press (цветная лазерная). Параметры: paper type (plain, coated, cardstock), weight (gsm — до 300-350 г/м² для цифры), duplex (двусторонняя), collated (скомплектована), stapling. Queue management: FIFO + экспресс (rush fee +30-50%). Тираж: от 1 экз (цифра — это short run). Finishing: trimming (гильотина — stack cutter, точность ±0.5 мм), creasing/scoring (биговка для плотной обложки чтобы не треснул сгиб), folding (буклеты), stapling/saddle-stitching (скрепка на скобу для брошюр), spiral binding (пластиковая/металлическая пружина), lamination (горячая/холодная плёнка). Упаковка: box или paper wrap. | Файлы клиента: JPEG вместо PDF, RGB вместо CMYK (цвета другие при печати!), no bleed (белые полосы после обрезки). Prepress knowledge: перевести RGB в CMYK, добавить bleed. |
| copyshop.ops.large_format_printing | Large Format — Poster & Banner Printing | METHOD | Широкоформатная печать (LFP — Large Format Printing). Технологии: Aqueous (водные чернила — для indoor, яркие, точная цветопередача), Solvent (сольвентные — outdoor, водостойкие), Eco-Solvent (менее токсичные, для indoor/outdoor), UV-curable (отверждаемые УФ — печать на любых материалах: пластик, дерево, стекло, metal), Dye Sublimation (сублимация на ткань/полиэстер). Материалы (substrates): Paper (фотобумага, матовая/глянцевая 120-260 г/м²), Vinyl (виниловая плёнка — самоклеющаяся, для наружной рекламы), Banner (баннерная ткань — PVC или ткань), Canvas (холст — для картин), Backlit film (для лайтбоксов). Размеры: рулоны 24", 36", 44", 60". RIP software (Raster Image Processor): интерпретирует файл, управляет цветом (ICC profile для конкретного материала). Finishing: eyelet/люверсы (металлические кольца для креплений), hemming (подгибка и сварка краёв баннера), mounting (наклейка на пенокартон/аллюминиевый композитный лист). | Разрешение для билборда — не 300 dpi! Просмотр с 20-30 м — 30-50 dpi достаточно. Размер файла для billboard 12×3 м в 300 dpi был бы гигабайтным. |
| copyshop.ops.binding_types_selection | Document Binding — Types & Selection | METHOD | Переплёт документов. Comb Binding (пластиковая гребёнка): отверстия (punch) по краю, flexible, можно добавлять/убирать страницы. Для отчётов, proposals. Coil/Spiral (металлическая или пластиковая пружина): отверстия круглые, coil вкручивается через отверстия (manual или electric coil inserter), затем crimped (загибание концов). Для календарей, ноутбуков. Wire-O (двойная металлическая петля): премиальная, прочная, страница кладётся на 360°, дороже. Для презентаций премиум-класса. Perfect Binding (термоклеевое): стопка листов, корешок фрезеруется и покрывается PU/PVA клеем, затем обложка обклеивает корешок. Для книг, толстых каталогов (30+ страниц минимум). Saddle Stitching (скрепка на скобу): 2 staples на корешке, booklet до 60-80 страниц. Velo Binding (VeloBind): пластиковые полоски спереди и сзади, pins. Термически запрессовывается — secure, но не открыть без разрезания. Proposals (юридические, финансовые). Выбор: толщина документа + желаемый look. Punching: электрический punch для high volume. | Coil загиб: специальные клещи, конец coil обрезается и загибается to prevent cut/uncoiling. Perfect binding: важно roughening (фрезерование корешка), клей проникает в бороздки — strong bond. |
| copyshop.ops.scanning_ocr_conversion | Scanning — High-Speed Document Conversion | METHOD | Потоковое сканирование документов в PDF. Сканер: Fujitsu, Canon DR-series (sheet-fed duplex scanner, 30-100 стр/мин). Подготовка: удалить скрепки/скобы (staple removal), разгладить согнутые страницы. Настройки: colour/B&W (300 dpi для текста, 600 dpi для фото/карт), format (PDF/A для архива, Searchable PDF с OCR слоем). OCR (Optical Character Recognition): ABBYY FineReader, Adobe Acrobat. Язык: указать (распознавание русского, английского), quality >95%. File naming: batch renaming по порядку или по штрих-коду разделителя страниц (separator sheet с barcode сканируется, создаёт новый файл). Compression: PDF создаётся с сжатием QC (quality), размер файла в мегабайтах. Cloud upload: Google Drive, Dropbox, email. Large volume (коробка документов 5000 стр): разбить на batches, проверять качество каждые 1000 стр. Стоимость: per page (10-50 цент/стр). | Barcode separator: лист с напечатанным штрих-кодом между разными документами — сканер распознаёт barcode и создаёт отдельный PDF для каждого раздела. Outsource scanning: для sensitive документов — соглашение о конфиденциальности. |
