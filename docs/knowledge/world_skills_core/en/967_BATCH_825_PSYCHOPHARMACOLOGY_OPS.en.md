# BATCH 825: Psychiatry — Psychopharmacology

| psychopharm.ops.snri_mechanism | SNRIs — Mechanism & Use | METHOD | Ингибиторы обратного захвата серотонина и норадреналина (SNRI): дулоксетин, венлафаксин, десвенлафаксин. Ингибируют SERT + NET → ↑5-HT + ↑NE. Дулоксетин: также GABAергические свойства → нейропатическая боль + диабетическая нейропатия + фибромиалгия. Венлафаксин: при GAD + MDD. Побочные: гипертензия (при высоких дозах венлафаксина). | SNRI в сравнении с SSRI: чаще используются при болевых синдромах + тревоге. |
| psychopharm.ops.atypical_antipsychotic_metabolic | Atypical Antipsychotics — Metabolic Side Effects | METHOD | Атипичные антипсихотики (метаболические): Клозапин + оланзапин: наибольший риск. Мониторинг: вес + глюкоза + липиды при каждом визите. Метаболический синдром: до 40% пациентов. Ziprasidone, арипипразол, луразидон: метаболически нейтральные. CATIE trial: оланзапин = наиболее эффективный но наибольший метаболический риск. | Рекомендации ADA/APA: метаболический мониторинг каждые 3-12 мес. |
| psychopharm.ops.clozapine_monitoring | Clozapine — Monitoring Protocol | METHOD | Клозапин: резервный препарат при рефрактерной шизофрении. Агранулоцитоз (1-2%): еженедельный CBC первые 6 мес, затем каждые 2 нед. Мониторинг уровня: 250-350 нг/мл (терапевтический). Другие побочные: сиалорея (стимулирует М4), судороги (дозовые), миокардит (первые недели), кишечная непроходимость. | Абсолютный нейтрофильный счёт (ANC): <1500 = стоп. <500 = угрожает жизни. |
| psychopharm.ops.valproate_uses | Valproate — Clinical Uses | METHOD | Вальпроевая кислота: биполярное расстройство (мания/профилактика), эпилепсия (несколько типов). Терапевтический уровень: 50-100 мкг/мл. Мониторинг: LFT + CBC (панцитопения). Противопоказания: беременность (тератоген — нейральная трубка, когнитивные нарушения). Гиперпаратиреоидизм (редко). Тромбоцитопения: дозозависимая. | Вальпроат + карбапенемы: значительно снижает уровень вальпроата (взаимодействие). |
| psychopharm.ops.benzodiazepines_taper | Benzodiazepine — Tapering | METHOD | Отмена бензодиазепинов: медленное постепенное снижение (не резкое). Рекомендованный темп: 5-10% снижение каждые 2-4 нед. Конверсия на долгодействующий (диазепам): более удобный тейпер. Синдром отмены: тревога, бессонница, тремор, потливость, судороги (тяжёлый). | Ashton Manual: широко используемый протокол отмены. |
| psychopharm.ops.lithium_interactions | Lithium — Drug Interactions | METHOD | Лекарственные взаимодействия лития: ↑ уровень лития: НПВП (снижают почечный клиренс), тиазидные диуретики (↑ реабсорбция), ингибиторы АПФ. ↓ уровень: теофиллин, кофеин в большом количестве. Противопоказание: тяжёлые почечные. Thyreotoxicosis: может маскировать при длительном использовании. | Дегидратация при Li: риск интоксикации (инфекция + рвота + диарея). Предупредить пациента. |
| psychopharm.ops.augmentation_strategies | Antidepressant Augmentation | METHOD | Аугментация антидепрессантов при частичном ответе: Литий: Gold standard + 20-30% ответ. Атипичные антипсихотики: арипипразол, кветиапин, оланзапин (FDA approved add-on). Буспирон: анксиолитический агент. Трийодтиронин (Т3): 25-50 мкг. Психостимуляторы: с осторожностью. Комбинация антидепрессантов. | Мелатонин + агомелатин: для биологического ритма (нетипичные антидепрессанты). |
| psychopharm.ops.stimulants_adhd | Stimulants — ADHD Pharmacology | METHOD | Стимуляторы при ADHD: Метилфенидат (Риталин, Концерта): ингибирует DAT + NET. Амфетамины (Adderall, Vyvanse): дополнительно высвобождают DA + NE. Prodrug: лисдексамфетамин (Vyvanse) = более постепенный эффект, меньше злоупотребление. Мониторинг: АД + ЧСС. Аппетит/рост у детей. | Atomoxetine (Strattera): не стимулятор, SNRI — NET ингибитор → второй выбор при ADHD. |
| psychopharm.ops.mao_inhibitor_diet | MAOIs — Tyramine Reaction | METHOD | MAO-ингибиторы: фенелзин, транилципромин, изокарбоксазид, селегилин (ТТС). Ингибируют MAO → нет расщепления тирамина из пищи. Тираминовая реакция: острый гипертонический криз. Продукты-триггеры: выдержанный сыр, красное вино, ферментированные продукты, сырое мясо. Нельзя: SSRI + MAOI (серотониновый синдром). | MAOI + пропанол: риск. MAOI + симпатомиметики: тяжёлая гипертония. |
| psychopharm.ops.naltrexone_alcohol | Naltrexone — Alcohol Use Disorder | METHOD | Налтрексон: опиоидный антагонист → блокирует эйфорию от алкоголя. Дозировка: 50 мг/день PO или 380 мг IM ежемесячно (Vivitrol). Снижает craving и рецидив. Акампросат: снижает абстинентный дистресс (NMDA модулятор). Disulfiram: вызывает неприятную реакцию при алкоголе (ацетальдегид). | Налтрексон противопоказан при: активной опиоидной терапии, гепатите/циррозе (осторожно). |
| psychopharm.ops.antipsychotic_switching | Antipsychotic Switching — Strategies | METHOD | Переключение антипсихотиков: Abrupt switch: при непереносимости. Cross-titration: постепенно снижать старый + повышать новый (безопаснее, minimizes withdrawal rebound). Overlap then taper. Причины: неэффективность, побочные. Рикошетный эффект: холинергический (тошнота) при резкой отмене. | Обрыв клозапина: психоз рикошета в течение 48-72 ч → нельзя резко. |
| psychopharm.ops.quetiapine_sedation | Quetiapine — Low Dose Use | METHOD | Кветиапин в низких дозах: широко используется OFF-LABEL как снотворное (25-50 мг). Антигистаминный эффект. FDA не одобрен как снотворное. Риски: метаболический + EPS. Спорный: альтернативы? — безопасная дозировка? Реальность: часто назначается в психиатрии как sedating agent. | «Seroquel snorkel»: практический сленг для низкодозового кветиапина для сна. |
| psychopharm.ops.plasma_drug_monitoring_psych | Plasma Monitoring — Psychiatric Drugs | METHOD | Мониторинг плазменного уровня психотропных: Литий: 0.6-1.2 мэкв/л (профилактика), 0.8-1.2 (мания). Вальпроат: 50-100 мкг/мл. Карбамазепин: 4-12 мкг/мл. Клозапин: 250-350 нг/мл. Нортриптилин: 50-150 нг/мл. Взять через 12 ч после последней дозы. | Клозапин: при плохом ответе → проверить уровень. Уровень >350-450 → токсичность. |
| psychopharm.ops.tardive_dyskinesia_prevention | Tardive Dyskinesia — Management | METHOD | Поздняя дискинезия: непроизвольные движения (рот, язык, лицо, конечности) после длительного приёма антипсихотиков. AIMS (Abnormal Involuntary Movement Scale): мониторинг. Лечение: снизить или отменить антипсихотик. VMAT2 ингибиторы: valbenazine (Ingrezza), deutetrabenazine (Austedo) — FDA approved. | Клозапин: меньший риск TD (нет D2 высокой аффинности). |
| psychopharm.ops.tricyclic_overdose | TCA Overdose — Emergency | METHOD | Трициклические антидепрессанты (ТЦА): при передозировке — угрожающие жизни. Антихолинергические: ажитация, гипертермия. ЭКГ: расширение QRS >100 мс = риск судорог. QTc удлинение → ТdP. Лечение: NaHCO3 IV (снижает связывание с каналами). Не использовать: флумазенил, физостигмин. | QRS >160 мс: очень высокий риск желудочковой аритмии + судороги. |
| psychopharm.ops.ketamine_treatment | Ketamine — Treatment-Resistant Depression | METHOD | Кетамин для лечения резистентной депрессии: NMDA antagonist → glutamate hypothesis. Эффект: быстрый (через 24-48 ч). IV инфузия 0.5 мг/кг × 40 мин. Эскетамин (Spravato): интраназальный (FDA 2019). Диссоциативные побочные. Мониторинг: АД, диссоциация. Поддерживающая терапия: ограниченная. | Кетамин для суицидальных мыслей: быстрый ответ = Emergency use context. |
