# BATCH 647: Arborist — Tree Care Operations

**KnowledgeUnits:** 50
**Namespace:** `arborist.ops.*`
**Scope:** pruning, removal, cabling, planting, diagnosis, climbing, stump_grinding, safety

| ID | KnowledgeUnit | Тип | Суть | Практический смысл |
|---|---|---|---|---|
| arborist.ops.crown_reduction_cut | Crown Reduction — Proper Cuts | METHOD | Снижение кроны (НЕ topping!). Cut to lateral: срезать ветвь на боковую (lateral branch) минимум 1/3 диаметра срезаемой. Угол: lateral идёт в нужном направлении. Цель: снизить высоту/ширину сохраняя natural form. Максимальное удаление: 25% живой кроны за сезон. ANSI A300 стандарт. Место среза: за branch collar (не заподлицо!). Техника трёх надпилов (для толстых ветвей): undercut → top cut → final cut. | Topping = варварство: massive sprouts, weak attachments, decay. |
| arborist.ops.rigging_block_setup | Rigging — Block & Pulley | METHOD | Такелаж для контролируемого спуска ветвей. Block (шкив) крепится выше срезаемой ветви (strop/ремень вокруг ствола). Rope (bull rope, 1.5-2 см) проходит через block к ground crew. Portawrap (фрикционное устройство на стволе) для контроля натяжения. Техника: climber срезает ветвь, ground crew плавно спускает. Let it run (не жёсткая остановка — shock loading). Вес: рассчитывать SWL (Safe Working Load, обычно 10:1 safety factor). Коммуникация: радио. | Никогда не стой под suspended load! |
| arborist.ops.disease_diagnosis_field | Tree Disease — Field Diagnosis | METHOD | Диагностика болезней на месте. Признаки: leaf spot, chlorosis, canker, fungal conk (на стволе — признак внутренней гнили), dieback, oozing. Armillaria (корневая гниль, honey fungus — опята у основания), Hypoxylon canker (на дубе при стрессе), Emerald Ash Borer (D-shaped exit holes на ясене). Почва: pH, compaction, drainage. Root zone: girdling roots (обвивающие корни). Resistance drilling (резистограф): измерение плотности древесины (скрытая гниль). | Лечение: не всегда возможно. Часто — management (удаление опасных частей). |
