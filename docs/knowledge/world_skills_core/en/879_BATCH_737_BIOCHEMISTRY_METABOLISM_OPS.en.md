| biochemistry.ops.glycolysis_steps | Glycolysis — 10 Steps & ATP Yield | METHOD | Гликолиз (10 шагов): Инвестиционная фаза (1-5): потратить 2 АТФ. Выходная фаза (6-10): 4 АТФ + 2 НАДН. Чистый выход: 2 АТФ + 2 НАДН + 2 пируват. Ключевые регуляторные ферменты: гексокиназа, ФФК-1, пируваткиназа. Аллостерика: ATP ингибирует ФФК-1, AMP активирует. Фруктозо-2,6-бисфосфат: активирует ФФК-1. | Оборот гликолиза RBC: ~2×10⁶ молекул АТФ/сек (единственный путь энергии без митохондрий). |
| biochemistry.ops.tca_cycle_cofactors | TCA Cycle — NADH Yield | METHOD | Цикл трикарбоновых кислот (ЦТК): один оборот (на ацетил-КоА). Выход: 3 НАДН + 1 ФАДН2 + 1 ГТФ + 2 CO2. Регуляторные ферменты: изоцитратдегидрогеназа (АТФ ингибирует, ADP активирует), α-кетоглутарат-дегидрогеназа. Субстраты из аминокислот и жиров → ацетил-КоА. Анаплеротические реакции (восполнение промежуточных). | ЦТК не требует O2 непосредственно — только доступность NAD+ (из окислительного фосфорилирования). |
| biochemistry.ops.oxidative_phosphorylation | ETC — Proton Gradient | METHOD | Окислительное фосфорилирование: Электрон-транспортная цепь (ЭТЦ): Комплекс I (НАДН→Q), II (ФАДН2→Q), III (Q→цит. c), IV (цит.c→O2). Протонный градиент: 10 H+ выкачивается на один оборот (4+4+2). АТФ-синтаза: 3 H+ на 1 АТФ. Теоретический выход: 30-32 АТФ/глюкоза. P/O ratio: НАДН = ~2.5, ФАДН2 = ~1.5. | Цианид: ингибирует Комплекс IV (блокирует O2 reduction → NO ATP). |
| biochemistry.ops.fatty_acid_oxidation | β-Oxidation — Per Cycle | METHOD | β-окисление жирных кислот: один цикл из 16С пальмитата. Каждый цикл: 1 ФАДН2 + 1 НАДН + 1 ацетил-КоА. Число циклов: (n/2 - 1) для насыщенной. Карнитинтранслоказа: переносит жирные кислоты в митохондрии. Мевалонатный путь: синтез холестерина. Чистый выход из пальмитата (C16): 129 АТФ (gross) - 2 АТФ activation. | Малонил-КоА: ингибирует карнитинтранслоказу → нельзя окислять синтезируемые жиры. |
| biochemistry.ops.purine_pyrimidine_synthesis | Nucleotide Synthesis — De Novo | METHOD | Синтез нуклеотидов de novo: Пуриновый (de novo): начинается с рибозо-5-фосфата → IMP → AMP/GMP. Начало = PRPP. Пиримидиновый (de novo): синтез кольца → + PRPP. Salvage pathway: экономичный (гипоксантин → IMP, аденин → AMP). HGPRT (hypoxanthine-guanine phosphoribosyltransferase): дефицит → Syndrome Lesch-Nyhan. | Метотрексат: ингибирует ДГФР → снижает тетрагидрофолат → блокирует пуриновый синтез. |
| biochemistry.ops.enzyme_michaelis_menten | Enzyme Kinetics — Michaelis-Menten | METHOD | Уравнение Михаэлиса-Ментен: v = Vmax × [S] / (Km + [S]). Km = концентрация субстрата при Vmax/2. Низкий Km = высокая аффинность. Lineweavever-Burk: 1/v vs 1/[S] (линейная трансформация). Конкурентное ингибирование: Km растёт, Vmax без изменений. Неконкурентное: Vmax снижается, Km без изменений. Бесконкурентное: оба снижаются. | kcat/Km = catalytic efficiency (нижний предел: диффузионный). |
| biochemistry.ops.protein_synthesis_translation | Translation — Ribosome Cycle | METHOD | Трансляция (синтез белка): Рибосома (70S: 50S + 30S прокариоты, 80S эукариоты). Сайты: A (аминоацил-тРНК), P (пептидил), E (exit). Шаги: инициация → элонгация (aminoacyl-tRNA + peptide bond + translocation) → терминация (stop codon + release factor). Polysome: несколько рибосом на мРНК. | Сигнальный пептид: N-terminal → ER lumen (ER-targeting). |
| biochemistry.ops.allosteric_regulation | Allosteric Enzymes — K vs V System | METHOD | Аллостерическая регуляция: K system: аллостерический эффектор изменяет Km (не Vmax). V system: изменяет Vmax (не Km). Cooperative enzymes (Hill equation): n > 1 (cooperativity). Sigmoidальная v/[S] кривая. ATCase (aspartate transcarbamoylase): модельный аллостерический фермент. Feedback inhibition: конечный продукт ингибирует первый фермент пути. | Concerted (MWC) model vs Sequential (KNF) model: два объяснения кооперативности. |
| biochemistry.ops.citric_acid_substrate_flux | Metabolic Flux — Substrate Channeling | METHOD | Поток через метаболические пути: Channeling: промежуточные продукты не выходят в раствор (сразу к следующему ферменту). Metabolons: комплексы ферментов. Pyruvate dehydrogenase complex (PDC): модельный пример. Измерение: ¹³C metabolic flux analysis (¹³C-MFA). Control coefficient: FCC = dlog(J)/dlog(Ei). | Metabolomics: NMR + MS → идентификация и количество малых молекул. |
| biochemistry.ops.reactive_oxygen_species | ROS — Antioxidant Defense | METHOD | Активные формы кислорода (ROS): O2⁻• (superoxide), H2O2 (перекись водорода), •OH (гидроксильный). Источники: Комплекс I и III, НАДФН-оксидаза, ксантиноксидаза. Защита: SOD (O2⁻• → H2O2), Каталаза (H2O2 → H2O + O2), Глутатионпероксидаза. Глутатион (GSH): тиол-антиоксидант. G6PD: поддерживает GSH (НАДФН). | G6PD-дефицит: гемолитическая анемия при окислительном стрессе (primaquine, fava beans). |
| biochemistry.ops.cholesterol_regulation | Cholesterol — HMGCR Regulation | METHOD | Регуляция холестерина: ГМГ-КоА-редуктаза (HMGCR): ключевой фермент синтеза. Регуляция: инсулин активирует, глюкагон ингибирует. Статины: конкурентные ингибиторы HMGCR. SРЕБР (Sterol Regulatory Element Binding Protein): транскрипция при снижении холестерина. LDL рецептор: эндоцитоз LDL (мутация → семейная гиперхолестеринемия). | PCSK9: деградирует LDL рецепторы → ингибиторы PCSK9 снижают LDL. |
| biochemistry.ops.dna_repair_mechanisms | DNA Repair — Base Excision | METHOD | Репарация ДНК: Base Excision Repair (BER): базис-специфическая гликозилаза удаляет изменённое основание → AP endonuclease → полимераза + лигаза. Nucleotide Excision Repair (NER): ксеродермапигментоза (XP) гены. Double-strand break (DSB): NHEJ (быстро, error-prone) vs HR (медленно, высокоточный, требует сестринскую хроматиду). Mismatch repair: MLH1/MSH2 (Lynch syndrome). | BRCA1/2: участие в HR repair (дефицит → геномная нестабильность). |
| biochemistry.ops.krebs_anaplerosis | Anaplerosis — TCA Intermediates | METHOD | Анаплероз: пополнение промежуточных продуктов ЦТК. Пируват + CO2 → Оксалоацетат (пируваткарбоксилаза): когда оксалоацетат истощается. Аспартат, глутамат → α-кетоглутарат, сукцинат (аминокислоты). Пропионил-КоА → метилмалонил-КоА → сукцинил-КоА (из odd-chain FA). Сукцинил-КоА: гем синтез. | Без анаплероза: ЦТК останавливается (не хватает OAA). |
| biochemistry.ops.cori_and_glucose_alanine | Cori Cycle — Glucose-Lactate | METHOD | Цикл Кори: лактат из мышц → глюкоза в печени. Мышцы: глюкоза → пируват → лактат (при анаэробном). Кровь: лактат → печень. Печень: лактат → пируват → глюкоза (глюконеогенез). Стоимость: 6 АТФ в печени на возобновление 2 АТФ в мышцах → net 4 АТФ «долг». Глюкозо-аланиновый цикл: аналогичный с аланином (из аминокислот). | Лактатный ацидоз: при недостаточной оксигенации или бигуанидах (метформин inhibition). |
