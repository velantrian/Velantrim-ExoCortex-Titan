| finplan.ops.inflation_real_return | Inflation — Real Return Calculation | METHOD | Реальная доходность: Real Return ≈ Nominal Return - Inflation. I-Bonds: переменная ставка (CPI + фиксированная). Rule of 72: 72 / annual rate = лет для удвоения. | Inflation = «тихий вор» savings в low-yield accounts. $100K при 3% инфляции → $74K покупательной способности через 10 лет. |
