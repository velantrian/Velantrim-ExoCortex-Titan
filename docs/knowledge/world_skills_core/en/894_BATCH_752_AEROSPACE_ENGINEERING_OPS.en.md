| aerospace.ops.lift_drag_polar | Lift & Drag — Polar Curve | METHOD | Поляра (Polar Curve): зависимость CL от CD. Lift equation: L = ½ρV²SCL. Drag: D = ½ρV²SCD. Induced drag: CDi = CL²/(πeAR) (Oswald factor e, Aspect Ratio AR). Profile drag: форма + трение. Total: CD = CD0 + CDi. Maximum L/D (L/Dmax): оптимальный угол атаки. | L/Dmax: экономичность (крейсерский режим). Транспортные самолёты: L/D = 15-20. |
| aerospace.ops.turbofan_efficiency | Turbofan — Bypass Ratio | METHOD | Турбовентиляторный двигатель: Bypass Ratio (BPR) = fan flow / core flow. Высокий BPR (8-15): экономичный, тихий (CFM56, LEAP, GEnx). Низкий BPR (0.3-1.0): для fighter jets. Thrust: 80% от fan (high BPR). Thermal efficiency ηth = thrust power / fuel power. SFC (Specific Fuel Consumption) г/Нс = thrust efficiency. | LEAP: BPR 9-11 → 15% экономия топлива vs CFM56. |
| aerospace.ops.structural_fail_safe | Structural — Fail-Safe Design | METHOD | Безотказная конструкция (Fail-Safe): при разрушении одного структурного элемента конструкция остаётся нагруженной без катастрофических последствий. Safe Life: определённый ресурс без инспекций. Damage Tolerant: рост трещины медленный, обнаруживается при инспекциях (damage tolerance/fracture mechanics). FAA требует Damage Tolerant для primary structures с 1978. | DT analysis: fracture mechanics (ΔK vs da/dN Paris Law). |
| aerospace.ops.fly_by_wire_control | Fly-by-Wire — Architecture | METHOD | Электродистанционное управление (FBW): пилот → electrical signal → Flight Control Computer → actuators. Резервирование: трёхкратное (triplex) или четырёхкратное (quad). Envelope protection: тяга/скорость не выйдет за ограничения. Normal law / Alternate law / Direct law. Full Authority Digital Engine Control (FADEC): аналогично для двигателя. | A320 FBW (1987): первый коммерческий самолёт с FBW. |
| aerospace.ops.do178c_safety | DO-178C — Software Levels | METHOD | DO-178C (авиационный стандарт ПО): Software Level = Design Assurance Level (DAL). DAL A: катастрофический отказ. B: опасный. C: значительный. D: незначительный. E: нет эффекта. Требования к верификации: DAL A = 100% structural coverage (MC/DC). Формальные методы (DO-333 Supplement). | MC/DC (Modified Condition/Decision Coverage): обязателен для DAL A. |
| aerospace.ops.landing_gear_retraction | Landing Gear — Retraction System | METHOD | Шасси (Landing Gear): hydraulic actuator: gear retraction/extension. Safety pins: на земле вставляются (предотвращение retraction). Downlock + Uplock: механические замки. Emergency extension: свободный падёж (gravity) или ручной насос гидравлики. Warning system: gear not down and locked при <1000 ft. | Одиночный отказ не должен приводить к непреднамеренному отводу шасси. |
| aerospace.ops.pneumatic_bleed_air | Aircraft Pneumatics — Bleed Air | METHOD | Пневматика воздушного судна: отбор воздуха из компрессора двигателя. Системы: противообледенительная (крыло, двигатель), кондиционирование (высокое давление → регулятор → 75 кПа в кабине). Pressurization schedule: cabin altitude 6000-8000 ft at cruise. More Electric Aircraft (MEA): Boeing 787 = без отбора (электрические compressors). | Отбор воздуха = снижение эффективности двигателя (MEA увеличивает KПД). |
| aerospace.ops.hydraulic_system_aircraft | Aircraft Hydraulics — Triple System | METHOD | Гидравлические системы (типично три независимых): приводятся от двигателей + электрических насосов. Давление: 3000 psi (AC) → перспективный 5000 psi. Гидравлическая жидкость: Skydrol (ТFRO ΙV совместимый). Функции: управление (control surfaces), шасси, тормоза, spoilers, flaps. RAT (Ram Air Turbine): аварийный. | A380: четыре гидравлические системы + электрические backup (2H + 2E). |
| aerospace.ops.aircraft_weight_balance | Weight & Balance — CG Envelope | METHOD | Центровка ВС: OEW (Operating Empty Weight), DOW (Dry Operating Weight), ZFW (Zero Fuel Weight), TOW (Takeoff Weight), LW (Landing Weight). CG envelope: передний предел (стабильность), задний (управляемость). MAC (Mean Aerodynamic Chord) → %MAC. Loading manifest. | ZFW CG = критический: вычислить перед добавлением fuel. |
| aerospace.ops.bird_strike_cert | Bird Strike — AC 25.775 | METHOD | Сертификация птицеудара: FAA AC 25.775 / EASA CS-25.631. Лобовое стекло: птица весом 1.8 кг при скорости VD → без проникновения. Двигатель: 1 большая птица (1.8 кг) или несколько средних → продолжение работы. Bird ingestion test: реальный тест. Windshield replacement: после каждого certification test. | Fan blade Out (FBO) + bird strike: оба независимо должны обеспечить continued flight. |
| aerospace.ops.composite_aerostructures | Composites — CFRP Inspection | METHOD | Контроль углепластиковых конструкций: CFRP (Carbon Fibre Reinforced Polymer). BVD (Barely Visible Damage): ключевой параметр дизайна. Moisture absorption: ухудшение механических свойств. | BVID (Barely Visible Impact Damage): сертифицированный дизайн должен выдержать без структурных нарушений. |
| aerospace.ops.aircraft_icing_certification | Aircraft Icing — Appendix C | METHOD | Обледенение: FAR Part 25 Appendix C: continuous max icing / intermittent max icing. Supercooled Large Droplets (SLD) — Appendix O: с 2014. Anti-ice (hot air): не допускает образования. De-ice: boots (пульсирующие): разрушает уже образовавшийся лёд. Ice shapes: stall degradation testing. | SLD: крупные капли замерзают за trailing edge boots = не защищены. |

| aerospace.ops.avionics_arinc_629 | Avionics Bus — ARINC 629 | METHOD | Шины авионики: ARINC 429: однонаправленный, 100 kbps / 12.5 kbps. ARINC 629: двунаправленный, 2 Мбит/с (B777). CPCP (Corrosion Prevention and Control Program): FAA требование. | PSE (Principal Structural Element): элементы, влияющие на flight safety = Damage Tolerant design. |
| aerospace.ops.cabin_pressurization | Cabin Pressurization — Schedule | METHOD | Наддув кабины: Pressurization schedule: при наборе высоты кабина набирает медленнее самолёта. Negative pressure relief: предотвращение reverse differential. Boeing 787: cabin alt 6000 ft (vs 8000 typical) → меньше усталость пассажиров. | Rapid depressurization: descent emergency to FL100 (<10 000 ft). |
