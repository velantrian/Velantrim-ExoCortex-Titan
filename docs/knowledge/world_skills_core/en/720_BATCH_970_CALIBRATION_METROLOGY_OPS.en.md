# BATCH 578: Calibration — Metrology Laboratory Operations

**KnowledgeUnits:** 44
**Namespace:** `calibration.ops.*`
**Scope:** temperature, pressure, dimensional, electrical, torque, mass, force, frequency, scope, accreditation

| ID | KnowledgeUnit | Тип | Суть | Практический смысл |
|---|---|---|---|---|
| calibration.ops.mass_balance_calibration | Mass — Balance Calibration | METHOD | Калибровка весов. Стандарты: OIML Class E1, E2, F1, F2, M1 (гири). Процедура: 1) Прогреть весы (30+ мин). 2) Eccentricity test: гиря в центр, затем на 4 угла весовой чаши (отклонение <допуск). 3) Repeatability: 5-10 измерений одной гири, стандартное отклонение (σ <0.5d). 4) Linearity: гири 0-Max capacity, измеренные значения vs истинные (отклонение <допуск). 5) Calibration: external (гиря) или internal (встроенный motorised weight). Документирование: Certificate с uncertainty (k=2, 95% confidence). Uncertainty calculation: standard deviation + uncertainty стандарта + temperature effects + etc. TUR (Test Uncertainty Ratio): 4:1 goal (UUT accuracy 4× calibrator accuracy). Окружающая среда: 20±2°C, RH 40-60%, вибрация, free from drafts. | Гири: хранить в защитных боксах, не касаться пальцами (жир/влага увеличивают массу на мкг). Пинцет с пластиковыми/замшевыми наконечниками. |
| calibration.ops.thermocouple_calibration | Temperature — Thermocouple Calibration | METHOD | Калибровка термопар (K, J, T, E, N типы). Методы: 1) Comparison (сухой блок-калибратор: metal insert block в печи, reference thermometer (SPRT — Standard Platinum Resistance Thermometer или precision TC) + UUT (unit under test) в соседние скважины блока. Стабилизация 15-30 мин, сравнение показаний. 2) Fixed-point cells (первичная лаборатория): Gallium (29.7646°C), Indium (156.5985°C), Tin (231.928°C), Zinc (419.527°C) — phase change plateau (международная температурная шкала ITS-90). 3) Electrical simulation (calibrator источник напряжения — подаёт мВ сигнал на TC readout). Холодный спай (Cold Junction Compensation): должен быть properly accounted (0°C reference или electronic). Погрешность: ±0.5°C для industrial K-type, ±0.1°C для precision. | TC деградирует со временем (окисление, contamination). Признак: calibration drift (уходит всё дальше с каждым годом). K-type: green rot (хромистая окисная коррозия при 800-1000°C в низкокислородной среде — отрицательный drift). |
| calibration.ops.pressure_gauge_calibration | Pressure — Gauge Calibration (Dead-Weight) | METHOD | Калибровка манометров. Dead-Weight Tester (DWT): первичный стандарт давления. Принцип: масса грузов на поршне создаёт давление P = F/A = (m·g)/A. Поправки: местная gravity, воздушная плавучесть грузов, температура поршня (thermal expansion). Поршень вращается (снижает трение). Процедура: установить UUT (gauge/transducer), создать давление DWT, сравнить показания UUT и DWT. Точки: 0-25-50-75-100% диапазона (up и down для гистерезиса). Допуск: Class 1.0 gauge = ±1.0% of span. Среда: oil (для высоких давлений >20 бар) или pneumatic (газ, для низких <20 бар, чистота). Безопасность: НИКОГДА не превышать max rated pressure DWT. Осторожно с внезапным сбросом давления! | DWT — абсолютный первичный стандарт (масса/длина/время). Не требует калибровки (кроме силе тяжести g). |
| calibration.ops.electrical_multimeter_cal | Electrical — Multimeter Calibration | METHOD | Калибровка мультиметров. Стандарты: Multi-function calibrator (Fluke 5522A, 5730A, Transmille). Функции: DC Voltage (0-1000V, точность ±10 ppm), AC Voltage, DC/AC Current, Resistance (стандартные катушки сопротивления), Capacitance. Процедура: прогрев calibrator и UUT (30+ мин). Подключение: 4-wire для низкого сопротивления (<1 МОм — исключение сопротивления проводов). Точки: 5-10 по диапазону. Waiting time для thermal EMF settling (особенно при переключении диапазонов). Автоматизация: ПО (MET/CAL, SureCal) управляет calibrator и собирает данные с UUT. Acceptance: по manufacturer's 1-year spec (95% или 99% confidence). Uncertainty: spec calibrator + resolution UUT + repeatability + leads + temp. | Сгоревший предохранитель в current input мультиметра: типичная проблема. Проверять предохранитель перед калибровкой current ranges. Guardbanding: сужение acceptance limit на величину uncertainty чтобы гарантировать ≤2% PFA (Probability of False Accept). |
