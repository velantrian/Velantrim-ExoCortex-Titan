| metalwork.ops.lathe_turning_basics | Lathe — Turning Operations & Tool Geometry | METHOD | Токарный станок: заготовка вращается (шпиндель), резец движется. Скорость резания (Vc, м/мин) = π × D × N / 1000, где D — диаметр заготовки (мм), N — обороты (об/мин). Подача (f, мм/об): черновая 0.2-0.5, чистовая 0.05-0.15. Глубина резания (ap, мм): черновая 2-5, чистовая 0.1-0.5. Расчёт времени: L / (f × N). Геометрия резца (tool geometry): передний угол (rake — влияет на усилие резания и стружкообразование: положительный — легче режет, мягкие материалы; отрицательный — прочнее режущая кромка, для твёрдых/прерывистого резания), задний угол (clearance — чтобы резец не тёрся о заготовку), главный угол в плане (approach angle — 90° для shoulder turning, 45° для общих работ), радиус при вершине (nose radius — 0.2-0.8 мм, влияет на чистоту поверхности). Операции: подрезание торца (facing), продольное точение (turning), точение канавок (grooving), отрезание (parting), сверление/растачивание (boring), нарезание резьбы резцом (threading). | Скорость резания для разных материалов (HSS tool): сталь низкоуглеродистая 20-30 м/мин, нержавейка 10-15, алюминий 80-120, латунь 50-80. Карбид (tungsten carbide): в 3-5 раз быстрее. Охлаждение (coolant): обязательно для стали (эмульсия 5-10%), для чугуна — обычно сухое (графит сам смазывает), для алюминия — керосин или специальное масло. |
| metalwork.ops.milling_operations | Milling — Climb vs Conventional, Speeds/Feeds | METHOD | Фрезерный станок: фреза вращается, заготовка движется. Climb milling (попутное фрезерование — подача в направлении вращения фрезы): стружка толстая → тонкая, лучше чистота поверхности, меньше износ фрезы, НО отжимает заготовку (требуется минимальный люфт в подаче — шарико-винтовая передача (ballscrew)). Conventional (встречное — подача против вращения): стружка тонкая → толстая, отжимает фрезу, хуже чистота, но безопаснее на старых станках с люфтом. Расчёт подачи: F (мм/мин) = fz × Z × N, где fz — подача на зуб (мм/зуб), Z — число зубьев фрезы, N — обороты. Типовые fz для end mill (HSS): алюминий 0.05-0.15 мм/зуб, сталь 0.02-0.07, нержавейка 0.01-0.03. Depth of cut: черновая — 0.5-1.0 × D (ширина фрезы), чистовая <0.1 × D для радиального (stepover). Типы фрез: end mill (концевая — вертикальная/горизонтальная обработка, пазы, карманы), face mill (торцевая — плоскости), ball nose (сферическая — 3D поверхности), chamfer (фаско-сниматель), T-slot (Т-образный паз). | Выбор фрезы: число зубьев (2 для алюминия — хороший отвод стружки, 4 для стали — прочнее). Coating: TiN (золотой — снижает трение), TiAlN (тёмно-фиолетовый — для высокотемпературного, сухого резания), AlCrN (для твёрдых материалов). |
| metalwork.ops.cnc_programming_basic | CNC — G-Code Fundamentals | METHOD | Программирование ЧПУ. Система координат: декартова, абсолютная (G90) или относительная (G91). Основные G-команды: G00 — rapid traverse (быстрое перемещение без резания), G01 — linear interpolation (рабочая подача с заданной скоростью F), G02/G03 — круговая интерполяция (clockwise/counterclockwise), G20/G21 — дюймы/мм, G40/G41/G42 — отмена/слева/справа коррекция на радиус фрезы (cutter compensation), G54-G59 — выбор нулевой точки (work offset), G81-G89 — циклы сверления, G96/G97 — постоянная скорость резания (CSS) / обороты, M03/M04/M05 — шпиндель по часовой / против / стоп, M06 — смена инструмента, M08/M09 — coolant on/off, M30 — конец программы с возвратом в начало. Пример: G90 G00 X0 Y0 Z10 ; G01 Z-5 F100 ; G01 X50 F200 ; G03 X75 Y25 R25 ; G00 Z10. CAM-программа (Fusion 360, Mastercam) генерирует G-код из 3D-модели. Верификация: симуляция обработки (проверить на столкновения, зарезы). Постпроцессор: преобразует общий toolpath в G-код конкретного станка. | G01 всегда требует подачу (F). Без F станок не двинется. Feedrate override на пульте (10-150%): при первом прогоне программы снижать подачу до минимума для проверки. Single block mode: выполнение программы по кадрам (по одному нажатию). |
| metalwork.ops.grinding_wheel_selection | Grinding — Wheel Selection & Dressing | METHOD | Шлифовальный круг. Параметры: Abrasive (A — aluminium oxide для стали, C — silicon carbide для чугуна/цветных металлов/карбида, CBN — cubic boron nitride для закалённых сталей, Diamond для карбида/керамики), Grain size (зернистость — 46-60 для черновых, 80-120 для чистовых), Grade (твёрдость связки — буква: H-K мягкий для твёрдых материалов, L-O средний, P-R твёрдый), Structure (структура — 5-8 средняя), Bond (V — vitrified/керамическая — самая распространённая, B — resin, E — shellac). Периферийная скорость (SFPM — surface feet per minute): 5500-6500 для vitrified, 8500-9500 для organic bonds. Dressing (правка): алмазный карандаш или ролик снимает затупившиеся зёрна и выравнивает круг (восстанавливает геометрию и режущую способность). Частота правки: перед чистовой операцией, после черновых каждые 10-30 деталей. Balancing: статическая балансировка круга (arbor + balancing stand). Coolant: обильный! При недостатке — прижог (burning — синие пятна на поверхности, микротрещины). | Круг проверяется перед установкой (ring test — ударить неметаллическим предметом, звук звон = нет трещин, глухой = трещина — утилизировать). Прижог — частая проблема при шлифовке закалённой стали (отпуск поверхностного слоя, потеря твёрдости). Увеличить подачу СОЖ. |
| metalwork.ops.heat_treatment_hardening | Heat Treatment — Quenching & Tempering | PROCESS | Термообработка стали (упрощённо). 1) Нагрев: до аустенитной температуры (для простой углеродистой стали — 760-850°C, зависит от содержания углерода; легированные стали — выше, 850-1000°C). 2) Выдержка (soaking): 1 час на дюйм толщины (минимум 30 мин). 3) Закалка (quenching): быстрое охлаждение в закалочной среде для формирования мартенсита. Среда: вода (самая быстрая — для простых углеродистых сталей, риск трещин), масло (средняя — для легированных сталей), воздух (медленная — для высоколегированных, air-hardening). Закаливаемость (hardenability): Jominy test (торцевая закалка) определяет глубину закаленного слоя. 4) Отпуск (tempering): нагрев до 150-650°C для снятия напряжений и снижения хрупкости. Низкий отпуск (150-200°C): режущий инструмент, твёрдость 60-65 HRC. Средний (350-450°C): springs. Высокий (500-650°C): конструкционные детали, твёрдость 30-45 HRC (sorbitol). Цвета побежалости: соломенный (230°C), коричневый (260°C), пурпурный (280°C), синий (300°C) — визуальный индикатор температуры при отпуске. 5) Annealing (отжиг): нагрев и МЕДЛЕННОЕ охлаждение (в печи) для максимальной мягкости. Normalizing (нормализация): охлаждение на воздухе для снятия напряжений и измельчения зерна. | Мартенсит — самая твёрдая и хрупкая структура (игольчатая). Без отпуска деталь может треснуть от малейшего удара. Деформация при закалке: деталь искривляется. Припуск на шлифовку после термообработки 0.2-0.5 мм на сторону. Обезуглероживание (decarburization): нагрев без защитной атмосферы → поверхностный слой теряет углерод → мягкая поверхность. |
| metalwork.ops.metrology_instruments | Precision Measurement — Micrometer & Indicators | METHOD | Измерение с точностью до 0.01-0.001 мм. Микрометр: точность 0.01 мм (нониус 0.001), диапазоны 0-25, 25-50, 50-75 мм. Использование: очистить пятки, проверить ноль, вращать трещотку (ratchet) пока не прощёлкнет 2-3 раза (постоянное усилие 5-10 Н). Не перетягивать (деформация рамки). Калибровка: gauge block. Штангенциркуль (vernier caliper): точность 0.02 мм. Dial indicator / digital indicator: точность 0.01 мм (или 0.001 мм у high precision). Magnetic stand: жёсткое крепление. Применение: проверка биения (runout), плоскостности, параллельности. Sine bar (синусная линейка): точная установка углов (H = L × sin α). Gauge blocks (плитки Иоганссона): эталонные меры длины (стальные или керамические, точность Grade 0/1/2). Wringing: способность двух очищенных плиток «слипаться» (молекулярное притяжение + вакуум от выдавливания воздуха) — суперточная сборка заданного размера. | Температурное расширение: на 1°C изменения — сталь 11.5 мкм/м, алюминий 23 мкм/м. Деталь должна акклиматизироваться в измерительной комнате (20°C) минимум 1-2 часа. |
