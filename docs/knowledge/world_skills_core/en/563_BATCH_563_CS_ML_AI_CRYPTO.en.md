|---|---|---|---|---|
| cs.ml.linear_regression | Linear Regression | INVARIANT | y = Xβ + ε. OLS (ordinary least squares): β̂ = (XᵀX)⁻¹Xᵀy. Предположения Гаусса-Маркова: линейность, экзогенность X, гомоскедастичность, некоррелированность ошибок (нарушение → GLS, robust SE). R² = 1 − SS_res/SS_tot. | Интерпретируемость (βᵢ — изменение y при +1 ед. Xᵢ). Мультиколлинеарность (VIF>10 — проблема). Регуляризация: Ridge (L2 — |β|²), Lasso (L1 — |β| → sparsity), Elastic Net. |
| cs.ml.logistic_regression | Logistic Regression | METHOD | P(y=1|x) = 1/(1+exp(−wᵀx)). Log-odds = wᵀx. Максимизация правдоподобия (градиентный спуск/Newton). Калибровка вероятностей. Decision boundary = {x: wᵀx=0}. | Базовый классификатор, интерпретируемый (odds ratio). Мультиклассовая: одна модель на класс (one-vs-rest) или softmax. |
| cs.ml.svm | Support Vector Machines (SVM) | METHOD | Максимизация ширины разделяющей полосы. Ядровой трюк: K(xᵢ,xⱼ) = φ(xᵢ)·φ(xⱼ). RBF: K = exp(−γ||xᵢ−xⱼ||²). Мягкий зазор (C — penalty). SMO-алгоритм для обучения. | SVM эффективны для средних размерностей, когда признаков больше, чем примеров. Kernel для нелинейных границ (но плохо масштабируются на большие данные). |
| cs.ml.tree_ensemble | Decision Trees & Random Forest | METHOD | Дерево: рекурсивное разбиение по признаку (max information gain — энтропия/Gini). Ансамбли: Bagging (Bootstrap aggregating, уменьшает дисперсию — Random Forest: + случайное подмножество признаков на каждом разбиении). Boosting (последовательное исправление ошибок, снижает смещение — XGBoost, LightGBM, CatBoost). | XGBoost — «чемпион» Kaggle для табличных данных. Важность признаков (feature importance — MDI, permutation). Out-of-bag error. |
| cs.ml.neural_network | Neural Network — Forward & Backpropagation | METHOD | Слои: Wx+b → активация (ReLU, sigmoid, tanh). Функция потерь L. Backprop: ∂L/∂W = ∂L/∂a · ∂a/∂z · ∂z/∂W (chain rule). Градиентный спуск: W ← W − η·∂L/∂W. Mini-batch, momentum, Adam (адаптивный, moments 1st/2nd). | Инициализация весов (Xavier/Glorot, He). Batch Normalization (стабилизирует, ускоряет). Dropout (зануление случайных нейронов на тренировке — регуляризация). |
| cs.ml.cnn | Convolutional Neural Networks (CNN) | METHOD | Свёртка (фильтр × рецептивное поле) + активация + пулинг (max/average, снижение размерности). Веса фильтров — общие (parameter sharing). Архитектуры: LeNet → AlexNet (2012) → VGG → ResNet (skip connections — решают проблему затухающих градиентов) → EfficientNet. | ImageNet (1.2М изображений, 1000 классов). Трансферное обучение: предобученные веса + fine-tuning на целевой задаче. |
| cs.ml.rnn_lstm | RNN, LSTM & GRU | METHOD | RNN: h_t = tanh(W_h·h_{t−1} + W_x·x_t). Vanishing/exploding gradients. LSTM: вентили забывания (f_t), входа (i_t), выхода (o_t), состояние ячейки c_t. GRU: упрощённая, update gate + reset gate. Двунаправленные (bidirectional). | Временные ряды (прогнозирование), текст (until Transformers). Seq2seq: encoder-decoder + attention. |
| cs.ml.transformer | Transformer — Attention is All You Need | INVARIANT | Self-Attention: Q=XW_Q, K=XW_K, V=XW_V. Attention(Q,K,V) = softmax(QKᵀ/√d_k)V. Multi-Head: параллельные внимания → concat. Positional encoding (синусоидальная). Feed-forward, residual connections, layer norm. | BERT (encoder-only, understanding), GPT (decoder-only, generation), T5 (encoder-decoder). Квадратичная сложность (L²) → длинные последовательности (Longformer, Linformer). |
| cs.ml.bias_variance | Bias-Variance Tradeoff | INVARIANT | Ошибка = Bias² + Variance + Irreducible Error. Недообучение (underfitting): высокое смещение (модель слишком проста). Переобучение (overfitting): высокая дисперсия (модель запоминает шум). Cross-validation (K-Fold) — оценка обобщающей способности. | Регуляризация снижает дисперсию. Больше данных уменьшает дисперсию. Ансамбли: bagging снижает дисперсию, boosting — смещение. |
| cs.ml.metrics_ml | Classification Metrics | METHOD | Accuracy = (TP+TN)/All. Precision = TP/(TP+FP). Recall = TP/(TP+FN). F₁ = 2PR/(P+R). ROC-AUC: кривая TPR vs FPR, порог AUC=1 — идеально. Матрица ошибок (confusion matrix). Log loss (кросс-энтропия). | Несбалансированные: precision/recall важнее accuracy. PR-кривая для сильного дисбаланса. Fβ: β>1 — recall важнее, β<1 — precision важнее. |
| cs.ml.regularization | Regularization Techniques | METHOD | L1 (Lasso): sparse, отбор признаков. L2 (Ridge): сжатие весов. Elastic Net: αL1+(1−α)L2. Dropout: случайное выключение нейронов (p~0.5). Data augmentation, early stopping (остановка когда val loss растёт). | Double descent феномен: с ростом сложности ошибка падает-растёт-падает опять (противоречит классической U-кривой для переобученных моделей!). |
| cs.ai.knowledge_representation | Knowledge Representation | METHOD | Семантические сети, фреймы (Мински), онтологии (OWL, RDF), дескриптивные логики (ALC, SHOIN(D)). Логика предикатов как представление: ∀x(Человек(x)→Смертен(x)). Проблема фрейма (что меняется/не меняется при действии). | Графы знаний: Wikidata, DBpedia, Google Knowledge Graph. Онтологии в биоинформатике (Gene Ontology). |
| cs.ai.search_algorithms | Classical Search — A* & Heuristics | METHOD | A*: f(n) = g(n) + h(n). Допустимость (h не переоценивает) и состоятельность (monotonicity: h(n) ≤ c(n,n') + h(n')). IDA* (итеративное углубление, ограниченная память). Эвристики: Манхэттенское расстояние (15-пазл), relaxed problem. | Планирование маршрутов, решение головоломок, игровой AI (шахматы — Minimax + α-β pruning). A* с хорошей эвристикой оптимален. |
| cs.ai.reinforcement_learning | Reinforcement Learning Basics | INVARIANT | Агент в среде: состояние S, действие A, награда R. Policy π(a|s), функция ценности V(s), Q(s,a). Bellman: Q(s,a) = R(s,a) + γ·max_a' Q(s',a'). Оптимальная политика: argmax_a Q*(s,a). | Q-Learning (off-policy), SARSA (on-policy). DQN (Deep Q-Network — нейросеть аппроксимирует Q, experience replay, target network). AlphaGo (MCTS + policy/value сети). |
| cs.cryptography.hash_sha | Cryptographic Hash Functions | INVARIANT | SHA-256 (256 бит), SHA-3 (Keccak). Свойства: детерминированный, быстро вычисляется, preimage resistance (необратимость), second preimage, collision resistance (нельзя найти x≠y: H(x)=H(y)). Лавинный эффект: 1 бит входа меняет ~50% бит выхода. | Хранение паролей: HMAC-SHA256 (salt + много итераций: bcrypt, scrypt, Argon2 — медленные хеши противостоят брутфорсу). Целостность файлов, блокчейн (Merkle tree). |
| cs.cryptography.sha3 | SHA-3 & Sponge Construction | METHOD | Keccak: sponge (поглощение → сжатие). Внутреннее состояние 1600 бит. Устойчивость к length extension (проблема SHA-256 — решается HMAC). Перестановка 24 раунда (θ, ρ, π, χ, ι). | Выбран через открытый конкурс NIST (2007-2012). Более элегантный дизайн, чем у SHA-256. |
