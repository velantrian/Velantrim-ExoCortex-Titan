# BATCH 590: Medicine — Nephrology, Gastroenterology & Pulmonology

**Scope:** kidney_disease, dialysis, acid_base_kidney, liver_function, hepatitis, cirrhosis, ibd, copd, asthma, ards, pulmonary_function_tests.

| ID | KnowledgeUnit | Тип | Суть | Практический смысл |
|---|---|---|---|---|
| medicine.nephrology.aki | Acute Kidney Injury (AKI) — RIFLE/AKIN | CONTROL | Преренальная (гипоперфузия: дегидратация, СН, цирроз), ренальная (ATN острый тубулярный некроз — ишемия/токсины; гломерулонефрит), постренальная (обструкция). Креатинин ↑, диурез ↓. FeNa <1% → преренальная (канальцы реабсорбируют Na), >2% → ATN. | Гидратация, избегать нефротоксинов (НПВС, аминогликозиды, контраст), лечение причины. Диализ показан при: гиперкалиемия рефрактерная, ацидоз, отёк лёгких, уремия (перикардит). |
| medicine.nephrology.ckd_stages | Chronic Kidney Disease (CKD) — Staging | VARIANT | G1: СКФ ≥90 + повреждение. G2: 60-89. G3a: 45-59, G3b: 30-44. G4: 15-29. G5: <15 (терминальная, диализ). Альбуминурия A1-3. По формуле CKD-EPI (креатинин, возраст, пол). Анемия (дефицит эритропоэтина), остеодистрофия (↓Ca, ↑PO₄, ↑PTH), ацидоз. | Контроль: ACEi/ARB (↓протеинурию, замедление прогрессии), SGLT2и (нефропротекция при любом СКФ). Анемия: эритропоэтин/дарбепоэтин. |
| medicine.nephrology.hemodialysis | Hemodialysis Principles | METHOD | Кровь vs диализат в противотоке через полупроницаемую мембрану. Диффузия (удаление мочевины, креатинина, K⁺) + ультрафильтрация (удаление воды через трансмембранное давление). Сосудистый доступ: AV фистула (нативная, золотой стандарт) > AV graft > катетер. | Адекватность диализа: Kt/V ≥ 1.2 (спроведено по Daugirdas). Проблемы: гипотензия, судороги, аритмии. Диализная деменция (алюминий, больше не актуально). |
| medicine.gastroenterology.peptic_ulcer | Peptic Ulcer Disease (PUD) | PROCESS | H. pylori (уреаза → аммиак → защита от кислоты, колонизация антрального отдела) + НПВС (↓PGE2 → ↓защитная слизь и бикарбонаты). Диагностика: эндоскопия + биопсия (быстрый уреазный тест, гистология), ¹³C-дыхательный тест, антиген в стуле. | Эрадикация H. pylori: ИПП + кларитромицин + амоксициллин (± метронидазол) 14 дней. Резистентность к кларитромицину >15-20% → квадротерапия с висмутом. |
| medicine.gastroenterology.liver_cirrhosis | Liver Cirrhosis — Decompensation | PROCESS | Фиброз → узлы-регенераты → нарушение архитектоники → портальная гипертензия. Осложнения: асцит (↓альбумин + ↑давление в синусоидах) → спонтанный бактериальный перитонит; варикоз пищевода → кровотечение; печёночная энцефалопатия (аммиак ↑); гепаторенальный синдром; гепатоцеллюлярная карцинома. | Оценка тяжести: Child-Pugh (билирубин, альбумин, INR, асцит, энцефалопатия) и MELD (билирубин, INR, креатинин). Трансплантация печени при MELD >15 (исключения для ГЦК). |
| medicine.gastroenterology.ibd | Inflammatory Bowel Disease (IBD) — Crohn vs UC | VARIANT | Болезнь Крона: трансмуральное воспаление, любой отдел ЖКТ («рот-анус»), skip lesions, гранулемы, стриктуры, свищи. Язвенный колит: только толстая кишка, непрерывное, начинается с прямой, поверхностное (слизистая), кровь в стуле. | Терапия: 5-ASA (месалазин — 1-я линия UC и лёгкого Крона), стероиды (индукция ремиссии, не поддержка), иммуномодуляторы (азатиоприн), биологическая (анти-TNFα инфликсимаб). |
| medicine.gastroenterology.colorectal_cancer_screening | Colorectal Cancer — Adenoma-Carcinoma Sequence | PROCESS | FAP (APC мутация — сотни полипов) и синдром Линча (MMR мутации — меньше полипов, быстрое прогрессирование). Спорадический: мутации APC → KRAS → p53 → метастазирование. | Колоноскопия с 45-50 лет каждые 10 лет (или FIT ежегодно). Полипэктомия предотвращает рак. |
| medicine.pulmonology.copd | COPD — Emphysema & Chronic Bronchitis | PROCESS | Нейтрофильная эластаза разрушает эластин → эмфизема (центриацинарная у курильщиков, панацинарная при α₁-антитрипсин дефиците). Гиперсекреция слизи, нарушение мукоцилиарного клиренса. Необратимая обструкция дыхательных путей. ОФВ₁/ФЖЕЛ <0.70 после бронходилататора. | Главный фактор риска — курение. Терапия: бронходилататоры (LAMA + LABA), ИКС при частых обострениях, оксигенотерапия (≥15 ч/сут при pO₂<55 мм рт.ст. — единственная доказанная модификация смертности при тяжёлой ХОБЛ). |
| medicine.pulmonology.asthma_pathophysiology | Asthma — Type 2 Inflammation | PROCESS | Аллерген → дендритная клетка → Th2 → IL-4 (→ IgE, тучные клетки, дегрануляция, гистамин, лейкотриены → бронхоспазм острая фаза) + IL-5 (эозинофилы → хроническое воспаление, ремоделирование дыхательных путей) + IL-13. Обратимая обструкция (вариабельность ПСВ). | Бронходилататоры (β2-агонисты короткого/длительного действия), ИКС (ингаляционные кортикостероиды — основа). Тяжёлая эозинофильная астма: анти-IL5 (меполизумаб). |
| medicine.pulmonology.ards | Acute Respiratory Distress Syndrome (ARDS) | CONTROL | Диффузное альвеолярное повреждение → отёк лёгких при нормальном давлении наполнения (некардиогенный). Определение (Berlin 2012): острое начало (<1 нед), двусторонние инфильтраты, P/F <300 (лёгкая), <200 (средняя), <100 (тяжёлая) при PEEP ≥5 см H₂O. | Вентиляция: малые дыхательные объёмы 4-6 мл/кг (защита от волюмотравмы — ARDSNet), PEEP для предотвращения ателектазов, прон-позиция (на животе) при тяжёлой. Консервативная жидкостная стратегия. |
| medicine.pulmonology.pulmonary_function_tests | Pulmonary Function Tests (PFTs) | METHOD | Spirometry: ОФВ₁ (объём форсированного выдоха за 1 сек), ФЖЕЛ (форсированная ЖЕЛ). Обструкция: ОФВ₁/ФЖЕЛ < 0.70. Рестрикция: снижена ЖЕЛ при нормальном отношении. Body plethysmography: ООЛ, ОЕЛ. DLCO (диффузионная способность по CO). | Бронходилатационный тест: ↑ОФВ₁ >12% и >200 мл → положительный (астма). DLCO снижена при эмфиземе, ИБЛ, лёгочной гипертензии; нормальна при ХБ, астме. |
