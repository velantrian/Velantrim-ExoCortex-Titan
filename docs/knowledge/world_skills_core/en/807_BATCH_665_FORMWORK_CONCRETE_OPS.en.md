# BATCH 665: Formwork — Concrete Shuttering Operations

**KnowledgeUnits:** 50
**Namespace:** `formwork.ops.*`
**Scope:** wall_forms, slab_forms, column_forms, shoring, stripping, form_ties, form_release, plywood

| ID | KnowledgeUnit | Тип | Суть | Практический смысл |
|---|---|---|---|---|
| formwork.ops.wall_form_panel_assembly | Wall Forms — Panel Assembly | METHOD | Сборка опалубки стен. Панели: фанерный лист 18-21 мм (B-B Plyform Class I) на стальной/алюминиевой раме. Form ties (стяжки): snap tie (одноразовый, отламывается после распалубки), coil tie (многоразовый с конусами), taper tie (через стену). Расстояние между ties: 60-90 см горизонтально и вертикально (по расчёту давления бетона). Walers (горизонтальные балки double): для распределения нагрузки от ties. Strongbacks (вертикальные рёбра): для жёсткости. Шаг: ties + walers + strongbacks = engineered assembly. Проверка: plumb (отвес), alignment (string line), dimensions, level. | Давление бетона: жидкий бетон — pressure = density × depth (гидростатическое до начала схватывания). |
| formwork.ops.slab_shoring_reshoring | Slab Shoring — Reshoring Procedure | METHOD | Установка поддерживающих стоек для плиты. Shores (домкратные стойки Ellis, PERI): шаг 1-1.5 м по расчёту (load capacity 20-40 кН/стойка). Stringers (балки под фанеру): 50×100 мм через 40-60 см (или aluminium joists). Plywood: 18 мм, perpendicular to stringers. Camber (строительный подъём): 3-5 мм на пролёт (компенсация прогиба). Reshoring: после снятия shores (набрав 50-70% прочности) немедленно установить обратно для поддержки свежего бетона этажом выше. Reshores не должны быть перегружены (несколько этажей нагрузки суммируются!). | Обрушение: ранняя распалубка без reshoring = коллапс. |
| formwork.ops.form_tie_cone_system | Form Tie — Cone & Waterstop | METHOD | Установка стяжек с конусами. Coil tie: пластиковый конус (cone) создаёт углубление в бетоне после распалубки. Гидроизоляция: waterstop (резиновый/ПВХ) на середине стяжки для водонепроницаемых стен (бассейны, подвалы). После распалубки: конус извлечь, отверстие заполнить цементным раствором. Snap tie: после распалубки отламывается заподлицо (breakback), отверстие замазывается. | Конуса оставленные в бетоне = путь для воды. |
| formwork.ops.form_release_application | Form Release — Application | METHOD | Нанесение разделительной смазки. Цель: предотвратить прилипание бетона к опалубке + защита фанеры. Типы: Nox-Crete (химически активный — реагирует с кальцием), barrier (воск-маслянный слой). Нанесение: распыление (thin uniform coat), не лужы! Избыток release agent = пятна на бетоне, плохая адгезия краски. Timing: за 1-2 часа до бетонирования (или день до). Не наносить на арматуру! (снижает bond). Чистка опалубки: после каждой заливки снять налипший бетон (scraper, wire brush). | Грязная опалубка + release agent = дефекты поверхности бетона. |
| formwork.ops.stripping_time_hardness | Stripping Time — Concrete Maturity | METHOD | Определение времени распалубки. Температурный метод: maturity (зрелость бетона) — функция времени и температуры. Зимой бетон набирает прочность медленнее. Ориентиры (20°C): стены (вертикальные) — 12-24 часа, плиты (нижняя опалубка) — 7-14 дней (или 70% проектной прочности). Field test: rebound hammer (склерометр — ориентировочный), pull-out test (LOK test), cast cylinders (испытание на сжатие). Правило: не распалубливать пока инженер не даст разрешение. | Распалубка слишком рано: прогиб, трещины, коллапс. |
