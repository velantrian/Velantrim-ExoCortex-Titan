# BATCH 619: Upholstery — Furniture Reupholstering

**KnowledgeUnits:** 44
**Namespace:** `upholstery.ops.*`
**Scope:** stripping, spring_tie, webbing, foam, fabric_cut, sewing, button_tufting, fitting

| ID | KnowledgeUnit | Тип | Суть | Практический смысл |
|---|---|---|---|---|
| upholstery.ops.stripping_old_removal | Stripping — Old Upholstery Removal | METHOD | Демонтаж старой обивки. Маркировка (фото/видео — как было!), последовательное снятие слоёв: внешняя ткань → вата/дакрон → пена → burlap → пружины/ремень. Удаление скоб (staple remover, плоскогубцы). Каждый снятый кусок ткани — шаблон для нового (разложить на столе, обвести). Оценка каркаса: расшатан (reglue joints), сломан (repair), squeaky. Пружины: если провисли/сломаны — заменить или перетянуть. Ремень (jute webbing): проверить натяжение (не провис). | Сохранять каждый piece fabric как pattern — экономия времени. |
| upholstery.ops.spring_tie_eight_way | Spring Tie — 8-Way Hand-Tied | METHOD | Классическая перетяжка пружин (8-way hand-tied). Пружины (coil springs) установлены на webbing. Каждая пружина обвязывается шпагатом (jute twine) в 8 направлениях (перед-зад, лево-право, 4 диагонали). Каждый узел: clove hitch на верхнем кольце пружины, затем к следующей пружине, натяжение (сжать пружину на 30-50%), закрепить. Цель: пружины работают как единая система (не независимо). Edge wire (проволока по периметру): придаёт форму краю. После обвязки: burlap cover, затем padding. | 8-way tie: марка качества высокой мебели (дороже, трудоёмко). Современная мебель часто использует drop-in coil units (быстрее). |
| upholstery.ops.foam_cutting_contour | Foam — Cutting & Shaping | METHOD | Работа с поролоном. Типы: standard polyurethane (жёсткость ILD 15-40, плотность 1-3 lb/ft³). High Resilience (HR foam — отскок выше). Memory foam (медленный отскок, температурно-чувствительный). Резка: electric carving knife (домашний — для прямой резки), band saw (для сложной), foam saw (специальный). Обёртывание: Dacron (полиэстер-ватин) поверх foam для гладкости. Клей для foam: 3M Super 77 spray adhesive (брызнуть, подождать 30 сек, соединить). Contour shaping: angle cuts (для спинки), rounding. Fire barrier (California TB117-2013): межслойный firewall (Kevlar/fiberglass sock). | Foam стареет (крошится жёлтым порошком через 10-15 лет). |
| upholstery.ops.fabric_pattern_matching | Fabric — Pattern Matching & Cutting | METHOD | Раскрой обивочной ткани. Pattern repeat (раппорт): расстояние между повторяющимися элементами рисунка. Stripes, florals, geometrics — должны совпадать (match) на соседних деталях (подушка ↔ спинка). Railroading (поворот ткани на 90°): для непрерывного рисунка без шва на длинных деталях. Направление pile (велюр, микровельвет): ворс должен идти в одном направлении (обычно сверху вниз — цвет выглядит темнее сверху). Припуски: на швы 1-2 см, на обивку 5-10 см (для затягивания). Ножницы: tailoring shears (Gingher), rotary cutter + self-healing mat. Количество: расчёт + 20% waste. | Недостаток ткани: невозможно докупить из другого dye lot (цвет другой). |
| upholstery.ops.tufting_button_technique | Button Tufting — Chesterfield Style | METHOD | Каретная стяжка (tufted). Разметка: ромбовидный/квадратный pattern на поверхности (шаблон + маркер). Просверлить отверстия в мебельной раме для каждого button. Foam: pre-tufted или создание складок вручную. Пуговицы: обтянутые тканью (button press). Процесс: длинная игла с петлёй протыкает все слои (ткань → foam → burlap → рама), захватывает шпагат с button, вытягивает, закрепляет (туго натянуть, knot). Каждая пуговица создаёт глубокую складку (fold). Порядок: от центра наружу, симметрия. Складки расправляются одинаково. | Chesterfield: классика, требует опыта (20+ часов). |
