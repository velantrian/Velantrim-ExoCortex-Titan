# BATCH 705: Erosion Control — Sediment & Slope

**KnowledgeUnits:** 50
**Namespace:** `erosion.ops.*`
**Scope:** silt_fence, wattles, hydroseeding, riprap, gabion, blanket, retaining, swale

| ID | KnowledgeUnit | Тип | Суть | Практический смысл |
|---|---|---|---|---|
| erosion.ops.silt_fence_trench_install | Silt Fence — Trenched Install | METHOD | Установка silt fence (илоуловителя). Trench: 15-20 см глубина (J-hook). Fabric: geotextile (Mirafi, Typar) заводится в trench, засыпается и трамбуется. Posts: steel (star pickets) или wood, через 1.5-2 м. Fabric: натянута, крепится к posts (zip ties). End treatment: wrapping (не открытый конец). Расположение: вдоль contours (не вверх/вниз, где вода обойдёт). Обслуживание: после каждого дождя — очистка накопившегося sediment. Максимальная drainage area: 0.25 га на 100 м fence. | Сорванная silt fence: обычно из-за слишком большой drainage area. |
| erosion.ops.straw_wattle_placement | Wattle — Staking & Spacing | METHOD | Установка соломенных валиков (fiber rolls). Wattle: straw/coconut, в сетке. Расположение: вдоль contour (по горизонталям). Канавка: 2-5 см для seating. Stakes (деревянные колья): через 1.2-1.5 м по обе стороны, забиваются flush с wattle. Стыки: внахлёст 30 см, staked. Spacing между рядами: slope 1:1 = 3 м, 2:1 = 6 м, 3:1 = 12 м. Применение: slopes, flow channels. Разложение: 1-4 года (coconut дольше straw). | Wattles удерживают sediment и влагу (помогают растительности). |
| erosion.ops.hydroseeding_application | Hydroseeding — Slurry Mix | METHOD | Гидропосев (водяной посев). Tank: вода + seed + мульча (wood fiber/paper) + tackifier (клей) + fertiliser. Нанесение: pump spray из шланга на склон. Слой: зелёный/синий цвет для видимости coverage. Уход: полив (irrigation) до germination (2-3 недели для grasses). Преимущества: быстрое покрытие больших склонов, erosion control. Недостатки: нужно watering для success. | Не наносить на сухой склон без последующего полива. |
| erosion.ops.riprap_geotextile_underlay | Riprap — Geotextile Underlay | METHOD | Укладка каменной наброски. Geotextile (non-woven) под riprap: предотвращает вымывание fines из subgrade. Riprap: размер камня (D50) по расчёту (зависит от скорости потока/волны). Толщина слоя: 1.5-3× D50. Укладка: экскаватор, от нижней точки вверх. Не сбрасывать камни с высоты (повреждение textile). Filter layer (гравий) между textile и riprap для крупных камней. Toe: заглубление для предотвращения подмыва. | Без geotextile: subgrade вымывается между камнями. |
| erosion.ops.cfs_mulch_blowing | Compost Sock — Filter Berm | METHOD | Фильтрующий берм из компостного носка (Filtrexx). Устройство: pneumatic blower заполняет mesh tube компостом на месте. Размещение: contour line. Проверка flow: вода проходит через компост (фильтрация). Очистка: periodic sediment removal. Преимущества: biodegradable, fertilises soil. Применение: perimeter control, slope interruption. | Более экологично чем silt fence. |
