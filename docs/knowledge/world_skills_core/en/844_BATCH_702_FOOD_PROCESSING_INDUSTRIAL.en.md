# BATCH 702: Food Processing — Industrial Operations

**KnowledgeUnits:** 50
**Namespace:** `foodprocess.ops.*`
**Scope:** pasteurization, fermentation, extrusion, freezing, HACCP, packaging, additives, canning, drying, hygiene

| ID | KnowledgeUnit | Тип | Суть | Практический смысл |
|---|---|---|---|---|
| foodprocess.ops.htst_pasteurization | HTST Pasteurization — Parameters | METHOD | HTST (High-Temperature Short-Time): молоко — 72°C × 15 сек. Equivalent lethality: 63°C × 30 мин (LTLT). Коэффициент F0: время эквивалентной стерилизации при 121°C (в консервах). Plate heat exchanger: нагрев + регенеративное охлаждение. Headspace temperature: контроль температуры продукта на выходе. Validation: thermal process authority approval. | UHT (Ultra-High Temperature): 135-140°C × 2-5 сек = shelf-stable (комнатная температура). |
| foodprocess.ops.fermentation_lactobacillus | Lactic Fermentation — pH Kinetics | METHOD | Молочнокислое брожение: Lactobacillus, Streptococcus thermophilus, Leuconostoc. Субстрат: лактоза → молочная кислота (гомоферментативные), + CO2/этанол (гетеро). pH снижение: 6.5 → 4.6 (изоэлектрическая точка казеина → свёртывание). Температура: мезофильные 20-30°C, термофильные 40-45°C. Inhibitors: NaCl, нитрат (антибактериальный). | pH <4.5: патогены не растут (кроме кислотоустойчивых). |
| foodprocess.ops.twin_screw_extrusion | Food Extrusion — Twin Screw | METHOD | Пищевая экструзия: продукт (крахмал, белок) загружается → двойной шнек сжимает/нагревает → через фильеру. HTST: мгновенный нагрев. Expansion: при выходе из фильеры → падение давления → испарение воды → «взрыв». Gelatinization: крахмал структурирует. SME (Specific Mechanical Energy): кДж/кг (контроль процесса). Применение: снэки, текстурированный растительный белок, корм. | Влажность: снижение до 13-14% при экструзии (shelf life). |
| foodprocess.ops.aseptic_packaging | Aseptic Packaging — UHT + Fill | METHOD | Асептическое упаковывание: стерильный продукт + стерильная упаковка + стерильная зона наполнения. Tetra Pak: HP2O2 (35%) + UV → обеззараживание ламината. Nitrogen blanket: предотвращает окисление. Форматы: Tetra Brik Aseptic, Tetra Prisma. Shelf life: 3-12 мес без охлаждения. FDA letter of no objection: для нового процесса. | Aseptic vs retort (консервный): aseptic = лучшее качество (меньше теплового воздействия). |
| foodprocess.ops.canning_retort | Retort Sterilization — Fo Value | METHOD | Стерилизация в автоклаве (ретортная обработка): F0 = суммарное летальное воздействие при 121°C. Minimum F0 = 3 (для Clostridium botulinum спор, pH>4.6). Clostridium botulinum D-value при 121°C = 0.21 мин; 12D = 2.52 мин = «botulinum cook». Thermal penetration data: самая холодная точка. NFPA (National Food Processors Association) approval. | pH <4.6 (acidic): нет риска C. botulinum (не растёт). |
| foodprocess.ops.spray_drying | Spray Drying — Powder Production | METHOD | Распылительная сушка: жидкий продукт → атомизация (вращающийся диск или форсунка высокого давления) → горячий воздух (180-220°C) → мгновенное испарение воды. Outlet air temperature: 80-100°C. Particle size: 50-200 мкм. Bulk density: low (пустотелые) vs high. Instant powder: lecithin coating. Применение: молоко, кофе, яйцо, сыворотка. | Thermal damage: кратковременный контакт с горячим воздухом → minimal nutrient loss. |
| foodprocess.ops.iqf_freezing | IQF Freezing — Individual Quick Freezing | METHOD | Быстрая заморозка отдельных кусков (IQF): тоннельный морозильник с воздухом -30 до -40°C. Флюидизация: продукты «плавают» в воздушном потоке (горох, кукуруза, ягоды). Достижение -18°C в центре за <30 мин. IQF advantages: отдельные кусочки (не слипшийся блок), малые кристаллы (минимум тканевого повреждения). Cryogenic (жидкий N2 -196°C): ультрабыстро, дорого. | Быстрая заморозка = мелкие кристаллы льда = меньше drip loss при размораживании. |
| foodprocess.ops.hurdle_technology | Hurdle Technology — Multiple Barriers | METHOD | Теория барьеров (Leistner): комбинация нескольких консервирующих факторов (каждый ниже летального уровня). Барьеры: температура (F), aw (активность воды), pH, Eh (redox), CO2, конкурирующая микрофлора, консерванты. Синергизм: 0.93 aw + pH 5.5 + 200 ppm нитрит = надёжное сохранение (каждый отдельно — недостаточно). | Реформулирование (соль, сахар): изменение одного барьера может дестабилизировать систему. |
| foodprocess.ops.maillard_control | Maillard Reaction — Control Parameters | METHOD | Реакция Майяра: аминокислота + редуцирующий сахар → продукты потемнения (меланоидины). Условия: T° (>120°C быстро), pH (щелочная ускоряет), aw 0.6-0.9 (оптимально), время. Желательная: хлеб корочка, кофе, жареное мясо. Нежелательная: молоко в порошке (потеря лизина), нежелательный цвет. Контроль: снизить T°, снизить pH, снизить aw, использовать невосстанавливающие сахара. | Лизин повреждён при Maillard: особенно критично для детского питания. |
| foodprocess.ops.food_additives_e_numbers | Food Additives — E-Number Categories | METHOD | E-номера ЕС: E100-E199 (красители), E200-E299 (консерванты), E300-E399 (антиоксиданты), E400-E499 (загустители, гелеобразователи, стабилизаторы), E500-E599 (регуляторы pH, разрыхлители), E600-E699 (усилители вкуса — MSG, E621), E700-E999 (прочие). ADI (Acceptable Daily Intake): JECFA/EFSA устанавливают. | E-номер ≠ плохо: аскорбиновая кислота = E300 (витамин C). |
| foodprocess.ops.water_activity_measurement | Water Activity (aw) — Measurement | METHOD | Активность воды (aw): мера доступной воды. aw = Vapor pressure (food) / VP (pure water). Диапазоны: свежее мясо 0.99, хлеб 0.95, джем 0.75-0.85, мёд 0.6, сухое молоко 0.2. Мониторинг: aw meter (Novasina, Aqualab). Патогены: большинство не растут ниже aw 0.9. C. botulinum: не растёт <0.93. Плесень: до 0.70-0.75. | aw 0.85: граница между стабильным и нестабильным продуктом (без охлаждения). |
| foodprocess.ops.cleaning_in_place | CIP — Cleaning-in-Place Protocol | METHOD | Безразборная мойка (CIP): циркуляция через трубы/оборудование. Последовательность: 1) Pre-rinse (вода, смыть остатки). 2) Caustic wash (NaOH 1-2%, 70°C, 15-20 мин). 3) Intermediate rinse. 4) Acid wash (HNO3 0.5-1%, 65°C, 10-15 мин). 5) Final rinse. Validation: conductivity после ополаскивания, ATP-swab. | Pre-rinse critical: органика + щелочь = плохая очистка (Maillard продукты трудно удалить). |
| foodprocess.ops.modified_atmosphere | MAP — Modified Atmosphere Packaging | METHOD | Упаковка в модифицированной атмосфере (MAP): замена воздуха газовой смесью. Fresh meat: 70-80% O2 + 20-30% CO2 (оксиген = яркий красный цвет, CO2 = бактериостатический). Cooked meat: 20-30% CO2 + 70% N2. Salads: N2 + CO2 (нет O2 для respiration). Barrier film: EVOH layer (высокий барьер к O2). Headspace oxygen meter: контроль. | Equilibrium MAP (EMAP): дышащая упаковка для свежих овощей — O2 поглощается продуктом. |
| foodprocess.ops.emulsification_hlt | Emulsification — HLB Value | METHOD | Эмульгирование: HLB (Hydrophile-Lipophile Balance) = числовая шкала 0-20. HLB <6: W/O эмульсия (лецитин HLB=4-8, монодиглицериды HLB=3-6). HLB 8-18: O/W эмульсия (полисорбаты, сахарные эфиры HLB=11-16). Lecithin (natural): соевый или подсолнечный. Gum arabic: O/W stabilizer для beverage. High pressure homogenization: уменьшает droplet size → более стабильная эмульсия. | Droplet size <1 мкм (nano-emulsion): более стабильная, лучше биодоступность. |
| foodprocess.ops.high_pressure_processing | HPP — High Pressure Processing | METHOD | Высокое гидростатическое давление (HPP): 400-600 МПа, холодный пастеризатор. Время: 1-3 мин. Давление равномерное (паскаль). Инактивация: вегетативные клетки (E. coli, Listeria, Salmonella), большинство вирусов. Сохраняет: вкус, витамины (не нагрев), текстуру. Не инактивирует: споры (не вместе с высокой T°). Применение: guacamole, cold-press juice, RTE deli meats. | HPP cold chain: продукт должен оставаться холодным. Не замороженным. |
| foodprocess.ops.allergen_management | Allergen Management — Top 9 | METHOD | Аллергены (USA FDA «Big 9»): молоко, яйца, рыба, ракообразные, орехи, арахис, пшеница (глютен), соя, кунжут (добавлен 2023). EU: 14 аллергенов (+ сельдерей, горчица, люпин, диоксид серы). FALCPA (Food Allergen Labelling): обязательная маркировка. «Может содержать» (may contain): добровольная (предупреждение о cross-contact). FSMA: allergen control plan обязателен. | Cross-contact: не cross-contamination. Contact = аллерген перенесён физически. |
| foodprocess.ops.ohmic_heating | Ohmic Heating — Principles | METHOD | Омический нагрев: электрический ток прямо через жидкий продукт (сопротивление → выделение тепла). Равномерный нагрев (без горячих поверхностей). Применение: частицы в соусах (требуют равного нагрева твёрдой и жидкой фазы). Не для всех продуктов: плохая проводимость (масла) = не работает. Преимущества: мягкий (нет теплового повреждения поверхности), быстрый. | Ohmic vs conventional: лучше для fragile products (клубника целая в соусе). |
| foodprocess.ops.fermented_beverage_control | Fermented Beverage — Process Control | METHOD | Производство пива: mashing (65-67°C, 60 мин → глюкоза/мальтоза из крахмала), lautering, boiling (хмель), cooling, pitching yeast, fermentation (15-25°C для ale, 10-12°C для lager). Контроль: OG/FG (Original/Final Gravity, ареометр), pH, T°. ABV (%) = (OG-FG) × 131.25. | Stuck fermentation: дрожжи остановились (T° слишком низкая, YAN дефицит, OSH inhibition). |
| foodprocess.ops.texture_measurement | Texture Analysis — TPA | METHOD | Текстурный профиль-анализ (TPA, Texture Profile Analysis): двукратное сжатие образца с измерением силы. Параметры: hardness (максимальная сила), adhesiveness (сила отрыва), cohesiveness, springiness, gumminess, chewiness. Instron, TA.XT Plus. ASTM F2492: стандарт. | TPA объективна vs панельное дегустирование (субъективно). Корреляция для product QC. |
| foodprocess.ops.food_irradiation | Food Irradiation — Doses & Applications | METHOD | Облучение продуктов: γ-лучи (Co-60/Cs-137), электронный пучок, X-ray. Дозы: ингибирование прорастания (0.05-0.15 кГр), disinfection insects (0.15-1 кГр), патоген reduction (1-7 кГр), sterilization (>10 кГр). Radiolytic products: очень малые количества (FDA GRAS). Маркировка: «Radura» символ + «treated with radiation». | Spices: облучение заменяет steam sterilization (лучше аромат). |
