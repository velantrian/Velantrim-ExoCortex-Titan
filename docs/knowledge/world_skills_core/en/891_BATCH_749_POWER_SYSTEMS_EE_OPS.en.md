| powersys.ops.load_flow_analysis | Load Flow — Newton-Raphson | METHOD | Расчёт установившегося режима (Load Flow): Newton-Raphson: итерационный метод. Mismatch vector (ΔP, ΔQ) → Jacobian matrix → Δθ, ΔV. Сходимость: 3-5 итераций. Gauss-Seidel: простой но медленный. Fast Decoupled: использует отдельные P-θ и Q-V. Буснарская матрица (Ybus): узловая матрица проводимостей. | Плоский старт: все напряжения 1.0 + угол 0 → хорошая начальная точка. |
| powersys.ops.transformer_equivalent | Transformer — Equivalent Circuit | METHOD | Схема замещения трансформатора: R1 + jX1 (первичное) → параллельный Rc, jXm (намагничивающая ветвь) → R2' + jX2' (вторичное приведённое). Приведение к первичной стороне: R2' = R2 × (n1/n2)². Нагрузочные потери (copper loss): I²R. Холостой ход (iron loss): Rc. Тест КЗ: нагрузочные. Тест ХХ: железные. | Per unit system: нормировка на базовые значения (унифицирует разные напряжения). |
| powersys.ops.per_unit_system | Per Unit — Base Values | METHOD | Система относительных единиц (p.u.): Sbase (единый для всей системы), Vbase (по уровням напряжения). Zbase = V²base / Sbase. Ibase = Sbase / (√3 × Vbase). Изменение базы: Znew = Zold × (Sbase,new / Sbase,old) × (Vbase,old / Vbase,new)². Стандартный Zbase: 100 MVA. | P.u. упрощает: трансформаторы теряют идеальный трансформатор в схеме. |
| powersys.ops.relay_protection | Protection Relay — Overcurrent | METHOD | Токовая защита: Current Transformer (CT): измеряет ток. Relay: сравнивает с уставкой. Inverse time overcurrent relay (50/51): ток > уставке → задержка = к/(I/Iset)^n. IDMT (Inverse Definite Minimum Time). Pickup current: немного выше max load. Coordination: last resort (50/51 downstream) → next (52 upstream). | Zone 1 protection: мгновенная (instantaneous). Zone 2-3: с задержкой (coordination). |
| powersys.ops.symmetrical_components | Fault Analysis — Symmetrical Components | METHOD | Симметричные составляющие (Fortescue): несимметричная 3-фазная система = positive + negative + zero sequence. Positive: нормальная последовательность (A, B, C). Negative: обратная (A, C, B). Zero: одинаковые по величине и фазе. Three-phase fault: только положительная. Line-to-ground: все три. Преобразование: [A012] = [a][Aabc]. | Нулевая последовательность через нейтраль: при наличии заземлённого нейтралного провода. |
| powersys.ops.bus_bar_protection | Busbar Protection — Differential | METHOD | Защита шин (87B): дифференциальная. Сумма токов в шину = 0 при нормальной работе. Неисправность на шине: ΔI = сумма ≠ 0 → отключение. CT насыщение: проблема (ложные срабатывания). Biased differential: торможение при насыщении. High-impedance busbar protection: более устойчивый к CT насыщению. | Шинная защита критична: отказ = отключение всего подстанционного оборудования. |
| powersys.ops.power_swing | Power Swing — Loss of Synchronism | METHOD | Нарушение синхронизма: после крупного возмущения (КЗ) генераторы могут потерять синхронизм. Power Swing Blocking (PSB, функция 68): предотвращает ложное отключение при нормальном качании. Out-of-Step Tripping (OST, функция 78): отключение при потере синхронизма. Swing Locus: траектория R-X на плоскости импедансов. | PSB critical: distance relay 21 может ложно сработать при качании. |
| powersys.ops.voltage_stability | Voltage Stability — PV Curves | METHOD | Напряжённость по напряжению: PV curve (P vs V): nose point = maximum load transfer. Voltage collapse: при превышении nose point. Reactive power compensation (SVC, STATCOM): поддержание напряжения. Загрузка линии: мощность ограничена термически или по напряжённости. | Короновые потери: высокое напряжение → ионизация воздуха → потери в передаче. |
| powersys.ops.scada_energy_management | SCADA/EMS — Functions | METHOD | Supervisory Control and Data Acquisition (SCADA): телемониторинг + управление. Energy Management System (EMS): оптимальный dispatch, state estimation. OPF (Optimal Power Flow): экономический dispatch с ограничениями. State Estimation: фильтрация измерений → оценка состояния сети. ICCP (Inter-Control Center Protocol): обмен между диспетчерскими. | State Estimation = зеркало сети для оператора (не реальные измерения, а расчёт). |
| powersys.ops.short_circuit_calculation | Short Circuit — IEC 60909 | METHOD | Расчёт токов КЗ (IEC 60909): c × Vn / (√3 × |Zk|). c = voltage factor (1.0-1.1). Максимальный ток: c=1.1, минимальный: c=1.0. Zk = суммарный импеданс до точки КЗ. Asy factor (κ): для ударного тока (peak). 3ф КЗ обычно самый большой (> 1ф КЗ при Zground=0). | Оборудование должно выдерживать токи КЗ (рейтинг ICW). |
| powersys.ops.generator_synchronization | Generator Synchronization — Conditions | METHOD | Синхронизация генератора: точные условия — одинаковые: напряжение, частота, порядок следования фаз, угловое положение. Sync-check relay (25): проверяет перед включением. Допустимый diff напряжения: ±10%. Diff частоты: ±0.5%. Угол: ±10°. Auto-synchronizer: автоматически выравнивает. | Неправильная синхронизация: ударный ток = 2× Inom → повреждение генератора. |
| powersys.ops.transformer_protection | Transformer Protection — 87T | METHOD | Дифференциальная защита трансформатора (87T): измеряет токи первичной и вторичной стороны (приведённые). Harmonic restraint: 2-я гармоника при намагничивании → не реагировать на бросок намагничивающего тока. 5-я гармоника: перенасыщение → restraint. Percentage differential: slope = 20-25% (bias). | Пуск трансформатора: ток намагничивания = 5-10×Iном → без 2nd harmonic block = ложное срабатывание. |
| powersys.ops.reactive_power_compensation | Reactive Power — SVC vs STATCOM | METHOD | Компенсация реактивной мощности: Capacitor banks: дешёвый, ступенчатый. SVC (Static Var Compensator): TSC + TCR: быстрее, непрерывный. STATCOM (Static Synchronous Compensator): VSC-based, лучше при низком напряжении. Capacitor + reactor: shunt compensation. Series capacitor: снижение Xlinha → increased transfer capacity. | STATCOM: независим от напряжения шины (vs SVC → уменьшение Q при снижении V). |
| powersys.ops.energy_market_bidding | Energy Market — LMP Pricing | METHOD | Цены на рынке электроэнергии: LMP (Locational Marginal Price): цена электроэнергии в узле с учётом потерь и заторов. LMP = Energy + Congestion + Loss components. Day-Ahead Market (DAM) vs Real-Time Market (RTM). Capacity Clearing Price (CCP): в рынке мощности. PJM, MISO, ISO-NE, CAISO, SPP: ISOs/RTOs в США. | Зажим (congestion): высокая нагрузка + перегрузка линии → разница LMP (дорогостоящий конец). |
| powersys.ops.substation_grounding | Substation Grounding — IEEE 80 | METHOD | Заземление подстанции (IEEE 80): безопасные пороговые значения шагового и касательного напряжений. Touch voltage: между двумя точками на расстоянии 1 м (рука + нога). Step voltage: между двумя ногами при ходьбе. Grid resistance должна обеспечить безопасные напряжения. Ground Potential Rise (GPR): при КЗ. | Глубина заземления: на 0.5-1 м ниже поверхности (влажный слой почвы). |
| powersys.ops.corona_discharge_hvdc | HVDC — Advantages | METHOD | HVDC (High Voltage Direct Current): преимущества перед HVAC для длинных линий (>500-800 км). Нет реактивной мощности (нет зарядной ёмкости). Асинхронное соединение: разные частоты/системы. Кабельные системы (подводные): HVAC не работает >50-100 км. LCC (Line Commutated Converter): тиристоры, VSC (Voltage Source Converter): IGBT. | Breakeven distance: подводный кабель ~50 км, воздушная линия ~500 км (HVDC vs HVAC). |
| powersys.ops.loss_of_excitation | Loss of Excitation — Distance Relay | METHOD | Потеря возбуждения (LOE) генератора: генератор переходит в режим «недовозбуждённого» → потребляет реактивную мощность → нестабильность. Защита: relay 40 (LOE protection) — distance relay Mho circle на P-Q или R-X plane. При LOE: первый сигнал → снизить нагрузку → если не восстановлено → отключить. | LOE без защиты: потеря синхронизма за секунды. |
| powersys.ops.islanding_microgrid_protection | Microgrid Protection — Adaptive | METHOD | Защита микросетей: традиционные реле рассчитаны на ток КЗ от одного источника (сеть). Microgrid: несколько DER → двунаправленный ток КЗ. Adaptive protection: защита изменяется при переходе grid-connected → island. IED (Intelligent Electronic Devices): цифровые реле. Settings group switching: автоматически при изменении конфигурации. | Стандартная защита не работает в микросетях без модификаций. |
| powersys.ops.feeder_recloser | Distribution Feeder — Recloser | METHOD | Реклозер (Recloser, 79): автоматическое повторное включение при временных замыканиях (удар молнии, ветка). 80-85% замыканий временные. Последовательность: операция (fast) → пауза (dead time) → включение → если снова → операция (slow) × 2-3 → разъединение. Координация с плавкими предохранителями: save-fuse logic. | Recloser: снижает количество устойчивых отключений до 15-20% (vs без = 100%). |
