# BATCH 624: Facade — External Wall Insulation & Finishing

**KnowledgeUnits:** 44
**Namespace:** `facade.ops.*`
**Scope:** EIFS, scaffolding, stucco, cladding, sealant, waterproofing

| ID | KnowledgeUnit | Тип | Суть | Практический смысл |
|---|---|---|---|---|
| facade.ops.eifs_installation | EIFS — External Insulation Finish System | METHOD | Монтаж теплоизоляции: Adhesive → EPS board 50-200 мм → Mechanical fasteners 6-8 шт/м² → Base coat 2-3 мм + fibreglass mesh → Primer → Finish coat (acrylic/silicone штукатурка). Детали: диагональная mesh на углах окон. Drip edge на цоколе. | EPS board: стыки вплотную, не совпадать с проёмами. |
| facade.ops.scaffolding_safety | Scaffolding — Erection & Safety | METHOD | Frame scaffold или tube & coupler. Base plates + screw jacks. Guardrails: top 1-1.2 м, mid rail, toe board. Tie-in каждые 4 м. Доступ: лестница внутри секции. Инспекция: tag system (зелёный/жёлтый/красный). | Ветер >40 км/ч — остановка работ. |
| facade.ops.stucco_three_coat | Stucco — Three-Coat Application | METHOD | Scratch coat 10 мм → процарапать, выдержка 24-48 ч. Brown coat 10 мм → выдержка 7 дней (увлажнять!). Finish coat 3-5 мм (текстурная). Lath: metal galvanized. WRB: два слоя building paper. Curing: mist spray 2-3× в день. | Трещины: главная проблема. Медленное curing критично! |
| facade.ops.joint_sealant_applied | Sealant — Expansion Joint | METHOD | Backer rod (на 25-30% больше ширины шва). Sealant: PU, silicone, MS polymer. Tooling для контакта со стенками. Primer для пористых поверхностей. Adhesion test. | Если sealant прилип к дну — рвётся. Backer rod обязателен. |
| facade.ops.brick_cleaning | Masonry Cleaning | METHOD | Mortar smears: вода + щётка сразу. Acid cleaning (muriatic 1:5-1:10) с предварительным увлажнением. Graffiti: специальные removers. Efflorescence: сухая щётка (не вода!). Sandblasting агрессивно — DOFF/TORC предпочтительнее. | Кислота: НЕ на известняк/мрамор! |
