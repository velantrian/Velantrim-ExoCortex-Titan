| chemistry.atmospheric.chapman_cycle | Chapman Ozone Cycle (1930) | INVARIANT | O₂ + hν(λ<242 нм) → O + O. O + O₂ + M → O₃ + M (М — третье тело для отвода энергии). O₃ + hν(λ<320 нм) → O₂ + O. O₃ + O → 2O₂. Цикл создаёт баланс — озоновый слой на высоте 15-35 км (стратосфера, макс. концентрация ~25 км). | Защита от УФ-B/C (без озонового слоя жизнь на суше была бы невозможна). Открытие антарктической озоновой дыры (Фарман, 1985). |
| chemistry.atmospheric.ozone_depletion | Catalytic Ozone Destruction — CFCs | PROCESS | Хлорфторуглероды (CF₃Cl) фотодиссоциируют в стратосфере → Cl· радикал. Каталитический цикл: Cl· + O₃ → ClO· + O₂; ClO· + O → Cl· + O₂ → Суммарно O₃ + O → 2O₂. Один атом Cl разрушает ~100,000 молекул O₃ до дезактивации (резервуарные газы: HCl, ClONO₂). | Монреальский протокол (1987) — запрет ХФУ. Озоновый слой восстанавливается, ожидается полное восстановление к ~2060-2075 (антарктическая дыра). |
| chemistry.atmospheric.tropospheric_chemistry | Tropospheric Chemistry — OH Radical | INVARIANT | Гидроксильный радикал OH· — «моющее средство атмосферы»: окисляет большинство загрязнителей (CH₄, CO, ЛОС, NO₂). Образуется фотолизом O₃ (O₃ + hν → O₂ + O(¹D)), затем O(¹D) + H₂O → 2OH·. Концентрация: ~10⁶ молекул/см³. | Окислительная способность атмосферы зависит от OH. Метан окисляется OH (CH₄ + OH → CH₃ + H₂O) — важнейший сток парникового газа. |
| chemistry.atmospheric.smog | Photochemical Smog | PROCESS | NOₓ + ЛОС + солнечный свет → O₃ (тропосферный, вредный для дыхания) + PAN (пероксиацетилнитрат, раздражает глаза). Летучие органические соединения от автомобилей и промышленности + NO₂ (бурый газ) + солнце = смог. | Лос-Анджелес, Мехико, Пекин. Борьба: каталитические нейтрализаторы (CO, HC, NOₓ), снижение ЛОС, электромобили. |
| chemistry.atmospheric.acid_rain | Acid Rain — SO₂ & NOₓ | PROCESS | SO₂ (уголь) + H₂O + O₂ → H₂SO₄. NOₓ → HNO₃. pH дождя в норме ~5.6 (CO₂ → H₂CO₃), кислотный дождь pH<5. Последствия: выщелачивание Ca, Mg из почвы, мобилизация Al³⁺ (токсичен для рыб), растворение мрамора (CaCO₃ + H₂SO₄ → CaSO₄ + CO₂ + H₂O). | Десульфуризация дымовых газов (FGD — скрубберы), каталитическое восстановление NOₓ (SCR). Кислотные дожди снижены в Европе и США на 50-80% с 1980-х благодаря регулированию. |
| chemistry.geochemistry.goldschmidt_classification | Goldschmidt Classification of Elements | INVARIANT | Сидерофильные (любящие железо: Fe, Ni, Co, Pt, Au, Pd — в ядре). Халькофильные (любящие серу: Cu, Zn, Pb, As, Cd). Литофильные (любящие камень: Si, Al, Ca, Na, K, Ti, REE — в коре/мантии, образуют оксиды/силикаты). Атмофильные (любящие газ: H, N, O, благородные газы — в атмосфере). | Объясняет распределение элементов в Земле (дифференциация). Почему Cu, Pb, Zn встречаются как сульфидные руды, а Si, Al — как оксиды/силикаты. |
| chemistry.geochemistry.isotope_fractionation | Stable Isotope Fractionation | PROCESS | Кинетический (скорости реакций различаются: лёгкие изотопы реагируют быстрее) и равновесный (более прочные связи для тяжёлых изотопов — предпочтительны в более плотной/упорядоченной фазе). Измерение: δ¹³C = (¹³C/¹²C_образец)/(¹³C/¹²C_стандарт) − 1 ‰. | Палеотемпературы: δ¹⁸O в морских карбонатах (фораминиферы) — холоднее → больше ¹⁸O в CaCO₃. Диета древних людей: δ¹³C различает C3 и C4 растения. |
| chemistry.geochemistry.radiometric_systems | Radiometric Dating Systems | METHOD | ²³⁸U→²⁰⁶Pb (t½=4.47 Mrd л — цирконы, возраст Земли). ⁴⁰K→⁴⁰Ar (t½=1.25 Mrd — вулканические породы). ¹⁴C→¹⁴N (t½=5730 л — органика до 50 тыс л). Sm-Nd, Lu-Hf, Rb-Sr (мантийная эволюция). Изохрона: линия в координатах (⁸⁷Sr/⁸⁶Sr) vs (⁸⁷Rb/⁸⁶Sr), наклон → возраст. | Циркон (ZrSiO₄) — идеальный минерал для U-Pb датирования: захватывает U, но не Pb при кристаллизации. Древнейший циркон Jack Hills (Австралия): 4.4 Mrd лет. |
| chemistry.cosmochemistry.chondrites | Chondrites — Primitive Solar System Matter | INVARIANT | Хондриты — недифференцированные метеориты, представляют состав протосолнечной туманности. Хондры (мм-размера сферические силикатные образования, быстрый нагрев → плавление → застывание < часов). Углистые хондриты (CI) — самый примитивный состав (солнечный, кроме H, He, C, N). | Возраст Солнечной системы (4567.3 ± 0.16 млн лет) определён по CAI (Ca-Al-rich inclusions — тугоплавкие включения в хондритах) U-Pb методом. |
| chemistry.cosmochemistry.presolar_grains | Presolar Grains — Stardust | RECORD | Микроскопические зёрна (SiC, Al₂O₃, графит, наноалмазы) в метеоритах с изотопным составом, НЕ соответствующим Солнечной системе (крайние аномалии). Образовались в атмосферах звёзд (AGB, сверхновые) ДО формирования Солнца. Выделены химическим растворением метеорита. | SiC зёрна: изотопы Kr/Xe (s-процесс), Ti, C — индивидуальные звёздные источники идентифицируемы! Древнейшие твёрдые объекты, доступные для лабораторного анализа (>5 млрд лет). |
