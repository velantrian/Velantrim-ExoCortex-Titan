| mladvanced.ops.backpropagation | Backpropagation — Algorithm | METHOD | Обратное распространение: вычислить ∂L/∂w через chain rule. Forward pass → compute loss. Backward pass: ∂L/∂w = ∂L/∂a × ∂a/∂z × ∂z/∂w. Gradient descent: w ← w - η × ∂L/∂w. Vanishing gradient: в глубоких сетях при sigmoid/tanh. ReLU: снижает vanishing. BatchNorm: ещё один метод. | Exploding gradient: клиппинг градиентов (gradient clipping). |
| mladvanced.ops.cnn_architecture | CNN — Convolutional Architecture | METHOD | Свёрточные нейронные сети: Convolutional layer: feature maps через filters (learnable). Pooling: max-pool (spatial downsampling). Flatten → FC → output. Receptive field: поле видения нейрона. Depth: # channels. Skip connections (ResNet): позволяют обучать 100+ layers. BatchNorm + Dropout. | ResNet: He et al. 2015. Skip connections → vanishing gradient solution. |
| mladvanced.ops.transformer_attention | Transformer — Self-Attention | METHOD | Self-attention механизм: Q = XWQ, K = XWK, V = XWV. Attention(Q,K,V) = softmax(QKᵀ/√dk) × V. Multi-head: несколько параллельных attention heads. Positional encoding: sinusoidal или learned. Encoder-Decoder vs Encoder-only (BERT) vs Decoder-only (GPT). | Квадратичная сложность attention: O(n²d). FlashAttention: более эффективный для длинных последовательностей. |
| mladvanced.ops.bert_pretraining | BERT — Pretraining | METHOD | BERT (Bidirectional Encoder Representations from Transformers): Masked Language Modeling (MLM): 15% токенов маскируется. Next Sentence Prediction (NSP). Bidirectional context: учитывает слева и справа. Fine-tuning: на downstream tasks с дополнительным linear layer. RoBERTa: без NSP + больший batch. | GPT vs BERT: GPT = autoregressive (unidirectional), BERT = bidirectional. |
| mladvanced.ops.gpt_architecture | GPT — Architecture | METHOD | GPT (Generative Pre-trained Transformer): decoder-only transformer. Autoregressive: predicts next token. Pre-training: causal language modeling. Few-shot, zero-shot: via prompting (no gradient update). Emergent abilities: при масштабировании. In-context learning. GPT-4 → GPT-o1 → GPT-4.5 → Claude Claude Sonnet 4.6: размер модели. | Instruction tuning (RLHF): выравнивание с человеческими предпочтениями. |
| mladvanced.ops.gan_training | GANs — Training Dynamics | METHOD | Generative Adversarial Networks: Generator (G) vs Discriminator (D). G пытается обмануть D. D пытается отличить real vs fake. Minmax game. Mode collapse: G генерирует только несколько режимов. WGAN (Wasserstein GAN): снижает mode collapse. DCGAN, StyleGAN, ProGAN. Conditional GAN: генерация по условию. | FID (Fréchet Inception Distance): метрика качества изображений GAN. |
| mladvanced.ops.reinforcement_learning_q | Reinforcement Learning — Q-Learning | METHOD | Q-обучение: Q(s,a) = R + γ × max_a' Q(s', a'). Bellman equation. ε-greedy exploration. DQN (Deep Q-Network, DeepMind 2015): нейросеть аппроксимирует Q-function. Experience Replay Buffer. Target Network. Policy gradient (REINFORCE): напрямую оптимизирует policy. | «Exploration vs Exploitation» trade-off: основная проблема RL. |
| mladvanced.ops.ppo_actor_critic | PPO — Actor-Critic | METHOD | Proximal Policy Optimization (PPO): Policy gradient + clipping для стабильности. Actor: π(a|s, θ). Critic: V(s, φ). Advantage function A(s,a). Clipping objective: min(rt × At, clip(rt, 1-ε, 1+ε) × At). Stable training. RLHF: Reinforcement Learning from Human Feedback = PPO + reward model. | OpenAI InstructGPT: RLHF с PPO = более полезная модель. |
| mladvanced.ops.embedding_word2vec | Embeddings — Word2Vec | METHOD | Word2Vec: Skip-gram vs CBOW. Skip-gram: предсказать контекст из слова. CBOW: наоборот. Negative sampling: эффективное обучение. Свойства: «King - Man + Woman = Queen» (аналогии). GloVe: матрица совместной встречаемости. FastText: символьные n-граммы. Contextual embeddings (BERT): зависит от контекста. | Static embeddings vs contextual: «bank» = одно представление (static) vs разное (contextual). |
| mladvanced.ops.diffusion_models | Diffusion Models — DDPM | METHOD | Диффузионные модели (DDPM, 2020): Forward process: добавлять Gaussian noise поэтапно. Reverse: нейросеть предсказывает noise → вычитает → генерирует изображение. Score matching. Latent Diffusion (Stable Diffusion): в latent space. DALL-E 3: text-to-image. | Diffusion vs GAN: более стабильное обучение, лучшее diversity. Медленнее inference. |
| mladvanced.ops.vision_transformer | Vision Transformer — ViT | METHOD | Vision Transformer (ViT, 2021): Image → patches → flatten → linear projection → Transformer encoder. No convolutions. Position embeddings. [CLS] token → classification. Data-hungry: требует много данных или pre-training (ImageNet-21k, JFT). DeiT: data-efficient ViT. | ViT outperforms CNN at scale. CNN better with less data. |
| mladvanced.ops.contrastive_learning | Contrastive Learning — CLIP | METHOD | Контrastive Learning: учить похожие embedding + разные отдельно. CLIP (OpenAI): image + text pairs → shared embedding space. InfoNCE loss. SimCLR: self-supervised visual. BYOL: без negative examples. MoCo. Downstream tasks: zero-shot classification. | CLIP applications: zero-shot image classification, DALL-E text-image matching. |
| mladvanced.ops.foundation_model | Foundation Models — Scale | METHOD | Фундаментальные модели: pre-trained на massive data → fine-tuned для downstream. Emergent capabilities при масштабировании (>10^23 FLOPs). Chinchilla scaling laws: оптимум данные/параметры. GPT-4: ~1.8T tokens training. LLaMA 3: open-source. | Chinchilla law: Hoffmann et al. 2022. Optimal: N параметров = 20×N tokens. |
| mladvanced.ops.multimodal_llm | Multimodal — LLM Integration | METHOD | Мультимодальные LLM: GPT-4V, Gemini 1.5, Claude 3 Vision. Image encoding: ViT → visual tokens → LLM input. Chain-of-thought multimodal. | Модальностей слияние: раньше separate models per modality → теперь unified transformer. |
| mladvanced.ops.quantization_llm | LLM Quantization — GPTQ | METHOD | Квантизация LLM для inference: GPTQ (Frantar, 2022): post-training quantization, INT4, одноразовый pass через данные. BitsAndBytes: 4-bit (NF4). GGUF (llama.cpp): CPU inference. AWQ (Activation-aware Weight Quantization): лучше точность.
