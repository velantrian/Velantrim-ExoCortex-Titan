| ot.ops.adl_assessment_fim | ADL Assessment — FIM Scale | METHOD | Functional Independence Measure (FIM): 18 задач (6 ADL самообслуживания, 2 контроль сфинктеров, 3 transfers, 2 locomotion, 3 communication, 2 social cognition). Каждый пункт 1-7: 1 = полная помощь (0%), 7 = полная независимость. Total 126 = полная независимость. Используется при реабилитации для документирования прогресса. | FIM чувствительна к изменениям, широко используется в страховании (payment outcomes). |
| ot.ops.home_modification_assessment | Home Modification — Assessment Process | METHOD | Оценка домашней среды: SAFER-HOME (Safety Assessment of Function and Environment for Rehabilitation). Зоны: вход (rampa, поручни), ванная (grab bars, shower bench, raised toilet seat), спальня (bed height, lighting), кухня (counter height, storage). Photography: документировать барьеры. Funding: HISA (Home Independence Special Adaptation — ветеранские), NDIS (Австралия). | Bathroom: наибольший риск падения для пожилых → приоритет. |
| ot.ops.task_analysis_occupation | Task Analysis — Occupational Profile | METHOD | Анализ занятий: разбить задачу на компоненты (subtasks → movements → cognitive steps). Temporal: последовательность. Contextual demands: освещение, шум, пространство. Motor demands: grip strength, coordination, balance. Cognitive demands: memory, sequencing, problem-solving. Sensory: vision, proprioception. Identify performance gaps → intervention targets. | Occupation-focused: не только «функция», но и «смысл занятия для человека». |
| ot.ops.splinting_resting_hand | Splinting — Resting Hand Position | METHOD | Статическая шина покоя для руки: нейтральное функциональное положение. Wrist 20-30° extension. MCP (пальцы) 60-70° сгибание. IP (межфаланговые) 5-10° сгибание. Thumb: opposition/abduction (конусное положение). Материал: low-temperature thermoplastic (LTTP): нагрев 60-70°C, моделировать на пациенте. Edge finishing: flare edges (нет давления). | Шина покоя: используется ночью при ревматоидном артрите, после stroke (спастичность). |
| ot.ops.dynamic_splint_mcp | Dynamic Splinting — MCP Extension | METHOD | Динамическая шина для разгибания пальцев (MCP): после флексорной контрактуры. Low-load prolonged stretch (LLPS): ≤250 г усилие, ≥6 ч/день. TERT (total end range time): накопленное время в конечном положении. Рычаги: attachment на проксимальной фаланге → через outrigger → rubber band тягу к тылу. Мониторинг: ежедневная PROM → прогрессирование. | Сильное растяжение неэффективно (вызывает protective guarding). |
| ot.ops.sensory_integration_ayres | Sensory Integration — Ayres' Theory | METHOD | Сенсорная интеграция (Ayres): мозг организует сенсорную информацию для адаптивного поведения. Нарушения SI: sensory processing disorder, гиперчувствительность (tactile defensiveness) / гипочувствительность. Interventions: sensory diet (structured sensory activities), proprioceptive input (heavy work — carrying, pushing), vestibular (swinging). Sensory gym. | Предупреждение: диагноз SPD не признан в DSM-5 (хотя симптомы реальны). |
| ot.ops.pediatric_developmental_milestones | Pediatric OT — Developmental Milestones | METHOD | Ключевые вехи для ОТ: 0-3 мес — ладонный захват. 6 мес — перекладывание из руки в руку. 9 мес — pincer grip (большой+указательный). 12 мес — шариковый захват в чашку. 2 года — рисование горизонтальных линий, удар по мячу. 3 года — рисование круга, перерезание ножницами. 5 лет — завязывание шнурков (emerging). 6 лет — письмо. | Scotoma: избегать «метки» для родителей — использовать strengths-based language. |
| ot.ops.cognitive_rehabilitation_goal | Cognitive Rehab — Goal Setting | METHOD | Когнитивная реабилитация: SMART goals (Specific, Measurable, Achievable, Relevant, Timely). Domains: orientation, attention, memory, executive function. Interventions: errorless learning (не допускать ошибок при обучении), spaced retrieval (увеличение интервалов), cueing hierarchies. Environmental modifications: calendars, alarms, lists. Metacognitive strategy training: осознание и компенсация. | Errorless learning лучше trial-and-error при тяжёлой amnesia. |
| ot.ops.wheelchair_seating_pressure | Wheelchair Seating — Pressure Mapping | METHOD | Оценка посадки в кресле-коляске: pressure mapping (FSA/XSENSOR): цветная карта давления. Normal pressure: ischial tuberosities несут вес. Риски: давление >32 мм рт.ст. на длительное время = ischemia → пролежни. Cushion selection: air-cell (Roho), foam (Jay), gel (supportive). Tilt-in-space: снижает pressure via weight shift. | Пролежни: профилактика дешевле лечения в 40:1 (AHCPR data). |
| ot.ops.work_hardening_vocational | Work Hardening — Return to Work | METHOD | Work hardening (Hardening program): структурированная программа приближения к рабочим требованиям. Job simulation: выполнение реальных рабочих задач. Physical conditioning: выносливость + силовые. FCE (Functional Capacity Evaluation): объективная оценка максимальных возможностей. Restrictions: lifting limits (light: 10 lb, medium: 20-50 lb, heavy: >50 lb). RTW (Return to Work): graduated schedule. | FCE: используется работодателем, страховой, судом для определения ограничений. |
| ot.ops.dysphagia_screening | Dysphagia — OT Role | METHOD | Нарушение глотания (дисфагия): OT роль (часть команды с SLP). 3-oz water test: 3 унции воды залпом → кашель/мокрый голос = positive. Modified barium swallow (MBSS): рентген исследование (OT/SLP совместно). Texture modified diet (IDDSI framework): жидкости (0-4) и еда (3-7). Positioning: chin tuck, head turn (избегать аспирации). | Dry swallowing (aspirate without cough): «silent aspiration» у stroke — высокий риск пневмонии. |
| ot.ops.grip_pinch_strength | Grip & Pinch Strength — Normative Data | METHOD | Измерение силы кисти: Jamar dynamometer (наиболее валидный). Норма (мужчины 45 лет): 52.6 кг (dominant). Норма (женщины 45 лет): 31.7 кг. Позиция: сидя, плечо 0°, локоть 90°, предплечье нейтрально. Pinch gauge: lateral (key) pinch, tripod, tip-to-tip. Three trials → average. | Bilateral asymmetry >15%: подозрение на патологию или дистрактивное поведение. |
| ot.ops.visual_perceptual_assessment | Visual Perception — Tests | METHOD | Зрительное восприятие: MVPT-4 (Motor-Free Visual Perception Test): воспроизведение по памяти, discrimination, spatial relations, visual closure. TVPS-4 (Test of Visual Perceptual Skills). Domains: figure-ground, visual closure, spatial relations, position in space, visual memory. OT: при low vision rehabilitation, brain injury, learning disabilities. | Zрительная агнозия (stroke): не слепота — видят, но не понимают (vs hemianopia). |
| ot.ops.low_vision_adaptation | Low Vision — Adaptive Strategies | METHOD | Реабилитация слабовидения: magnification (optical: magnifiers, CCTVs; digital: tablet zoom). Contrast enhancement: high-contrast keyboard, dark plate rim. Lighting: task-specific (100-200 lux for reading). Eccentric viewing training: использование функционирующей периферии при центральной скотоме (macula). Orientation and Mobility (O&M): белая трость. | Macular degeneration: central scotoma (центральное поле выпадает) → eccentric viewing essential. |
| ot.ops.ischemic_stroke_upper_limb | Stroke — Upper Limb Neurological Recovery | METHOD | Восстановление руки после инсульта: Brunnstrom stages 1-6 (1 = flaccid, 6 = near-normal). COPM (Canadian Occupational Performance Measure): клиент-центрированная цель. Constraint-induced movement therapy (CIMT): ≥10 ч/нед активной практики. FES (functional electrical stimulation): активирует сгибатели/разгибатели пальца. Task-specific training лучше impairment-focused. | Восстановление руки: наиболее выражено в первые 3 мес, продолжается до 2 лет. |
| ot.ops.pressure_garment_burns | Pressure Garment — Burns Rehab | METHOD | Компрессионные изделия при ожоговых рубцах: 20-25 мм рт.ст. давление (как compression hosiery). Носить 23 ч/сутки на протяжении 12-24 мес (до созревания рубца). Бесцветный гелевый вкладыш (silicone insert): под давлением → ускоряет созревание. Подбор: замеры по контуру ожога. Кастомный или off-the-shelf. Замена каждые 2-3 мес (растягиваются). | Без компрессии: гипертрофический рубец (raised, red, itchy) — труднее исправить позже. |
| ot.ops.driving_rehabilitation | Driving Rehabilitation — Assessment | METHOD | Возобновление вождения после инсульта/TBI: desk screening (MVPT, UFOV, Trail Making Test). Behind-the-wheel evaluation: OT специалист по вождению (CDRS — Certified Driving Rehabilitation Specialist). Adaptive equipment: left-foot accelerator, spinner knob, hand controls. Restrictions: первые 3 мес после stroke (seizure risk). On-road assessment: обязательна для recommending return. | UFOV (Useful Field of View): пространство обработки за 1/10 сек — сильный предиктор accident risk у пожилых. |
| ot.ops.ergonomics_workstation | Ergonomics — Workstation Assessment | METHOD | Эргономика рабочего места: монитор на высоте глаз (или 10-15° ниже), дистанция 50-70 см. Кресло: высота = высота голени (ноги на полу), поясничная поддержка. Клавиатура: ниже уровня локтей, локоть 90-100°. Мышь: рядом с клавиатурой (нет вытягивания плеча). Macro breaks: каждые 20-30 мин. Typing wrist: нейтральная (нет extension). | RULA/REBA: инструменты быстрой оценки позы (Rapid Upper Limb/Entire Body Assessment). |
| ot.ops.mental_health_ot_model | Mental Health OT — Recovery Model | METHOD | Восстановительная модель (Recovery Model) в психическом здоровье: recovery = личный процесс (не только ремиссия). Pillars: Hope (надежда), Agency (самоопределение), Social connection, Meaningful occupation. OT роль: выявить занятия, важные для клиента → постепенно возобновлять. ACT (Acceptance & Commitment Therapy): values-based action. Psychiatric occupational rehabilitation: клубный дом (clubhouse model). | Recovery ≠ cure: человек может иметь симптомы и всё же жить значимой жизнью. |
| ot.ops.orthosis_swan_neck | Orthosis — Swan Neck Deformity | METHOD | Лебединая шея (swan neck): МCP сгибание + PIP переразгибание + DIP сгибание (ревматоидный артрит). Ортез: Silver Ring splint (PIP extension blocking — PIP фиксируется в небольшом сгибании 20-30°). Подгонка: при согнутом PIP. Предотвращает лишнюю гиперэкстензию PIP (не блокирует сгибание). Отличие от boutonniere deformity (PIP сгибание + DIP переразгибание). | Silver Ring splint: серебряный металлический ринг, изготавливается по размеру. |
