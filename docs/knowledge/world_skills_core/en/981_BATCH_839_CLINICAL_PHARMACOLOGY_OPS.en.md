| clinpharm.ops.receptor_types | Receptor Types — G Proteins | METHOD | Типы рецепторов: Gαs (adenylyl cyclase ↑): β-адренорецепторы, D1, H2. Gαi (adenylyl cyclase ↓): α2, D2, M2. | clinpharm.ops.benzodiazepine_gabaa | GABAA Receptor — Benzodiazepine Site | METHOD | ГАМК-А рецептор: ионотропный (Cl⁻ канал). Benzo site: не активирует сам, но усиливает GABA-индуцированный ток. Barbiturates: прямой активатор (сами открывают канал). Flumazenil: benzo антагонист. Активация ГАМК-А → гиперполяризация. Общий анестетик действие: усиление ГАМК-А + ингибирование NMDA. | Барбитураты > Бензодиазепины: по риску передозировки (прямой агонист). |
| clinpharm.ops.opioid_receptor | Opioid Receptors — Subtypes | METHOD | Опиоидные рецепторы: μ (MOR): аналгезия, эйфория, угнетение дыхания, запор. κ (KOR): аналгезия, седация, дисфория. δ (DOR): аналгезия, антидепрессивный. Все Gαi → ↓cAMP + активация K⁺ каналов + ↓Ca²⁺. Полный агонист (морфин) vs частичный (бупренорфин, с высоким аффинитетом = «потолочный эффект»). | Бупренорфин: частичный агонист μ — снижает риск злоупотребления + блокирует другие опиоиды. |
| clinpharm.ops.beta_blocker_pharmacology | Beta-Blockers — Selectivity | METHOD | β-блокаторы: β1 (сердце): снижение ЧСС, сократимости, AV проводимости. β2 (бронхи, сосуды, матка): бронходилатация. Кардиоселективные (β1>β2): метопролол, бисопролол, атенолол. Неселективные: пропранолол, карведилол. ISA (intrinsic sympathomimetic activity): пиндолол, лабеталол. | Неселективные β-блокаторы + диабет: маскируют тахикардию при гипогликемии. |
| clinpharm.ops.ace_inhibitor_pharmacology | ACE Inhibitors — Mechanism | METHOD | ИАПФ (ACE inhibitors): блокируют превращение AngI → AngII. Ангиотензин II: вазоконстрикция + альдостерон + ADH. ИАПФ → вазодилатация + натрий/вода выведение. Bradykinin накопление → кашель (10-20%). ARBs: блокируют AT1 рецептор (нет кашля). ARNI: неприлизин + ARB. | ИАПФ кашель: замените на ARB. Ангионевротический отёк: редкий но опасный побочный эффект. |
| clinpharm.ops.statin_mechanism | Statins — HMG-CoA Reductase | METHOD | Статины: конкурентные ингибиторы ГМГ-КоА редуктазы. ↓ Внутриклеточный холестерин → ↑ LDL рецепторы → ↓ плазменный LDL. Плейотропные эффекты: противовоспалительные, антитромботические. Рабдомиолиз: редкий (CK ↑×10 + миоглобинурия). Ингибиторы CYP3A4 (кларитромицин) ↑ риск рабдомиолиза. | ЛОВАстатин/симвастатин: CYP3A4 metabolized. Розувастатин/правастатин: менее зависимы от CYP3A4. |
| clinpharm.ops.diuretic_mechanisms | Diuretics — Sites of Action | METHOD | Диуретики: Карбоангидразы (CA) ингибиторы (ацетазоламид): PCT (HCO3 потеря). Петлевые (фуросемид): толстое восходящее колено (NKCC2). Тиазиды (гидрохлоротиазид): ДКТ (NCC). Калийсберегающие (спиронолактон): собирательная трубочка (ENaC антагонисты). SGLT2 ингибиторы (дапаглифлозин): проксимальный каналец (глюкоза + Na+ реабсорбция). | Петлевые диуретики: наиболее мощные. Гипокалиемия (НЕ спиронолактон). |
| clinpharm.ops.anticoagulant_targets | Anticoagulants — Mechanisms | METHOD | Антикоагулянты: НФГ: активирует антитромбин III (AT III) → ингибирование тромбина (Ф IIa) + Xa. НМГ: больше анти-Xa. Ривароксабан/апиксабан: прямые анти-Xa. Дабигатран: прямой тромбин-ингибитор. Варфарин: витамин K эпоксид-редуктаза → ↓ II, VII, IX, X синтез. | Варфарин + зеленые овощи: витамин К конкурирует → снижает INR. |
| clinpharm.ops.ssri_adverse | SSRI — Side Effects & Management | METHOD | Побочные эффекты SSRI: Ранние: тошнота, бессонница, тревога, сексуальная дисфункция. SIADH (↓Na+): особенно у пожилых. Akathisia: беспокойство (не паркинсонизм). Серотониновый синдром (при сочетании с MAOI, метиленовым синим): жар + ригидность + клонус. Лечение СС: ципрогептадин. | Серотониновый синдром vs NMS: СС = tachycardia, hyperreflexia, clonus. NMS = bradycardia, rigidity (без clonus). |
| clinpharm.ops.antibiotic_mechanisms | Antibiotic Mechanisms — Cell Wall | METHOD | Механизмы антибиотиков: Пенициллины/Цефалоспорины: ингибиторы PBP (пенициллинсвязывающего белка) → нарушение синтеза КС. Ванкомицин: связывается с D-ala-D-ala → нет синтеза КС. Аминогликозиды: ошибки трансляции (30S рибосома). Хинолоны: ингибиция ДНК-гиразы (топоизомераза II). | Метронидазол: цепи разрыва ДНК (анаэробы + простейшие). |
| clinpharm.ops.anticancer_targeted | Targeted Cancer Therapy — Kinases | METHOD | Таргетная терапия рака: Иматиниб (BCR-ABL TKI): ХМЛ. Gefitinib/Erlotinib (EGFR TKI): НМРЛ. Trastuzumab (anti-HER2): рак молочной железы. Rituximab (anti-CD20): лимфома. Bevacizumab (anti-VEGF): снижение ангиогенеза. CDK4/6 ингибиторы: пalbociclib при РМЖ. | Мутационная терапия: необходимо генетическое тестирование опухоли перед назначением. |
| clinpharm.ops.bronchodilator_mechanisms | Bronchodilators — SABA vs LABA | METHOD | Бронходилататоры: SABA (Short-Acting β2 Agonists): сальбутамол (albuterol), формотерол — используется при приступе. LABA (Long-Acting β2): формотерол, салметерол — поддерживающие. Механизм: β2 → Gαs → cAMP → PKA → расслабление гладких мышц + снижение воспаления. LAMA: ипратропий, тиотропий — М3 антагонисты. | LABA без ICS: не использовать в монотерапии астмы (риск летальных приступов). |
| clinpharm.ops.glucocorticoid_receptor | Glucocorticoids — Transactivation vs Transrepression | METHOD | Глюкокортикоиды (GC): Transactivation: ГК-ГК рецептор → ядро → активация противовоспалительных генов (липокортин-1 → ↓PLA2). Transrepression: ГР прямо ингибирует NFκB + AP-1 → снижение провоспалительных цитокинов. Метаболические эффекты: гипергликемия, остеопороз, надпочечниковая супрессия. | Альтернирующий режим приёма ГК (через день): снижает надпочечниковую супрессию. |
| clinpharm.ops.immunosuppressant_mechanisms | Immunosuppressants — Calcineurin | METHOD | Иммуносупрессанты: Кальциневрин-ингибиторы (Такролимус, Циклоспорин А): FK506 или CSA + cyclophilin/FKBP12 → ингибирование кальциневрина → нет NFAT активации → нет IL-2. MMF (mycophenolate mofetil): IMPDH ингибитор → ↓ гуанозинтрифосфат → ↓ пролиферация лимфоцитов. Sirolimus/Everolimus: mTOR ингибиторы. | Такролимус: нефротоксичный. Мониторинг уровня: 5-12 нг/мл (почки), 5-10 нг/мл (печень). |
| clinpharm.ops.analgesic_ladder_pharmacology | Analgesics — COX Inhibition | METHOD | Анальгетики: Парацетамол: центральный механизм (TRPV1 + CB1). НПВП: ингибирование ЦОГ (COX1 = защита желудка, тромбоксан A2; COX2 = провоспалительные PG). Селективные ЦОГ-2 (целекоксиб): меньше ЖКТ побочных но ↑ ССЗ риск. Опиоиды: оpioid receptor агонисты. | «Старт с простых»: парацетамол → НПВП → слабые опиоиды → сильные. |

Кальциевые антагонисты: изолированная систолическая гипертония, пожилые. Тиазиды: низкая стоимость, хроническая гипертония (↓ ССЗ).
