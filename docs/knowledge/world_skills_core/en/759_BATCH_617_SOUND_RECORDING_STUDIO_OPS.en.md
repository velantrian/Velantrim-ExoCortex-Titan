# BATCH 617: Sound Recording — Studio Engineering Operations

**KnowledgeUnits:** 44
**Namespace:** `recording.ops.*`
**Scope:** DAW, microphone, preamp, mixing, mastering, acoustics, monitoring, session, editing

| ID | KnowledgeUnit | Тип | Суть | Практический смысл |
|---|---|---|---|---|
| recording.ops.mic_placement_stereo | Microphone — Stereo Techniques | METHOD | Стереофоническая запись. XY (Coincident): два кардиоидных микрофона, капсюли максимально близко, угол 90-120°. Хорошая моно-совместимость (нет phase issues). AB (Spaced pair): два omni микрофона на расстоянии 40-60 см (3:1 rule — расстояние между микрофонами минимум в 3 раза больше чем до источника, для минимизации phase). ORTF (near-coincident): кардиоиды на 17 см, 110° (эмулирует уши человека). Mid-Side (M-S): один кардиоид/omni (Mid — центр) + один bidirectional (Side — сторона). Матричное декодирование: Left = M+S, Right = M−S. Регулируемая ширина стерео (side level). | Близкое размещение (proximity effect) для cardioid: усиление басов (<200 Гц) при близкой дистанции. |
| recording.ops.gain_staging_preamp | Gain Staging — Preamp & Converter Levels | METHOD | Правильная установка уровней. Preamp (микрофонный предусилитель): gain устанавливается так чтобы пиковые уровни были около −18 to −12 dBFS (Full Scale) в DAW (не 0 dBFS!). Headroom: 18-20 dB для пиков (транзиенты ударных могут быть +18 dB над RMS). Аналоговый VU-метр: 0 VU = +4 dBu = −18 dBFS (стандарт для США). Конвертор (A/D): не клипповать! Если входной сигнал клиппует вход конвертора — никакие плагины не исправят (квадратная волна). Output: master fader на 0 dB, limiter (ceiling −0.3 to −1 dBFS для предотвращения inter-sample peaks). | Клиент говорит «а можно погромче записать?» — уровень в наушниках (headphone amp), не preamp gain! |
| recording.ops.compression_parallel | Compression — Serial & Parallel Techniques | METHOD | Динамическая обработка. Serial (прямая цепь): Compressor → EQ. Порядок влияет на результат. Parallel (New York compression): дубликат дорожки, сильно сжатый, подмешивается к оригиналу — сохраняет транзиенты + добавляет sustain. Attack (1-20 мс — быстрее = ловит пики), Release (50-300 мс — медленнее = естественнее). Ratio (2:1 gentle, 4:1 moderate, 10:1+ limiting). Threshold. Knee (hard/soft). Sidechain: compressor слушает внешний источник (напр., kick ducking bass). Multiband: отдельная компрессия для разных частотных диапазонов. De-esser: сжатие только в области 5-8 кГц (сибилянты «с-с-с»). | Over-compression: нет динамики (уши устают). |
| recording.ops.reverb_send_return | Reverb — Send/Return Setup | METHOD | Пространственная обработка. Insert vs Send: reverb обычно на send (aux track), а не как insert (чтобы несколько инструментов использовали одно пространство). Pre-fader vs Post-fader: post-fader (уровень реверба меняется с громкостью источника) — стандарт. Pre-fader — для эффектов. Размер room (small room, hall, plate, spring, chamber). Decay time (RT60 — время затухания на 60 dB: 0.5-1 с для room, 2-4 с для hall). Pre-delay (10-30 мс — задержка перед началом реверба, сохраняет чёткость): разделяет источник от пространства. EQ на return (hi-cut 8-12 кГц, low-cut 200-400 Гц — убрать мутность). Early Reflections: первые отражения (дают ощущение размера комнаты). | Слишком много реверба: мутный микс. |
| recording.ops.mastering_level_loudness | Mastering — LUFS & Final Level | METHOD | Финальная обработка. Loudness Normalisation (стриминг): Spotify −14 LUFS Integrated, YouTube −14, Apple Music −16 LUFS. True Peak: −1 dBTP (избегать межпикового клиппинга при lossy сжатии). Эквалайзер (mastering EQ): широкие Q (0.5-1 октава), subtle (±1-3 dB). Stereo width: sub-bass (ниже 150 Гц) — mono (для воспроизведения на клубах). Limiter: transparent (FabFilter Pro-L, iZotope Ozone). Dither: при переходе с 24-bit на 16-bit (для CD). Секвенция: паузы между треками (2-3 сек), уровни consistent. | Конкуренция по громкости (Loudness War) закончилась — loudness normalisation выровняло. |
