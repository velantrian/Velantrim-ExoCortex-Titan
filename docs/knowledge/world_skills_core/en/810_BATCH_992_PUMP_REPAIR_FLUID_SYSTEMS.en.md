# BATCH 668: Pump — Repair & Fluid System Operations

**KnowledgeUnits:** 50
**Namespace:** `pumprepair.ops.*`
**Scope:** centrifugal, gear, peristaltic, seal_replacement, alignment, cavitation, impeller, priming

| ID | KnowledgeUnit | Тип | Суть | Практический смысл |
|---|---|---|---|---|
| pumprepair.ops.centrifugal_troubleshoot | Centrifugal Pump — Troubleshooting | METHOD | Диагностика центробежного насоса. Нет подачи: не примирован, воздух на всасе, высокий static head. Сниженная подача: partial blockage, wear ring wear, incorrect rotation (обратное вращение — 30% производительности!). Повышенное потребление тока: over-pressure, перегруженная жидкость (density). Вибрация: cavitation, imbalance, misalignment. Шум (grinding): bearing failure. Утечка из сальника: wear, high pressure. Primer centrifugal: должны быть полностью заполнены перед пуском (dry run = damage в секунды!). | Кавитация (cavitation): звук «щебетания», образование пузырьков при локальном снижении давления. |
| pumprepair.ops.mechanical_seal_replace | Mechanical Seal — Replacement | METHOD | Замена торцевого уплотнения. Разборка: снять coupling, motor support, backplate, impeller (lock impeller, loosen shaft nut). Стационарное кольцо (stationary seat): в stuffing box — вытащить (аккуратно, не касаться уплотняющей поверхности). Вращающееся кольцо (rotary face): снято со вала. Cleaning: shaft, stuffing box. Установка нового seal: lubricant (IPA или water, не petroleum), не капать на ceramic face! Компрессия seal spring: 2-4 мм. Flatness: seat должен быть perfectly flat (не tilted). Тест: пуск на холостом, проверка утечки (капли/мин). | Ceramic faces: не касаться руками (жирный след = расцарапывание). |
| pumprepair.ops.alignment_laser | Shaft Alignment — Laser Method | METHOD | Выравнивание валов насоса и двигателя. Типы несоосности: angular (угловая, оси пересекаются), parallel/offset (параллельная, оси смещены). Инструмент: Rotalign, SKF laser system. Крепление датчиков: на обоих полумуфтах. Измерение: вращение обоих валов (пошагово или непрерывно). Расчёт: система показывает shim values и foot adjustments. Допуски (по муфте): <0.05 мм для высокооборотных, <0.1 мм для низкооборотных. Soft foot check: каждая лапа motor checked (jack test). | Misalignment: преждевременный wear bearing + seal failure. |
| pumprepair.ops.npsh_cavitation_prevent | NPSH — Cavitation Prevention | METHOD | Предотвращение кавитации. NPSH (Net Positive Suction Head): NPSHA (доступный) > NPSHR (требуемый насосом) на 0.5-1 м margin. Увеличение NPSHA: понизить насос (closer to liquid level), увеличить pipe size (снизить velocity head losses), снизить temperature жидкости (выше vapor pressure = меньше NPSHA), increase suction pressure. Признаки кавитации: noise (грохот), vibration, резкое снижение производительности, erosion impeller/volute. | При кавитации: насос не работает, а уничтожается. |
| pumprepair.ops.pump_curve_operating_point | Pump Curve — Operating Point | METHOD | Рабочая точка насоса. Pump curve: H (head) vs Q (flow) — снижение напора с ростом расхода. System curve: H = static head + dynamic losses (velocity head + friction). Пересечение pump curve и system curve = operating point. Если operating point влево от BEP (Best Efficiency Point): low flow, high head, recirculation, vibration. Если вправо: low head, high flow, возможен кавитация. Регулировка: trimmed impeller (меньший диаметр → сниженная head/flow), VFD (изменение оборотов — все параметры пропорционально меняются по законам подобия). | Affinity laws: Q∝n, H∝n², P∝n³. |
