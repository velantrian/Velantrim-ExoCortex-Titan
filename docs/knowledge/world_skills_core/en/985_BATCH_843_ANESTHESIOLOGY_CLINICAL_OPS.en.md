| anesthesia.ops.asa_classification | ASA Physical Status Classification | METHOD | Физический статус ASA: ASA I: здоровый. II: лёгкое системное заболевание. III: серьёзное системное заболевание. IV: серьёзное угрожающее жизни. V: умирающий (не выживет без операции). VI: смерть мозга (для донора органов). Суффикс «E»: экстренная операция. | ASA ≥ III: консультация анестезиолога необходима заранее. |
| anesthesia.ops.volatile_agents | Volatile Anesthetics — MAC | METHOD | Ингаляционные анестетики: MAC (Minimum Alveolar Concentration): концентрация при которой 50% пациентов не двигаются при хирургическом разрезе. Sevoflurane (MAC 1.8% в О2): наиболее используемый. Desflurane (MAC 6.6%): быстрый выход, ↑ тахикардия. Isoflurane (MAC 1.2%): дешевле. N₂O (MAC 104%): только в комбинации. | MAC снижается: пожилой возраст, гипотиреоз, гипотермия, препараты. |
| anesthesia.ops.propofol_induction | Propofol — TIVA | METHOD | Пропофол (2,6-дисопропилфенол): индукция 1-2.5 мг/кг (IV). Обслуживание: 4-12 мг/кг/ч (TIVA). Время действия: 3-5 мин. Механизм: GABAa потенцирование. PRIS (Propofol Infusion Syndrome): при высоких дозах >4 мг/кг/ч × >48ч. Болезненный: при инъекции в периферический доступ. | Пропофол + фентанил: синергизм → снизить дозы каждого. |
| anesthesia.ops.sugammadex_reversal | Sugammadex — NMB Reversal | METHOD | Сугаммадекс: модифицированный гамма-циклодекстрин. Обёртывает рокурониум (+ векурониум) → полная инактивация. Дозировка: глубокий блок (PTC ≥2) = 16 мг/кг. Умеренный = 4 мг/кг. Поверхностный = 2 мг/кг. Немедленный реверс (emergency): 16 мг/кг. Мгновенный эффект (2 мин). | Сугаммадекс vs неостигмин: сугаммадекс = более полный, быстрый, без холинергических эффектов. |
| anesthesia.ops.spinal_epidural | Spinal vs Epidural Anesthesia | METHOD | Региональная анестезия: Спинальная (subаrachnoid block): игла до CSF → непосредственное введение LA (бупивакаин 0.5%, 2-4 мл). Высокий блок (С4): опасность. Гипотензия: после спинальной (симпатэктомия). Эпидуральная: катетер в эпидуральном пространстве → болюс или инфузия. Более управляемая. | Тест-доза эпидурала: 3 мл 1.5% лидокаин + адреналин → ЧСС ↑ при IV = предотвращение токсичности. |
| anesthesia.ops.difficult_airway | Difficult Airway — ASA Algorithm | METHOD | Трудные дыхательные пути (ASA DAS): Pre-oxygenation. Если интубация неудачна → Try again (max 3 attempts) → Call for help → SGA (LMA). Если вентиляция невозможна (CICO: Can't Intubate, Can't Oxygenate) → Front of Neck Access (FONA). Cricothyroidotomy. | Мнемоника LEMON: Look, Evaluate (3-3-2 rule), Mallampati, Obstruction, Neck mobility. |
| anesthesia.ops.ponv_prevention | PONV — Apfel Score | METHOD | Профилактика тошноты/рвоты (PONV): Apfel Score (0-4): женский пол, некурящий, история PONV/укачивания, послеоперационные опиоиды. Score 0: риск 10%. Score 4: риск 80%. Лечение: ондансетрон (5-HT3), дексаметазон, дроперидол, скополамин. Комбинация для высокого риска. | Apfel Score ≥2: профилактика двумя препаратами. ≥3: тремя. |
| anesthesia.ops.ketamine_anesthesia | Ketamine — Mechanism | METHOD | Кетамин: NMDA антагонист. Диссоциативная анестезия + аналгезия. Сохранение защитных рефлексов дыхательных путей. Симпатомиметический эффект: ↑АД + ↑ЧСС. Применение: педиатрия, процедуральная анестезия, аналгезия при травме. Гемодинамически нестабильные. | Кетамин + бензодиазепин: снижение галлюцинаций. Не при внутричерепной гипертензии. |
| anesthesia.ops.pediatric_induction | Pediatric — Inhalation Induction | METHOD | Педиатрическая анестезия: индукция севофлюраном (менее раздражающий). Масочная индукция: 8% севофлюран + NO₂ в О₂. Расчёт дозы: по весу. Tracheotomy size: (age/4 + 4) мм для неманжетных (теперь манжетные стандарт). IV доступ после индукции. Затылочный приоритет: голова пропорционально большая → риск флексии. | Ларингоспазм у детей: CPAP + пропофол 0.5-1 мг/кг + сукцинилхолин при не поддающемся. |
| anesthesia.ops.local_anesthetic_toxicity | Local Anesthetic — LAST | METHOD | Системная токсичность LA (LAST): высокая доза или IV инъекция. ЦНС симптомы: металлический привкус → судороги. Сердечно-сосудистые: аритмии → ПЭА/ФЖ. Лечение: остановить инъекцию → дыхательные пути → Intralipid 20% (1.5 мл/кг болюс). Ropivacaine < Bupivacaine: менее кардиотоксичный. | Intralipid «lipid sink»: связывает жирорастворимый LA → снижает токсичность. |
| anesthesia.ops.neuromuscular_monitoring | Neuromuscular Monitoring — TOF | METHOD | Мониторинг нервно-мышечного блока: Train-of-Four (TOF): 4 импульса → считать ответы (4 = minimal block). TOF ratio: T4/T1 ≥0.9 = no significant residual block. PTC (Post-Tetanic Count): при глубоком блоке. Double Burst Suppression (DBS): более чувствительный для определения TOF ratio. | TOF <0.9 при экстубации: риск аспирации + дыхательная недостаточность. |
| anesthesia.ops.analgesia_multimodal | Multimodal Analgesia — ERAS | METHOD | Мультимодальная анальгезия: ERAS (Enhanced Recovery After Surgery). Компоненты: Парацетамол + НПВП (COX2) + регионал. Избегать опиоиды или снизить (opioid-sparing). Дексаметазон: аналгетический + PONV профилактика. Кетамин: суб-анестетический. Лидокаин: IV инфузия. | ERAS протоколы: коронаротические + колоректальные → снижают LOS. |
| anesthesia.ops.acute_pain_service | Acute Pain Service — Protocols | METHOD | Служба острой боли: APS (Acute Pain Service): послеоперационный мониторинг + управление. Протоколы: PCA (Patient-Controlled Analgesia). Эпидуральная инфузия: bupivacaine + fentanyl. Регионал: TAP block, ESPB. NRS (Numerical Rating Scale) каждые 4ч. Opioid adverse effects management: naloxone, laxatives, antiemetics. | PCA + basal rate: не улучшает обезболивание у взрослых + ↑ побочные. |
| anesthesia.ops.hypotensive_spinal | Spinal Hypotension — Prevention | METHOD | Гипотензия после спинальной анестезии: частота 30-70% при кесаревом. Профилактика: кристаллоид co-load + фенилэфрин инфузия (100-200 мкг/мин). Co-loading (одновременно с SA) лучше чем preloading. Если брадикардия + гипотензия: атропин + эфедрин. Левый наклон: декомпрессия нижней полой вены. | Профилактическая инфузия фенилэфрина при кесаревом: стандарт у большинства центров. |
| anesthesia.ops.icu_sedation | ICU Sedation — PAD Guidelines | METHOD | Седация в ОРиТ (PAD Guidelines 2018): PADIS (Pain, Agitation/Sedation, Delirium, Immobility, Sleep). Цели: Light sedation (RASS 0 до -2). Ежедневные «пробуждения» (SAT + SBT). Дексмедетомидин: предпочтительнее при делирии (vs бензодиазепины). Ранняя мобилизация. | CAM-ICU/ICDSC: скрининг делирия в ОРиТ (обязательный). |
| anesthesia.ops.malignant_hyperthermia | Malignant Hyperthermia — Treatment | METHOD | Злокачественная гипертермия (ЗГ): гиперметаболизм мышц (RYRI мутация) при галогеновых агентах/сукцинилхолине. Признаки: ↑ ETCO2, ↑Т°, ригидность, рабдомиолиз. Лечение: остановить триггеры → дантролен 2.5 мг/кг IV (повторять до ETCO2 норм) → охладить → реанимация. | Дантролен: единственный специфический препарат. Не задерживать. Стоковой запас в ОР. |
| anesthesia.ops.awake_craniotomy | Awake Craniotomy — Technique | METHOD | Краниотомия в сознании: для функциональной нейрохирургии (моторные/речевые зоны). Методика: Sedation (MAC/dexmedetomidine) → scalp block → awake mapping → re-sedation. Тест речи, движения. TIVA с пропофолом. Психологическая подготовка пациента. | Asleep-awake-asleep: anaesthesia для первого и последнего этапов, awake для маппинга. |
