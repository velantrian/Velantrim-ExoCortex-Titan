|---|---|---|---|---|
| controlsys.ops.transfer_function | Transfer Function — Laplace Domain | METHOD | Передаточная функция: G(s) = Y(s)/U(s) в Лапласовской области. Полюса (знаменателя нули): стабильность. Нули (числителя нули): отклик. Единичная обратная связь: Closed-loop T(s) = G(s)/(1+G(s)H(s)). Характеристическое уравнение: 1+G(s)H(s) = 0. DC gain: G(0). | Полюса в левой полуплоскости: стабильная система. В правой: нестабильная. |
| controlsys.ops.root_locus | Root Locus — Design | METHOD | Метод корневого годографа: как корни перемещаются при изменении K. Правила: начало у полюсов G(s)H(s), конец у нулей. Угол отправления/прихода. Точки пересечения Real axis. Центроид асимптот: (Σpolюса - Σнули)/(n-m). Проектирование: выбор K для желаемых полюсов. | Root Locus: инструмент для настройки коэффициента усиления. |
| controlsys.ops.bode_plot | Frequency Response — Bode Plot | METHOD | Диаграмма Боде: Amplitude Ratio (dB) vs ω (log). Phase vs ω (log). Gain Crossover frequency ωgc: |G(jω)| = 0 dB. Phase Crossover ωpc: ∠G(jω) = -180°. Gain margin: 1/|G(jωpc)| dB. Phase margin: 180° + ∠G(jωgc). GM > 6 dB + PM > 45°: хорошая устойчивость. | Большой PM: медленный отклик. Малый PM: быстрый но нестабильный. |
| controlsys.ops.nyquist_stability | Nyquist — Stability Criterion | METHOD | Критерий Найквиста: Z = N + P. Z = правополосные нули замкнутой. N = обходы (-1, 0) по часовой. P = правополосные полюса разомкнутой. Z = 0 для стабильности. Contour: охватывает правую полуплоскость. Упрощение: если P=0, то N=0 для стабильности. | Найквист vs Боде: Найквист точнее для нестандартных систем. |
| controlsys.ops.pid_ziegler_nichols | PID — Ziegler-Nichols Tuning | METHOD | Настройка по Циглеру-Николсу: Метод реакции (Step response): K = slope/ultimate gain. Метод предельного усиления: усилить K до незатухающих осмсколебаний → Ku, Tu. PID: Kp = 0.6 Ku, Ti = Tu/2, Td = Tu/8. Ограничения: консервативный для некоторых процессов. | Cohen-Coon: улучшенный метод для первого порядка + чистая задержка. |
| controlsys.ops.state_space | State Space — Representation | METHOD | Пространство состояний: ẋ = Ax + Bu, y = Cx + Du. A: матрица динамики. B: матрица входа. C: матрица выхода. D: прямая связь. Наблюдаемость + управляемость: условия для проектирования. Решение: x(t) = e^At x(0) + ... Eigenvalues(A) = полюса. | Pole placement (Ackermann formula): выбор желаемых eigenvalues → находим K. |
| controlsys.ops.observer_design | Observer — Luenberger | METHOD | Наблюдатель Луенбергера: оценка состояния из измерений. ẋ̂ = Aх̂ + Bu + L(y - Cх̂). L = gain matrix. Eigenvalues наблюдателя: быстрее чем полюса регулятора (~3-5×). Separation principle: регулятор и наблюдатель проектируются независимо. Kalman filter: оптимальный наблюдатель при шуме. | Kalman Filter: BLUE (Best Linear Unbiased Estimator). |
| controlsys.ops.digital_control_sampling | Digital Control — Sampling | METHOD | Цифровое управление: Теорема дискретизации Шеннона: fs ≥ 2f_max. ZOH (Zero-Order Hold): удерживает между выборками. Tustin (bilinear) transform: s → 2/T × (z-1)/(z+1). Z-domain. Stability: все полюса внутри единичного круга. Anti-aliasing filter: перед АЦП. | Practical sampling: fs = 5-20× bandwidth (не только 2×). |
| controlsys.ops.cascade_control | Cascade Control — Inner-Outer Loop | METHOD | Каскадное управление: внутренний (fast) + внешний (slow) контроллер. Inner: быстрее (отклонения подавляются раньше). Outer: управляет setpoint для inner. Применение: температура реактора (внешний) + расход охладителя (внутренний). | Правило: Inner loop должен быть в 5-10× быстрее outer loop. |
| controlsys.ops.feedforward_control | Feedforward — Disturbance Rejection | METHOD | Опережающее регулирование (Feedforward): компенсирует до нарушения достигнет процесса. FF = -Gd(s)/Gp(s). Не требует обратной связи с отклонением. Идеальный FF: полная компенсация (нереально — неточные модели). Комбинирование: FF + FB = наилучший. | FF быстро, FB надёжно: комбинация = optimal. |
| controlsys.ops.anti_windup | Integrator Windup — Anti-Windup | METHOD | Интегратор Windup: при насыщении актуатора → integrator accumulates → при снятии ограничения → пересыщение. Anti-windup methods: conditional integration (остановить при sat), back-calculation. Conditional integration: стоп интегрирования при насыщении + ошибка правильного знака. | Без anti-windup: большие отклонения при снятии ограничений (windup response). |
| controlsys.ops.model_predictive | MPC — Model Predictive Control | METHOD | МРС (Model Predictive Control): оптимизация на горизонте предсказания N. Ограничения: входные + выходные. Online optimization (QP). Receding horizon. Industrial use: нефтехимия, HVAC, автономные авто. Computational load: обновлено каждый цикл. | MPC handles constraints explicitly (vs PID implicitly). |
| controlsys.ops.frequency_domain_robustness | Robust Control — H∞ | METHOD | Робастное управление (H∞): минимизация H∞ norm = max singular value. Uncertainty bounds. Sensitivity function S(s). Complementary sensitivity T(s). Mixed-sensitivity problem. Small gain theorem. MATLAB Robust Control Toolbox. | H∞ control: гарантированная стабильность при bounded uncertainty. |
| controlsys.ops.nonlinear_control | Nonlinear Systems — Lyapunov | METHOD | Нелинейные системы: Метод Ляпунова: найти V(x) > 0 such that dV/dt < 0 → стабильность. Квадратичная форма: V = xᵀPx. SDRE (State Dependent Riccati Equation): нелинейный LQR. Linearization: Taylor expansion at equilibrium. | Lyapunov: глобальная стабильность если V радиально несвязана. |
| controlsys.ops.optimal_control_lqr | LQR — Linear Quadratic Regulator | METHOD | Линейный квадратичный регулятор (LQR): минимизировать J = ∫(xᵀQx + uᵀRu)dt. Q: вес состояний. R: вес управлений. Optimal gain K = R⁻¹BᵀP, где P решает Riccati equation. Trade-off Q vs R: больший Q → агрессивный, больший R → экономный. | LQR: системы без ограничений. MPC: с ограничениями. |
| controlsys.ops.delay_systems | Time Delay — Smith Predictor | METHOD | Системы с чистым запаздыванием (dead time): τd — задержка транспортирования. Smith Predictor: внутренняя модель без задержки + компенсация задержки. G(s)e^(-τs). Delay margin = Phase margin / ω×τ. | Large dead time systems: θ/τ > 0.5 → труден для обычного PID. |
