| transeng.ops.traffic_flow_theory | Traffic Flow — LOS | METHOD | Уровень обслуживания (LOS, HCM): LOS A (свободный поток), B (умеренно свободный), C (стабильный, некоторые задержки), D (приближение к нестабильному), E (нестабильный, максимальная плотность), F (принудительный, стоп-и-вперёд). Измерение: delay (seconds/vehicle) для сигнализированных пересечений. v/c ratio. PCE (passenger car equivalents). | LOS D: обычный стандарт проектирования для городских коридоров. |
| transeng.ops.stopping_sight_distance | Highway Design — Stopping Sight Distance | METHOD | Расстояние видимости для остановки (SSD): SSD = d_reaction + d_braking. d_reaction = 0.278 × V × 2.5 (for 85th % reaction time). d_braking = V² / (254 × f) (f = friction factor, зависит от скорости). Design Speed: определяет все геометрические элементы. AASHTO Green Book: source. Crest vertical curves: SSD governs. | Дизайн горной дороги vs равнинной: минимальные K-values отличаются. |
| transeng.ops.intersection_channelization | Intersection Design — Channelization | METHOD | Канализация пересечений: Raised channelizing islands: направляют потоки. Turning radius: минимальный для расчётного ТС. Control delay: параметр оценки LOS. Left-turn lanes: при volume >100 pcph. Right-turn channelized slip ramp: при высоком правороте. Bike lanes: отдельные или shared turn lanes. | Channelization без светофора: особенно эффективна при дисбалансе потоков. |
| transeng.ops.roundabout_design | Roundabouts — Geometric Standards | METHOD | Кольцевые пересечения: Single-lane: диаметр вписанного круга (ICD) 30-40 м. Multi-lane: до 55 м. Yield control на въезде. Splitter islands: направляют + снижают скорость на въезде. Benefits: снижение аварий с тяжёлыми последствиями на 75-90%. Pedestrian: crossings на splitter island. | Roundabouts vs signals: roundabout = 40% снижение задержек (при низких объёмах). |
| transeng.ops.freeway_on_ramp | Freeway — Weaving Analysis | METHOD | Анализ плетений (weaving) на перегонах автомагистрали: weaving volume + freeway volume → Vw. Lane configuration type (A, B, C). Volume ratio = Vw / Vt. LOS для зон плетения: по HCM 6th Edition. Acceleration/Deceleration lanes: длина по расчётной скорости. AASHTO on-ramp taper: standard. | Weaving segment: short → low LOS → necessitate collector-distributor roads. |
| transeng.ops.pedestrian_crosswalk | Pedestrian Safety — Design | METHOD | Пешеходная безопасность: Crosswalk placement: у пересечения (не в середине квартала). Refuge islands: при ширине дороги >6 полос. Curb ramps: ADA compliant (1:12). LPI (Leading Pedestrian Interval): пешеходы начинают раньше ТС (7 сек). HAWK signal: пешеходный светофор (середина блока). In-roadway warning lights. | High-Intensity Activated CrossWalk (HAWK): снижает конфликты на 29% (FHWA). |
| transeng.ops.sight_line_horizontal | Horizontal Alignment — Sight Lines | METHOD | Горизонтальное выравнивание: Minimum radius: R = V² / (127 × (e + f)). e = superelevation (до 10%), f = side friction factor. Stopping sight distance на кривых: смещение оси к обочине ограничивает видимость. Spiral transitions: соединяют прямые с кривыми (уменьшает резкое изменение кривизны). Sight obstruction: обрезать растительность, убрать ограждения. | Superelevation 10% (emax): при скорости 120 км/ч максимально. |
| transeng.ops.pavement_design_aashto | Pavement Design — AASHTO Method | METHOD | Проектирование дорожной одежды (AASHTO 1993): SN (Structural Number) = a1D1 + a2D2m2 + a3D3m3. Layer coefficients (a): асфальт = 0.44, гранулярный основание = 0.14. Drainage modifiers (m). ESALs (Equivalent Single Axle Loads): расчётная нагрузка. Subgrade resilient modulus (Mr). Reliability (95% для интерстейта). | ESALS: тяжёлые ТС = в 1000× больше ESALs, чем легковые (4th power law). |
| transeng.ops.traffic_signal_timing | Traffic Signal — Cycle Length | METHOD | Оптимальная длина цикла (Уэбстер): C₀ = (1.5 L + 5) / (1 - Y). L = total lost time. Y = sum of critical volume-capacity ratios. Для городского пересечения: C₀ ≈ 60-120 сек. Splits: распределение зелёного пропорционально объёмам. Координация: band width + offset для прогрессивных систем. Adaptive: SCATS, SCOOT, InSync. | Pedestrian crossing time: min 3.5 fps для пожилых vs 4.0 fps для молодых. |
| transeng.ops.road_safety_audit | Road Safety Audit — Process | METHOD | Аудит безопасности дорог (RSA): формальная проверка проекта/существующей дороги специалистами по безопасности. Stages: Feasibility, Preliminary Design, Detailed Design, Construction, Opening, In-Service. Findings: risk, recommendation, timing. Independent team: не вовлечённый в проект. BCR: benefit-cost ratio для приоритизации. | RSA снижает accidents: stage 2-3 RSA → 60% более дешёвые исправления vs в строительстве. |
| transeng.ops.itsv_its | Intelligent Transportation Systems | METHOD | ITS (Интеллектуальные транспортные системы): ATMS (Advanced Traffic Management): CCTV + TMC. | transeng.ops.road_markings_standards | Road Markings — MUTCD Standards | METHOD | Разметка дорог (MUTCD, USA): Белые линии: разделение потоков одного направления. Stop lines. Thermoplastic markings: более долговечные. | Retroreflectivity: светоотражательность ночью — требование MUTCD для поддержания разметки. |
| transeng.ops.at_grade_rail_crossing | Rail-Highway Crossing — Safety | METHOD | Железнодорожные переезды в одном уровне: Passive warning (для тихих дорог): advance warning signs + pavement markings. Active warning: flashing lights + gates. Predictor algorithm: closure time based on train speed. Wayside horn: снижение шумового загрязнения. Grade separation: наилучшее решение. QZSS: train detection system. | 90% railroad crossing accidents: происходят при наличии предупреждений (human factor). |
| transeng.ops.travel_demand_forecasting | Travel Demand — Four-Step Model | METHOD | Четырёхшаговая транспортная модель: Trip Generation (количество поездок). Trip Distribution (O-D матрица). | transeng.ops.geometric_design_vertical | Vertical Alignment — K-values | METHOD | Вертикальная планировка: K-value: расстояние, необходимое для изменения уклона на 1%. Grade: max 8-10% (mountains), max 5% (freeways). Minimum grade: 0.5% (drainage). | Шире K → мягче кривая, выше SSD. Minimum K в зависимости от design speed. |
