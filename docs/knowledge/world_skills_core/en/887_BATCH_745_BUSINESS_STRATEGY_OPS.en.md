| bizstrategy.ops.porter_five_forces | Porter's Five Forces Analysis | METHOD | Пять сил Портера: Угроза новых участников (barriers to entry). Угроза substitutes (заменителей). Переговорная сила покупателей. Переговорная сила поставщиков. Внутриотраслевая конкуренция (rivalry). Высокая сила = ↓ прибыльность. Низкая привлекательность: если несколько сил высокие. | Ошибка: анализировать в статике. Нужно отслеживать изменения сил во времени. |
| bizstrategy.ops.value_chain_analysis | Value Chain — Primary & Support | METHOD | Цепочка ценности (Портер): Primary: Input logistics → Operations → Output logistics → Marketing & Sales → Service. Support: Firm infrastructure, HR, Technology, Procurement. Value = Margin + Cost. Analysed по VRIN: Valuable, Rare, Inimitable, Non-substitutable. Competitive advantage = уникальная activity или комбинация. | Outsource: деятельность без конкурентного преимущества → focus on core. |
| bizstrategy.ops.blue_ocean_strategy | Blue Ocean — ERRC Grid | METHOD | Стратегия голубого океана (Ким & Мобурн): Blue Ocean = создание нового рыночного пространства. ERRC Grid: Eliminate (устранить), Reduce (снизить), Raise (увеличить), Create (создать). Strategy Canvas: кривая ценности vs конкуренты. Non-customers: три яруса. Пример: Cirque du Soleil = без животных, без звёзд + театр. | Red Ocean = борьба в существующем пространстве (zero-sum). |
| bizstrategy.ops.disruptive_innovation | Disruptive Innovation — Christensen | METHOD | Подрывные инновации (Кристенсен): Sustaining innovation: улучшение существующего (для текущих клиентов). Disruptive: начинает на нижних сегментах (хуже по key attributes) → улучшается → поднимается → побеждает мейнстрим. Low-end disruption: нижний сегмент. New-market disruption: несовершённые пользователи. | Incumbent response: обычно игнорируют disruption (их клиенты — premium, не bottom). |
| bizstrategy.ops.okr_framework | OKRs — Setting Framework | METHOD | OKR (Objectives and Key Results): Objective: амбициозный, качественный, мотивирующий. Key Results: 3-5 на каждый Objective, измеримые, отслеживаемые. Scoring: 0.0-1.0 (0.7 = успех, 1.0 = слишком легко). Google/Intel: исходный. Stretch goals: 70% выполнения = успех. OKRs ≠ Performance Review. | CFRs (Conversations, Feedback, Recognition): поддерживают OKR culture. |
| bizstrategy.ops.balanced_scorecard | Balanced Scorecard — Kaplan Norton | METHOD | Сбалансированная система показателей (BSC): 4 перспективы. Financial: что для акционеров? Customer: что для клиентов? Internal Processes: в чём преуспеем? Learning & Growth: как будем развиваться? Strategy Map: причинно-следственные связи между перспективами. KPIs per perspective. | BSC = система коммуникации стратегии, не только измерений. |
| bizstrategy.ops.ansoff_matrix | Ansoff Matrix — Growth Options | METHOD | Матрица Ансоффа: Market Penetration (текущий продукт, текущий рынок): наименее рискованный. Product Development (новый продукт, текущий рынок). Market Development (текущий продукт, новый рынок). Diversification (новый продукт, новый рынок): наиболее рискованный. Synergistic diversification. | «Related diversification»: общие ресурсы, синергия. «Unrelated»: конгломерат. |
| bizstrategy.ops.competitive_intelligence | Competitive Intelligence — Sources | METHOD | Конкурентная разведка: OSINT (open sources): патенты, рабочие вакансии (указывают направления развития), LinkedIn, SEC filings, trade press, job descriptions. Win/loss analysis. Customer interviews. HUMINT (конференции, нетворкинг). NDA-friendly. | Patent surveillance: конкурент подаёт заявку на patent → signal about R&D direction. |
| bizstrategy.ops.scenario_planning | Scenario Planning — Shell Method | METHOD | Сценарное планирование: два наиболее неопределённых, важных фактора → 4 квадранта сценария. Каждый сценарий: narrative, implications, early warning signals. Robust strategy: работает во всех сценариях. Regrets-based strategy: minimize worst case. Royal Dutch Shell: pioneer (использовали в 1970-х нефтяном кризисе). | Сценарий ≠ прогноз. Сценарий = «если X произойдёт, что сделаем?» |
| bizstrategy.ops.generic_strategies | Generic Strategies — Porter | METHOD | Дженериковые стратегии Портера: Cost Leadership: самая низкая цена на рынке. Differentiation: уникальность, premium. Cost Focus: низкая цена в нише. Differentiation Focus: дифференциация в нише. Stuck in the Middle: не одна стратегия. IKEA = cost leadership + some differentiation. | «Fit»: согласованность активностей внутри компании = устойчивое конкурентное преимущество. |
| bizstrategy.ops.platform_economics | Platform Strategy — Network Effects | METHOD | Платформенный бизнес: Network effects: ценность растёт с пользователями. Direct (same-side): Facebook (больше = лучше для всех). Indirect (cross-side): Visa (больше магазинов → больше покупателей). Multi-sided platform: соединяет 2+ группы. Winner-takes-all тенденция при сильных сетевых эффектах. Chicken-and-egg problem: как запустить. | Platform envelopment: крупная платформа поглощает смежную меньшую (Microsoft vs Netscape). |
| bizstrategy.ops.job_to_be_done | Jobs to be Done Theory | METHOD | Теория «работ» (Кристенсен/Ulwick): клиенты «нанимают» продукты для выполнения «работ». Outcome-based innovation: определить недовыполненные desired outcomes. Пример: «Hire milkshake to make morning commute more enjoyable». Innovation opportunity: слабо закрытые «работы». Competitors = all solutions for the same job. | «People don't want a quarter-inch drill, they want a quarter-inch hole» (Levitt). |
| bizstrategy.ops.bcg_matrix | BCG Growth-Share Matrix | METHOD | Матрица BCG: Stars (высокий рост + высокая доля): инвестировать. Cash Cows (низкий рост + высокая доля): извлекать прибыль. Question Marks (высокий рост + низкая доля): selective investment. Dogs (низкий рост + низкая доля): divest. Limitation: относительная доля vs market attractiveness. | McKinsey-GE Matrix: более сложная (9 ячеек) версия. |
| bizstrategy.ops.vrio_framework | VRIO Framework | METHOD | VRIO (Барни): Valuable (создаёт ценность для клиента?). Rare (не у многих конкурентов?). Inimitable (сложно скопировать?). Organized (способна использовать?). Все четыре + = sustained competitive advantage. Три = temporary advantage. Первые два без Inimitable = competitive parity. | Inimitable ресурсы: историческая уникальность, социальная сложность, causal ambiguity. |
| bizstrategy.ops.growth_hacking | Growth Hacking — AARRR | METHOD | Pirate Metrics (AARRR): Acquisition (откуда приходят?), Activation (первый положительный опыт?), Retention (возвращаются?), Revenue (платят?), Referral (рекомендуют?). Воронка: Acquisition → Activation имеет наибольший leverage у новых продуктов. Product-Market Fit (PMF): >40% говорят «очень разочарованы» без продукта. | NPS как метрика Retention + Referral прокси. |
| bizstrategy.ops.m_and_a_value_creation | M&A — Value Creation Sources | METHOD | Слияния и поглощения: синергия — операционная (снижение затрат, объединение) vs финансовая (налоги, стоимость капитала). Revenue synergy: cross-sell, new markets. Управленческое замена. Market power. Asset stripping. Проблемы M&A: culture clash, overpayment (winner's curse), integration complexity. | Post-merger integration (PMI): 70-80% M&A разрушают ценность из-за плохой интеграции. |
| bizstrategy.ops.strategic_inflection_point | Strategic Inflection Points — Grove | METHOD | Точки стратегического перелома (Гроув, Intel): «10× change» в конкурентных силах. Сигналы: рынок меняется быстро, традиционные конкуренты теряют значение. Intel: shift from memory chips to microprocessors. «Only the Paranoid Survive». Useful for: restructuring, pivoting. | «When everybody knows the answer, nobody is asking the right question» — важность disruption detection. |
| bizstrategy.ops.innovation_ambidexterity | Organizational Ambidexterity | METHOD | Амбидекстерность (Tushman & O'Reilly): одновременно Exploitation (использование текущих компетенций) и Exploration (поиск новых). Structural ambidexterity: отдельные подразделения. Sequential: чередование. Contextual: среда поощряет оба поведения. Главная задача лидера: балансировать оба режима. | Exploration too much: не используем что имеем. Exploitation too much: устаревание. |
| bizstrategy.ops.ecosystem_strategy | Ecosystem Strategy — Key Concepts | METHOD | Бизнес-экосистема: сеть организаций co-evolving вокруг ценностного предложения. Keystone (ключевой вид): создаёт платформу для других (Microsoft, Apple). Dominator: контролирует всю цепочку (вред для экосистемы). Niche players: специализированные. Complementors (Brandenburger): не конкуренты, а ценностные партнёры. | Amazon: keystone для 3P sellers + logistics + AWS. |
| bizstrategy.ops.customer_lifetime_value | CLV — Calculation & Strategy | METHOD | Ценность клиента на протяжении жизни (CLV): CLV = (Average Purchase Value × Purchase Frequency) / Churn Rate. Или: CLV = Margin per customer / Churn rate. CAC (Customer Acquisition Cost): ROI = CLV/CAC (хорошо если ≥3). Customer segments: не все CLV одинаковы. LTV-to-CAC: 3:1 = benchmark для SaaS. | Retention improvement на 5% → прибыль растёт на 25-95% (Reichheld). |
