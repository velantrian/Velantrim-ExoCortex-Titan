| biology.cell.cell_theory | Cell Theory | INVARIANT | Все живые организмы состоят из клеток. Клетка — базовая единица жизни. Все клетки происходят от предсуществующих клеток (Вирхов, 1855). Прокариоты (бактерии, археи) и эукариоты. | Шлейден и Шванн (1839). Вирусы — не клетки (не имеют собственного метаболизма, не размножаются вне клетки). |
| biology.cell.plasma_membrane | Plasma Membrane — Fluid Mosaic | INVARIANT | Фосфолипидный бислой + белки + холестерин (у эукариот). Амфипатические липиды: гидрофильная голова, гидрофобный хвост. Текучесть: ненасыщенные жирные кислоты (изгиб «кинк») поддерживают текучесть, холестерин буферизует (при высоких T снижает, при низких повышает). | Singer-Nicholson (1972). Интегральные (трансмембранные) и периферические белки. Гликокаликс — углеводы на внешней поверхности (защита, узнавание). |
| biology.cell.membrane_transport | Membrane Transport | PROCESS | Пассивный: простая диффузия (O₂, CO₂, стероиды), облегчённая (GLUT — глюкоза, аквапорины — вода). Активный: первичный (Na⁺/K⁺-АТФаза, 3Na⁺ из клетки, 2K⁺ в клетку, 1 АТФ), вторичный (SGLT — симпорт Na⁺/глюкоза, Na⁺/Ca²⁺ обменник). | Дигиталис (дигоксин) ингибирует Na⁺/K⁺-АТФазу → ↑внутриклеточный Na⁺ → ↓обмен Na⁺/Ca²⁺ → ↑Ca²⁺ в кардиомиоцитах → ↑сократимость. |
| biology.cell.mitochondria | Mitochondria — Powerhouse | INVARIANT | Две мембраны: внешняя (гладкая), внутренняя (кристы — увеличение площади). Матрикс: цикл Кребса, β-окисление жирных кислот. Внутренняя мембрана: дыхательная цепь (комплексы I-IV), АТФ-синтаза (комплекс V). Собственная ДНК (кольцевая, 37 генов у человека), рибосомы 70S. | Наследование только по материнской линии. Митохондриальные болезни: LHON (зрительный нерв), MELAS (энцефалопатия, лактат-ацидоз). |
| biology.cell.glycolysis | Glycolysis — Embden-Meyerhof Pathway | INVARIANT | Глюкоза (C6) → 2 пирувата (C3) + 2 АТФ + 2 НАДH. 10 ферментативных стадий, цитозоль. Ключевые регуляторные ферменты: гексокиназа, фосфофруктокиназа-1 (PFK-1 — лимитирующая скорость), пируваткиназа. | АТФ и цитрат ингибируют PFK-1 (достаточно энергии → остановка гликолиза). АМФ и фруктозо-2,6-бисфосфат активируют (нужна энергия). Анаэробный гликолиз → лактат (регенерация NAD⁺). |
| biology.cell.krebs_cycle | Citric Acid (Krebs) Cycle | INVARIANT | Ацетил-CoA (2С) + оксалоацетат (4С) → цитрат (6С) → изоцитрат → α-кетоглутарат (5С) → сукцинил-CoA → сукцинат (4С) → фумарат → малат → оксалоацетат (цикл). 3 НАДН + 1 ФАДH₂ + 1 ГТФ за оборот. Матрикс митохондрий. | Пируватдегидрогеназный комплекс (ПДК): пируват → ацетил-CoA + CO₂ + НАДН. Регуляция: ингибируется НАДН, ацетил-CoA, АТФ (продуктами). Активируется Ca²⁺ и инсулином. |
| biology.cell.oxidative_phosphorylation | Oxidative Phosphorylation | INVARIANT | НАДН → Комплекс I (НАДН-дегидрогеназа) → CoQ → Комплекс III (цитохром bc₁) → Cyt c → Комплекс IV (цитохром c оксидаза) → O₂ → H₂O. Энергия переноса e⁻ используется для перекачки H⁺ в межмембранное пространство → протонный градиент → обратный ток H⁺ через АТФ-синтазу → АТФ. | 1 НАДН ≈ 2.5 АТФ, 1 ФАДH₂ ≈ 1.5 АТФ. Разобщители (UCP1 в буром жире, 2,4-DNP — яд) пропускают H⁺ мимо АТФ-синтазы → тепло вместо АТФ. Цианид и CO ингибируют комплекс IV → клеточное удушье. |
| biology.cell.gluconeogenesis | Gluconeogenesis | PROCESS | Синтез глюкозы из неуглеводных предшественников: лактат (цикл Кори), аминокислоты (аланин, глютамин), глицерол. В основном печень, немного почки. 7 из 10 реакций — обратные гликолизу; 3 обходных (пируваткарбоксилаза, PEPCK, фруктозо-1,6-бисфосфатаза, глюкозо-6-фосфатаза). | Метформин (диабет 2) подавляет глюконеогенез в печени (↓глюкоза крови). Глюкагон ↑, инсулин ↓ глюконеогенез. |
| biology.cell.cytoskeleton | Cytoskeleton Components | INVARIANT | Микрофиламенты (актин, 7 нм: форма клетки, движение, цитокинез). Промежуточные филаменты (10 нм: кератин, виментин, ламины — механическая прочность). Микротрубочки (тубулин, 25 нм: транспорт органелл, митотическое веретено, реснички/жгутики — аксонема 9+2). | Таксол (паклитаксел) стабилизирует микротрубочки → блок митоза → противоопухолевый. Винкристин — деполимеризует. Актин-миозиновое взаимодействие — основа движения. |
| biology.cell.motor_proteins | Motor Proteins | VARIANT | Миозин (движение по актину: миозин II — сокращение мышц, миозин V — транспорт везикул). Кинезин (движется к (+) концу микротрубочки — антероградный транспорт, к периферии). Динеин (к (−) концу — ретроградный, к телу клетки). Гидролиз АТФ как источник энергии. | Аксональный транспорт: кинезин доставляет везикулы от тела нейрона к синапсу. Динеин возвращает отработанные компоненты (аутофагия). Нарушения → нейродегенерация. |
| biology.cell.protein_sorting | Protein Sorting & Secretion | PROCESS | Сигнальная последовательность (N-конец) → распознавание SRP (signal recognition particle) → транслокация в ЭПР через транслокон Sec61 → сворачивание в ЭПР (+ гликозилирование, дисульфидные связи) → COPII везикулы → Гольджи (модификация: гликозилирование, сульфатирование) → сортировка в транс-Гольджи → секреторные везикулы / лизосомы (маннозо-6-фосфат маркер) / мембрана. | Муковисцидоз: мутация CFTR (ΔF508) → неправильное сворачивание → деградация в протеасоме вместо выхода на мембрану → нарушение транспорта Cl⁻. |
| biology.cell.enzyme_kinetics | Michaelis-Menten Kinetics | INVARIANT | v = V_max · [S] / (K_m + [S]). K_m — концентрация субстрата при ½V_max (мера сродства). V_max пропорциональна [E] и k_cat (число оборотов). Ингибирование: конкурентное (K_m↑, V_max прежняя), неконкурентное (K_m прежняя, V_max↓). | Lineweaver-Burk plot (1/v vs 1/[S]) — прямая линия, определяет тип ингибирования. |
| biology.cell.meiosis | Meiosis & Genetic Diversity | PROCESS | Одно удвоение ДНК, два деления → 4 гаплоидные клетки (n). Метафаза I: независимое расхождение хромосом (2²³ ≈ 8.4 млн комбинаций у человека). | Нерасхождение в мейозе I (трисомия 21 — синдром Дауна, возраст матери >35 — повышенный риск).
