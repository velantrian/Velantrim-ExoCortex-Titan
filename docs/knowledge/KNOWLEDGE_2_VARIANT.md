# 🌊 KNOWLEDGE_2_VARIANT — Меняющиеся факты (v3.0)

**Цель:** 500-1500 фактов.
**ESM:** → `Supported` или `Hypothesized`.
**Confidence:** 0.5-0.9.
**Время сбора:** 100-200 часов.

---

## 🎯 Что собирать

**Знания которые меняются:** актуальные данные, современные открытия, спорные вопросы.

**Проверка:** если факт сопровождается датой источника или фразой «учёные расходятся» — это VARIANT.

---

## 📚 Темы

### 🌍 География (меняющаяся)
- Текущие политические границы и столицы (переименования, новые государства)
- Состояние рек (пересыхание, изменение русел, загрязнение)
- Состояние ледников и арктического льда
- Численности населения стран и городов
- Координаты и статус природных объектов

### 🪨 Геология (частично меняющаяся)
- Активность вулканов (текущий статус: активный/спящий/потухший)
- Сейсмические зоны и их актуальная опасность
- Уточнения возраста горных пород по регионам
- Актуальные данные по месторождениям полезных ископаемых
- Состояние литосферных плит (скорости движения уточняются)

### 🌊 Гидрология
- Уровни Каспийского моря, Аральского моря (активно меняются)
- Состояние крупных озёр (Байкал, Виктория, Мичиган)
- Площадь ледников Гренландии и Антарктиды (ежегодно меняется)
- Уровень Мирового океана (текущие данные)

### 🌱 Почвоведение
- Деградация почв по регионам
- Опустынивание (площади Сахары и других пустынь меняются)
- Плодородность агрокультурных зон

### 📜 История (факты уточняются и переосмысляются)
- Археологические открытия (новые находки меняют датировки)
- Уточнения хронологий (радиоуглеродный анализ даёт новые даты)
- Пересмотр причин исторических событий
- Открытие неизвестных цивилизаций и культур
- Документальные свидетельства (рассекреченные архивы)
- Демографические оценки исторических периодов

### 🌡️ Климат
- Концентрация CO₂, температурные аномалии
- Состояние биоразнообразия

### 🧬 Современная медицина
- Эффективность лекарств
- Протоколы лечения (актуальные)
- Микробиом, эпигенетика

### 🚀 Космос
- Известные экзопланеты
- Космические миссии
- Гипотезы (тёмная материя, мультивселенная)

### 💻 Технологии
- Состояние AI/ML
- Квантовые вычисления
- Современные материалы

### 📜 История (уточнения)
- Археологические открытия
- Уточнения хронологий

## 📦 Формат v3.0

```json
{
  "id": "fact.amazon.length",
  "domain": "geography",
  "type": "fact",
  "statement": "Длина Амазонки приблизительно 6 992 км.",
  "conditions": "Зависит от методики измерения.",
  "limits": ["Бразильские источники оспаривают первенство Нила (6 853 км)"],
  "prereq": [],
  "confidence": 0.75,
  "tags": ["amazon", "river", "geography"],

  "source": "Bertarelli Foundation Marine Reserve Programme, 2014",
  "valid_from": "2014-01-01",
  "valid_until": null,
  "has_disputes": true,
  "alternative_views": [
    {
      "claim": "Нил длиннее Амазонки (6 853 км)",
      "confidence": 0.6
    }
  ]
}
```

**Особые поля для VARIANT:**
- `source` — обязательно
- `valid_from` — обязательно
- `valid_until` — null если ещё актуально
- `has_disputes` — true/false
- `alternative_views` — массив альтернатив с confidence

## 🤖 Инструкция для ИИ-сборщика

1. Возьми тему (например, климатические данные).
2. Собери 25-30 фактов на файл.
3. Формат v3.0.
4. **ОБЯЗАТЕЛЬНО:**
   - `source` — конкретный источник
   - `valid_from` — дата
   - `has_disputes` — если есть споры
5. **Confidence по шкале:**
   - 0.85-0.95 — стабильно подтверждено
   - 0.7-0.85 — общепринято, возможны уточнения
   - 0.5-0.7 — активные споры
   - 0.3-0.5 — гипотеза
6. **НЕ ДОБАВЛЯЙ:** examples, why_it_matters, common_confusions.

**Объём на файл:** 25-30 фактов. Файлов ~20-50.
