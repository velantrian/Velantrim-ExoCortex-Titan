# 🤖 Velantrim — Промпты для сбора знаний

**Версия:** 1.0
**Дата:** 20 мая 2026
**Использование:** вставить в чат с ИИ вместе с соответствующим документом-инструкцией

---

## 📋 Как использовать

```
1. Открыть новый чат с ИИ (Claude / ChatGPT / Gemini / DeepSeek)
2. Загрузить ОДИН документ (например KNOWLEDGE_BASE_LAWS.md)
3. Скопировать нужный промпт ниже
4. Заменить [ТЕМУ] на конкретную тему
5. Получить JSON → сохранить как файл
```

**Формат имён файлов:** `{domain}_{001}_{025}.json`
Пример: `base_laws_001_025.json`, `invariant_math_026_050.json`
