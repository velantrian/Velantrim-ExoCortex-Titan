## 📦 Формат v3.0

```json
{
  "id": "process.metallurgy.bof",
  "domain": "metallurgy",
  "type": "process",
  "statement": "Кислородно-конвертерный процесс производит сталь продувкой кислорода через расплавленный чугун при 1600-1700°C.",
  "conditions": "Промышленный масштаб; доступ к жидкому чугуну и кислороду.",
  "limits": [
    "Не подходит для мелкомасштабного производства",
    "Не работает для нержавеющих сталей (нужен EAF)"
  ],
  "prereq": ["process.iron_smelting", "concept.oxidation"],
  "derives_from": ["law.conservation_mass", "law.thermodynamics.1"],
  "confidence": 0.95,
  "tags": ["steel", "BOF", "metallurgy"],

  "success_rate": 0.98,
  "scale": "industrial",
  "safety_critical": true,
  "safety_notes": "Расплавленный металл 1700°C; CO выделяется; опасность взрыва при влаге.",
  "source": "ASM Handbook"
}
```

**Особые поля для PRACTICAL:**
- `success_rate` — надёжность 0-1
- `scale` — `industrial` / `workshop` / `home`
- `safety_critical` — true/false
- `safety_notes` — критичные риски

## 🤖 Инструкция для ИИ-сборщика

1. Возьми индустрию (например, металлургия).
2. Собери 25-30 процессов на файл.
3. **СУТЬ В STATEMENT:** что делает, не как работает в деталях.
4. **ОБЯЗАТЕЛЬНО:**
   - `scale` — масштаб
   - `success_rate` — надёжность
   - `safety_critical` + `safety_notes` если есть риски
   - `derives_from` — на каких законах
5. **НЕ ДОБАВЛЯЙ:** examples, why_it_matters, длинные описания процесса.

**Объём:** 25-30 на файл. Файлов ~30-50.
