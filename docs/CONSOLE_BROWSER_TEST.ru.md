# Веб-консоль Velantrim — тестовая система в браузере

> **Статус:** экспериментальный стенд для локальной проверки памяти, LLM и визуализации «эссенции» диалога.  
> **Не production.** Данные блока памяти хранятся в **браузере** (localStorage), не в облаке по умолчанию.

## Как включить

1. Установите зависимости и подготовьте `.env` (см. [README.md](../README.md)).
2. Запустите сервер с консолью:

```powershell
cd "C:\path\to\Velantrim-ExoCortex-Titan"
.\scripts\start_console.ps1
```

Скрипт откроет браузер по адресу:

`http://127.0.0.1:8755/console/?v=40`

3. В **браузере** (Chrome, Edge, Firefox):
   - введите ключ Velantrim API (или dev-ключ из скрипта);
   - при необходимости включите LLM и вставьте ключ провайдера (DeepSeek, Gemini и т.д.);
   - пишите в чат — система работает **только пока открыта вкладка** и запущен локальный сервер.

Перезагрузка страницы с **Ctrl+F5** подтягивает новую версию UI (`?v=…` в URL).

## Что это за система

| Компонент | Назначение |
|-----------|------------|
| **Чат** | Диалог с LLM; история сессии в браузере |
| **Память → блок** | Заметки в `localStorage` — видны новым чатам и подмешиваются в prompt |
| **Память → система** | Опционально POST `/facts` + RAG (нужна галочка «Также в систему Velantrim») |
| **Эссенция** (вкладка 🔗) | **Живой граф** темы, узлов и связей из сообщения и памяти — не полный текст чата |

Консоль **не** подключает полную «энциклопедию человечества». Эссенция строится из:

- текста вашего сообщения (эвристики + шаблоны);
- блока памяти браузера;
- фактов, найденных RAG по запросу.

Педагогическая строка в панели — **для человека**; в LLM уходит компактный граф и факты.

## LLM: длина ответа и DeepSeek Thinking

| Настройка | Где | Описание |
|-----------|-----|----------|
| **Макс. токенов ответа** | Левая колонка, блок LLM, слайдер | 256–40 000 (по умолчанию 8192). Раньше лимит ~1024 обрезал длинные ответы. |
| **Thinking (DeepSeek V4)** | Только при провайдере DeepSeek | `Выкл` / `High` / `X-High (max)` — см. [Thinking Mode](https://api-docs.deepseek.com/guides/thinking_mode) |
| **🧠 в чате** | Во время стрима | Пока модель отдаёт `reasoning_content`, показывается анимация мозга; финальный текст — в `content`. |

Модели в списке обновлены под OpenAI (GPT‑4.1, GPT‑5), Gemini 2.5/3.x, DeepSeek V4 Flash/Pro.

---

При включённом **«Печатать ответ»** (SSE `/chat/stream`) сервер шлёт события:

| Стадия | Смысл |
|--------|--------|
| `read` | Разбор сообщения: тема, намерение, сущности |
| `link` | Связь с блоком памяти и фактами RAG |
| `commit` | Кандидаты и автосохранение после ответа |

Вкладка **🔗 Эссенция** обновляется по мере стадий. Галочка **«Открывать при отправке»** переключает на эту вкладку при каждом сообщении.

Справка в браузере: `GET /console/help` (этот файл в Markdown).
Roadmap задач: `GET /console/roadmap` (интерактивная страница по аудит-бэклогу).
Research Mode overview: `GET /console/research-mode` (красивая HTML-страница).
Raw Markdown: `GET /console/research-mode.md`.

## Research Mode

Для экспериментов с Fractal Router и `RetrievalPath` предусмотрена отдельная
спека: [RESEARCH_MODE.ru.md](RESEARCH_MODE.ru.md).

Идея: браузерная Research Console должна использовать Velantrim как API-инструмент
памяти, но писать в отдельную БД `data/velantrim_research.db`, не трогая stable
память V8.6. Планируемые маршруты: `/console/research`, `/research/query`,
`/research/facts`.

## Ограничения тест-режима

- Блок памяти **не синхронизируется** между устройствами и браузерами.
- RAG возвращает **несколько** наиболее похожих фактов, не «всю биографию».
- Сложные правки («исправь то, что было раньше») лучше формулировать явно: `запомни: …`.
- Для production нужны отдельный профиль, ключи, бэкап БД и политика приватности.

## Связанные файлы

- UI: `static/console/index.html`
- Эссенция: `core/dialogue_essence.py`
- Чат API: `POST /chat`, `POST /chat/stream` в `server.py`
- Память чата: `core/console_memory.py`

## Дальнейшее развитие (идея)

- LLM-извлечение узлов/связей вместо только эвристик;
- слой компактной онтологии (типы отношений, «исправление» vs «новый факт»);
- экспорт графа эссенции в долгую память `/facts`.
