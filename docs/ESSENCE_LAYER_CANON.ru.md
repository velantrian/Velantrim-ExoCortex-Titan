# 🌿 Essence Layer Canon v1.0

**Статус:** future work / архитектурный канон  
**Runtime:** не активирован как отдельный слой  
**Правило:** не менять stable `/query`, БД и Truth Gate без отдельного RFC, тестов и feature flag.

---

## Простая цель

Essence Layer нужен, чтобы Velantrim отвечал не длинным пересказом, а как человек,
который понял главное:

```text
вход: много терминов, фактов, противоречий и деталей
выход: короткая суть + смысловая цепочка + почему это важно
```

Это не “эмоции” и не “личность”. Это **ясность мышления**:
система выделяет главное, связывает сложные куски и отдаёт короткий ответ.

---

## Что он делает

| Компонент | Простыми словами | Результат |
|-----------|------------------|-----------|
| `EssenceExtractor` | находит главную мысль | “о чём это на самом деле” |
| `MeaningRoleTagger` | отделяет причину, механизм, следствие, риск, пример | текст превращается в структуру |
| `ConceptMapper` | понимает, что разные термины могут говорить об одной идее | меньше путаницы в словах |
| `MeaningChainBuilder` | строит цепочку `A -> B -> C` | видно, как одно ведёт к другому |
| `ShortAnswerComposer` | сжимает вывод до человеческой формы | короткий ответ без воды |
| `WhyTrace` | сохраняет, почему выбрана именно эта суть | проверяемость и объяснимость |

---

## Пример

Вход:

```text
Fractal Memory, Knowledge Quality, Temporal Epistemology,
Negative Knowledge, TRACE, Cross-Domain Bridges...
```

Плохой ответ:

```text
Вот список модулей: Fractal Memory, Quality Layer, Temporal...
```

Ответ через Essence Layer:

```text
Суть: Velantrim должен не просто помнить факты, а понимать,
насколько им можно доверять, не устарели ли они, не противоречат ли другим
фактам и как из них получается короткий вывод.
```

---

## Минимальный pipeline

```text
1. Input Chunk
   -> выделить ключевые утверждения

2. Meaning Roles
   -> что является причиной, механизмом, следствием, риском, примером

3. Concept Mapping
   -> связать разные термины, если они говорят об одной сути

4. Meaning Chain
   -> построить цепочку смысла: причина -> механизм -> вывод

5. Short Answer
   -> ответить коротко, без потери главного

6. WhyTrace
   -> сохранить, почему эта суть была выбрана
```

---

## Как это связано с текущей архитектурой

| Уже есть | Как Essence Layer использует |
|----------|------------------------------|
| Fractal Memory | берёт материал с нужного уровня памяти |
| Retrieval / PPR / BM25 | получает найденные факты, но не пересказывает всё подряд |
| Cross-Domain | связывает термины из разных областей |
| Causal Graph | превращает связи в цепочки причин и следствий |
| TRACE | сохраняет путь: какие факты дали эту суть |
| Guardian / Truth Gate | не даёт сжать сомнительное в уверенный вывод |
| World Knowledge Core | даёт качество, время, negative knowledge и противоречия |

---

## Что нельзя делать

- Нельзя подменять Truth Gate красивой формулировкой.
- Нельзя скрывать неопределённость ради короткого ответа.
- Нельзя превращать это в “личность” или фальшивые эмоции.
- Нельзя делать auto-write в L3 без Pending/Review.
- Нельзя выкидывать источники и TRACE ради “человечности”.

---

## Чем это делает систему человечнее

Не тем, что система притворяется человеком.

А тем, что она отвечает как хороший инженер или исследователь:

1. Понимает главный вопрос.
2. Отбрасывает шум.
3. Связывает термины в смысловую цепочку.
4. Показывает, что важно.
5. Говорит коротко.
6. При необходимости раскрывает TRACE.

---

## P0 для будущей реализации

1. `EssenceSummary`: одно предложение “суть этого блока”.
2. `MeaningRole`: `cause`, `mechanism`, `effect`, `risk`, `example`, `source`, `decision`.
3. `MeaningChain`: список шагов `A -> B -> C`.
4. `ShortAnswerPolicy`: коротко, но не скрывать uncertainty.
5. `WhyTrace`: почему выбрана такая суть.

---

## Каноническая формула

```text
Essence Layer =
  extract gist
  + map concepts
  + build meaning chain
  + preserve uncertainty
  + answer briefly
  + keep WhyTrace
```

Коротко:

> Essence Layer делает Velantrim более “человечным” не через эмоции,
> а через способность схватить главное, связать сложное и объяснить коротко.
