# 📓 Diary — личный журнал Велантрийца

Эта папка — для твоих заметок, наблюдений, мыслей о направлении проекта.

В отличие от `CHANGELOG_*.md`, которые фиксируют технические правки,
Diary хранит **смысл** — почему ты строишь Velantrim, какие у тебя
видения, что тебя ведёт.

## Записи

- **`01_vision_manifesto.md`** — манифест автора, отправная точка проекта.
  Объясняет, зачем нужен Velantrim, и чем он отличается от обычных
  RAG-систем и LLM-агентов. Если хочешь понять «душу» проекта — начни отсюда.

- **`02_polyperspective_seed.md`** — рабочий чертёж первой полиперспективной
  базы знаний Velantrim. Пятиуровневая структура (инварианты мира →
  биология → конкретные Umwelt'ы → технологии → перекрёстные паттерны),
  с примерами для 8 агентов (воробей, кошка, муравей, дождевой червь,
  грибница, человек-натуралист, столяр, ребёнок) и 4 технологий
  (компьютер, SQLite, LLM, Velantrim). Готов к расширению.

- **`umwelt_mvp_seed.json`** — runtime seed для Umwelt store (layer 99):
  дерево / дождь / дом × инженер, учёный, воробей. Загрузка: `POST /umwelt/seed`
  или автоматически при старте (`ENABLE_UMWELT_AUTO_SEED=1`).

## Как добавлять записи

Используй нумерацию + короткое имя темы, например:
`02_first_benchmark_thoughts.md`, `03_understanding_layer_design.md`,
`04_v8.6_priorities.md`. Дату ставь в начале файла. Это не обязательно,
но помогает потом восстанавливать хронологию своих мыслей.

Пиши в любом стиле: тезисы, поток сознания, разговор с самим собой,
спор с предыдущими записями. Дневник для тебя, не для кого-то ещё.
