# 🗄️ Бэкенды памяти Velantrim — SQLite / Kuzu / Graphiti (опционально)

> **Дата:** 2026-05-31 · Память V8.6 **сменная (pluggable)**: слой `GraphStore ABC` +
> фабрика `core/backends/factory.py`, выбор через `STORAGE_BACKEND`. Можно начать на SQLite,
> а позже включить графовый бэкенд **без переписывания остального кода**.
>
> **Главное:** Graphiti **не выкидываем** — это готовая зрелая технология. Он подключается
> **опционально** и даёт возможности, которых нет у SQLite. Ниже — что выбрать и зачем.

---

## Доступные бэкенды

| Бэкенд | `STORAGE_BACKEND` | Зависимости | Где живёт |
|---|---|---|---|
| **In-memory** | `memory` | нет | ОЗУ (тесты, эфемерно) |
| **SQLite** 🟢 *(дефолт)* | `sqlite` | stdlib | один файл `./data/*.db` |
| **Kuzu** | `kuzu` | `kuzu` (pip) | встроенная граф-БД, файл, без сервера |
| **Ladybug** | `ladybug` | `ladybug` | встроенная граф-БД (fallback → sqlite) |
| **Graphiti + Neo4j** | `neo4j` / `kuzu`(+graphiti) | `graphiti-core` + сервер Neo4j + LLM-ключ | граф-сервер + bi-temporal |

Все реализуют один контракт `GraphStore`, поэтому остальной код (ESM, Truth Gate, Essence,
retrieval) работает **одинаково** на любом бэкенде. Недоступный бэкенд **gracefully** падает в SQLite.

---

## Что даёт Graphiti **сверх** SQLite (ключевое)

SQLite честно хранит факты + bi-temporal поля (как TEXT) + BM25/FTS5-поиск. Этого хватает для
большинства локальных сценариев. Но это **таблица фактов**, а не живой граф. Graphiti добавляет:

| Возможность | SQLite (дефолт) | **Graphiti + Neo4j** |
|---|---|---|
| 🕸️ **Нативный граф-обход** | LIKE/FTS5 по тексту, связи вручную | Cypher-обход связей любой глубины (A→B→C…) «из коробки» |
| ⏳ **Bi-temporal рёбра** | поля-строки, проверка вручную | нативный тип `datetime` + **temporal invalidation** рёбер |
| 🧩 **Community detection** | ❌ нет | `build_communities()` → авто-кластеры → это и есть **L2 «семантические сообщества»** |
| 🌀 **L3 фрактальный профиль** | ❌ нет | LLM-синтез профиля сущности из сообществ (см. донор `layers/l3_fractal`) |
| 🔎 **Гибридный поиск** | BM25 + (опц.) dense | BM25 + vector + **graph-aware** в одном запросе |
| 🧬 **Авто-извлечение сущностей/связей** | ручное / linker по тегам | LLM парсит текст → узлы+рёбра автоматически |
| 🔗 **Связность знаний** | через наш `knowledge_linker` (эвристика) | семантические рёбра от модели |

> 💡 **Перевод на простой язык:** на SQLite система **помнит факты**; с Graphiti она **видит граф
> знаний целиком** — сама группирует родственное в «сообщества» (L2), строит профили (L3) и
> ходит по связям вглубь. Это прямой путь к «понимает суть и связи», который ты задумывал.

---

## Чем платим за Graphiti (честно)

| Минус | Деталь |
|---|---|
| ⚙️ **Нужен сервер Neo4j** | отдельный процесс/докер, не «один файл» как SQLite |
| 💸 **Нужен LLM** | авто-извлечение сущностей/связей и L3-профили требуют LLM-вызовов (у тебя `LLM_PROVIDER=none`) |
| 🐢 **Тяжелее и медленнее** | запросы к графу + сетевой слой vs локальный SQLite |
| 📦 **Доп. зависимость** | `graphiti-core` (есть в `pyproject` extra `async-backend`) |

---

## 🎯 Когда что выбирать

- 🟢 **SQLite** — по умолчанию: локально, быстро, ноль зависимостей, для разработки/демо/гранта на одной машине. **Сейчас все наши фичи (ESM, Essence, обучение, забывание, linker) работают на нём.**
- 🟡 **Kuzu** — если нужен **настоящий граф-обход локально**, но без сервера Neo4j и без LLM. Хороший средний шаг: Cypher + связи, всё в файле.
- 🔵 **Graphiti + Neo4j** — когда дойдём до **богатого семантического графа**: сообщества (L2), фрактальные профили (L3), авто-извлечение связей. Включать, когда (а) подключим LLM и (б) нужен масштаб/качество связей выше эвристики.

---

## Как включить (когда захочешь)

```env
# вариант Kuzu (граф локально, без сервера, без LLM)
STORAGE_BACKEND=kuzu
KUZU_DB_PATH=./data/exocortex.kuzu

# вариант Graphiti + Neo4j (богатый семантический граф; нужен сервер + LLM)
STORAGE_BACKEND=neo4j
NEO4J_URI=bolt://localhost:7687
LLM_PROVIDER=...        # для авто-извлечения и L3-профилей
```
По умолчанию — `sqlite`, ничего включать не нужно. Бэкенд меняется **одной строкой**, остальной
код не трогается (в этом смысл `GraphStore ABC`).
